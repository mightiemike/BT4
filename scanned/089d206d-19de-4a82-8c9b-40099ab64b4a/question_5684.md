# Q5684: system-borrow via borrow: absorb a sub-step failure into a fold flag and proceed on 

## Question
Does `borrow` (mainnet/contracts/market/v0-4-market.clar:1238) let an unprivileged attacker who controls `amount` reach `system-borrow` (mainnet/contracts/vault/v0-vault-stx.clar:865) in a state where it absorb a sub-step failure into a fold flag and proceed on partial state? Given that it independently computes `scaled-amount` with `mul-div-up` from its own `index`, duplicating the market's own scaling of the same borrow, the invariant that when a multi-step entry point aborts, no value is stranded and no identifier survives breaks and the result is protocol insolvency through uncollateralised debt.

- Expected Immunefi impact: Critical - protocol insolvency through uncollateralised debt
