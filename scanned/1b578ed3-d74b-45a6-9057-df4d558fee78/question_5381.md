# Q5381: insert via collateral-remove: reuse one price and index snapshot across a batch that mut

## Question

- Entrypoint: `collateral-remove` (`mainnet/contracts/market/v0-4-market.clar:1107`), unprivileged and publicly callable

- Exploit idea: `insert` rewrites the whole registry entry for a user id. Reach it through `collateral-remove` and reuse one price and index snapshot across a batch that mutates state between entries.

- Expected Immunefi impact: Critical - protocol insolvency through uncollateralised debt
- Fast validation: Run the baseline `collateral-remove` call, then the attacker-shaped one with whether the position has any enabled debt row (the has-debt branch), and assert the attacker's net token balance change is zero or negative.
