# Q2816: oracle-timestamp-fresh via collateral-remove-redeem: bind a balance before an accrual and assert against it aft

## Question
Does `collateral-remove-redeem` (mainnet/contracts/market/v0-4-market.clar:1211) let an unprivileged attacker who controls `receiver` for the underlying leg reach `oracle-timestamp-fresh` (mainnet/contracts/market/v0-4-market.clar:365) in a state where it bind a balance before an accrual and assert against it after?
