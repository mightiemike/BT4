Preconditions: sequencer bundles both txs in one L2 block (default block building loop in `runner.rs`). Binding: `ProverStorage::compute_state_update`'s `final_root` for L2 block N == `ZkStorage::compute_state_update`'s `final_root` for L2 block N, verified via the `StateRootTransition` returned to `StfBlueprint::finalize_l2_block`/`apply_l2_block`.
