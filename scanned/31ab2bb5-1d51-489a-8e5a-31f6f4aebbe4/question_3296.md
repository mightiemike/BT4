# Q3296: normalize via call-ststx-ratio: reuse one price and index snapshot across a batch that mut

## Question
Does `call-ststx-ratio` (mainnet/contracts/market/v0-4-market.clar:1015) let an unprivileged attacker who controls the block and transaction position at which the external ratio is fetched reach `normalize` (mainnet/contracts/market/v0-4-market.clar:576) in a state where it reuse one price and index snapshot across a batch that mutates state between entries? Given that it divides by `(pow u10 decimals)` only AFTER multiplying amount by price, making the protocol's USD unit a whole dollar, the invariant that a failed sub-step aborts the transaction or is explicitly compensated breaks and the result is protocol insolvency.

- Expected Immunefi impact: Critical - protocol insolvency
