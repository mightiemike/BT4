Binding: `BitcoinLightClient::getBlockHash(height)` computed by every honest full node after processing L1 block N == the same value for all honest full nodes. Impact: Critical, honest full nodes converging on different state roots (EXECUTION AGREEMENT violated), which also breaks batch-proof verifiability for whichever node's root the prover doesn't match.
