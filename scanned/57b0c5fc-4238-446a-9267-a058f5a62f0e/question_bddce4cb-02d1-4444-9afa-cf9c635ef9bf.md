Precondition: Bridge initialized, first deposit already processed. Sequence: craft tx2 with same vin/vout/version/locktime as tx1 but different witness -> compute new `wtxId2` -> get inclusion proof for tx2 -> `deposit(tx2, proof2, shaScriptPubkeys2)`. Binding: cBTC credited count == number of distinct Bitcoin `wtxId`-identified deposits actually mined (CUSTODY, counted exactly once). Impact: Critical, potential double mint if `txId` collision allows bypassing the nullifier while a distinct `wtxId` still gets counted as a fresh deposit. Proof: cargo/forge test constructing two txs with identical txid-relevant fields but different witnesses, asserting the second deposit call reverts.
