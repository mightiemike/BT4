Can a miner who repeatedly wins sortitions but intentionally fails to produce a tenure-change block (missed sortitions) accumulate `accumulated_coinbase_ustx` across several burn blocks, then finally produce a valid tenure and claim `coinbase_at_block + accumulated_rewards` as a single coinbase, exceeding what a single sortition win is supposed to award, and can this be claimed *again* if a later sibling fork replays the same accumulated_coinbase_ustx snapshot for a different winning block at the same burn height? Equality that must hold: total_coinbase credited to the eventual tenure == coinbase_at_block + accumulated_rewards, credited exactly once across the whole chain, not once per fork that references the same electing snapshot. Impact: Critical if two sibling forks both claim the same `accumulated_coinbase_ustx` (double-mint of missed-sortition coinbase); otherwise High if bounded to a single tenure.
