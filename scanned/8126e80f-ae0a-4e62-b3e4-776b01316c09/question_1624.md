# Q1624: get-account-scaled-debt via liquidate-multi: reuse one price and index snapshot across a batch that mut

## Question
Does `liquidate-multi` (mainnet/contracts/market/v0-4-market.clar:1593) let an unprivileged attacker who controls the full batch list and its ordering reach `get-account-scaled-debt` (mainnet/contracts/market/v0-market-vault.clar:307) in a state where it reuse one price and index snapshot across a batch that mutates state between entries? - Expected Immunefi impact: Critical - direct theft of another user's collateral
