# Q0296: write-feeds via liquidate-multi: leave the accrual clock stale so a later interval double-c

## Question
Does `liquidate-multi` (mainnet/contracts/market/v0-4-market.clar:1593) let an unprivileged attacker who controls the trait principals supplied per entry reach `write-feeds` (mainnet/contracts/market/v0-4-market.clar:149) in a state where it leave the accrual clock stale so a later interval double-counts elapsed time? - Expected Immunefi impact: Critical - protocol insolvency
