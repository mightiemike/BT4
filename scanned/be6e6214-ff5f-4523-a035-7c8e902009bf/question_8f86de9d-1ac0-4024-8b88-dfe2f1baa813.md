Preconditions: JMT state after a block containing both orphan chunks and a genuinely processed complete proof. Call sequence: advancement logic reads `VerifiedStateTransitionForSequencerCommitmentIndexAccessor::get(next_index, ...)` and compares `initial state root == last L2 state root` before updating `last_l2_height`/`l2_state_root`. Binding: `last_l2_state_root` after `run_l1_block` == the `l2_state_root` field of the actual `BatchProofCircuitOutput` most recently verified by `process_complete_proof`, unaffected by any unrelated `ChunkAccessor` entries. Impact: Critical — an unrelated/orphan chunk causing the wrong state root to be advanced would make honest full nodes converge on a state root the proved chain does not contain. Proof idea: cargo test flooding orphan chunks alongside one legitimate complete proof and asserting `output.l2_state_root` equals the value from a control run with no orphan chunks present.
