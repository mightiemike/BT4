`StacksChainState::get_matured_miner_payment` (accounts.rs) expects exactly 2 rows for a `(parent_block_id, child_block_id)` pair and dispatches via `ret_0.is_child()` / `ret_1.is_child()`, calling `.try_add_parent(...).expect("FATAL: got two child rewards")`. `MinerReward::is_child` is defined as `self.coinbase > 0 && self.tx_fees_streamed_produced == 0`, and `is_parent` as `self.coinbase == 0`. Impact: Critical (permanent fork freeze / node divergence if crash is non-deterministic across nodes).
