Proof idea: cargo test constructing a `HeaderWrapper` with `precomputed_hash` set to an arbitrary value not matching the inner header bytes, and asserting `verify_header_chain_common` returns `Err(ValidationError::InvalidBlockHash)` rather than proceeding.
