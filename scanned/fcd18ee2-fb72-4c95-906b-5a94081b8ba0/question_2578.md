# Q2578: collateral-add via liquidate-redeem: bind a balance before an accrual and assert against it aft

## Question
Entering through `liquidate-redeem` (mainnet/contracts/market/v0-4-market.clar:1604) while controlling the borrower targeted, can an unprivileged attacker make `collateral-add` (mainnet/contracts/market/v0-market-vault.clar:374) bind a balance before an accrual and assert against it after? `collateral-add` evaluates the map write and `mask-update` as `let` bindings BEFORE `check-impl-auth`, the pause state and the amount assertion, so the invariant that a failed sub-step aborts the transaction or is explicitly compensated would fail, yielding direct theft of another user's collateral.
