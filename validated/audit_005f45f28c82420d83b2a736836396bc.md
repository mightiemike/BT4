## Title
Autoswap `minPCOut` self-referenced from same-block Uniswap spot quote enables DEX price-manipulation to devalue user gas top-ups on GAS/GAS_AND_PAYLOAD inbounds - (File: `x/uexecutor/keeper/evm.go`, `x/uexecutor/keeper/execute_inbound_gas.go`, `x/uexecutor/keeper/execute_inbound_gas_and_payload.go`)

### Summary
The PrimeX report's root cause was that slippage protection was derived purely from the same manipulable DEX price rather than an independent oracle, letting a keeper flash-loan the pool and execute against a self-referential bound. Push Chain's `x/uexecutor` autoswap path for `GAS` and `GAS_AND_PAYLOAD` inbounds has the identical pattern: the "protection" bound (`minPCOut`) is computed from a single-block spot quote of the very same Uniswap V3 pool that is swapped against a moment later, with no comparison to the independently-voted `ChainMeta`/oracle price.

### Finding Description
When an inbound of type `GAS` or `GAS_AND_PAYLOAD` finalizes (any unprivileged user can trigger this simply by bridging an asset from a supported external chain and having honest Universal Validators observe/vote it — see `x/uexecutor/keeper/msg_vote_inbound.go` `VoteInbound` → `ExecuteInbound`), the keeper swaps the deposited PRC20 for PC via `depositPRC20WithAutoSwap`. The `minPCOut` bound is derived like this in `ExecuteInboundGas` (`x/uexecutor/keeper/execute_inbound_gas.go:104-153`) and `gasAndPayloadDepositAutoSwap` (`x/uexecutor/keeper/execute_inbound_gas_and_payload.go:347-379`):

1. `GetSwapQuote` calls `QuoterV2.quoteExactInputSingle` (`sqrtPriceLimitX96 = 0`, no TWAP) — a pure single-block spot-price simulation against the live Uniswap V3 pool: [1](#0-0) 
2. `minPCOut = quote * 95 / 100` — a fixed 5% band computed relative to that same spot quote: [2](#0-1) 
3. The actual swap executes moments later against the same pool via `CallPRC20DepositAutoSwap`: [3](#0-2) 

Nowhere in this flow is the result cross-checked against the module's independent `ChainMeta` oracle (aggregated across Universal Validator votes, see `x/uexecutor/keeper/chain_meta.go`) or any other price source external to the pool being traded against. If the pool's price has been pushed away from fair value by a preceding transaction in the same block (e.g., a large swap funded by a flash loan), both the quote and the executed swap reflect the manipulated price — the 5% band only bounds intra-call slippage, it does nothing to detect that the reference price itself is wrong.

This is architecturally the same flaw as the PrimeX report: slippage/oracle protection that is self-referential to the very DEX being traded against, rather than checked against an independent price feed.

### Impact Explanation
A successful attack devalues the PC amount minted for the bridged user's gas top-up (and, for `GAS_AND_PAYLOAD`, the funds available to their payload execution), effectively transferring value from the protocol/user swap to whoever reverses the pool manipulation for arbitrage profit. This corrupts native/PRC20 asset accounting for the affected `UniversalTx` (the `PCTx`/`OutboundTx` records reflect a swap executed at a manipulated price) and represents a fund-drain vector reachable purely from an ordinary, unprivileged user's bridge deposit combined with routine DEX interaction — no privileged actor is required.

### Likelihood Explanation
Requires the attacker to time a large pool-skewing swap to land in the same block, immediately before, the block that finalizes the target `MsgVoteInbound`/executes the autoswap. On a chain that also processes EVM transactions in the same blocks, this is a realistic same-block MEV pattern (mempool observation + gas/priority ordering), and the underlying Uniswap V3 pools for PRC20/WPC pairs are expected to be the natural liquidity venues for bridged assets, likely with moderate depth, making manipulation economically feasible especially for newly-listed or thinner PRC20 tokens.

### Recommendation
Bound `minPCOut` (or reject/flag the autoswap) using an independent reference price — e.g., compare the QuoterV2 spot quote against the aggregated `ChainMeta`/oracle-derived expected value (or a TWAP observation from the pool) within a tolerable deviation, similar to the PrimeX fix's `needOracleTolerableLimitCheck`/`maximumOracleTolerableLimit` pattern, rather than deriving the tolerance solely from the same block's spot quote of the pool being traded.

### Proof of Concept
1. Attacker identifies (or triggers) a pending `GAS`/`GAS_AND_PAYLOAD` inbound for a target PRC20/WPC pool with modest on-chain liquidity.
2. In the block where the finalizing `MsgVoteInbound` (crossing the 2/3 threshold) is expected to land, attacker submits a flash-loan-funded large swap on the same Uniswap V3 pool ordered immediately before it, depressing `WPC` output for `tokenIn = prc20`.
3. `ExecuteInboundGas`/`gasAndPayloadDepositAutoSwap` calls `GetSwapQuote` against the now-skewed pool, computes `minPCOut = quote*0.95` based on the bad price, and `CallPRC20DepositAutoSwap` executes successfully at that same bad price (no revert, since the band is self-consistent).
4. Attacker reverses their manipulating swap later in the block/next block, capturing arbitrage profit extracted from the value the bridging user should have received, while the `UniversalTx`/`OutboundTx` records reflect fewer PC minted for the honest depositor than fair market value warranted. // GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}
