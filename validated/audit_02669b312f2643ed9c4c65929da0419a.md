The `left`/`right` temporaries at storage_gas.move:467-472 are not a security defect. This mirrors the same sentinel convention already used and formally specified in `validate_points`, which explicitly treats `Point{0,0}` and `Point{BASIS_POINT_DENOMINATION, BASIS_POINT_DENOMINATION}` as the implicit boundary points surrounding `curve.points` <cite repo="patrichyt/aptos-core--035" path="aptos-move/framework/aptos-framework/sources/storage_gas.move" start="440="440" end="450" />.

These constants are not read from any external or attacker-influenced source — they are hardcoded literals evaluated identically by every validator executing the same bytecode, so there is no scope for an "unprivileged actor" to substitute a different curve or cause divergent results between nodes. `calculate_gas` is a pure, deterministic Move function invoked internally to compute a gas price from `curve.min_gas`/`curve.max_gas` and the actual `curve.points` for all non-boundary segments [2](#0-1) ; it is not itself a stored object, proof node, or authenticated API response that gets "bound" to a `GasCurve` — there is no separate proof/response artifact referencing a `GasCurve` object whose binding could be confused with a synthetic one. The function's only output is a `u64` gas value consumed internally by `calculate_read_gas`/`calculate_create_gas`/`calculate_write_gas`, which is then used to update `StorageGas` on-chain, not returned as any kind of "gas-cost proof" to external callers [3](#0-2) .

Since the temporary `Point` values are compile-time constants (not attacker-controlled), are computed identically on every validator, and never substitute for or corrupt the actual `curve.points`/`curve.min_gas`/`curve.max_gas` fields used in the final interpolation, there is no state-commitment corruption, no proof-material corruption, no misbinding of an authenticated response, and no hard-fork-only divergence possible from this code path.

    fun calculate_gas(max_usage: u64, current_usage: u64, curve: &GasCurve): u64 {
        let capped_current_usage = if (current_usage > max_usage) max_usage else current_usage;
        let points = &curve.points;
        let num_points = points.length();
        let current_usage_bps = capped_current_usage * BASIS_POINT_DENOMINATION / max_usage;

        // Check the corner case that current_usage_bps drops before the first point.
        let (left, right) = if (num_points == 0) {
            (&Point { x: 0, y: 0 }, &Point { x: BASIS_POINT_DENOMINATION, y: BASIS_POINT_DENOMINATION })
        } else if (current_usage_bps < points.borrow(0).x) {
            (&Point { x: 0, y: 0 }, points.borrow(0))
        } else if (points.borrow(num_points - 1).x <= current_usage_bps) {
            (points.borrow(num_points - 1), &Point { x: BASIS_POINT_DENOMINATION, y: BASIS_POINT_DENOMINATION })
        } else {
            let (i, j) = (0, num_points - 2);
            while ({
                spec {
                    invariant i <= j;
                    invariant j < num_points - 1;
                    invariant points[i].x <= current_usage_bps;
                    invariant current_usage_bps < points[j + 1].x;
                };
                i < j
            }) {
                let mid = j - (j - i) / 2;
                if (current_usage_bps < points.borrow(mid).x) {
                    spec {
                        // j is strictly decreasing.
                        assert mid - 1 < j;
                    };
                    j = mid - 1;
                } else {
                    spec {
                        // i is strictly increasing.
                        assert i < mid;
                    };
                    i = mid;
                };
            };
            (points.borrow(i), points.borrow(i + 1))
        };
