**Rationale:** The `UpdateJobProposalSpecDefinition` resolver explicitly invokes `authenticateUserCanEdit(ctx)` as its first action, which pulls the authenticated session from context (set only by validated cookie-session middleware `auth.AuthenticateGQL`) and rejects `UserRoleView`/`UserRoleRun` roles before any privileged mutation logic executes [1](#0-0) . The role-check logic itself lives in `authenticateUserCanEdit`, which requires a valid `GQLSession` and blocks non-edit roles [2](#0-1) .

The `/query` GraphQL endpoint is wired with `auth.AuthenticateGQL` as middleware before the GraphQL handler runs, so the session is populated in request context prior to any resolver execution [3](#0-2) . This middleware only trusts a validated session cookie via `AuthorizedUserWithSession`; it does not set a session object if authentication fails [4](#0-3) .

Because `graph-gophers/graphql-go` resolves each field occurrence — including aliased or fragment-referenced instances of `updateJobProposalSpecDefinition` — by directly invoking the bound Go resolver method `(*Resolver).UpdateJobProposalSpecDefinition`, every invocation (regardless of alias, fragment, or variable sharing) re-executes the `authenticateUserCanEdit` check independently. There is no memoization or context-level caching of authorization decisions across aliased fields that could be exploited to skip the check on a second invocation.

There is also no REST-equivalent endpoint for this specific action (job proposal spec definition update is only exposed via the feeds/GraphQL path; no `JobProposalSpecsController` REST route exists in `core/web/router.go`), so the premise of a divergent, more-permissive REST path to compare against does not hold in this codebase — this functionality is GraphQL-only and enforces its own role check consistently. // Authenticates the user from the session cookie and asserts at least 'edit' role.
func authenticateUserCanEdit(ctx context.Context) error {
	session, ok := auth.GetGQLAuthenticatedSession(ctx)
	if !ok {
		return unauthorizedError{}
	}
	switch session.User.Role {
	case sessions.UserRoleView, sessions.UserRoleRun:
		return RoleNotPermittedError{session.User.Role}
	default:
	}
	return nil
}

func AuthenticateGQL(authenticator Authenticator, lggr logger.Logger) gin.HandlerFunc {
	return func(c *gin.Context) {
		ctx := c.Request.Context()
		session := sessions.Default(c)
		sessionID, ok := session.Get(SessionIDKey).(string)
		if !ok {
			return
		}

		user, err := authenticator.AuthorizedUserWithSession(ctx, sessionID)
		if err != nil {
			if errors.Is(err, clsessions.ErrUserSessionExpired) {
				lggr.Warnw("Failed to authenticate session", "err", err)
			} else {
				lggr.Errorw("Failed call to AuthorizedUserWithSession, unable to get user", "err", err)
			}
			return
		}

		ctx = WithGQLAuthenticatedSession(c.Request.Context(), user, sessionID)

		c.Request = c.Request.WithContext(ctx)
	}
