**Rationale:**

`TokenMutationEvent::try_from_bytes` is a pure BCS decode helper operating only on already-extracted `event_data` bytes; it has no notion of ledger version and is never itself part of the proof-binding computation. [1](#0-0) 

The security-critical binding happens earlier and independently of decoding: `ContractEvent` derives `CryptoHasher`/`BCSCryptoHash` over the *raw serialized* event (including `event_data`, key, sequence number, type tag), and `TransactionWithProof::verify` hashes the raw events into an in-memory accumulator and checks that root against `self.proof.transaction_info().event_root_hash()` before checking `self.proof.verify(ledger_info, self.version)`. [2](#0-1) [3](#0-2) 

If an attacker (or a buggy replay/restore path) tried to attach a `TokenMutationEvent`'s raw bytes decoded from one transaction/version to a `TransactionInfoWithProof` for a different version, the substituted `ContractEvent`'s raw-byte hash would not match the `event_root_hash` recorded in that transaction's `TransactionInfo`, so `event_root_hash == self.proof.transaction_info().event_root_hash()` would fail and `verify()` would return an error — exactly the outcome the question's own "proof idea" describes as the expected/correct result, not an exploit. Because `try_from_bytes` is only ever invoked for display/interpretation purposes on event bytes that have already passed this raw-hash check via `verify()`, there is no path by which unbound deserialization could cause a `TokenMutationEvent` to be silently misattributed to the wrong `(ledger_version, event_key, sequence_number)` in an authenticated API response — any such mismatch is caught by the accumulator/root-hash equality check prior to, and independent of, decoding.

    pub fn verify(&self, ledger_info: &LedgerInfo) -> Result<()> {
        let txn_hash = self.transaction.committed_hash();
        ensure!(
            txn_hash == self.proof.transaction_info().transaction_hash(),
            "Transaction hash ({}) not expected ({}).",
            txn_hash,
            self.proof.transaction_info().transaction_hash(),
        );

        if let Some(events) = &self.events {
            let event_hashes: Vec<_> = events.iter().map(CryptoHash::hash).collect();
            let event_root_hash =
                InMemoryEventAccumulator::from_leaves(&event_hashes[..]).root_hash();
            ensure!(
                event_root_hash == self.proof.transaction_info().event_root_hash(),
                "Event root hash ({}) not expected ({}).",
                event_root_hash,
                self.proof.transaction_info().event_root_hash(),
            );
        }

        self.proof.verify(ledger_info, self.version)
    }
