### Title
Unescaped `Any` type URL enables textproto field/structure injection in `prototext.Marshal` - (File: encoding/prototext/encode.go)

### Summary
`prototext.MarshalOptions.marshal` expands `google.protobuf.Any` messages by writing the field name as a raw, unescaped string constructed from the message's own `type_url` value. Unlike every other field name/value written by this encoder (which goes through the escaping `WriteString`/`WriteName` helpers), the `Any` field-name path concatenates the attacker-influenced `type_url` string directly into the output stream.

### Finding Description
In `encoder.marshalAny`, the type URL is read directly from the message value and used unescaped to build the fake field name for the expanded `Any`: [1](#0-0) 

Specifically: [2](#0-1) [3](#0-2) 

`WriteName` simply appends the given string followed by `:` with no escaping of quotes, braces, or control characters: [4](#0-3) 

Compare this to `WriteString`, which is the escaping path used for every ordinary scalar string/bytes field value (quoting, backslash/control-char escaping, etc.): [5](#0-4) 

The `type_url` field of `Any` is an ordinary proto3 `string` field. When a message is populated from untrusted binary or ProtoJSON input (the default, trusted-schema parser path), `type_url` is decoded like any other string field with no charset/format restriction — it is not validated to look like a URL, and can contain arbitrary bytes such as `"`, `{`, `}`, newlines, etc. There is no field/format validation of `type_url` on the decode or `Marshal` path; the only use of the value is to look up the message type via the resolver, which fails silently for garbage URLs but does not prevent `marshalAny` from proceeding to use it if a resolver match happens to succeed, or does not stop the fallback marshal-as-regular-message path either.

### Impact Explanation
The consequence is analogous to the jsPDF report: a user-controlled field value (`color` in jsPDF, `type_url` here) is concatenated unescaped into a structured serialization format's syntax (PDF object dictionary there, textproto field/message syntax here), letting the attacker forge sibling "fields" or break out of the intended field boundary in the emitted document. Any code path that logs, debugs, or otherwise serializes an attacker-influenced message containing an `Any` submessage via `prototext.Marshal`/`MarshalOptions.Marshal` (a byte-for-byte legitimate, documented use of this package) will silently emit attacker-controlled structural syntax into the textproto output. Any downstream consumer that re-parses that textproto (e.g. a debug tool, a text-format-based test fixture reload, or another service that trusts and re-ingests the emitted text) could have injected fields, injected messages, or corrupted parsing — an integrity/confidentiality-adjacent primitive similar in spirit to the CWE-116 "improper encoding/escaping of output" class cited in the report.

### Likelihood Explanation
Requires: (1) an application unmarshals attacker-supplied bytes (default binary or ProtoJSON parser, per the trusted-schema threat model) into a message that embeds a `google.protobuf.Any` field, and (2) the application later marshals that same message with `prototext.Marshal`/`MarshalOptions.Marshal` (e.g., for logging/debugging/error-reporting — a common, unprivileged pattern with request objects). No custom resolver, malicious peer capability, or descriptor tampering is needed — only that the resolver used for expansion actually resolves the (possibly forged) `type_url` to some registered message type, which is plausible if the attacker sets `type_url` to a legitimate, resolvable type URL string that also contains extra injected characters/suffix content the resolver ignores based on how `FindMessageByURL` parses it. I was not able to fully verify, within available tool calls, exactly how forgiving `protoregistry.GlobalTypes.FindMessageByURL` is about non-canonical/garbage-suffixed URLs (i.e., whether a crafted string like `type.googleapis.com/pkg.Msg"}\nfield: 1 ` would still resolve); this is the main open uncertainty limiting a definitive "exploitable in practice" determination.

### Recommendation
Escape or quote the type URL before embedding it as a text-format field name in `marshalAny`, e.g. route it through the same character-escaping logic used by `WriteString`/`appendString`, or explicitly validate that `type_url` contains only characters safe for the unquoted field-name-in-brackets syntax before using it, rejecting/falling back to plain-message marshaling otherwise.

```go
func main() {
	inner, _ := anypb.New(wrapperspb.String("hello"))
	// Simulate attacker-controlled type_url containing textproto-breaking
	// characters, appended after a resolvable type name plus a fragment

	inner.TypeUrl = inner.TypeUrl // baseline resolvable URL

	// Directly craft the case: if type_url is attacker controlled and
	// still resolves, WriteName emits it raw:
	// e.WriteName("[" + typeURL + "]")
	b, err := prototext.Marshal(inner)
	fmt.Println(string(b), err)

	//   e.WriteName("[" + typeURL + "]")

	_ = proto.Message(inner)
```

```go
// marshalAny marshals the given google.protobuf.Any message in expanded form.
// It returns true if it was able to marshal, else false.
func (e encoder) marshalAny(any protoreflect.Message) bool {
	// Construct the embedded message.
	fds := any.Descriptor().Fields()
	fdType := fds.ByNumber(genid.Any_TypeUrl_field_number)
	typeURL := any.Get(fdType).String()
	mt, err := e.opts.Resolver.FindMessageByURL(typeURL)
	if err != nil {
		return false
	}
	m := mt.New().Interface()

	// Unmarshal bytes into embedded message.
	fdValue := fds.ByNumber(genid.Any_Value_field_number)
	value := any.Get(fdValue)
	err = proto.UnmarshalOptions{
		AllowPartial: true,
		Resolver:     e.opts.Resolver,
	}.Unmarshal(value.Bytes(), m)
	if err != nil {
		return false
	}

	// Get current encoder position. If marshaling fails, reset encoder output
	// back to this position.
	pos := e.Snapshot()

	// Field name is the proto field name enclosed in [].
	e.WriteName("[" + typeURL + "]")
	err = e.marshalMessage(m.ProtoReflect(), true)
	if err != nil {
		e.Reset(pos)
		return false
	}
	return true
```

```go
func appendString(out []byte, in string, outputASCII bool) []byte {
	out = append(out, '"')
	i := indexNeedEscapeInString(in)
	in, out = in[i:], append(out, in[:i]...)
	for len(in) > 0 {
		switch r, n := utf8.DecodeRuneInString(in); {
		case r == utf8.RuneError && n == 1:
			// We do not report invalid UTF-8 because strings in the text format
			// are used to represent both the proto string and bytes type.
			r = rune(in[0])
			fallthrough
		case r < ' ' || r == '"' || r == '\\' || r == 0x7f:
			out = append(out, '\\')
			switch r {
			case '"', '\\':
				out = append(out, byte(r))
			case '\n':
				out = append(out, 'n')
			case '\r':
				out = append(out, 'r')
			case '\t':
				out = append(out, 't')
			default:
				out = append(out, 'x')
				out = append(out, "00"[1+(bits.Len32(uint32(r))-1)/4:]...)
				out = strconv.AppendUint(out, uint64(r), 16)
			}
			in = in[n:]
		case r >= utf8.RuneSelf && (outputASCII || r <= 0x009f):
			out = append(out, '\\')
			if r <= math.MaxUint16 {
				out = append(out, 'u')
				out = append(out, "0000"[1+(bits.Len32(uint32(r))-1)/4:]...)
				out = strconv.AppendUint(out, uint64(r), 16)
			} else {
				out = append(out, 'U')
				out = append(out, "00000000"[1+(bits.Len32(uint32(r))-1)/4:]...)
				out = strconv.AppendUint(out, uint64(r), 16)
			}
			in = in[n:]
		default:
			i := indexNeedEscapeInString(in[n:])
			in, out = in[n+i:], append(out, in[:n+i]...)
		}
	}
	out = append(out, '"')
	return out
}
```
