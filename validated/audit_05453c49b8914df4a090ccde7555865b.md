### Title
Auto-swap `minPCOut` derived from a manipulable instantaneous QuoterV2 spot price enables sandwich-style value extraction from inbound GAS deposits - (File: `x/uexecutor/keeper/evm.go`, `x/uexecutor/keeper/execute_inbound_gas.go`, `x/uexecutor/keeper/execute_inbound_gas_and_payload.go`)

### Summary
The external report's bug class is "valuing a position using an easily-moved spot price instead of a robust/fair reference price, and letting an attacker time an action around that mismatch to extract value." Push Chain's `uexecutor` module has a direct structural analog: when processing `GAS` / `GAS_AND_PAYLOAD` inbounds (and gas-refund outbounds), the module prices the PRC20→WPC auto-swap using a single instantaneous call to the Uniswap V3 `QuoterV2.quoteExactInputSingle` (the pool's current spot price) and only tolerates 5% slippage around that number, with no TWAP, no external reference price, and no minimum-liquidity/deviation guard.

### Finding Description
`GetSwapQuote` in [1](#0-0)  fetches `amountOut` from `QuoterV2.quoteExactInputSingle` against the current block's pool state — this is the AMM's instantaneous spot price, structurally identical to the "spot price" the external report warns is unsuitable for valuation because it can be moved cheaply, especially "when liquidity is insufficient in the early stages" (a caveat the client itself raised in the Acknowledged response).

This quote is used immediately to compute `minPCOut` with a fixed 5% slippage band: [2](#0-1) 
and again for `GAS_AND_PAYLOAD` inbounds in [3](#0-2) 
and for excess-gas refunds in [4](#0-3) .

`minPCOut` is then passed straight through to `CallPRC20DepositAutoSwap` / `CallUniversalCoreRefundUnusedGas`, which execute `depositPRC20WithAutoSwap` on `UniversalCore` — a real, committed swap against the same pool: [5](#0-4) 

The pool itself is a permissionless Uniswap V3 fork deployed as part of the chain's own infra (`v3-core`/`v3-periphery`, `QuoterV2`, `SwapRouter`), as seen in the e2e setup script [6](#0-5) , meaning any unprivileged user can trade against it and move its spot price.

Because the quote-then-swap sequence has no staleness/TWAP protection and the slippage tolerance is a fixed percentage of whatever the spot price happens to be at that moment, an attacker who moves the pool price downward (relative to fair value) immediately before the module's `GetSwapQuote` call gets a correspondingly depressed `minPCOut` floor. The subsequent committed swap then executes against that manipulated pool state and is accepted because it still clears the (already-depressed) floor, so the depositing user's UEA receives a below-fair-value amount of PC/WPC while the attacker recaptures the difference by reversing their manipulating trade. This is the same fundamental defect as the report: an on-chain quantity intended to represent fair value is read as an instantaneous, attacker-movable number, and that number is then used to gate a real value transfer with no independent floor.

### Impact Explanation
Every `GAS` and `GAS_AND_PAYLOAD` inbound (and every outbound gas refund) routes end-user PRC20 through this auto-swap path. A successful sandwich reduces the PC/WPC actually credited to the depositor's UEA below fair value, with the attacker extracting the difference from the pool — this is "corruption of PRC20 or native asset accounting" and unauthorized value transfer/theft reachable purely by an unprivileged external user via the default deposit path, matching the allowed impact scope (stealing/draining funds from ordinary users through default transaction submission).

### Likelihood Explanation
Likelihood is highest during the low-liquidity phase of the pool (explicitly called out by the client's own risk model in the seed report) and requires only ordinary permissionless AMM trades plus normal inbound-deposit usage — no validator, relayer, or admin compromise is needed. The fixed 5% band is a meaningful but not decisive barrier; it bounds worst-case loss per swap but does not prevent the underlying manipulation-then-extraction pattern, particularly for larger deposit amounts or thinner pools.

### Recommendation
Do not use a single instantaneous `quoteExactInputSingle` call as the sole basis for `minPCOut`. Use a time-weighted average price (TWAP) over a meaningful window, cross-check the spot quote against the TWAP and reject/clamp if deviation exceeds a safety threshold, and/or widen protection using a dynamically computed slippage bound tied to pool depth rather than a flat 5%. Consider adding a minimum-liquidity gate before allowing auto-swap deposits against a given PRC20/WPC pair.

### Proof of Concept
1. Attacker deploys/uses the permissionless `SwapRouter` against a low-liquidity PRC20/WPC pool.
2. Attacker submits a swap to push the PRC20→WPC spot price down, ahead of (or interleaved with) a pending inbound `GAS`/`GAS_AND_PAYLOAD` deposit's finalization.
3. When the module runs `ExecuteInboundGas`/`ExecuteInboundGasAndPayload`, `GetSwapQuote` reads the manipulated depressed price and computes a correspondingly depressed `minPCOut` (95% of the manipulated quote).
4. `CallPRC20DepositAutoSwap` executes `depositPRC20WithAutoSwap` against the still-manipulated pool; it clears the depressed floor and completes, crediting the victim's UEA with fewer WPC/PC than fair value.
5. Attacker reverses their initial trade, realizing the price difference as profit extracted from the victim's deposit.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)
}
