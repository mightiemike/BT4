### Title
Auto-swap gas top-up/refund uses manipulable spot-price quote as its own slippage reference, enabling theft via AMM price manipulation - ([File: x/uexecutor/keeper/execute_inbound_gas.go], [File: x/uexecutor/keeper/evm.go], [File: x/uexecutor/keeper/outbound.go])

### Summary
The reported Omnipool bug is "no independent floor price — the swap will accept whatever price it gets." Push Chain's `x/uexecutor` auto-swap paths (gas top-up on inbound, and gas refund on outbound) do compute a `minPCOut` floor, but that floor is derived from `GetSwapQuote` — an on-chain `QuoterV2.quoteExactInputSingle` call against the *current* Uniswap V3 spot price, fetched in the same atomic keeper call that immediately executes the swap. There is no TWAP, no external oracle, and no check that the pool price is within a sane historical band. An unprivileged actor who can move the pool's spot price (a normal, permissionless swap on the WPC/PRC20 pool) immediately before the validator-triggered auto-swap executes can make the "protected" quote itself reflect the manipulated price, so the 5% tolerance protects against nothing.

### Finding Description
`GetSwapQuote` ( [1](#0-0) ) calls `quoteExactInputSingle` with `SqrtPriceLimitX96 = 0`, i.e., it simply reads whatever the pool's spot price is at call time. Both `ExecuteInboundGas` ( [2](#0-1) ) and `gasAndPayloadDepositAutoSwap` ( [3](#0-2) ) fetch this quote and immediately derive `minPCOut = quote * 95 / 100`, then pass it straight into `CallPRC20DepositAutoSwap` ( [4](#0-3) ), all within the same keeper invocation triggered when Universal Validator votes cross threshold on `MsgVoteInbound`. The same pattern repeats for the outbound gas refund path in `applyGasRefund` / `getSwapQuoteForRefund` ( [5](#0-4) , [6](#0-5) ).

Because the "protection" (minPCOut) is computed from the *same* manipulable spot price that the swap itself will execute against, an attacker doesn't need to sandwich the module's tx directly — they just need to move the pool price before the validator-finalizing transaction lands in a block (a normal, unprivileged swap against the public WPC/PRC20 Uniswap V3 pool referenced via `GetUniversalCoreQuoterAddress`/`GetUniversalCoreWPCAddress`). The 5% band is computed *after* the manipulation and therefore travels with it — it only bounds noise/rounding around an already-corrupted reference price, not genuine market price.

### Impact Explanation
This directly matches the "Corruption of PRC20 or native asset accounting / gas fee accounting / refund accounting" and "unauthorized module-originated EVM execution" impact classes. A user's PRC20 deposit intended to fund gas (`TxType_GAS`, `GAS_AND_PAYLOAD`) or a destination-chain gas refund (`applyGasRefund`) can be swapped by the protocol's own module account at an attacker-manipulated price, resulting in the user receiving far less WPC/PC than the honest market rate, while the attacker (who supplied the counter-liquidity via their own manipulating swap and reverses it afterward) captures the difference. This is value theft from ordinary users going through the default inbound/outbound flows, reachable without any validator, relayer, or admin misbehavior — only honest validators voting normally are needed for the module to execute the swap at whatever price is on-chain at that moment.

### Likelihood Explanation
Requires an attacker to have capital to move the specific WPC/PRC20 pool and to time a swap shortly before the validator-quorum-triggering transaction executes (which is observable, since `MsgVoteInbound`/`MsgVoteOutbound` are public mempool transactions and thresholds are deterministic based on bonded validator set). Thinly-liquid PRC20 pools (newly bridged/long-tail assets) make this materially cheaper. No privileged role or validator collusion is needed — a plain permissionless AMM swap plus front-running the vote-finalizing transaction is sufficient.

### Recommendation
Do not derive the slippage floor from the same spot price the swap will consume. Use a manipulation-resistant reference, e.g., a Uniswap V3 TWAP via `observe()`/`OracleLibrary`, or an external price oracle (as suggested in the original report), and only allow the 5% (or configurable) band around that TWAP-based reference — not around a live `quoteExactInputSingle` call issued immediately before the swap. Alternatively, add a maximum allowed deviation between spot and TWAP before permitting the auto-swap, and fall back to the no-swap path (already implemented in `applyGasRefund`'s step-2 fallback) whenever that check fails.

### Proof of Concept
1. Attacker identifies a pending `MsgVoteInbound` (or an outbound about to reach vote threshold) for a `TxType_GAS`/`GAS_AND_PAYLOAD` inbound that will trigger `CallPRC20DepositAutoSwap` for a thinly-liquid PRC20/WPC pool.
2. Immediately before the finalizing validator vote lands (front-running via normal mempool visibility), attacker submits a large swap against the same Uniswap V3 pool used by `GetUniversalCoreQuoterAddress`, depressing the PRC20→WPC spot price.
3. The module's `ExecuteInboundGas` calls `GetSwapQuote` (reflecting the now-depressed price), computes `minPCOut = quote*95/100`, and calls `CallPRC20DepositAutoSwap`, which executes at the manipulated price (within only 5% of the corrupted reference).
4. Attacker reverses their manipulating swap, netting the price-impact profit; the intended gas-top-up recipient receives far less WPC than the honest exchange rate would have produced.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}

// getSwapQuoteForRefund fetches a Uniswap quote for the gas token refund swap.
func (k Keeper) getSwapQuoteForRefund(ctx sdk.Context, gasToken common.Address, fee *big.Int, amount *big.Int) (*big.Int, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(ctx)
	if err != nil {
		return nil, err
	}
	wpcAddr, err := k.GetUniversalCoreWPCAddress(ctx)
	if err != nil {
		return nil, err
	}
	return k.GetSwapQuote(ctx, quoterAddr, gasToken, wpcAddr, fee, amount)
