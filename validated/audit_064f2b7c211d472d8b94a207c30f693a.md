### Title
Instantaneous Uniswap V3 spot-price quote used as swap-slippage bound allows unprivileged AMM price manipulation to steal value from gas-abstraction deposit auto-swaps - (File: x/uexecutor/keeper/evm.go, execute_inbound_gas.go, execute_inbound_gas_and_payload.go, outbound.go)

### Summary
This is the same bug class as the reported LP-price issue: an oracle/price value is derived from a single, manipulable on-chain snapshot (there, `get_virtual_price`; here, `QuoterV2.quoteExactInputSingle`) rather than a value resistant to short-term manipulation (e.g., TWAP). Push Chain's `GetSwapQuote` [1](#0-0)  reads the current spot price of the PRC20/WPC Uniswap V3 pool and uses it, with only a flat 5% haircut, as the `minPCOut` slippage bound for the deposit auto-swap that actually moves user funds [5](#0-4) .

### Finding Description
When a user bridges native gas (`GAS` or `GAS_AND_PAYLOAD` inbound), the uexecutor module deposits the corresponding PRC20 and immediately auto-swaps it to native PC using the on-chain Uniswap V3 pool referenced by `UniversalCore`. The keeper:
1. Calls `GetDefaultFeeTierForToken` and `GetSwapQuote` to obtain `amountOut` for the exact `amount` being deposited, sourced live from the pool's current reserves/tick state [1](#0-0) .
2. Derives `minPCOut = quote * 95 / 100`, a fixed 5% tolerance band anchored to that same spot quote [6](#0-5) .
3. Executes the real swap via `CallPRC20DepositAutoSwap` against the same pool [7](#0-6) .

Because both the quote and the swap read the *same* manipulable pool state, an unprivileged attacker can move the pool price out of line with fair value before the finalizing validator transaction that triggers this deposit/swap sequence lands in a block (classic sandwich against a spot-price oracle), then reverse the manipulation afterward. The 5% band only bounds slippage *relative to the already-manipulated price* — it does nothing to protect against the manipulation itself, exactly mirroring the report's core point that a "ramp"-influenced instantaneous value is not a safe substitute for a manipulation-resistant price. This can be triggered purely by an ordinary unprivileged actor trading against the public pool; no validator, relayer, or TSS compromise is required, and the inbound/deposit path itself is triggered by ordinary user bridge deposits.

### Impact Explanation
A successful sandwich extracts value from the PRC20→PC auto-swap that is meant to top up a user's gas balance, resulting in the depositing user (or protocol, since the module executes the swap) receiving less PC than fair value while the attacker captures the difference. This falls under "stealing/draining/permanent loss of user or protocol-controlled funds" in the allowed-impact list, reached purely through the ordinary GAS/GAS_AND_PAYLOAD inbound path and public AMM trading — no privileged actor needed. The refund-swap path (`applyGasRefund`) is similarly exposed [4](#0-3) .

### Likelihood Explanation
Likelihood is Medium: it requires the pool to have exploitable liquidity depth and requires the attacker to time trades around the (semi-predictable) validator vote-finalization transaction that triggers the module-originated swap. Since `MsgVoteInbound`/finalization transactions are observable in the mempool/chain like any other transaction, front-running is feasible without any privileged access.

### Recommendation
Do not derive `minPCOut` from a single live `quoteExactInputSingle` call against the same pool the swap executes on. Use a manipulation-resistant reference price (e.g., a time-weighted average price/TWAP oracle, or a price bounded against an external oracle/chain-meta price) to compute the slippage floor, and/or widen protections such as per-block price-deviation caps, so that the bound is independent of the pool state observed immediately before the swap.

### Proof of Concept
1. Attacker observes a pending `MsgVoteInbound` (or the vote pattern that will soon reach quorum) referencing a `GAS`/`GAS_AND_PAYLOAD` inbound with a known deposit `amount` for token `PRC20_X`.
2. Attacker submits a large swap against the same `PRC20_X`/WPC Uniswap V3 pool referenced by `UniversalCore`, moving the spot price so that `PRC20_X` is undervalued relative to WPC.
3. The finalizing transaction executes `ExecuteInboundGas`/`gasAndPayloadDepositAutoSwap`, which calls `GetSwapQuote` [8](#0-7)  against the now-manipulated pool, computes `minPCOut` at 95% of that skewed quote, and executes `CallPRC20DepositAutoSwap` at the manipulated price.
4. Attacker reverses the initial swap, restoring the pool to fair value and pocketing the value difference extracted from the module-executed auto-swap.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}
