### Title
Unbounded per-log outbound processing in `EVMHooks.PostTxProcessing` allows disproportionate node-side gas griefing from a single user-submitted EVM transaction - (File: `x/uexecutor/keeper/evm_hooks.go`, `x/uexecutor/keeper/create_outbound.go`)

### Summary
The external report's core pattern — an attacker-controlled result of variable/attacker-influenced size that is copied and processed by privileged code without a size cap, causing gas cost disproportionate to what the attacker actually paid — has a structural analog in Push Chain's EVM post-processing hook. `EVMHooks.PostTxProcessing` runs after **every** EVM transaction on the chain (not just module-originated `DerivedEVMCall`s), and iterates `receipt.Logs` with no bound on log count, invoking `BuildOutboundsFromReceipt` for every log matching the `UniversalGatewayPC` address and outbound event signature. [1](#0-0) [2](#0-1) 

### Finding Description
`app.EVMKeeper.SetHooks(uexecutorkeeper.NewEVMHooks(app.UexecutorKeeper))` wires this hook into every EVM transaction processed by the chain. [3](#0-2) 

For each log in the receipt, `BuildOutboundsFromReceipt` performs: an address/topic filter, an ABI decode (`DecodeUniversalTxOutboundFromLog`), an `IsChainOutboundEnabled` registry lookup, a `GetTokenConfigByPRC20` registry lookup, and construction of an `OutboundTx` struct. [4](#0-3) 

Each matched event is then attached via `attachOutboundsToUtx`, which for every outbound does an additional `GetChainConfig` lookup, a `PendingOutbounds.Set` KV write, and an `UpdateUniversalTx` read-modify-write plus event emission — i.e. several distinct keeper/state operations per log. [5](#0-4) 

The number of iterations is fully driven by `len(receipt.Logs)` from the underlying EVM transaction, with no cap enforced anywhere in this Go-level path. If the `UniversalGatewayPC` contract exposes any user-reachable function that can be invoked repeatedly (e.g., in a loop, or via a single call that internally loops) to emit many `UniversalTxOutboundEvent` logs cheaply in EVM-gas terms (the `LOG` opcode is comparatively cheap relative to the KV-store reads/writes and ABI-decoding work triggered per log on the Cosmos side), an attacker can submit one ordinary `MsgEthereumTx` that is inexpensive from the EVM gas-metering perspective but forces the node to perform a large, unbounded amount of Cosmos-SDK-level keeper work (multiple KV Get/Set calls, append-growing UTX writes, event emission) per log, entirely outside of EVM opcode gas accounting. This mirrors the ExpressRelay finding's core defect: work performed on attacker-supplied output data is not bounded relative to the cost the attacker paid to produce that data.

### Impact Explanation
This is a denial-of-service / gas-griefing pattern reachable by an ordinary unprivileged EVM-transaction sender with no special privileges (any account able to submit a `MsgEthereumTx` that triggers the gateway contract to emit many qualifying logs). Depending on how cheap it is for the gateway contract to emit many `UniversalTxOutboundEvent` logs relative to their downstream Cosmos-side processing cost, this could disproportionately inflate the actual computational/storage cost of processing a single transaction relative to the gas paid for it, and could grow the size of `UniversalTx` records (`utx.OutboundTx` slices) and `PendingOutbounds` index unpredictably. This falls under the in-scope "denial of service only when it is not network-level and is reachable without privileged control" and "corruption of ... UniversalTx state" categories.

### Likelihood Explanation
Exploitability depends entirely on whether the `UniversalGatewayPC` Solidity contract (not present in this Go repository, so not directly verifiable here) allows a single externally-triggerable transaction to emit an unbounded or large number of `UniversalTxOutboundEvent` logs cheaply (e.g. a batched/looped call). The Go-side code itself imposes no independent limit on `len(receipt.Logs)` processed by the hook, so if such a contract-side amplification path exists, the Go-level consumption path is unguarded. Because the contract source is out of scope of this repository, I cannot confirm the exact gas ratio needed to make this practically exploitable versus already bounded by the EVM's own per-block/per-tx gas limit (which caps total log emission regardless).

### Recommendation
Add an explicit cap on the number of qualifying outbound-event logs processed per `PostTxProcessing` invocation (and/or per receipt), and consider metering the Cosmos-side keeper work (KV reads/writes, ABI decode) against the SDK gas meter so that expensive per-log downstream work is proportionally charged against the transaction, closing any asymmetry between cheap EVM-gas log emission and expensive SDK-level state processing.

### Proof of Concept
Not constructible from this repository alone: the amplification vector depends on the `UniversalGatewayPC` Solidity contract's exposed functions (external repo, not indexed here), specifically whether any user-reachable function can emit multiple `UniversalTxOutboundEvent` logs per call at low EVM-gas cost. I could not verify this contract's logic within the scoped repository, so this finding should be treated as a **structural/likely** analog rather than a confirmed, fully-reproducible exploit; a Devin session with access to the `push-chain-core-contracts` repository (`UniversalGatewayPC.sol`) would be needed to confirm or reject actual exploitability.

func (k Keeper) BuildOutboundsFromReceipt(
	ctx context.Context,
	utxId string,
	receipt *evmtypes.MsgEthereumTxResponse,
) ([]*types.OutboundTx, error) {

	outbounds := []*types.OutboundTx{}
	universalGatewayPC := strings.ToLower(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_GATEWAY_PC"].Address)

	k.Logger().Debug("building outbounds from receipt", "utx_id", utxId, "tx_hash", receipt.Hash, "log_count", len(receipt.Logs))

	for _, lg := range receipt.Logs {
		if lg.Removed {
			continue
		}

		if strings.ToLower(lg.Address) != universalGatewayPC {
			continue
		}

		if len(lg.Topics) == 0 {
			continue
		}

		if strings.ToLower(lg.Topics[0]) != strings.ToLower(types.UniversalTxOutboundEventSig) {
			continue
		}

		event, err := types.DecodeUniversalTxOutboundFromLog(lg)
		if err != nil {
			return nil, fmt.Errorf("failed to decode UniversalTxWithdraw: %w", err)
		}

		// Check if outbound is enabled for the destination chain
		outboundEnabled, err := k.uregistryKeeper.IsChainOutboundEnabled(ctx, event.ChainId)
		if err != nil {
			return nil, fmt.Errorf("failed to check outbound enabled for chain %s: %w", event.ChainId, err)
		}
		if !outboundEnabled {
			k.Logger().Warn("outbound disabled for chain", "chain_id", event.ChainId, "utx_id", utxId)
			return nil, fmt.Errorf("outbound is disabled for chain %s", event.ChainId)
		}

		// Get the external asset addr
		tokenCfg, err := k.uregistryKeeper.GetTokenConfigByPRC20(
			ctx,
			event.ChainId,
			event.Token, // PRC20 address
		)
		if err != nil {
			return nil, err
		}

		outbound := &types.OutboundTx{
			DestinationChain:  event.ChainId,
			Recipient:         event.Target,
			Amount:            event.Amount.String(),
			ExternalAssetAddr: tokenCfg.Address,
			Prc20AssetAddr:    event.Token,
			Sender:            event.Sender,
			Payload:           event.Payload,
			GasFee:            event.GasFee.String(),
			GasLimit:          event.GasLimit.String(),
			GasPrice:          event.GasPrice.String(),
			GasToken:          event.GasToken,
			TxType:            event.TxType,
			PcTx: &types.OriginatingPcTx{
				TxHash:   receipt.Hash,
				LogIndex: fmt.Sprintf("%d", lg.Index),
			},
			RevertInstructions: &types.RevertInstructions{
				FundRecipient: event.RevertRecipient,
			},
			OutboundStatus: types.Status_PENDING,
			Id:             strings.TrimPrefix(event.TxID, "0x"),
		}

		k.Logger().Debug("outbound built from receipt",
			"utx_id", utxId,
			"outbound_id", outbound.Id,
			"dest_chain", outbound.DestinationChain,
			"amount", outbound.Amount,
			"tx_type", outbound.TxType.String(),
		)
		outbounds = append(outbounds, outbound)
	}

func (k Keeper) attachOutboundsToUtx(
	ctx sdk.Context,
	utxId string,
	outbounds []*types.OutboundTx,
	revertMsg string, // revert msg if the outbound is for a inbound revert
) error {

	if len(outbounds) == 0 {
		return nil
	}
	return k.UpdateUniversalTx(ctx, utxId, func(utx *types.UniversalTx) error {

		for _, outbound := range outbounds {

			utx.OutboundTx = append(utx.OutboundTx, outbound)

			// Compute signature expiry deadline for the destination chain.
			var signingDeadline int64
			if chainCfg, err := k.uregistryKeeper.GetChainConfig(ctx, outbound.DestinationChain); err == nil {
				if chainCfg.TssSigningDeadline != nil && *chainCfg.TssSigningDeadline > 0 {
					signingDeadline = ctx.BlockTime().Unix() + int64(chainCfg.TssSigningDeadline.Seconds())
				}
			}

			// Write to pending outbounds index (inside UpdateUniversalTx closure for atomicity)
			if err := k.PendingOutbounds.Set(ctx, outbound.Id, types.PendingOutboundEntry{
				OutboundId:      outbound.Id,
				UniversalTxId:   utxId,
				CreatedAt:       ctx.BlockHeight(),
				SigningDeadline: signingDeadline,
			}); err != nil {
				return fmt.Errorf("failed to set pending outbound index for %s: %w", outbound.Id, err)
			}

			var pcTxHash string
			var logIndex string

			if outbound.PcTx != nil {
				pcTxHash = outbound.PcTx.TxHash
				logIndex = outbound.PcTx.LogIndex
			}

			evt, err := types.NewOutboundCreatedEvent(types.OutboundCreatedEvent{
				UniversalTxId:    utxId,
				TxID:             outbound.Id,
				DestinationChain: outbound.DestinationChain,
				Recipient:        outbound.Recipient,
				Amount:           outbound.Amount,
				AssetAddr:        outbound.ExternalAssetAddr,
				Sender:           outbound.Sender,
				Payload:          outbound.Payload,
				GasFee:           outbound.GasFee,
				GasLimit:         outbound.GasLimit,
				GasPrice:         outbound.GasPrice,
				GasToken:         outbound.GasToken,
				TxType:           outbound.TxType.String(),
				PcTxHash:         pcTxHash,
				LogIndex:         logIndex,
				RevertMsg:        revertMsg,
				SigningDeadline:  signingDeadline,
			})
			if err == nil {
				ctx.EventManager().EmitEvent(evt)
			}
		}

		return nil
	})
