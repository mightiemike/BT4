### Title
Missing declared-class validation in Starknet OS `execute_replace_class` allows state-root divergence from Blockifier — (File: `crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo`)

### Summary
The `replace_class` syscall handler in the Starknet OS Cairo re-execution code updates a contract's class hash without verifying that the new class hash corresponds to a declared class, unlike the equivalent Rust `blockifier` implementation which performs this check explicitly.

### Finding Description
In the Rust `blockifier`, the `replace_class` syscall implementation explicitly ensures the target class is declared (and of the correct Cairo version) before mutating state: [1](#0-0) 
This calls `self.state.get_compiled_class(class_hash)?`, which returns `StateError::UndeclaredClassHash` if the class hash was never declared, and additionally rejects Cairo0 class hashes via `is_cairo1`. The deprecated (Cairo0) syscall path performs an analogous check: [2](#0-1) , and tests confirm this behavior rejects undeclared class hashes with "is not declared": [3](#0-2) .

In contrast, the Starknet OS Cairo implementation of the same syscall — used for re-execution/proving of the block — performs the state update directly, with an explicit acknowledged gap: [4](#0-3) 
Note line 902: `// TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.` The function reads `class_hash` from the syscall request and unconditionally writes a new `StateEntry` with that class hash into `contract_state_changes`, with no lookup against the declared-classes table. The deprecated (Cairo0) OS syscall handler `execute_replace_class` in `deprecated_execute_syscalls.cairo` exhibits the identical pattern — no declared-class check before the `dict_update`: [5](#0-4) 

### Impact Explanation
The Starknet OS is responsible for re-executing the block to produce the committed state root and prove correctness of Blockifier's execution. If the Blockifier (the actual sequencer execution engine) rejects a transaction that calls `replace_class` with an undeclared or invalid class hash (reverting that call/transaction), but the OS accepts the same syscall and commits a state change setting the contract's class hash to an undeclared value, the two execution paths diverge: the OS-computed state commitment/state diff for that block would not match what the sequencer's Blockifier actually produced. This can result in a wrong committed state root, an unprovable or incorrectly proven block, or — in the more severe case — a state where a contract's `class_hash` points to a class that was never declared, meaning any subsequent `call_contract` to that address would reference nonexistent code, since compiled-class lookups depend on the class actually being declared (as enforced by the Blockifier's `get_compiled_class`). This is a correctness/soundness gap between the sequencer's execution and its own OS proof, not merely an audit nit.

### Likelihood Explanation
This is reachable by any account contract executing `replace_class` as part of a normal `__execute__` call (a standard, unprivileged Starknet syscall available to any deployed contract), passing an arbitrary/undeclared class hash. The condition is a single-transaction one-syscall trigger — no operator or prover privilege is required. The only mitigating factor is that this requires the Blockifier's stricter check to actually diverge from what the OS permits, which is exactly what happens here: the OS lacks the check that the Blockifier enforces, and the TODO comment in the source confirms this is a known, currently-unaddressed gap.

### Recommendation
Add the equivalent declared-class check in the OS's `execute_replace_class` (and the analogous Cairo0 `execute_replace_class` in `deprecated_execute_syscalls.cairo`) mirroring the Blockifier's `syscall_base.rs::replace_class` logic: look up the class hash in the OS's declared-classes structure (and reject unsupported Cairo0-vs-Cairo1 combinations analogous to `is_cairo1`) before performing the `dict_update` on `contract_state_changes`, ensuring OS re-execution semantics are identical to Blockifier's for this syscall.

### Proof of Concept
1. Deploy an account contract that calls `replace_class_syscall(undeclared_class_hash)` inside `__execute__`, where `undeclared_class_hash` has never been declared in this state.
2. In the Blockifier, this transaction reverts because `syscall_base::replace_class` calls `state.get_compiled_class(class_hash)` and returns `StateError::UndeclaredClassHash` (per test `undeclared_class_hash` in `crates/blockifier/src/execution/syscalls/syscall_tests/replace_class.rs`).
3. When the same block/transaction trace is re-executed by the Starknet OS (`execute_replace_class` in `syscall_impls.cairo`), no such check exists — the OS unconditionally updates `contract_state_changes` with the undeclared `class_hash`, producing a different final state (and thus a different committed root) than the Blockifier's rejection path, or accepting a call that Blockifier would revert.

    pub fn replace_class(&mut self, class_hash: ClassHash) -> SyscallResult<()> {
        // Ensure the class is declared (by reading it), and of type V1.
        let compiled_class = self.state.get_compiled_class(class_hash)?;

        if !is_cairo1(&compiled_class) {
            return Err(SyscallExecutionError::ForbiddenClassReplacement { class_hash });
        }
        self.state.set_class_hash_at(self.call.storage_address, class_hash)?;
        Ok(())
    }

func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
