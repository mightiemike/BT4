The relevant analog centers on Starknet's `replace_class` syscall — the on-chain equivalent of the Meerkat Finance vault's unchecked `upgradeTo()`/`init()` backdoor that let an attacker rewrite a contract's implementation. Let me confirm the exact missing-check location in the OS code versus the Blockifier's stricter check.## Title
Starknet OS `execute_replace_class` accepts undeclared class hashes, unlike Blockifier — ([File: crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo])

### Summary
The Meerkat Finance exploit succeeded because the Vault's upgrade/init logic never verified that the "owner" or new implementation being installed was legitimate — a caller could set arbitrary state (`init(address owner)`) with no validation and then call a backdoor withdrawal function. The Starknet analog is the `replace_class` syscall implementation inside the Starknet OS (the Cairo program used to re-execute a block and produce the state commitment/proof). Unlike the Blockifier's native implementation, which requires the target class hash to already be a declared class before allowing `replace_class` to succeed, the OS's `execute_replace_class` performs this update unconditionally, with an explicit unresolved `TODO` acknowledging the missing check.

### Finding Description
In the OS's syscall implementation, `execute_replace_class` overwrites a contract's `class_hash` in `contract_state_changes` without verifying the class was ever declared: [1](#0-0) 

Note the comment at line 902: `// TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.` The deprecated syscall path has the exact same gap, with no check at all: [2](#0-1) 

Compare this to the Blockifier's native (non-OS) `replace_class` handler, which explicitly fetches the compiled class before mutating state, causing the syscall to fail if the class hash is undeclared: [3](#0-2) 

Furthermore, in the OS's global state-update flow, the `contract_state_changes` tree (which stores each contract's `class_hash`) and the `contract_class_changes` tree (which stores declared classes and their compiled-class hashes) are committed independently, with no cross-check that class hashes referenced from `contract_state_changes` exist in `contract_class_changes`: [4](#0-3) 

This means the constraint system that ultimately produces the proven state root does not enforce the invariant "every contract's class hash corresponds to a declared class" for the `replace_class` code path — a check that only exists, informally, in the Blockifier's Rust implementation used for the sequencer's own execution.

### Impact Explanation
This is a soundness gap between the two execution engines that must agree bit-for-bit for a Starknet block to be provable/valid: the Blockifier (which decides what actually gets included in a block) enforces the declared-class invariant, while the OS (which re-executes the block to build the committed state root and generate the STARK proof) does not. If any transaction path reaches `execute_replace_class`/`execute_replace_class` (deprecated variant) with a state where the OS's hint-provided data diverges from what Blockifier would have enforced, the OS would happily commit a `class_hash` for a contract that has no corresponding entry in `contract_class_changes`. This can corrupt the committed contract state tree with an unresolvable class reference, causing all subsequent calls to that contract to fail unpredictably in re-execution/proving contexts, and represents a violation of the "wrong committed root" / "honest-node divergence" class of bug: the OS's re-execution does not actually enforce an invariant that the informal/production execution path relies on, undermining the guarantee that the proof faithfully validates the block.

### Likelihood Explanation
Likelihood is moderate: reaching this code path requires only a normal, unprivileged contract calling the `replace_class` syscall (deployed via a standard `Invoke`/`Execute` transaction) — no special privileges, staker/prover role, or malicious operator behavior is needed. The missing check is explicitly flagged as an open TODO by the developers themselves, confirming it is a real, currently-unaddressed gap rather than a false positive.

### Recommendation
Add the same "class must be declared" check that exists in the Blockifier's `replace_class` handler to both OS syscall implementations (`execute_replace_class` in `syscall_impls.cairo` and in `deprecated_execute_syscalls.cairo`), by verifying the target `class_hash` has a corresponding entry in `contract_class_changes` (or the declared-classes tree) before allowing the `StateEntry.class_hash` update, matching the TODO's stated intent and closing the Blockifier/OS parity gap.

### Proof of Concept
1. Deploy any contract and, from within an entry point, invoke the `replace_class` syscall with an arbitrary, never-declared `class_hash` (e.g., a random felt).
2. In the Blockifier execution path, `syscall_handler.state.get_compiled_class(request.class_hash)` fails, causing the syscall/transaction to fail as expected.
3. In the OS re-execution path (`execute_replace_class` in `syscall_impls.cairo` / `deprecated_execute_syscalls.cairo`), no equivalent check is performed: the `StateEntry.class_hash` for the contract is unconditionally updated in `contract_state_changes`, and this change flows straight into `compute_contract_state_commitment` in `state.cairo` with no cross-validation against `contract_class_changes`, demonstrating that the OS accepts a state transition the Blockifier would have rejected.

func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
