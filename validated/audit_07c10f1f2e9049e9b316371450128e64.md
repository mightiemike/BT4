## Analog Found: Spot-price AMM quote used to bound the auto-swap slippage in universal execution — same drainable-pool pattern as WooFi

### Title
Universal execution's PRC20→WPC auto-swap trusts an atomic Uniswap V3 spot-price quote for slippage protection, enabling price-manipulation drain of the WPC pool - (File: `x/uexecutor/keeper/evm.go`, `x/uexecutor/keeper/execute_inbound_gas.go`, `x/uexecutor/keeper/execute_inbound_gas_and_payload.go`, `x/uexecutor/keeper/outbound.go`)

### Summary
The original WooFi bug is that `maxNotionalSwap`/`maxGamma` (bespoke AMM guardrails) fail to stop pool drainage because the pool's spot price itself is what's being manipulated, and no independent oracle constrains it for tokens without a Chainlink feed. Push Chain's analog is the `depositPRC20WithAutoSwap` / `refundUnusedGas` flow, which computes its only slippage guard (`minPCOut`) from `GetSwapQuote`, an on-chain spot-price read of the Uniswap V3 `QuoterV2.quoteExactInputSingle` for the PRC20↔WPC pool, with `SqrtPriceLimitX96` unset (0). There is no TWAP, no external price oracle, and no cap on price impact — the "protection" is entirely derived from the pool's own instantaneous state, exactly like WOO's SPMM price.

### Finding Description
`GetSwapQuote` [1](#0-0)  queries the AMM's current price for the exact `amount` being swapped. Immediately afterward, `gasAndPayloadDepositAutoSwap` derives `minPCOut` as a flat 95% of that same quote and passes it straight into `CallPRC20DepositAutoSwap`, which executes the real swap via `DerivedEVMCall("depositPRC20WithAutoSwap", ...)`: [2](#0-1) 

The identical pattern repeats in the `ExecuteInboundGas` path [3](#0-2)  and in the outbound gas-refund path (`applyGasRefund` → `getSwapQuoteForRefund` → `CallUniversalCoreRefundUnusedGas` with `withSwap=true`): [4](#0-3) 

Because the quote and the swap both read/write the *same* on-chain Uniswap V3 pool state, and the "protection" is nothing more than "don't accept less than 95% of whatever the pool says right now," any actor who moves the pool's price before this quote is fetched (or between when honest UVs' votes are broadcast/queued and when the finalizing vote lands in a block) forces the auto-swap to execute at their manipulated price. The `e2e-tests/setup.sh` comments themselves acknowledge the WPC/gas-token AMM pools are intentionally shallow ("Surfpool fees are negligible... Keep local Solana gas quotes small so repeated Route 3 tests do not drain the tiny WPC/pSOL AMM pool") [5](#0-4) , confirming the production pools this logic relies on can plausibly have thin liquidity, which is precisely the precondition that made the WOO pool drainable via partial-fill price walking.

Unlike the ballot/vote/TSS surfaces (which require validator collusion, explicitly out of scope), this is a pure AMM-price-oracle problem reachable by an unprivileged actor who can (a) see a pending inbound/vote in the mempool destined to trigger auto-swap, and (b) submit ordinary swap transactions against the same PRC20/WPC Uniswap V3 pool ahead of (and after) that trigger — no validator or TSS compromise needed, only normal transaction submission against a public AMM pool that the protocol itself created and seeded.

### Impact Explanation
An attacker who manipulates the PRC20/WPC pool price immediately before a module-triggered `depositPRC20WithAutoSwap` or `refundUnusedGas(withSwap=true)` call can force that swap to execute at an artificially unfavorable rate for the protocol/user side and favorable for the attacker's own subsequent reverse trade, extracting WPC (or PRC20) value from the pool — a direct value-drain of protocol/user-controlled AMM liquidity, matching the "draining the pool" impact class of the source report. Every gas-and-payload deposit and every gas refund routes through this exact quote-then-swap pattern, so the surface is large and continuously exercised by ordinary crosschain traffic.

### Likelihood Explanation
Medium-High for pools with limited liquidity (as acknowledged in the repo's own test tooling). The attack requires no validator/TSS/relayer compromise — only capital to move the pool price and the ability to land transactions before/after the module's swap in the same or adjacent blocks, which is standard MEV/sandwich behavior against any public constant-product/concentrated-liquidity pool with only a 5% static slippage band and no TWAP or external price cross-check.

### Recommendation
Do not derive `minPCOut` solely from a same-block spot-price `QuoterV2.quoteExactInputSingle` call. Use a TWAP-based quote (or a period-averaged internal price), cross-check against `x/uexecutor`'s chain-meta/gas-price oracle where available, cap per-swap price impact independent of the instantaneous quote, and/or set a non-zero `SqrtPriceLimitX96` bound derived from a manipulation-resistant reference price rather than `big.NewInt(0)`.

### Proof of Concept
1. Attacker monitors the mempool/UV vote traffic for an about-to-finalize `MsgVoteInbound`/`MsgVoteOutbound` that will trigger `ExecuteInboundGas` / outbound gas refund for a given PRC20.
2. Attacker submits a large swap against the PRC20/WPC Uniswap V3 pool to shift the spot price just before the module's transaction lands in the block.
3. `GetSwapQuote` returns the manipulated price; `minPCOut = quote * 95/100` inherits the manipulation. [1](#0-0) 
4. `CallPRC20DepositAutoSwap` / `CallUniversalCoreRefundUnusedGas` executes the protocol-originated swap at the manipulated price, transferring excess value into/out of the pool relative to the true price. [6](#0-5) 
5. Attacker reverses their initial trade in a following transaction, capturing the price-impact spread extracted from the pool — the WOO-style "sell in pieces / drain the pool" pattern applied to Push Chain's PRC20↔WPC AMM.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}
