## Analysis

`determineEventType` and its caller `processSignatureBatch` classify **every log line** in a transaction that merely *references* the configured gateway address, matching it purely by an 8‑byte discriminator prefix — with no verification of which program actually emitted the log. [1](#0-0) 

### Root cause

1. **Signature discovery is address-membership based, not program-invocation based.** `GetSignaturesForAddress(gatewayAddr, ...)` returns any transaction where `gatewayAddr` appears among the account keys (as any signer/writable/readonly account) — it does not require the gateway *program* to have been invoked. [2](#0-1) 

2. **Log scanning has no program-origin binding.** `processSignatureBatch` iterates over *every* log line in `tx.Meta.LogMessages` for that transaction and calls `determineEventType(log)` on each individually. Solana logs are only bracketed by `"Program <id> invoke"` / `"Program <id> success"` text; this code never inspects or verifies those markers, so a `"Program data: <base64>"` line emitted by *any other program* invoked in the same transaction is indistinguishable from one emitted by the real gateway program. [3](#0-2) 

3. **`determineEventType` only checks an 8-byte discriminator match** against a registry-configured map, then hands the entire log off to `ParseEvent` for full decoding. [4](#0-3) 

4. **`parseSendFundsEvent`/`decodeUniversalTxEvent` place no additional trust anchor** on the data beyond raw byte-length checks; sender, recipient, token, amount, payload, revert_recipient, and tx_type are all decoded straight out of attacker-controlled bytes with no linkage to any actual token transfer or vault balance change on Solana. [5](#0-4) 

5. **Transaction success/failure is never checked.** `processSignatureBatch` never inspects `tx.Meta.Err`, so logs from a transaction that ultimately failed/reverted on-chain (e.g., a real `send_funds` CPI emitted its event log and then a later instruction in the same tx failed, rolling back the fund transfer) are still processed identically to a successful transaction's logs. [6](#0-5) 

### Exploit path

An unprivileged attacker can:
1. Deploy an arbitrary Solana program.
2. Build a transaction that (a) includes the real gateway pubkey as a harmless read-only/non-signer account (satisfying `GetSignaturesForAddress` matching) and (b) invokes their own malicious program, which calls `sol_log_data`/emits a `"Program data: <base64>"` line whose first 8 bytes equal the legitimate `send_funds` discriminator, followed by attacker-chosen sender/recipient/token/amount/payload/revert-recipient bytes.
3. No real deposit or lock of funds occurs on Solana — the gateway program is never invoked.
4. Every honest Push Chain `universalClient` node deterministically decodes the same forged log and produces the same `store.Event` (`EventID = signature:logIndex`) via `InsertEventIfNotExists`, so honest validators converge on identical (but forged) ballot content. [7](#0-6) 
5. This forged inbound `UniversalTx` observation proceeds into voting/finalization with attacker-chosen recipient/amount/token, leading to unauthorized minting/execution on Push Chain for funds that were never actually deposited — direct theft.

This satisfies the in-scope impact "forged... inbound... state accepted through user-reachable flows with honest validators and honest nodes" and "unauthorized mint... of user or protocol-controlled funds," and does not require any malicious validator, relayer, or privileged actor — only an ordinary Solana account able to submit a transaction referencing the public gateway address.

### Title
Forged inbound SVM events via unauthenticated program-origin log matching - (`universalClient/chains/svm/event_listener.go`)

### Summary
`determineEventType`/`processSignatureBatch` treat any `"Program data: ..."` log line inside any transaction that references the gateway address as a legitimate gateway event, without verifying it was emitted by the actual gateway program or that the transaction succeeded, allowing attacker-controlled programs to forge fully attacker-specified `send_funds` inbound events.

### Finding Description
See analysis above: signature discovery is address-membership based rather than program-invocation based, log-to-event mapping relies solely on an 8-byte discriminator with no program-ID binding, downstream parsers trust the raw bytes with no external state verification, and `tx.Meta.Err` is never checked before log processing.

### Impact Explanation
An attacker can get honest Push Chain validators to accept a fully forged, attacker-chosen inbound `UniversalTx` (arbitrary sender, recipient, token, amount, payload, revert recipient) without ever depositing real funds into the Solana gateway, leading to unauthorized minting/execution of value on Push Chain — direct theft of protocol funds.

### Likelihood Explanation
High for an unprivileged attacker with basic Solana program deployment ability; no privileged role, relayer, or validator compromise is required — only crafting a transaction that references the gateway's public address alongside a custom program.

### Recommendation
- Bind event extraction to program-invocation context: parse the `"Program <id> invoke"`/`"Program <id> success"` bracketing (or use `Meta.InnerInstructions`/`LogMessages` correlated with `Meta.LoadedAddresses`/instruction program IDs) so only logs actually emitted by the configured gateway program ID are considered.
- Reject transactions where `tx.Meta.Err != nil` before processing any logs.
- Consider using an indexer/RPC method that returns logs already scoped to instructions invoking the target program ID rather than filtering by mere account-key membership.

### Proof of Concept
1. Deploy a minimal Solana program `Forge` that calls `sol_log_data(discriminator_bytes || fake_serialized_event)` where `discriminator_bytes` equals the registered `send_funds` `EventIdentifier`.
2. Submit a transaction invoking `Forge`, listing the real gateway `gatewayAddress` as an extra (non-signer, read-only) account so `GetSignaturesForAddress(gatewayAddr, ...)` returns this signature.
3. Observe the `universalClient` SVM listener: `processSignatureBatch` → `determineEventType` matches the forged discriminator → `ParseEvent`/`parseSendFundsEvent` decodes attacker-chosen sender/recipient/amount/token/payload → `InsertEventIfNotExists` stores a `Pending` inbound `UniversalTx` event, indistinguishable from a genuine deposit, ready to be voted on and finalized.

```go
// determineEventType determines the event type based on the log discriminator
func (el *EventListener) determineEventType(log string) string {
	if !strings.HasPrefix(log, "Program data: ") {
		return ""
	}

	eventData := strings.TrimPrefix(log, "Program data: ")
	decoded, err := base64.StdEncoding.DecodeString(eventData)
	if err != nil {
		return ""
	}

	if len(decoded) < 8 {
		return ""
	}

	discriminator := strings.ToLower(hex.EncodeToString(decoded[:8]))

	// Look up event type from discriminator map
	eventType, ok := el.discriminatorToEventType[discriminator]
	if !ok {
		return ""
	}

	return eventType
```

```go
// decodeUniversalTxEvent decodes a TxWithFunds event
func decodeUniversalTxEvent(data []byte, logger zerolog.Logger) (*common.UniversalTx, error) {
	if len(data) < 120 {
		logger.Warn().
			Int("data_len", len(data)).
			Msg("data might be too short for complete TxWithFunds event")
	}

	offset := 8
	payload := &common.UniversalTx{}

	// Parse sender (32 bytes)
	if len(data) < offset+32 {
		return nil, fmt.Errorf("not enough data for sender")
	}
	sender := solana.PublicKey(data[offset : offset+32])
	// Convert sender to hex format
	senderHex, err := base58ToHex(sender.String())
	if err != nil {
		logger.Warn().Err(err).Msg("failed to convert sender to hex, using base58")
		payload.Sender = sender.String()
	} else {
		payload.Sender = senderHex
	}
	offset += 32

	// Parse recipient (20 bytes - byte20 format)
	if len(data) < offset+20 {
		return nil, fmt.Errorf("not enough data for recipient")
	}
	// Convert 20 bytes to hex string (0x + 40 hex chars)
	recipientBytes := data[offset : offset+20]
	payload.Recipient = "0x" + hex.EncodeToString(recipientBytes)
	offset += 20

	// Parse bridge_token (32 bytes)
	if len(data) < offset+32 {
		return nil, fmt.Errorf("not enough data for bridge_token")
	}
	bridgeToken := solana.PublicKey(data[offset : offset+32])
	payload.Token = bridgeToken.String()
	offset += 32

	// Parse bridge_amount (8 bytes)
	if len(data) < offset+8 {
		return nil, fmt.Errorf("not enough data for bridge_amount")
	}
	bridgeAmount := binary.LittleEndian.Uint64(data[offset : offset+8])
	payload.Amount = fmt.Sprintf("%d", bridgeAmount)
	offset += 8

	// Parse data field length (4 bytes)
	if len(data) < offset+4 {
		logger.Warn().Msg("not enough data for data field length")
		return payload, nil
	}
	dataLen := binary.LittleEndian.Uint32(data[offset : offset+4])
	offset += 4

	// Parse data field
	if len(data) < offset+int(dataLen) {
		logger.Warn().
			Uint32("expected_len", dataLen).
			Int("available", len(data)-offset).
			Msg("not enough data for data field")
		return payload, nil
	}
	if dataLen > 0 {
		dataField := data[offset : offset+int(dataLen)]
		payload.RawPayload = "0x" + hex.EncodeToString(dataField)
		offset += int(dataLen)
	}

	// Parse revert_recipient (Pubkey)
	if len(data) < offset+32 {
		logger.Warn().Msg("not enough data for revert recipient")
		return payload, nil
	}
	revertRecipient := solana.PublicKey(data[offset : offset+32])
	payload.RevertFundRecipient = revertRecipient.String()
	offset += 32

	// Parse tx_type (TxType enum)
	if len(data) <= offset {
		logger.Warn().Msg("not enough data for tx_type, defaulting to Funds")
		payload.TxType = uint(0)
		return payload, nil
	}
	txType := data[offset]
	payload.TxType = uint(txType)
	offset++
```

```go
func (cs *ChainStore) InsertEventIfNotExists(event *store.Event) (bool, error) {
	if cs.database == nil {
		return false, fmt.Errorf("database is nil")
	}

	// Check for existing event
	var existing store.Event
	err := cs.database.Client().Where("event_id = ?", event.EventID).First(&existing).Error
	if err == nil {
		// Event already exists
		return false, nil
	}
	if err != gorm.ErrRecordNotFound {
		return false, fmt.Errorf("failed to check existing event: %w", err)
	}

	// Store new event
	if err := cs.database.Client().Create(event).Error; err != nil {
		// UNIQUE constraint violation means another goroutine or poll cycle already
		// inserted this event between our check and insert — treat as duplicate.
		if strings.Contains(err.Error(), "UNIQUE constraint failed") {
			return false, nil
		}
		return false, fmt.Errorf("failed to create event: %w", err)
	}

	return true, nil
}
```
