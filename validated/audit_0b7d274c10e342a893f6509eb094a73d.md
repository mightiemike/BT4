## Analysis

The external report's core defect is: a withdraw/exit swap executes with `minOut = 0`, i.e., no real slippage protection, letting an attacker (via price manipulation or unfavorable execution) extract value from the user's swap. The Push Chain analog exists in the auto-swap paths that convert a user's deposited PRC20 (bridged) collateral into native PC via Uniswap V3, and in the gas-refund swap-back path.

### Title
Swap "slippage protection" for PRC20→PC auto-swaps is derived from a same-transaction spot quote, not an independent price reference - ([File: x/uexecutor/keeper/evm.go, execute_inbound_gas.go, execute_inbound_gas_and_payload.go, outbound.go])

### Summary
`GetSwapQuote` fetches a Uniswap V3 `QuoterV2.quoteExactInputSingle` spot quote and the caller immediately derives `minPCOut = quote * 95 / 100` and, in the very same keeper flow, executes `depositPRC20WithAutoSwap` against that same pool. [1](#0-0)  Because the "protection" bound is computed from the identical, manipulable on-chain pool state that the swap itself will execute against (rather than a TWAP or externally-verified price), the 5% band only buffers ordinary price drift between the quote call and swap call within the same tx — it does nothing to prevent an attacker who manipulates the underlying pool price (e.g., via a large trade sandwiching the block in which the module-originated swap lands) from making both the "reference" quote and the real swap execute at the manipulated price.

### Finding Description
This pattern is used in three call sites:
- `ExecuteInboundGas`: computes `minPCOut` from `GetSwapQuote` then calls `CallPRC20DepositAutoSwap` in the same execution. [2](#0-1) 
- `gasAndPayloadDepositAutoSwap`: identical pattern for `GAS_AND_PAYLOAD` inbounds. [3](#0-2) 
- `applyGasRefund`: same pattern when swapping the gas token back to PC for excess-gas refunds on outbound finalization. [4](#0-3) 

In all three, the "slippage guard" is `quote * 95 / 100` where `quote` itself comes from the exact pool the swap will hit, queried immediately before executing the swap. [5](#0-4)  This is architecturally equivalent to having `minOut = 0` from a security standpoint: any adversary able to move the pool's spot price in the block where the module-originated deposit/refund swap executes (an ordinary, unprivileged DEX trade on the external Uniswap V3 pool used by `UniversalCore`) can depress the price just before the quote+swap pair executes, causing both to reflect the manipulated rate, then restore the price afterward and capture the difference — a classic sandwich against a swap that only checks against its own spot price rather than an independent, harder-to-manipulate reference (e.g., a TWAP).

### Impact Explanation
Users bridging PRC20 collateral in as `GAS` / `GAS_AND_PAYLOAD` inbounds, and users owed excess-gas refunds on outbound finalization, can receive materially less native PC than fair value, with the difference captured by an unprivileged attacker trading against the same pool. This is a fund-loss issue reachable purely through ordinary user deposit/outbound flows and ordinary DEX trading — no validator or admin compromise required.

### Likelihood Explanation
The trigger only requires the ability to trade on the referenced Uniswap V3 pool around the block containing the module's derived swap call, which is a normal unprivileged capability on an EVM chain with a visible mempool/block-building process. The threshold-based execution (ballot finalization, outbound observation) provides a somewhat predictable trigger point that an attacker can watch for and time a sandwich around, making this practically exploitable, though it requires liquidity/capital to move the specific pool and depends on Push Chain's block-building/mempool visibility characteristics.

### Recommendation
Replace the same-block spot `QuoterV2` quote used as the slippage benchmark with an independent, harder-to-manipulate price reference (e.g., a TWAP over multiple blocks, or a governance/oracle-set reference price), or otherwise bound the acceptable deviation between the executed swap and a price source that cannot be moved atomically by the same actor executing the swap.

### Proof of Concept
1. Attacker identifies a pending `GAS`/`GAS_AND_PAYLOAD` inbound (or a pending outbound about to finalize with excess-gas refund) that will trigger `ExecuteInboundGas`/`gasAndPayloadDepositAutoSwap`/`applyGasRefund`.
2. Immediately before/around the block in which the module's derived EVM call executes, attacker submits a large trade against the same Uniswap V3 pool (`prc20Address`/`gasToken` vs `wpcAddress`) to depress price.
3. `GetSwapQuote` returns the manipulated (lower) quote; `minPCOut = quote*95/100` is computed from this manipulated value. [6](#0-5) 
4. `CallPRC20DepositAutoSwap`/`CallUniversalCoreRefundUnusedGas` executes the swap at the manipulated rate, satisfying its own (manipulated) `minPCOut` bound and delivering less PC than the user should fairly receive.
5. Attacker reverses the initial trade, capturing the arbitrage profit extracted from the protocol/user swap.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}
