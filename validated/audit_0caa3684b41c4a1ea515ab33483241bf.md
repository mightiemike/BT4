### Title
Manipulable spot-price swap quote allows attacker to corrupt PRC20→WPC auto-swap slippage protection - (File: x/uexecutor/keeper/execute_inbound_gas.go)

### Summary
Push Chain's gas-abstraction and refund flows swap inbound PRC20 tokens for WPC (wrapped native PC) using a `minPCOut` bound computed from a single, same-block spot quote pulled from the Uniswap-V3-style pool deployed on Push Chain's own EVM. There is no TWAP, external oracle, or governance-set floor price anywhere in the module — the quote and the swap execution both read the same manipulable pool state. This mirrors the H-02 pattern: a value used to gate/guard a protocol operation (there, collateral status; here, minimum acceptable swap output) is derived from a pool composition that an unprivileged actor can distort within the same block, extract value, and revert.

### Finding Description
`GetSwapQuote` calls `QuoterV2.quoteExactInputSingle` on the live pool to get `amountOut` for a PRC20→WPC swap: [1](#0-0) 

This quote is then only shaved by a fixed 5% before being used as the executed swap's minimum-output guard, in three separate code paths: [2](#0-1) [3](#0-2) [4](#0-3) 

Because `quote` and the subsequent `CallPRC20DepositAutoSwap`/`CallUniversalCoreRefundUnusedGas` execution happen sequentially inside the same module-driven flow, an unprivileged attacker who trades against the pool in a transaction ordered just before the module's derived EVM call — the classic flash-loan/sandwich pattern from the external report — can push the pool's instantaneous price to whatever value is profitable, wait for the module to read that manipulated price via `quoteExactInputSingle`, let the swap execute with only a 5% cushion around the distorted price, and then reverse their own position in the same or a following transaction, capturing the difference between the manipulated execution price and the pool's fair/pre-attack price. This is functionally identical to the flashloan-manipulated threshold check in the external report: a protocol-critical decision (there, `_anyDepeggedInPool`'s deviation check; here, `minPCOut`'s deviation check) is derived from a spot on-chain value with no manipulation-resistant sourcing (no TWAP, no external oracle, no min-liquidity/deviation sanity check against a stored reference price).

Local devnet documentation and setup scripts corroborate that these pools are thin and easily moved: [5](#0-4) 

### Impact Explanation
This falls under "corruption of PRC20 or native asset accounting, gas fee accounting, refund accounting" and "unauthorized state transitions in universal execution flows" in the allowed-impact gate. A successful attack drains value from either the user (whose inbound gas gets converted to WPC at a manipulated, unfavorable rate, protected only by a fixed 5% band around a corrupted quote) or from protocol-controlled liquidity (if the attacker manipulates price to receive more WPC than the fair swap would return, taking the difference from pool reserves that the protocol effectively backstops via its own swap flow). Because this triggers on ordinary inbound deposits (gas abstraction) and ordinary outbound gas refunds — both default, unprivileged-user-reachable flows — it satisfies the "reachable without privileged control" requirement.

### Likelihood Explanation
Likelihood is proportional to pool depth: on any newly bootstrapped chain or newly listed token, WPC/PRC20 pools have shallow liquidity (as acknowledged in the e2e setup comments about "tiny WPC/pSOL AMM pool"), making single-transaction price manipulation with a modest flash loan or self-funded capital straightforward. The attack requires no validator collusion, no admin privileges, and no cross-chain trust assumptions — only ordinary EVM transactions against a Push-Chain-hosted pool combined with triggering (or waiting for) an inbound/outbound gas swap.

### Recommendation
Do not rely on a single spot-price `quoteExactInputSingle` call taken at execution time as the sole slippage guard. Options: (1) source `minPCOut` from a manipulation-resistant reference (e.g., a TWAP over N blocks, or the chain-meta/gas-price oracle already aggregated via UV median voting), (2) widen or dynamically compute the slippage band based on pool liquidity depth and cap maximum price impact per swap, (3) add a sanity check comparing the spot quote against a stored/aggregated reference price and reject or fall back to no-swap PRC20 delivery when deviation exceeds a bounded threshold, similar in spirit to the external report's suggestion to check the outside-pool/LP price rather than trusting the manipulable in-pool distribution directly.

### Proof of Concept
1. Attacker identifies a Push-Chain-hosted WPC/PRC20 pool with shallow liquidity for a given gas token.
2. Attacker submits a large swap (self-funded or flash-loaned within Push Chain's EVM) that shifts the pool's instantaneous price against the direction that benefits a pending inbound/outbound gas swap.
3. In the same block, an inbound deposit (or outbound completion) triggers `ExecuteInboundGas`/`applyGasRefund`, which calls `GetSwapQuote` and reads the now-manipulated price, then executes `CallPRC20DepositAutoSwap`/`CallUniversalCoreRefundUnusedGas` with `minPCOut = quote * 0.95`.
4. The module's swap executes against the manipulated pool, transferring value to the attacker's position (or shortchanging the victim's user account) at the distorted rate.
5. Attacker reverses their manipulating trade (repaying any flash loan) in a subsequent transaction in the same or next block, retaining the extracted profit while the pool price returns to normal.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}
