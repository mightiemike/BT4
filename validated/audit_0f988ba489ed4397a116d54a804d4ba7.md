## Analysis: On-chain AMM spot-price trusted as its own slippage reference in gas-abstraction autoswap

### Title
Gas-abstraction autoswap (`ExecuteInboundGas`) computes `minPCOut` from the same manipulable Uniswap-V3 spot quote it swaps against, allowing sandwich extraction of user deposits - (File: `x/uexecutor/keeper/execute_inbound_gas.go`)

### Summary
`ExecuteInboundGas` implements the gas-abstraction swap path (`GAS_ONLY` / `GAS_AND_PAYLOAD` inbounds), converting a bridged PRC20 into WPC via `CallPRC20DepositAutoSwap`. Its only slippage guard, `minPCOut`, is derived by taking 5% off the *same* just-fetched `QuoterV2.quoteExactInputSingle` spot quote that determines the swap price, rather than validating that quote against an independent reference (e.g. Chainlink or the module's own `ChainMeta`/registry price data), which is exactly the flaw described in the GMX report.

### Finding Description
`k.GetSwapQuote` performs a static call to `QuoterV2.quoteExactInputSingle` to obtain a same-block, on-chain spot quote from a Uniswap-V3-style pool [1](#0-0) . `ExecuteInboundGas` then computes the slippage bound directly from that quote and immediately performs the swap with it:

```go
quote, execErr = k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
...
minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
minPCOut.Div(minPCOut, big.NewInt(100))
receipt, execErr = k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
``` [2](#0-1) 

Because `minPCOut` is only ever bounded relative to the pool's own instantaneous price, this "slippage protection" verifies nothing about fairness — it only ensures the executed price doesn't drift more than 5% from whatever price the pool happens to be at when `GetSwapQuote` is called. If the pool is already manipulated (e.g. via a large swap in a prior block, or a swap immediately preceding the ballot's finalization block), both the quote and the subsequent swap execute against the same skewed price, and the 5% band travels with the manipulation. This is structurally identical to `exchangeFromExactBase()` trusting GMX's `getMinPrice()`/`getMaxPrice()` without cross-checking against Chainlink.

`ExecuteInboundGas` is reached automatically by the honest-validator finalization pipeline whenever a `GAS_ONLY`/`GAS_AND_PAYLOAD` inbound reaches quorum — i.e., for every ordinary user gas-abstraction deposit, with no privileged actor involved.

### Impact Explanation
An unprivileged attacker who can move the price of the WPC/PRC20 Uniswap V3 pool used by `defaultFeeTier`/`QuoterV2` (ordinary swap transactions, no special privilege required) can force any user's (or their own) gas-abstraction deposit to be autoswapped at an unfair, attacker-favorable rate. The victim's `UEA` receives materially less WPC than fair value while the attacker captures the difference by reversing their pool manipulation afterward (classic sandwich/spot-price manipulation), corrupting PRC20-to-native accounting for the affected `UniversalTx` and directly transferring value from users/protocol to the attacker.

### Likelihood Explanation
Every ordinary `GAS_ONLY`/`GAS_AND_PAYLOAD` inbound deposit invokes this exact code path with no additional preconditions, so the trigger is fully user-reachable. The only requirement for the attacker is the ability to move the price on the specific fee-tier pool selected by `GetDefaultFeeTierForToken`, which is an ordinary DEX interaction, not a privileged action.

### Recommendation
Do not derive the slippage bound solely from the same spot quote being executed against. Cross-validate the Uniswap spot quote against an independent price reference (e.g., a TWAP over multiple blocks, or the chain's registered token price data) before accepting it as the basis for `minPCOut`, mirroring the fix applied upstream for `exchangeFromExactBase()` (bounding GMX's manipulable price against Chainlink).

### Proof of Concept
1. Attacker swaps a large amount in the WPC/PRC20 Uniswap V3 pool (the specific fee tier returned by `GetDefaultFeeTierForToken`) to skew the spot price so PRC20 is undervalued relative to WPC.
2. Attacker (or any user) submits/has pending a `GAS_AND_PAYLOAD`/`GAS_ONLY` inbound deposit of PRC20-backed assets; universal validators vote it to quorum.
3. On finalization, `ExecuteInboundGas` calls `GetSwapQuote`, which reads the already-skewed pool price, then computes `minPCOut = quote * 0.95` and calls `CallPRC20DepositAutoSwap` in the same manipulated pool state [3](#0-2) .
4. The swap executes at the manipulated rate (satisfying its own 5% band trivially), crediting the recipient `UEA` with less WPC than fair value.
5. Attacker reverses the initial pool swap, extracting the manipulated spread as profit. [4](#0-3)

// GetDefaultFeeTierForToken reads defaultFeeTier[prc20] from UniversalCore.
func (k Keeper) GetDefaultFeeTierForToken(ctx sdk.Context, prc20Address common.Address) (*big.Int, error) {
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse UniversalCore ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	receipt, err := k.evmKeeper.CallEVM(ctx, abi, ueModuleAccAddress, handlerAddr, false, nil, "defaultFeeTier", prc20Address)
	if err != nil {
		return nil, errors.Wrap(err, "failed to call defaultFeeTier")
	}

	results, err := abi.Methods["defaultFeeTier"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack defaultFeeTier result")
	}

	// go-ethereum unpacks uint24 as *big.Int (non-standard widths always map to *big.Int)
	fee, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for defaultFeeTier: %T", results[0])
	}

	return fee, nil
}

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}
