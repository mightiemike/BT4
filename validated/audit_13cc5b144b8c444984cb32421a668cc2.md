Based on my investigation, this CVE describes an infinite loop in Wireshark's WSP dissector caused by a header/parameter parsing loop that fails to advance its read position on certain malformed packet data. I searched for the analogous "non-advancing loop" pattern across protobuf-go's binary, JSON, and text decode paths:

- The core binary unmarshal loops (`internal/impl/decode.go` `unmarshalPointerEager`, `internal/impl/lazy.go` `unmarshalField`/`unmarshalPointerLazy`, `proto/decode.go` `unmarshalMessageSlow`) all consume via `protowire.ConsumeTag`/`ConsumeVarint`/`ConsumeFieldValue`, and each of these explicitly returns a negative sentinel on failure to advance, which is checked (`if n < 0 { return out, errDecode }`) before the loop continues, preventing infinite spin. [1](#0-0) [2](#0-1) 

- The lazy-index builder (`internal/protolazy/lazy.go` `buildIndex`) and `BufferReader.SkipGroup`/`SkipValue` similarly bail out with an error on any decode failure rather than looping without progress. [3](#0-2) [4](#0-3) 

- The ProtoJSON decoder's list/map/message loops (`encoding/protojson/decode.go` `unmarshalMessage`, `unmarshalList`, `unmarshalMap`) depend on the underlying tokenizer (`internal/encoding/json/decode.go` `Decoder.Read`), which always consumes at least one byte per token or returns an explicit syntax/EOF error — there's even an explicit comment noting the EOF case is guarded specifically "to avoid an infinite loop." [5](#0-4) [6](#0-5) 

None of these loops exhibit the WSP dissector's broken invariant (looping without consuming bytes on certain malformed input). All discovered loops either monotonically shrink the remaining buffer or terminate on an explicit error before the next iteration, so there is no reachable analog of CVE-2016-6506 in protobuf-go's default binary or ProtoJSON decode paths under the stated trusted-schema/unprivileged-caller threat model.

// skipGroup skips a group with the specified tag.  It executes efficiently using a tag stack
func (b *BufferReader) SkipGroup(tag uint32) (err error) {
	tagStack := make([]uint32, 0, 16)
	tagStack = append(tagStack, tag)
	var n uint32
	for len(tagStack) > 0 {
		tag, err = b.DecodeVarint32()
		if err != nil {
			return err
		}
		switch protowire.Type(tag & 0x7) {
		case protowire.VarintType:
			err = b.SkipVarint()
		case protowire.Fixed64Type:
			err = b.Skip(8)
		case protowire.BytesType:
			n, err = b.DecodeVarint32()
			if err == nil {
				err = b.Skip(int(n))
			}
		case protowire.StartGroupType:
			tagStack = append(tagStack, tag)
		case protowire.Fixed32Type:
			err = b.SkipFixed32()
		case protowire.EndGroupType:
			if protoFieldNumber(tagStack[len(tagStack)-1]) == protoFieldNumber(tag) {
				tagStack = tagStack[:len(tagStack)-1]
			} else {
				err = fmt.Errorf("end group tag %d does not match begin group tag %d at pos %d",
					protoFieldNumber(tag), protoFieldNumber(tagStack[len(tagStack)-1]), b.Pos)
			}
		}
		if err != nil {
			return err
		}
	}
	return nil
}
