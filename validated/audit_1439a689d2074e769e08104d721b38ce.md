### Title
Unbounded, cost-free account creation via gasless `AccountInitDecorator` — state-bloat DOS ([File: app/ante/account_init_decorator.go])

### Summary
The Hats `mintTopHat()` bug lets an attacker permanently exhaust a scarce on-chain resource (the 32-bit top-hat ID space) through an unprivileged, cheap, repeatable action, degrading the protocol for everyone. Push Chain's gasless bootstrap path in `AccountInitDecorator` has the same shape: an unprivileged attacker can create unlimited, permanently-persisted Cosmos accounts on Push Chain for zero fee and zero pre-existing balance, purely by generating fresh keypairs and signing trivially-valid gasless messages, causing unbounded growth of the global account store across every honest node.

### Finding Description
`AccountInitDecorator.AnteHandle` (`app/ante/account_init_decorator.go:31-81`) runs for any transaction whose messages are entirely within the gasless whitelist (`app/txpolicy/gasless.go:17-25`, which includes `MsgVoteChainMeta`, `MsgVoteInbound`, `MsgVoteOutbound`, `MsgExecutePayload`, `MsgMigrateUEA`, `MsgVoteTssKeyProcess`, `MsgVoteFundMigration`).

For any signer address that does not yet have an on-chain account, the decorator:
1. Verifies the signature against a fixed `account_number=0, sequence=0` (`account_init_decorator.go:106-159`) — trivially satisfiable because the attacker generates and signs with their own brand-new key.
2. Calls `ak.NewAccountWithAddress` + `SetSequence(1)` + `SetAccount` to persist a new account (`account_init_decorator.go:68-70`).
3. Returns `(ctx, nil)` directly — **it never calls `next(ctx, tx, simulate)`**, so it short-circuits the entire rest of the ante chain and the actual message is never executed.

Because `DeductFeeDecorator` (`app/ante/fee.go:59-64`) also unconditionally skips fee collection for gasless txs, and this decorator runs *before* `SetPubKeyDecorator`/`SigVerificationDecorator`/`IncrementSequenceDecorator`, the attacker pays **no fee, needs no funded account, and needs no protocol-level privilege** (e.g. being a bonded Universal Validator) to get an account persisted. The whitelisted messages' `ValidateBasic()` checks (e.g. `MsgVoteChainMeta.ValidateBasic`, `MsgVoteInbound.ValidateBasic`) only check for non-empty/non-zero fields — they do not verify the signer is an authorized validator or owner. The decorator itself performs no check that the signer corresponds to any legitimate bonded UV or UEA owner before creating the account.

### Impact Explanation
An attacker can script an off-chain loop: generate a keypair, craft a syntactically-valid gasless message (e.g. `MsgVoteChainMeta` with non-empty `ObservedChainId`/non-zero `Price`/`ChainHeight`), sign it with the fresh key, and broadcast. Each such transaction is free and results in a permanent new entry in the `x/auth` account store on every honest node — the underlying message is discarded (since `next()` is never invoked), so the attack costs the network storage/bandwidth/replication overhead with zero cost or business value returned to anyone. Repeated indefinitely (bounded only by per-block gas from `ConsumeGasForTxSizeDecorator`, not by any fee or cap), this permanently and unboundedly grows account-store/IAVL size, increasing sync time, snapshot size, and state-storage burden for every honest full node/validator — a denial-of-service reachable by an ordinary unprivileged actor acting entirely alone, without any external-chain or validator compromise.

### Likelihood Explanation
High. No monetary cost is required beyond negligible bandwidth to broadcast transactions; no pre-funded account, validator bonding, or privileged role is needed. The whitelist-check and `ValidateBasic()` gates are trivially satisfiable with garbage-but-well-formed field values, and the decorator performs no authorization or rate-limiting check tying the bootstrap privilege to an actual bonded UV/UEA owner.

### Recommendation
Mirror the Hats mitigation pattern (bound the free resource): 
- Require the message content to be independently authorizable before the free account-bootstrap grant is issued — e.g., only allow `AccountInitDecorator` to fire for `MsgVoteTssKeyProcess`/`MsgVoteFundMigration`/`MsgVoteInbound`/`MsgVoteOutbound`/`MsgVoteChainMeta` when the signer's pubkey maps to a currently bonded Universal Validator/consensus key (looked up via `x/uvalidator` or the validator set) rather than accepting any never-before-seen address.
- Alternatively, impose a small non-refundable minimum fee or a strict per-block/per-epoch cap on “free” account creations to make mass account creation economically or throughput-bounded, consistent with how Hats considered (but ultimately rejected for different reasons) requiring a deposit fee to bound top-hat minting.
- Add telemetry/limits on new-account creation rate to detect and throttle abuse before it materially impacts state size.

### Proof of Concept
1. Off-chain: generate N fresh secp256k1/ed25519 keypairs, none funded, none registered anywhere.
2. For each keypair, build a `MsgVoteChainMeta{Signer: newAddr, ObservedChainId: "anything", Price: 1, ChainHeight: 1}` (any gasless-whitelisted msg works), sign it with `account_number=0, sequence=0`.
3. Broadcast the tx. `IsGaslessTx` → true → `DeductFeeDecorator` skips fee → `AccountInitDecorator` sees `!ak.HasAccount(newAddr)`, signature check passes (self-signed by the attacker's own new key), creates and persists the account, returns `(ctx, nil)` without executing the vote.

func (aid AccountInitDecorator) AnteHandle(ctx sdk.Context, tx sdk.Tx, simulate bool, next sdk.AnteHandler) (sdk.Context, error) {
	if !txpolicy.IsGaslessTx(tx) {
		// Skip account initialization for non-gasless transactions
		ctx.Logger().Debug("account init decorator: non-gasless tx, skipping account init")
		return next(ctx, tx, simulate)
	}

	sigTx, ok := tx.(authsigning.Tx)
	if !ok {
		return ctx, errorsmod.Wrap(sdkerrors.ErrTxDecode, "invalid transaction type")
	}

	signers, err := sigTx.GetSigners()
	if err != nil || len(signers) != 1 {
		ctx.Logger().Debug("account init decorator: could not get unique signer, passing to next handler",
			"num_signers", len(signers),
			"error", err,
		)
		return next(ctx, tx, simulate)
	}

	newAccAddr := signers[0]
	if !aid.ak.HasAccount(ctx, newAccAddr) {
		ctx.Logger().Debug("account init decorator: new account detected on gasless tx, verifying signature",
			"address", sdk.AccAddress(newAccAddr).String(),
			"simulate", simulate,
		)
		// if account does not exist on chain, bypass rest of ante chain (especially gas and signature verification) here.
		// Perform signature verification on account number e and sequence number e instead.
		if err := aid.verifySignatureForNewAccount(ctx, tx, simulate); err != nil {
			ctx.Logger().Debug("account init decorator: signature verification failed for new account",
				"address", sdk.AccAddress(newAccAddr).String(),
				"error", err,
			)
			return ctx, err
		}

		acc := aid.ak.NewAccountWithAddress(ctx, newAccAddr)
		acc.SetSequence(1)
		aid.ak.SetAccount(ctx, acc)
		ctx.Logger().Info("account init decorator: new account created via gasless tx",
			"address", sdk.AccAddress(newAccAddr).String(),
		)
		return ctx, nil
	}

	ctx.Logger().Debug("account init decorator: existing account on gasless tx, passing to next handler",
		"address", sdk.AccAddress(newAccAddr).String(),
	)
	return next(ctx, tx, simulate)
}

func IsGaslessTx(tx sdk.Tx) bool {
	var (
		// GaslessMsgTypes defines the message types that are allowed in gasless transactions
		GaslessMsgTypes = []string{
			sdk.MsgTypeURL(&uexecutortypes.MsgMigrateUEA{}),
			sdk.MsgTypeURL(&uexecutortypes.MsgExecutePayload{}),
			sdk.MsgTypeURL(&uexecutortypes.MsgVoteInbound{}),
			sdk.MsgTypeURL(&uexecutortypes.MsgVoteOutbound{}),
			sdk.MsgTypeURL(&utsstypes.MsgVoteTssKeyProcess{}),
			sdk.MsgTypeURL(&utsstypes.MsgVoteFundMigration{}),
			sdk.MsgTypeURL(&uexecutortypes.MsgVoteChainMeta{}),
		}
	)

	msgs := tx.GetMsgs()
	if len(msgs) == 0 {
		return false
	}

	for _, msg := range msgs {
		switch m := msg.(type) {
		case *authz.MsgExec:
			// Only gasless if ALL inner messages are allowed
			for _, innerMsg := range m.Msgs {
				if !slices.Contains(GaslessMsgTypes, innerMsg.TypeUrl) {
					return false
				}
			}
		default:
			if !slices.Contains(GaslessMsgTypes, sdk.MsgTypeURL(msg)) {
				return false
			}
		}
	}
	return true
}

// ValidateBasic does a sanity check on the provided data.
func (msg *MsgVoteChainMeta) ValidateBasic() error {
	if _, err := sdk.AccAddressFromBech32(msg.Signer); err != nil {
		return errors.Wrap(err, "invalid signer address")
	}
	if msg.ObservedChainId == "" {
		return errors.Wrap(sdkerrors.ErrInvalidRequest, "observed_chain_id cannot be empty")
	}
	if msg.Price == 0 {
		return errors.Wrap(sdkerrors.ErrInvalidRequest, "price must be greater than 0")
	}
	if msg.ChainHeight == 0 {
		return errors.Wrap(sdkerrors.ErrInvalidRequest, "chain_height must be greater than 0")
	}
	return nil
}
