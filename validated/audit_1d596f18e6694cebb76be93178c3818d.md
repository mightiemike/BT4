The libEMF issue is an integer overflow in scaling extent calculations that leads to invalid memory access when processing untrusted binary metafile records. Searching for the analogous pattern in protobuf-go — unchecked arithmetic on attacker-controlled length/size fields feeding into buffer indexing or allocation — did not surface a matching unvalidated path.

The core wire-decoding primitives in `encoding/protowire/wire.go`'s `ConsumeVarint` explicitly bounds-check `len(b)` at every 7-bit shift step and returns `errCodeOverflow`/`errCodeTruncated` rather than wrapping silently. [1](#0-0) . Similarly `ConsumeBytes` validates the decoded length `m` against the remaining buffer size before slicing, preventing any out-of-bounds read from an oversized length field. [2](#0-1) .

The lazy-decoding buffer reader in `internal/protolazy/bufferreader.go` mirrors this discipline: `DecodeVarintSlow` and `DecodeVarint`/`DecodeVarint32` explicitly detect the 64-bit/32-bit overflow condition and return `errOverflow` instead of silently wrapping into a bad size, and `Skip` checks `len(b.Buf) < b.Pos+n` before advancing. [3](#0-2) [4](#0-3) .

Generated-message decode paths (e.g. `consumeUint64Slice`, `consumeSfixed64Slice` in `internal/impl/codec_gen.go`) rely on these same primitives and propagate `errDecode` on any negative return rather than proceeding with an unchecked size. [5](#0-4) .

Because every reachable length/size computation on the default binary decode path is bounds-checked against the actual buffer before use (unlike the unchecked `ScaleViewPortExtEx` arithmetic in libEMF), there is no analogous integer-overflow-to-DoS/OOB path in scoped production protobuf-go code reachable via an unprivileged request with a trusted schema.

func ConsumeBytes(b []byte) (v []byte, n int) {
	m, n := ConsumeVarint(b)
	if n < 0 {
		return nil, n // forward error code
	}
	if m > uint64(len(b[n:])) {
		return nil, errCodeTruncated
	}
	return b[n:][:m], n + int(m)
}

var errOverflow = errors.New("proto: integer overflow")

func (b *BufferReader) DecodeVarintSlow() (x uint64, err error) {
	i := b.Pos
	l := len(b.Buf)

	for shift := uint(0); shift < 64; shift += 7 {
		if i >= l {
			err = io.ErrUnexpectedEOF
			return
		}
		v := b.Buf[i]
		i++
		x |= (uint64(v) & 0x7F) << shift
		if v < 0x80 {
			b.Pos = i
			return
		}
	}

	// The number is too large to represent in a 64-bit value.
	err = errOverflow
	return
}

func consumeSfixed64Slice(b []byte, p pointer, wtyp protowire.Type, f *coderFieldInfo, opts unmarshalOptions) (out unmarshalOutput, err error) {
	sp := p.Int64Slice()
	if wtyp == protowire.BytesType {
		b, n := protowire.ConsumeBytes(b)
		if n < 0 {
			return out, errDecode
		}
		count := len(b) / protowire.SizeFixed64()
		if count > 0 {
			p.growInt64Slice(count)
		}
		s := *sp
		for len(b) > 0 {
			v, n := protowire.ConsumeFixed64(b)
			if n < 0 {
				return out, errDecode
			}
			s = append(s, int64(v))
			b = b[n:]
		}
		*sp = s
		out.n = n
		return out, nil
