### Title
Rent-Reclaim Age Check Uses Signature History, Not Account Creation Time — Griefer Can Indefinitely Block Orphan PDA Reclaim - (File: `universalClient/chains/svm/rent_reclaimer.go`)

### Summary
`RentReclaimer.isOldEnough` decides whether an orphaned `StoredIxData` PDA is safe to close by asking Solana's `getSignaturesForAddress` for the most recent signature that references that PDA, and comparing its block time against `minAge` (10 minutes). [1](#0-0)  The comment justifying this design explicitly (and incorrectly) assumes the PDA "only ever see[s] one tx — their creating `store_execute_ix_data`." [2](#0-1)  On Solana, any account pubkey — including one an attacker has no authority over — can be listed as a read-only, non-signer account in an arbitrary, unrelated transaction (e.g., a self-transfer with an extra account appended). Solana's `getSignaturesForAddress` indexes such transactions under that address, since it matches any transaction whose account-keys list contains the address, not just transactions that mutate it.

### Finding Description
An attacker can enumerate orphan `StoredIxData` PDAs the same way `discoverOrphans` does — via a public `getProgramAccounts` call filtered by the account discriminator and refund-recipient (relayer) field [3](#0-2)  — since this is public on-chain state. For each such orphan address, the attacker submits a cheap, self-funded transaction that merely lists that PDA as an unused read-only account, repeating this at an interval shorter than `rentReclaimMinPDAAge` (10 minutes) [4](#0-3) . Each such transaction becomes the "most recent signature" for that PDA in `getSignaturesForAddress`, so `isOldEnough` perpetually observes an age below `minAge` and returns `false`, causing `runOnce` to skip the PDA on every 30-minute sweep tick indefinitely [5](#0-4) .

Note that precise timing relative to the ticker is not actually required — the attacker only needs a refresh cadence shorter than `minAge`, independent of when `runOnce` fires, since `isOldEnough` is a stateless point-in-time check against the latest signature, not against ticks.

### Impact Explanation
This breaks the stated invariant that periodic sweeps eventually reclaim all true orphans, and permanently withholds the rent (~0.002 SOL) locked in each targeted `StoredIxData` PDA from the relayer/protocol. The attack is unprivileged, non-network-flooding (targeted at specific low-value transactions), and low-cost per PDA (base Solana transaction fee only). However, the amount frozen per PDA is small and bounded by the number of orphan PDAs that actually exist (a rare condition requiring a prior `finalize` failure), so the aggregate value at risk is limited — this is a griefing/DoS on a rent-recovery housekeeping process rather than a drain of user funds, mint/burn corruption, or consensus-affecting state divergence.

### Likelihood Explanation
Feasible for any attacker willing to run a low-cost recurring transaction bot targeting known orphan addresses; requires no privileged role, validator collusion, or network flooding — only knowledge of the public account-discovery filter and a wallet capable of paying base transaction fees indefinitely.

### Recommendation
Determine PDA age from data that an unprivileged third party cannot manipulate, e.g., look up the account's creation slot/blocktime via the transaction that actually wrote/initialized the account (first signature, or account rent-epoch/creation metadata) rather than "most recent signature touching the address," or track discovery time server-side (e.g., first time the reclaimer observed the orphan) as the age reference instead of relying on `getSignaturesForAddress`'s "most recent" result.

### Proof of Concept
1. Attacker calls `getProgramAccounts` on the gateway program with the `StoredIxData` discriminator filter and the relayer's pubkey at `storedIxDataRefundRecipientOffset`, mirroring `discoverOrphans`, to obtain candidate orphan PDA addresses.
2. For each candidate PDA address `P`, attacker submits (from their own low-cost wallet) a transaction whose instruction includes `P` as an extra read-only, non-signer account (no actual read/write of `P`'s data is required).
3. Attacker repeats step 2 for `P` at an interval < 10 minutes, indefinitely.
4. On each `RentReclaimer.run` tick (every 30 minutes), `isOldEnough(ctx, P)` queries `getSignaturesForAddress(P)`, finds the attacker's most recent "poisoning" transaction, computes `age < minAge`, and returns `false`, so `runOnce` skips `P` forever regardless of how many ticks elapse. [6](#0-5)

func (r *RentReclaimer) discoverOrphans(ctx context.Context, relayer solana.PublicKey) ([]orphanPDA, error) {
	var result rpc.GetProgramAccountsResult
	err := r.builder.rpcClient.executeWithFailover(ctx, "get_program_accounts", func(client *rpc.Client) error {
		opts := &rpc.GetProgramAccountsOpts{
			Commitment: rpc.CommitmentFinalized,
			Filters: []rpc.RPCFilter{
				// match account type
				{Memcmp: &rpc.RPCFilterMemcmp{Offset: 0, Bytes: solana.Base58(storedIxDataAccountDiscriminator)}},
				// match refund recipient = us
				{Memcmp: &rpc.RPCFilterMemcmp{Offset: storedIxDataRefundRecipientOffset, Bytes: solana.Base58(relayer.Bytes())}},
			},
		}
		resp, innerErr := client.GetProgramAccountsWithOpts(ctx, r.builder.gatewayAddress, opts)
		if innerErr != nil {
			return innerErr
		}
		result = resp
		return nil
	})
	if err != nil {
		return nil, err
	}

	orphans := make([]orphanPDA, 0, len(result))
	for _, ka := range result {
		if ka == nil || ka.Account == nil {
			continue
		}

			continue
		}

	}
	return orphans, nil

// isOldEnough reports whether the most recent tx touching addr is at least
// minAge old. For StoredIxData PDAs, that's effectively the PDA's age (they
// only ever see one tx — their creating store_execute_ix_data).
func (r *RentReclaimer) isOldEnough(ctx context.Context, addr solana.PublicKey) (bool, error) {
	limit := signatureAgeProbeLimit
	var sigs []*rpc.TransactionSignature
	err := r.builder.rpcClient.executeWithFailover(ctx, "get_signatures_for_address", func(client *rpc.Client) error {
		resp, innerErr := client.GetSignaturesForAddressWithOpts(ctx, addr, &rpc.GetSignaturesForAddressOpts{
			Limit: &limit,
		})
		if innerErr != nil {
			return innerErr
		}
		sigs = resp
		return nil
	})
	if err != nil || len(sigs) == 0 {
		return false, err
	}
	if sigs[0].BlockTime == nil {
		return false, nil
	}
	age := time.Since(time.Unix(int64(*sigs[0].BlockTime), 0))
	return age >= r.minAge, nil
}
