## Finding [1](#0-0) 

### Title
Unbounded recursive descent over attacker-influenced `bytecode_segment_lengths` tree causes stack overflow when computing compiled-class hash and re-executing declared classes - (File: `crates/starknet_api/src/contract_class/compiled_class_hash.rs`)

### Summary
The CVE describes a stack-overflow DoS in a recursive-descent parser (`parse_statement`) that has no recursion-depth guard and is driven by attacker-supplied nesting. The sequencer contains structurally analogous unguarded recursive descent over a `NestedIntList` (`bytecode_segment_lengths`) tree that is derived from a user-submitted Sierra class, with no depth cap, in three separate call sites.

### Finding Description
When a class is declared, the sequencer compiles the submitted Sierra program to CASM (`SierraToCasmCompiler::compile`, [2](#0-1) ) via an external, resource-limited subprocess. The resulting `CasmContractClass` carries a `bytecode_segment_lengths: NestedIntList` field whose *nesting depth* is a function of the contract's Sierra call/control-flow structure — this depth is not size-limited by `max_bytecode_size`/`max_memory_usage`/`max_cpu_time`, which only bound total resource usage of the external compiler process, not the recursion depth of the emitted segment tree.

That tree is then walked recursively, **in-process, with no depth guard**, in at least three places reachable from an ordinary declared class:

1. `bytecode_hash_node` — computes the compiled-class hash by recursing once per tree level via `HashableNestedIntList::iter_children`, with no depth check: [1](#0-0) 
This is invoked from `SierraCompiler::compile` right after in-process, native compilation output is hashed ( [3](#0-2) ), from `ClassManager::add_class` on every declare ( [4](#0-3) ), and from blockifier's `state.get_compiled_class_hash_v2` used during transaction execution/migration checks ( [5](#0-4) ).

2. `create_bytecode_segment_structure_inner` — recursively rebuilds the segment tree during Starknet OS re-execution/proving of a declared class's bytecode, again with no depth guard: [6](#0-5) 

3. `get_visited_segments` in blockifier, recursing over the analogous `NestedFeltCounts` tree while computing execution resource/visited-segment accounting: [7](#0-6) 

Notably, the codebase *does* have an explicit recursion-depth guard for Cairo contract-call recursion (`RecursionDepthGuard`/`max_recursion_depth`, enforced via `try_increment_and_check_depth`): [8](#0-7) 
and a dedicated `RUST_MIN_STACK` sizing note tied specifically to `MAX_ENTRY_POINT_RECURSION_DEPTH`: [9](#0-8) 
No equivalent protection exists for the `bytecode_segment_lengths`/`NestedIntList` traversal — this is the exact bug class from CVE-2020-36368: recursive descent with no bound, driven by structure the caller (here, the class declarer) can shape.

### Impact Explanation
A crafted Sierra contract that compiles into a CASM class with a deeply-nested `bytecode_segment_lengths` tree can exhaust the native call stack of any process performing hashing/traversal of that class:
- The class-manager component (hashes on every `add_class`) and any blockifier-executing full node/sequencer (hashes/traverses during DECLARE validation, migration, and subsequent invocations of the class) crash with a stack overflow (process abort), rather than returning a graceful error.
- Starknet OS re-execution (proving pipeline) crashes when reconstructing the bytecode segment structure for the same class, which can halt block proving/re-execution for that block.
A crash at any of these mandatory per-declare/per-block stages can render the sequencer unable to admit/execute the declaring transaction or unable to produce/verify the corresponding block, i.e. a network unable to confirm new transactions — a Medium/High-severity availability issue reachable purely by an unprivileged declarer submitting one class.

### Likelihood Explanation
Reachable by any account submitting a single DECLARE transaction containing a Sierra program engineered to produce a segment-length tree with very deep nesting (achievable by chaining many nested functions/control-flow scopes within existing bytecode-size limits, since segmentation depth is not itself size- or depth-bounded). No special privileges, staking, or operator/prover role is required — only the ability to declare a class, which is a standard, unprivileged capability of any Starknet account.

### Recommendation
- Add an explicit maximum recursion/nesting-depth check (analogous to `RecursionDepthGuard`/`max_recursion_depth`) when constructing/validating `bytecode_segment_lengths` right after Sierra→CASM compilation, rejecting classes whose segment tree exceeds a safe bound before they are hashed or persisted.
- Convert the recursive traversals in `bytecode_hash_node`, `create_bytecode_segment_structure_inner`, and `get_visited_segments` to iterative (worklist/stack-based) implementations, or add a depth counter that returns an error (e.g., a new `CompilationUtilError`/`OsHintError` variant) instead of overflowing the native stack.
- Alternatively/in addition, enforce a depth bound within the Sierra-to-CASM compilation step itself (or immediately validate compiler output) so no declared class can ever carry a `NestedIntList` beyond a fixed, small maximum depth.

### Proof of Concept
1. Author a Cairo 1 contract whose Sierra program is structured (e.g., via many nested function calls / deeply nested control-flow blocks) so that the cairo-lang Sierra→CASM segmentation algorithm emits a `bytecode_segment_lengths: NestedIntList` with nesting depth in the thousands, while keeping total bytecode size under `max_bytecode_size`.
2. Submit a DECLARE transaction for this class to the sequencer/gateway.
3. Observe that `SierraCompiler::compile` ( [3](#0-2) ) or the subsequent blockifier hash/validation of the compiled class hash ( [1](#0-0) ) crashes the process with a stack overflow instead of returning `SierraCompilerError`/`ClassManagerError`, and/or that Starknet OS re-execution of the block crashes in `create_bytecode_segment_structure_inner`.

```rust
fn bytecode_hash_node<H, NL>(iter: &mut impl Iterator<Item = Felt>, node: &NL) -> (usize, Felt)
where
    H: StarkHash,
    NL: HashableNestedIntList,
{
    if node.is_leaf() {
        let len = node.get_segment_length();
        let data = iter.take(len).collect_vec();
        assert_eq!(data.len(), len);
        (len, H::hash_array(&data))
    } else {
        // Compute `1 + poseidon(len0, hash0, len1, hash1, ...)`.
        let inner_nodes = node
            .iter_children()
            .map(|child| bytecode_hash_node::<H, NL>(iter, child))
            .collect_vec();
        let hash = H::hash_array(
            &inner_nodes.iter().flat_map(|(len, hash)| [Felt::from(*len), *hash]).collect_vec(),
        ) + Felt::ONE;
        (inner_nodes.iter().map(|(len, _)| len).sum(), hash)
    }
}
```

```rust
pub(crate) fn create_bytecode_segment_structure_inner(
    bytecode: &[Felt],
    bytecode_segment_lengths: NestedIntList,
    bytecode_offset: usize,
) -> (BytecodeSegmentNode, usize) {
    match bytecode_segment_lengths {
        NestedIntList::Leaf(length) => {
            let segment_end = bytecode_offset + length;
            let bytecode_segment = bytecode[bytecode_offset..segment_end].to_vec();

            (BytecodeSegmentNode::Leaf(BytecodeSegmentLeaf { data: bytecode_segment }), length)
        }
        NestedIntList::Node(lengths) => {
            let mut segments = vec![];
            let mut total_len = 0;
            let mut bytecode_offset = bytecode_offset;

            for item in lengths {
                let (current_structure, item_len) =
                    create_bytecode_segment_structure_inner(bytecode, item, bytecode_offset);

                segments.push(BytecodeSegment { length: item_len, node: current_structure });

                bytecode_offset += item_len;
                total_len += item_len;
            }

            (BytecodeSegmentNode::InnerNode(BytecodeSegmentInnerNode { segments }), total_len)
        }
    }
}
```

```rust
fn get_visited_segments(
    segment_lengths: &NestedFeltCounts,
    visited_pcs: &mut Vec<usize>,
    bytecode_offset: &mut usize,
) -> Result<Vec<usize>, TransactionExecutionError> {
    let mut res = Vec::new();

    match segment_lengths {
        NestedFeltCounts::Leaf(length, _) => {
            let segment = *bytecode_offset..*bytecode_offset + length;
            if visited_pcs.last().is_some_and(|pc| segment.contains(pc)) {
                res.push(segment.start);
            }

            while visited_pcs.last().is_some_and(|pc| segment.contains(pc)) {
                visited_pcs.pop();
            }
            *bytecode_offset += length;
        }
        NestedFeltCounts::Node(segments) => {
            for segment in segments {
                let segment_start = *bytecode_offset;
                let next_visited_pc = visited_pcs.last().copied();

                let visited_inner_segments =
                    get_visited_segments(segment, visited_pcs, bytecode_offset)?;

                if next_visited_pc.is_some_and(|pc| pc != segment_start)
                    && !visited_inner_segments.is_empty()
                {
                    return Err(TransactionExecutionError::InvalidSegmentStructure(
                        next_visited_pc.unwrap(),
                        segment_start,
                    ));
                }

                res.extend(visited_inner_segments);
            }
        }
    }
    Ok(res)
}
```

```rust
// Ensure that the recursion depth does not exceed the maximum allowed depth.
struct RecursionDepthGuard {
    current_depth: Arc<RefCell<usize>>,
    max_depth: usize,
}

impl RecursionDepthGuard {
    fn new(current_depth: Arc<RefCell<usize>>, max_depth: usize) -> Self {
        Self { current_depth, max_depth }
    }

    // Tries to increment the current recursion depth and returns an error if the maximum depth
    // would be exceeded.
    fn try_increment_and_check_depth(&mut self) -> Result<(), EntryPointExecutionError> {
        *self.current_depth.borrow_mut() += 1;
        if *self.current_depth.borrow() > self.max_depth {
            return Err(EntryPointExecutionError::RecursionDepthExceeded);
        }
        Ok(())
    }
}
```
