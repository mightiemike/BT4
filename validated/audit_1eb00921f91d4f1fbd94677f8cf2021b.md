## Finding

### Title
Truncating division before multiplication in `CalculateGasCost` can zero out gas-fee collection for payload execution — (File: `x/uexecutor/keeper/fees.go`)

### Summary
`x/uexecutor/keeper/fees.go`'s `CalculateGasCost` truncates the on-chain `baseFee` (an 18-decimal `LegacyDec`) down to a whole "upc" integer via integer division **before** multiplying by `gasUsed`, instead of multiplying the raw decimal-precision base fee by `gasUsed` and dividing once at the end. This is the same division-before-multiplication ordering flaw as the referenced Y2K Finance `beforeWithdraw` bug, and it can cause the computed `gasCost` to be silently rounded down — including to exactly zero — even though real EVM gas was consumed, mirroring the "receiver/treasury receive nothing" impact.

### Finding Description [1](#0-0) 

```go
baseFeeBig := baseFee.BigInt()
// ... comment asserts baseFee is always a whole number of upc ...
baseFeeBig.Div(baseFeeBig, big.NewInt(1e18))
```

`baseFee.BigInt()` returns the internal fixed-point representation of the `LegacyDec` (value × 10^18). The code immediately floor-divides this by `1e18` to recover an integer "upc" price, and only afterward multiplies by `gasUsed`: [2](#0-1) 

This is called from `DeductGasFeesFromReceipt`, which is the sole gas-fee accounting step for UEA/CEA payload execution (`ExecuteInboundGasAndPayload` → deduct fee from recipient → burn): [3](#0-2) 

If `gasCost.Sign() <= 0`, the function returns `nil` and **no fee is deducted or burned at all** — the invariant "gas consumed on execution must be charged to the recipient" is broken.

The comment justifying the `Div` claims "the base fee is always a whole number of upc — no fractional upc exists," but this is an assumption about the feemarket's `BaseFee` state, not something enforced by this function. The feemarket's EIP-1559-style base-fee adjustment (`BeginBlock` calculation based on gas-used delta) is a `LegacyDec` computation that can legitimately produce fractional (sub-1-upc) values over time as blocks run below/above target gas usage, unless a floor no lower than 1 upc is strictly enforced elsewhere in the feemarket keeper. Any unprivileged user submitting ordinary payload transactions when the network's actual base fee is below 1 upc (a state reachable purely through normal, low block-utilization periods — not requiring any privileged actor) triggers `effectiveGasPrice = 0`, hence `gasCost = 0`, hence the fee-burn step is skipped entirely for that execution.

### Impact Explanation
When triggered, the protocol collects and burns zero fee for a payload execution that consumed real EVM gas resources, i.e., a permanent loss/under-collection of protocol fee accounting — the same class of impact as the referenced report (receiver/treasury silently receiving nothing due to a rounding-to-zero artifact from wrong operation order). Even in sub-total-zero cases (baseFee has a nonzero but non-integer upc component), the truncation systematically undercharges every payload-gas deduction across the network, corrupting fee/burn accounting invariants.

### Likelihood Explanation
Reachable by any unprivileged user simply by submitting an inbound funds-and-payload/gas-and-payload transaction whenever the live `feemarketKeeper.GetBaseFee` value happens to be below 1 upc (or non-integer). Materiality depends on whether the feemarket module enforces an integer/≥1-upc floor on `BaseFee` independent of the `MinGasPrice` ante-check (which only gates the *user-supplied* transaction fee, not the module's internal `BaseFee` state used here). This should be verified against the deployed feemarket parameters/floor logic; if no such hard floor exists, the bug is trivially and repeatedly triggerable during normal low-traffic periods.

### Recommendation
Reorder the arithmetic to multiply before dividing, and only floor-divide once at the very end (matching the Y2K Finance mitigation of `(amount * idClaimTVL[id]) / idFinalTVL[id]`):

```go
gasUsedBig := new(big.Int).SetUint64(gasUsed)
// baseFee.BigInt() is already scaled by 1e18; multiply first, then divide once.
gasCost := new(big.Int).Mul(baseFee.BigInt(), gasUsedBig)
gasCost.Div(gasCost, big.NewInt(1e18))
```
Additionally, add an explicit floor check (e.g., reject or round up to 1 upc minimum) rather than silently returning `nil`/skipping fee collection when the computed cost is non-positive.

### Proof of Concept
1. Set `feemarketKeeper`'s `BaseFee` to a `LegacyDec` representing `0.9` upc (i.e., internal `BigInt()` = `9 * 10^17`).
2. Call `k.CalculateGasCost(baseFee, maxFeePerGas, maxPriorityFeePerGas, gasUsed)` with any `gasUsed > 0`.
3. `baseFeeBig.Div(baseFeeBig, 1e18)` → `9*10^17 / 10^18 = 0` (integer division truncates).
4. `effectiveGasPrice = 0` → `gasCost = 0 * gasUsed = 0`.
5. In `DeductGasFeesFromReceipt`, `gasCost.Sign() <= 0` is true → function returns `nil`, and `DeductAndBurnFees` is never invoked — the recipient pays nothing despite `receipt.GasUsed > 0`. [4](#0-3)

```go
func (k Keeper) CalculateGasCost(
	baseFee sdkmath.LegacyDec,
	maxFeePerGas *big.Int,
	maxPriorityFeePerGas *big.Int,
	gasUsed uint64,
) (*big.Int, error) {
	baseFeeBig := baseFee.BigInt()
	// @dev: LegacyDec stores values with 18-decimal precision internally, so 1 upc = 1e18
	// in the LegacyDec representation. Since 1 upc is the smallest denomination (like wei
	// in Ethereum), the base fee is always a whole number of upc -- no fractional upc exists.
	// This division unwraps the LegacyDec encoding back to the actual upc amount.
	// Note: baseFee.BigInt() returns a reference to the internal big.Int; the in-place Div
	// mutates it, which is safe here since baseFee is a local value-type copy.
	baseFeeBig.Div(baseFeeBig, big.NewInt(1e18))
```

```go
func (k Keeper) DeductGasFeesFromReceipt(
	ctx context.Context,
	sdkCtx sdk.Context,
	recipient common.Address,
	receipt *evmtypes.MsgEthereumTxResponse,
	universalPayload *types.UniversalPayload,
) error {
	if receipt == nil || receipt.GasUsed == 0 {
		return nil
	}
	if universalPayload == nil {
		return nil
	}

	abiPayload, err := types.NewAbiUniversalPayload(universalPayload)
	if err != nil {
		return fmt.Errorf("failed to parse payload for gas deduction: %w", err)
	}

	baseFee := k.feemarketKeeper.GetBaseFee(sdkCtx)
	if baseFee.IsNil() {
		return fmt.Errorf("base fee not found")
	}

	gasCost, err := k.CalculateGasCost(baseFee, abiPayload.MaxFeePerGas, abiPayload.MaxPriorityFeePerGas, receipt.GasUsed)
	if err != nil {
		return fmt.Errorf("failed to calculate gas cost: %w", err)
	}
	if gasCost.Sign() <= 0 {
		return nil
	}
```
