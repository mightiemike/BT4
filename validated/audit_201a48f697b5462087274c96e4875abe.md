## Finding Analysis

The external report concerns a Uniswap V3 LP `rebalance` function performing a swap with no slippage bound — an unbounded sandwich-attack surface. Push Chain's scoped `x/uexecutor` code does implement a slippage bound (`minPCOut = quote * 95 / 100`) on every swap it performs, but the *quote used to derive that bound is itself an unauthenticated, same-transaction spot price* pulled from the same Uniswap V3 pool the swap executes against. This reduces the "slippage protection" to a check against a self-manipulable reference price, which is the same class of bug as the original report (swap value governed by manipulable in-block AMM state) rather than a genuine fix.

### Title
On-chain spot-price quote used as its own slippage reference lets an attacker manipulate protocol-executed PRC20→PC swaps - ([File: x/uexecutor/keeper/evm.go])

### Summary
`GetSwapQuote` reads `QuoterV2.quoteExactInputSingle` against the live Uniswap V3 pool immediately before `CallPRC20DepositAutoSwap` executes the real swap in the same keeper call/transaction, with `minPCOut` computed as 95% of that just-fetched quote. Because the quote and the swap read the same pool state with no independent reference (no TWAP, no external oracle, no cross-block observation window), an attacker who moves the pool price before the swap executes controls both the "fair" quote and the executed price, defeating the slippage bound entirely.

### Finding Description
`GetSwapQuote` in [1](#0-0)  calls `quoteExactInputSingle` with `sqrtPriceLimitX96 = 0`, returning the current spot-price-implied output for the pool. This value is used directly to compute the slippage floor:

```go
minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
minPCOut.Div(minPCOut, big.NewInt(100))
```
in three call sites: `ExecuteInboundGas` [2](#0-1) , `gasAndPayloadDepositAutoSwap` [3](#0-2) , and `applyGasRefund`'s swap-refund leg [4](#0-3) .

Immediately after, `CallPRC20DepositAutoSwap` executes the real swap against the same pool via `depositPRC20WithAutoSwap`, passing that same `minPCOut` and a hardcoded `deadline = 0` (meaning "contract uses its default", i.e. no attacker-controlled or externally-verifiable execution-time bound) [5](#0-4) . Both the quote read and the swap write happen inside the same keeper execution — there is no independent TWAP, no minimum-liquidity check, and no comparison against an external price feed (e.g., the CoinGecko/chain-meta gas-price oracle already present in `x/uexecutor` for other purposes).

An unprivileged attacker can:
1. Execute a large swap against the Uniswap V3 pool backing the PRC20↔WPC pair used by `UniversalCore`, pushing the pool's spot price for the target PRC20 down.
2. Trigger (or wait for) a `GAS`, `GAS_AND_PAYLOAD`, or a gas-refund event that causes `ExecuteInboundGas`/`gasAndPayloadDepositAutoSwap`/`applyGasRefund` to run for that PRC20 while the pool is still distorted. Since `VoteInbound`/outbound finalization execution happens automatically once UV quorum is reached — with no minimum-delay or price-freshness requirement — the attacker only needs the manipulating trade and the triggering deposit/outbound-observation to land in temporally adjacent transactions.
3. `GetSwapQuote` returns the depressed quote; `minPCOut` is 95% of that already-bad number, so the manipulated price passes the "slippage" check trivially.
4. `CallPRC20DepositAutoSwap`/`refundUnusedGas` executes the swap at the manipulated price, permanently under-crediting PC to the bridging user's UEA (or refund recipient) versus fair value.
5. The attacker reverses their initial pool-distorting trade, extracting the value gap as arbitrage profit.

### Impact Explanation
This corrupts PRC20/native asset accounting for every `GAS`, `GAS_AND_PAYLOAD` inbound deposit-with-autoswap and every gas-fee-refund-with-swap on outbound finalization — protocol/user-controlled funds are permanently under-delivered in PC relative to fair market value, with the shortfall captured by the attacker via the round-trip arbitrage. This is reachable purely by an unprivileged external actor via a normal DEX trade plus ordinary bridging/outbound flows, with no compromise of validators, TSS, or admin keys required — it directly matches the "corruption of PRC20 or native asset accounting" and "unauthorized... refund accounting" allowed impacts.

### Likelihood Explanation
Likelihood is Medium: it depends on pool liquidity depth for the specific PRC20/WPC pair and on the attacker being able to land their manipulating trade close enough (same or adjacent block/transaction ordering) to the bridging event execution. Thinly-liquid or newly-listed token pools (the exact scenario Uniswap V3 LP sandwich attacks target) are the most exposed; UniversalCore's own pools are protocol-deployed and may start with limited depth, increasing practical exploitability at launch or for lower-liquidity assets.

### Recommendation
Do not derive the slippage floor from a same-transaction spot quote on the same pool the swap executes against. Use a time-weighted average price (TWAP) observation window from the Uniswap V3 pool (or an independent price oracle already available to `x/uexecutor`, such as the gas-price/chain-meta oracle) to compute `minPCOut`, and set a real (non-zero, bounded) `deadline` on `depositPRC20WithAutoSwap`/`refundUnusedGas` rather than `big.NewInt(0)`. Additionally consider bounding the maximum acceptable deviation between the TWAP and the current spot price, rejecting/deferring the swap if that deviation exceeds a safe threshold, so a single manipulating trade cannot control both the reference and the executed price in the same window.

### Proof of Concept
1. Deploy/observe the low-liquidity Uniswap V3 pool used by `UniversalCore` for a target PRC20 ↔ WPC pair (address discoverable via `defaultFeeTier`/pool config).
2. Submit a large swap against that pool to depress the PRC20 price relative to WPC.
3. Immediately submit (or have already pending) a source-chain gas-abstraction deposit of that PRC20's underlying asset, causing UVs to vote a `GAS`/`GAS_AND_PAYLOAD` inbound.
4. Observe `ExecuteInboundGas` → `GetSwapQuote` → `CallPRC20DepositAutoSwap` execute at the manipulated price, `minPCOut` passing trivially since it is 95% of the manipulated quote itself.
5. Reverse the initial manipulating trade to recover the attacker's capital plus the arbitrage captured from the under-priced protocol swap, confirmed by comparing PC credited to the recipient UEA against the pre-manipulation fair-value quote.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}
