This is a valid, exploitable vulnerability.

### Title
Unauthenticated exposure of LOOP plugin pprof profiling/debug endpoints allowing memory/secret disclosure - ([File: core/web/router.go])

### Summary
`loopRoutes` in `core/web/router.go` registers `/plugins/:name/debug/pprof/*profile` and `/plugins/:name/debug/pprof/symbol` directly on the base `api` router group, which only carries rate-limiting and session middleware — no authentication is applied. This lets any unauthenticated network client trigger `pluginPPROFHandler`/`pluginPPROFPOSTSymbolHandler`, which proxy the request straight into the LOOP plugin's internal `net/http/pprof` endpoints and return the raw profiling/heap data to the caller.

### Finding Description
`NewRouter` builds the `api` group with only `rateLimiter` and `sessions.Sessions` middleware, then calls `loopRoutes(app, api)` [1](#0-0) . `loopRoutes` registers the plugin pprof routes on that same unauthenticated group with no `auth.Authenticate` wrapper: [2](#0-1) . Compare this to the analogous node-level pprof routes (`metricRoutes`), which are explicitly registered only inside the authenticated `authv2` group with the comment "Debug routes accessible via authentication" [3](#0-2) , confirming that pprof exposure is intentionally meant to require auth elsewhere in this same codebase — but the LOOP-plugin variant was missed.

`pluginPPROFHandler` looks up the plugin by the `:name` URL parameter, builds an internal URL to the plugin's own pprof server (`http://<loopHostName>:<PrometheusPort>/debug/pprof/<profile>`), and forwards the response body verbatim back to the caller with `gc.Data(http.StatusOK, ...)`: [4](#0-3) . `pluginPPROFPOSTSymbolHandler` does the same for `POST /debug/pprof/symbol`, also forwarding the request body: [5](#0-4) . Neither handler nor the shared `doRequest` helper performs any authentication or authorization check: [6](#0-5) .

Since Go's `pprof.Handler("heap")`/`Profile`/`Trace` dump raw process memory, goroutine stacks, and CPU/heap samples, an unauthenticated attacker who can reach the node's HTTP port can request e.g. `GET /plugins/<name>/debug/pprof/heap` and receive the LOOP plugin process's heap dump, which may contain secrets resident in memory (e.g., transmitter/OCR keys, decrypted config) depending on what the plugin process holds.

### Impact Explanation
This is an unauthenticated information-disclosure vulnerability: any external, unprivileged network client that can reach the Chainlink node's web port can pull heap/goroutine/profile/trace data out of any registered LOOP plugin process. Such dumps commonly leak in-memory secret material (private keys, tokens, internal addresses) and internal state, which is a direct secret/memory disclosure impact and matches Chainlink's bounty category for unauthorized secret disclosure from node processes.

### Likelihood Explanation
No preconditions are required beyond network reachability to the node's configured HTTP listener and at least one LOOP plugin being registered (common in OCR2/median/relayer LOOP deployments). The request is a simple, repeatable unauthenticated `GET`/`POST` — no credentials, tokens, or session cookies are needed since the route sits on the unauthenticated `api` group rather than `authv2`.

### Recommendation
Move `loopRoutes` registration (or at least the pprof/debug sub-routes) behind the same authentication middleware used for other debug endpoints, e.g. wrap them with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)` similar to how `metricRoutes(authv2)` is protected, or register `/plugins/:name/debug/pprof/*` only within `authv2` instead of the base `api` group.

### Proof of Concept
Integration test plan:
1. Start a Chainlink node with `NewRouter` and register at least one LOOP plugin in the `LoopRegistry` (or mock `app.GetLoopRegistry()` to return a fake plugin entry pointing at a local test pprof server).
2. Issue `GET /plugins/<name>/debug/pprof/heap` with no `Authorization` header and no session cookie.
3. Assert the current (vulnerable) behavior: HTTP 200 with the plugin's raw heap profile bytes returned in the response body — demonstrating the endpoint is reachable without authentication.
4. After applying the fix (wrapping the route with `auth.Authenticate`), re-run the same request and assert HTTP 401/403 is returned instead of profiling data.
5. Repeat for `POST /plugins/<name>/debug/pprof/symbol` to confirm the same fix covers both handlers.

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method string, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}
