Based on my investigation, I found a concrete native analog to the vault front-running/sandwich bug class in Push Chain's GAS-abstraction auto-swap flow.

### Title
Sandwichable auto-swap deposit lets an attacker extract value from GAS/GAS_AND_PAYLOAD inbound deposits via same-block AMM price manipulation - (File: x/uexecutor/keeper/execute_inbound_gas.go)

### Summary
When a user bridges native gas tokens via a `GAS` or `GAS_AND_PAYLOAD` inbound, the `uexecutor` module auto-swaps the deposited PRC20 for PC through a Uniswap V3 pool. The module computes its own slippage bound (`minPCOut`) from a spot quote taken from the *same, currently manipulable* pool state that the swap itself will execute against, in the same keeper call. This mirrors the report's core flaw: a "protection" value derived from state the attacker controls just before the victim operation executes provides no real protection.

### Finding Description
In `ExecuteInboundGas` [1](#0-0) , and identically in `gasAndPayloadDepositAutoSwap` [2](#0-1) , the keeper:
1. Calls `GetSwapQuote`, which reads a live spot price from the Uniswap V3 `QuoterV2.quoteExactInputSingle` [3](#0-2) .
2. Derives `minPCOut = quote * 95 / 100` (a flat 5% slippage buffer) [4](#0-3) .
3. Immediately calls `CallPRC20DepositAutoSwap` → `depositPRC20WithAutoSwap` on the same pool, using that `minPCOut` as the only protection [5](#0-4) .

Because the quote and the swap both read/act on the same on-chain AMM state, and this state is a normal, unprivileged-user-reachable Uniswap V3 pool (as referenced by `uniswapV3Quoter`/`WPC` in `UniversalCore` [6](#0-5) ), any external actor can push the pool price down (e.g., with a large PRC20→PC swap) shortly before the validator-driven `MsgVoteInbound` finalization transaction that triggers this auto-swap lands. The 5% band is computed from the *already-depressed* price, so it does not defend against pre-existing manipulation — it only tolerates ordinary quote-to-execution drift within a single atomic call. The victim's deposit is swapped at the manipulated rate, and the attacker reverses their trade afterward, capturing the difference. There is no TWAP oracle, no bound tied to a fair/reference price, and no check that the pool price is consistent with recent history — confirmed by the absence of any such oracle in this swap path (the chain does have a chain-meta gas-price oracle for source chains [7](#0-6) , but it is unrelated to and not used to bound the PC-side AMM swap).

### Impact Explanation
This directly corrupts native/PRC20 asset accounting for gas-abstraction deposits: the recipient UEA receives less PC than fair value for the deposited gas-token amount, while the attacker extracts the skimmed value from the pool — an unauthorized transfer of protocol/user-controlled value reachable by an ordinary unprivileged actor, matching the "corruption of ... gas fee accounting ... or canonical UniversalTx state" and "stealing ... of user or protocol-controlled funds" impact categories.

### Likelihood Explanation
Medium: it requires the attacker to control enough capital to move the specific PRC20/WPC pool price meaningfully and to time a swap around the GAS/GAS_AND_PAYLOAD inbound's ballot-finalization block. Since inbound processing runs deterministically once quorum is reached (not hidden), and pool liquidity for a given PRC20 gas token may be shallow, this is realistically exploitable, especially against low-liquidity pools.

### Recommendation
Do not derive `minPCOut` solely from a same-transaction spot quote of the pool being traded against. Use a TWAP-based reference price (or an external price oracle) to bound acceptable execution price, and/or cap deposit-triggered swap size relative to pool depth, and/or require the swap to be validated against a price attested independently of the immediately-preceding EVM state (analogous to using a committed price feed rather than `balanceOf`-derived state in the vault example).

### Proof of Concept
1. Attacker identifies a PRC20 gas-token/WPC Uniswap V3 pool with shallow liquidity used by `defaultFeeTier`/`GetSwapQuote`.
2. Attacker submits a large PRC20→WPC swap to depress the pool price just before (or in the same block window as) a pending `GAS`/`GAS_AND_PAYLOAD` inbound ballot reaches quorum.
3. When quorum finalizes, `ExecuteInboundGas`/`gasAndPayloadDepositAutoSwap` calls `GetSwapQuote` against the now-depressed pool and computes `minPCOut` from that depressed quote.
4. `CallPRC20DepositAutoSwap` executes at the depressed price; the victim's UEA receives less PC than the pre-manipulation fair value.
5. Attacker reverses the initial swap, extracting the value difference from the pool at the victim's expense.

func (k Keeper) gasAndPayloadDepositAutoSwap(

		return nil, err

		return nil, err

	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)

// GetUniversalCoreQuoterAddress reads the uniswapV3Quoter address stored in UniversalCore.
func (k Keeper) GetUniversalCoreQuoterAddress(ctx sdk.Context) (common.Address, error) {
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return common.Address{}, errors.Wrap(err, "failed to parse UniversalCore ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	receipt, err := k.evmKeeper.CallEVM(ctx, abi, ueModuleAccAddress, handlerAddr, false, nil, "uniswapV3Quoter")
	if err != nil {
		return common.Address{}, errors.Wrap(err, "failed to call uniswapV3Quoter")
	}

	results, err := abi.Methods["uniswapV3Quoter"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return common.Address{}, errors.Wrap(err, "failed to unpack uniswapV3Quoter result")
	}

	return results[0].(common.Address), nil
}

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)
}
