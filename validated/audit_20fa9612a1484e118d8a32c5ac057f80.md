## Finding

This is a real, but distinct, variant of the reported sandwich-attack bug class, already partially mitigated but with a gap left in Push Chain's own analog.

### Title
Spot-price AMM quote with no TWAP/maximum-price bound allows gas-swap price manipulation in `depositPRC20WithAutoSwap` / `refundUnusedGas` flows - (File: `x/uexecutor/keeper/evm.go`, `x/uexecutor/keeper/execute_inbound_gas.go`, `x/uexecutor/keeper/execute_inbound_gas_and_payload.go`, `x/uexecutor/keeper/outbound.go`)

### Summary
Push Chain already remediated the literal "zero slippage / unlimited deadline" bug class in a prior upgrade — `GetSwapQuote` now feeds a 5%-slippage `minPCOut` into `CallPRC20DepositAutoSwap`, as recorded in the upgrade handler comment: "GAS and GAS_AND_PAYLOAD inbound routes now call the Uniswap V3 QuoterV2 contract to obtain an on-chain swap quote and pass minPCOut (quote × 95%) ... replacing the previous 0-slippage call." [1](#0-0) 

However, the quote that seeds `minPCOut` is a raw spot price (`sqrtPriceLimitX96: big.NewInt(0)`, no TWAP) fetched from `QuoterV2.quoteExactInputSingle` immediately before the module executes the real swap: [2](#0-1) 

### Finding Description
`minPCOut` only guards the *lower* bound of the auto-swap (protects the recipient from receiving less than 95% of the current spot quote), it does not guard against the spot price itself being artificially inflated. This pattern is reused across three separate module-originated swap paths:
- `ExecuteInboundGas` (GAS inbound route): fetches quote then swaps in the same keeper call. [3](#0-2) 
- `gasAndPayloadDepositAutoSwap` (GAS_AND_PAYLOAD route): identical pattern. [4](#0-3) 
- `applyGasRefund` (outbound gas refund route): identical pattern, swapping `gasToken → PC`. [5](#0-4) 

Because the Uniswap V3 pools used for these swaps (WPC ↔ gas-token pools, e.g. pETH/WPC) are ordinary public EVM pools reachable by any address, an unprivileged attacker can, within the same Cosmos block that finalizes a pending inbound/outbound ballot (finalization timing is predictable from public vote-count observability), submit a large trade against the relevant pool immediately before the validator's `MsgVoteInbound`/`MsgVoteOutbound` transaction executes. This inflates the spot price that `GetSwapQuote` reads, causing the module's own `depositPRC20WithAutoSwap`/`refundUnusedGas` call to execute against the manipulated pool at an inflated rate. The attacker then reverses the manipulating trade in a follow-up transaction, extracting the price-impact spread from the pool's liquidity at the expense of the pool's other liquidity (which for these protocol gas-swap pools may be protocol-owned/protocol-seeded per the local setup scripts). This requires no validator, relayer, or TSS collusion — only ordinary EVM transactions from an unprivileged address plus knowledge of when a pending inbound/outbound is about to finalize.

Additionally, the module always passes a fixed `deadline = big.NewInt(0)` for `depositPRC20WithAutoSwap`, deferring to "the contract's default" — the actual default-deadline behavior lives in the Solidity `UniversalCore` contract, which is not present in this repository (it is deployed/managed from `push-chain-core-contracts`), so its safety cannot be verified from this codebase alone.

### Impact Explanation
If the AMM liquidity for gas-swap pools is protocol-funded or otherwise protocol-controlled (as implied by the local core-contract setup scripts that seed WPC/token pools for the auto-swap feature), this allows an unprivileged attacker to repeatedly extract value from that liquidity via price manipulation around predictable module-triggered swaps, i.e., unauthorized draining of protocol-controlled funds through the universal execution gas-swap path.

### Likelihood Explanation
Medium. It requires the attacker to (a) hold or borrow capital to move the specific pool's price, (b) time a trade around ballot finalization — feasible since inbound/outbound votes and their approaching quorum are publicly observable on-chain before finalization, and (c) have sufficient AMM depth asymmetry to make the round-trip profitable net of the 5% slippage buffer and swap fees. It is not a guaranteed win on every gas swap but is a systemic weakness applicable to every GAS/GAS_AND_PAYLOAD inbound and every outbound gas refund.

### Recommendation
Use a time-weighted average price (TWAP) or an independently-sourced reference price (e.g., cross-checked against `ChainMetaOracle`/validator-reported prices) instead of, or in addition to, the single-block spot quote from `QuoterV2.quoteExactInputSingle` when computing `minPCOut`. Additionally, bound the maximum acceptable execution price (not just a minimum output), and consider enforcing a real (non-zero, bounded) deadline value from the Go keeper rather than delegating entirely to an unverified contract-side default.

### Proof of Concept
1. Attacker observes an in-flight `Inbound`/`Outbound` for a GAS or GAS_AND_PAYLOAD route nearing ballot quorum via public validator votes.
2. In the same target block (or immediately prior), attacker submits a large EVM swap against the WPC/gas-token Uniswap V3 pool used by `GetSwapQuote`, pushing the spot price in the direction that benefits them once the module's forced swap executes.
3. The validator's vote transaction finalizes the ballot; `ExecuteInboundGas`/`gasAndPayloadDepositAutoSwap`/`applyGasRefund` calls `GetSwapQuote` against the now-manipulated pool state and computes `minPCOut = quote * 95/100`, then executes `CallPRC20DepositAutoSwap`/`CallUniversalCoreRefundUnusedGas` at the manipulated price. [6](#0-5) 
4. Attacker reverses their manipulating trade in a subsequent transaction, capturing the price-impact spread extracted from the pool's liquidity.

```go
// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
```

```go
// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}
```
