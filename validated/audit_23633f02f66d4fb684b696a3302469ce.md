### Title
Starknet OS `replace_class` Syscall Skips Declared-Class Validation Enforced by the Sequencer's Blockifier — ([File: crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo])

### Summary
The Starknet OS Cairo implementation of the `replace_class` syscall (`execute_replace_class`) updates a contract's class hash without first verifying that the target class hash corresponds to a declared, Cairo1 class. This validation is explicitly marked as a `TODO` in the OS code, yet the sequencer's Rust `blockifier` implementation of the same syscall (`syscall_base.rs::replace_class`) already performs this exact check and rejects the call otherwise. This creates a divergence between what the sequencer executes/commits and what the Starknet OS (used to re-execute and prove blocks) will accept, analogous to the reported Mattermost bug class of "failing to restrict an action that should be blocked given the object's state."

### Finding Description
The blockifier (used by the sequencer to build blocks) enforces that `replace_class` targets a declared, Cairo1 class: [1](#0-0) 

By contrast, the Starknet OS Cairo re-execution code path for the same syscall performs no such check — it directly reads the requested `class_hash` from the syscall request and writes it into the contract's state entry, with an explicit acknowledgement that the check is missing: [2](#0-1) 

The deprecated (Cairo0) syscall handler in the OS has the identical gap — no verification that the class is declared before updating the contract's class hash: [3](#0-2) 

This is a genuine reachable bug: any contract that invokes `replace_class` (a standard Starknet syscall available to any Cairo1 contract) with an undeclared or Cairo0 class hash will have its call rejected during blockifier execution (`ForbiddenClassReplacement` / "is not declared" errors, confirmed by tests), while the Starknet OS trace for the identical call sequence has no code path enforcing the same rule. [4](#0-3) 

Since the Starknet OS is responsible for re-executing and proving the exact same block that the sequencer built (Starknet OS re-execution / state commitment), any place where the OS's constraints are looser than the sequencer's actual execution rules threatens the guarantee that the OS's proven state transition matches the sequencer-committed one.

### Impact Explanation
If the OS accepts an undeclared or Cairo0 class hash where the sequencer's blockifier would have reverted the call, the OS-computed state diff for that transaction (and hence the OS's computed state root/commitment) can differ from what the sequencer actually committed on-chain. This falls squarely into "wrong committed root" / honest-node divergence: a discrepancy between blockifier-driven block building and Starknet-OS-driven proof generation for the same block content. It could also allow a contract's class hash to be set to an undeclared value, corrupting subsequent calls into that contract within the OS's world view (since no compiled class exists for that hash), while diverging from the "real" sequencer state where the operation never took effect (the transaction reverted instead).

### Likelihood Explanation
Likelihood is high in terms of reachability: `replace_class` is a standard, unprivileged syscall any deployed Cairo1 contract can invoke by calling `replace_class_syscall(class_hash)` with an arbitrary attacker-chosen felt as the class hash — no special permissions needed, as shown in the test-contract usage. [5](#0-4) 

### Recommendation
Add the same declared-class (and Cairo1-type) validation to the OS's `execute_replace_class` implementations (both the current syscall path in `syscall_impls.cairo` and the deprecated path in `deprecated_execute_syscalls.cairo`) that the blockifier already performs in `syscall_base.rs::replace_class`, i.e., look up the compiled class facts bundle for the requested `class_hash` and reject/revert if it is not present or not Cairo1, consistent with the blockifier's `ForbiddenClassReplacement`/"is not declared" checks. Track and resolve the existing `TODO(Yoni, 1/1/2026)` comment before proofs relying on this code path are trusted for consensus-relevant state commitments.

### Proof of Concept
1. Declare/deploy a Cairo1 contract that exposes `replace_class_syscall` (e.g., the existing `test_contract.cairo`'s `test_forbidden_syscall_in_virtual_mode`/`test_replace_class` entry points).
2. Submit an invoke transaction calling `replace_class_syscall(class_hash)` with `class_hash` set to an undeclared felt (or a declared Cairo0 class hash).
3. Observe that the sequencer's blockifier execution rejects the call ("is not declared" / `ForbiddenClassReplacement`), as demonstrated in `crates/blockifier/src/execution/syscalls/syscall_tests/replace_class.rs` (`undeclared_class_hash`, `cairo0_class_hash`).
4. Feed the identical transaction trace/inputs to the Starknet OS re-execution path (`execute_replace_class` in `syscall_impls.cairo`); because it lacks the same check, it will accept the class hash unconditionally and update `contract_state_changes`, producing a different state diff/commitment than the blockifier's actual (reverted) result.

    pub fn replace_class(&mut self, class_hash: ClassHash) -> SyscallResult<()> {
        // Ensure the class is declared (by reading it), and of type V1.
        let compiled_class = self.state.get_compiled_class(class_hash)?;

        if !is_cairo1(&compiled_class) {
            return Err(SyscallExecutionError::ForbiddenClassReplacement { class_hash });
        }
        self.state.set_class_hash_at(self.call.storage_address, class_hash)?;
        Ok(())
    }

// Replaces the class.
func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}

fn undeclared_class_hash(runnable_version: RunnableCairo1) {
    let test_contract = FeatureContract::TestContract(CairoVersion::Cairo1(runnable_version));

        ..trivial_external_entry_point_new(test_contract)
    };
    let error = entry_point_call.execute_directly(&mut state).unwrap_err();

    assert!(error.to_string().contains("is not declared"));
}
