Found a clear discrepancy between the `blockifier`'s execution-time enforcement and the Starknet OS's (Cairo) re-execution logic for the `replace_class` syscall.

**Blockifier** (used by the actual sequencer to execute and admit transactions) enforces that the target class must be declared: [1](#0-0) 

But the **Starknet OS** Cairo implementation of the same syscall — which re-executes the block to produce the STARK proof of the state transition — has this check explicitly missing, flagged by its own TODO: [2](#0-1) 

### Title
Starknet OS `execute_replace_class` omits the "class must be declared" check enforced by blockifier, allowing an unsound state transition to be proven - (File: crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo)

### Summary
The Cairo `replace_class` syscall handler in the Starknet OS (`execute_replace_class`) updates a contract's `class_hash` in `contract_state_changes` using an attacker-supplied `class_hash` from the syscall request, without verifying that a class was ever declared under that hash. This is explicitly acknowledged by the inline `// TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.` comment. In contrast, the native Rust blockifier execution path (`replace_class` in `crates/blockifier/src/execution/deprecated_syscalls/hint_processor.rs`) performs `syscall_handler.state.get_compiled_class(request.class_hash)?` before writing the new class hash, which fails if the class is undeclared.

### Finding Description
`execute_replace_class` in `syscall_impls.cairo` reads the request's `class_hash`, reads the contract's current `StateEntry` via the `GetContractAddressStateEntry` hint, and unconditionally writes a new `StateEntry` with the caller-supplied `class_hash`, updating `contract_state_changes` for the calling contract's own address: [3](#0-2) 

Meanwhile, the equivalent Rust logic used by blockifier during actual transaction execution (i.e., what determines whether a block/transaction is admissible in the first place) requires the class to already be declared: [1](#0-0) 

This is also confirmed by the blockifier's own test, which asserts that replacing to an undeclared class hash fails with "is not declared": [4](#0-3) 

The Starknet OS is not merely a passive execution engine — it is the Cairo program whose trace is proven and whose outputs (including the final state commitment) are trusted by L1/verifiers as the ground truth for a valid state transition. Because the OS's own constraint set for `replace_class` lacks the "declared class" check that blockifier enforces, a party constructing the OS execution trace (rather than a legitimately blockifier-validated block) can produce a "provably valid" trace that sets a contract's class hash to an arbitrary, undeclared `class_hash` value. The OS accepts this as a legitimate part of the state diff and will happily compute and commit a state root reflecting the bogus class assignment.

### Impact Explanation
This creates a soundness gap between the two components that are supposed to agree on transaction validity: blockifier (execution/admission) and the Starknet OS (proving/re-execution, and by extension the OS-computed state commitment that becomes the network's committed root). An honest full node running blockifier would never allow `replace_class` to succeed for an undeclared class hash, yet the OS constraint system that underlies the STARK proof of block validity does not check this invariant. This is exactly the kind of "wrong committed root" / "honest-node divergence" class of bug called out in scope: two components in the same sequencer stack disagree about what constitutes a valid state transition for the identical syscall, with the weaker (OS) constraint governing what actually gets proven and committed.

### Likelihood Explanation
The bug is triggered by nothing more than a contract calling the `replace_class` syscall (a standard, permissionless Starknet syscall reachable from any contract call) with a `class_hash` value corresponding to a class that was never declared. The missing check is explicit and acknowledged in the code (`TODO(Yoni, 1/1/2026)`), meaning it is a genuine, currently-unaddressed gap rather than a hypothetical one.

### Recommendation
Add the missing "class must be declared" check in `execute_replace_class` in `syscall_impls.cairo` (and its deprecated counterpart `execute_replace_class` in `deprecated_execute_syscalls.cairo`, which has the same unconditional update pattern) so that the OS's constraints for this syscall match blockifier's: verify `class_hash` exists in `contract_class_changes` / the declared-class table before permitting the `StateEntry` update, mirroring the check already present in `crates/blockifier/src/execution/deprecated_syscalls/hint_processor.rs`.

### Proof of Concept
1. A contract's `__execute__` (or any entry point) invokes `replace_class_syscall(class_hash)` with a `class_hash` that has never been the subject of a successful `declare` transaction.
2. In the real sequencer path (blockifier), this syscall fails with `"... is not declared"`, so the transaction/block containing it would never be admitted by an honest blockifier-based node — see `crates/blockifier/src/execution/deprecated_syscalls/deprecated_syscalls_test.rs:375-391`.
3. However, if an execution trace is fed directly into the Starknet OS (the actual Cairo program whose execution is proven, per `crates/apollo_starknet_os_program/.../syscall_impls.cairo`), `execute_replace_class` performs no equivalent existence check and will happily update `contract_state_changes` to point the calling contract at the undeclared `class_hash`, allowing a state diff/commitment to be produced (and proven as valid) that blockifier itself would never have produced or accepted. // Replaces the class.
func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
