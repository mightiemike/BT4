### Title
`check_first_nakamoto_tenure_change` accepts any epoch2 header as the boundary parent without verifying it is the canonical epoch2 tip - (File: stackslib/src/chainstate/nakamoto/tenure.rs)

### Summary
`NakamotoChainState::check_first_nakamoto_tenure_change` validates the first Nakamoto tenure-change purely through self-consistency of the attacker-supplied payload against whatever row `get_block_header` returns for `previous_tenure_end`, with no check that this epoch2 header is the canonical (highest-work) epoch2 tip. [1](#0-0)  A stale/forked epoch2 header that still exists in the headers DB can satisfy every check in this function.

### Finding Description
The equality claimed to hold is: `previous_tenure_end == canonical_epoch2_tip_block_id`. What the code actually checks is only `tenure_payload.prev_tenure_consensus_hash == parent_header.consensus_hash`, where `parent_header` is whatever row `Self::get_block_header(headers_conn, &tenure_payload.previous_tenure_end)` returns by primary-key lookup, and `previous_tenure_blocks == 1`. [2](#0-1)  None of these three checks reference sortition-level canonicity or the dedicated canonical-epoch2-tip selection routine `get_highest_canonical_block_header_from_candidates` (which exists elsewhere specifically to deterministically pick the highest-work epoch2 tip at the boundary, as exercised by `test_get_highest_canonical_block_header_from_candidates_epoch2_deterministic`). [3](#0-2) 

In the caller `check_nakamoto_tenure`, the checks that *are* canonicity-aware (`check_valid_consensus_hash`) are applied only to `tenure_payload.tenure_consensus_hash` and `tenure_payload.burn_view_consensus_hash` — i.e., the new tenure's own sortition — not to the epoch2 parent referenced by `previous_tenure_end`/`prev_tenure_consensus_hash` when the caller falls through to `check_first_nakamoto_tenure_change` because `get_ongoing_tenure` returned `None` (first tenure case). [4](#0-3)  Consequently, any epoch2 header present in the `staging`/headers DB (including a losing/orphaned epoch2 fork tip that a node retained from a natural pre-boundary Stacks fork) can be referenced as `previous_tenure_end`, and the check will pass as long as the payload's `prev_tenure_consensus_hash` matches that header's own consensus hash — a condition trivially satisfiable by the block producer, since they choose both fields.

This means two different miners (or the same miner at different times) could each construct a self-consistent "first Nakamoto tenure" block rooted at two different epoch2 headers — one at the true canonical tip, one at a stale epoch2 fork tip — and both would independently satisfy `check_first_nakamoto_tenure_change`, producing two structurally valid but historically divergent Nakamoto genesis tenures.

### Impact Explanation
If such a divergent first tenure gains sufficient support to become the locally-recorded Nakamoto tip on some nodes (via the height/latter-signed tie-break logic in `set_stacks_block_accepted_at_tip`), the resulting Nakamoto chain carries forward account balances, PoX commitments, and unlock heights from the wrong epoch2 ancestor rather than the true canonical epoch2 chain state — this is a Critical chain-split/deep-fork condition at the epoch2/epoch3 boundary, matching the "chain split or deep fork" and "invalid block accepted network-wide" categories.

### Likelihood Explanation
Exploitation requires the attacker to already control (or have previously mined into) a non-canonical epoch2 header that is still retrievable via `get_block_header`, and to win a real sortition to produce the tenure-change block containing it — consistent with an unprivileged, single-miner-slot attacker. Whether this is prevented in practice depends on validation performed outside this function (e.g., by stacks-signers or coordinator boot logic) that I could not fully trace within the available tool budget; I found no such canonicity re-check inside `check_first_nakamoto_tenure_change` or its direct caller `check_nakamoto_tenure` for the epoch2-parent case.

### Recommendation
In `check_first_nakamoto_tenure_change`, after resolving `parent_header`, verify that `parent_header`'s consensus hash/block corresponds to the canonical epoch2 tip as computed by `get_highest_canonical_block_header_from_candidates` (or equivalent canonical-tip lookup keyed off the sortition DB), rejecting the tenure-change if it does not match, rather than accepting any epoch2 header found by raw lookup.

### Proof of Concept
Construct a test harness that: (1) mines two competing epoch2 forks near the 2.x/3.0 boundary such that both headers remain in the headers DB but only one is canonical per `get_highest_canonical_block_header_from_candidates`; (2) craft a `TenureChangePayload` with `previous_tenure_end`/`prev_tenure_consensus_hash` pointing at the losing epoch2 header and `previous_tenure_blocks = 1`; (3) call `NakamotoChainState::check_first_nakamoto_tenure_change` directly and assert it currently returns `Ok(Some(..))` (bug reproduced) instead of `Ok(None)`; (4) after the fix, assert it returns `Ok(None)` unless `previous_tenure_end` equals the canonical epoch2 tip identified via the sortition DB.

    pub(crate) fn check_first_nakamoto_tenure_change(
        headers_conn: &Connection,
        tenure_payload: &TenureChangePayload,
    ) -> Result<Option<NakamotoTenureEvent>, ChainstateError> {
        // must be a tenure-change
        if !tenure_payload.cause.expects_sortition() {
            warn!("Invalid tenure-change: not a sortition-induced tenure-change";
                  "consensus_hash" => %tenure_payload.tenure_consensus_hash,
                  "previous_tenure_end" => %tenure_payload.previous_tenure_end
            );
            return Ok(None);
        }

        let Some(parent_header) =
            Self::get_block_header(headers_conn, &tenure_payload.previous_tenure_end)?
        else {
            warn!("Invalid tenure-change from epoch2: no parent epoch2 header";
                  "consensus_hash" => %tenure_payload.tenure_consensus_hash,
                  "previous_tenure_end" => %tenure_payload.previous_tenure_end
            );
            return Ok(None);
        };
        if tenure_payload.previous_tenure_blocks != 1 {
            warn!("Invalid tenure-change from epoch2: expected 1 previous tenure block";
                  "consensus_hash" => %tenure_payload.tenure_consensus_hash,
                  "previous_tenure_blocks" => %tenure_payload.previous_tenure_blocks
            );
            return Ok(None);
        }
        if tenure_payload.prev_tenure_consensus_hash != parent_header.consensus_hash {
            warn!("Invalid tenure-change from epoch2: parent tenure consensus hash mismatch";
                  "prev_tenure_consensus_hash" => %tenure_payload.prev_tenure_consensus_hash,
                  "parent_header.consensus_hash" => %parent_header.consensus_hash
            );
            return Ok(None);
        }
        let Some(epoch2_header_info) = parent_header.anchored_header.as_stacks_epoch2() else {
            warn!("Invalid tenure-change: parent header is not epoch2";
                  "consensus_hash" => %tenure_payload.tenure_consensus_hash,
                  "previous_tenure_end" => %tenure_payload.previous_tenure_end
            );
            return Ok(None);
        };

#[test]
fn test_get_highest_canonical_block_header_from_candidates_epoch2_deterministic() {
    let (mut test_signers, test_stackers) = TestStacker::common_signing_set();
    let mut peer = boot_nakamoto(
        function_name!(),
        vec![],
        &mut test_signers,
        &test_stackers,
        None,
    );

    let sort_db = peer.chain.sortdb.as_mut().unwrap();
    let tip_snapshot = SortitionDB::get_canonical_burn_chain_tip(sort_db.conn()).unwrap();
    let canonical_ch = tip_snapshot.consensus_hash.clone();

    let epoch2_proof_bytes = hex_bytes("9275df67a68c8745c0ff97b48201ee6db447f7c93b23ae24cdc2400f52fdb08a1a6ac7ec71bf9c9c76e96ee4675ebff60625af28718501047bfd87b810c2d2139b73c23bd69de66360953a642c2a330a").unwrap();
    let epoch2_proof = VRFProof::from_bytes(&epoch2_proof_bytes[..]).unwrap();

    let mut candidates = Vec::new();
    // Make the middle candidate the canonical one.
    let canonical_index = 5;
    for i in 0..10 {
        let work = 110u64.saturating_sub(i as u64);
        let header = StacksBlockHeader {
            version: 0,
            total_work: StacksWorkScore { burn: 1, work },
            proof: epoch2_proof.clone(),
            parent_block: BlockHeaderHash([(0x11 + i as u8); 32]),
            parent_microblock: BlockHeaderHash([0x00; 32]),
            parent_microblock_sequence: 0,
            tx_merkle_root: Sha512Trunc256Sum([(0x22 + i as u8); 32]),
            state_index_root: TrieHash([(0x33 + i as u8); 32]),
            microblock_pubkey_hash: Hash160([(0x44 + i as u8); 20]),
        };

        // Make sure the candidate with the correct consensus hash is selected based on the first in the list (i.e.
        // the one with the highest stacks block height as well as correct consensus hash)
        let consensus_hash = if i >= canonical_index {
            canonical_ch.clone()
        } else {
            ConsensusHash([(0x50 + i as u8); 20])
        };

        let candidate = StacksHeaderInfo {
            anchored_header: StacksBlockHeaderTypes::Epoch2(header),
            microblock_tail: None,
            // Make the stacks block height decrease with each candidate, since get_highest_canonical_block_header_from_candidates
            // expects a height-ordered list of candidates
            stacks_block_height: work,
            index_root: TrieHash([(0x60 + i as u8); 32]),
            consensus_hash,
            burn_header_hash: tip_snapshot.burn_header_hash.clone(),
            burn_header_height: tip_snapshot.block_height as u32,
            burn_header_timestamp: tip_snapshot.burn_header_timestamp,
            anchored_block_size: 120 + i as u64,
            burn_view: None,
            total_tenure_size: 0,
        };
        candidates.push(candidate);
    }
    let canonical_candidate = candidates[canonical_index].clone();
    let selected =
        NakamotoChainState::get_highest_canonical_block_header_from_candidates(sort_db, candidates)
            .unwrap()
            .expect("Expected a canonical epoch2 header");

    assert_eq!(
        selected.anchored_header.block_hash(),
        canonical_candidate.anchored_header.block_hash()
    );
    assert_eq!(
        selected.stacks_block_height,
        canonical_candidate.stacks_block_height
    );
}
