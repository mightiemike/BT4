### Title
Missing declared-class validation in `execute_replace_class` (Starknet OS) causes blockifier/OS execution divergence - ([File: crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo])

### Summary
The Starknet OS Cairo implementation of the `replace_class` syscall unconditionally rewrites a contract's class hash without ever checking that the target class hash is a class that has actually been declared. The blockifier (Rust) implementation of the same syscall does perform this check. Because the STARK-proved Starknet OS execution and the blockifier's native execution must always agree on the resulting state transition for a given transaction, this asymmetry is a soundness/consistency bug: a transaction that the blockifier correctly reverts (attempt to `replace_class` to an undeclared class hash) can be accepted and committed by the OS re-execution path.

### Finding Description
`execute_replace_class` in `syscall_impls.cairo` performs the class-hash rewrite directly from hint-supplied data, with an explicit TODO acknowledging the missing check: [1](#0-0) 

The same absence of validation exists in the deprecated (Cairo 0) syscall path: [2](#0-1) 

Neither Cairo implementation ever calls anything analogous to "is class declared" before performing `dict_update` on `contract_state_changes` — a repo-wide search for such checks in `.cairo` files returned no results, confirming this is not validated anywhere else in the OS pipeline.

By contrast, the blockifier's native (Rust) execution of the identical syscall explicitly requires the target class to already be declared, by attempting to read it and propagating any resulting `UndeclaredClassHash` error: [3](#0-2) 

This behavior is directly covered by tests confirming the blockifier rejects an undeclared class hash with an "is not declared" error: [4](#0-3) [5](#0-4) 

This is analogous in bug class to the reported PostgreSQL CVE-2022-2625: an operation that mutates/replaces a referenced object (a class pointer for a contract, analogous to a schema object) is performed without re-validating a required precondition on the referenced object (that it exists/was properly created), allowing the operation to silently succeed where the trusted validating engine (blockifier) would have rejected it.

### Impact Explanation
The Starknet OS is the component whose execution is proven via STARK and whose resulting state commitment (state root / block hash) is what the network ultimately trusts as the canonical state transition function output, re-executed independently from the sequencer's blockifier. If the OS accepts and commits a `replace_class` to an undeclared class hash that the blockifier would have reverted, the OS-derived state root/output diverges from the blockifier-committed state, which is a state-root/block-hash mismatch and honest-node divergence between the two execution engines that are required to be equivalent. This can also let a malicious contract silently overwrite its own class pointer to a class hash that was never legitimately declared, in a state artifact ultimately consumed by the proof/commitment pipeline.

### Likelihood Explanation
This is reachable by any unprivileged contract during ordinary execution: any Cairo0 or Cairo1 contract can invoke the `replace_class` syscall with an arbitrary `class_hash`, including one that has never been declared. No special privileges, node role, or off-chain coordination are required — only a single submitted transaction whose entry point invokes `replace_class` with an attacker-chosen, undeclared class hash.

### Recommendation
Add an explicit "class is declared" check inside `execute_replace_class` in both `syscall_impls.cairo` and `deprecated_execute_syscalls.cairo`, mirroring the blockifier's check (`state.get_compiled_class(request.class_hash)?` before `set_class_hash_at`), so that the OS rejects/reverts the syscall identically to the blockifier when the target class hash is undeclared. Resolve the outstanding `TODO(Yoni, 1/1/2026)` before this code path can process real transactions.

### Proof of Concept
1. Deploy any contract exposing an entry point that calls the `replace_class` syscall with a caller-supplied `class_hash` (e.g., the `test_replace_class` pattern used in `crates/blockifier/src/execution/syscalls/syscall_tests/replace_class.rs`).
2. Submit an invoke transaction calling that entry point with a `class_hash` that has never been declared on-chain.
3. In the blockifier, this reverts with `"... is not declared"` (per `crates/blockifier/src/execution/deprecated_syscalls/hint_processor.rs:801` and the corresponding tests).
4. Trace the same transaction through the Starknet OS's `execute_replace_class` (`syscall_impls.cairo:881-920` / `deprecated_execute_syscalls.cairo:307-329`): no declared-class check exists, so the OS updates `contract_state_changes` with the undeclared class hash unconditionally, producing a different state diff/commitment than the blockifier's reverted outcome for the identical transaction.

// Replaces the class.
func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
