### Title
Front-runnable `Factory.initialize()` after genesis lets an attacker seize ownership of the UEA Factory — ([File: x/uexecutor/keeper/genesis.go])

### Summary
Push Chain deploys the UEA `Factory` proxy/implementation/proxy-admin triad in `deployFactoryEA` at genesis, but never calls `initialize(initialOwner)` on the Factory itself as part of that genesis code. [1](#0-0)  The Factory's `initialize(address initialOwner)` function is a normal external call with no caller restriction visible in the ABI, and is invoked from an ordinary EOA/account in test tooling exactly the way the Unlock Protocol's `PublicLock.initialize()` was invoked by an arbitrary deployer in the referenced report. [2](#0-1) [3](#0-2) 

### Finding Description
At genesis, `x/uexecutor` deploys the Factory implementation, the `ProxyAdmin`, and the Factory proxy by writing EVM account/code/storage directly (`deployFactoryImplContract`, `deployProxyAdminContract`, `deployFactoryProxy`). [4](#0-3)  Only the `ProxyAdmin`'s own `Ownable.owner` slot is set directly via `SetState`; the Factory contract's internal `owner` (used for `onlyOwner`-gated functions such as `setUEAProxyImplementation`, `registerNewChain`, and `registerUEA`) is set exclusively through the Factory's own `initialize(initialOwner)` call, which is never invoked by the module's `InitGenesis`. [5](#0-4) 

The Factory's `initialize` implementation bytecode uses selector `0xc4d66de8`, the canonical OpenZeppelin `Initializable.initialize(address)` selector, which only guards against being called *twice*, not against being called by an *unauthorized first caller*. [6](#0-5)  Consequently, after genesis produces the deployed-but-uninitialized Factory proxy, a race window exists in which any unprivileged account can submit an ordinary EVM transaction calling `initialize(attackerAddress)` on the Factory proxy at `FACTORY_PROXY_ADDRESS_HEX` before the legitimate operator's bootstrap transaction lands. [7](#0-6)  This is functionally identical to the referenced Unlock Protocol finding: `PublicLock.initialize()` had no access control, letting an attacker front-run the intended deployer and seize the implementation's owner slot.

### Impact Explanation
Whoever wins the `initialize()` race becomes the Factory's `owner`, which per the ABI gates `setUEAProxyImplementation`, `registerNewChain`, and `registerUEA`. [8](#0-7)  Every UEA that `x/uexecutor` later deploys or interacts with — via `CallFactoryToDeployUEA`, `DeployUEAV2`, and the inbound/execute-payload flows that deposit PRC20/native funds into a computed UEA address — is resolved and created through this same Factory. [9](#0-8) [10](#0-9)  A malicious Factory owner could call `setUEAProxyImplementation` to point every future UEA proxy at attacker-controlled bytecode, or `registerUEA` to bind a malicious per-chain-namespace implementation, letting them redirect or steal funds deposited into any subsequently deployed UEA — directly matching the in-scope impact "unauthorized UEA or CEA execution" and "stealing, draining … of user or protocol-controlled funds."

### Likelihood Explanation
Likelihood depends entirely on operational timing that is outside the repository's control: whether the legitimate deployer's `initialize` transaction is guaranteed to be the very first transaction to touch the Factory proxy on a fresh chain (e.g., baked into the same genesis block or submitted with validator-level priority before public RPC access opens). If the chain's launch process exposes RPC/mempool access before the operator's `initialize` call is confirmed, the race is trivially winnable by any external account with minimal gas. I could not find code in this repository that closes this window (no `InitGenesis` call to `initialize`, no `onlyGovernance`/allowlist check embedded in the Factory ABI signature), so likelihood is assessed as plausible but contingent on deployment/launch procedure details not visible in this codebase (the Solidity source for the Factory implementation itself is not present in the index — only compiled bytecode/ABI — so I cannot fully rule out an off-chain or genesis-embedded safeguard I did not locate).

### Recommendation
- Call `Factory.initialize(governanceOrModuleAddress)` directly inside `deployFactoryEA`/`InitGenesis` (the same way `deployProxyAdminContract` sets the `ProxyAdmin` owner via `SetState`), so the Factory never exists in an initializable-but-unowned state reachable by public transactions.
- Alternatively, harden the Factory implementation itself so `initialize` can only be called by a hardcoded deployer/module address or via a genesis-only code path, removing the assumption that "first caller wins" is safe.
- Add an integration test asserting the Factory's `owner()` is non-zero and matches the expected authority immediately after `InitGenesis`, before any user-submitted transaction is processed.

### Proof of Concept
1. Observe that `InitGenesis` deploys the Factory proxy/impl/admin via raw state writes only, with no `initialize` call. [1](#0-0) 
2. On chain start, before the operator's bootstrap script (mirrored in `test/utils/contracts_setup.go`'s `setupFactoryContract`) submits its `initialize(owner)` call, submit a competing transaction from any unprivileged account calling `Factory.initialize(attackerAddress)` at `FACTORY_PROXY_ADDRESS_HEX` (`0x00000000000000000000000000000000000000eA`). [11](#0-10) 
3. If the attacker's transaction is included first, `owner()` on the Factory now returns the attacker's address; subsequent legitimate `initialize` calls revert (OZ `Initializable` guard), permanently locking the attacker in as owner.
4. The attacker then calls `setUEAProxyImplementation`/`registerUEA` with malicious bytecode addresses, compromising every UEA subsequently deployed through `CallFactoryToDeployUEA`.

func deployFactoryProxy(ctx context.Context, evmKeeper types.EVMKeeper) {
	sdkCtx := sdk.UnwrapSDKContext(ctx)
	proxyAddress := common.HexToAddress(types.FACTORY_PROXY_ADDRESS_HEX)
	proxyAdminOwner := common.HexToAddress(types.PROXY_ADMIN_ADDRESS_HEX)
	factoryImplAddress := common.HexToAddress(types.FACTORY_IMPL_ADDRESS_HEX)

	// Compute the code hash from the runtime bytecode
	codeHash := crypto.Keccak256(types.ProxyRuntimeBytecode)

	// Create the EVM account object
	evmAccount := statedb.Account{
		Nonce:    1,             // to prevent tx nonce=0 conflicts
		Balance:  new(uint256.Int), // zero balance by default
		CodeHash: codeHash,      // link to deployed code
	}

	// Set the EVM account with the factory proxy contract
	err := evmKeeper.SetAccount(sdkCtx, proxyAddress, evmAccount)
	if err != nil {
		panic("failed to set factory proxy contract account: " + err.Error())
	}

	// Store the runtime bytecode linked to the code hash
	evmKeeper.SetCode(sdkCtx, codeHash, types.ProxyRuntimeBytecode)

	// Update proxyAdmin Slot with the proxyAdmin owner address (left padded to 32 bytes)
	evmKeeper.SetState(sdkCtx, proxyAddress, types.PROXY_ADMIN_SLOT, common.LeftPadBytes(proxyAdminOwner.Bytes(), 32))

	// Update proxyImplementation Slot with the factory implementation address (left padded to 32 bytes)
	evmKeeper.SetState(sdkCtx, proxyAddress, types.PROXY_IMPLEMENTATION_SLOT, common.LeftPadBytes(factoryImplAddress.Bytes(), 32))
}

// CallFactoryToDeployUEA deploys a new UEA using factory contract
// Returns deployment response or error if deployment fails
func (k Keeper) CallFactoryToDeployUEA(
	ctx sdk.Context,
	from, factoryAddr common.Address,
	universalAccount *types.UniversalAccountId,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: deployUEA",
		"factory", factoryAddr.Hex(),
		"chain_namespace", universalAccount.ChainNamespace,
		"chain_id", universalAccount.ChainId,
		"owner", universalAccount.Owner,
	)

	abi, err := types.ParseFactoryABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse factory ABI")
	}

	abiUniversalAccount, err := types.NewAbiUniversalAccountId(universalAccount)
	if err != nil {
		return nil, errors.Wrapf(err, "failed to create universal account")
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		from,        // who is sending the transaction
		factoryAddr, // destination: FactoryV1 contract
		big.NewInt(0),
		nil,
		true,  // commit = true (real tx, not simulation)
		false, // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		false, // not a module sender
		nil,
		"deployUEA",
		abiUniversalAccount,
	)
}
