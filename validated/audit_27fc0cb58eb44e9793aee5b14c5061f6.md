## Finding: Protocol fee from `getOutboundTxGasAndFees` is discarded before it is used to seed and refund outbound gas accounting

### Title
Protocol fee returned by `UniversalCore.getOutboundTxGasAndFees` is silently dropped in `GetOutboundTxGasAndFees`, causing outbound gas/refund accounting to omit the protocol's fee cut - (File: `x/uexecutor/keeper/gas_fee.go`)

### Summary
The Swivel bug is a case where a fee that should be taken on a swapped/remainder amount is never extracted because the code path that performs the swap does not call the fee-extraction logic. The Push Chain analog is in `Keeper.GetOutboundTxGasAndFees`, which calls the `UniversalCore` system contract's `getOutboundTxGasAndFees` view function. That ABI explicitly returns a `protocolFee` output (index 2) alongside `gasToken`, `gasFee`, `gasPrice`, `chainNamespace`, and `gasLimitUsed` [1](#0-0) , but the Go keeper explicitly discards it with the comment "not needed for outbound fields": [2](#0-1) .

### Finding Description
`GetOutboundTxGasAndFees` unpacks all six return values but only propagates `gasToken`, `gasFee`, `gasPrice`, and `gasLimit` into the `GasFeeInfo` struct; `protocolFee` is read into a commented-out variable and never used [3](#0-2) . This function backs `GetGasFeeInfoForRevertOutbound`, which is used by `buildRevertOutbound` to populate `outbound.GasFee` on every `INBOUND_REVERT` outbound created for a failed/reverted inbound [4](#0-3) . The same `GetDefaultFeeTierForToken`/`GetSwapQuote` pattern (Uniswap fee tier, unrelated to `protocolFee`) is separately used elsewhere for auto-swap deposits, e.g. `gasAndPayloadDepositAutoSwap` and `ExecuteInboundGas` [5](#0-4) [6](#0-5) , confirming that only `gasFee` (not `protocolFee`) flows downstream into the outbound's stored gas budget.

That `outbound.GasFee` value is later used, unmodified, by `applyGasRefund` to compute the excess-gas refund on both successful and failed outbounds: `refundAmount = gasFee - gasFeeUsed`, and the excess is swapped back to PC and sent to the refund recipient via `CallUniversalCoreRefundUnusedGas` [7](#0-6) . Because `protocolFee` was never subtracted out (or otherwise accounted for) when `GasFee` was captured, the entire `gasFee` figure — which the contract computes alongside a distinct `protocolFee` component — is treated as fully refundable/attributable to gas, with no path in the Go keeper that ever collects, burns, or routes the `protocolFee` amount for outbound/revert flows.

### Impact Explanation
Every `INBOUND_REVERT` outbound (triggered whenever an ordinary user's inbound fails and needs to be reverted) and the excess-gas-refund computation derived from it never account for the protocol's fee cut on that leg of the flow. Structurally this mirrors the Swivel finding: a fee value that the underlying logic explicitly computes and returns is dropped by the calling code before any accounting/collection step, so the protocol systematically fails to capture revenue on this reachable, unprivileged, user-driven code path (a normal user submitting an inbound that later needs reverting, or any GAS_AND_PAYLOAD/GAS-only inbound whose outbound gas fields flow into the excess-refund formula).

### Likelihood Explanation
High likelihood of occurring on ordinary usage: `buildRevertOutbound` runs on any inbound failure path reachable by unprivileged users (no privileged actor needed), and `applyGasRefund` runs on both success and failure outbound observation flows already exercised in the existing test suite (`test/integration/uexecutor/gas_fee_refund_test.go`) [8](#0-7) . No malicious validator/TSS/relayer collusion is required to trigger the drop — it happens deterministically inside the Go keeper regardless of who is honest.

### Recommendation
Propagate `protocolFee` from `GetOutboundTxGasAndFees` into `GasFeeInfo`, plumb it through `GetGasFeeInfoForRevertOutbound`/`buildRevertOutbound` into a new `OutboundTx.ProtocolFee` field, and ensure `applyGasRefund` (and any other outbound-gas-seeding code path) subtracts/collects `protocolFee` before computing the refundable excess, so the protocol's fee is consistently captured rather than silently discarded.

### Proof of Concept
1. Trigger any inbound that results in `buildRevertOutbound` being called (e.g., factory lookup failure or `DeployUEAV2` failure during `ExecuteInboundGasAndPayload`), producing an `INBOUND_REVERT` outbound whose `GasFee` is populated solely from `GetGasFeeInfoForRevertOutbound` [4](#0-3) .
2. Observe that the contract-side `protocolFee` return value is never read into the `OutboundTx` — confirmed by the discarded variable in `GetOutboundTxGasAndFees` [9](#0-8) .
3. When validators vote this outbound as observed, `applyGasRefund` computes `refundAmount = gasFee - gasFeeUsed` using the fee-less `gasFee`, and refunds it to the user without ever debiting/collecting the `protocolFee` component [10](#0-9) .

### Caveat / Confidence Limitation
I was unable to inspect the Solidity source of the `UniversalCore` contract in this index (only the ABI is present), so I cannot fully confirm whether `protocolFee` is meant to be a component the Go keeper must separately collect, versus being already netted by the contract into `gasFee` at the time of transfer. The strong signal in-scope is that the Go code itself annotates the value as "not needed" and never uses it anywhere in the repository (confirmed via repo-wide grep), which is the direct analog to the Swivel report's core defect (a computed fee value that is available but never extracted along a specific code path). A background engineer should verify against the actual `UniversalCore.sol` source (likely in a separate contracts repo) to confirm whether `protocolFee` is truly uncollected end-to-end before implementing the fix.

```go
func (k Keeper) GetOutboundTxGasAndFees(ctx sdk.Context, prc20 common.Address, gasLimitWithBaseLimit *big.Int) (*GasFeeInfo, error) {
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	ucABI, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse UniversalCore ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	receipt, err := k.evmKeeper.CallEVM(ctx, ucABI, ueModuleAccAddress, handlerAddr, false, nil,
		"getOutboundTxGasAndFees", prc20, gasLimitWithBaseLimit)
	if err != nil {
		return nil, errors.Wrap(err, "failed to call getOutboundTxGasAndFees")
	}

	results, err := ucABI.Methods["getOutboundTxGasAndFees"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack getOutboundTxGasAndFees result")
	}

	gasToken := results[0].(common.Address)
	gasFee := results[1].(*big.Int)
	// protocolFee := results[2].(*big.Int) — not needed for outbound fields
	gasPrice := results[3].(*big.Int)
	// chainNamespace := results[4].(string) — not needed for outbound fields
	// gasLimitUsed (results[5]) is the exact gas limit the contract resolved
	// (caller-supplied or per-chain baseGasLimitByChainNamespace fallback).
	// Reading it directly avoids the gasFee/gasPrice round-trip and keeps us
	// in lock-step with the contract's own resolution.
	gasLimit := results[5].(*big.Int)

	return &GasFeeInfo{
		GasToken: gasToken,
		GasFee:   gasFee,
		GasPrice: gasPrice,
		GasLimit: gasLimit,
	}, nil
}
```

```go
	prc20AddressHex common.Address,
	ueaAddr common.Address,

	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err

		return nil, err

		return nil, err

	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))
```

```go
// applyGasRefund computes the excess gas (gasFee - gasFeeUsed) and, if positive,
// calls UniversalCore refundUnusedGas. The result is recorded in outbound.PcRefundExecution.
// It is called for both successful and failed outbounds — gas is consumed on the
// external chain regardless of execution outcome.
func (k Keeper) applyGasRefund(ctx sdk.Context, outbound *types.OutboundTx, obs *types.OutboundObservation) {
	if obs.GasFeeUsed == "" || outbound.GasFee == "" || outbound.GasToken == "" {
		return
	}

	gasFee := new(big.Int)
	if _, ok := gasFee.SetString(outbound.GasFee, 10); !ok {
		return
	}

	gasFeeUsed := new(big.Int)
	if _, ok := gasFeeUsed.SetString(obs.GasFeeUsed, 10); !ok {
		return
	}

	// No excess gas to refund
	if gasFee.Cmp(gasFeeUsed) <= 0 {
		return
	}

	refundAmount := new(big.Int).Sub(gasFee, gasFeeUsed)
	gasToken := common.HexToAddress(outbound.GasToken)

	// Refund recipient: prefer fund_recipient in revert_instructions, fall back to sender
	refundRecipient := outbound.Sender
	if outbound.RevertInstructions != nil && outbound.RevertInstructions.FundRecipient != "" {
		refundRecipient = outbound.RevertInstructions.FundRecipient
	}
	recipientAddr := common.HexToAddress(refundRecipient)

	refundPcTx := &types.PCTx{
		Sender:      outbound.Sender,
		BlockHeight: uint64(ctx.BlockHeight()),
	}

	// Step 1: try refund with swap (gasToken → PC native)
	fee, swapErr := k.GetDefaultFeeTierForToken(ctx, gasToken)
	var swapFallbackReason string

	if swapErr == nil {
		quote, quoteErr := k.getSwapQuoteForRefund(ctx, gasToken, fee, refundAmount)
		if quoteErr == nil {
			minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
			minPCOut.Div(minPCOut, big.NewInt(100))

			resp, err := k.CallUniversalCoreRefundUnusedGas(ctx, gasToken, refundAmount, recipientAddr, true, fee, minPCOut)
			if err == nil {
				refundPcTx.TxHash = resp.Hash
				refundPcTx.GasUsed = resp.GasUsed
				refundPcTx.Status = "SUCCESS"
				outbound.PcRefundExecution = refundPcTx
				return
			}
```
