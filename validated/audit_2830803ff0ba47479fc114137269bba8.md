### Title
Starknet OS `replace_class` syscall handler skips declared-class/version validation performed by the Blockifier, causing OS/Blockifier execution divergence - ([File: crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo])

### Summary
The `replace_class` syscall lets a contract change its own class hash — analogous to Kokomo Finance's exploit, where an attacker leveraged an uncontrolled implementation/class swap to redirect calls to a malicious implementation. In this codebase, the Rust `Blockifier` (the real sequencer execution engine) validates that a `replace_class` target class hash is declared and is a Cairo1 class before performing the swap, but the Starknet OS's Cairo re-implementation of the same syscall performs no such validation, leaving a TODO instead.

### Finding Description
In the Blockifier, `replace_class` explicitly checks the target class is declared and is Cairo1 before writing the new class hash: [1](#0-0) 

The deprecated (Cairo0) syscall handler likewise enforces the class must be declared: [2](#0-1) 

Tests confirm the Blockifier rejects `replace_class` when the target class hash is undeclared ("is not declared") or is a Cairo0 hash replacing a Cairo1 class ("Cannot replace V1 class hash with V0 class hash"): [3](#0-2) 

However, the Starknet OS's Cairo implementation of the same syscall (`execute_replace_class` in `syscall_impls.cairo`) performs the state-entry class-hash swap unconditionally, with an explicit TODO noting the missing check: [4](#0-3) 

The same missing validation exists in the deprecated OS syscall path: [5](#0-4) 

Neither OS code path checks that the target class hash was actually declared, nor that it is Cairo1 (i.e., it doesn't reject a Cairo0 class replacing a Cairo1 class, or an entirely undeclared class hash). This is a genuine semantic divergence between the two independent implementations of the same syscall that must produce identical results for the Starknet OS's re-execution (used to prove correctness of a block) to match the Blockifier's committed state.

### Impact Explanation
Since Blockifier and the Starknet OS are two independent re-implementations of Starknet execution semantics that must agree bit-for-bit for a block to be provable, this divergence means:
- Any unprivileged contract (reachable from a normal invoke transaction) can call `replace_class_syscall` with an undeclared class hash or a Cairo0 hash targeting a Cairo1 contract.
- In the Blockifier (the sequencer's real execution and state commitment), this call fails/reverts, leaving the contract's class hash unchanged.
- In the Starknet OS re-execution (used to generate/verify the STARK proof of the block), the same call succeeds and unconditionally overwrites the contract's class hash in the state tree.
- This produces a different computed state root/state diff between the two engines for the same block, which can result in the OS being unable to prove the block matching the sequencer's committed state (network unable to confirm/finalize new blocks) or, if reconciled incorrectly, a wrong committed root — both explicitly in-scope high-severity impacts per the rules ("wrong committed root or block hash, honest-node divergence... network unable to confirm new transactions").

### Likelihood Explanation
High reachability: `replace_class_syscall` is a standard, publicly documented Starknet syscall callable by any Cairo1 contract from any unprivileged invoke transaction — no special privilege, staking, or operator role is required. Triggering the divergence only requires calling the syscall with a class hash that is undeclared (trivial to construct) or a Cairo0 class hash on a Cairo1 contract.

### Recommendation
Implement the same validation in the Starknet OS's `execute_replace_class` (both `syscall_impls.cairo` and `deprecated_execute_syscalls.cairo`) that the Blockifier performs: verify the target class hash corresponds to a declared class (reading its compiled class / component hashes as the OS would for any other class access) and reject non-Cairo1 targets exactly as `is_cairo1(&compiled_class)` does in `syscall_base.rs`, before mutating `contract_state_changes`. Resolve the TODO referenced at `syscall_impls.cairo:902` and add regression tests mirroring `crates/blockifier/src/execution/syscalls/syscall_tests/replace_class.rs` for the OS execution path to guarantee Blockifier/OS equivalence.

### Proof of Concept
1. Deploy a Cairo1 contract `A` that calls `replace_class_syscall(class_hash)` on user-controlled `class_hash` (e.g., `test_replace_class` pattern shown in `crates/blockifier_test_utils/resources/feature_contracts/cairo1/test_contract.cairo`).
2. Submit an ordinary invoke transaction calling this entry point with an arbitrary/undeclared `class_hash` (e.g., `felt!(1234_u16)`, as used in `crates/blockifier/src/execution/syscalls/syscall_tests/replace_class.rs:17-29`).
3. Observe: the Blockifier-driven sequencer reverts the call (`"... is not declared"`), so the state committed to L2/L1 shows no class-hash change for contract `A`.
4. Feed the identical transaction/block into the Starknet OS re-execution path (`syscall_impls.cairo` `execute_replace_class`) — it will set `contract_state_changes` for `A` to the arbitrary class hash without error, since no declared-class check exists there.
5. This produces a computed state diff/root in the OS that differs from what the Blockifier already committed for the same block, demonstrating the divergence.

    pub fn replace_class(&mut self, class_hash: ClassHash) -> SyscallResult<()> {
        // Ensure the class is declared (by reading it), and of type V1.
        let compiled_class = self.state.get_compiled_class(class_hash)?;

        if !is_cairo1(&compiled_class) {
            return Err(SyscallExecutionError::ForbiddenClassReplacement { class_hash });
        }
        self.state.set_class_hash_at(self.call.storage_address, class_hash)?;
        Ok(())
    }

func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
