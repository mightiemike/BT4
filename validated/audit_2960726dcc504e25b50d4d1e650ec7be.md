## Finding

Both the sequencer's block-building execution engine (blockifier) and the proving/re-execution engine (Starknet OS) implement the `replace_class` syscall independently, but only the blockifier version enforces the safety invariants. [1](#0-0) 

The OS's Cairo implementation of the same syscall — reached by both the current and deprecated syscall dispatch paths — skips the "is this class hash actually declared" check entirely, as flagged by its own inline TODO, and never enforces the V0/V1 compatibility rule either. [2](#0-1) [3](#0-2) 

### Title
Starknet OS `replace_class` syscall omits declared-class and V0/V1 checks that Blockifier enforces, causing state-transition divergence and unauthorized class substitution - ([File: crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo])

### Summary
Any contract can invoke the `replace_class` syscall with an arbitrary `class_hash` supplied via its own calldata — no privilege or admin role is required, exactly analogous to how the Aevo/Ribbon exploit abused an unprotected `setImplementation`/proxy-admin path. In the sequencer's actual execution engine (blockifier), this syscall is guarded: it fails if the class is undeclared, and it rejects replacing a Cairo1 contract with a Cairo0 (V0) class hash. In the Starknet OS's Cairo re-implementation of the identical syscall — used to independently re-derive the block's state diff for proving and state-root commitment — both of these checks are missing (the declared-class check is explicitly marked with a TODO, and there is no forbidden-class-replacement check at all).

### Finding Description
`SyscallHandlerBase::replace_class` in the blockifier enforces two invariants before mutating a contract's class pointer:
1. The target `class_hash` must correspond to a class actually declared in state (`self.state.get_compiled_class(class_hash)?`).
2. The target class must be Cairo1 (`is_cairo1`), otherwise it returns `ForbiddenClassReplacement`. [1](#0-0) 

Unit tests confirm both checks are load-bearing in the reference execution engine: an undeclared class hash errors with "is not declared", and a Cairo0 target errors with "Cannot replace V1 class hash with V0 class hash". [4](#0-3) 

The deprecated (Cairo0) syscall path in blockifier applies the equivalent declared-class check as well. [5](#0-4) 

By contrast, the Starknet OS's Cairo hint-based execution of the same syscall — `execute_replace_class` in `syscall_impls.cairo` (Cairo1 path) and the structurally identical function in `deprecated_execute_syscalls.cairo` (deprecated path) — writes the new `class_hash` straight into `contract_state_changes` with no declared-class lookup and no V0/V1 compatibility check: [6](#0-5) [3](#0-2) 

This is precisely the pattern in the Aevo report: a legacy/authoritative validation path (Opyn's Gamma protocol rules, analogous to blockifier's checks) is bypassed by a newer or parallel code path (Ribbon's oracle configuration, analogous to the OS's Cairo hint implementation) that omits the same guard, letting a transaction do something the "real" execution semantics were designed to forbid.

The Starknet OS is the component that independently re-executes every transaction in a block to derive the state diff that is hashed into the committed state root and proven via STARK — it is a second, non-blockifier implementation of the STF that must match blockifier's semantics exactly for the system to be sound. Because both `replace_class` implementations are reachable from a single, ordinary transaction (no special sender privilege — just a contract calling `replace_class_syscall` on itself), this divergence is fully triggerable by any user.

### Impact Explanation
- **State-transition divergence / wrong committed root**: A transaction that blockifier rejects (undeclared class hash, or replacing a Cairo1 class with a Cairo0 class) is not rejected by the OS's Cairo implementation, which instead accepts it and rewrites the contract's `class_hash` in `contract_state_changes` to the caller-supplied value. If the block/proof pipeline relies on the OS's independently-computed state diff to build the committed state root (rather than strictly replaying blockifier's revert/success decisions), an attacker-chosen transaction can force the OS to produce a state diff/root that differs from what the "authoritative" blockifier semantics would produce — a wrong committed root/block-hash class of bug.
- **Unauthorized account action**: Any caller can, through this path, drive a contract's class pointer to an arbitrary felt value that was never declared as a class (or that is a Cairo0 class while the contract's account-abstraction assumptions expect Cairo1), corrupting that contract's class-hash pointer without any authorization from the contract owner, and without the two invariants the ecosystem otherwise relies on when using `replace_class` legitimately.

### Likelihood Explanation
High reachability: `replace_class` is a public Starknet syscall usable by any deployed contract, invocable from an ordinary, unprivileged transaction — no special sender role, staking, or node privilege needed, matching the "unprivileged transaction sender" reachability required. The only requirement is a contract whose code calls `replace_class_syscall(arbitrary_hash)`, which is trivial to deploy and declare.

### Recommendation
Add the same two checks to the Starknet OS's Cairo `execute_replace_class` (both the Cairo1 path in `syscall_impls.cairo` and the deprecated path in `deprecated_execute_syscalls.cairo`) that blockifier's `syscall_base.rs::replace_class` already performs:
1. Verify the requested `class_hash` corresponds to a class declared in the OS's committed class state (mirroring `get_compiled_class`/declared-class lookup), failing/reverting the syscall otherwise.
2. Reject replacement when the target class is Cairo0 (V0) for a caller currently running Cairo1 semantics, mirroring `ForbiddenClassReplacement`.

Resolve the outstanding `TODO(Yoni, 1/1/2026)` before it can be exploited, and add a differential/consistency test between blockifier and the OS Cairo hints specifically for `replace_class` with (a) an undeclared class hash and (b) a Cairo0 target, asserting identical revert/accept behavior and identical resulting state diffs.

### Proof of Concept
1. Deploy any Cairo1 contract `C` exposing a function that calls `replace_class_syscall(class_hash)` with a caller-supplied `class_hash` (the existing `test_replace_class` test entry point in the feature contracts already does this).
2. Submit a transaction invoking that function on `C` with `class_hash = 1234` (or any felt not corresponding to any declared class).
3. Blockifier execution (as verified by `undeclared_class_hash` test) reverts the call with "is not declared". [7](#0-6) 
4. When the same transaction/block is re-executed by the Starknet OS's Cairo hints (`execute_replace_class` in `syscall_impls.cairo`), no declared-class check exists, so the OS accepts the call and writes `class_hash=1234` into `contract_state_changes` for `C`'s address, producing a state diff/root that disagrees with blockifier's reverted outcome. [6](#0-5)

    pub fn replace_class(&mut self, class_hash: ClassHash) -> SyscallResult<()> {
        // Ensure the class is declared (by reading it), and of type V1.
        let compiled_class = self.state.get_compiled_class(class_hash)?;

        if !is_cairo1(&compiled_class) {
            return Err(SyscallExecutionError::ForbiddenClassReplacement { class_hash });
        }
        self.state.set_class_hash_at(self.call.storage_address, class_hash)?;
        Ok(())
    }

func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
