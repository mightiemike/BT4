## Finding confirmed

The exploit path in the question is real: `MsgMigrateUEA` is both gasless and lacks any post-execution fee/gas accounting, unlike its sibling message `MsgExecutePayload`.

### Title
Gasless `MsgMigrateUEA` triggers real, unbounded, fee-free EVM execution with no gas-cost recoupment - (File: `app/txpolicy/gasless.go`, `x/uexecutor/keeper/msg_migrate_uea.go`)

### Summary
`IsGaslessTx` whitelists `MsgMigrateUEA` [1](#0-0) , so it skips the FeeMarket minimum-fee check and `DeductFeeDecorator` entirely (per `app/README.md`'s documented ante-decorator behavior for gasless txs). Unlike `ExecutePayload`, whose keeper deducts EVM gas cost from the target UEA's balance after execution via `DeductGasFeesFromReceipt` [2](#0-1) , the `MigrateUEA` keeper function performs a real, committed `DerivedEVMCall` (`commit=true`) via `CallUEAMigrateUEA` but never calls any fee-deduction routine afterward [3](#0-2) .

### Finding Description
`CallUEAMigrateUEA` issues a real, state-committing EVM call into the target UEA contract (`commit=true`, `gasless=false` only in the sense that the EVM receipt records gas, not that anyone is billed) [4](#0-3) . The only preconditions to reach this call are: the chain config exists and has inbound enabled, and the target UEA is already deployed [5](#0-4) . There is no authorization check tying `Signer` to `UniversalAccountId.Owner` at the Cosmos layer (by design, matching `ExecutePayload`'s "contract-only binding" model) — the real signature check happens only inside the UEA contract, after the EVM call has already executed and consumed real computation/storage-read work.

Because:
1. `MsgMigrateUEA` is in `GaslessMsgTypes`, the ante pipeline skips both the FeeMarket minimum-fee check (`MinGasPriceDecorator`) and fee deduction (`DeductFeeDecorator`) for this message.
2. The `MigrateUEA` keeper path has no equivalent of `DeductGasFeesFromReceipt` — there is no mechanism recouping the EVM execution cost from the UEA, the signer, or any account.

An unprivileged attacker can repeatedly submit `MsgMigrateUEA` (targeting their own deployed UEA, or any other already-deployed UEA — the call will simply revert inside the contract due to signature-check failure, but only after real EVM state access/computation) at zero Cosmos fee, triggering real committed EVM execution on every submission with no fee deterrent whatsoever.

### Impact Explanation
Each submission costs the attacker nothing (no fee required, gasless account creation via `AccountInitDecorator` even lets a brand-new key submit without funding), yet each one performs genuine EVM work (contract call dispatch, storage reads for nonce/owner, signature-recovery computation) that consumes real block gas and validator compute time. This is an asymmetry versus `ExecutePayload`, which recoups its EVM cost from the UEA balance and thus is self-limiting once the UEA is drained. `MigrateUEA` has no such backstop, so it is a strictly cheaper, unbounded way to force validators to perform real state-changing EVM execution work for free, degrading block throughput/finalization time under sustained spam — a non-network-level DoS reachable by an ordinary unprivileged account.

### Likelihood Explanation
High. No special role is required (any funded-or-unfunded account can submit gasless txs), the target only needs to be a deployed UEA (trivially true for the attacker's own UEA, or any address they've previously deployed for themselves via the normal deposit/execute flow), and the message is explicitly gasless by design in `app/txpolicy/gasless.go`.

### Recommendation
Either remove `MsgMigrateUEA` from `GaslessMsgTypes` in `app/txpolicy/gasless.go` (the `x/uexecutor/README.md` documentation already states this message path was supposed to be retired in favor of `MsgExecutePayload`, suggesting the gasless whitelist entry and dedicated message/keeper path are stale and should be deleted), or, if the message must remain, add a `DeductGasFeesFromReceipt`-equivalent gas-cost recoupment step to `x/uexecutor/keeper/msg_migrate_uea.go` mirroring `ExecutePayload`'s Step 4, so that every committed EVM execution is paid for regardless of outcome.

### Proof of Concept
1. Attacker submits a normal deposit/execute flow (or any existing deployed UEA is targeted) so a UEA exists at address `U` for `UniversalAccountId{chain, owner}`.
2. Attacker crafts `N` distinct `MsgMigrateUEA` txs with `Signer = attackerAddr`, `UniversalAccountId = {chain, owner=U's owner}` (or any other already-deployed UEA's id), and an arbitrary/garbage `MigrationPayload`/`Signature`.
3. `IsGaslessTx` returns true for each, so `MinGasPriceDecorator` and `DeductFeeDecorator` are skipped [6](#0-5) .
4. Each tx reaches `msgServer.MigrateUEA` → `Keeper.MigrateUEA` → `CallUEAMigrateUEA` → `DerivedEVMCall(commit=true, ...)`, performing real EVM execution/revert with zero balance requirement and zero fee deduction afterward.
5. Repeating this at volume consumes real block gas/validator time with no economic cost to the attacker, verified by comparing to `ExecutePayload`'s `DeductGasFeesFromReceipt` step which is absent from the `MigrateUEA` path.

// IsGaslessTx checks if a transaction contains only allowed gasless message types
// Returns true if all messages in the transaction are in the allowed gasless message types
func IsGaslessTx(tx sdk.Tx) bool {
	var (
		// GaslessMsgTypes defines the message types that are allowed in gasless transactions
		GaslessMsgTypes = []string{
			sdk.MsgTypeURL(&uexecutortypes.MsgMigrateUEA{}),
			sdk.MsgTypeURL(&uexecutortypes.MsgExecutePayload{}),
			sdk.MsgTypeURL(&uexecutortypes.MsgVoteInbound{}),
			sdk.MsgTypeURL(&uexecutortypes.MsgVoteOutbound{}),
			sdk.MsgTypeURL(&utsstypes.MsgVoteTssKeyProcess{}),
			sdk.MsgTypeURL(&utsstypes.MsgVoteFundMigration{}),
			sdk.MsgTypeURL(&uexecutortypes.MsgVoteChainMeta{}),
		}
	)

	msgs := tx.GetMsgs()
	if len(msgs) == 0 {
		return false
	}

	for _, msg := range msgs {
		switch m := msg.(type) {
		case *authz.MsgExec:
			// Only gasless if ALL inner messages are allowed
			for _, innerMsg := range m.Msgs {
				if !slices.Contains(GaslessMsgTypes, innerMsg.TypeUrl) {
					return false
				}
			}
		default:
			if !slices.Contains(GaslessMsgTypes, sdk.MsgTypeURL(msg)) {
				return false
			}
		}
	}
	return true
}

// CallUEAMigrateUEA migrates UEA through existing UEA
func (k Keeper) CallUEAMigrateUEA(
	ctx sdk.Context,
	from, ueaAddr common.Address,
	migration_payload *types.MigrationPayload,
	signature []byte,
) (*evmtypes.MsgEthereumTxResponse, error) {
	abi, err := types.ParseUeaABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse UEA ABI")
	}

	abiMigrationPayload, err := types.NewAbiMigrationPayload(migration_payload)
	if err != nil {
		return nil, errors.Wrapf(err, "failed to create universal payload")
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		from,
		ueaAddr,
		big.NewInt(0),
		nil,
		true,  // commit = true (real tx, not simulation)
		false, // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		false, // not a module sender
		nil,
		"migrateUEA",
		abiMigrationPayload,
		signature,
	)
}
