### Title
Sierra-to-Native compilation path skips the audited-libfuncs safety gate enforced for Sierra-to-CASM, letting a class declarer run unaudited libfuncs as native machine code in the sequencer process - ([File: crates/apollo_compile_to_native/src/compiler.rs])

### Summary
The Sierra-to-CASM compiler (`SierraToCasmCompiler::compile`) always passes `--allowed-libfuncs-list-name` (`audited` or `all`, governed by `audited_libfuncs_only`) to the compiler binary, enforcing that only libfuncs on Starknet's audited safety list are accepted for a declared class. The Sierra-to-Native compiler (`SierraToNativeCompiler::compile`), used when `CairoNativeMode` is `LazyCompilation`/`WaitOnCompilation`, never passes any libfunc allow-list argument, so it compiles and executes any Sierra program regardless of whether its libfuncs are on the audited list.

### Finding Description
`SierraToCasmCompiler::compile` builds its `additional_args` including the audited-libfuncs restriction: [5](#0-4) 

In contrast, `SierraToNativeCompiler::compile` builds `additional_args` with only the output path and optimization level — no libfunc restriction flag exists at all in this crate: [6](#0-5) 

Once a class is declared, the batcher's `NativeClassManager` (when Cairo Native mode is enabled) asynchronously (or synchronously) compiles the previously-declared Sierra program straight to native code via `process_compilation_request`, with no libfunc gating step in between: [7](#0-6) 

The resulting `AotContractExecutor` is then run in-process (not in a subprocess or sandbox) whenever the class is invoked, directly executing native machine code compiled from the declarer's Sierra program inside the sequencer/batcher process: [8](#0-7) 

The audited-libfuncs list exists specifically to gate which libfuncs are considered safe/stable enough for production compilation; the CASM compilation pipeline treats this as a hard security boundary (`audited_libfuncs_only` defaults to `true` in production configs, e.g. `sierra_compiler_config.audited_libfuncs_only: true`): [9](#0-8) 

Because the native path has no equivalent check, a class that was compiled to CASM using the audited list can still be silently promoted to native execution using libfuncs Starknet has not vetted for native codegen safety, executing unaudited compiler-generated native code directly inside the sequencer process rather than inside the sandboxed/CASM-interpreted VM.

### Impact Explanation
Unaudited libfuncs are excluded from the CASM audited list precisely because their generated code has not been vetted as safe/deterministic/side-effect-free. When such a class is compiled to native and executed in-process (no OS-level process isolation at execution time, unlike compile time which uses `ResourceLimits`/subprocess isolation), any memory-safety or determinism issue in the libfunc's native lowering runs with the full privileges of the sequencer/batcher process. This can manifest as memory corruption, crashes (denial of service for block building/validation), or divergent execution results between nodes running Native vs. VM mode — i.e., honest-node divergence in committed state, satisfying the required impact bar for this class of finding.

### Likelihood Explanation
Reachable by any account that can submit a `Declare` transaction (an ordinary authenticated user), followed by any `Invoke` that reaches the declared class's entry point, provided the deployment runs with Cairo Native compilation enabled (`CairoNativeMode::LazyCompilation` or `WaitOnCompilation`), which several service configs enable (e.g. `contract_class_manager_config.cairo_native_run_config.cairo_native_mode`). No special privileges beyond normal transaction submission are required.

### Recommendation
Apply the same audited-libfuncs gating to the Sierra-to-Native compilation path as is applied to Sierra-to-CASM: reject (or fall back permanently to CASM execution for) any Sierra program containing libfuncs outside the audited list before invoking `SierraToNativeCompiler::compile`, or pass an equivalent `--allowed-libfuncs` restriction to the native compiler binary if supported.

### Proof of Concept
1. Enable Cairo Native (`cairo_native_run_config.cairo_native_mode = "lazy_compilation"`) on a batcher/gateway deployment with `sierra_compiler_config.audited_libfuncs_only = true`.
2. Submit a `Declare` transaction whose Sierra program contains a libfunc that is valid Sierra but absent from `crates/apollo_compile_to_casm/src/allowed_libfuncs.json` (i.e., accepted by CASM compilation with `audited_libfuncs_only=false`/rejected with `true`, but syntactically compilable) — chosen so that CASM validation of the class either isn't enforced project-wide, or the unaudited libfunc still compiles fine, and the resulting `CompiledClasses::V1` gets pushed into the native compilation channel via `set_and_compile`.
3. Observe `run_compilation_worker`/`process_compilation_request` in `crates/blockifier/src/state/native_class_manager.rs` invoke `SierraToNativeCompiler::compile` with no libfunc restriction, successfully producing an `AotContractExecutor` for the unaudited-libfunc class.
4. Invoke the declared contract; `native_entry_point_execution::execute_entry_point_call` runs the compiled native code in-process, demonstrating that the unaudited libfunc's native code executes with no additional isolation.

```rust
            resource_limits,
        )?;
```

```rust
/// Processes a compilation request and caches the result.
fn process_compilation_request(
    class_cache: RawClassCache,
    compiler: Arc<SierraToNativeCompiler>,
    compilation_request: CompilationRequest,
    panic_on_compilation_failure: bool,
) -> Result<(), CompilationUtilError> {
    let (class_hash, sierra, casm) = compilation_request;
    if let Some(CompiledClasses::V1Native(_)) = class_cache.get(&class_hash) {
        // The contract class is already compiled to native - skip the compilation.
        return Ok(());
    }
    let sierra_for_compilation = into_contract_class_for_compilation(sierra.as_ref());
    let start = Instant::now();
    let compilation_result = compiler.compile(sierra_for_compilation);
    let duration = start.elapsed();
    log::info!(
        "Compiling to native contract with class hash: {:#066x}. Duration: {:.3} seconds",
        class_hash.0,
        duration.as_secs_f32()
    );
    match compilation_result {
        Ok(executor) => {
            let native_compiled_class = NativeCompiledClassV1::new(executor, casm);
            class_cache.set(
                class_hash,
                CompiledClasses::V1Native(CachedCairoNative::Compiled(native_compiled_class)),
            );
            log::info!("Compilation succeeded");
            Ok(())
        }
```

```rust
pub fn execute_entry_point_call(
    call: ExecutableCallEntryPoint,
    compiled_class: NativeCompiledClassV1,
    state: &mut dyn State,
    context: &mut EntryPointExecutionContext,
) -> Result<CallInfo, EntryPointExecutionError> {
    let entry_point = compiled_class
        .get_entry_point(&call.type_and_selector())
        .map_err(EntryPointExecutionError::from)?;

    let mut syscall_handler: NativeSyscallHandler<'_> =
        NativeSyscallHandler::new(call, state, context);

    let gas_costs = &syscall_handler.base.context.gas_costs();
    let builtin_costs = BuiltinCosts {
        // todo(rodrigo): Unsure of what value `const` means, but 1 is the right value.
        r#const: 1,
        pedersen: gas_costs.builtins.pedersen,
        bitwise: gas_costs.builtins.bitwise,
        ecop: gas_costs.builtins.ecop,
        poseidon: gas_costs.builtins.poseidon,
        add_mod: gas_costs.builtins.add_mod,
        mul_mod: gas_costs.builtins.mul_mod,
        blake: gas_costs.builtins.blake,
    };

    // Pre-charge entry point's initial budget to ensure sufficient gas for executing a minimal
    // entry point code. When redepositing is used, the entry point is aware of this pre-charge
    // and adjusts the gas counter accordingly if a smaller amount of gas is required.
    let initial_budget = syscall_handler.base.context.gas_costs().base.entry_point_initial_budget;
    let call_initial_gas = syscall_handler
        .base
        .call
        .initial_gas
        .checked_sub(initial_budget)
        .ok_or(PreExecutionError::InsufficientEntryPointGas)?;

    let execution_result = compiled_class.executor.run(
        entry_point.selector.0,
        &syscall_handler.base.call.calldata.0.clone(),
        call_initial_gas,
        Some(builtin_costs),
        &mut syscall_handler,
    );
```
