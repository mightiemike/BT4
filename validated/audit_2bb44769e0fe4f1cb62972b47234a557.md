## Title
Deposit auto-swap uses a manipulable on-chain spot price (QuoterV2) as both the reference price and the execution venue for `minPCOut`, allowing sandwich/price-manipulation attacks on inbound `GAS`/`GAS_AND_PAYLOAD` deposits - (File: `x/uexecutor/keeper/execute_inbound_gas.go`, `x/uexecutor/keeper/evm.go`)

### Summary
This is the Push Chain analog of the Derby "unprotected slippage tolerance" finding. Instead of a user-supplied, unbounded slippage value, Push Chain hardcodes a 5% tolerance, but the *reference price* used to compute `minPCOut` is itself taken from the same manipulable AMM (`QuoterV2.quoteExactInputSingle`, a spot-price static call) that immediately executes the real swap. Because the "protection" is relative to a price an attacker can move in the same or a preceding block, the 5% floor protects against nothing when the attacker controls the reference price.

### Finding Description
For `GAS` and `GAS_AND_PAYLOAD` inbounds, the keeper deposits the bridged PRC20 and auto-swaps it to native PC/WPC for the recipient's UEA: [1](#0-0) 

It fetches a quote via `GetSwapQuote`, which performs a **static, non-committed call** to `QuoterV2.quoteExactInputSingle` — i.e., it reads the *current spot price* of the pool at call time: [2](#0-1) 

`minPCOut` is then derived as a flat 95% of that just-fetched spot quote: [3](#0-2) 

and immediately consumed by `CallPRC20DepositAutoSwap`, which executes the real swap against the same pool: [4](#0-3) 

The identical 95%-of-spot-quote pattern is repeated for `GAS_AND_PAYLOAD` deposits and for gas refunds: [5](#0-4) [6](#0-5) 

Because the quote and the swap both read from the same on-chain pool state and there is no TWAP, external price feed, or protocol-set floor independent of that pool, an unprivileged actor can move the pool's spot price (via an ordinary permissionless swap on the WPC/PRC20 Uniswap V3 pool) immediately before the keeper's swap executes. The 5% band then only bounds slippage *relative to the attacker-manipulated price*, not the fair market price — the classic "quote-and-swap-from-the-same-AMM" oracle manipulation pattern.

### Impact Explanation
An attacker who is also the recipient of an inbound `GAS`/`GAS_AND_PAYLOAD` deposit (or who colludes with/targets one) can:
1. Distort the WPC/PRC20 pool price just before the vote-finalization tx that triggers `ExecuteInboundGas`/`ExecuteInboundGasAndPayload` executes (these run synchronously inside `MsgVoteInbound` processing once quorum is reached, in an ordinary, observable Cosmos/EVM block).
2. Cause `GetSwapQuote` to return an inflated quote, so `minPCOut` is set relative to the manipulated price.
3. Have the module's real swap execute at that same distorted price, extracting value from the pool's other liquidity (or from `UniversalCore`'s reserves used for the auto-swap) — a net fund drain / mispriced accounting on `CallPRC20DepositAutoSwap`/`CallUniversalCoreRefundUnusedGas`.

This corrupts PRC20-to-native accounting and can result in unauthorized value extraction on every gas-abstraction deposit and gas refund, matching "corruption of PRC20 or native asset accounting" and "loss of protocol/user funds" in the allowed-impact list.

### Likelihood Explanation
Medium-High. The WPC/PRC20 pools are ordinary, permissionless Uniswap V3 pools reachable by any unprivileged user; MsgVoteInbound/MsgVoteOutbound transactions (and thus the timing of the swap) are visible in the public mempool/finalization flow, giving an attacker a predictable execution window to manipulate price beforehand. No privileged role, validator collusion, or external chain compromise is required — only ordinary swap transactions on Push Chain plus a normal cross-chain deposit.

### Recommendation
- Do not derive `minPCOut` from the same pool that will execute the swap. Use a manipulation-resistant reference (TWAP over a sufficient window, an external price oracle, or a governance/keeper-set floor) independent of the immediately-preceding spot price.
- Alternatively/additionally, cap the maximum price deviation allowed between consecutive blocks/quotes for the pools used in `GetSwapQuote`, and/or route auto-swaps through pools with circuit breakers against large single-block price impact.
- Consider widening the observation window between quote and swap execution enough to require the manipulation to persist across a market-observable interval, or use `quote * (1 - slippage)` combined with a sanity bound against a slower-moving reference price.

### Proof of Concept
1. Attacker identifies a pending inbound `GAS` deposit routed to their own UEA (or front-runs a victim's pending inbound whose outbound/refund benefits the attacker's controlled recipient).
2. Attacker submits an ordinary large one-sided swap against the WPC/PRC20 Uniswap V3 pool used by `GetUniversalCoreQuoterAddress`/`GetUniversalCoreWPCAddress`, moving the spot price so that a `PRC20`→`WPC` quote will return an inflated value.
3. When the `MsgVoteInbound` quorum-triggering vote lands and `ExecuteInboundGas` runs (`x/uexecutor/keeper/execute_inbound_gas.go:104-153`), `GetSwapQuote` reads the now-distorted spot price and computes `minPCOut = quote*95/100` off of it.
4. `CallPRC20DepositAutoSwap` executes the swap against the still-distorted pool, paying out WPC to the attacker's UEA at the manipulated (favorable-to-attacker) rate, while the pool/`UniversalCore` reserves absorb the loss.
5. Attacker reverses their initial swap in a following transaction, realizing the extracted value, net of pool fees.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}
