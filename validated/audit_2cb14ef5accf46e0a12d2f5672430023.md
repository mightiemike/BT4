### Title
Starknet OS `execute_replace_class` accepts undeclared/incompatible class hashes without validation, diverging from Blockifier's `replace_class` syscall check - ([File: crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo])

### Summary
The Cairo Starknet OS implementation of the `replace_class` syscall writes an attacker-supplied `class_hash` directly into a contract's state entry with **no validation** that the class is declared or of the correct Cairo version, while the Rust Blockifier's implementation of the same syscall enforces both checks before mutating state.

### Finding Description
Any deployed contract can invoke the `replace_class` syscall (reachable from any unprivileged transaction sender via `__execute__`) to change its own class hash, as shown in the feature contract test helper `test_replace_class` which simply calls `replace_class_syscall(class_hash)` [1](#0-0) .

In the Rust execution engine (Blockifier), `SyscallHandlerBase::replace_class` explicitly validates the target class before applying the state change: it ensures the class is declared via `get_compiled_class`, and rejects the change with `ForbiddenClassReplacement` if the class is not Cairo1 (V1): [2](#0-1) 

This is confirmed by tests: an undeclared class hash produces `"is not declared"`, and a Cairo0 class hash produces `"Cannot replace V1 class hash with V0 class hash"`: [3](#0-2) 

However, the Starknet OS's Cairo implementation of the identical syscall, `execute_replace_class` in `syscall_impls.cairo`, performs **no such check**. It reads the requested `class_hash` and unconditionally overwrites the contract's `StateEntry`, with an explicit TODO acknowledging the missing validation: [4](#0-3) 

The same unguarded pattern exists in the deprecated syscalls path used for older Cairo0 contracts: [5](#0-4) 

The Starknet OS is the reference execution used for block re-execution, state commitment, and proof generation — it must reproduce the exact same accept/reject decisions and resulting state diffs as the Blockifier that actually built the block. Since the OS's `execute_replace_class` unconditionally accepts any `class_hash` (including undeclared or Cairo0-incompatible ones) that the Blockifier would reject/revert, the two execution engines can produce different outcomes for the same transaction: Blockifier reverts the call (no state change, possibly whole-transaction revert depending on call context) while the OS proceeds to record a state change setting the contract's class hash to an arbitrary/undeclared value.

### Impact Explanation
This produces a **wrong committed root / honest-node divergence**: the OS-computed state diff and its Patricia-tree commitment can disagree with the actual state transition enforced and produced by the Blockifier for the same block/transaction, since the OS omits a mandatory-in-Blockifier check. A divergence between the trusted, network-agreed execution semantics (Blockifier) and the proof-generating re-execution (Starknet OS) undermines the guarantee that the STARK proof attests to the state transition that was actually applied to the chain — a correctness/soundness break in state commitment for a widely reachable, ordinary externally-callable syscall (`replace_class`), not requiring any privilege beyond deploying/calling a Cairo1 contract.

### Likelihood Explanation
High likelihood of being triggered unintentionally, and trivially triggerable intentionally: any account or contract can call `replace_class_syscall` with an arbitrary felt as `class_hash` (undeclared, zero, or a Cairo0 class hash) as part of ordinary contract logic. No special permissions, staking, or privileged role is required — this is reachable from a single unprivileged L2 transaction.

### Recommendation
Add the same validation to the Starknet OS's `execute_replace_class` (and the deprecated-syscalls equivalent) that Blockifier enforces:
1. Verify the target `class_hash` corresponds to a declared class (mirroring `get_compiled_class` check).
2. Verify the class is of the expected version (reject Cairo0/V0 class hashes for the new-syscalls `replace_class`, matching `is_cairo1` in `syscall_base.rs`).
3. On failure, revert the syscall/transaction in the same manner Blockifier does, so state diffs produced by the OS and by Blockifier are guaranteed to match for every possible input.

### Proof of Concept
1. A user deploys any Cairo1 contract exposing a `replace_class`-invoking entry point (e.g., `test_replace_class` as in the feature contracts).
2. The user submits an `INVOKE` transaction calling that entry point with an undeclared or Cairo0 `class_hash`.
3. In Blockifier (actual sequencer execution), `SyscallHandlerBase::replace_class` rejects this with `is not declared` or `ForbiddenClassReplacement`, causing the call (and likely transaction) to fail — no class-hash state change is recorded.
4. If the same syscall trace were independently re-derived/re-executed through the Starknet OS `execute_replace_class` path (used for state commitment/proof), the missing check (per the explicit `TODO(Yoni, 1/1/2026)` comment) means the OS logic itself does not reject this input and would record the new (invalid) class hash into `contract_state_changes`, i.e., a different outcome than Blockifier's authoritative decision for the identical syscall request.

    pub fn replace_class(&mut self, class_hash: ClassHash) -> SyscallResult<()> {
        // Ensure the class is declared (by reading it), and of type V1.
        let compiled_class = self.state.get_compiled_class(class_hash)?;

        if !is_cairo1(&compiled_class) {
            return Err(SyscallExecutionError::ForbiddenClassReplacement { class_hash });
        }
        self.state.set_class_hash_at(self.call.storage_address, class_hash)?;
        Ok(())
    }

// Replaces the class.
func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
