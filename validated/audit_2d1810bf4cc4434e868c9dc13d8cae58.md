### Title
`CalculateGasCost` floors the EIP-1559 base fee to whole `upc` before multiplying by `gasUsed`, systematically under-charging gas fees on every UEA payload execution - (File: `x/uexecutor/keeper/fees.go`)

### Summary
`CalculateGasCost` in `x/uexecutor/keeper/fees.go` converts the feemarket's `LegacyDec` base fee into a `*big.Int` by doing `baseFeeBig.Div(baseFeeBig, big.NewInt(1e18))` *before* multiplying by `gasUsed`. This is analogous to the Rubicon `_borrowLimit` bug: an early, unrounded-up division discards fractional precision, and that discarded fraction gets amplified once multiplied by a large scalar (`gasUsed`, up to millions for `MsgExecutePayload`/UEA-routed calls), rather than being multiplied first and rounded once at the end.

### Finding Description
`CalculateGasCost` (`x/uexecutor/keeper/fees.go:47-91`) computes:

```go
baseFeeBig := baseFee.BigInt()
baseFeeBig.Div(baseFeeBig, big.NewInt(1e18))   // floor to whole upc
...
gasCost := new(big.Int).Mul(effectiveGasPrice, gasUsedBig)  // then scale by gasUsed
```

The in-line comment asserts "the base fee is always a whole number of upc -- no fractional upc exists," but this is only true if the feemarket module's `BaseFee` state is *always* re-quantized to a whole `upc` on every block update. The feemarket AIMD/EIP-1559 base-fee-adjustment arithmetic (`cosmos/evm` dependency, out of this repo's own source) operates in `LegacyDec` with 18-decimal precision and there is nothing in the scoped Push code that guarantees the stored base fee never carries a genuine sub-`upc` fractional component after successive per-block adjustments. If it does, `Div` floors that fraction away at the *price-per-gas-unit* level, and the loss is then multiplied by `gasUsed` in `DeductGasFeesFromReceipt` (`x/uexecutor/keeper/fees.go:97-148`), which is reachable from ordinary, unprivileged UEA payload execution (`ExecutePayloadV2` / `MsgExecutePayload`, `x/uexecutor/keeper/execute_payload.go`, `execute_inbound_funds_and_payload.go`, `execute_inbound_gas_and_payload.go`).

This mirrors the root cause of the external report: an unrounded (here, floor rather than Rubicon's `wmul`) computation performed on a per-unit rate, followed by multiplication with a scaling factor, causes the effective outcome (borrowed amount / gas fee charged) to diverge materially from the intended value.

### Impact Explanation
If exploitable, the effect is a systematic under-collection of gas fees relative to the true EIP-1559 price for every EVM call routed through `ExecutePayloadV2`, which corresponds to "corruption of ... gas fee accounting" explicitly listed as in-scope impact. Because `DeductAndBurnFees` burns exactly the (under-computed) `gasCost`, this represents a small but compounding deflationary shortfall — value that should be burned per the protocol's fee model is not, functioning as a systemic economic leak rather than a direct fund drain from any specific victim.

### Likelihood Explanation
I could not confirm from the code available in this repository whether the feemarket's stored `BaseFee` can actually hold a genuine sub-`upc` fractional value in production — the feemarket base-fee update logic lives in the external `cosmos/evm` dependency, not in this repository's own scoped source (`x/`, `universalClient/`, `precompiles/usigverifier/`, ante). I was unable to locate `CalculateBaseFee`/`BaseFeeChangeDenominator` logic in this repo to verify whether the value is re-quantized to a whole `upc` on each block, which the in-line `@dev` comment claims as an invariant. Without that confirmation, likelihood is uncertain: if the invariant genuinely holds (base fee is always re-floored to a whole `upc` by the fork before being exposed via `GetBaseFee`), this finding does not manifest, and existing guards would preserve the invariant, making this a non-issue. Given the dependency-only nature of the piece needed to confirm exploitability, and per the out-of-scope rule for "dependency-only behavior," I cannot assert this as a proven, reachable root cause within this repository alone.

### Recommendation
If the feemarket base fee can carry sub-`upc` precision, compute `gasCost` by multiplying `gasUsed` against the *unrounded* Dec base fee (or against `maxFeePerGas`/effective price) first, and floor/round only the final `gasCost` result, mirroring the "round up" mitigation recommended in the original report (round at the last step, not at an intermediate per-unit step). Additionally, remove or verify the `@dev` comment's invariant claim by asserting (with an explicit check/test) that `baseFee` modulo `1e18` is always zero before relying on it, and fail loudly (rather than silently truncate) if that invariant is ever violated.

### Proof of Concept
I could not construct a concrete, reproducible PoC because verifying the actual range of values `feemarketKeeper.GetBaseFee` can return (whole vs. fractional `upc`) requires inspecting the external `cosmos/evm` feemarket base-fee-adjustment implementation, which is not part of this repository's indexed/scoped source and thus outside what I can confirm here. A deterministic PoC would require: (1) confirming the feemarket base fee formula/state representation, (2) driving several blocks of gas-used/gas-target imbalance to produce a fractional base fee, and (3) submitting a `MsgExecutePayload` with a large `gasUsed` to observe the discrepancy between the EIP-1559-intended fee and the actual burned `gasCost`. func (k Keeper) CalculateGasCost(
	baseFee sdkmath.LegacyDec,
	maxFeePerGas *big.Int,
	maxPriorityFeePerGas *big.Int,
	gasUsed uint64,
) (*big.Int, error) {
	baseFeeBig := baseFee.BigInt()
	// @dev: LegacyDec stores values with 18-decimal precision internally, so 1 upc = 1e18
	// in the LegacyDec representation. Since 1 upc is the smallest denomination (like wei
	// in Ethereum), the base fee is always a whole number of upc -- no fractional upc exists.
	// This division unwraps the LegacyDec encoding back to the actual upc amount.
	// Note: baseFee.BigInt() returns a reference to the internal big.Int; the in-place Div
	// mutates it, which is safe here since baseFee is a local value-type copy.
	baseFeeBig.Div(baseFeeBig, big.NewInt(1e18))

	// Step 1: Validate maxFeePerGas >= baseFee
	if maxFeePerGas.Cmp(baseFeeBig) < 0 {
		return nil, fmt.Errorf("maxFeePerGas (%s) cannot be less than baseFee (%s)", maxFeePerGas, baseFeeBig)
	}

	// Step 2: Calculate baseFee + maxPriorityFeePerGas (potential effective gas price)
	// @dev: Currently, we are not using maxPriorityFeePerGas in the calculation
	// tipPlusBase := new(big.Int).Add(baseFeeBig, maxPriorityFeePerGas)
	// tipPlusBase := maxFeePerGas

	// Step 3: Find effective gas price by taking minimum
	// @dev: Currently, since we are not using maxPriorityFeePerGas, effectiveGasPrice is just baseFee
	effectiveGasPrice := new(big.Int).Set(baseFeeBig)
	// if tipPlusBase.Cmp(maxFeePerGas) == -1 {
	// 	effectiveGasPrice = tipPlusBase
	// }

	// Step 4: Calculate final gas cost: effectiveGasPrice * gasUsed
	gasUsedBig := new(big.Int).SetUint64(gasUsed)
	gasCost := new(big.Int).Mul(effectiveGasPrice, gasUsedBig)

	k.Logger().Debug("gas cost calculated",
		"base_fee", baseFee.String(),
		"effective_gas_price", effectiveGasPrice.String(),
		"gas_used", gasUsed,
		"gas_cost", gasCost.String(),
	)

	return gasCost, nil
}

func (k Keeper) DeductGasFeesFromReceipt(
	ctx context.Context,
	sdkCtx sdk.Context,
	recipient common.Address,
	receipt *evmtypes.MsgEthereumTxResponse,
	universalPayload *types.UniversalPayload,
) error {
	if receipt == nil || receipt.GasUsed == 0 {
		return nil
	}
	if universalPayload == nil {
		return nil
	}

	abiPayload, err := types.NewAbiUniversalPayload(universalPayload)
	if err != nil {
		return fmt.Errorf("failed to parse payload for gas deduction: %w", err)
	}

	baseFee := k.feemarketKeeper.GetBaseFee(sdkCtx)
	if baseFee.IsNil() {
		return fmt.Errorf("base fee not found")
	}

	gasCost, err := k.CalculateGasCost(baseFee, abiPayload.MaxFeePerGas, abiPayload.MaxPriorityFeePerGas, receipt.GasUsed)
	if err != nil {
		return fmt.Errorf("failed to calculate gas cost: %w", err)
	}
	if gasCost.Sign() <= 0 {
		return nil
	}

	gasUsedBig := new(big.Int).SetUint64(receipt.GasUsed)
	if gasUsedBig.Cmp(abiPayload.GasLimit) > 0 {
		return fmt.Errorf("gas used (%d) exceeds gas limit (%s)", receipt.GasUsed, abiPayload.GasLimit.String())
	}

	recipientAccAddr := sdk.AccAddress(recipient.Bytes())
	balance := k.bankKeeper.GetBalance(sdkCtx, recipientAccAddr, pchaintypes.BaseDenom)

	if err := k.DeductAndBurnFees(ctx, recipientAccAddr, gasCost); err != nil {
		return fmt.Errorf("insufficient gas: required %s upc, available %s upc, gas_used %d, from %s: %w",
			gasCost.String(), balance.Amount.String(), receipt.GasUsed, recipient.Hex(), err)
	}

	k.Logger().Debug("gas fees deducted",
		"recipient", recipient.Hex(),
		"gas_used", receipt.GasUsed,
		"gas_cost", gasCost.String(),
	)
	return nil
}
