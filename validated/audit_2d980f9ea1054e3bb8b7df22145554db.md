### Title
Uncaught `TypeError` from `new URL()` in `sanitizeHost` causes unhandled exception/500 in embedded-app auth path - ([File: packages/apps/shopify-api/lib/utils/shop-validator.ts])

### Summary
`sanitizeHost` validates the `host` query parameter only with a shallow base64-character regex before decoding it and passing it directly into `new URL(\`https://${decodedHost}\`)`. The base64 regex does not guarantee the decoded value is a syntactically valid URL authority, so a crafted `host` value can decode into a string that makes the native `URL` constructor throw a `TypeError`, which is not caught anywhere in `sanitizeHost` or in its callers (`getEmbeddedAppUrl`/`buildEmbeddedAppUrl`, `redirectToShopifyOrAppRoot` in Express/Remix/React Router).

### Finding Description
`sanitizeHost` in [1](#0-0)  only checks `base64regex.test(host)` (`/^[0-9a-zA-Z+/]+={0,2}$/`) before calling `decodeHost(sanitizedHost)` (a thin wrapper around `atob`, [2](#0-1) ) and immediately constructing `new URL(\`https://${decodeHost(...)}\`)` with no try/catch. Because base64 characters can decode into arbitrary bytes/text, an attacker can choose a base64 string whose decoded content is not a valid authority component (e.g., decodes to a string with multiple/invalid colons, control characters, or other WHATWG-URL-invalid host syntax such as `':::garbage:::'`). The WHATWG URL parser throws a `TypeError` for such malformed authorities for `https:` (a special scheme requiring a non-empty valid host), and that exception propagates unhandled out of `sanitizeHost` (no try/catch exists in the function). This directly affects all call sites that invoke `sanitizeHost`/`getEmbeddedAppUrl` without wrapping in their own try/catch, including `buildEmbeddedAppUrl`/`getEmbeddedAppUrl` ( [3](#0-2) ), Express's `redirectToShopifyOrAppRoot` ( [4](#0-3) ), and the Remix equivalent ( [5](#0-4) , and `validateShopAndHostParams` at [6](#0-5) ). The attacker fully controls the `host` query parameter on an anonymous request to an embedded-admin route, requires no secret, and no privileged role. Existing tests only cover base64-decodable strings that still form syntactically valid hostnames (e.g. `plain-string-is-not-base64` fails the regex test itself, not the URL-parsing step) — see [7](#0-6)  — so this crash path is not exercised or guarded against.

### Impact Explanation
Any anonymous request to an embedded-admin route (or any endpoint that calls `sanitizeHost`/`getEmbeddedAppUrl`) with a crafted `host` parameter can trigger an unhandled exception in the request-authentication path of any app built on this library, causing an unhandled server error (potential process crash or unhandled promise rejection depending on the host framework's error handling), which matches a DoS-in-authentication-handler impact class.

### Likelihood Explanation
Low complexity, no authentication or secrets needed — a single crafted GET request to any embedded route with `?host=<base64 of malformed authority>` is sufficient, and is fully repeatable/scriptable by an anonymous attacker.

### Recommendation
Wrap the `new URL(...)` construction in `sanitizeHost` in a try/catch, returning `null` (or throwing `InvalidHostError` when `throwOnInvalid` is set) on any parse failure, consistent with how `sanitizeShop` never lets a native exception escape.

export function getEmbeddedAppUrl(config: ConfigInterface): GetEmbeddedAppUrl {
  return async ({...adapterArgs}: GetEmbeddedAppUrlParams): Promise<string> => {
    const request = await abstractConvertRequest(adapterArgs);

    if (!request) {
      throw new ShopifyErrors.MissingRequiredArgument(
        'getEmbeddedAppUrl requires a request object argument',
      );
    }

    if (!request.url) {
      throw new ShopifyErrors.InvalidRequestError(
        'Request does not contain a URL',
      );
    }

    const url = new URL(request.url, `https://${request.headers.host}`);
    const host = url.searchParams.get('host');

    if (typeof host !== 'string') {
      throw new ShopifyErrors.InvalidRequestError(
        'Request does not contain a host query parameter',
      );
    }

    return buildEmbeddedAppUrl(config)(host);
  };
}

export async function redirectToShopifyOrAppRoot(
  request: Request,
  params: BasicParams,
  responseHeaders?: Headers,
): Promise<never> {
  const {api} = params;
  const url = new URL(request.url);

  const host = api.utils.sanitizeHost(url.searchParams.get('host')!)!;
  const shop = api.utils.sanitizeShop(url.searchParams.get('shop')!)!;

  const redirectUrl = api.config.isEmbeddedApp
    ? await api.auth.getEmbeddedAppUrl({rawRequest: request})
    : `/?shop=${shop}&host=${encodeURIComponent(host)}`;

  throw redirect(redirectUrl, {headers: responseHeaders});
