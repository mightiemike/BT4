### Title
Fast-forward relay authentication signature has no expiration/replay protection allowing indefinite impersonation of a witness node's trusted relay handshake - (File: `framework/src/main/java/org/tron/core/net/service/relay/RelayService.java`)

### Summary
The external report describes `NodeRegistry.registerNodeFor()` accepting a signature over data that lacks a `registryID`/contract-address binding and an expiration timestamp, allowing that signed message to be replayed indefinitely against other contracts/chains. The closest reachable analog in java-tron is the fast-forward relay handshake authentication in `RelayService`, where a witness signs a bare timestamp with no domain separation (no genesis block id / peer / purpose binding) and no server-side freshness check, so a captured `(address, timestamp, signature)` tuple can be replayed forever to gain "trusted node" status for an arbitrary IP.

### Finding Description
When fast-forward mode is enabled, a witness signs `Sha256Hash(timestamp)` with its private key and attaches it to the `HelloMessage`: [1](#0-0) 

The verifying side, `checkHelloMessage`, recovers the address from `Sha256Hash(timestamp)` + signature and, if it matches an active witness (or its multisig witness-permission address), adds the connecting peer's IP to `trustNodes`: [2](#0-1) 

The signed payload is only `ByteArray.fromLong(timestamp)` — it does not include the genesis block id/chain identifier, the receiving peer's address/channel, or any nonce, and `checkHelloMessage` never checks that `msg.getTimestamp()` is close to the verifier's current time. The only other validations performed before/after this check (`HandshakeService.processHelloMessage`) are unrelated to the signature's freshness — they check `msg.valid()` (structural/length checks), genesis block id equality, and solid/head block relationships, none of which bind or expire the *signature* itself: [3](#0-2) 

Because the timestamp is attacker-controlled input embedded in the message (the attacker simply replays a captured `HelloMessage` with the same encoded timestamp value it was originally signed with), any adversary who observes a single legitimate witness handshake message can resend that exact same `(timestamp, signature, address)` triple from a different TCP connection/IP at any later point. `checkHelloMessage` will independently re-derive the same hash and recover the same witness address, and will add the attacker's own channel IP to `trustNodes` on the assumption that the connecting party controls the witness key — exactly the "no `registryID`/domain, no expiration" replay pattern described in the report.

### Impact Explanation
Being added to `trustNodes` lets an attacker's IP be treated as a trusted relay/fast-forward peer by `TronNetService`, which is used to influence P2P trust/allow-list behavior. An attacker who is any unprivileged network participant (does not need the witness private key, only the ability to observe one prior handshake, e.g. by connecting to the witness's fast-forward peer set or sniffing an unencrypted/observable exchange) can obtain trusted-peer status indefinitely, since the signed data never expires and is not bound to the connection it was created for. This is an authentication/authorization-bypass primitive on the P2P trust boundary, matching the report's "no replay protection and no expiration" bug class, though the downstream blast radius is limited to P2P peer-trust bookkeeping rather than funds/consensus state directly.

### Likelihood Explanation
Exploitation requires observing exactly one legitimate `HelloMessage` handshake exchange from an active witness's fast-forward relay flow (this traffic is not authenticated confidentiality-wise beyond the P2P transport, and fast-forward nodes are specifically configured relay peers that a network observer could target). Once captured, replay is trivial — no cryptographic work, no time-window bypass needed, since there is no time-window check at all. This makes the likelihood moderate: it depends on this feature (`isFastForward`) being enabled and on the attacker having network visibility into a witness's relay handshake, but once those conditions hold, exploitation is straightforward and repeatable indefinitely.

### Recommendation
Bind the signed payload to a domain separator including the genesis/chain id and the specific channel/peer identity (e.g., include `genesisBlockId`, the receiving peer's node id, and/or a per-connection nonce in the hash signed in `fillHelloMessage`), and enforce a strict freshness window for `msg.getTimestamp()` in `checkHelloMessage` (reject if too far from the verifier's local time), mirroring the report's recommendation to include a registry/chain identifier and an expiration check validated on-chain (here, at message-verification time).

### Proof of Concept
1. Enable fast-forward mode on a victim node (`isFastForward()==true`) that peers with an active witness's fast-forward node.
2. Attacker observes/captures a legitimate `HelloMessage` sent by the witness to the fast-forward peer, containing `{address, timestamp, signature}` produced by `fillHelloMessage`.
3. Attacker opens a new connection to the victim node from a different IP and resends the identical `HelloMessage` bytes (same `timestamp`/`signature`/`address` fields) as part of its own handshake.
4. In `RelayService.checkHelloMessage`, `Sha256Hash.of(timestamp)` is recomputed identically, `SignUtils.signatureToAddress` recovers the same witness address, `witnessScheduleStore.getActiveWitnesses().contains(msg.getAddress())` still passes (witness schedule unaffected), and no timestamp-freshness check exists — so `flag=true` and the attacker's new IP (`channel.getInetAddress()`) is added to `TronNetService.getP2pConfig().getTrustNodes()`, granting it trusted-peer status without ever possessing the witness's private key.

  public void fillHelloMessage(HelloMessage message, Channel channel) {
    if (isActiveWitness()) {
      fastForwardNodes.forEach(address -> {
        if (address.getAddress().equals(channel.getInetAddress())) {
          SignInterface cryptoEngine = SignUtils
              .fromPrivate(ByteArray.fromHexString(Args.getLocalWitnesses().getPrivateKey()),
                  Args.getInstance().isECKeyCryptoEngine());

          ByteString sig = ByteString.copyFrom(cryptoEngine.Base64toBytes(cryptoEngine
              .signHash(Sha256Hash.of(CommonParameter.getInstance()
                  .isECKeyCryptoEngine(), ByteArray.fromLong(message
                  .getTimestamp())).getBytes())));
          message.setHelloMessage(message.getHelloMessage().toBuilder()
              .setAddress(witnessAddress).setSignature(sig).build());
        }
      });
    }
  }

  public boolean checkHelloMessage(HelloMessage message, Channel channel) {
    if (!parameter.isFastForward()) {
      return true;
    }

    Protocol.HelloMessage msg = message.getHelloMessage();

    if (msg.getAddress() == null || msg.getAddress().isEmpty()) {
      logger.info("HelloMessage from {}, address is empty.", channel.getInetAddress());
      return false;
    }

    if (!witnessScheduleStore.getActiveWitnesses().contains(msg.getAddress())) {
      logger.warn("HelloMessage from {}, {} is not a schedule witness.",
          channel.getInetAddress(),
          ByteArray.toHexString(msg.getAddress().toByteArray()));
      return false;
    }

    if (getPeerCountByAddress(msg.getAddress()) > MAX_PEER_COUNT_PER_ADDRESS) {
      logger.warn("HelloMessage from {}, the number of peers of {} exceeds {}.",
          channel.getInetAddress(),
          ByteArray.toHexString(msg.getAddress().toByteArray()),
          MAX_PEER_COUNT_PER_ADDRESS);
      return false;
    }

    if (!SignUtils.isValidLength(msg.getSignature().size())) {
      logger.warn("HelloMessage from {}, signature size is {}.",
          channel.getInetAddress(), msg.getSignature().size());
      return false;
    }

    boolean flag;
    try {
      Sha256Hash hash = Sha256Hash.of(CommonParameter
          .getInstance().isECKeyCryptoEngine(), ByteArray.fromLong(msg.getTimestamp()));
      String sig =
          TransactionCapsule.getBase64FromByteString(msg.getSignature());
      byte[] sigAddress = SignUtils.signatureToAddress(hash.getBytes(), sig,
          Args.getInstance().isECKeyCryptoEngine());
      if (manager.getDynamicPropertiesStore().getAllowMultiSign() != 1) {
        flag = Arrays.equals(sigAddress, msg.getAddress().toByteArray());
      } else {
        byte[] witnessPermissionAddress = manager.getAccountStore()
            .get(msg.getAddress().toByteArray()).getWitnessPermissionAddress();
        flag = Arrays.equals(sigAddress, witnessPermissionAddress);
      }
      if (flag) {
        TronNetService.getP2pConfig().getTrustNodes().add(channel.getInetAddress());
        DesensitizedConverter.addSensitive(channel.getInetAddress().toString().substring(1),
            ByteArray.toHexString(msg.getAddress().toByteArray()));
      }
      return flag;
    } catch (Exception e) {
      logger.error("Check hello message failed, msg: {}, {}", message, channel.getInetAddress(), e);
      return false;
    }
  }

  public void processHelloMessage(PeerConnection peer, HelloMessage msg) {
    if (peer.getHelloMessageReceive() != null) {
      logger.warn("Peer {} receive dup hello message", peer.getInetSocketAddress());
      peer.disconnect(ReasonCode.BAD_PROTOCOL);
      return;
    }

    TronNetService.getP2pService().updateNodeId(peer.getChannel(), msg.getFrom().getHexId());
    if (peer.isDisconnect()) {
      logger.info("Duplicate Peer {}", peer.getInetSocketAddress());
      peer.disconnect(ReasonCode.DUPLICATE_PEER);
      return;
    }

    if (!msg.valid()) {
      logger.warn("Peer {} invalid hello message parameters, GenesisBlockId: {}, SolidBlockId: {}, "
              + "HeadBlockId: {}, address: {}, sig: {}, codeVersion: {}",
          peer.getInetSocketAddress(),
          ByteArray.toHexString(msg.getInstance().getGenesisBlockId().getHash().toByteArray()),
          ByteArray.toHexString(msg.getInstance().getSolidBlockId().getHash().toByteArray()),
          ByteArray.toHexString(msg.getInstance().getHeadBlockId().getHash().toByteArray()),
          msg.getInstance().getAddress().toByteArray().length,
          msg.getInstance().getSignature().toByteArray().length,
          msg.getInstance().getCodeVersion().toByteArray().length);
      peer.disconnect(ReasonCode.INCOMPATIBLE_PROTOCOL);
      return;
    }

    peer.setAddress(msg.getHelloMessage().getAddress());

    if (!relayService.checkHelloMessage(msg, peer.getChannel())) {
      peer.disconnect(ReasonCode.UNEXPECTED_IDENTITY);
      return;
    }

    long headBlockNum = chainBaseManager.getHeadBlockNum();
    long lowestBlockNum = msg.getLowestBlockNum();
    if (lowestBlockNum > headBlockNum) {
      logger.info("Peer {} miss block, lowestBlockNum:{}, headBlockNum:{}",
              peer.getInetSocketAddress(), lowestBlockNum, headBlockNum);
      peer.disconnect(ReasonCode.LIGHT_NODE_SYNC_FAIL);
      return;
    }

    if (msg.getVersion() != Args.getInstance().getNodeP2pVersion()) {
      logger.info("Peer {} different p2p version, peer->{}, me->{}",
              peer.getInetSocketAddress(), msg.getVersion(),
              Args.getInstance().getNodeP2pVersion());
      peer.disconnect(ReasonCode.INCOMPATIBLE_VERSION);
      return;
    }

    if (!Arrays.equals(chainBaseManager.getGenesisBlockId().getBytes(),
            msg.getGenesisBlockId().getBytes())) {
      logger.info("Peer {} different genesis block, peer->{}, me->{}",
              peer.getInetSocketAddress(),
              msg.getGenesisBlockId().getString(),
              chainBaseManager.getGenesisBlockId().getString());
      peer.disconnect(ReasonCode.INCOMPATIBLE_CHAIN);
      return;
    }
