This is a genuine, reachable "division-before-multiplication" precision bug in `x/uexecutor/keeper/fees.go`'s `CalculateGasCost`, matching the reported bug class. It's triggered by any ordinary user's `MsgExecutePayload`/inbound gas-and-payload flow (no privilege required), and it systematically undercharges the burned gas fee whenever the feemarket's dynamically-adjusted `baseFee` (an `EIP-1559`-style `LegacyDec`, which is not guaranteed to be an exact multiple of `1e18`) carries a fractional upc component.

### Title
Gas fee undercharging via division-before-multiplication in `CalculateGasCost` - (File: x/uexecutor/keeper/fees.go)

### Summary
`Keeper.CalculateGasCost` truncates the dynamic `baseFee` (an 18-decimal `LegacyDec`) down to a whole `upc` integer *before* multiplying by `gasUsed`, instead of multiplying first and rounding once at the end. This is the same "division/truncation before multiplication" defect described in the referenced Ajna finding, applied here to Push Chain's gas-fee burn accounting.

### Finding Description [1](#0-0) 

```
baseFeeBig := baseFee.BigInt()
// @dev: ... the base fee is always a whole number of upc -- no fractional upc exists.
baseFeeBig.Div(baseFeeBig, big.NewInt(1e18))
```

`baseFee` comes from `k.feemarketKeeper.GetBaseFee(sdkCtx)` [2](#0-1)  — the feemarket module's EIP-1559-style base fee, adjusted every block based on gas-used deltas relative to a target. That adjustment produces a `LegacyDec` value (18-decimal fixed point) which is not guaranteed to be an exact whole `upc`; the code's own comment simply *asserts* this invariant without any enforcement in the type system or in the feemarket module (an external `cosmos/evm` dependency), so it is not a validated guarantee.

The function then does:
```
effectiveGasPrice := new(big.Int).Set(baseFeeBig)          // already floor(baseFee)
gasCost := new(big.Int).Mul(effectiveGasPrice, gasUsedBig) // floor(baseFee) * gasUsed
```
instead of the precision-preserving order:
```
gasCost = floor(baseFee_full_precision * gasUsed)
```

Any fractional-upc component of `baseFee` (e.g. `1.5` upc/gas) is discarded *before* scaling by `gasUsed`, rather than being scaled first and rounded once. Since `gasUsed` can be large (up to the tx gas limit), this converts a small per-gas-unit rounding error into a proportionally large absolute undercharge.

Example: `baseFee = 1.9` upc/gas, `gasUsed = 1,000,000`.
- Correct: `floor(1.9 × 1,000,000) = 1,900,000` upc burned.
- Current code: `floor(1.9) × 1,000,000 = 1 × 1,000,000 = 1,000,000` upc burned — a 47% undercharge.

`DeductGasFeesFromReceipt` uses this result directly to burn coins from the payload sender via `DeductAndBurnFees` [3](#0-2) , so the shortfall is a systemic and reproducible reduction in the amount of `upc` burned per universal-payload execution, reachable by every ordinary inbound-with-payload transaction (`ExecuteInboundGasAndPayload`, `execute_payload.go`, etc.) — no privileged role needed.

### Impact Explanation
This corrupts gas-fee/burn accounting for the universal-execution flow: users (or an attacker crafting/timing transactions when `baseFee` has a fractional component) will be systematically undercharged relative to the fee mechanism's design, meaning less `upc` is burned than the EIP-1559 formula intends. This falls under the in-scope impact "corruption of ... gas fee accounting ... or canonical UniversalTx state," since `DeductGasFeesFromReceipt` is invoked on the standard payload-execution path with no attacker privilege required.

### Likelihood Explanation
Likelihood depends on whether `feemarketKeeper.GetBaseFee` in practice ever returns a non-integer-upc value; this can only happen when the block-to-block base-fee adjustment (percentage-based, using `LegacyDec` division) does not happen to land on an exact multiple of `1e18`, which is the generic/expected case for a continuously adjusting EIP-1559 base fee rather than the exception. The code's own inline comment acknowledges this is an assumption, not a proven invariant of the (external) feemarket module.

### Recommendation
Do not strip the fractional-upc precision from `baseFee` before multiplying. Compute `gasCost` using the full-precision `LegacyDec` (or its underlying big.Int scaled by `1e18`) multiplied by `gasUsed` first, and only then divide/round down by `1e18` once, e.g.:
```go
gasCostDec := baseFee.MulInt64(int64(gasUsed))     // full precision
gasCost := gasCostDec.QuoInt64(1e18).TruncateInt().BigInt()
```
or equivalently perform the multiplication on the raw (unscaled) big.Int representation before the final single division by `1e18`.

### Proof of Concept
1. Set feemarket `baseFee` to a non-integer-upc value, e.g. `1_900_000_000_000_000_000 + 500_000_000_000_000_000` upc-scaled (`1.5` upc/gas) via `app.FeeMarketKeeper.SetBaseFee`.
2. Execute an inbound gas-and-payload transaction with `gasUsed = 1,000,000`.
3. Observe `CalculateGasCost` returns `1,000,000` upc burned instead of the mathematically correct `1,500,000` upc, confirmed by comparing `DeductAndBurnFees` amount to `baseFee.MulInt64(gasUsed).TruncateInt()`. [4](#0-3)

// CalculateGasCost calculates the gas cost based on EIP-1559 fee mechanism:
// 1. Effective Gas Price = min(maxFeePerGas, baseFee + maxPriorityFeePerGas)
// 2. Total Fee = gasUsed × Effective Gas Price
// Parameters:
// - baseFee: current network base fee
// - maxFeePerGas: maximum total fee user is willing to pay
// - maxPriorityFeePerGas: maximum tip to validator
// - gasUsed: amount of gas consumed
func (k Keeper) CalculateGasCost(
	baseFee sdkmath.LegacyDec,
	maxFeePerGas *big.Int,
	maxPriorityFeePerGas *big.Int,
	gasUsed uint64,
) (*big.Int, error) {
	baseFeeBig := baseFee.BigInt()
	// @dev: LegacyDec stores values with 18-decimal precision internally, so 1 upc = 1e18
	// in the LegacyDec representation. Since 1 upc is the smallest denomination (like wei
	// in Ethereum), the base fee is always a whole number of upc -- no fractional upc exists.
	// This division unwraps the LegacyDec encoding back to the actual upc amount.
	// Note: baseFee.BigInt() returns a reference to the internal big.Int; the in-place Div
	// mutates it, which is safe here since baseFee is a local value-type copy.
	baseFeeBig.Div(baseFeeBig, big.NewInt(1e18))

	// Step 1: Validate maxFeePerGas >= baseFee
	if maxFeePerGas.Cmp(baseFeeBig) < 0 {
		return nil, fmt.Errorf("maxFeePerGas (%s) cannot be less than baseFee (%s)", maxFeePerGas, baseFeeBig)
	}

	// Step 2: Calculate baseFee + maxPriorityFeePerGas (potential effective gas price)
	// @dev: Currently, we are not using maxPriorityFeePerGas in the calculation
	// tipPlusBase := new(big.Int).Add(baseFeeBig, maxPriorityFeePerGas)
	// tipPlusBase := maxFeePerGas

	// Step 3: Find effective gas price by taking minimum
	// @dev: Currently, since we are not using maxPriorityFeePerGas, effectiveGasPrice is just baseFee
	effectiveGasPrice := new(big.Int).Set(baseFeeBig)
	// if tipPlusBase.Cmp(maxFeePerGas) == -1 {
	// 	effectiveGasPrice = tipPlusBase
	// }

	// Step 4: Calculate final gas cost: effectiveGasPrice * gasUsed
	gasUsedBig := new(big.Int).SetUint64(gasUsed)
	gasCost := new(big.Int).Mul(effectiveGasPrice, gasUsedBig)

	k.Logger().Debug("gas cost calculated",
		"base_fee", baseFee.String(),
		"effective_gas_price", effectiveGasPrice.String(),
		"gas_used", gasUsed,
		"gas_cost", gasCost.String(),
	)

	return gasCost, nil
}

func (k Keeper) DeductGasFeesFromReceipt(
	ctx context.Context,
	sdkCtx sdk.Context,
	recipient common.Address,
	receipt *evmtypes.MsgEthereumTxResponse,
	universalPayload *types.UniversalPayload,
) error {
	if receipt == nil || receipt.GasUsed == 0 {
		return nil
	}
	if universalPayload == nil {
		return nil
	}

	abiPayload, err := types.NewAbiUniversalPayload(universalPayload)
	if err != nil {
		return fmt.Errorf("failed to parse payload for gas deduction: %w", err)
	}

	baseFee := k.feemarketKeeper.GetBaseFee(sdkCtx)
	if baseFee.IsNil() {
		return fmt.Errorf("base fee not found")
	}

	gasCost, err := k.CalculateGasCost(baseFee, abiPayload.MaxFeePerGas, abiPayload.MaxPriorityFeePerGas, receipt.GasUsed)
	if err != nil {
		return fmt.Errorf("failed to calculate gas cost: %w", err)
	}
	if gasCost.Sign() <= 0 {
		return nil
	}

	gasUsedBig := new(big.Int).SetUint64(receipt.GasUsed)
	if gasUsedBig.Cmp(abiPayload.GasLimit) > 0 {
		return fmt.Errorf("gas used (%d) exceeds gas limit (%s)", receipt.GasUsed, abiPayload.GasLimit.String())
	}

	recipientAccAddr := sdk.AccAddress(recipient.Bytes())
	balance := k.bankKeeper.GetBalance(sdkCtx, recipientAccAddr, pchaintypes.BaseDenom)

	if err := k.DeductAndBurnFees(ctx, recipientAccAddr, gasCost); err != nil {
		return fmt.Errorf("insufficient gas: required %s upc, available %s upc, gas_used %d, from %s: %w",
			gasCost.String(), balance.Amount.String(), receipt.GasUsed, recipient.Hex(), err)
	}
