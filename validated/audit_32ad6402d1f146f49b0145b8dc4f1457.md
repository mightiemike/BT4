### Title
Truncated `baseFee` unit conversion in `CalculateGasCost` can zero out gas fees for module-originated EVM execution - (File: `x/uexecutor/keeper/fees.go`)

### Summary
`CalculateGasCost` in `x/uexecutor/keeper/fees.go` converts the feemarket `LegacyDec` base fee into an integer "upc-per-gas" price by dividing the internal fixed-point representation by `1e18`. The code explicitly assumes "the base fee is always a whole number of upc — no fractional upc exists," but the feemarket's dynamically-adjusted base fee is not bounded to whole-upc granularity. If the base fee ever settles below `1` upc per gas unit (a legitimate, non-privileged network state reachable simply by sustained low block gas utilization when `MinGasPrice` is configured at or near zero), the integer division truncates the effective gas price to `0`, making `gasCost = effectiveGasPrice * gasUsed = 0` regardless of how much gas is actually consumed.

### Finding Description [1](#0-0) 

`CalculateGasCost` computes the effective gas price by:
1. Reading `baseFee.BigInt()`, which is the `LegacyDec` internal scaled representation (`actualUpcPerGas * 1e18`).
2. Truncating it back to a whole-upc value via `baseFeeBig.Div(baseFeeBig, big.NewInt(1e18))`.
3. Multiplying the result by `gasUsed` to get `gasCost`.

This is called from `DeductGasFeesFromReceipt` [2](#0-1) , which burns the computed `gasCost` from the recipient's (UEA/module-derived) account for gas consumed by module-originated `DerivedEVMCall`/universal-payload execution. If `gasCost.Sign() <= 0` the function returns `nil` with no error and **no fee is charged** [3](#0-2) .

The vulnerable assumption is that `baseFee` (in upc/gas) is always `>= 1`. This holds only as long as the feemarket's dynamically adjusted base fee never drops below `1` upc/gas. The feemarket module (`app/cosmos/min_gas_price.go` reads `feemarketKeeper.GetParams(ctx).MinGasPrice` as the floor [4](#0-3) ) adjusts base fee up/down each block based on gas utilization relative to target, floored only by the configurable `MinGasPrice` param. If `MinGasPrice` is `0` or a very small fractional value (a legitimate, non-malicious chain configuration — many EVM chains permit near-zero minimum gas prices), sustained low utilization can legitimately drive `base_fee` below `1` upc/gas over ordinary blocks, with no privileged action required. Once that happens, every `DeductGasFeesFromReceipt` call silently charges `0` regardless of `receipt.GasUsed`.

### Impact Explanation
This breaks the gas fee accounting invariant for module-originated EVM execution (`DerivedEVMCall`/universal payload flows): a user's Universal Executor Account (UEA) can consume arbitrary EVM gas via inbound payload execution while being charged zero fee, as long as the network's dynamic base fee has drifted under 1 upc/gas. This is analogous to the Panoptic `s_ITMSpreadFee` bug — a fixed-granularity assumption ("commission is always non-zero because fee tiers are always ≥ 1 basis point"/"base fee is always ≥ 1 upc") silently breaks the fee-collection mechanism instead of reverting or falling back to a minimum charge, letting execution proceed for free and permanently under-collecting protocol fees that should be burned.

### Likelihood Explanation
Reaching `base_fee < 1 upc/gas` requires the feemarket's `MinGasPrice` param to be at or near zero and sustained low network utilization — both are ordinary, non-privileged network conditions rather than a governance-abuse or admin-only scenario. No attacker capability beyond normal transaction submission (to keep utilization low) is needed to trigger and then exploit the zero-fee window.

### Recommendation
Do not truncate the fixed-point base fee to a whole-upc integer before use. Perform the gas-cost multiplication in the full-precision `LegacyDec`/fixed-point domain (multiply `baseFee` by `gasUsed` first, then convert to the smallest unit with `Ceil()`/`RoundUp()` similar to how `min_gas_price.go` computes `requiredFees` via `Ceil().RoundInt()`), and treat any positive computed cost as chargeable rather than silently returning `nil` when the naive integer division floors to zero.

### Proof of Concept
1. Configure (or allow the feemarket module to organically drift to) `base_fee` such that its upc/gas value is `< 1`, e.g. `0.5` upc/gas (internal `LegacyDec` value `5*10^17`).
2. Submit an inbound payload that results in a `DerivedEVMCall` consuming, e.g., `500,000` gas.
3. In `CalculateGasCost`, `baseFeeBig = 5*10^17`; `baseFeeBig.Div(baseFeeBig, 1e18)` truncates to `0`.
4. `gasCost = 0 * 500000 = 0`; `DeductGasFeesFromReceipt` sees `gasCost.Sign() <= 0` and returns `nil` without burning any fee from the recipient's account, despite `500,000` gas of real EVM execution having occurred.

```go
func (k Keeper) CalculateGasCost(
	baseFee sdkmath.LegacyDec,
	maxFeePerGas *big.Int,
	maxPriorityFeePerGas *big.Int,
	gasUsed uint64,
) (*big.Int, error) {
	baseFeeBig := baseFee.BigInt()
	// @dev: LegacyDec stores values with 18-decimal precision internally, so 1 upc = 1e18
	// in the LegacyDec representation. Since 1 upc is the smallest denomination (like wei
	// in Ethereum), the base fee is always a whole number of upc -- no fractional upc exists.
	// This division unwraps the LegacyDec encoding back to the actual upc amount.
	// Note: baseFee.BigInt() returns a reference to the internal big.Int; the in-place Div
	// mutates it, which is safe here since baseFee is a local value-type copy.
	baseFeeBig.Div(baseFeeBig, big.NewInt(1e18))

	// Step 1: Validate maxFeePerGas >= baseFee
	if maxFeePerGas.Cmp(baseFeeBig) < 0 {
		return nil, fmt.Errorf("maxFeePerGas (%s) cannot be less than baseFee (%s)", maxFeePerGas, baseFeeBig)
	}

	// Step 2: Calculate baseFee + maxPriorityFeePerGas (potential effective gas price)
	// @dev: Currently, we are not using maxPriorityFeePerGas in the calculation
	// tipPlusBase := new(big.Int).Add(baseFeeBig, maxPriorityFeePerGas)
	// tipPlusBase := maxFeePerGas

	// Step 3: Find effective gas price by taking minimum
	// @dev: Currently, since we are not using maxPriorityFeePerGas, effectiveGasPrice is just baseFee
	effectiveGasPrice := new(big.Int).Set(baseFeeBig)
	// if tipPlusBase.Cmp(maxFeePerGas) == -1 {
	// 	effectiveGasPrice = tipPlusBase
	// }

	// Step 4: Calculate final gas cost: effectiveGasPrice * gasUsed
	gasUsedBig := new(big.Int).SetUint64(gasUsed)
	gasCost := new(big.Int).Mul(effectiveGasPrice, gasUsedBig)

	k.Logger().Debug("gas cost calculated",
		"base_fee", baseFee.String(),
		"effective_gas_price", effectiveGasPrice.String(),
		"gas_used", gasUsed,
		"gas_cost", gasCost.String(),
	)

	return gasCost, nil
}
```

```go
func (k Keeper) DeductGasFeesFromReceipt(
	ctx context.Context,
	sdkCtx sdk.Context,
	recipient common.Address,
	receipt *evmtypes.MsgEthereumTxResponse,
	universalPayload *types.UniversalPayload,
) error {
	if receipt == nil || receipt.GasUsed == 0 {
		return nil
	}
	if universalPayload == nil {
		return nil
	}

	abiPayload, err := types.NewAbiUniversalPayload(universalPayload)
	if err != nil {
		return fmt.Errorf("failed to parse payload for gas deduction: %w", err)
	}

	baseFee := k.feemarketKeeper.GetBaseFee(sdkCtx)
	if baseFee.IsNil() {
		return fmt.Errorf("base fee not found")
	}

	gasCost, err := k.CalculateGasCost(baseFee, abiPayload.MaxFeePerGas, abiPayload.MaxPriorityFeePerGas, receipt.GasUsed)
	if err != nil {
		return fmt.Errorf("failed to calculate gas cost: %w", err)
	}
	if gasCost.Sign() <= 0 {
		return nil
	}
```
