### Title
Off-by-one rounding mismatch between `GlobalStateEvaluator::reached_agreement` and `NakamotoBlockHeader::compute_voting_weight_threshold` lets a sub-70% signer coalition force "global state" consensus - (File: `libsigner/src/v0/signer_state.rs`)

### Summary
The signer network implements the same conceptual "70% supermajority" threshold in two different places with two different rounding rules. `NakamotoBlockHeader::compute_voting_weight_threshold` (used to actually validate a Nakamoto block's aggregated signer signatures) rounds the 70% cutoff **up** (ceiling), while `GlobalStateEvaluator::reached_agreement`/`reached_disagreement` (used by signers to agree on burn view, active protocol version, current miner, and tx-replay set) rounds the same cutoff **down** (floor). For `total_weight` values where `total_weight * 7` is not a multiple of 10, these two "70%" thresholds differ by exactly 1 unit of weight, so a signer coalition that holds strictly less than the block-approval-required weight can still be judged to have "reached agreement" by the global state machine. [1](#0-0) [2](#0-1) 

### Finding Description
`NakamotoBlockHeader::compute_voting_weight_threshold` computes `ceil(total_weight * 7 / 10)` and is the formula actually used to verify whether enough signer weight has signed a Nakamoto block (`verify_signer_signatures`): [1](#0-0) 

Confirmed by unit test, e.g. `compute_voting_weight_threshold(511) == 358` (ceiling of 357.7): [3](#0-2) 

`GlobalStateEvaluator::reached_agreement`, by contrast, computes `floor(total_weight * 7 / 10)` via truncating integer division and then does a `>=` comparison:

```rust
pub fn reached_agreement(&self, vote_weight: u32) -> bool {
    u64::from(vote_weight)
        >= u64::from(self.total_weight).strict_mul(NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD)
            / 10
}
``` [4](#0-3) 

For `total_weight = 511`, the block-approval threshold requires `358` (i.e. `358/511 = 70.06%`), but `reached_agreement` will already report "agreement" once weight `357` (`69.86%`) is reached — one unit of weight below what the actual Nakamoto block-signing quorum requires. `reached_agreement` is the function used by `determine_latest_supported_signer_protocol_version`, `determine_global_burn_view`, and `determine_global_state` — all of which gate which burn view, active miner, active protocol version, and tx-replay set the signer set treats as canonical: [5](#0-4) [6](#0-5) 

The equality this breaks is: "the weight required to be considered a supermajority for global-state purposes" should equal "the weight required to approve a Nakamoto block", since both are meant to enforce the same `NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD = 7/10` supermajority constant. Because one formula floors and the other ceilings, a coalition holding weight strictly between `floor(total_weight*7/10)` and `ceil(total_weight*7/10)` (i.e., below the weight actually required to sign a valid Nakamoto block) is nonetheless treated by the global state machine as having reached consensus on burn view / active miner / protocol version / replay set.

### Impact Explanation
This is a "signer weight below threshold" divergence as called out in scope: a coalition of signers holding less than the true 70% block-approval weight can force the rest of the signer set's local state machines to accept a "globally agreed" burn view, active miner, or transaction-replay set that the actual block-approval mechanism would not yet endorse. Since `determine_global_state`/`determine_global_burn_view` feed directly into how signers decide which miner/tenure they treat as canonical (used in `stacks-signer/src/v0/signer_state.rs` and `signer.rs`), this can produce temporary disagreement in signer behavior/tip tracking relative to what the real 70% block-signing quorum would allow — a bounded, temporary tip/consensus disagreement rather than a silent chain split, consistent with the "High" impact bucket (minority/sub-threshold-triggerable weight divergence, temporary tip disagreement).

### Likelihood Explanation
This triggers deterministically and automatically whenever `total_weight * 7` is not a multiple of 10 (the vast majority of possible reward-cycle weight totals) and a coalition's weight lands exactly in the 1-unit gap between the floor and ceiling values — no special signer privilege or majority collusion is required beyond controlling that exact boundary weight, which for many real distributions of `total_weight` (signer weights are ordinary small integers, not necessarily multiples of 10) is easily reachable.

### Recommendation
Use a single shared threshold function (the same ceiling-based `compute_voting_weight_threshold` formula) for both the Nakamoto block-approval check and `GlobalStateEvaluator::reached_agreement`/`reached_disagreement`, so that "reached global agreement" and "reached block-approval weight" always refer to the identical numeric threshold.

### Proof of Concept
1. Configure a reward cycle where the sum of signer weights, `total_weight`, satisfies `total_weight * 7 % 10 != 0` (e.g. `total_weight = 511`, as used in the existing test `test_compute_voting_weight_threshold`).
2. Real Nakamoto block approval requires `compute_voting_weight_threshold(511) = 358` weight units of valid signatures (`stackslib/src/chainstate/nakamoto/tests/mod.rs:4118-4122`).
3. Construct a `GlobalStateEvaluator` with `total_weight = 511` and have a coalition contribute exactly `357` weight units of matching `StateMachineUpdate`s (e.g., same burn view, same current miner).
4. `reached_agreement(357)` returns `true` (`357 >= floor(511*7/10) = 357`), so `determine_global_burn_view`/`determine_global_state` declare consensus, even though only `357/511 = 69.86%` — less than the `358/511` weight that would actually be required to approve a Nakamoto block signed by the same signer set.

    /// Compute the threshold for the minimum number of signers (by weight) required
    /// to approve a Nakamoto block.
    pub fn compute_voting_weight_threshold(total_weight: u32) -> Result<u32, ChainstateError> {
        let threshold = NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD;
        let total_weight = u64::from(total_weight);
        let ceil = if (total_weight * threshold) % 10 == 0 {
            0
        } else {
            1
        };
        u32::try_from((total_weight * threshold) / 10 + ceil).map_err(|_| {
            ChainstateError::InvalidStacksBlock(
                "Overflow when computing nakamoto block approval threshold".to_string(),
            )
        })
    }

    /// Determine what the maximum signer protocol version that a majority of signers can support
    pub fn determine_latest_supported_signer_protocol_version(&self) -> Option<u64> {
        let mut protocol_versions = HashMap::new();
        for (address, update) in &self.address_updates {
            let Some(weight) = self.address_weights.get(address) else {
                continue;
            };
            let entry = protocol_versions
                .entry(update.local_supported_signer_protocol_version)
                .or_insert_with(|| 0);
            *entry += weight;
        }
        // find the highest version number supported by a threshold number of signers
        let mut protocol_versions: Vec<_> = protocol_versions.into_iter().collect();
        protocol_versions.sort_by_key(|(version, _)| *version);
        let mut total_weight_support: u32 = 0;
        for (version, weight_support) in protocol_versions.into_iter().rev() {
            total_weight_support += weight_support;
            if self.reached_agreement(total_weight_support) {
                return Some(version);
            }
        }
        None
    }

    /// Determine what the global burn view is if there is one

    /// Check if there is an agreed upon global state
    pub fn determine_global_state(&self) -> Option<SignerStateMachine> {
        let active_signer_protocol_version =
            self.determine_latest_supported_signer_protocol_version()?;
        let mut state_views = HashMap::new();
        let mut tx_replay_sets = HashMap::new();
        let mut found_state_view = None;
        let mut found_replay_set = None;
        for (address, update) in &self.address_updates {
            let Some(weight) = self.address_weights.get(address) else {
                continue;
            };
            let (burn_block, burn_block_height) = update.content.burn_block_view();
            let current_miner = update.content.current_miner();
            let tx_replay_set = update.content.tx_replay_set();

            let state_machine = SignerStateMachine {
                burn_block: burn_block.clone(),
                burn_block_height,
                current_miner: current_miner.clone().into(),
                active_signer_protocol_version,
                // We need to calculate the threshold for the tx_replay_set separately
                tx_replay_set: ReplayTransactionSet::none(),
            };
            let key = SignerStateMachineKey(state_machine.clone());
            let entry = state_views.entry(key).or_insert_with(|| 0);
            *entry += weight;

            if self.reached_agreement(*entry) {
                found_state_view = Some(state_machine);
            }

            let replay_entry = tx_replay_sets
                .entry(tx_replay_set.clone())
                .or_insert_with(|| 0);
            *replay_entry += weight;

            if self.reached_agreement(*replay_entry) {
                found_replay_set = Some(tx_replay_set);
            }
            if found_replay_set.is_some() && found_state_view.is_some() {
                break;
            }
        }
        // Try to find agreed replay set, or find longest common prefix if no exact agreement
        let final_replay_set = if let Some(tx_replay_set) = found_replay_set {
            tx_replay_set
        } else {
            // No exact agreement found, try finding longest common prefix with majority support
            self.find_majority_prefix_replay_set(&tx_replay_sets)
                .unwrap_or_else(ReplayTransactionSet::none)
        };

        if let Some(state_view) = found_state_view.as_mut() {
            state_view.tx_replay_set = final_replay_set;
        }
        found_state_view
    }
