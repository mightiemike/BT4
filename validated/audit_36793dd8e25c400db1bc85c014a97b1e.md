## Analog Found

### Title
Starknet OS `execute_replace_class` omits the "class must be declared" check enforced by Blockifier, causing honest-node state divergence - (File: `crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo`)

### Summary
The external report describes a Llama `delegatecall` bug where privileged state (`slot0`) could be silently corrupted by script execution because the delegate-callee is not restricted from writing arbitrary/invalid state. The closest reachable analog in this sequencer is the `replace_class` syscall path: the actual execution engine (Blockifier) enforces that the new class hash must be a declared, Cairo1 class before rebinding a contract's class, but the Starknet OS Cairo implementation that re-derives the state diff for proving/commitment performs no such check at all.

### Finding Description
When a Cairo1 contract invokes the `replace_class` syscall during normal Blockifier execution, `syscall_base.rs::replace_class` requires the target class hash to be declared and to be a Cairo1 class, otherwise the call reverts: [1](#0-0) 

This is confirmed by the dedicated negative-flow tests (`undeclared_class_hash`, `cairo0_class_hash`) that assert the syscall must fail for undeclared or Cairo0 class hashes: [2](#0-1) 

The deprecated (Cairo0) syscall handler enforces the equivalent check by reading the compiled class before writing the new class hash: [3](#0-2) 

However, the Starknet OS's own Cairo implementation of the same syscall — which independently re-derives the block's `contract_state_changes` for the purpose of building the committed state diff/state root that feeds Starknet OS proving — performs the class-hash rebind unconditionally, with an explicit outstanding TODO acknowledging the missing check: [4](#0-3) 

The same unconditional behavior exists in the deprecated (Cairo0) OS syscall path as well: [5](#0-4) 

In both OS implementations, `class_hash` is taken directly from the syscall request and written into the new `StateEntry` for the calling contract with no verification that a compiled class with that hash was ever declared (unlike Blockifier's `get_compiled_class` + `is_cairo1` gate).

### Impact Explanation
The Starknet OS is the formal, provable re-execution of block transactions used to derive the state diff/commitment that is ultimately verified and committed (analogous to LlamaCore's `slot0` protection meant to prevent uncontrolled privileged-state mutation via `delegatecall`-style execution). Because the OS's `execute_replace_class` never validates that the requested class hash is a declared, valid class, the OS-computed state diff can diverge from what Blockifier's protocol rules actually permit for a given transaction trace. This is a state-commitment soundness gap: the class-hash rebind invariant that Blockifier guarantees (only declared Cairo1 classes can be bound to a contract) is not independently re-verified by the OS, so a discrepancy between Blockifier's enforced semantics and the OS's accepted semantics for this syscall constitutes an honest-node divergence / wrong-committed-state-root risk class, the exact category called out as acceptable impact in the validation criteria.

### Likelihood Explanation
The `replace_class` syscall is reachable directly by any account/contract that a transaction sender interacts with — no operator, prover, or p2p privilege is required. The missing check is explicit and acknowledged in the code via the `TODO(Yoni, 1/1/2026)` comment, confirming this is a known, currently-unaddressed gap rather than a speculative one.

### Recommendation
Add the same validation performed in `syscall_base.rs::replace_class` (declared-class lookup and Cairo1-type check) to the OS's `execute_replace_class` implementations in both `syscall_impls.cairo` and `deprecated_execute_syscalls.cairo`, so that the OS's re-derived state diff can never diverge from Blockifier's enforced class-replacement invariants.

### Proof of Concept
1. An account contract's Cairo1 code calls `replace_class_syscall(class_hash)` where `class_hash` does not correspond to any declared class (or is a Cairo0 class).
2. In actual Blockifier execution this syscall reverts (per `syscall_base.rs:369-378`), matching the tests in `crates/blockifier/src/execution/syscalls/syscall_tests/replace_class.rs`.
3. When the Starknet OS re-executes/derives the state diff for this transaction trace (`execute_replace_class` in `syscall_impls.cairo:881-920`), it performs no equivalent check and unconditionally writes the new `class_hash` into `contract_state_changes`, producing a state diff entry that Blockifier's protocol rules would never allow — demonstrating the divergence between the two independently-implemented enforcement paths for the identical syscall.

    pub fn replace_class(&mut self, class_hash: ClassHash) -> SyscallResult<()> {
        // Ensure the class is declared (by reading it), and of type V1.
        let compiled_class = self.state.get_compiled_class(class_hash)?;

        if !is_cairo1(&compiled_class) {
            return Err(SyscallExecutionError::ForbiddenClassReplacement { class_hash });
        }
        self.state.set_class_hash_at(self.call.storage_address, class_hash)?;
        Ok(())
    }

func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
