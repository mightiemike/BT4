### Title
Starknet OS `execute_replace_class` syscall omits the "declared class" check enforced by blockifier, allowing state divergence — (File: `crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo`)

### Summary
The external report describes `Referrals.sol::addDiamond()` mutating a security-critical field (`diamond`) with no validation that the caller is authorized, letting anyone hijack privileged access checks. The analogous root cause exists in the Starknet OS Cairo implementation of the `replace_class` syscall: it writes an attacker-supplied `class_hash` into a contract's state entry **without verifying the class was ever declared**, whereas the blockifier's real (Rust) execution path enforces exactly that check before the write. This is a missing-validation-before-critical-state-write bug, reachable by any unprivileged transaction that triggers a `replace_class` syscall.

### Finding Description
In the blockifier's actual syscall execution (used by the sequencer to build blocks), `replace_class` explicitly checks that the target class hash is declared before mutating the contract's class hash: [1](#0-0) 

The equivalent test coverage confirms this is a required invariant — attempting to replace with an undeclared class hash fails with `"is not declared"`: [2](#0-1) 

However, the Starknet OS's own Cairo implementation of the same syscall (`apollo_starknet_os_program`, used to re-execute transactions and prove block validity) performs the state write directly, with an explicit TODO acknowledging the missing check: [3](#0-2) 

The deprecated Cairo0 syscall handler in the OS has the identical gap — it updates `contract_state_changes` with the caller-supplied `class_hash` with no declared-class assertion at all: [4](#0-3) 

Just as `Referrals.sol::addDiamond()` lacked the `onlyOwner` gate that every other privileged function implicitly relied on, the OS's `execute_replace_class` lacks the "class must be declared" gate that the blockifier relies on as an invariant of a valid state transition. Any contract can invoke the `replace_class` syscall (it is a standard, permissionless Starknet syscall available to any contract during execution), so this code path is reachable from a single, ordinary transaction — no privileged role is required.

### Impact Explanation
The Starknet OS is the component responsible for re-executing transactions and producing the state diff/commitment that is proven and ultimately verified on L1. If its `replace_class` handling accepts an undeclared (or otherwise invalid) class hash while the actual sequencer/blockifier would reject the same operation, the two execution engines can diverge on what constitutes a valid state transition for the exact same transaction. This falls squarely into the "wrong committed root ... honest-node divergence" impact category: the OS could compute/attest a state commitment where a contract's `class_hash` field is set to a class that was never declared, which the CASM/Sierra compilation and class-hash machinery elsewhere assume is always a validated invariant (`UndeclaredClassHash` is a first-class `StateError`). A contract's class-hash slot silently corrupted with an undeclared value undermines any downstream consumer (native/RPC execution, other nodes) that trusts the invariant "every deployed contract's class_hash is declared," and represents an integrity failure in the state-transition/proving component of the sequencer stack.

### Likelihood Explanation
`replace_class` is a syscall available to any contract without special privileges; an attacker only needs to deploy a trivial contract that calls `replace_class` with an arbitrary/undeclared class hash and get it included via one ordinary transaction. The bug is not gated behind any operator, prover, or admin role — it is purely a missing validation in a code path that processes attacker-controlled calldata (`class_hash`), matching the "unprivileged transaction sender" reachability required by scope rules. The presence of an explicit `TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.` comment in production code confirms the gap is real and currently unaddressed.

### Recommendation
Add the same "declared class" verification in the Starknet OS's Cairo `execute_replace_class` (both the current `syscall_impls.cairo` implementation and the deprecated `deprecated_execute_syscalls.cairo` path) that the blockifier already performs — i.e., assert that `class_hash` exists in `contract_class_changes` / the declared-classes mapping (and, matching blockifier's Cairo-version-compatibility check, that a Cairo1 class isn't replaced by a Cairo0 hash) before writing the new `StateEntry`, mirroring `hint_processor.rs`'s `state.get_compiled_class(request.class_hash)?` check.

### Proof of Concept
1. Deploy a contract `A` whose Cairo code performs the `replace_class` syscall with an attacker-chosen `new_class_hash` that has never been declared on-chain.
2. In the real blockifier execution path, this transaction reverts with `"Class with hash ... is not declared"` (see `crates/blockifier/src/execution/syscalls/syscall_tests/replace_class.rs:17-29`).
3. If the same call sequence is (re-)executed through the Starknet OS's Cairo `execute_replace_class` (`syscall_impls.cairo:881-920` or `deprecated_execute_syscalls.cairo:307-329`), no equivalent assertion exists — the `dict_update` on `contract_state_changes` unconditionally proceeds and would accept the undeclared `class_hash`, producing a state view/commitment inconsistent with what blockifier's runtime rules allow.

// Replaces the class.
func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
