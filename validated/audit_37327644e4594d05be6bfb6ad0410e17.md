## Analysis Result

The audit report's bug class — a delegate-call/clone target being able to corrupt the caller's storage state through unchecked implementation logic — maps to a concrete divergence in this codebase between the **blockifier** (used to execute and build blocks) and the **Starknet OS** (used to re-execute transactions and produce the committed state/proof) implementations of the `replace_class` syscall.

### Title
Starknet OS `execute_replace_class` omits the declared-class and Cairo-version checks that blockifier enforces, causing state divergence between block building and OS re-execution - (File: `crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo`)

### Summary
`replace_class` lets a contract change its own class hash, i.e., swap the code that will run against its storage — functionally the same primitive abused in the reported "Malicious Vesting Escrow" (an untrusted implementation is substituted into a context that keeps operating on existing storage). In blockifier, `replace_class` is guarded: the new class must be declared and must be a Cairo1 (V1) class. [1](#0-0) 

The same guard exists for the deprecated (Cairo0) syscall path: [2](#0-1) 

However, the Starknet OS's Cairo implementation of the same syscall — used for re-execution when generating the state commitment/proof — performs neither check, and explicitly documents this gap with a TODO: [3](#0-2) 

The deprecated (Cairo0) OS syscall handler has the identical omission: [4](#0-3) 

### Finding Description
Blockifier's `replace_class` syscall implementation performs `state.get_compiled_class(class_hash)` (failing if the class is undeclared) and rejects non-Cairo1 class hashes with `ForbiddenClassReplacement`, as proven by the test suite: [5](#0-4) 

A Cairo1 contract can invoke `replace_class_syscall` and catch its `SyscallResult` without panicking/reverting the whole transaction (standard Starknet syscall error handling). If a transaction wraps `replace_class_syscall(undeclared_or_v0_class_hash)` in an error-catching branch, blockifier's syscall returns an `Err`, which the contract can catch and continue execution without applying the class change — this behavior becomes part of the committed state diff and block.

The Starknet OS, which independently re-executes the same transaction to build the trace/proof that backs the committed state root, does **not** perform this check (per the explicit TODO). Given the identical class hash and identical calldata, the OS syscall implementation unconditionally overwrites `contract_state_changes` with the new (potentially undeclared/V0) class hash and treats the call as successful, rather than mirroring blockifier's failure/catch path.

### Impact Explanation
This causes an execution/state divergence between the block-building path (blockifier — determines what actually gets included and committed as the state diff) and the proving/re-execution path (Starknet OS — determines the state root/commitments proven and referenced by the block hash). For the same transaction with the same inputs, one path applies a class-hash state update while the other rejects it, which can lead to a committed state root/block hash that does not match what an honest re-execution (or a differently-configured node) computes — matching the accepted impact categories "wrong committed root or block hash" and "honest-node divergence."

### Likelihood Explanation
The path is reachable directly by any unprivileged Cairo1 (or Cairo0) contract call: any account can submit an `invoke` transaction whose contract calls `replace_class_syscall` with an undeclared class hash or a Cairo0 class hash and catches the resulting error to keep executing, exactly as demonstrated in the repository's own test/fuzzing harness (`test_replace_class`, `Scenario::ReplaceClass` in the fuzz contracts). No special privileges, staking, or operator/proposer collusion are required — a single submitted transaction triggers the divergence.

### Recommendation
Port the same validation that blockifier performs (`get_compiled_class` existence check plus Cairo1/V1-only enforcement) into the Starknet OS's `execute_replace_class` (both `syscall_impls.cairo` and the deprecated `deprecated_execute_syscalls.cairo` variants) so that success/failure semantics for `ReplaceClass` are identical between blockifier execution and OS re-execution, closing the TODO noted at `crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo:902`.

### Proof of Concept
1. Declare (or use) a class hash `X` that is never declared on-chain (or is a Cairo0/V0 class).
2. Deploy a Cairo1 contract whose external function calls `syscalls::replace_class_syscall(X)` and pattern-matches the `Result` instead of calling `.unwrap_syscall()`, so the failure path is caught and execution continues (as in `crates/blockifier_test_utils/resources/feature_contracts/cairo1/fuzz_revert.cairo:195-198`, `Scenario::ReplaceClass`).
3. Invoke this function. In blockifier, `replace_class` fails inside `syscall_base.rs::replace_class` (undeclared or `ForbiddenClassReplacement`), the contract catches it, and the state diff/block excludes the class-hash change.
4. During Starknet OS re-execution of the same transaction, `execute_replace_class` unconditionally performs `dict_update` on `contract_state_changes` with the new class hash (no declared/version check), producing a different final `class_hash` for the contract than what blockifier computed and committed.     pub fn replace_class(&mut self, class_hash: ClassHash) -> SyscallResult<()> {
        // Ensure the class is declared (by reading it), and of type V1.
        let compiled_class = self.state.get_compiled_class(class_hash)?;

        if !is_cairo1(&compiled_class) {
            return Err(SyscallExecutionError::ForbiddenClassReplacement { class_hash });
        }
        self.state.set_class_hash_at(self.call.storage_address, class_hash)?;
        Ok(())
    }

func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
