### Title
Unauthenticated LOOP plugin pprof/metrics endpoints allow memory/goroutine dump of plugin processes - ([File: core/web/router.go])

### Summary
`loopRoutes` in `core/web/router.go` registers `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` directly on the plain `api` router group without any `auth.Authenticate` middleware, unlike every other debug/pprof exposure in the codebase. This lets a fully unauthenticated network client enumerate LOOP plugin names and pull heap/goroutine/profile dumps from the plugin process.

### Finding Description
`NewRouter` builds the base `api` group with only rate-limiting and session middleware (no auth), then calls `loopRoutes(app, api)`: [1](#0-0) 

`loopRoutes` registers the discovery, metrics, and pprof endpoints on that unauthenticated group: [2](#0-1) 

Contrast this with `debugRoutes`, which wraps `/debug/vars` in `auth.Authenticate`: [3](#0-2) 

and with the standard Go pprof endpoints registered via `metricRoutes`, which is only called from inside the authenticated `authv2` group: [4](#0-3) [5](#0-4) 

`pluginPPROFHandler` and `pluginPPROFPOSTSymbolHandler` take the `:name` and `profile` path params directly from the unauthenticated request and forward them to the plugin's internal pprof port with no further access control: [6](#0-5) [7](#0-6) 

An attacker can call the unauthenticated `discoveryHandler` to enumerate registered plugin names: [8](#0-7) 

then request `GET /plugins/<name>/debug/pprof/heap` or `/goroutine` to receive a full memory/goroutine dump of the plugin process, which may hold chain RPC credentials, signing keys, or other in-memory secrets used by the LOOP plugin.

### Impact Explanation
Successful exploitation discloses process memory of a chain-connected LOOP plugin (heap, goroutine stacks, allocs, full profile) to an unauthenticated network attacker. This maps to a secret-disclosure impact under Chainlink's bounty program — plugin-held keys/credentials or other sensitive in-memory data could be leaked, and the profile/trace endpoints also allow a moderate DoS surface (CPU profiling, blocking `seconds`-based captures) against the plugin.

### Likelihood Explanation
The precondition is only network reachability to the node's web server (no credentials, no privileged role, no social engineering). The plugin name is trivially discoverable via the equally unauthenticated `/discovery` endpoint. This is deterministic and fully repeatable — every call to `loopRoutes` on a running node with LOOP plugins registered reproduces the issue.

### Recommendation
Wrap the `loopRoutes` group (or at minimum the pprof/metrics sub-routes) with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)` and gate the pprof endpoints behind `auth.RequiresAdminRole`, consistent with how `metricRoutes` and `debugRoutes` are protected elsewhere in `core/web/router.go`.

### Proof of Concept
Integration test in `core/web` (similar to existing router tests):
1. Start a test app/router via `setupWebSession`/`NewRouter` equivalent test harness with a registered LOOP plugin in `app.GetLoopRegistry()`.
2. Issue `GET /discovery` with no `Authorization`/session cookie — assert `200 OK` and that the response contains the plugin's metric path (confirms plugin name is enumerable unauthenticated).
3. Issue `GET /plugins/<name>/debug/pprof/heap` with no auth — assert current behavior returns `200 OK` with pprof binary payload (vulnerability confirmed) instead of the expected `401 Unauthorized`.
4. Issue `POST /plugins/<name>/debug/pprof/symbol` with no auth — assert same unauthenticated `200 OK` instead of expected `401`.
5. After applying the fix (wrapping the group in `auth.Authenticate`), re-run steps 3–4 and assert `401 Unauthorized` for unauthenticated requests, and `200 OK` only when a valid session/token is supplied.

func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}
