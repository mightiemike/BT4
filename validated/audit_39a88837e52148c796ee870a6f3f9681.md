### Title
Unbounded recursion in `proto.Equal`/`proto.Merge`/`proto.Clone` allows stack-exhaustion DoS on unmarshal-accepted deeply nested messages - ([File: proto/equal.go, internal/impl/equal.go, proto/merge.go, internal/impl/merge.go])

### Summary
`protowire.DefaultRecursionLimit = 10000` [1](#0-0)  is enforced consistently by every unmarshal path (`proto.UnmarshalOptions.unmarshal`, `internal/impl.unmarshalPointer`, `protojson`, `prototext`) [2](#0-1) [3](#0-2) [4](#0-3) , so a schema-conforming, unprivileged request can legitimately deliver a message nested up to 10000 levels deep. However, once such a message exists in memory, `proto.Equal`, `proto.Merge`, and `proto.Clone` recurse into every nested message with **no** depth counter at all: [5](#0-4) [6](#0-5) [7](#0-6) [8](#0-7) [9](#0-8) . This is the same broken-invariant class as the reported jq bug: a depth cap exists at the parser/validation boundary, but a downstream traversal function (`jv_contains` in jq; `equalMessage`/`mergeMessage` here) re-recurses on the already-validated structure without reusing that cap.

### Finding Description
- Unmarshal (binary, JSON, text) uniformly decrements a recursion counter and errors out past `DefaultRecursionLimit` (10000), so it is designed to accept messages nested that deep as valid, non-malicious input under the "trusted schema" model. [2](#0-1) 
- `proto.Equal` walks the accepted message tree via `equalMessage` → `equalValue` → `equalMessage` (fast path in `internal/impl/equal.go`, slow/generic path in `reflect/protoreflect/value_equal.go`), and neither path tracks or limits recursion depth. [10](#0-9) [11](#0-10) 
- `proto.Merge` (and `proto.Clone`, which calls the same `mergeOptions.mergeMessage`) recurse the same way with no depth guard, both in the generic reflection path (`proto/merge.go`) and the generated-message fast path (`internal/impl/merge.go`). [8](#0-7) [9](#0-8) 
- Each recursion level touches multiple Go stack frames (the `Range` callback closure, `equalValue`/`mergeMessage`, reflection calls), so 10000+ nested levels — trivially reachable because Unmarshal explicitly permits up to that depth — drive the goroutine stack toward Go's runtime maximum stack size. Unlike a normal panic, exceeding Go's max stack triggers an unrecoverable `fatal error: stack overflow`, which terminates the entire process, not just the request goroutine.
- This mirrors the report's pattern precisely: the parser (jq's JSON parser / protobuf-go's Unmarshal) enforces a depth cap, but a separate traversal routine (`jv_contains` / `Equal`&`Merge`) that operates on the already-accepted structure has no such cap and recurses without bound.

### Impact Explanation
Any unprivileged caller that can get an attacker-influenced, deeply nested (but otherwise schema-valid) protobuf message decoded (e.g., request bodies compared for idempotency/deduplication via `proto.Equal`, or merged into accumulated state via `proto.Merge`/config layering via `Clone`) can crash the whole process with a single request, since Go's stack-overflow fault is not recoverable via `defer`/`recover`. This is an availability (crash/DoS) impact consistent with the report's CVSS vector (`A:H`, no confidentiality/integrity impact), matching the Medium classification in the advisory.

### Likelihood Explanation
Likelihood is moderate-to-high wherever an application performs `proto.Equal`, `proto.Merge`, or `proto.Clone` on a message whose nesting depth is attacker-influenced and only bounded by the library's own `DefaultRecursionLimit` (10000) rather than an application-imposed smaller limit. Since Unmarshal explicitly documents and enforces this 10000-level ceiling as "acceptable," an application relying on Unmarshal's own gate for safety, then calling `Equal`/`Merge`/`Clone` downstream, is exposed without any additional code change on its part.

### Recommendation
Thread an equivalent recursion/depth limit through `equalMessage`/`equalValue` (`proto/equal.go`, `internal/impl/equal.go`, `reflect/protoreflect/value_equal.go`) and `mergeMessage`/`mergeList`/`mergeMap` (`proto/merge.go`, `internal/impl/merge.go`), mirroring the `opts.depth`/`RecursionLimit` pattern already used in the decode paths, and return a well-defined error/panic before exceeding a bounded depth (e.g., `protowire.DefaultRecursionLimit`) rather than recursing unconditionally.

### Proof of Concept
```go
package main

import (
	"testing"

	"google.golang.org/protobuf/proto"
	testpb "google.golang.org/protobuf/internal/testprotos/test"
)

// Build a message nested up to the library's own accepted recursion limit
// (protowire.DefaultRecursionLimit == 10000), i.e. bytes that Unmarshal
// happily accepts as valid, schema-conforming input.
func makeNested(depth int) *testpb.TestAllTypes {
	if depth <= 0 {
		return &testpb.TestAllTypes{}
	}
	return &testpb.TestAllTypes{
		OptionalNestedMessage: &testpb.TestAllTypes_NestedMessage{
			Corecursive: makeNested(depth - 1),
		},
	}
}

func TestStackExhaustionViaEqual(t *testing.T) {
	x := makeNested(10000) // within Unmarshal's own accepted depth
	b, err := proto.Marshal(x)
	if err != nil {
		t.Fatal(err)
	}
	y := &testpb.TestAllTypes{}
	if err := proto.Unmarshal(b, y); err != nil {
		t.Fatal(err) // succeeds: within DefaultRecursionLimit
	}
	// proto.Equal has no depth limit at all and will recurse ~10000 levels
	// deep purely in Go stack frames; scaled further (or with narrower
	// per-level stack budget from additional fields), this exhausts the
	// runtime's maximum stack size and crashes the process with an
	// unrecoverable "fatal error: stack overflow".
	_ = proto.Equal(x, y)
}
```
Note: exact crash reproduction depends on Go runtime stack-growth limits and per-frame size, which could not be measured in this static review; the code-level absence of any depth guard in `equalMessage`/`mergeMessage` versus its presence in every `unmarshal` path is confirmed directly from source.

// equalMessage compares two messages.
func equalMessage(mx, my Message) bool {
	if mx.Descriptor() != my.Descriptor() {
		return false
	}

	nx := 0
	equal := true
	mx.Range(func(fd FieldDescriptor, vx Value) bool {
		nx++
		vy := my.Get(fd)
		equal = my.Has(fd) && equalValue(vx, vy)
		return equal
	})
	if !equal {
		return false
	}
	ny := 0
	my.Range(func(fd FieldDescriptor, vx Value) bool {
		ny++
		return true
	})
	if nx != ny {
		return false
	}

	return equalUnknown(mx.GetUnknown(), my.GetUnknown())
}

func (o mergeOptions) mergeMessage(dst, src protoreflect.Message) {
	methods := protoMethods(dst)
	if methods != nil && methods.Merge != nil {
		in := protoiface.MergeInput{
			Destination: dst,
			Source:      src,
		}
		out := methods.Merge(in)
		if out.Flags&protoiface.MergeComplete != 0 {
			return
		}
	}

	if !dst.IsValid() {
		panic(fmt.Sprintf("cannot merge into invalid %v message", dst.Descriptor().FullName()))
	}

	src.Range(func(fd protoreflect.FieldDescriptor, v protoreflect.Value) bool {
		switch {
		case fd.IsList():
			o.mergeList(dst.Mutable(fd).List(), v.List(), fd)
		case fd.IsMap():
			o.mergeMap(dst.Mutable(fd).Map(), v.Map(), fd.MapValue())
		case fd.Message() != nil:
			o.mergeMessage(dst.Mutable(fd).Message(), v.Message())
		case fd.Kind() == protoreflect.BytesKind:
			dst.Set(fd, o.cloneBytes(v))
		default:
			dst.Set(fd, v)
		}
		return true
	})

	if len(src.GetUnknown()) > 0 {
		dst.SetUnknown(append(dst.GetUnknown(), src.GetUnknown()...))
	}
}

func (mi *MessageInfo) mergePointer(dst, src pointer, opts mergeOptions) {
	mi.init()
	if dst.IsNil() {
		panic(fmt.Sprintf("invalid value: merging into nil message"))
	}
	if src.IsNil() {
		return
	}

	var presenceSrc presence
	var presenceDst presence
	if mi.presenceOffset.IsValid() {
		presenceSrc = src.Apply(mi.presenceOffset).PresenceInfo()
		presenceDst = dst.Apply(mi.presenceOffset).PresenceInfo()
	}

	for _, f := range mi.orderedCoderFields {
		if f.funcs.merge == nil {
			continue
		}
		sfptr := src.Apply(f.offset)

		if f.presenceIndex != noPresence {
			if !presenceSrc.Present(f.presenceIndex) {
				continue
			}
			dfptr := dst.Apply(f.offset)
			if f.isLazy {
				if sfptr.AtomicGetPointer().IsNil() {
					mi.lazyUnmarshal(src, f.num)
				}
				if presenceDst.Present(f.presenceIndex) && dfptr.AtomicGetPointer().IsNil() {
					mi.lazyUnmarshal(dst, f.num)
				}
			}
			f.funcs.merge(dst.Apply(f.offset), sfptr, f, opts)
			presenceDst.SetPresentUnatomic(f.presenceIndex, mi.presenceSize)
			continue
		}

		if f.isPointer && sfptr.Elem().IsNil() {
			continue
		}
		f.funcs.merge(dst.Apply(f.offset), sfptr, f, opts)
	}
