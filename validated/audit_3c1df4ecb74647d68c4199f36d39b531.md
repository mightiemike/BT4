### Title
Unauthenticated Job-Run Resume Endpoint Allows Arbitrary Injection of Task Results - (File: core/web/pipeline_runs_controller.go)

### Summary
The `PipelineRunsController.Resume` handler, mounted at `PATCH /v2/jobs/:ID/runs/:runID` (or equivalent unauthenticated group in `core/web/router.go`), accepts a task ID and an arbitrary `pipeline.ResumeRequest` body and directly calls `prc.App.ResumeJobV2(ctx, taskID, result)` without validating that the caller is authorized to complete that specific task/run. The audit event itself is literally named `audit.UnauthedRunResumed`, confirming this route is a deliberately unauthenticated action path.

### Finding Description
`Resume` parses a `runID`/`taskID` UUID from the URL and a JSON body into `pipeline.ResumeRequest`, converts it to a `pipeline.Result`, and calls `App.ResumeJobV2` to inject that result and unblock a suspended pipeline run: [1](#0-0) 

Unlike the GraphQL resolver mutations in `core/web/resolver/mutation.go`, which universally call `authenticateUserCanRun`/`authenticateUserCanEdit`/`authenticateUserIsAdmin` before mutating state (e.g. `RunJob`) [2](#0-1) , this REST handler performs no session/role check and no ownership check tying the caller to the specific suspended task. It relies solely on the `taskID` UUID being hard to guess — a "security by obscurity" pattern analogous to the missing `require(msg.sender == owner)` in `testFinalizeSettlement()`. The audit log call names the action `UnauthedRunResumed`, which is direct evidence that this is a known, intentionally unauthenticated code path rather than an oversight caught elsewhere: [3](#0-2) 

If this route is mounted outside the standard authenticated route groups (as most `/v2/*` routes are, per `core/web/router.go`, which wraps routes in `auth.Authenticate(...)` middlewares), any external caller who can enumerate or guess/leak a `taskID` (e.g. via webhook/bridge callback flows that expose it) can inject arbitrary results into a suspended pipeline task — including forcing an errored/successful completion of any async task (e.g. bridge/external-adapter callback tasks) without being the legitimate external adapter.

### Impact Explanation
This maps to the "unauthorized privileged node action" class analogous to `testFinalizeSettlement()`: an unprivileged caller can force a state transition (finalize/complete a pipeline run) that should be restricted to the entity that legitimately owns the suspended external task, potentially:
- Injecting forged data into a job run that feeds an oracle report, effectively data/report tampering.
- Prematurely completing or corrupting async pipeline runs, causing incorrect job outputs (misreporting) or denial of service for jobs awaiting legitimate callbacks.

### Likelihood Explanation
Likelihood depends on whether `taskID` values are treated as an unguessable secret and never exposed to untrusted parties, and whether this route sits inside or outside authenticated route groups in `core/web/router.go`. I could not fully confirm the exact middleware wrapping for this specific route within the available index — the `router.go` search only confirmed the string `PipelineRunsController` appears 5 times, but the surrounding route-group registration code (which determines auth middleware) was not returned by my searches.

### Recommendation
- Confirm in `core/web/router.go` whether the `Resume` route is behind `auth.Authenticate(...)` middleware; if not, require authentication and verify caller authorization against the run/task owner (e.g., matching external initiator credentials for webhook-triggered tasks) before calling `ResumeJobV2`.
- Treat `taskID` as sensitive and ensure it is never leaked to parties other than the intended callback recipient (bridge/external adapter).

### Proof of Concept

Content-Type: application/json

{"error": null, "value": "<attacker-controlled result>"}

func (prc *PipelineRunsController) Resume(c *gin.Context) {
	taskID, err := uuid.Parse(c.Param("runID"))
	if err != nil {
		jsonAPIError(c, http.StatusUnprocessableEntity, err)
		return
	}

	rr := pipeline.ResumeRequest{}
	decoder := json.NewDecoder(c.Request.Body)
	err = errors.Wrap(decoder.Decode(&rr), "failed to unmarshal JSON body")
	if err != nil {
		jsonAPIError(c, http.StatusUnprocessableEntity, err)
		return
	}
	result, err := rr.ToResult()
	if err != nil {
		jsonAPIError(c, http.StatusUnprocessableEntity, err)
		return
	}

	if err := prc.App.ResumeJobV2(c.Request.Context(), taskID, result); err != nil {
		jsonAPIError(c, http.StatusInternalServerError, err)
		return
	}

	prc.App.GetAuditLogger().Audit(audit.UnauthedRunResumed, map[string]any{"runID": c.Param("runID")})
	c.Status(http.StatusOK)
