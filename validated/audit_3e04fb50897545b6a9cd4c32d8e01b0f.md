### Title
Starknet OS `execute_replace_class` omits the "class is declared" check enforced by the native Blockifier, creating an execution/re-execution divergence - ([File: crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo])

### Summary
The `replace_class` syscall lets a contract change the class hash bound to its own address (analogous to Keycloak binding a "verified" identity to a mutable attribute without re-validating it). In the native Blockifier (the sequencer's actual execution engine), `replace_class` re-validates that the new class hash is declared before accepting it. The Cairo implementation of the same syscall inside the Starknet OS program (used for re-execution/proof generation) explicitly skips this validation, marked by an open `TODO`.

### Finding Description
In the blockifier's deprecated syscall hint processor, `replace_class` explicitly re-reads/verifies the class before mutating state: [1](#0-0) 
This mirrors the documented invariant in `CachedState`: "Replace class: verify the contract is deployed before running any code" and "verify the class is not declared through `get_compiled_class`": [2](#0-1) 
A dedicated blockifier test confirms an undeclared class hash is rejected with an "is not declared" error: [3](#0-2) 

However, the equivalent syscall handler inside the Starknet OS Cairo program (`starkware/starknet/core/os/execution/syscall_impls.cairo`), which is what re-executes blocks for proof generation, contains an explicit `TODO` acknowledging the check is missing, and unconditionally updates the contract's `state_entry.class_hash` to the requested `class_hash` without any declaration check: [4](#0-3) 
The deprecated-syscall variant of the same OS logic has the identical unguarded pattern: [5](#0-4) 

Because state transitions accepted by the native Blockifier during sequencing are what get committed on-chain, this asymmetry by itself would not normally allow an undeclared class hash to enter the committed state diff (the Blockifier rejects it first). The risk instead lies in the OS being the re-execution/verification path used by Starknet OS flow tests and the prover: any hint or code path (present or future) where the OS's `GetContractAddressStateEntry` hint supplies a `class_hash` that was never checked against the declared-class table means the OS's local invariant "a contract's `class_hash` field always refers to a declared class" is not actually enforced by the Cairo logic itself, only assumed. This is exactly the "trust not (re-)verified when the underlying identity/attribute changes" class of bug from the Keycloak report — here, a contract's class-hash "identity" is swapped via `replace_class` without the checker re-validating that the new identity is a legitimate (declared) one at the point of the swap.

### Impact Explanation
If this check is ever relied upon (e.g., if a future change lets the OS process a state diff produced by a component other than the current Blockifier validation path, or if the missing check masks a bug in how declared-class checks are threaded through hints), a contract could end up bound to an undeclared/nonexistent class hash in the OS's committed contract-state trie, causing:
- Divergence between the Blockifier-computed state root and the OS-computed state root (honest-node divergence / unprovable block), or
- A contract effectively "impersonating" an undeclared or attacker-chosen class identity in the trie that the prover accepts without validation.

Given Starknet's proof pipeline treats the OS's accepted state transition as authoritative for proof soundness, a missing invariant check here is a structural soundness gap even though the immediate blockifier path currently blocks the concrete exploit.

### Likelihood Explanation
Low-to-moderate: the current blockifier layer independently enforces declaration before allowing `replace_class` to succeed, which is the dominant mitigating factor. The likelihood of this manifesting as an actual root/impersonation bug depends on whether any code path feeds the OS a state diff/hint value that bypasses the blockifier's check — something not fully verifiable from static text search alone (the exact hint implementation behind `%{ GetContractAddressStateEntry %}` and how `class_hash` values are threaded from the executed transaction into the OS's Cairo trace was not directly inspected in this session).

### Recommendation
Add the same "class is declared" check to `execute_replace_class` in both `syscall_impls.cairo` and `deprecated_execute_syscalls.cairo` that mirrors the Blockifier's `get_compiled_class` verification, closing the `TODO(Yoni, 1/1/2026)` gap, so the OS enforces the invariant independently rather than relying on the Blockifier as the sole gatekeeper.

### Proof of Concept
Not independently reproducible from static analysis alone: exploiting this requires driving the Starknet OS's `execute_replace_class` with a `class_hash` that was never declared, bypassing the Blockifier's own `get_compiled_class` check documented at `crates/blockifier/src/execution/deprecated_syscalls/hint_processor.rs:795-807`. The existing regression test `test_replace_class` (`crates/blockifier/src/execution/deprecated_syscalls/deprecated_syscalls_test.rs:375-392`) demonstrates the Blockifier-side rejection of an undeclared class hash; no equivalent rejecting test exists for the Cairo OS path, and the hint implementation that supplies `state_entry` in `%{ GetContractAddressStateEntry %}` was not located/verified in this session, so full exploitability confirmation would require running/instrumenting the OS re-execution directly.

// Replaces the class.
func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
