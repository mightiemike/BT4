The reported CVE describes a Linux kernel networking type-confusion bug where `team` copies `header_ops` callbacks from a non-Ethernet lower device and later invokes them with the wrong `net_device`, causing `netdev_priv()` to misinterpret memory. This bug class requires: (1) a driver stacking topology where function pointers are copied between structurally different "device" objects, and (2) those copied callbacks later being invoked with the wrong "self" pointer, causing private-data type confusion.

Protobuf-go has no analogous construct reachable from a trusted-schema binary/JSON decode path. The `oneof` itab dispatch in [1](#0-0)  compares the interface's itab before reusing a pointer, and falls back to allocating a fresh wrapper of the correct static type when the itab doesn't match — this is the opposite of the kernel bug's blind copy without a type check. The core unsafe-pointer helpers in [2](#0-1)  and [3](#0-2)  are all driven by compile-time-fixed field offsets and static Go types derived from the message descriptor at `MessageInfo` init time, not by runtime substitution of one message's accessor set for another's memory layout. Dynamic type lookups such as `FindMessageByName`/`FindMessageByURL` explicitly check the resolved type against the expected interface and return an error on mismatch, e.g. [4](#0-3) , and `dynamicpb` similarly validates field-value types before assignment in [5](#0-4) .

There is no code path in a trusted-schema binary/ProtoJSON decode where one message type's unsafe pointer or accessor function is invoked against another, structurally different type's memory layout without a preceding type/itab check. This bug class does not have a reachable analog in protobuf-go's scoped production code.

func pointerOf(p Pointer) pointer {
	return pointer{p: unsafe.Pointer(p)}
}

// pointerOfValue returns v as a pointer.
func pointerOfValue(v reflect.Value) pointer {
	return pointer{p: unsafe.Pointer(v.Pointer())}
}

// ifaceHeader is the memory layout of an interface (both iface and eface).
// For a non-empty interface (iface), Type is *runtime.itab.
// For an empty interface (eface / any), Type is *runtime._type.
type ifaceHeader struct {
	Type unsafe.Pointer
	Data unsafe.Pointer
}

// pointerOfIface returns the pointer portion of an interface.
func pointerOfIface(v any) pointer {
	return pointer{p: (*ifaceHeader)(unsafe.Pointer(&v)).Data}
}

// asIfaceHeader returns p as a pointer to an interface header.
func (p pointer) asIfaceHeader() *ifaceHeader {
	return (*ifaceHeader)(p.p)
}

// IsNil reports whether the pointer is nil.
func (p pointer) IsNil() bool {
	return p.p == nil
}

// Apply adds an offset to the pointer to derive a new pointer
