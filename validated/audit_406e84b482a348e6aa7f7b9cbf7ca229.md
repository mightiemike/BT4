### Title
Reward for a non-equivocating miner via duplicated PoisonMicroblock header pair - ([File: stackslib/src/chainstate/stacks/db/transactions.rs])

### Summary
`handle_poison_microblock` (invoked via `process_transaction_payload` -> `run_poison_microblock`) only checks that `mblock_header_1` and `mblock_header_2` recover to the same public key hash via `check_microblock_header_signer`, and never checks that the two headers are actually distinct (different `block_hash()`, `tx_merkle_root`, or `prev_block`). Because block-level transaction processing does not enforce the "headers must conflict" rule that only exists in the mempool relay-policy check (`will_admit_mempool_tx` in `blocks.rs`), a reporter can submit a real, previously-published microblock header duplicated as both arguments and receive the poison-microblock reward, even though there is zero fork evidence.

### Finding Description
The claimed equality is: `reward_paid == exactly_one_valid_double_signature` (i.e., a reward should only be paid when two *distinct* headers at the same sequence, signed by the same key, are presented as proof of equivocation).

Tracing the code:
- `check_microblock_header_signer` (`stackslib/src/chainstate/stacks/db/transactions.rs:686-713`) recovers `pkh1` and `pkh2` from each header's signature and errors only if `pkh1 != pkh2`. It performs no comparison of `sequence`, `prev_block`, `tx_merkle_root`, or `block_hash()` between the two headers. [1](#0-0) 
- `handle_poison_microblock` (`stackslib/src/chainstate/stacks/db/transactions.rs:722-856`) calls only this signer check, then looks up `get_microblock_pubkey_hash_height(&pubkh)`, verifies the maturity window, and calls `get_microblock_poison_report`/`insert_microblock_poison` to record the reporter and pay out a reward — with no verification anywhere in this function that `mblock_header_1 != mblock_header_2`. [2](#0-1) 
- The *only* place in the codebase that checks the two headers actually conflict (`sequence`, `prev_block`, `version` equal but headers distinct via checking `microblock_pkh_1 != microblock_pkh_2`, plus mismatched-fields rejection) is `will_admit_mempool_tx` in `stackslib/src/chainstate/stacks/db/blocks.rs:6844-6868`, which is a mempool relay-policy gate, not a consensus-critical check invoked from `process_transaction_payload`. A transaction included directly in a miner's own block bypasses mempool admission entirely and goes straight to `process_transaction` → `process_transaction_payload` → `run_poison_microblock` → `handle_poison_microblock`.

Exploit flow: an attacker takes any already-published, legitimately-signed `StacksMicroblockHeader` from a victim miner's fork (public information; its `pubkh` is stored via `insert_microblock_pubkey_hash` and is queryable via `get_microblock_pubkey_hash_height`) and submits `TransactionPayload::PoisonMicroblock(header.clone(), header.clone())` as their own transaction, including it directly in a block they mine (as an unprivileged miner with a valid burn commit) so it never passes through `will_admit_mempool_tx`. Because `mblock_header_1.block_hash() == mblock_header_2.block_hash()`, `check_microblock_header_signer` trivially returns `pkh1 == pkh2` (they're identical signatures), and `get_microblock_poison_report` finds no prior report for that height, so `insert_microblock_poison` is executed and the reporter is credited a reward for "reporting" a fork that never happened — the honest miner never equivocated.

### Impact Explanation
This causes an unearned/misdirected reward: `insert_microblock_poison` records the attacker as reporter and pays a slashing commission against an honest miner's coinbase who never double-signed anything. This matches the "High" (poison/reward mis-payment bounded to fees/commission) or potentially "Critical" (block-reward theft/diversion) category depending on how the poison commission is sized relative to coinbase, since funds are diverted from an honest party to an attacker who supplied no real fork evidence. Nodes that accept the containing block will all apply this payout identically (no chain-split, since all nodes run the same buggy logic), but the honest miner is wrongfully slashed and the attacker wrongfully paid.

### Likelihood Explanation
The only precondition is (1) an already-published microblock header signed by some miner whose `microblock_pubkey_hash` is still within the `MINER_REWARD_MATURITY` window recorded via `insert_microblock_pubkey_hash`, and (2) the ability to include a transaction directly into a mined block (i.e., being a miner, which only requires a minority-stake Bitcoin block-commit — well within the unprivileged-attacker capability described). No private keys are needed beyond the attacker's own signing key for the transaction's origin; the poisoned header's signature is reused verbatim from public chain data. This is fully repeatable against any recently-active miner's microblock key.

### Recommendation
Add an explicit consensus-level check inside `handle_poison_microblock` (or `check_microblock_header_signer`) requiring that the two headers are distinct — e.g., `mblock_header_1.block_hash() != mblock_header_2.block_hash()` (or equivalently, differing `tx_merkle_root`/`signature` while `sequence` and `prev_block` match) — mirroring the conflict-detection logic already present in `will_admit_mempool_tx`, and reject the transaction with `Error::InvalidStacksTransaction` if the headers are identical.

### Proof of Concept
Rust integration test in `stackslib/src/chainstate/stacks/db/transactions.rs` alongside the existing `process_poison_microblock_*` tests:
1. Set up a chainstate as in `process_poison_microblock_invalid_transaction`, insert a `block_pubkh` via `insert_microblock_pubkey_hash` at some height `h` within the maturity window.
2. Construct a single real signed `StacksMicroblockHeader` (`mblock = make_signed_microblock(...)`).
3. Build `TransactionPayload::PoisonMicroblock(mblock.header.clone(), mblock.header.clone())`, sign it as `reporter_privk`, and directly call `StacksChainState::process_transaction` (bypassing `will_admit_mempool_tx`).
4. Assert both sides of the broken equality:
   - `mblock_1.header.block_hash() == mblock_2.header.block_hash()` (headers are identical — no fork evidence).
   - `StacksChainState::get_poison_microblock_report(&mut conn, h).unwrap() == Some((reporter_addr, mblock.header.sequence))` (a reward/report was still recorded despite identical headers), proving `reward_paid` is true even though `exactly_one_valid_double_signature` (two distinct headers) is false.

    /// Given two microblock headers, were they signed by the same key?
    /// Return the pubkey hash if so; return Err otherwise
    fn check_microblock_header_signer(
        mblock_hdr_1: &StacksMicroblockHeader,
        mblock_hdr_2: &StacksMicroblockHeader,
    ) -> Result<Hash160, Error> {
        let pkh1 = mblock_hdr_1.check_recover_pubkey().map_err(|e| {
            Error::InvalidStacksTransaction(
                format!("Failed to recover public key: {:?}", &e),
                false,
            )
        })?;

        let pkh2 = mblock_hdr_2.check_recover_pubkey().map_err(|e| {
            Error::InvalidStacksTransaction(
                format!("Failed to recover public key: {:?}", &e),
                false,
            )
        })?;

        if pkh1 != pkh2 {
            let msg = format!(
                "Invalid PoisonMicroblock transaction -- signature pubkey hash {} != {}",
                &pkh1, &pkh2
            );
            warn!("{}", &msg);
            return Err(Error::InvalidStacksTransaction(msg, false));
        }
        Ok(pkh1)
    }

    pub fn handle_poison_microblock(
        env: &mut ExecutionState,
        invoke_ctx: &InvocationContext,
        mblock_header_1: &StacksMicroblockHeader,
        mblock_header_2: &StacksMicroblockHeader,
    ) -> Result<Value, Error> {
        let cost_before = env.global_context.cost_track.get_total();

        // encodes MARF reads for loading microblock height and current height, and loading and storing a
        // poison-microblock report
        runtime_cost(ClarityCostFunction::PoisonMicroblock, env, 0)
            .map_err(|e| Error::from_cost_error(e, cost_before.clone(), env.global_context))?;

        let sender_principal = match &invoke_ctx.sender {
            Some(ref sender) => {
                if let PrincipalData::Standard(sender) = sender.clone() {
                    sender
                } else {
                    panic!(
                        "BUG: tried to handle poison microblock without a standard principal sender"
                    );
                }
            }
            None => {
                panic!("BUG: tried to handle poison microblock without a sender");
            }
        };

        // is this valid -- were both headers signed by the same key?
        let pubkh =
            StacksChainState::check_microblock_header_signer(mblock_header_1, mblock_header_2)?;

        let microblock_height_opt = env
            .global_context
            .database
            .get_microblock_pubkey_hash_height(&pubkh)?;
        let current_height = env.global_context.database.get_current_block_height();

        // for the microblock public key hash we had to process
        env.add_memory(20)
            .map_err(|e| Error::from_cost_error(e, cost_before.clone(), env.global_context))?;

        // for the block height we had to load
        env.add_memory(4)
            .map_err(|e| Error::from_cost_error(e, cost_before.clone(), env.global_context))?;

        // was the referenced public key hash used anytime in the past
        // MINER_REWARD_MATURITY blocks?
        let mblock_pubk_height = match microblock_height_opt {
            None => {
                // public key has never been seen before
                let msg = format!(
                    "Invalid Stacks transaction: microblock public key hash {} never seen in this fork",
                    &pubkh
                );
                warn!("{}", &msg;
                      "microblock_pubkey_hash" => %pubkh
                );

                return Err(Error::InvalidStacksTransaction(msg, false));
            }
            Some(height) => {
                if height
                    .checked_add(
                        u32::try_from(MINER_REWARD_MATURITY).expect("FATAL: maturity > 2^32"),
                    )
                    .expect("BUG: too many blocks")
                    < current_height
                {
                    let msg = format!(
                        "Invalid Stacks transaction: microblock public key hash from height {} has matured relative to current height {}",
                        height, current_height
                    );
                    warn!("{}", &msg;
                          "microblock_pubkey_hash" => %pubkh
                    );

                    return Err(Error::InvalidStacksTransaction(msg, false));
                }
                height
            }
        };

        // add punishment / commission record, if one does not already exist at lower sequence
        let (reporter_principal, reported_seq) = if let Some((reporter, seq)) = env
            .global_context
            .database
            .get_microblock_poison_report(mblock_pubk_height)?
        {
            // account for report loaded
            env.add_memory(u64::from(TypeSignature::PrincipalType.size().map_err(
                |_| Error::Expects("Failed to get size of PrincipalType".into()),
            )?))
            .map_err(|e| Error::from_cost_error(e, cost_before.clone(), env.global_context))?;

            // u128 sequence
            env.add_memory(16)
                .map_err(|e| Error::from_cost_error(e, cost_before.clone(), env.global_context))?;

            if mblock_header_1.sequence < seq {
                // this sender reports a point lower in the stream where a fork occurred, and is now
                // entitled to a commission of the punished miner's coinbase
                debug!("Sender {} reports a better poison-miroblock record (at {}) for key {} at height {} than {} (at {})", &sender_principal, mblock_header_1.sequence, &pubkh, mblock_pubk_height, &reporter, seq;
                    "sender" => %sender_principal,
                    "microblock_pubkey_hash" => %pubkh
                );
                env.global_context.database.insert_microblock_poison(
                    mblock_pubk_height,
                    &sender_principal,
                    mblock_header_1.sequence,
                )?;
                (sender_principal, mblock_header_1.sequence)
            } else {
                // someone else beat the sender to this report
                debug!("Sender {} reports an equal or worse poison-microblock record (at {}, but already have one for {}); dropping...", &sender_principal, mblock_header_1.sequence, seq;
                    "sender" => %sender_principal,
                    "microblock_pubkey_hash" => %pubkh
                );
                (reporter, seq)
            }
        } else {
            // first-ever report of a fork
            debug!(
                "Sender {} reports a poison-microblock record at seq {} for key {} at height {}",
                &sender_principal, mblock_header_1.sequence, &pubkh, &mblock_pubk_height;
                "sender" => %sender_principal,
                "microblock_pubkey_hash" => %pubkh
            );
            env.global_context.database.insert_microblock_poison(
                mblock_pubk_height,
                &sender_principal,
                mblock_header_1.sequence,
            )?;
            (sender_principal, mblock_header_1.sequence)
        };
