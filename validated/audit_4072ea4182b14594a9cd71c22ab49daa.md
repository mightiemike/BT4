The ActiveMQ CVE-2023-46604 vulnerability stems from OpenWire allowing a remote, unauthenticated peer to specify an arbitrary Java class name that gets instantiated via reflection, enabling arbitrary class instantiation from the entire classpath (including gadget classes) — a broken invariant where the deserializer trusts attacker-supplied type information without restricting it to a safe allowlist.

The analogous mechanism in protobuf-go is `Any` type resolution via `FindMessageByURL`, used in `types/known/anypb/any.pb.go` `UnmarshalNew`, `encoding/protojson/well_known_types.go` `unmarshalAny`, and `encoding/prototext/decode.go` `unmarshalExpandedAny`. However, this is fundamentally different from the ActiveMQ flaw: `FindMessageByURL` only resolves the type name against `protoregistry.GlobalTypes` (or a caller-supplied resolver), which only contains message types that are statically linked into the binary via generated-code `init()` registration [1](#0-0) . It cannot instantiate arbitrary classes/types outside of what the Go binary was compiled with — there is no classpath-wide reflective instantiation gadget analogous to Java's `Class.forName` + no-arg-constructor + arbitrary bytecode execution. The resolved type is only ever used with `mt.New()` to construct a zero-value message, and the subsequent `Unmarshal` call operates on the already-well-defined proto wire/JSON/text format for that message type [2](#0-1) .

This does not meet the report's bug-class: there's no reachable code path in protobuf-go where a remote request can cause instantiation of an unintended/arbitrary Go type outside the fixed, developer-controlled proto schema, and no code-execution or class-loading side effect from `New()` on a registered `MessageType`.

func (r *Types) FindMessageByURL(url string) (protoreflect.MessageType, error) {
	// This function is similar to FindMessageByName but
	// truncates anything before and including '/' in the URL.
	if r == nil {
		return nil, NotFound
	}
	if r == GlobalTypes {
		globalMutex.RLock()
		defer globalMutex.RUnlock()
	}
	message := protoreflect.FullName(url)
	if i := strings.LastIndexByte(url, '/'); i >= 0 {
		message = message[i+len("/"):]
	}

	if v := r.typesByName[message]; v != nil {
		if mt, _ := v.(protoreflect.MessageType); mt != nil {
			return mt, nil
		}
		return nil, errors.New("found wrong type: got %v, want message", typeName(v))
	}
	return nil, NotFound
}
