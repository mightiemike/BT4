## Analysis: Slippage protection in Push Chain's PRC20 auto-swap path is derived from a manipulable spot quote (sandwichable)

### Title
Auto-swap slippage bound (`minPCOut`) is derived from a same-transaction spot AMM quote, enabling sandwich extraction of user deposit value - (File: `x/uexecutor/keeper/evm.go`, `x/uexecutor/keeper/execute_inbound_gas.go`, `x/uexecutor/keeper/execute_inbound_gas_and_payload.go`, `x/uexecutor/keeper/outbound.go`)

### Summary
The external report flags Uniswap V3 Factory Owner-style `claimFees` for having *no* slippage protection on a token swap performed on the caller's behalf. Push Chain's analog code — the `GAS`/`GAS_AND_PAYLOAD` inbound auto-swap path and the outbound gas-refund swap-back path — does add a slippage bound, but the bound is computed from `QuoterV2.quoteExactInputSingle`, a live/spot AMM quote fetched via `GetSwapQuote`, immediately before the swap is executed in the same keeper call chain [1](#0-0) . Because both the quote read (`commit=false`) and the swap execution (`commit=true` via `DerivedEVMCall`) reference the current state of the same Uniswap V3 pool, an attacker who moves that pool's price immediately beforehand (a standard sandwich) can force `minPCOut` itself to reflect the manipulated price, defeating the "5% slippage" guard rather than being blocked by it.

### Finding Description
The relevant code paths:
- `ExecuteInboundGas` (GAS inbound type) fetches a quote and computes `minPCOut = quote * 95/100` right before calling `CallPRC20DepositAutoSwap` [2](#0-1) .
- `gasAndPayloadDepositAutoSwap` (GAS_AND_PAYLOAD inbound type) does the identical quote → 95% → swap sequence [3](#0-2) .
- `applyGasRefund` (outbound gas-refund swap-back) does the same pattern via `getSwapQuoteForRefund` [4](#0-3) .

In each case, `GetSwapQuote` calls `quoteExactInputSingle` on the live QuoterV2 contract to obtain `amountOut` for the pool's *current* tick/liquidity state [1](#0-0) , and the resulting `minPCOut` is passed straight into `CallPRC20DepositAutoSwap`/`CallUniversalCoreRefundUnusedGas`, which execute the real swap moments later via `DerivedEVMCall` [5](#0-4) . The upgrade changelog confirms this design intentionally replaced a "0-slippage call" with this on-chain QuoterV2-derived 5% bound [6](#0-5) .

The weakness: `minPCOut` is not an independently-sourced, time-weighted, or off-chain-verified floor — it is 95% of whatever the pool's instantaneous price is at call time. An attacker can:
1. Submit a large PRC20→WPC (or WPC→PRC20) swap against the same Uniswap V3 pool used by `GetSwapQuote`, timed to land in the same block immediately before the core validator's message processing that finalizes the inbound/outbound (a normal, unprivileged AMM interaction — no validator or admin collusion required).
2. This depresses (or inflates) the pool's spot price so that the subsequent `quoteExactInputSingle` call returns a manipulated `amountOut`, and `minPCOut` is computed as 95% of that already-bad price.
3. The module's real swap (`depositPRC20WithAutoSwap` / `refundUnusedGas` with `withSwap=true`) then executes and succeeds against the manipulated price, since it only needs to clear the (also manipulated) `minPCOut` floor — not a fair-market floor.
4. The attacker reverses their position after the module's swap lands, completing a sandwich and pocketing the spread between the fair rate and the manipulated rate, which was extracted from the user's bridged PRC20 (turned into fewer native PC/WPC than a fair swap would have produced) or from the outbound sender's refunded gas token.

This is the same root-cause class as the source report (a caller-provided swap output guaranteed only by a value that is itself attacker-influenceable at execution time), just realized as "quote sourced from the same manipulable pool" rather than "no bound at all."

### Impact Explanation
Depositors using the `GAS`/`GAS_AND_PAYLOAD` inbound routes have their bridged PRC20 auto-swapped to native PC to fund their UEA's gas; outbound senders receive excess gas back via a swap-back leg. In both cases, real user/protocol-controlled value is converted through this swap. A sandwich attack against the same-block/no-TWAP quote lets an unprivileged actor skim value from that conversion on every inbound/outbound that routes through auto-swap — a partial, per-transaction version of "loss of payoutAmount," scaled by the pool's available liquidity and the 5% tolerance band (and further amplified whenever the attacker can push price beyond 5% and still have the transaction clear because the bound itself moved with the manipulated price).

### Likelihood Explanation
Triggering requires only an ordinary EVM transaction against the public PRC20/WPC Uniswap V3 pool, timed relative to the core validator's processing of a `MsgVoteInbound`/`MsgVoteOutbound` finalization — no privileged role, no validator collusion, and no protocol bug beyond the quote-sourcing design. Thinly-liquefied PRC20/WPC pools (likely for newly-listed bridged assets) make this materially cheap to execute.

### Recommendation
Do not derive `minPCOut` from a spot quote fetched in the same call chain as the swap execution. Options: (a) use a TWAP-based quote (Uniswap V3 pools support `observe`/oracle cardinality) with a sufficiently long window that isn't atomically manipulable; (b) source the reference price from `x/uexecutor`'s existing `ChainMeta`/gas-price oracle rather than the AMM being traded against; (c) if a spot AMM quote must be used, widen the slippage tolerance to bound worst-case extraction and/or cap trade size relative to pool depth; (d) as in the original report's recommendation, consider letting the flow fail safely (revert to no-swap deposit) whenever quote staleness/manipulation cannot be bounded, rather than always allowing the swap leg to proceed on a self-referential quote.

### Proof of Concept
1. Attacker identifies a PRC20↔WPC Uniswap V3 pool used for a token with an active `GAS`/`GAS_AND_PAYLOAD` inbound in flight (visible once 2/3 UV votes have accumulated on a `MsgVoteInbound`, since finalization triggers execution on the next matching vote).
2. Attacker submits (or has pending) a large swap against that pool in the same block window, depressing the PRC20→WPC price.
3. The core validator processes the finalizing vote, calling `GetSwapQuote` (`x/uexecutor/keeper/evm.go:500-538`) against the now-manipulated pool, then `CallPRC20DepositAutoSwap` (`evm.go:540-593`) with `minPCOut` computed at 95% of that manipulated quote (`execute_inbound_gas.go:134-153`).
4. The deposit's PRC20 is swapped into native PC at the depressed rate, clearing the (also depressed) `minPCOut` check.
5. Attacker reverses their initial swap, realizing a profit equal to the price impact minus fees, extracted from the value that should have accrued to the depositing user's UEA.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)
}

	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	nonce, err := k.GetModuleAccountNonce(ctx)

		return nil, err

		return nil, err

		&nonce,

		amount,
		recipient,

	)

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}
