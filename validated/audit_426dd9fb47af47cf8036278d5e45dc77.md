## Analog Found: Spot-price slippage guard for the protocol's mandatory autoswap can be sandwiched

### Title
Manipulable spot-price `minPCOut` slippage guard lets an attacker sandwich the protocol-driven `depositPRC20WithAutoSwap` conversion - (File: `x/uexecutor/keeper/evm.go`, `x/uexecutor/keeper/execute_inbound_gas.go`, `x/uexecutor/keeper/execute_inbound_gas_and_payload.go`)

### Summary
The original report shows that `SingleSidedLiquidityVault` is exploitable because its only safety check (`isPoolSafe` / `THRESHOLD`) is derived from the *same manipulable AMM pool* that the attacker trades against to extract value from a mint/deposit → trade → withdraw loop. Push Chain has a structurally identical pattern in the `GAS` and `GAS_AND_PAYLOAD` inbound execution paths: the module unconditionally swaps the bridged PRC20 for WPC through a live Uniswap V3 pool and protects the swap with `minPCOut`, computed as 95% of a **spot** `QuoterV2.quoteExactInputSingle` result taken in the same execution as the swap itself.

### Finding Description
`Keeper.GetSwapQuote` [1](#0-0)  calls `QuoterV2.quoteExactInputSingle` against the live pool state to get `amountOut`, and the caller immediately derives `minPCOut = quote * 95 / 100` [2](#0-1) [3](#0-2) , then passes it straight into `CallPRC20DepositAutoSwap` → `depositPRC20WithAutoSwap` on `UniversalCore` [4](#0-3) .

Both the quote and the guarded swap read/execute against the *same* on-chain pool state, in the *same* block/transaction context that finalizes the inbound (triggered once 2/3 Universal Validators vote — an event whose landing an attacker can observe in the mempool). This is the same failure mode as the sherlock H-2 report: the "safety" bound is computed from a spot price that the attacker itself can move immediately beforehand, so the bound protects nothing against a price that has just been manipulated. An unprivileged user can:
1. Submit a swap on the public PRC20/WPC Uniswap V3 pool to shift the spot price in a favorable direction.
2. Trigger (or wait for) their own bridged `GAS`/`GAS_AND_PAYLOAD` inbound to finalize in the same block, so the module's `depositPRC20WithAutoSwap` executes against the now-skewed price — the 5% tolerance is computed off that same skewed price, so it does not block execution.
3. Reverse the initial swap immediately after, restoring the pool and capturing the price-impact/fee spread as profit, funded by whatever counter-value (WPC/PC) the protocol's swap paid into the pool.

This mirrors the report's core insight almost exactly: "the fee/threshold only slightly impacts profitability... it is impossible to make this kind of attack unprofitable [with a fixed tolerance], tighter thresholds just increase the capital required."

### Impact Explanation
Every `GAS` and `GAS_AND_PAYLOAD` inbound (i.e. ordinary user bridging flow, no privileged actor needed) is exposed to this pattern, letting an attacker extract value from the protocol's own conversion at the expense of whatever backs the PRC20/WPC pool. Because the trigger is a routine bridging deposit, the attack surface is broad and reusable per inbound.

### Likelihood Explanation
Requires only ordinary EVM transactions around the block containing the inbound's ballot finalization — no validator collusion, no privileged role, and no external chain dishonesty. The 5% tolerance is a fixed constant, not tied to a robust oracle/TWAP, so it is trivially satisfiable after a same-block spot-price shift.

### Recommendation
Do not derive slippage protection from a same-block/same-transaction spot quote of a manipulable pool. Use a time-weighted average price (TWAP) oracle, a maximum single-block price deviation check backed by an external reference price (e.g., `ChainMeta`/oracle price), or execute the autoswap deterministically outside of the same block in which price could be freshly manipulated, and tighten/adjust tolerance based on trade size relative to pool depth rather than a flat percentage.

### Proof of Concept
Conceptual, mirroring the original report's numeric walkthrough:
1. Attacker swaps X→WPC on-chain to shift the PRC20-X/WPC pool spot price.
2. Attacker's own previously-submitted bridging tx for asset X reaches quorum in the same block; `ExecuteInboundGas`/`ExecuteInboundGasAndPayload` calls `gasAndPayloadDepositAutoSwap` → `GetSwapQuote` (reads the just-manipulated spot price) → `minPCOut = quote*0.95` → `CallPRC20DepositAutoSwap` executes at the skewed price [5](#0-4) .
3. Attacker reverses the initial WPC→X swap, restoring price and netting the price-impact/fee differential, exactly as the original report's "deposit → trade within threshold → withdraw → dump" loop netted 0.499 stETH per cycle.

```go
// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
```

```go
// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)
}
```

```go
// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
```
