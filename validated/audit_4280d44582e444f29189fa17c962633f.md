### Title
Fixed 5% slippage tolerance on module-executed auto-swaps enables sandwich extraction of bridged user funds - (File: x/uexecutor/keeper/execute_inbound_gas.go, x/uexecutor/keeper/execute_inbound_gas_and_payload.go, x/uexecutor/keeper/outbound.go)

### Summary
Whenever `x/uexecutor` needs to convert a bridged PRC20 gas token into native PC — during `GAS`/`GAS_AND_PAYLOAD` inbound execution (`ExecuteInboundGas`, `gasAndPayloadDepositAutoSwap`) and during excess-gas refunds on outbound completion (`applyGasRefund`) — it fetches a live spot quote from the on-chain Uniswap-v3-style `QuoterV2` via `GetSwapQuote`, and unconditionally derives `minPCOut = quote * 95 / 100`, a fixed 5% slippage bound computed from the *current, manipulable* pool price rather than any protocol-set or oracle-anchored reference price. It then immediately submits the swap via `CallPRC20DepositAutoSwap` / `CallUniversalCoreRefundUnusedGas` in the same execution context. This mirrors the BCCR report's underlying pattern: a threshold/guard value (`minPCOut`, analogous to `CCR`) is computed on the fly from state an unprivileged actor can move (pool price, analogous to TCR) immediately before the guarded action executes, so the guard offers no real protection against value extraction timed around it.

### Finding Description
`GetSwapQuote` (x/uexecutor/keeper/evm.go:500-538) is a static `CallEVM` (`commit=false`) read of `QuoterV2.quoteExactInputSingle` against the live pool reserves at the moment of execution. Both call sites that use it compute the slippage floor immediately from that same read:
- `ExecuteInboundGas` (execute_inbound_gas.go:126-146): quote → `minPCOut = quote*95/100` → `CallPRC20DepositAutoSwap` executed in the same keeper call, with no cross-check against any independent price reference (e.g. the `ChainMeta`/gas-price oracle, or a max-deviation clamp).
- `gasAndPayloadDepositAutoSwap` (execute_inbound_gas_and_payload.go:347-379): identical pattern for `GAS_AND_PAYLOAD` inbounds.
- `applyGasRefund` (outbound.go:174-257): identical pattern for excess-gas refunds on outbound completion, feeding straight into `CallUniversalCoreRefundUnusedGas`.

Because inbound/outbound execution is deterministically triggered the moment ballot/vote quorum is reached (this is itself attacker-influenceable — the attacker controls when they submit the triggering deposit, and once enough honest UV votes land the finalize-and-execute path runs in that same block), and because the swap executes against the Push Chain-local Uniswap pool for PRC20↔WPC pairs, an attacker who can move that pool's price (e.g., by holding a large position in the same pool, or by front-running/back-running the finalizing vote transaction with their own swap in the mempool of the same block) can depress the quoted price right before `minPCOut` is computed, and then correct it afterward, extracting the difference. Unlike a typical two-transaction sandwich, the 5% band is fixed regardless of trade size, pool depth, or volatility, so it under-protects large bridged amounts and low-liquidity PRC20/WPC pools particularly.

This is structurally the same invariant gap as the CDP report: a state-dependent guard (`minPCOut`/`CCR`) is derived from a value the attacker can shift (`pool price`/`TCR`) in the same window as the guarded action (`the auto-swap`/`closeCdp`), so satisfying the guard does not guarantee the outcome is fair to the victim (`the depositing/refunded user`/`the sniped CDP owner`).

### Impact Explanation
A successful attack degrades the amount of native PC a bridging user or gas-refund recipient receives for their deposited/unused gas token — a direct, if bounded (capped at ~5% of swap notional per call plus the fallback-to-no-swap path in `applyGasRefund`), loss of protocol/user value. Given `x/uexecutor` is the sole path issuing these auto-swaps for every GAS and GAS_AND_PAYLOAD inbound and every outbound gas refund, the surface is exercised continuously and the loss compounds across all bridged transactions on any thin-liquidity PRC20/WPC pool.

### Likelihood Explanation
Likelihood is medium: it requires the attacker to control or influence the Push Chain-local Uniswap pool price for the specific PRC20↔WPC pair at the exact block where inbound/outbound execution fires, which is feasible for low-liquidity pools and is not gated by any privileged role — any address can trade on the pool and any address can submit the deposit that (once voted) triggers the auto-swap in the same/adjacent block.

### Recommendation
Anchor `minPCOut` to an independent, harder-to-manipulate reference (e.g., the validator-voted `ChainMeta`/gas-price oracle, a TWAP quote from the pool, or a governance-set max-deviation from a recent moving average) rather than a fixed percentage of the instantaneous spot quote, and/or clamp the maximum single-block price impact the module will accept before falling back to the no-swap PRC20 deposit path that already exists in `applyGasRefund`.

### Proof of Concept
1. Attacker identifies a PRC20/WPC pool on Push Chain's Uniswap-v3-style DEX with shallow liquidity, used by `GetUniversalCoreQuoterAddress`/`GetUniversalCoreWPCAddress` for a given gas token.
2. Attacker prepares a large swap that depresses the PRC20→WPC price in that pool.
3. Attacker (or a colluding victim-adjacent bridging flow) submits a deposit/inbound (`GAS` or `GAS_AND_PAYLOAD` tx type) for that PRC20 token, or waits for a pending outbound that will refund excess gas in that token.
4. Immediately before/around the block where Universal Validator votes finalize quorum and `ExecuteInboundGas`/`applyGasRefund` fires, attacker executes the price-depressing swap so `GetSwapQuote` returns a depressed `quote`.
5. `minPCOut = quote*95/100` is computed from the depressed price; `CallPRC20DepositAutoSwap`/`CallUniversalCoreRefundUnusedGas` executes at up to 5% below fair value.
6. Attacker reverses the price-depressing swap, capturing the difference paid by the underfilled swap, while the bridging user/refund recipient receives less native PC than the fair-price quote would have implied.

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}
