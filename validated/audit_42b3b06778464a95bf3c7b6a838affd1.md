## Analysis



### Title
Forged `send_funds` inbound event via unattributed `Program data:` log scanning — (File: universalClient/chains/svm/event_listener.go, universalClient/chains/svm/event_parser.go)

### Summary
The SVM event listener determines that a log line represents a genuine gateway `send_funds` event purely by (a) the transaction merely *referencing* the gateway address as one of its accounts, and (b) any log line in that transaction starting with `Program data: ` whose first 8 decoded bytes equal a known discriminator. It never verifies that the `Program data:` line was actually emitted from inside a CPI/invocation of the real gateway program.

### Finding Description
`processSignatureBatch` in [1](#0-0)  discovers candidate transactions via `GetSignaturesForAddress(ctx, gatewayAddr, ...)`. Solana's `getSignaturesForAddress` RPC returns any confirmed transaction where the given pubkey appears anywhere in the transaction's account list — it does not require that the address be the invoked program, a signer, or writable.

For every log line in such a transaction, `determineEventType` in [2](#0-1)  only checks the `"Program data: "` prefix and matches the leading 8 bytes against `discriminatorToEventType`. There is no correlation with the surrounding `Program <id> invoke [n]` / `Program <id> success` log markers that Solana's runtime uses to delimit which program actually produced a given log line.

`ParseEvent` → `parseSendFundsEvent` → `decodeUniversalTxEvent` then decode the raw bytes as `sender`, `recipient`, `bridge_token`, `bridge_amount`, arbitrary `payload`, `revert_recipient`, `tx_type`, and `fromCEA`, with only length/bounds checks and no origin/authenticity check [3](#0-2) .

Consequently, an attacker can submit a Solana transaction that:
1. Lists the real gateway program address as a (read-only, non-signer) account so the transaction is returned by `GetSignaturesForAddress`.
2. Invokes an attacker-deployed, unrelated program that simply logs `msg!("Program data: {base64}")`/`sol_log_data` with the first 8 bytes equal to the known `send_funds` discriminator, followed by attacker-chosen bytes for sender/recipient/token/amount/payload/revert_recipient/tx_type.

Because honest observer nodes running this same code will all read the same public chain data and reach the same (wrong) decoded event, this is not a malicious-validator scenario — it is a forged, unauthenticated inbound event accepted through the ordinary observation pipeline that honest validators will converge on identically.

### Impact Explanation
A successfully forged event is inserted into local store as a pending `EventTypeInbound` UniversalTx with attacker-chosen `Amount`, `Token`, `Recipient`, and `RawPayload` [4](#0-3) . If this event flows through the normal inbound voting/finalization pipeline (outside the files read here but standard for this architecture), it can result in unauthorized minting/release of PRC20 or native value to an attacker-controlled recipient on Push Chain with no corresponding real deposit on Solana — a direct violation of the "only well-formed SVM gateway bytes can become an inbound observation" invariant, and a fund-theft/inflation impact.

### Likelihood Explanation
The entrypoint requires no privileged access: any Solana account can submit a transaction listing the gateway address among its accounts (any role) while invoking an attacker-owned program that logs the forged discriminator + fields. This is trivially achievable with standard Solana tooling. The only gate is knowledge of the 8-byte discriminator, which is public (loaded from on-chain `GatewayMethods` metadata / IDL and observable from historical genuine `send_funds` logs).

### Recommendation
Bind log parsing to actual program provenance:
- Track the Solana runtime invoke stack while iterating `tx.Meta.LogMessages` (parsing `Program <id> invoke [n]` / `Program <id> success` boundaries) and only treat a `Program data:` line as a candidate gateway event if it was emitted while the *currently active* program on the stack equals the configured `gatewayAddress`.
- Alternatively/additionally, verify via `tx.Meta.InnerInstructions`/`tx.Transaction.Message.Instructions` that the gateway program ID was actually invoked (directly or via CPI) at the point corresponding to that log, rather than relying solely on `GetSignaturesForAddress` returning the tx and a bare discriminator match on unattributed log text.

### Proof of Concept
1. Deploy a throwaway Solana program `Fake` that does: `sol_log_data(&[fake_bytes])` where `fake_bytes` = `send_funds` discriminator (8 bytes) || attacker-controlled `sender`(32) || `recipient`(20, attacker's target UEA) || `bridge_token`(32) || `bridge_amount`(8, arbitrary large value) || `data_len=0`(4) || `revert_recipient`(32) || `tx_type`(1) || `sig_len=0`(4) || `fromCEA`(1).
2. Submit a transaction that includes the real gateway program's pubkey as a read-only account (e.g., as an unrelated remaining account) and invokes `Fake` with the crafted log.
3. Confirm that Push Chain's SVM `EventListener.processSignatureBatch` (via `GetSignaturesForAddress` on the gateway address) picks up this signature, `determineEventType` matches the `send_funds` discriminator on the forged log line, and `decodeUniversalTxEvent` decodes and stores a pending inbound `UniversalTx` event with attacker-chosen recipient/amount/token — without any real gateway deposit having occurred. func (el *EventListener) processSignatureBatch(
	ctx context.Context,
	batch []*solanarpc.TransactionSignature,
	fromSlot, toSlot uint64,
) (uint64, error) {
	var processed uint64
	for _, sig := range batch {
		if sig.Slot < fromSlot {
			continue
		}
		if sig.Slot > toSlot {
			continue
		}
		processed++

		// Get transaction details
		tx, err := el.rpcClient.GetTransaction(ctx, sig.Signature)
		if err != nil {
			el.logger.Error().
				Err(err).
				Str("signature", sig.Signature.String()).
				Msg("failed to get transaction")
			continue
		}

		// Process each log in the transaction
		if tx != nil && tx.Meta != nil && len(tx.Meta.LogMessages) > 0 {
			for logIndex, log := range tx.Meta.LogMessages {
				// Determine event type based on discriminator
				eventType := el.determineEventType(log)
				if eventType == "" {
					continue
				}

				// Parse gateway event from individual log
				event := ParseEvent(log, sig.Signature.String(), sig.Slot, uint(logIndex), eventType, el.chainID, el.logger)

// determineEventType determines the event type based on the log discriminator
func (el *EventListener) determineEventType(log string) string {
	if !strings.HasPrefix(log, "Program data: ") {
		return ""
	}

	eventData := strings.TrimPrefix(log, "Program data: ")
	decoded, err := base64.StdEncoding.DecodeString(eventData)
	if err != nil {
		return ""
	}

	if len(decoded) < 8 {
		return ""
	}

	discriminator := strings.ToLower(hex.EncodeToString(decoded[:8]))

	// Look up event type from discriminator map
	eventType, ok := el.discriminatorToEventType[discriminator]
	if !ok {
		return ""
	}

	return eventType
}

// parseSendFundsEvent parses a sendFunds event as UniversalTx
func parseSendFundsEvent(log string, signature string, slot uint64, logIndex uint, chainID string, logger zerolog.Logger) *store.Event {
	if !strings.HasPrefix(log, "Program data: ") {
		return nil
	}

	eventData := strings.TrimPrefix(log, "Program data: ")
	decoded, err := base64.StdEncoding.DecodeString(eventData)
	if err != nil {
		return nil
	}

	if len(decoded) < 8 {
		return nil
	}

	// Create EventID in format: signature:LogIndex
	eventID := fmt.Sprintf("%s:%d", signature, logIndex)

	logger.Debug().
		Str("event_id", eventID).
		Str("signature", signature).
		Uint("log_index", logIndex).
		Uint64("slot", slot).
		Msg("processing sendFunds event")

	// Create store.Event
	event := &store.Event{
		EventID:           eventID,
		BlockHeight:       slot,
		Type:              store.EventTypeInbound, // Gateway events from external chains are INBOUND
		Status:            store.StatusPending,
		ExpiryBlockHeight: 0, // Will be set based on confirmation type if needed
	}

	// Parse event data from this log
	parseUniversalTxEvent(event, decoded, logIndex, chainID, logger)

	return event

// decodeUniversalTxEvent decodes a TxWithFunds event
func decodeUniversalTxEvent(data []byte, logger zerolog.Logger) (*common.UniversalTx, error) {
	if len(data) < 120 {
		logger.Warn().
			Int("data_len", len(data)).
			Msg("data might be too short for complete TxWithFunds event")
	}

	offset := 8
	payload := &common.UniversalTx{}

	// Parse sender (32 bytes)
	if len(data) < offset+32 {
		return nil, fmt.Errorf("not enough data for sender")
	}
	sender := solana.PublicKey(data[offset : offset+32])
	// Convert sender to hex format
	senderHex, err := base58ToHex(sender.String())
	if err != nil {
		logger.Warn().Err(err).Msg("failed to convert sender to hex, using base58")
		payload.Sender = sender.String()
	} else {
		payload.Sender = senderHex
	}
	offset += 32

	// Parse recipient (20 bytes - byte20 format)
	if len(data) < offset+20 {
		return nil, fmt.Errorf("not enough data for recipient")
	}
	// Convert 20 bytes to hex string (0x + 40 hex chars)
	recipientBytes := data[offset : offset+20]
	payload.Recipient = "0x" + hex.EncodeToString(recipientBytes)
	offset += 20

	// Parse bridge_token (32 bytes)
	if len(data) < offset+32 {
		return nil, fmt.Errorf("not enough data for bridge_token")
	}
	bridgeToken := solana.PublicKey(data[offset : offset+32])
	payload.Token = bridgeToken.String()
	offset += 32

	// Parse bridge_amount (8 bytes)
	if len(data) < offset+8 {
		return nil, fmt.Errorf("not enough data for bridge_amount")
	}
	bridgeAmount := binary.LittleEndian.Uint64(data[offset : offset+8])
	payload.Amount = fmt.Sprintf("%d", bridgeAmount)
	offset += 8

	// Parse data field length (4 bytes)
	if len(data) < offset+4 {
		logger.Warn().Msg("not enough data for data field length")
		return payload, nil
	}
	dataLen := binary.LittleEndian.Uint32(data[offset : offset+4])
	offset += 4

	// Parse data field
	if len(data) < offset+int(dataLen) {
		logger.Warn().
			Uint32("expected_len", dataLen).
			Int("available", len(data)-offset).
			Msg("not enough data for data field")
		return payload, nil
	}
	if dataLen > 0 {
		dataField := data[offset : offset+int(dataLen)]
		payload.RawPayload = "0x" + hex.EncodeToString(dataField)
		offset += int(dataLen)
	}

	// Parse revert_recipient (Pubkey)
	if len(data) < offset+32 {
		logger.Warn().Msg("not enough data for revert recipient")
		return payload, nil
	}
	revertRecipient := solana.PublicKey(data[offset : offset+32])
	payload.RevertFundRecipient = revertRecipient.String()
	offset += 32

	// Parse tx_type (TxType enum)
	if len(data) <= offset {
		logger.Warn().Msg("not enough data for tx_type, defaulting to Funds")
		payload.TxType = uint(0)
		return payload, nil
	}
	txType := data[offset]
	payload.TxType = uint(txType)
	offset++
