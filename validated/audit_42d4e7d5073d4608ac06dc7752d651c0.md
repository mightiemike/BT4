### Title
Hardcoded 5% slippage against a single-block, non-TWAP Uniswap V3 spot quote enables sandwich extraction of PRC20→WPC auto-swap value - (File: x/uexecutor/keeper/evm.go, x/uexecutor/keeper/execute_inbound_gas.go, x/uexecutor/keeper/execute_inbound_gas_and_payload.go, x/uexecutor/keeper/outbound.go)

### Summary
Every automatic PRC20→WPC conversion performed by the `uexecutor` module (gas-only inbound deposits, gas+payload inbound deposits, and unused-gas refunds) derives its slippage protection from a single call to `QuoterV2.quoteExactInputSingle`, an instantaneous simulated spot price against the module's own Uniswap V3 pool, and then applies a fixed, hardcoded 95% (5% slippage) floor. There is no TWAP, no external price reference, and no keeper/relayer-supplied `minOut` — the exact failure mode the C4 report describes for `CrvDepositorWrapper`, just with an AMM spot quote instead of a stale Balancer TWAP.

### Finding Description
`Keeper.GetSwapQuote` calls the Uniswap V3 `QuoterV2.quoteExactInputSingle` (a simulated, non-committed call against current pool reserves) to obtain `amountOut` for a given `prc20 → wpc` amount: [1](#0-0) 

That instantaneous quote is then used directly, in the same top-level function invocation, to compute `minPCOut` as `quote * 95 / 100` before immediately executing the real swap via `CallPRC20DepositAutoSwap`: [2](#0-1) 

The identical pattern — quote, then `95%` floor, then execute — is repeated for GAS_AND_PAYLOAD inbound deposits: [3](#0-2) 

and for unused-gas refund swaps on outbound finalization: [4](#0-3) 

The fee tier and quoter/WPC addresses used to select the pool are read from `UniversalCore` (`defaultFeeTier`, `uniswapV3Quoter`, `WPC`), but nothing about the pool itself is TWAP-protected — `quoteExactInputSingle` reflects whatever the pool's reserves are at the moment the module calls it: [5](#0-4) [6](#0-5) 

Because these swaps are triggered deterministically by inbound-vote finalization / outbound-observation finalization (ordinary, unprivileged user flows — a user deposits funds on an external chain, relayers observe and vote, and once quorum is reached the module executes the swap in the same block/transaction as the finalizing vote), an unprivileged actor who can observe the mempool or otherwise anticipate finalization can:
1. Front-run with a large swap against the same low/thin-liquidity WPC/PRC20 pool to push the spot price to an extreme.
2. Let the module's `GetSwapQuote` + `CallPRC20DepositAutoSwap` execute against the manipulated price — the 95% floor is computed from the *already-manipulated* quote, so it does not protect against pre-existing manipulation, only against price movement occurring strictly between the quote read and the swap execution.
3. Back-run to restore the pool price, capturing the value that should have gone to the deposited-fund recipient / gas-refund recipient.

This mirrors the audited issue precisely: reliance on an easily-influenced, non-time-weighted on-chain price feed combined with a generous fixed slippage tolerance, rather than a keeper-provided `minOut` computed from a manipulation-resistant reference price.

### Impact Explanation
Successful manipulation directly corrupts PRC20/native asset accounting for the affected `UniversalTx`/`OutboundTx`: the UEA/recipient receives less WPC than the fair-value conversion of the deposited/refunded PRC20 amount, while the attacker captures the difference via the sandwich. This is unauthorized value extraction from user- and protocol-controlled funds during a core, unprivileged, default execution path (`ExecuteInboundGas`, `ExecuteInboundGasAndPayload`, `applyGasRefund`), matching the in-scope "corruption of PRC20 or native asset accounting … refund accounting" and "stealing … of user or protocol-controlled funds" impact categories.

### Likelihood Explanation
Likelihood depends on the liquidity depth of the specific WPC/PRC20 pool used for a given token — for low-volume or newly listed PRC20 tokens (directly analogous to the thin 20/80 WETH/BAL pool in the original report), a modest amount of capital is sufficient to move the spot price meaningfully within one block, and the swap trigger (vote/observation finalization) is deterministic and externally observable, making the attack practically executable by any unprivileged actor with capital and mempool visibility.

### Recommendation
Do not derive `minPCOut` solely from an instantaneous `quoteExactInputSingle` call taken immediately before execution. Use a manipulation-resistant reference (e.g., a Uniswap V3 TWAP over a meaningful window, or a Chainlink/external price feed) to bound acceptable slippage, and/or let relayers/keepers supply a validated `minOut` that is checked against a governance-configured maximum deviation from a trusted reference price rather than a fixed percentage of the same-block spot quote.

### Proof of Concept
1. Attacker identifies a PRC20/WPC pool (selected via `defaultFeeTier`) with limited liquidity.
2. Attacker deposits funds on the source chain corresponding to a `GAS` or `GAS_AND_PAYLOAD` inbound, triggering relayer observation and eventual `ExecuteInboundGas`/`ExecuteInboundGasAndPayload` execution once validator quorum is reached (a normal, unprivileged deposit flow).
3. In the same block (or immediately prior), attacker submits a large swap against the pool to skew the price so that `GetSwapQuote` (x/uexecutor/keeper/evm.go:502-538) returns an inflated `amountOut` quote for a small amount of PRC20 input, or otherwise positions the pool state to their advantage.
4. `minPCOut = quote * 95 / 100` (x/uexecutor/keeper/execute_inbound_gas.go:142-146) is computed off the manipulated quote and easily satisfied by `CallPRC20DepositAutoSwap`, executing the swap at the manipulated price.
5. Attacker reverses their swap, restoring the pool to its prior price and pocketing the extracted value; the deposit recipient/refund recipient receives less WPC than fair value.

// GetUniversalCoreQuoterAddress reads the uniswapV3Quoter address stored in UniversalCore.
func (k Keeper) GetUniversalCoreQuoterAddress(ctx sdk.Context) (common.Address, error) {
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return common.Address{}, errors.Wrap(err, "failed to parse UniversalCore ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	receipt, err := k.evmKeeper.CallEVM(ctx, abi, ueModuleAccAddress, handlerAddr, false, nil, "uniswapV3Quoter")
	if err != nil {
		return common.Address{}, errors.Wrap(err, "failed to call uniswapV3Quoter")
	}

	results, err := abi.Methods["uniswapV3Quoter"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return common.Address{}, errors.Wrap(err, "failed to unpack uniswapV3Quoter result")
	}

	return results[0].(common.Address), nil
}

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}
