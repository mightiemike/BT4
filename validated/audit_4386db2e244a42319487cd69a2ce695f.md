## Title
`MsgExecutePayload`'s gasless status combined with an unbounded `UniversalPayload.Data`/`GasLimit` field lets an unprivileged attacker force free, unbounded EVM execution — (File: `app/txpolicy/gasless.go`, `x/uexecutor/types/universal_payload.go`, `x/uexecutor/keeper/evm.go`)

### Summary
The Hats.uri finding is a case of an attacker-controlled string field with no size limit that becomes expensive to process, and that the victim/caller pays for. The Push Chain analog is `MsgExecutePayload`: its `UniversalPayload.Data` (arbitrary hex calldata) and `UniversalPayload.GasLimit` (attacker-chosen, unbounded numeric string) have no length/size cap in validation, and this exact message type is on the **gasless whitelist**, meaning the sender pays neither a fee nor a minimum gas price for whatever gas the resulting EVM call consumes. This lets any unprivileged UEA owner submit large/expensive payloads at zero cost, repeatedly, consuming validator compute and block gas space for free.

### Finding Description
`UniversalPayload.ValidateBasic` only checks that `Data` decodes as valid hex — there is no maximum length check: [1](#0-0) 

`MsgExecutePayload.ValidateBasic` likewise validates structure/format but never bounds the size of `UniversalPayload.Data` or the magnitude of `UniversalPayload.GasLimit`: [2](#0-1) 

`MsgExecutePayload` is included in the gasless allowlist (`app/txpolicy/gasless.go`), so both `DeductFeeDecorator` and `MinGasPriceDecorator` fully skip fee/min-gas-price checks for it: [3](#0-2) [4](#0-3) [5](#0-4) 

The `GasLimit` string is parsed directly from the attacker's payload and passed straight through to a real, module-issued EVM call via `DerivedEVMCall`, with no upper-bound check against a sane maximum: [6](#0-5) 

Because `MsgExecutePayload` requires only a valid signature over the sender's own UEA (`verificationData`), which any address can generate for itself, this is fully permissionless — no validator/admin/TSS privilege is needed to trigger it, unlike `MsgVoteInbound`/`MsgVoteOutbound` which require a bonded Universal Validator.

### Impact Explanation
An attacker can craft `MsgExecutePayload` transactions with a large `Data` blob and a large `GasLimit` (bounded only by the tx's own `GasWanted`, which itself needs no fee to be honored because the tx is gasless), and submit them repeatedly. Each such transaction:
- Costs the attacker nothing (fee = 0, no min-gas-price enforcement).
- Forces the node to perform real EVM execution (via `CallUEAExecutePayload` → `DerivedEVMCall`) up to the attacker-chosen gas limit.
- Occupies real block gas space that would otherwise go to legitimate transactions, degrading throughput for all users — a denial-of-service condition reachable purely through the ordinary unprivileged `MsgExecutePayload` submission path, at effectively zero cost to the attacker (in contrast with the original Hats report, where the attacker at least had to pay real gas to write the oversized string).

### Likelihood Explanation
High. Creating and controlling a UEA is free and permissionless (self-service via `DeployUEAV2`/auto-deploy), and constructing a valid `verificationData` signature over one's own payload requires no special access. No existing guard limits `Data` length or `GasLimit` magnitude before the transaction is accepted as gasless and processed.

### Recommendation
- Enforce a maximum length on `UniversalPayload.Data` in `UniversalPayload.ValidateBasic`.
- Enforce a maximum value on `UniversalPayload.GasLimit` (e.g., capped to a fraction of the block gas limit) in `ValidateBasic` and/or before it is forwarded to `DerivedEVMCall`.
- Consider excluding `MsgExecutePayload` from the gasless allowlist, or applying a stricter gas/size ceiling specifically for gasless-eligible messages, since it is the only gasless message type triggerable by an arbitrary unprivileged address rather than a bonded Universal Validator.

### Proof of Concept
1. Attacker deploys/self-funds a UEA for an address they control (permissionless, `DeployUEAV2`/auto-deploy path).
2. Attacker crafts `UniversalPayload{ Data: <e.g. 1MB of hex>, GasLimit: "<near block gas limit>", ... }` and a valid `verificationData` signature over it, matching the fixtures used in `test/integration/uexecutor/execute_payload_test.go`.
3. Attacker submits `MsgExecutePayload` as a standalone gasless tx (fee = 0). `IsGaslessTx` returns true, so `DeductFeeDecorator`/`MinGasPriceDecorator` skip all fee checks (`app/txpolicy/gasless.go`, `app/ante/fee.go:59-64`).
4. `ExecutePayload`/`ExecutePayloadV2` calls `CallUEAExecutePayload`, which forwards the attacker-chosen `GasLimit` unmodified into `DerivedEVMCall` (`x/uexecutor/keeper/evm.go:172-193`), causing the node to execute up to that much gas for free.
5. Repeating this across blocks consumes disproportionate block gas capacity at zero cost, degrading throughput for legitimate users.

// ValidateBasic does a sanity check on the provided data.
func (msg *MsgExecutePayload) ValidateBasic() error {
	// Validate signer
	if _, err := sdk.AccAddressFromBech32(msg.Signer); err != nil {
		return errors.Wrap(err, "invalid signer address")
	}

	// Validate universalAccountId
	if msg.UniversalAccountId == nil {
		return errors.Wrap(sdkerrors.ErrInvalidRequest, "universal account cannot be nil")
	}

	// Validate universal payload
	if msg.UniversalPayload == nil {
		return errors.Wrap(sdkerrors.ErrInvalidRequest, "universal payload cannot be nil")
	}

	// Validate verificationData
	if len(msg.VerificationData) == 0 {
		return errors.Wrap(sdkerrors.ErrInvalidRequest, "verificationData cannot be empty")
	}
	if _, err := hex.DecodeString(strings.TrimPrefix(msg.VerificationData, "0x")); err != nil {
		return errors.Wrap(sdkerrors.ErrInvalidRequest, "invalid verificationData hex")
	}

	// Validate universalAccountId structure
	if err := msg.UniversalAccountId.ValidateBasic(); err != nil {
		return errors.Wrap(err, "invalid universalAccountId")
	}

	// Validate universal payload structure
	if err := msg.UniversalPayload.ValidateBasic(); err != nil {
		return errors.Wrap(err, "invalid universal payload")
	}

	return nil
}

// CallUEAExecutePayload executes a universal payload through UEA
func (k Keeper) CallUEAExecutePayload(
	ctx sdk.Context,
	from, ueaAddr common.Address,
	universal_payload *types.UniversalPayload,
	verificationData []byte,
) (*evmtypes.MsgEthereumTxResponse, error) {
	abi, err := types.ParseUeaABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse UEA ABI")
	}

	abiUniversalPayload, err := types.NewAbiUniversalPayload(universal_payload)
	if err != nil {
		return nil, errors.Wrapf(err, "failed to create universal payload")
	}

	gasLimit := new(big.Int)
	gasLimit, ok := gasLimit.SetString(universal_payload.GasLimit, 10)
	if !ok {
		return nil, fmt.Errorf("invalid gas limit: %s", universal_payload.GasLimit)
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		from,
		ueaAddr,
		big.NewInt(0),
		gasLimit,
		true,  // commit = true (real tx, not simulation)
		false, // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		false, // not a module sender
		nil,
		"executeUniversalTx",
		abiUniversalPayload,
		verificationData,
	)
}
