### Title
Sandwichable spot-price auto-swap in inbound gas-abstraction execution allows value extraction from user deposits - (File: x/uexecutor/keeper/execute_inbound_gas.go)

### Summary
`ExecuteInboundGas` and `ExecuteInboundGasAndPayload` (and the gas-refund path in `outbound.go`) perform a module-initiated, protocol-funded swap of a deposited PRC20 gas token into WPC using a spot price quote fetched from `QuoterV2.quoteExactInputSingle` and a fixed 5% slippage band (`minPCOut = quote * 95/100`), with the quote-fetch and the swap execution happening back-to-back in the same transaction/block. Because the quote is a live spot price rather than a time-weighted average, an unprivileged actor can manipulate the underlying Uniswap V3 pool's price immediately around the block in which this swap executes and extract value up to the 5% slippage tolerance from the module/user funds, exactly mirroring the "proactive sandwiching of gulp calls" bug class.

### Finding Description
When a `GAS` or `GAS_AND_PAYLOAD` inbound reaches voting quorum, `ExecuteInboundGas` computes a swap quote and immediately swaps: [1](#0-0) 
using [2](#0-1) 
which calls the AMM pool's `quoteExactInputSingle` for the *current* pool state (spot price), not a moving-average oracle. The resulting `minPCOut` tolerates up to 5% deviation from that spot price: [3](#0-2) 

The same spot-quote + fixed-5%-slippage pattern is repeated in `gasAndPayloadDepositAutoSwap` for `GAS_AND_PAYLOAD` inbounds: [4](#0-3) 
and again in the outbound gas-refund path `applyGasRefund`, which swaps the excess gas token back to PC using the identical 5% band derived from a fresh spot quote: [5](#0-4) 

In all three call sites the quote fetch (`GetSwapQuote`, a `commit=false` static call reading live pool reserves) and the actual state-changing swap (`CallPRC20DepositAutoSwap` / `CallUniversalCoreRefundUnusedGas`, both real `DerivedEVMCall`s) happen in the same keeper invocation, which itself executes synchronously as soon as UV vote quorum is reached inside a single block. There is no commitment/reveal, no TWAP, and no cap tying the swapped amount to available pool depth. An external, unprivileged actor who can trade against the same Uniswap V3 pool that `UniswapV3Quoter`/`WPC` point to (a pool the registry, not the attacker, does not control liquidity of — `UniversalCore.uniswapV3Quoter()` / `WPC()` just resolve pool routing) can push the pool's spot price against the module right before this swap executes and restore it right after, pocketing the difference up to the 5% band, since the block proposer/mempool ordering is not restricted to prevent adjacent transactions around the vote-finalizing transaction.

### Impact Explanation
Each exploited inbound/refund drains up to ~5% of the swapped notional value from protocol/user-controlled funds (the module-held PRC20/PC swap proceeds destined for the UEA or refund recipient), i.e., unauthorized loss of user or protocol-controlled funds during universal execution, matching the in-scope impact "stealing ... permanent loss ... of user or protocol-controlled funds" and "corruption of PRC20 or native asset accounting ... gas fee accounting, refund accounting." This can be repeated on every GAS/GAS_AND_PAYLOAD inbound and every outbound gas refund, making it a systemic drain rather than a one-off.

### Likelihood Explanation
No malicious validator or privileged actor is required — Universal Validators are assumed honest and simply vote real observations. Any external user can watch pending inbound votes (public on the source chain and via `MsgVoteInbound` broadcasts) to predict roughly when quorum/execution will land in a given block, and submit ordinary swap transactions against the same pool immediately before/after. This requires no protocol compromise, only capital and knowledge of the quoter/pool, so likelihood is moderate-to-high wherever the WPC/PRC20 pool has limited depth relative to inbound amounts.

### Recommendation
Replace the spot `quoteExactInputSingle` price with a TWAP-based reference price (or an external price oracle) for computing `minPCOut`, and/or introduce a maximum single-swap notional relative to pool depth, and/or split large swaps to limit price impact. Consider widening the revert path so that if slippage cannot be safely bounded, the module reverts to a no-swap deposit (already the fallback used in `applyGasRefund`) rather than accepting a spot-price-derived 5% band on every swap.

### Proof of Concept
1. Attacker observes a pending `GAS` inbound accumulating UV votes on `x/uexecutor` for a large PRC20 amount.
2. Just before/around the block where the final vote is expected to push the inbound to quorum, attacker submits a large trade on the Uniswap V3 pool referenced by `UniversalCore.uniswapV3Quoter()`/`WPC()` to move the PRC20/WPC spot price against the module (e.g., inflate PRC20 price relative to WPC).
3. The vote-finalizing transaction triggers `ExecuteInboundGas` → `GetSwapQuote` (spot, manipulated) → `CallPRC20DepositAutoSwap` with `minPCOut = manipulatedQuote * 0.95`, executing at the manipulated price.
4. Attacker submits a reverse trade immediately after to restore the pool price, realizing profit equal to the price impact minus the 5% buffer that was already captured from the module's swap.
5. Repeat for subsequent inbounds/outbound refunds that use `applyGasRefund`'s equivalent spot-quote swap. [6](#0-5)

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}
