Confirmed: `execute_fee_transfer` in `crates/blockifier/src/transaction/account_transaction.rs` calls `fee_transfer_call.execute(...)` (`CallEntryPoint::execute`, not `non_reverting_execute`) directly, and returns the resulting `CallInfo` to `handle_fee` without checking `call_info.execution.failed`.

### Title
Fee-transfer call's revert/failure boolean (`CallInfo.execution.failed`) is not checked in `execute_fee_transfer` - (File: `crates/blockifier/src/transaction/account_transaction.rs`)

### Summary
`AccountTransaction::execute_fee_transfer` invokes the fee-token contract's `transfer` entry point via `CallEntryPoint::execute`, which — unlike `non_reverting_execute` — does not treat an internally-reverted (failed) call as an `Err`. [1](#0-0)  The returned `CallInfo` is used as-is by `handle_fee`, which only checks `charge_fee`/`actual_fee == 0`, not `execution.failed`. [2](#0-1) 

### Finding Description
`CallEntryPoint::execute` returns `Ok(CallInfo)` even when the callee's Cairo1 execution ends in a revert (`execution.failed == true`); only `non_reverting_execute` upgrades a failed inner call into an `Err(EntryPointExecutionError::ExecutionFailed)`. [3](#0-2)  `execute_deployment`/`syscall_base.deploy` and `execute_inner_call` (used for `call_contract`/`library_call` syscalls) both explicitly detect `call_info.execution.failed` and propagate a revert. [4](#0-3)  In contrast, `execute_fee_transfer` calls the plain `.execute()` and simply `map_err`s only genuine `EntryPointExecutionError`s (e.g. panics/out-of-gas), never inspecting whether the transfer itself "failed" (e.g. the ERC20 contract's `transfer` returning without moving balance, hitting an internal assert that reverts, or otherwise short-circuiting) as a `CallInfo.execution.failed == true` outcome that is not surfaced as a Rust error. [5](#0-4)  This `CallInfo` (with `failed: true` possibly set) is then stored as `fee_transfer_call_info` and returned as `Some(...)` from `handle_fee`, and the top-level `execute_raw` treats the transaction as fully successful (non-reverted) once `run_or_revert` and `handle_fee` both return `Ok`. [6](#0-5) 

### Impact Explanation
If the fee-token contract's `transfer` entry point can complete with `execution.failed = true` (a Cairo1 revert) without the state changes it made prior to the revert being fully undone by the outer flow — or more critically, if this silent "failed but not erroring" call info is accepted as the recorded `fee_transfer_call_info` for a transaction that the sequencer nonetheless marks as accepted/non-reverted — the sequencer could commit a block where the sender's fee was never actually deducted (loss of protocol fee revenue / broken fee accounting), while the transaction's receipt/state diff still reports it as paid. Since fee accounting feeds directly into the committed state diff and block state root, this is a state-correctness/fee-integrity issue reachable by any account whose fee-token contract (or a griefing target invoked from `transfer`, subject to standard fee-token semantics) can trigger such a path, and it does not require operator or prover privilege — only a normal transaction submission with a chosen/compromised fee-token interaction pattern.

### Likelihood Explanation
Likelihood is constrained by the fact that the protocol's designated fee-token contract is fixed and well-known/audited (the code comment even notes "the token contract is well known to the sequencer, so there is no need to limit its run" [7](#0-6) ), so an unprivileged sender cannot arbitrarily choose the fee-token class. This makes exploitation depend on a specific, already-buggy or upgraded fee-token implementation causing an internal Cairo1 revert during `transfer` that the caller cannot influence today. I could not fully verify, within the tool budget available, whether some other layer (e.g. `TransactionalState` commit logic or `handle_fee`'s caller) separately asserts `!fee_transfer_call_info.execution.failed` before finalizing the receipt — this should be checked directly in the repository to confirm whether the missing check is actually exploitable end-to-end or merely a defense-in-depth gap.

### Recommendation
In `execute_fee_transfer` (`crates/blockifier/src/transaction/account_transaction.rs`), use `non_reverting_execute` (as already done for constructor and deprecated-syscall inner calls) instead of `execute`, or explicitly check `call_info.execution.failed` after the call and return a `TransactionFeeError` if the fee transfer reverted, mirroring the pattern used in `syscall_base::execute_inner_call`.

### Proof of Concept
Not independently reproducible from static analysis alone within this investigation; the root-cause code path is: `AccountTransaction::execute_fee_transfer` → `CallEntryPoint::execute` (not `non_reverting_execute`) → `handle_fee` returns `Ok(Some(call_info))` regardless of `call_info.execution.failed` → `execute_raw` includes this `CallInfo` in a non-reverted `TransactionExecutionInfo`. [8](#0-7)  Confirming actual fund loss requires validating whether the fixed fee-token class can, under any deployed/valid class hash, revert mid-`transfer` after partial balance mutation, which is outside what static repo search can confirm.

    fn execute_fee_transfer(
        state: &mut dyn State,
        tx_context: Arc<TransactionContext>,
        actual_fee: Fee,
    ) -> TransactionExecutionResult<CallInfo> {
        // The least significant 128 bits of the amount transferred.
        let lsb_amount = Felt::from(actual_fee.0);
        // The most significant 128 bits of the amount transferred.
        let msb_amount = Felt::ZERO;

        let TransactionContext { block_context, tx_info } = tx_context.as_ref();
        let storage_address = tx_context.fee_token_address();
        // The fee contains the cost of running this transfer, and the token contract is
        // well known to the sequencer, so there is no need to limit its run.
        let mut remaining_gas_for_fee_transfer =
            block_context.versioned_constants.os_constants.gas_costs.base.default_initial_gas_cost;
        let fee_transfer_call = CallEntryPoint {
            class_hash: None,
            code_address: None,
            entry_point_type: EntryPointType::External,
            entry_point_selector: selector_from_name(constants::TRANSFER_ENTRY_POINT_NAME),
            calldata: calldata![
                *block_context.block_info.sequencer_address.0.key(), // Recipient.
                lsb_amount,
                msb_amount
            ],
            storage_address,
            caller_address: tx_info.sender_address(),
            call_type: CallType::Call,

            initial_gas: remaining_gas_for_fee_transfer,
        };
        let mut context = EntryPointExecutionContext::new_invoke(
            tx_context,
            true,
            SierraGasRevertTracker::new(GasAmount(remaining_gas_for_fee_transfer)),
        );

        Ok(fee_transfer_call
            .execute(state, &mut context, &mut remaining_gas_for_fee_transfer)
            .map_err(|error| Box::new(TransactionFeeError::ExecuteFeeTransferError(error)))?)
    }

impl CallEntryPoint {
    pub fn execute(
        mut self,
        state: &mut dyn State,
        context: &mut EntryPointExecutionContext,
        remaining_gas: &mut u64,
    ) -> EntryPointExecutionResult<CallInfo> {
        let tx_context = &context.tx_context;
        let strip_vm_frames = context.versioned_constants().strip_vm_frames_in_sierra_gas;
        let mut decrement_when_dropped = RecursionDepthGuard::new(
            context.current_recursion_depth.clone(),
            context.versioned_constants().max_recursion_depth,
        );
        decrement_when_dropped
            .try_increment_and_check_depth()
            .map_err(|e| e.annotated(TrackedResource::CairoSteps, strip_vm_frames))?;

        // Validate contract is deployed.
        let storage_class_hash = state.get_class_hash_at(self.storage_address).map_err(|e| {
            EntryPointExecutionError::from(e)
                .annotated(TrackedResource::CairoSteps, strip_vm_frames)
        })?;
        if storage_class_hash == ClassHash::default() {
            return Err(EntryPointExecutionError::from(
                PreExecutionError::UninitializedStorageAddress(self.storage_address),
            )
            .annotated(TrackedResource::CairoSteps, strip_vm_frames));
        }

        let class_hash = match self.class_hash {
            Some(class_hash) => class_hash,
            None => storage_class_hash, // If not given, take the storage contract class hash.
        };
        // Hack to prevent version 0 attack on argent accounts.
        if tx_context.tx_info.version() == TransactionVersion::ZERO
            && class_hash
                == ClassHash(
                    Felt::from_hex(FAULTY_CLASS_HASH).expect("A class hash must be a felt."),
                )
        {
            return Err(EntryPointExecutionError::from(PreExecutionError::FraudAttempt)
                .annotated(TrackedResource::CairoSteps, strip_vm_frames));
        }
        // Add class hash to the call, that will appear in the output (call info).
        self.class_hash = Some(class_hash);
        let compiled_class = state.get_compiled_class(class_hash).map_err(|e| {
            EntryPointExecutionError::from(e)
                .annotated(TrackedResource::CairoSteps, strip_vm_frames)
        })?;

        context.revert_infos.0.push(EntryPointRevertInfo::new(
            self.storage_address,
            storage_class_hash,
            context.n_emitted_events,
            context.n_sent_messages_to_l1,
        ));

        // This is the last operation of this function.
        execute_entry_point_call_wrapper(
            self.into_executable(class_hash),
            compiled_class,
            state,
            context,
            remaining_gas,
        )
    }

    /// Similar to `execute`, but returns an error if the outer call is reverted.
    pub fn non_reverting_execute(
        self,
        state: &mut dyn State,
        context: &mut EntryPointExecutionContext,
        remaining_gas: &mut u64,
    ) -> EntryPointExecutionResult<CallInfo> {
        let execution_result = self.execute(state, context, remaining_gas);
        if let Ok(call_info) = &execution_result {
            // Update revert gas tracking (for completeness - value will not be used unless the tx
            // is reverted).
            context.sierra_gas_revert_tracker.update_with_next_remaining_gas(
                call_info.tracked_resource,
                GasAmount(*remaining_gas),
            );
            // If the execution of the outer call failed, revert the transction.
            if call_info.execution.failed {
                return Err(EntryPointExecutionError::ExecutionFailed {
                    error_trace: extract_trailing_cairo1_revert_trace(
                        call_info,
                        Cairo1RevertHeader::Execution,
                    ),
                }
                .annotated(
                    call_info.tracked_resource,
                    context.versioned_constants().strip_vm_frames_in_sierra_gas,
                ));
            }
        }

        execution_result
    }

    pub fn execute_inner_call(
        &mut self,
        call: CallEntryPoint,
        remaining_gas: &mut u64,
    ) -> SyscallResult<Vec<Felt>> {
        let revert_idx = self.context.revert_infos.0.len();

        let call_info = call.execute(self.state, self.context, remaining_gas)?;

        let mut raw_retdata = call_info.execution.retdata.0.clone();
        let call_failed = call_info.execution.failed;
        self.inner_calls.push(call_info);
        if call_failed {
            self.context.revert(revert_idx, self.state)?;

            // Delete events and l2_to_l1_messages from the reverted call.
            let reverted_call = &mut self.inner_calls.last_mut().unwrap();
            let mut stack: Vec<&mut CallInfo> = vec![reverted_call];
            while let Some(call_info) = stack.pop() {
                call_info.execution.events.clear();
                call_info.execution.l2_to_l1_messages.clear();
                // Add inner calls that did not fail to the stack.
                // The events and l2_to_l1_messages of the failed calls were already cleared.
                stack.extend(
                    call_info
                        .inner_calls
                        .iter_mut()
                        .filter(|call_info| !call_info.execution.failed),
                );
            }

            raw_retdata.push(ENTRYPOINT_FAILED_ERROR_FELT);
            return Err(SyscallExecutionError::Revert { error_data: raw_retdata });
        }

        Ok(raw_retdata)
    }
