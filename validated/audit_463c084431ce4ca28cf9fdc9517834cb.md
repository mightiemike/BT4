Based on my research, I found a genuine analog to the "missing auth check" bug class in the Starknet OS's `replace_class` syscall implementation, which represents a divergence between what the sequencer's blockifier enforces at execution time and what the Starknet OS (SNOS) re-execution enforces when proving the block.

### Title
Starknet OS `execute_replace_class` skips the "class must be declared" check that Blockifier enforces, causing honest-node divergence - ([File: crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo])

### Summary
The `ReplaceClass` syscall lets any contract change its own class hash. In the Blockifier (the execution engine used by the sequencer to build/validate blocks), this syscall is required to verify that the target `class_hash` has actually been declared before permitting the replacement — done by reading the compiled class and erroring if it doesn't exist, e.g. `syscall_handler.state.get_compiled_class(request.class_hash)?` [1](#0-0)  and confirmed by the test asserting `"is not declared"` for an undeclared class hash [2](#0-1) .

However, in the Starknet OS Cairo implementation that re-executes the same transactions when producing the STARK proof for the block, the analogous `execute_replace_class` function in `syscall_impls.cairo` explicitly omits this check, with a TODO acknowledging the gap: `// TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.` before directly writing the new class hash into the contract's state entry [3](#0-2) .

### Finding Description
`ReplaceClass` is a syscall reachable from any unprivileged contract call (`__execute__`, or any entry point) — a contract simply calls `replace_class_syscall(class_hash)` to change its own class hash [4](#0-3) . This is a normal user-facing capability (e.g., contract upgrade proxies), so no permission check is normally required for "self" replacement — but the correctness invariant that must hold is that the target `class_hash` corresponds to a class that has actually been declared on-chain. If that check is skipped, a contract's `class_hash` state entry can be set to an arbitrary, non-existent class hash.

The Blockifier's deprecated syscall handler enforces this invariant via `get_compiled_class`, and native/CASM syscall handlers route through the same `base.replace_class` logic that also relies on this check being present in the state layer / test asserts an "is not declared" error [5](#0-4) . The OS Cairo implementation used for SNOS re-execution (which recomputes the same state transition to build the proof that anchors the committed state root) does not perform this validation before committing the state update — it directly does `dict_update` on `contract_state_changes` with the unchecked `class_hash` [6](#0-5) .

### Impact Explanation
If the Blockifier (used at execution/proposal time) and the Starknet OS (used to generate the proof and, ultimately, the committed state root) disagree on whether a `ReplaceClass` syscall with an undeclared class hash should succeed or revert, this is a state-transition divergence between the two engines that are supposed to compute identical results for the same block. Such a divergence can produce:
- A wrong committed state root / block hash if the discrepancy affects a real chain of execution that reverts in one engine but not the other (fee charged differently, revert vs success, differing `contract_state_changes`).
- A subtler class of "honest-node divergence": if the Blockifier rejects a transaction that attempts `replace_class` to an undeclared hash (transaction reverts, no state change), but SNOS re-execution (if ever exercised on that transaction, e.g., in future proving/verification paths or via other OS-driven code paths) would accept it and write the state change, the two systems no longer agree on the resulting state.

This maps to the "wrong committed root or block hash" / "honest-node divergence" categories accepted by the validation rules.

### Likelihood Explanation
Likelihood is constrained by whether SNOS re-execution is the actual proving mechanism enforced in this deployment and whether the code path is reachable independent from the Blockifier's own check (i.e., whether SNOS ever executes a case where Blockifier would have reverted). The TODO comment itself, dated 1/1/2026, is direct evidence from the maintainers that this check is a known, currently-missing gap in the OS implementation, which supports feasibility of the bug class but I could not fully confirm from the available context whether this divergence is actually exploitable end-to-end in the current SNOS/Blockifier pairing (e.g., whether Blockifier's revert on undeclared class also prevents the transaction from ever reaching SNOS, or whether other invariants elsewhere close this gap). This uncertainty should be validated by a deeper trace through `transaction_impls.cairo`/`state.cairo` state-update and revert-log handling before treating this as fully confirmed.

### Recommendation
Add the same "class hash must be declared" check in the Starknet OS's `execute_replace_class` (both the deprecated syscall variant in `deprecated_execute_syscalls.cairo` and the current variant in `syscall_impls.cairo`) that the Blockifier already performs, i.e., read/verify the compiled class for `request.class_hash` before writing the new `StateEntry`, mirroring `get_compiled_class` in the Rust implementation. This closes the gap noted by the maintainers' own TODO and removes the risk of Blockifier/SNOS state-transition divergence.

### Proof of Concept
1. A contract calls `replace_class_syscall(undeclared_class_hash)` where `undeclared_class_hash` has never been declared on-chain — reachable via any `__execute__` entry point, e.g. as demonstrated by the test helper `test_forbidden_syscall_in_virtual_mode` which directly invokes `syscalls::replace_class_syscall(class_hash)` [7](#0-6) .
2. In Blockifier execution, this reverts with a "not declared" class error, per the negative-flow assertion in `test_replace_class` [8](#0-7) .
3. In the Starknet OS re-execution of the same syscall (`execute_replace_class` in `syscall_impls.cairo`), no equivalent declared-class check exists before the `dict_update` writing the new `StateEntry` with the unchecked `class_hash` [6](#0-5) , meaning the OS's view of the resulting state can differ from the Blockifier's.

#[test]
fn test_replace_class() {
    // Negative flow.
    let chain_info = &ChainInfo::create_for_testing();
    let test_contract = FeatureContract::TestContract(CairoVersion::Cairo0);
    let empty_contract = FeatureContract::Empty(CairoVersion::Cairo0);
    let mut state = test_state(chain_info, Fee(0), &[(test_contract, 1), (empty_contract, 1)]);
    let test_address = test_contract.get_instance_address(0);
    // Replace with undeclared class hash.
    let calldata = calldata![felt!(1234_u16)];
    let entry_point_call = CallEntryPoint {
        calldata,
        entry_point_selector: selector_from_name("test_replace_class"),
        ..trivial_external_entry_point_new(test_contract)
    };
    let error = entry_point_call.execute_directly(&mut state).unwrap_err().to_string();
    assert!(error.contains("is not declared"));

    // Positive flow.
    let old_class_hash = test_contract.get_class_hash();
    let new_class_hash = empty_contract.get_class_hash();
    assert_eq!(state.get_class_hash_at(test_address).unwrap(), old_class_hash);
    let entry_point_call = CallEntryPoint {
        calldata: calldata![new_class_hash.0],
        entry_point_selector: selector_from_name("test_replace_class"),
        ..trivial_external_entry_point_new(test_contract)
    };
    entry_point_call.execute_directly(&mut state).unwrap();
    assert_eq!(state.get_class_hash_at(test_address).unwrap(), new_class_hash);
}

func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
