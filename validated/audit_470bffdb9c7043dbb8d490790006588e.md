## Analog Identified: Aborted Outbound Permanently Strands the Prepaid Excess Gas-Fee Reserve

### Title
Permanent loss of prepaid excess gas fee when outbound re-mint fails and the outbound is marked ABORTED - (File: x/uexecutor/keeper/outbound.go)

### Summary
The Kinetiq report describes funds being deducted from an accounting pool ("buffer") to satisfy an action, and then, when that action is reversed, the pool is never credited back and the funds become permanently stuck with no automated recovery path. Push Chain has the same structural bug in the outbound gas-refund path: the relayer gas fee (`gas_fee`) is collected/reserved up front when an outbound is created, and the excess (`gas_fee - gas_fee_used`) is supposed to be refunded via `applyGasRefund` once the outbound is finalized. But when the "revert bridged funds" re-mint step fails, `handleFailedOutbound` returns early via `AbortOutbound` *before* `applyGasRefund` is ever invoked, and an `ABORTED` outbound can never be finalized again.

### Finding Description
`FinalizeOutbound` only processes outbounds in `OBSERVED` status [1](#0-0) . For a failed observation it calls `handleFailedOutbound`, which — for `FUNDS`, `GAS_AND_PAYLOAD`, and `FUNDS_AND_PAYLOAD` outbounds — first tries to re-mint the bridged PRC20 amount back to the revert recipient via `CallPRC20Deposit`: [2](#0-1) 

If that re-mint call fails, the function stores a `FAILED` `PcRevertExecution` and immediately returns via `AbortOutbound`, **never reaching** the `applyGasRefund` call that sits further down the function body for the success path: [3](#0-2) 

`AbortOutbound` flips the outbound to `Status_ABORTED` and removes it from `PendingOutbounds` [4](#0-3) . Because `FinalizeOutbound` only acts on `Status_OBSERVED` outbounds, an `ABORTED` outbound can never be revisited by the normal finalization flow again — there is no code path that re-attempts `applyGasRefund` for an aborted outbound.

The `gas_fee` amount reserved for this outbound was already collected/tracked by the `UniversalGatewayPC`/`UniversalCore` contracts at outbound-creation time (`event.GasFee` populated in `BuildOutboundsFromReceipt` [5](#0-4) ), and the excess (`gasFee - gasFeeUsed`) is meant to flow back to the sender/`fund_recipient` through `CallUniversalCoreRefundUnusedGas` [6](#0-5) . When the abort path is hit, that excess remains held by the protocol/UniversalCore contract with no remaining automated or admin-driven mechanism in `x/uexecutor` to trigger the refund — mirroring the Kinetiq pattern where a reserved amount is silently orphaned once the normal completion path is short-circuited.

An unprivileged user can reach the re-mint-failure branch deterministically without any validator or admin misbehavior: the sender fully controls `RevertInstructions.fund_recipient` on their own outbound-creating transaction (it is taken verbatim from the `UniversalTxOutboundEvent` the user's own transaction emits, see `RevertInstructions: &types.RevertInstructions{FundRecipient: event.RevertRecipient}` in `create_outbound.go`). By pointing the recipient at a PRC20 whose `deposit`/mint call reliably reverts for that address (e.g. an address that is blacklisted/paused on the PRC20, a contract designed to revert on receipt, or one that would push a `uint256` balance past the overflow guard), the user forces `CallPRC20Deposit` to fail on every outbound-failure vote from honest UVs, permanently landing the outbound in `ABORTED` before any gas refund logic runs.

### Impact Explanation
The `gas_fee` excess is protocol/relayer-reserved value that belongs to the sender once the destination-chain execution consumes less gas than budgeted. Once the outbound is `ABORTED` via the re-mint failure branch, this excess is permanently unreachable through any code path in `x/uexecutor` — it is effectively a protocol-level fund loss/freeze, matching the "permanent loss/freezing of user or protocol-controlled funds" allowed-impact category.

### Likelihood Explanation
The attacker only needs to control `fund_recipient` on their own outbound (which they do, by construction of the FUNDS/FUNDS_AND_PAYLOAD/GAS_AND_PAYLOAD flow) and needs the underlying PRC20 deposit call to revert for that recipient — achievable via any address whose mint reverts deterministically. No validator, TSS, or admin misbehavior is required; honest UVs voting the true (failed) destination-chain outcome are sufficient to drive the state machine into the unrecoverable `ABORTED` branch.

### Recommendation
Move the `applyGasRefund` call so it always executes for `handleFailedOutbound`, regardless of whether the bridged-funds re-mint succeeds — i.e., call `applyGasRefund` before evaluating the re-mint result (or in a `defer`), so the excess gas fee is refunded even when the outbound is subsequently aborted. Alternatively, extend `AbortOutbound` (or add a dedicated recovery message) to still process the pending gas refund for `ABORTED` outbounds so the reserved excess is not orphaned.

### Proof of Concept
1. User submits a `FUNDS`/`FUNDS_AND_PAYLOAD` outbound whose `UniversalTxOutboundEvent.RevertRecipient` is set to an address `X` whose PRC20 mint always reverts (e.g., a contract that reverts unconditionally, or a blacklisted address if the PRC20 supports blacklisting).
2. UVs (honestly) observe the destination-chain execution failed and vote via `MsgVoteOutbound` with `success=false` and `gas_fee_used < gas_fee` (a real, non-zero amount was spent on the destination chain before it reverted).
3. `FinalizeOutbound` → `handleFailedOutbound` is invoked; `CallPRC20Deposit(..., X, amount)` reverts because of `X`'s deliberately-reverting mint hook.
4. The function returns via `AbortOutbound` at [7](#0-6) , before `k.applyGasRefund(ctx, &outbound, obs)` at line 158 is ever reached.
5. The outbound is now `Status_ABORTED`; `FinalizeOutbound`'s status guard (`if outbound.OutboundStatus != types.Status_OBSERVED { return nil }`) permanently prevents any future re-entry into `applyGasRefund` for this outbound, and the `gasFee - gasFeeUsed` excess reserved by the protocol is never returned to the sender.

// AbortOutbound marks an outbound as ABORTED with a reason.
// This signals that automatic processing has failed and manual intervention is needed.
func (k Keeper) AbortOutbound(ctx context.Context, utxId string, outbound types.OutboundTx, reason string) error {
	sdkCtx := sdk.UnwrapSDKContext(ctx)

	outbound.OutboundStatus = types.Status_ABORTED
	outbound.AbortReason = reason

	if err := k.UpdateOutbound(ctx, utxId, outbound); err != nil {
		return err
	}

	// Defensively remove from pending index (may already be removed by caller)
	_ = k.PendingOutbounds.Remove(ctx, outbound.Id)

	// Emit event for monitoring/alerting
	sdkCtx.EventManager().EmitEvent(sdk.NewEvent(
		"outbound_aborted",
		sdk.NewAttribute("utx_id", utxId),
		sdk.NewAttribute("outbound_id", outbound.Id),
		sdk.NewAttribute("abort_reason", reason),
	))

	return nil
}

func (k Keeper) FinalizeOutbound(ctx context.Context, utxId string, outbound types.OutboundTx) error {
	// If not observed yet, do nothing
	if outbound.OutboundStatus != types.Status_OBSERVED {
		return nil
	}

	obs := outbound.ObservedTx
	if obs == nil {
		return nil
	}

	sdkCtx := sdk.UnwrapSDKContext(ctx)

	k.Logger().Info("finalizing outbound",
		"utx_id", utxId,
		"outbound_id", outbound.Id,
		"success", obs.Success,
		"dest_chain", outbound.DestinationChain,
		"tx_type", outbound.TxType.String(),
	)

	if !obs.Success {
		return k.handleFailedOutbound(sdkCtx, utxId, outbound, obs)
	}

	return k.handleSuccessfulOutbound(sdkCtx, utxId, outbound, obs)
}

func (k Keeper) handleFailedOutbound(ctx sdk.Context, utxId string, outbound types.OutboundTx, obs *types.OutboundObservation) error {
	// Only revert bridged funds for funds-related tx types
	if outbound.TxType == types.TxType_FUNDS || outbound.TxType == types.TxType_GAS_AND_PAYLOAD ||
		outbound.TxType == types.TxType_FUNDS_AND_PAYLOAD {

		// Decide revert recipient safely
		recipient := outbound.Sender
		if outbound.RevertInstructions != nil &&
			outbound.RevertInstructions.FundRecipient != "" {
			recipient = outbound.RevertInstructions.FundRecipient
		}

		amount := new(big.Int)
		amount, ok := amount.SetString(outbound.Amount, 10)
		if !ok {
			return fmt.Errorf("invalid amount: %s", outbound.Amount)
		}
		receipt, err := k.CallPRC20Deposit(ctx, common.HexToAddress(outbound.Prc20AssetAddr), common.HexToAddress(recipient), amount)

		pcTx := types.PCTx{
			Sender:      outbound.Sender,
			BlockHeight: uint64(ctx.BlockHeight()),
		}
		// Capture tx hash from receipt even on EVM revert for debugging.
		if receipt != nil {
			pcTx.TxHash = receipt.Hash
			pcTx.GasUsed = receipt.GasUsed
		}
		if err != nil {
			pcTx.Status = "FAILED"
			pcTx.ErrorMsg = err.Error()
			outbound.PcRevertExecution = &pcTx
			// Re-mint failed — mark as ABORTED for manual intervention
			return k.AbortOutbound(ctx, utxId, outbound,
				fmt.Sprintf("failed to re-mint tokens for revert: %s", err.Error()))
		}
		pcTx.TxHash = receipt.Hash
		pcTx.GasUsed = receipt.GasUsed
		pcTx.Status = "SUCCESS"
		outbound.PcRevertExecution = &pcTx
		k.Logger().Info("outbound failed: funds re-minted for revert",
			"utx_id", utxId,
			"outbound_id", outbound.Id,
			"tx_hash", receipt.Hash,
		)
	}

	outbound.OutboundStatus = types.Status_REVERTED
	k.Logger().Info("outbound reverted",
		"utx_id", utxId,
		"outbound_id", outbound.Id,
		"dest_chain", outbound.DestinationChain,
	)

	// Refund excess gas regardless of tx type — gas was consumed on the external
	// chain whether the execution succeeded or failed.
	k.applyGasRefund(ctx, &outbound, obs)

	return k.UpdateOutbound(ctx, utxId, outbound)

// applyGasRefund computes the excess gas (gasFee - gasFeeUsed) and, if positive,
// calls UniversalCore refundUnusedGas. The result is recorded in outbound.PcRefundExecution.
// It is called for both successful and failed outbounds — gas is consumed on the
// external chain regardless of execution outcome.
func (k Keeper) applyGasRefund(ctx sdk.Context, outbound *types.OutboundTx, obs *types.OutboundObservation) {
	if obs.GasFeeUsed == "" || outbound.GasFee == "" || outbound.GasToken == "" {
		return
	}

	gasFee := new(big.Int)
	if _, ok := gasFee.SetString(outbound.GasFee, 10); !ok {
		return
	}

	gasFeeUsed := new(big.Int)
	if _, ok := gasFeeUsed.SetString(obs.GasFeeUsed, 10); !ok {
		return
	}

	// No excess gas to refund
	if gasFee.Cmp(gasFeeUsed) <= 0 {
		return
	}

	refundAmount := new(big.Int).Sub(gasFee, gasFeeUsed)
	gasToken := common.HexToAddress(outbound.GasToken)

	// Refund recipient: prefer fund_recipient in revert_instructions, fall back to sender
	refundRecipient := outbound.Sender
	if outbound.RevertInstructions != nil && outbound.RevertInstructions.FundRecipient != "" {
		refundRecipient = outbound.RevertInstructions.FundRecipient
	}
	recipientAddr := common.HexToAddress(refundRecipient)

	refundPcTx := &types.PCTx{
		Sender:      outbound.Sender,
		BlockHeight: uint64(ctx.BlockHeight()),
	}

	// Step 1: try refund with swap (gasToken → PC native)
	fee, swapErr := k.GetDefaultFeeTierForToken(ctx, gasToken)
	var swapFallbackReason string

	if swapErr == nil {
		quote, quoteErr := k.getSwapQuoteForRefund(ctx, gasToken, fee, refundAmount)
		if quoteErr == nil {
			minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
			minPCOut.Div(minPCOut, big.NewInt(100))

			resp, err := k.CallUniversalCoreRefundUnusedGas(ctx, gasToken, refundAmount, recipientAddr, true, fee, minPCOut)
			if err == nil {
				refundPcTx.TxHash = resp.Hash
				refundPcTx.GasUsed = resp.GasUsed
				refundPcTx.Status = "SUCCESS"
				outbound.PcRefundExecution = refundPcTx
				return
			}
			swapFallbackReason = fmt.Sprintf("swap refund failed: %s", err.Error())
		} else {
			swapFallbackReason = fmt.Sprintf("quote fetch failed: %s", quoteErr.Error())
		}
	} else {
		swapFallbackReason = fmt.Sprintf("fee tier fetch failed: %s", swapErr.Error())
	}

	// Step 2: fallback — refund without swap (deposit PRC20 directly to recipient)
	ctx.Logger().Error("applyGasRefund: swap refund failed, falling back to no-swap",
		"outbound_id", outbound.Id,
		"reason", swapFallbackReason,
	)

	resp, err := k.CallUniversalCoreRefundUnusedGas(ctx, gasToken, refundAmount, recipientAddr, false, big.NewInt(0), big.NewInt(0))
	if err != nil {
		refundPcTx.Status = "FAILED"
		refundPcTx.ErrorMsg = err.Error()
	} else {
		refundPcTx.TxHash = resp.Hash
		refundPcTx.GasUsed = resp.GasUsed
		refundPcTx.Status = "SUCCESS"
	}

	outbound.PcRefundExecution = refundPcTx
	outbound.RefundSwapError = swapFallbackReason
}
