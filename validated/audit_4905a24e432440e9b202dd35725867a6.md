### Title
Missing allowlist/rate-limit check in `HandleLegacyUserMessage` broadcasts unauthenticated attacker-controlled `web_api_trigger` payload to every DON member - ([File: core/services/gateway/handlers/capabilities/handler.go])

### Summary
`handler.HandleLegacyUserMessage` decodes an unauthenticated user's `webapicap.TriggerRequestPayload`, performs only a JSON-decode check, a `Timestamp` non-zero check, and a staleness check, then converts the raw message into a JSON-RPC request via `common.ValidatedRequestFromMessage` and forwards it unmodified to **every** `h.donConfig.Members` node via `don.SendToNode`. There is no signature/sender authorization or allowlist check anywhere in this path, and the code explicitly marks this gap with `// TODO: apply allowlist and rate-limiting here`.

### Finding Description
The call sequence is: `HandleLegacyUserMessage` → `json.Unmarshal(body.Payload, &payload)` → `payload.Timestamp == 0` check → staleness check → method check (`== MethodWebAPITrigger`) → `common.ValidatedRequestFromMessage(msg)` → loop over `h.donConfig.Members` → `don.SendToNode(ctx, member.Address, req)` [1](#0-0) .

None of these checks validate `msg.Body.Sender` against any allowlist, nor is there rate-limiting on the caller — the only rate limiter in this file (`h.nodeRateLimiter`) is applied to outgoing node messages (`handleWebAPIOutgoingMessage`), not to incoming user messages [2](#0-1) . `common.ValidatedRequestFromMessage` only checks that `MessageId` and `Method` are non-empty; it performs no signature verification or sender authorization [3](#0-2) . This is confirmed by comparison with sibling handlers that do enforce sender allowlisting before dispatching to nodes: `functionsHandler.HandleLegacyUserMessage` calls `h.allowlist.Allow(sender)` and `h.userRateLimiter.Allow(...)` before processing [4](#0-3) , and the `vault` handler enforces `h.requestProcessor.ProcessRequest` authorization before dispatch [5](#0-4) . The dispatch layer (`multiHandler.HandleLegacyUserMessage`) performs no authorization either — it merely routes by method name to the target handler [6](#0-5) . This is corroborated by the handler's own test file, which contains a `TODO: Validate Senders and rate limit chck, pending question in trigger about where senders and rate limits are validated`, confirming this is a known, unresolved gap rather than an intentional design decision documented elsewhere [7](#0-6) .

As a result, any network-reachable, unauthenticated caller of the gateway's user-facing endpoint can submit a `web_api_trigger` message with an arbitrary `webapicap.TriggerRequestPayload` (subject only to having a non-zero, non-stale `Timestamp`), and the gateway will forward it as-is to every member of the DON.

### Impact Explanation
This breaks the invariant that unprivileged external messages must be scoped/allowlisted before being broadcast to DON nodes. It allows an unauthenticated attacker to use the gateway as an amplification/fan-out proxy that causes every DON node to receive and act on an attacker-chosen trigger payload (e.g., a fabricated HTTP trigger event), which can be used to spam DON nodes, trigger unwanted downstream capability workflow executions, or serve as a vector for further attacks against whatever consumes the trigger on the node side. This matches the "unauthorized transaction or workflow execution" / DON-wide unauthorized call fan-out impact category.

### Likelihood Explanation
The precondition is minimal: network access to the gateway's legacy user-facing endpoint, no authentication or prior enrollment required at this layer. The only barriers are trivially satisfiable format checks (valid JSON payload, non-zero `Timestamp` within `MaxAllowedMessageAgeSec`, method equal to `web_api_trigger`). This is a highly repeatable, low-effort exploit path.

### Recommendation
Implement the allowlist and rate-limiting check that is called out in the `// TODO` comment before constructing the request and looping over `don.SendToNode`. Specifically, validate `msg.Body.Sender` (and its signature, per `msg.Validate()`/signature-verification conventions used elsewhere) against a configured per-DON allowlist, and enforce a per-sender rate limiter (mirroring `functionsHandler`'s `h.allowlist.Allow(sender)` / `h.userRateLimiter.Allow(...)` pattern) before the fan-out loop.

### Proof of Concept
Integration test plan (extending `core/services/gateway/handlers/capabilities/handler_test.go`):
1. Construct a `handler` with a `donConfig.Members` list of N mock nodes and a `don` mock (`handlers.DON`).
2. Build a legacy `api.Message` with `Body.Method = MethodWebAPITrigger`, an arbitrary attacker-crafted `webapicap.TriggerRequestPayload` (custom URL/Headers/Body-equivalent fields), a valid non-zero non-stale `Timestamp`, and a `Sender` that is NOT present in any allowlist configuration (since no allowlist config field currently exists, this is trivially true).
3. Call `handler.HandleLegacyUserMessage(ctx, msg, callback)`.
4. **Current (vulnerable) behavior**: assert `don.SendToNode` is invoked once per `donConfig.Members` entry with the unmodified attacker payload — proving unauthenticated fan-out occurs.
5. **Expected (fixed) behavior**: after adding an allowlist check, assert that `don.SendToNode` is `AssertNotCalled` and `callback.SendResponse` returns an authorization-error response (mirroring `functions` handler's `ErrNotAllowlisted` test pattern in `handler.functions_test.go`) when `Sender` is not allowlisted.

func (h *handler) HandleLegacyUserMessage(ctx context.Context, msg *api.Message, callback handlers.Callback) error {
	body := msg.Body
	var payload webapicap.TriggerRequestPayload
	codec := api.JsonRPCCodec{}
	err := json.Unmarshal(body.Payload, &payload)
	if err != nil {
		h.lggr.Errorw(ErrDecodingPayload, "err", err)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload+" "+err.Error(),
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if payload.Timestamp == 0 {
		h.lggr.Errorw(ErrDecodingPayload)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if uint(time.Now().Unix())-h.config.MaxAllowedMessageAgeSec > uint(payload.Timestamp) {
		h.lggr.Errorw("stale message")
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.HandlerError),
				"stale message",
				nil,
			),
			ErrorCode: api.HandlerError,
		})
	}
	// TODO: apply allowlist and rate-limiting here
	if msg.Body.Method != MethodWebAPITrigger {
		h.lggr.Errorw("unsupported method", "method", body.Method)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UnsupportedMethodError),
				"invalid method "+msg.Body.Method,
				nil,
			),
			ErrorCode: api.UnsupportedMethodError,
		})
	}
	req, err := common.ValidatedRequestFromMessage(msg)
	if err != nil {
		h.lggr.Errorw(ErrTransformingMessageToRequest)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrTransformingMessageToRequest,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	h.mu.Lock()
	h.savedCallbacks[msg.Body.MessageId] = &savedCallback{id: msg.Body.MessageId, createdAt: time.Now(), Callback: callback}
	don := h.don
	h.mu.Unlock()

	// Send original request to all nodes
	for _, member := range h.donConfig.Members {
		err = errors.Join(err, don.SendToNode(ctx, member.Address, req))
	}
	return err

// ValidatedRequestFromMessage converts a legacy Gateway Message to a JSON-RPC request
func ValidatedRequestFromMessage(msg *api.Message) (*jsonrpc.Request[json.RawMessage], error) {
	if msg == nil {
		return nil, errors.New("nil message")
	}
	if msg.Body.MessageId == "" {
		return nil, errors.New("message ID is empty")
	}
	if msg.Body.Method == "" {
		return nil, errors.New("method is empty")
	}
	params, err := json.Marshal(msg)
	if err != nil {
		return nil, fmt.Errorf("failed to marshal message: %w", err)
	}
	rawParams := json.RawMessage(params)
	req := &jsonrpc.Request[json.RawMessage]{
		Version: "2.0",
		ID:      msg.Body.MessageId,
		Method:  msg.Body.Method,
		Params:  &rawParams,
	}
	return req, nil
}

func (h *functionsHandler) HandleLegacyUserMessage(ctx context.Context, msg *api.Message, callback handlers.Callback) error {
	sender := common.HexToAddress(msg.Body.Sender)
	if h.allowlist != nil && !h.allowlist.Allow(sender) {
		h.lggr.Debugw("received a message from a non-allowlisted address", "sender", msg.Body.Sender)
		promHandlerError.WithLabelValues(h.donConfig.DonId, ErrNotAllowlisted.Error()).Inc()
		return ErrNotAllowlisted
	}
	if h.userRateLimiter != nil && !h.userRateLimiter.Allow(msg.Body.Sender) {
		h.lggr.Debugw("rate-limited", "sender", msg.Body.Sender)
		promHandlerError.WithLabelValues(h.donConfig.DonId, ErrRateLimited.Error()).Inc()
		return ErrRateLimited
	}
