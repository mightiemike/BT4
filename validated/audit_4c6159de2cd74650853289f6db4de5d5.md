### Title
Spot-price self-referential slippage floor in PRC20 auto-swap deposits enables sandwich extraction — (File: x/uexecutor/keeper/execute_inbound_gas.go, execute_inbound_gas_and_payload.go, outbound.go)

### Summary
The GAS/GAS_AND_PAYLOAD auto-swap deposit path and the gas-refund auto-swap path both derive their slippage floor (`minPCOut`) from a spot quote (`QuoterV2.quoteExactInputSingle`) taken from the exact AMM pool that the swap is about to execute against, in the same call sequence, with no TWAP or independent reference price. Because the reference price and the executed trade share the same manipulable pool state, the 5% band offers no real protection against sandwich/price-manipulation attacks — it is the modern equivalent of the reported "unused slippage params" issue: slippage exists syntactically but is computed against an attacker-controllable value rather than a safe, independent price.

### Finding Description
`ExecuteInboundGas` (and the GAS_AND_PAYLOAD analog) fetches a quote via `GetSwapQuote`, which calls `quoteExactInputSingle` on the UniversalCore Uniswap V3 `QuoterV2` for the exact `prc20 → wpc` pair and exact `amount` about to be swapped [5](#0-4) . It then computes `minPCOut = quote * 95 / 100` and immediately calls `CallPRC20DepositAutoSwap`, which performs the deposit+swap on the identical pool via `DerivedEVMCall` in a `commit=true`, non-simulated transaction [6](#0-5) .

Because inbound votes accumulate over multiple blocks until quorum, and `MsgVoteInbound`/similar finalizing votes are ordinary broadcast transactions visible before inclusion, an unprivileged attacker observing the pending vote that will trigger quorum can:
1. Submit a large swap against the `prc20/WPC` Uniswap V3 pool in the same block, ordered before the finalizing vote, moving the spot price against WPC.
2. The `GetSwapQuote` call inside the triggered `ExecuteInboundGas`/`ExecuteInboundGasAndPayload` reads this manipulated spot price, so `minPCOut` is computed off the depressed price with only a 5% band on top of the manipulation itself, not a fair-market band.
3. The autoswap executes at the manipulated price, minting less WPC to the user's UEA than fair value.
4. The attacker reverses their price-moving trade later in the block or in a subsequent block, capturing the spread as a classic sandwich/extraction profit, while the depositing user's funds are permanently under-delivered (no slippage error is raised because the check passes against the manipulated reference).

The `deadline` parameter is also hardcoded to `0` (contract default) rather than being tied to quote freshness, offering no additional protection against staleness/manipulation [7](#0-6) . The same pattern is repeated for gas refunds in `applyGasRefund`/`getSwapQuoteForRefund` [8](#0-7) .

### Impact Explanation
This directly reaches the "corruption of PRC20 or native asset accounting" and "unauthorized state transitions in universal execution flows" impact categories: an ordinary unprivileged user's cross-chain GAS/GAS_AND_PAYLOAD deposit is auto-swapped for less WPC than fair value, and the difference is extracted by a sandwiching attacker who only needs to observe public pending validator votes and submit ordinary swap transactions against a public AMM pool — no privileged actor, malicious validator, or malicious relayer is required. This is fund loss for the depositing user, reachable purely through default deposit/auto-swap flows.

### Likelihood Explanation
Requires the attacker to have liquidity to move the pool price meaningfully and requires observing the pending finalizing vote in the mempool to time the sandwich; on a Cosmos-SDK chain with a public mempool this is standard, well-understood MEV tooling. Likelihood is moderate — it depends on pool depth relative to attacker capital and on deposit size, but is not blocked by any current on-chain guard, since the reference price itself is the manipulable value.

### Recommendation
Do not derive `minPCOut` from a spot quote against the same pool the swap will immediately execute in. Use a TWAP-based reference price (e.g., Uniswap V3 pool `observe`/oracle cardinality) independent of the current-block spot state, or bound the maximum single-block price impact allowed for auto-swaps, and/or widen protection with circuit breakers on abnormal price deviation between last observed chain-meta price and current spot quote before executing the swap.

### Proof of Concept
1. Attacker monitors the mempool for the `MsgVoteInbound`/`MsgVoteOutbound`/etc. transaction that will push a pending GAS or GAS_AND_PAYLOAD inbound to quorum.
2. Attacker submits (with higher gas priority, same block) a large swap of `prc20 → WPC` (or WPC → prc20) on the UniversalCore Uniswap V3 pool to move the spot price unfavorably for the pending deposit's direction.
3. The finalizing vote lands, triggering `ExecuteInboundGas`, which calls `GetSwapQuote` — reading the now-manipulated spot price — and computes `minPCOut` as 95% of that manipulated quote.
4. `CallPRC20DepositAutoSwap` executes at the manipulated price; the user's UEA receives WPC valued near the manipulated price rather than the fair pre-attack price.
5. Attacker reverses their initial swap in the same or next block, restoring the pool price and realizing the extracted spread as profit, funded by the under-delivered deposit.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}

// getSwapQuoteForRefund fetches a Uniswap quote for the gas token refund swap.
func (k Keeper) getSwapQuoteForRefund(ctx sdk.Context, gasToken common.Address, fee *big.Int, amount *big.Int) (*big.Int, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(ctx)
	if err != nil {
		return nil, err
	}
	wpcAddr, err := k.GetUniversalCoreWPCAddress(ctx)
	if err != nil {
		return nil, err
	}
	return k.GetSwapQuote(ctx, quoterAddr, gasToken, wpcAddr, fee, amount)
}
