### Title
`replace_class` syscall in the Starknet OS skips declared-class/type validation performed by the blockifier - ([File: crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo])

### Summary
The `replace_class` syscall lets a contract change its own class hash — the exact primitive the Munchables attacker abused via manual storage/implementation manipulation to swap in code that let him mint himself a fake balance. In this codebase, the blockifier's Rust implementation of `replace_class` enforces two safety checks before allowing the class swap, but the Starknet OS's Cairo implementation of the same syscall enforces neither, creating a divergence between what the sequencer actually commits and what the OS (the component whose execution is proven and anchored to L1) will accept.

### Finding Description
In `crates/blockifier/src/execution/syscalls/syscall_base.rs`, `SyscallHandlerBase::replace_class` performs two validations before mutating state: [1](#0-0) 
It reads the compiled class (which fails with `UndeclaredClassHash` if the class was never declared) and rejects the swap if the class is not Cairo1 (`ForbiddenClassReplacement`).

The Starknet OS's equivalent Cairo implementation, `execute_replace_class` in `syscall_impls.cairo`, performs the state mutation directly, with an explicit TODO acknowledging the missing declared-class check, and no check at all for class type: [2](#0-1) 

The corresponding deprecated (Cairo0) OS path, `execute_replace_class` in `deprecated_execute_syscalls.cairo`, similarly writes the new class hash into `contract_state_changes` unconditionally, without reading/validating the target class: [3](#0-2) 

By contrast, the blockifier's deprecated syscall path at least confirms the class is declared before allowing replacement: [4](#0-3) 

Since Cairo contracts typically call `replace_class_syscall(...).unwrap()`, a failure in the blockifier (undeclared class hash or Cairo0 class) causes a Cairo-level panic that reverts the invoking transaction, so blockifier records no class-hash state change and marks the transaction reverted. The OS, re-executing the identical bytecode/syscall trace independently to build/prove the block, would not fail this syscall at all — it would succeed and commit the new (possibly undeclared or Cairo0) class hash into contract state.

### Impact Explanation
This produces a genuine root-cause divergence between the two independent implementations of the same protocol-critical syscall: for an unprivileged transaction sender who deploys a contract that calls `replace_class` with an undeclared class hash (or a deprecated Cairo0 class hash), the blockifier-based sequencer computes REVERTED with no state change, while the Starknet OS computes SUCCESS with the class hash actually replaced. Because the OS's execution is what is re-executed/proven to derive the committed state root, this is a wrong-committed-root / honest-node-divergence class bug — nodes/provers running the OS path will disagree with the sequencer's blockifier-derived state, which can block block finalization/proof verification or allow inconsistent state to be accepted depending on which path is trusted downstream.

### Likelihood Explanation
Trivially reachable by any unprivileged transaction sender: a single declared Cairo1 contract that calls the `replace_class` syscall (a standard, unrestricted external-facing syscall) with an attacker-chosen, undeclared or Cairo0 class hash triggers the divergence. No special privileges, storage manipulation, or race conditions are required — only a contract deployment and one invoke transaction.

### Recommendation
Implement the same validations in the OS's `execute_replace_class` (`syscall_impls.cairo`) as in the blockifier's `SyscallHandlerBase::replace_class`: verify the target class hash is declared (mirroring `get_compiled_class`) and verify it is a Cairo1 class before performing the `dict_update` that writes the new class hash into `contract_state_changes`. Remove the outstanding TODO by wiring the check into the OS execution path so both implementations reject/allow the same set of `replace_class` calls identically.

### Proof of Concept
1. Attacker declares only class A (a normal Cairo1 account/contract). Class hash B is never declared on-chain.
2. Attacker deploys contract A and invokes an entry point that calls `replace_class_syscall(B).unwrap()`.
3. Sequencer (blockifier) execution: `SyscallHandlerBase::replace_class` calls `state.get_compiled_class(B)`, which returns `UndeclaredClassHash`; the syscall errors, the Cairo `.unwrap()` panics, and the whole invoke is marked REVERTED with no class-hash state change recorded in the sequencer's local state/state diff.
4. Starknet OS re-execution of the identical calldata/trace: `execute_replace_class` in `syscall_impls.cairo` never reads/validates class B; it unconditionally performs `dict_update` setting the contract's class hash to B and logs success — the OS computes the transaction as succeeding with the class hash replaced.
5. Result: two independent, consensus-relevant execution engines produce different final states (and therefore different state roots) for the identical transaction — an honest-node divergence / wrong committed root.

    pub fn replace_class(&mut self, class_hash: ClassHash) -> SyscallResult<()> {
        // Ensure the class is declared (by reading it), and of type V1.
        let compiled_class = self.state.get_compiled_class(class_hash)?;

        if !is_cairo1(&compiled_class) {
            return Err(SyscallExecutionError::ForbiddenClassReplacement { class_hash });
        }
        self.state.set_class_hash_at(self.call.storage_address, class_hash)?;
        Ok(())
    }

func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
