### Title
Spot-price-derived slippage bound on inbound gas-abstraction swaps enables sandwich extraction from user deposits - (File: x/uexecutor/keeper/execute_inbound_gas.go / execute_inbound_gas_and_payload.go)

### Summary
When Push Chain executes a `GAS` or `GAS_AND_PAYLOAD` inbound, it auto-swaps the deposited PRC20 into PC via `depositPRC20WithAutoSwap`. The "slippage protection" (`minPCOut`) is computed by calling `GetSwapQuote` (a live `QuoterV2.quoteExactInputSingle` spot-price read) immediately before the swap and applying a fixed 5% tolerance — the same manipulable spot price is used both as the reference and as the bound, so it offers no protection against price manipulation that occurs in the same block.

### Finding Description
`k.ExecuteInboundGas` (and the duplicate logic in `k.gasAndPayloadDepositAutoSwap`) fetches a swap quote and computes the minimum output entirely from live pool state: [1](#0-0) 

```go
quote, execErr = k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
...
minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
minPCOut.Div(minPCOut, big.NewInt(100))
receipt, execErr = k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
```

`GetSwapQuote` reads the Uniswap V3 `QuoterV2` at the current pool state, with no TWAP, no oracle cross-check, and no external "expected" value supplied by any authorized party: [2](#0-1) 

Because `minPCOut` is derived from the exact same pool the swap will execute against, in the same synchronous execution path, any unprivileged actor who can move that pool's price in a transaction ordered earlier in the same block (a standard front-run) forces the quote — and therefore the "protection" threshold — to reflect the manipulated price. The subsequent swap then executes and validates successfully against that already-degraded price, after which the attacker back-runs to restore the pool and capture the difference. This is the same underlying flaw as the reported `SuperVaultStrategy` bug (a slippage bound that can be made to track an attacker-influenced value instead of a fair reference price) — except here the manipulable input is the pool's own instantaneous price rather than a caller-supplied `expectedAssetsOrSharesOut`, and the trigger is an ordinary unprivileged trader, not a privileged strategist.

The identical pattern also protects `CallUniversalCoreRefundUnusedGas`'s optional `withSwap` PRC20→PC refund leg (referenced in `x/uexecutor/keeper/outbound.go`), meaning both the inbound deposit-swap and the outbound gas-refund-swap paths share this weakness.

### Impact Explanation
A successful sandwich degrades the amount of PC a depositing user's UEA actually receives for their bridged gas token, i.e. a corruption of PRC20-to-native accounting reachable purely from an ordinary user's inbound deposit — in scope under "corruption of PRC20 or native asset accounting" and "unauthorized ... state transitions in universal execution flows." Value is extracted from users/protocol liquidity by an unprivileged actor with no special role, satisfying the required unprivileged-trigger constraint.

### Likelihood Explanation
Medium. It requires the attacker to control transaction ordering around the block in which the qualifying inbound's execution transaction lands (classic MEV/sandwich conditions), and depth/liquidity of the PRC20/WPC pool determines profitability. This is a routine, well-understood DeFi attack pattern and doesn't require any elevated privilege, validator collusion, or protocol bug beyond the missing TWAP/oracle binding.

### Recommendation
Do not derive the slippage floor from a spot quote fetched in the same execution as the swap. Use a time-weighted average price (TWAP) from the Uniswap V3 pool (or an external price oracle) to compute `minPCOut`, and/or widen protection by binding it to a governance/registry-configured maximum-deviation parameter instead of a fixed percentage of the just-fetched spot quote. Apply the same fix to the refund-with-swap path in `CallUniversalCoreRefundUnusedGas`.

### Proof of Concept
1. Attacker observes an in-flight inbound (`GAS` or `GAS_AND_PAYLOAD`) that will trigger `ExecuteInboundGas`/`ExecuteInboundGasAndPayload` once validator votes reach quorum on Push Chain.
2. Before the quorum-finalizing vote transaction is included, attacker submits a large PRC20→WPC swap against the same Uniswap V3 pool used by `GetUniversalCoreQuoterAddress`/`GetSwapQuote`, depressing the PRC20 price.
3. The inbound-execution transaction lands later in the same block; `GetSwapQuote` returns the now-depressed quote, `minPCOut = quote * 0.95` is computed from that depressed value, and `CallPRC20DepositAutoSwap` executes and passes validation trivially.
4. Attacker back-runs with a swap in the opposite direction to restore the pool price, capturing the spread — the depositing user's UEA receives materially less PC than fair value for the deposit. [3](#0-2)

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}
