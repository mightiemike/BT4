### Title
Missing declared-class validation in Starknet OS `replace_class` syscall re-execution enables honest-node state divergence - ([File: crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo])

### Summary
The Starknet OS Cairo implementation of the `replace_class` syscall (`execute_replace_class`) applies a contract's new class hash to `contract_state_changes` without verifying that the supplied class hash corresponds to a declared class, unlike the blockifier's Rust implementation of the same syscall, which explicitly performs this check before mutating state.

### Finding Description
The OS's `execute_replace_class` function contains the class-hash mutation logic with an explicit unresolved `TODO`: [1](#0-0) 

Specifically, the code reads:
```
// TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
local state_entry: StateEntry*;
%{ GetContractAddressStateEntry %}

tempvar new_state_entry = new StateEntry(
    class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
);

dict_update{dict_ptr=contract_state_changes}(
    key=contract_address,
    prev_value=cast(state_entry, felt),
    new_value=cast(new_state_entry, felt),
);
```
This unconditionally writes `request.class_hash` (fully attacker-controlled, since it comes directly from the `replace_class` syscall request written by the calling contract) into the contract's state entry, with no check that the class hash was ever declared, and no check that it is a Cairo1 class (only Cairo1 classes are allowed to be set via `replace_class`).

By contrast, the blockifier's native Rust implementation of the same syscall, which is what actually executes on the sequencer and determines the committed state, performs both checks before mutating state: [2](#0-1) 

```rust
pub fn replace_class(&mut self, class_hash: ClassHash) -> SyscallResult<()> {
    // Ensure the class is declared (by reading it), and of type V1.
    let compiled_class = self.state.get_compiled_class(class_hash)?;

    if !is_cairo1(&compiled_class) {
        return Err(SyscallExecutionError::ForbiddenClassReplacement { class_hash });
    }
    self.state.set_class_hash_at(self.call.storage_address, class_hash)?;
    Ok(())
}
```
This is confirmed by the deprecated-syscall test suite, which explicitly asserts that replacing with an undeclared class hash fails with "is not declared" and that replacing a Cairo1 class with a Cairo0 class hash is rejected: [3](#0-2) [4](#0-3) 

This is directly analogous to the IDOR bug class in the report: a resource-identifying value (there, a credential UUID; here, a class hash) is consumed and used to mutate/access protected state (there, cross-workspace credentials; here, a contract's assigned class) without the ownership/existence check ("was this ID actually registered/declared to the caller/system") that the equivalent, authoritative code path enforces.

I was unable to fully verify, within the available tool budget, whether the Rust-side hint processor for the OS (`crates/starknet_os/src/hint_processor/snos_syscall_executor.rs`, which showed 6 matches for `replace_class`) supplements the Cairo code with an out-of-band declared-class check via a hint. This is the key remaining uncertainty: if that Rust hint independently verifies declaration and aborts on failure, the Cairo-level TODO would be non-exploitable in practice. The explicit unresolved `TODO(Yoni, 1/1/2026)` comment in the Cairo source, left in place with no accompanying assertion in the Cairo code itself, is strong evidence that the check is genuinely missing at the point of interest.

### Impact Explanation
If the OS's re-execution of a block accepts a `replace_class` call with an undeclared (or wrong-version) class hash that the blockifier itself would have rejected (as a revertible `SyscallExecutionError`), the OS-computed contract state entry (and therefore the state commitment / block hash produced by the Starknet OS proof) diverges from the actual state committed by the honest blockifier-based sequencer. This falls squarely into "wrong committed root or block hash" / "honest-node divergence," since the network's canonical state (from block production) and the SNOS-proved state would disagree for the same block of transactions, which could be used to either prove an invalid state transition or cause the prover/verifier pipeline to reject/halt on blocks that were otherwise valid, undermining the finality guarantees the OS proof is meant to provide.

### Likelihood Explanation
The syscall is reachable by any contract executing `replace_class_syscall(class_hash)` with an arbitrary felt as `class_hash` — no special privileges are required, and it is a syscall available to ordinary invoke transactions from any account (as demonstrated by the `test_replace_class` Cairo0/Cairo1 test contracts). Triggering the divergence only requires submitting a transaction that calls `replace_class` with a class hash that has never been declared (or is the wrong Cairo version), which any unprivileged transaction sender can do trivially.

### Recommendation
Implement the missing declared-class (and Cairo1-version) check in `execute_replace_class` in the Starknet OS Cairo code, mirroring the blockifier's `replace_class` logic in `syscall_base.rs` (verify the class is declared via `is_contract_class_declared`/equivalent OS-side lookup, and reject non-Cairo1 classes), so that the OS's semantics for `replace_class` failures exactly match the blockifier's, guaranteeing execution parity between the sequencer and the proving pipeline. Add explicit OS test coverage (following the pattern in `crates/starknet_os_flow_tests`) asserting that `replace_class` with an undeclared class hash reverts identically in both the blockifier and OS re-execution paths.

### Proof of Concept
1. Deploy an account contract whose `__execute__` (or any externally callable function) invokes `replace_class_syscall(class_hash)` with a `class_hash` value that has never been declared on-chain (e.g., `felt!(0xdeadbeef)`), as in the `test_replace_class` feature contract functions: [5](#0-4) 
2. Submit this as a normal invoke transaction. Under the blockifier (actual sequencer execution), `replace_class` calls `state.get_compiled_class(class_hash)` which returns `StateError::UndeclaredClassHash`, causing the syscall (and typically the whole call, depending on revert handling) to fail/revert — the contract's class hash is unchanged in the committed state.
3. When the same transaction is re-executed by the Starknet OS (SNOS) for proving, `execute_replace_class` in `syscall_impls.cairo` performs no declared-class check (per the `TODO` at line 902) and unconditionally writes the new (undeclared) class hash into `contract_state_changes`, producing a state diff / state root for that block that differs from the one actually committed by the sequencer for the same set of transactions.

func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,

    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    return ();
}

#[test]
fn test_replace_class() {
    // Negative flow.
    let chain_info = &ChainInfo::create_for_testing();
    let test_contract = FeatureContract::TestContract(CairoVersion::Cairo0);
    let empty_contract = FeatureContract::Empty(CairoVersion::Cairo0);
    let mut state = test_state(chain_info, Fee(0), &[(test_contract, 1), (empty_contract, 1)]);
    let test_address = test_contract.get_instance_address(0);
    // Replace with undeclared class hash.
    let calldata = calldata![felt!(1234_u16)];
    let entry_point_call = CallEntryPoint {
        calldata,
        entry_point_selector: selector_from_name("test_replace_class"),
        ..trivial_external_entry_point_new(test_contract)
    };
    let error = entry_point_call.execute_directly(&mut state).unwrap_err().to_string();
    assert!(error.contains("is not declared"));

    // Positive flow.
    let old_class_hash = test_contract.get_class_hash();
    let new_class_hash = empty_contract.get_class_hash();
    assert_eq!(state.get_class_hash_at(test_address).unwrap(), old_class_hash);
    let entry_point_call = CallEntryPoint {
        calldata: calldata![new_class_hash.0],
        entry_point_selector: selector_from_name("test_replace_class"),
        ..trivial_external_entry_point_new(test_contract)
    };
    entry_point_call.execute_directly(&mut state).unwrap();
    assert_eq!(state.get_class_hash_at(test_address).unwrap(), new_class_hash);
