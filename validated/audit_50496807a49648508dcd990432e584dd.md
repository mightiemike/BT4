### Title
Textproto injection via unescaped `Any.TypeUrl` written raw into `[type_url]` field-name syntax during `google.protobuf.Any` expansion - (File: encoding/prototext/encode.go)

### Summary
`prototext.Marshal` expands a `google.protobuf.Any` message by writing the type URL directly into the text-format field-name position (`[typeURL]:`) via `Encoder.WriteName`, which performs no escaping or character validation, unlike `Encoder.WriteString`, which escapes quotes, backslashes, control characters and newlines for ordinary string field values.

### Finding Description
`Any.TypeUrl` is an ordinary proto3 `string` field with no validation enforced by the generated setters or by binary/JSON unmarshal — any byte sequence permitted in a UTF-8 string can be assigned to it [1](#0-0) . When `prototext.MarshalOptions.Marshal` serializes a message containing an `Any` and the type resolves via `Resolver.FindMessageByURL`, `marshalAny` writes the type URL straight into the output as a bracketed field name: [2](#0-1) 

The name is emitted through `Encoder.WriteName`, which does a raw, unescaped append: [3](#0-2) 

This is asymmetric with the treatment given to normal proto string field values, which go through `appendString`/`WriteString`, escaping control characters, quotes, backslashes and non-ASCII bytes: [4](#0-3) 

Because `WriteName` performs none of these checks, a `TypeUrl` value containing text-format metacharacters (`}`, `<`, `>`, `"`, `\n`, `#`, `:` etc.) is written verbatim into the structural position of the output, allowing the attacker-controlled string to break out of the intended `[type_url]:` field-name token and inject arbitrary additional textproto fields/messages, or prematurely close/desync the current message body — the same class of bug as Netty's `setUri()` writing an unvalidated string verbatim into a delimited protocol's structural position.

### Impact Explanation
If a service accepts an untrusted `Any` (e.g., via binary or JSON unmarshal, where `TypeUrl` is not schema-validated as a well-formed URL/type-name) and later re-serializes that message with `prototext.Marshal`/`Format` for logging, auditing, inter-service transport, or consumption by another trusted textproto parser, the injected content could corrupt the structure of the emitted textproto and inject unintended fields, causing textproto "smuggling"/desync between what was intended to be serialized and what a downstream trusted textproto consumer parses. This maps to a data-integrity issue (CWE-93/CWE-74-class injection) rather than memory corruption.

### Likelihood Explanation
Requires: (1) an unprivileged path that populates an `Any.TypeUrl` from external input without validating URL/type-name syntax, (2) the referenced type to be resolvable via the configured `Resolver` so `marshalAny` takes the "expanded" branch rather than falling back to plain `type_url`/`value` fields, and (3) the resulting textproto output to be consumed by a second, trusted textproto parser or for the injection to matter to a human/automated log consumer. These preconditions are plausible in the wild but require a fairly specific text-format-based downstream integration; protobuf-go's own binary and JSON wire paths are not affected (JSON keys/strings are always escaped by the JSON encoder, and binary format has no delimiter-based structure to inject into).

### Recommendation
Validate or escape the `TypeUrl` string before using it to construct the `[type_url]` field-name token in `marshalAny` — e.g., reject/skip expansion (fall back to the unexpanded `type_url`/`value` form, which is always safely escaped via `WriteString`) whenever the URL contains characters outside the syntax documented for `Any.TypeUrl` (alphanumerics, `/-.~_!$&()*+,;=`, percent-escapes), consistent with the character restriction already documented in `types/known/anypb/any.pb.go`.

### Proof of Concept
```go
package main

import (
	"fmt"

	"google.golang.org/protobuf/encoding/prototext"
	"google.golang.org/protobuf/proto"
	anypb "google.golang.org/protobuf/types/known/anypb"
	emptypb "google.golang.org/protobuf/types/known/emptypb"
)

func main() {
	// Attacker controls TypeUrl (e.g., decoded from an untrusted binary/JSON
	// payload where TypeUrl syntax is never validated).
	inner := &emptypb.Empty{}
	value, _ := proto.Marshal(inner)

	malicious := &anypb.Any{
		// Breaks out of the bracketed field-name token and injects
		// a bogus structural fragment into the textproto output.
		TypeUrl: "google.protobuf.Empty]\ninjected_field: 1 #",
		Value:   value,
	}

	out, err := prototext.MarshalOptions{Multiline: true}.Marshal(malicious)
	fmt.Println(string(out), err)
}
```
Because `WriteName` performs no escaping, the emitted textproto will contain the raw `]` and newline from `TypeUrl`, closing the field-name token early and introducing an attacker-controlled `injected_field: 1 #` line into the output that a downstream trusted textproto parser would interpret as a legitimate field, unlike the value/type_url fallback path which would have safely quoted/escaped these characters via `WriteString`.

// marshalAny marshals the given google.protobuf.Any message in expanded form.
// It returns true if it was able to marshal, else false.
func (e encoder) marshalAny(any protoreflect.Message) bool {
	// Construct the embedded message.
	fds := any.Descriptor().Fields()
	fdType := fds.ByNumber(genid.Any_TypeUrl_field_number)
	typeURL := any.Get(fdType).String()
	mt, err := e.opts.Resolver.FindMessageByURL(typeURL)
	if err != nil {
		return false
	}
	m := mt.New().Interface()

	// Unmarshal bytes into embedded message.
	fdValue := fds.ByNumber(genid.Any_Value_field_number)
	value := any.Get(fdValue)
	err = proto.UnmarshalOptions{
		AllowPartial: true,
		Resolver:     e.opts.Resolver,
	}.Unmarshal(value.Bytes(), m)
	if err != nil {
		return false
	}

	// Get current encoder position. If marshaling fails, reset encoder output
	// back to this position.
	pos := e.Snapshot()

	// Field name is the proto field name enclosed in [].
	e.WriteName("[" + typeURL + "]")
	err = e.marshalMessage(m.ProtoReflect(), true)
	if err != nil {
		e.Reset(pos)
		return false
	}
	return true
}

func (e *Encoder) WriteString(s string) {
	e.prepareNext(scalar)
	e.out = appendString(e.out, s, e.outputASCII)
}

func appendString(out []byte, in string, outputASCII bool) []byte {
	out = append(out, '"')
	i := indexNeedEscapeInString(in)
	in, out = in[i:], append(out, in[:i]...)
	for len(in) > 0 {
		switch r, n := utf8.DecodeRuneInString(in); {
		case r == utf8.RuneError && n == 1:
			// We do not report invalid UTF-8 because strings in the text format
			// are used to represent both the proto string and bytes type.
			r = rune(in[0])
			fallthrough
		case r < ' ' || r == '"' || r == '\\' || r == 0x7f:
			out = append(out, '\\')
			switch r {
			case '"', '\\':
				out = append(out, byte(r))
			case '\n':
				out = append(out, 'n')
			case '\r':
				out = append(out, 'r')
			case '\t':
				out = append(out, 't')
			default:
				out = append(out, 'x')
				out = append(out, "00"[1+(bits.Len32(uint32(r))-1)/4:]...)
				out = strconv.AppendUint(out, uint64(r), 16)
			}
			in = in[n:]
		case r >= utf8.RuneSelf && (outputASCII || r <= 0x009f):
			out = append(out, '\\')
			if r <= math.MaxUint16 {
				out = append(out, 'u')
				out = append(out, "0000"[1+(bits.Len32(uint32(r))-1)/4:]...)
				out = strconv.AppendUint(out, uint64(r), 16)
			} else {
				out = append(out, 'U')
				out = append(out, "00000000"[1+(bits.Len32(uint32(r))-1)/4:]...)
				out = strconv.AppendUint(out, uint64(r), 16)
			}
			in = in[n:]
		default:
			i := indexNeedEscapeInString(in[n:])
			in, out = in[n+i:], append(out, in[:n+i]...)
		}
	}
	out = append(out, '"')
	return out
}
