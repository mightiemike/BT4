### Title
Gas-deposit auto-swap prices PC payout from a manipulable spot AMM quote with only fixed 5% slippage, no TWAP or oracle cross-check, letting an attacker drain UniversalCore's WPC/PC reserve - (File: `x/uexecutor/keeper/execute_inbound_gas.go`, `x/uexecutor/keeper/evm.go`)

### Summary
The M-9 report is about minting a stablecoin at 100% of an oracle price with no fee buffer, which arbitragers exploit whenever the oracle price diverges from the "true" market price, draining value from the protocol's collateral. Push Chain has a structurally identical pattern in `x/uexecutor`'s gas-abstraction flow: when a user's inbound deposits a gas token, the module fetches a live Uniswap V3 spot quote and immediately executes a swap against that same quote with only a fixed 5% slippage buffer and no time-weighted or oracle-based price validation.

### Finding Description
`ExecuteInboundGas` (and the `GAS_AND_PAYLOAD` analog `gasAndPayloadDepositAutoSwap`) drives the PRC20→WPC conversion for gas abstraction: [1](#0-0) 

The quote comes from `GetSwapQuote`, which is a live, uncommitted call into the Uniswap V3 `QuoterV2.quoteExactInputSingle` against the pool's *current* on-chain reserves — i.e., a pure spot price, not a TWAP: [2](#0-1) 

The only protection applied before executing the real swap is a static 5% slippage margin computed from that same spot quote: [3](#0-2) 

`CallPRC20DepositAutoSwap` then commits the swap on-chain using `minPCOut` derived purely from that spot price: [4](#0-3) 

The same pattern is reused in the `GAS_AND_PAYLOAD` inbound path (`gasAndPayloadDepositAutoSwap`) and in the refund path `CallUniversalCoreRefundUnusedGas` when `withSwap=true`: [5](#0-4) [6](#0-5) 

Because the quote and the swap both read/act on the same mutable pool state, and there is no TWAP, no oracle cross-check (Push Chain does have a separate `ChainMetaOracle`/`GasPrice` median-voting mechanism, but it is not consulted here), and no protocol fee, an unprivileged attacker can:
1. Trade against the WPC/PRC20 Uniswap V3 pool in a prior transaction/block to skew the spot price in their favor (push the PRC20→WPC exchange rate up).
2. Trigger (or wait for) their own gas-abstraction inbound to be processed by `x/uexecutor` at that skewed spot price — the deposit executes automatically in `BeginBlock`/`EndBlock` processing of finalized inbounds, using whatever the pool price is *at that moment*, with 5% slippage as the only guard.
3. Reverse the initial pool trade afterward, netting a profit extracted from UniversalCore's WPC/PC reserves while leaving the pool's price restored.

This mirrors M-9 exactly: a price used to mint/convert value at (near) 100% face value with no fee and no freshness/oracle safeguard, letting arbitragers systematically extract value from the protocol-held liquidity that ultimately backs user gas/fund deposits.

### Impact Explanation
Each exploited inbound converts external gas-token deposits into PC at an attacker-favorable rate, depleting UniversalCore's WPC/PC reserve (protocol-controlled funds) over repeated executions. Since gas abstraction runs automatically for every incoming `GAS` and `GAS_AND_PAYLOAD` inbound, this is a systemic value leak rather than a one-off exploit, and it corrupts the gas-fee/refund accounting invariant (the amount of PC actually delivered no longer reflects fair value of the deposited token).

### Likelihood Explanation
The Uniswap V3 pools in question are presumably thin relative to potential attacker capital especially early in the chain's life (mirroring the Sherlock lead judge's point about a shallow USSD/DAI pool), making single-block or near-block price manipulation cheap. No privileged role, validator collusion, or TSS/relayer compromise is required — any user who can also submit EVM transactions against the same pool (or simply times their bridge deposit around organic price swings, given the deviation is not bounded by any oracle) can capture the spread. The 5% slippage tolerance is wide enough to accommodate meaningful single-block price movement, so the guard is a slippage floor for the *user*, not an anti-manipulation control for the protocol.

### Recommendation
- Use a time-weighted average price (or the median `GasPrice`/`ChainMeta` oracle already collected by Universal Validators, appropriately unit-converted) as the reference price for `minPCOut`, rather than the instantaneous `quoteExactInputSingle` spot quote.
- Bound the allowed deviation between the spot quote and the TWAP/oracle reference, rejecting or reverting the auto-swap if divergence exceeds a safe threshold.
- Consider adding a small protocol fee/spread on the auto-swap conversion to disincentivize pure arbitrage, and tighten slippage tolerance below the deviation threshold rather than a flat 5%.

### Proof of Concept
1. Attacker observes the WPC/PRC20 Uniswap V3 pool used by UniversalCore's `defaultFeeTier`/`quoteExactInputSingle` for a given PRC20 gas token.
2. Attacker swaps a sizeable amount of WPC into the pool (or PRC20 out of it) to push the PRC20→WPC exchange rate favorably.
3. Attacker (or an accomplice) sends a bridge deposit on the source chain that becomes a `GAS` or `GAS_AND_PAYLOAD` inbound; once Universal Validators finalize the ballot, `ExecuteInboundGas`/`gasAndPayloadDepositAutoSwap` calls `GetSwapQuote` against the now-skewed pool and executes `CallPRC20DepositAutoSwap` with `minPCOut` computed from that skewed quote.
4. Attacker reverses the initial pool trade, restoring the price and realizing the arbitrage profit extracted from UniversalCore's PC/WPC reserve.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil

// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)
}

// CallUniversalCoreRefundUnusedGas calls refundUnusedGas on UniversalCore to return excess gas fee
// to the recipient. withSwap=true swaps the gas token back to PC; withSwap=false deposits PRC20 directly.
func (k Keeper) CallUniversalCoreRefundUnusedGas(
	ctx sdk.Context,
	gasToken common.Address,
	amount *big.Int,
	recipient common.Address,
	withSwap bool,
	fee *big.Int,
	minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse UniversalCore ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	// fee is uint24 in Solidity — pass as *big.Int (go-ethereum ABI packs non-standard widths as *big.Int)
	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress,
		handlerAddr,
		big.NewInt(0),
		nil,
		true,
		false,
		true,
		&nonce,
		"refundUnusedGas",
		gasToken,
		amount,
		recipient,
		withSwap,
		fee,
		minPCOut,
	)
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}
