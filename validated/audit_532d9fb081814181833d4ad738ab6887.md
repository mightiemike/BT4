### Title
Spot-price-derived `minPCOut` slippage guard in gas-and-payload auto-swap allows sandwich-style value extraction from the PRC20↔WPC pool - (File: x/uexecutor/keeper/execute_inbound_gas_and_payload.go, x/uexecutor/keeper/execute_inbound_gas.go, x/uexecutor/keeper/evm.go)

### Summary
`gasAndPayloadDepositAutoSwap` (used by `ExecuteInboundGasAndPayload`) and the equivalent path in `ExecuteInboundGas` compute the minimum acceptable swap output (`minPCOut`) by taking a **single spot-price quote** from `GetSwapQuote` (which calls `QuoterV2.quoteExactInputSingle` on the live Uniswap-V3-style pool) and applying a flat 5% haircut, then immediately execute the real swap (`CallPRC20DepositAutoSwap` / `depositPRC20WithAutoSwap`) against that same pool state [2](#0-1) . Because the quote and the trade are derived from the *same* manipulable on-chain price with no TWAP, external oracle, or protocol-set bound, an unprivileged actor can move the pool price in blocks prior to inbound execution (via ordinary, permissionless swaps on the public `SwapRouter`) and then unwind the manipulation afterward — the classic sandwich pattern — extracting value at the expense of whoever supplies liquidity/backing to that pool, while the 95%-of-quote check offers no real protection since it is self-referential to the already-manipulated quote.

### Finding Description
`ExecuteInboundGas` (`x/uexecutor/keeper/execute_inbound_gas.go:104-153`) and `gasAndPayloadDepositAutoSwap` (`x/uexecutor/keeper/execute_inbound_gas_and_payload.go:348-379`) both follow this pattern:
1. `quoterAddr, _ := k.GetUniversalCoreQuoterAddress(sdkCtx)` and `wpcAddr, _ := k.GetUniversalCoreWPCAddress(sdkCtx)` read fixed addresses from `UniversalCore` [3](#0-2) .
2. `quote, _ := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)` calls `QuoterV2.quoteExactInputSingle` against the pool's *current* reserves/tick state [4](#0-3) .
3. `minPCOut := quote * 95 / 100` is derived purely from that same just-fetched quote [5](#0-4) .
4. `k.CallPRC20DepositAutoSwap(...)` immediately executes the actual `depositPRC20WithAutoSwap` swap on the same pool using that `minPCOut` [6](#0-5) .

Because both the quote and the real swap read the same pool state within the same keeper call (no other transaction can execute in between), `minPCOut` only bounds slippage *relative to whatever the price already is at that moment* — it provides zero protection against the price having been pushed away from a fair/external market rate by prior transactions. The pool itself, per the e2e deployment tooling, is a standard permissionless Uniswap V3 fork (`v3-core`/`v3-periphery`, public `SwapRouter`) seeded with liquidity [7](#0-6) , so any unprivileged address can submit ordinary swap transactions against it at will.

An attacker can therefore:
1. Submit a large ordinary swap that pushes the PRC20/WPC pool price so that PRC20 is valued artificially high in WPC terms.
2. Trigger (or wait for) their own inbound `GAS`/`GAS_AND_PAYLOAD` deposit to be executed by honest validators once quorum is reached — this deposit auto-swaps the attacker's incoming PRC20 into PC/WPC using the manipulated price, yielding the attacker more PC than the fair-value trade would produce.
3. Reverse the initial swap to restore the price, netting an arbitrage profit extracted from the pool's liquidity providers/protocol-held reserves.

### Impact Explanation
This lets an unprivileged, ordinary user obtain more native PC (or its wrapped equivalent) from the protocol-operated auto-swap than the swap is economically worth, at the expense of pool liquidity (protocol/LP funds) — a form of unauthorized/incorrect value transfer via manipulated on-chain accounting during a fund-moving flow (`CallPRC20DepositAutoSwap`), which falls under "corruption of PRC20 or native asset accounting" / fund-loss impact categories in scope.

### Likelihood Explanation
Likelihood depends heavily on: (a) actual on-chain liquidity depth in the live PRC20/WPC pool (thin pools are cheap to manipulate, deep pools are expensive), (b) the size of the attacker's own inbound deposit relative to pool depth, and (c) MEV/block-ordering conditions on Push Chain (whether an attacker can reliably land manipulation and reversal swaps in blocks adjacent to their own inbound's finalization block). This is a real design gap (spot-price quote used as its own slippage bound, no TWAP) rather than a hypothetical, but it requires capital and favorable liquidity/timing conditions to be profitable, and the 5% band bounds worst-case loss per single manipulation window.

### Recommendation
Do not derive `minPCOut` solely from a spot quote taken immediately before the swap. Use a manipulation-resistant reference price (e.g., a time-weighted average price over multiple blocks, or a protocol-configured maximum allowed deviation from a recent TWAP/oracle price) to bound `minPCOut`, and/or cap the portion of pool liquidity a single auto-swap deposit can consume, so that pre-execution price manipulation cannot be laundered through the "5% off the current quote" check.

### Proof of Concept
1. Deploy/seed a PRC20/WPC Uniswap-V3-style pool with liquidity as in `e2e-tests/setup.sh` pool-manager step [7](#0-6) .
2. As an unprivileged EOA, submit a large swap through the public `SwapRouter` to skew the PRC20→WPC price favorably.
3. Submit (or have pending) a cross-chain `GAS_AND_PAYLOAD`/`GAS` inbound deposit of PRC20 for your own UEA; once honest validators reach quorum, `ExecuteInboundGasAndPayload`/`ExecuteInboundGas` calls `GetSwapQuote` then `CallPRC20DepositAutoSwap` back-to-back against the still-skewed pool [2](#0-1) .
4. Compare the PC/WPC received by the UEA against a fair-value quote taken before step 2's manipulation — assert it exceeds fair value by more than the 5% band, then reverse the initial swap to realize the profit; this demonstrates `minPCOut` failed to enforce a manipulation-independent bound.

// GetUniversalCoreQuoterAddress reads the uniswapV3Quoter address stored in UniversalCore.
func (k Keeper) GetUniversalCoreQuoterAddress(ctx sdk.Context) (common.Address, error) {
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return common.Address{}, errors.Wrap(err, "failed to parse UniversalCore ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	receipt, err := k.evmKeeper.CallEVM(ctx, abi, ueModuleAccAddress, handlerAddr, false, nil, "uniswapV3Quoter")
	if err != nil {
		return common.Address{}, errors.Wrap(err, "failed to call uniswapV3Quoter")
	}

	results, err := abi.Methods["uniswapV3Quoter"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return common.Address{}, errors.Wrap(err, "failed to unpack uniswapV3Quoter result")
	}

	return results[0].(common.Address), nil
}

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)
}
