### Title
Fixed 5% slippage on instantaneous Uniswap V3 spot quote allows sandwich extraction of user gas-deposit value in GAS/GAS_AND_PAYLOAD inbound execution - (File: x/uexecutor/keeper/evm.go, x/uexecutor/keeper/execute_inbound_gas.go, x/uexecutor/keeper/execute_inbound_gas_and_payload.go)

### Summary
The external report describes CAP protocol allowing value extraction because mint/burn use the current oracle price with no protection beyond the raw Chainlink deviation band. Push Chain's `uexecutor` module has a native analog: when an inbound `GAS`/`GAS_AND_PAYLOAD` transaction is finalized, the module fetches a live Uniswap V3 `QuoterV2.quoteExactInputSingle` spot quote and immediately submits `depositPRC20WithAutoSwap` with `minPCOut = quote * 95 / 100` — a fixed 5% tolerance band around whatever price the pool happens to report at that moment, with no TWAP, staleness check, or manipulation detection.

### Finding Description
`GetSwapQuote` [1](#0-0)  calls the QuoterV2 contract for an instantaneous spot-price quote on `prc20 → wpc`. Both `ExecuteInboundGas` [2](#0-1)  and `gasAndPayloadDepositAutoSwap` [3](#0-2)  then compute `minPCOut` as exactly `quote * 95 / 100` and pass it straight into `CallPRC20DepositAutoSwap` [4](#0-3) , which performs the real swap via `DerivedEVMCall`. The same pattern is used for the unused-gas refund path in `applyGasRefund` [5](#0-4) .

Unlike Chainlink price feeds (which update discretely at defined deviation thresholds), an AMM spot price can be moved arbitrarily within a single block by anyone submitting an ordinary swap against the pool — no privileged role is required. Because the quote is read and consumed back-to-back inside the same keeper call with only a static 5% cushion, an attacker who swaps the pool price down just before the inbound-finalizing transaction lands (e.g., by out-bidding it in the same block) forces `GetSwapQuote` to return an already-depressed price. `minPCOut` is derived from that same depressed price, so it provides no real protection — the module's `depositPRC20WithAutoSwap` executes at the manipulated rate, and the attacker reverses their swap immediately afterward, capturing the arbitrage that should have gone to the depositing user as WPC/PC.

### Impact Explanation
The depositing user's PRC20 gas top-up (or gas-and-payload deposit) is swapped for less native PC than fair market value; the deficit is extracted by the attacker via the sandwich, directly reducing the funds credited to the user's UEA. This falls within the allowed impact of "draining ... of user or protocol-controlled funds" via corrupted PRC20/native asset accounting during universal execution. The same mechanism also applies to the excess-gas refund swap path, potentially reducing refunds owed to users.

### Likelihood Explanation
Medium. The attack requires only ordinary, unprivileged transactions (a swap before and after the module's finalization tx) and standard mempool-visibility/tx-ordering incentives common to EVM-compatible chains — no validator, relayer, or TSS compromise is needed. The bound on extractable value is capped by the 5% tolerance and pool liquidity/fee-tier depth, similar to how the CAP bug's impact was capped by the sum of oracle deviation thresholds.

### Recommendation
Short term: tighten the slippage tolerance to the minimum viable for legitimate volatility, and/or add a baseline fee/haircut that exceeds the maximum extractable sandwich value for the pool's typical liquidity depth. Long term: replace the instantaneous `quoteExactInputSingle` read with a TWAP-based quote (e.g., Uniswap V3 `OBSERVE`) or cross-check the spot quote against `ChainMeta`/an external reference price and reject/circuit-break the swap when the deviation exceeds a safe bound.

### Proof of Concept
1. Attacker monitors the mempool for a `MsgVoteInbound` transaction that will finalize a `GAS`/`GAS_AND_PAYLOAD` inbound and trigger `ExecuteInboundGas`/`ExecuteInboundGasAndPayload`.
2. Attacker submits a large swap against the same Uniswap V3 pool (`prc20AddressHex ↔ wpc`) with higher priority, depressing the pool's spot price for that pair within the same block.
3. The finalizing transaction executes; `GetSwapQuote` reads the now-depressed price, and `CallPRC20DepositAutoSwap` executes `depositPRC20WithAutoSwap` with `minPCOut` computed from that depressed price (only 5% below it), so it does not revert.
4. Attacker submits a reverse swap immediately after, restoring the pool price and pocketing the difference between the fair price and the depressed execution price that was applied to the user's deposit.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(

	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

		return nil, err

	minPCOut.Div(minPCOut, big.NewInt(100))
