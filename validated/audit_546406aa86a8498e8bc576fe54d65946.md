## Analysis Result

### Title
Uniswap V3 spot-quote used as its own slippage floor allows sandwich-manipulated swaps to drain value from user PRC20 deposits and gas refunds - (File: `x/uexecutor/keeper/evm.go`, `x/uexecutor/keeper/execute_inbound_gas.go`, `x/uexecutor/keeper/execute_inbound_gas_and_payload.go`, `x/uexecutor/keeper/outbound.go`)

### Summary
The external report flags `latestAnswer` (a single, unvalidated price read) being used for a critical financial calculation instead of `latestRoundData`, which would let the caller validate freshness/completeness before trusting the value. The Push Chain analog is the module's Uniswap V3 `QuoterV2.quoteExactInputSingle` spot-price call in [1](#0-0)  — it is a raw, single-block AMM spot quote with no TWAP, no external reference check, and no round/staleness validation, yet the module both uses it as the "expected output" and derives its own slippage protection from it.

### Finding Description
`GetSwapQuote` calls `QuoterV2.quoteExactInputSingle` and returns the instantaneous AMM spot price with zero freshness or manipulation safeguards (no TWAP, no comparison against a second source, no `sqrtPriceLimitX96` bound) [1](#0-0) .

This `quote` is then used to compute `minPCOut` as a flat 5% haircut of the *same* quote in three independent user-reachable flows:
- Inbound `GAS` deposits: `quote, execErr = k.GetSwapQuote(...)` then `minPCOut := quote * 95/100` before calling `CallPRC20DepositAutoSwap` [2](#0-1) .
- Inbound `GAS_AND_PAYLOAD` deposits: same pattern in `gasAndPayloadDepositAutoSwap` [3](#0-2) .
- Outbound gas refunds: `getSwapQuoteForRefund` feeds the same spot price into `applyGasRefund`'s `minPCOut` before calling `CallUniversalCoreRefundUnusedGas` [4](#0-3) , [5](#0-4) .

Because the "expected" quote and the "floor" (`minPCOut`) are both derived from the identical, unauthenticated spot price read in the same transaction, this provides no defense against price manipulation: an attacker who moves the underlying pool's price immediately before the module's `DerivedEVMCall` executes (e.g., via a large swap against the PRC20/WPC pool in the same or a preceding block) can force `quoteExactInputSingle` to return an already-skewed price. The 95% floor is computed relative to that skewed price, so the auto-swap executes at the manipulated rate and the attacker captures the difference — the same "read only the last-reported/uncorroborated value and trust it" defect the Chainlink report is about, applied to an AMM spot price instead of an oracle round.

### Impact Explanation
This directly corrupts PRC20/native asset accounting for ordinary user deposit and refund flows: the deposit auto-swap (`CallPRC20DepositAutoSwap`) and the gas-refund auto-swap (`CallUniversalCoreRefundUnusedGas`) move user/protocol-controlled value through a manipulable price with a self-referential slippage bound, allowing extraction of value from user deposits or from the protocol's refund pool — matching the in-scope impact "corruption of PRC20 or native asset accounting... unauthorized refund of user or protocol-controlled funds."

### Likelihood Explanation
Reachable by any unprivileged external attacker who can submit a normal crosschain GAS or GAS_AND_PAYLOAD deposit (or trigger an outbound gas refund) while also being able to move the underlying Uniswap pool price around the time honest validators finalize/execute that inbound/outbound — no privileged validator or TSS behavior is required; only the manipulable AMM pool and normal user-initiated deposit/refund paths.

### Recommendation
Do not derive the slippage floor from the same instantaneous quote used as the expected output. Use a manipulation-resistant reference (e.g., a TWAP over multiple blocks, or an external price feed cross-checked against the spot quote) to compute `minPCOut`, and/or bound the maximum deviation allowed between the spot quote and a longer-window reference before allowing the auto-swap to proceed. Consider making the slippage tolerance configurable/tightened and reverting to the no-swap fallback path when the spot/TWAP deviation exceeds a safe threshold.

### Proof of Concept
1. Attacker identifies the PRC20/WPC Uniswap V3 pool used by `GetUniversalCoreQuoterAddress`/`GetSwapQuote` for a given gas token.
2. Attacker swaps a large amount into/out of that pool to skew its instantaneous price just before (or in a preceding block relative to) submitting/triggering a GAS deposit inbound (or waiting for an outbound gas refund) for that same gas token.
3. When the module executes `ExecuteInboundGas`/`gasAndPayloadDepositAutoSwap`/`applyGasRefund`, `GetSwapQuote` returns the skewed price; `minPCOut = quote * 95/100` is computed from that same skewed price, so it does not protect against the manipulation.
4. `CallPRC20DepositAutoSwap` / `CallUniversalCoreRefundUnusedGas` executes at the skewed rate, and the attacker reverses their pool manipulation, netting the price difference at the expense of the user's deposit value or the protocol's refund pool.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)

// getSwapQuoteForRefund fetches a Uniswap quote for the gas token refund swap.
func (k Keeper) getSwapQuoteForRefund(ctx sdk.Context, gasToken common.Address, fee *big.Int, amount *big.Int) (*big.Int, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(ctx)
	if err != nil {
		return nil, err
	}
	wpcAddr, err := k.GetUniversalCoreWPCAddress(ctx)
	if err != nil {
		return nil, err
	}
	return k.GetSwapQuote(ctx, quoterAddr, gasToken, wpcAddr, fee, amount)
}
