## Analysis

The reported bug (Uniswap `swapInput` called with `amountOutMinimum = 0`, exposing liquidations to price-manipulation loss) maps onto Push Chain's own gas-abstraction and gas-refund auto-swap flows in `x/uexecutor/keeper/`, which route PRC20↔WPC conversions through an internal Uniswap V3 deployment via `UniversalCore.depositPRC20WithAutoSwap` / `refundUnusedGas`.

### Title
Slippage protection for gas-abstraction and gas-refund auto-swaps is computed from a manipulable spot quote, not a manipulation-resistant reference price - (File: `x/uexecutor/keeper/execute_inbound_gas.go`, `x/uexecutor/keeper/outbound.go`, `x/uexecutor/keeper/evm.go`)

### Summary
Unlike the original report where `amountOutMinimum` was hardcoded to `0`, Push Chain does compute a `minPCOut` before every PRC20→PC auto-swap. However, that `minPCOut` is derived from `GetSwapQuote`, which calls `QuoterV2.quoteExactInputSingle` against the *same* live Uniswap V3 pool that the swap itself will execute against, with no TWAP or external oracle reference. Because the "protection" price and the "execution" price come from the same manipulable spot state, an attacker who moves the pool price immediately beforehand causes both the quote and the real swap to be evaluated against the manipulated price, defeating the 5% slippage band entirely.

### Finding Description
`GetSwapQuote` (`x/uexecutor/keeper/evm.go:502-538`) is a `CallEVM` (non-commit) read of `QuoterV2.quoteExactInputSingle`, which simulates the swap against current pool reserves — i.e., a spot price, not a TWAP: [1](#0-0) 

This quote is consumed identically in three places, always as `minPCOut = quote * 95 / 100`:
- `ExecuteInboundGas` (gas-abstraction deposit path): [2](#0-1) 
- `gasAndPayloadDepositAutoSwap` (GAS_AND_PAYLOAD deposit path): [3](#0-2) 
- `applyGasRefund` (excess gas refund path on outbound completion): [4](#0-3) 

All three then execute the real swap via `CallPRC20DepositAutoSwap` / `CallUniversalCoreRefundUnusedGas`, both of which pass through the same generic `DerivedEVMCall` primitive as a normal, block-ordered EVM transaction: [5](#0-4) [6](#0-5) 

Since `DerivedEVMCall` produces a normal transaction ordered like any other EVM tx in the block, an unprivileged attacker who can predict that a validator-vote quorum (`MsgVoteInbound`) or outbound-completion vote will trigger one of these auto-swaps in an upcoming block can submit an ordinary large swap against the same WPC/PRC20 Uniswap V3 pool immediately beforehand. Both `GetSwapQuote` and the subsequent real swap will then observe the attacker-manipulated pool state, so the 5% band is computed against an already-bad price and provides no real floor. The attacker reverses their manipulating trade afterward (same or later block) and captures the value difference at the expense of the bridging user (gas-abstraction deposit) or the refund recipient (gas refund).

### Impact Explanation
This directly corrupts "gas fee accounting" / "refund accounting" and results in unauthorized loss of user funds during otherwise-honest, validator-approved universal execution flows — a bridging user depositing native gas token receives materially less PC than fair value, or a refund recipient receives a manipulated (lower) PC amount, with the difference captured by an unprivileged attacker via pool manipulation. No privileged actor is required; only an ordinary EVM account able to trade against the internal Uniswap pool. Impact is capped by available liquidity/slippage bounds and requires a thin/low-liquidity pool to be highly profitable, so severity is Medium, matching the analogous upstream finding's impact/likelihood rating.

### Likelihood Explanation
Likelihood depends on: (1) pool liquidity depth for the relevant PRC20/WPC pair being thin enough that a single-block manipulation is economical, and (2) the attacker being able to anticipate when quorum will be reached for a pending inbound/outbound vote (observable via mempool/chain state, since votes accumulate publicly before quorum). Both conditions are plausible for newly-bridged or low-volume PRC20 assets, making this a realistic Medium-likelihood scenario rather than purely theoretical.

### Recommendation
Do not derive the slippage floor from the same spot AMM state the swap will execute against. Use a manipulation-resistant reference price (e.g., a TWAP over multiple blocks from the Uniswap V3 pool's oracle observations, or an external price feed) to compute `minPCOut`/`minAmountOut`, or bound the maximum allowed single-block price impact independent of the current spot quote.

### Proof of Concept
1. Attacker identifies a pending `Inbound`/`OutboundTx` close to reaching vote quorum for a PRC20 asset with a thin WPC/PRC20 Uniswap V3 pool (observable via public vote transactions before quorum is met).
2. In the block immediately preceding the quorum-triggering vote, attacker submits a large swap that pushes the pool price against PC (e.g., dumps PRC20 into the pool).
3. The quorum vote executes in a later transaction in the same/following block, triggering `ExecuteInboundGas`/`applyGasRefund`, which calls `GetSwapQuote` — reading the now-manipulated pool price — and computes `minPCOut` as 95% of that manipulated (low) quote.
4. `CallPRC20DepositAutoSwap`/`CallUniversalCoreRefundUnusedGas` executes the real swap, which trivially satisfies the manipulated `minPCOut`, delivering far less PC than fair value to the bridging user/refund recipient.
5. Attacker reverses their initial trade to restore the pool price, realizing the captured spread as profit.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)
}

// CallUniversalCoreRefundUnusedGas calls refundUnusedGas on UniversalCore to return excess gas fee
// to the recipient. withSwap=true swaps the gas token back to PC; withSwap=false deposits PRC20 directly.
func (k Keeper) CallUniversalCoreRefundUnusedGas(
	ctx sdk.Context,
	gasToken common.Address,
	amount *big.Int,
	recipient common.Address,
	withSwap bool,
	fee *big.Int,
	minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse UniversalCore ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	// fee is uint24 in Solidity — pass as *big.Int (go-ethereum ABI packs non-standard widths as *big.Int)
	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress,
		handlerAddr,
		big.NewInt(0),
		nil,
		true,
		false,
		true,
		&nonce,
		"refundUnusedGas",
		gasToken,
		amount,
		recipient,
		withSwap,
		fee,
		minPCOut,
	)
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}
