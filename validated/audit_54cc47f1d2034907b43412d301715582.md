### Title
`execute_replace_class` in the Starknet OS Cairo program updates the class-hash mapping without verifying class declaration, unlike the Blockifier's syscall handler - (File: `crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo`)

### Summary
The Starknet OS (Cairo re-execution/"Starknet OS re-execution" program) implements the `replace_class` syscall in `execute_replace_class` by unconditionally overwriting the contract's `class_hash` entry in `contract_state_changes`, with an explicit `TODO` acknowledging that the check for class declaration is missing. In contrast, the Blockifier's native syscall handler enforces this invariant before performing the write. This mismatch is the same bug class as the external report: a state-tracking mapping (`ownerToId` there, `class_hash` here) that one code path updates without validating the precondition another code path enforces, breaking the intended invariant that a contract's class hash can only be replaced with a **declared** class.

### Finding Description
The Blockifier's `replace_class` syscall handler explicitly requires the target class to be declared before mutating state: [1](#0-0) 

The corresponding Cairo-1 syscall handler in the Starknet OS program (`crates/apollo_starknet_os_program`), which is the code that Starknet full nodes/provers run during **Starknet OS re-execution** to independently verify and commit a block's state transition, does not perform this check at all. The code contains a literal admission of the gap: [2](#0-1) 

Note line 902: `// TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.` — the function proceeds directly to `GetContractAddressStateEntry` and unconditionally writes the new `class_hash` into `contract_state_changes` via `dict_update`, with no lookup into any class-declaration mapping. The deprecated (Cairo-0) syscall path has the identical gap: [3](#0-2) 

A grep across the entire `apollo_starknet_os_program` tree confirms there is no `declared_classes`/`UndeclaredClassHash`-style guard anywhere in the OS execution path that would compensate for this — the mapping enforcing "is this class hash declared" that the Blockifier consults is simply never consulted by the OS when processing `REPLACE_CLASS_SELECTOR`.

This is structurally identical to the reported NFTPool bug: an invariant (`ownerToId` should reflect true ownership / `class_hash` should only ever be set to a declared class) is enforced on one code path (mint/`create_position` vs. Blockifier's `replace_class`) but silently bypassed on a semantically equivalent path (`safeTransferFrom` vs. the OS's `execute_replace_class`), because the second path's implementation of the state-mutating primitive omits the validation that keeps the tracked mapping consistent with the security invariant.

### Impact Explanation
The Starknet OS is the ground truth used to re-execute and commit the state diff / state root for a block (via Patricia tree updates over `contract_state_changes`) and is also the logic proven by the Starknet OS program for L1 state validity. If the OS's `execute_replace_class` accepts and commits a `class_hash` update for an undeclared class while a conformant Blockifier execution would have reverted that call (and produced a different state diff / gas consumption / revert flag), then:
- The state root the OS computes and commits can diverge from what an honest sequencer executing the same transaction via the Blockifier would produce (honest-node divergence / wrong committed root).
- A contract could end up with its `class_hash` pointing to a class hash that was never declared on-chain, corrupting the class/compiled-class commitment invariant that every deployed/replaced class hash must correspond to a declared class — this is a permanent, unauthorized modification of protocol-level account state reachable from a single unprivileged contract call to the `replace_class` syscall.

### Likelihood Explanation
This is trivially reachable by any account/contract: any Cairo 1 contract can invoke `replace_class_syscall(class_hash)` with an arbitrary, never-declared `class_hash` in a single transaction. No special privileges, staking, or multi-transaction setup is required — only a deployed contract capable of issuing the syscall, matching an "unprivileged transaction sender/contract call" reachable path.

### Recommendation
Add the same declared-class validation used in the Blockifier's `replace_class` handler to the Cairo OS implementation before writing the new `StateEntry`: look up `class_hash` in the compiled/declared classes structures (mirroring `get_compiled_class`/`UndeclaredClassHash` handling) and fail/revert the syscall if the class hash has not been declared, in both `execute_replace_class` (Cairo 1, `syscall_impls.cairo`) and `execute_replace_class` (deprecated Cairo 0, `deprecated_execute_syscalls.cairo`), so the OS's accepted state transitions are always consistent with the Blockifier's.

### Proof of Concept
1. Deploy a contract `A` with a valid, declared class hash.
2. From within `A`, invoke the `replace_class` syscall with an arbitrary `class_hash` value that has never been declared (no `Declare` transaction exists for it).
3. Under the Blockifier (`crates/blockifier/src/execution/deprecated_syscalls/hint_processor.rs::replace_class`), `state.get_compiled_class(request.class_hash)` returns `StateError::UndeclaredClassHash`, causing the syscall/entry point to fail, per the existing test: [4](#0-3) 
4. Under the Starknet OS re-execution path (`execute_replace_class` in `syscall_impls.cairo`), the same syscall request is processed without any declared-class check and unconditionally commits `class_hash=undeclared_hash` into `contract_state_changes`, which subsequently gets Patricia-committed into the contract state root — a divergent, invalid outcome compared to the Blockifier's revert.

// Replaces the class.
func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
