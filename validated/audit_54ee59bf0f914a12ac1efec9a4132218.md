### Title
Unmetered O(codeSize) SHA3 recomputation on every internal CALL via `Program.getCodeHash()` enables CPU-amplification DoS - (File: `actuator/src/main/java/org/tron/core/vm/program/Program.java`)

### Finding Description
`Program.getCodeHash()` computes the callee's code hash to build the jump-destination analysis cache key (`getJumpDestAnalysisCacheKey()`), which is invoked whenever a new `Program` frame is created for a call target (`CALL`/`DELEGATECALL`/`STATICCALL`): [1](#0-0) 

Unlike `getCodeHashAt()` (used for the `EXTCODEHASH` opcode), which persists the computed hash back onto the `ContractCapsule` so subsequent lookups are O(1): [2](#0-1) 

`getCodeHash()` never writes the computed digest back to storage. If the target contract's `ContractCapsule.codeHash` field is empty/zero (e.g., a contract deployed under a code path or version where `codeHash` was never persisted at creation time), every single call into that contract falls into the `Hash.sha3(ops)` branch, hashing the *entire* bytecode of the target contract from scratch. Since this happens once per new call frame, an attacker-controlled contract B that issues N sequential `CALL`/`DELEGATECALL`/`STATICCALL` instructions to a large contract A forces N full-bytecode SHA3 passes over A's code within a single transaction. Each such call is charged only the flat `EnergyCost.CALL_ENERGY` base cost plus stipend/memory expansion — none of which scale with the callee's code size — so the CPU cost of hashing (O(codeSize) per call, O(N·codeSize) total) is not reflected in the energy charged for the transaction.

### Impact Explanation
This breaks the faithful-metering invariant between energy charged and CPU work performed by the node executing the transaction: a transaction that is capped by `energyLimit` at 40 energy per CALL can force disproportionate CPU expenditure by repeatedly triggering full-bytecode hashing of a large, un-hash-cached contract. This falls into the "DoS via the TRON protocol implementation" bounty class — a crafted, self-funded transaction can cause execution-time amplification relative to its metered cost, degrading node throughput for validators processing the transaction.

### Likelihood Explanation
Preconditions: (1) attacker must control or find a target contract A whose `ContractCapsule.codeHash` is empty (this can be attacker-deployed, since deployment is permissionless and attacker fully controls contract A's bytecode size up to the max contract size), and (2) attacker deploys caller contract B with a loop of CALL/DELEGATECALL/STATICCALL opcodes targeting A, bounded by `energyLimit`. Both actions are ordinary, unprivileged, fee-paying operations (contract creation + a single transaction invoking B). The attack is fully repeatable and does not require any race condition, privileged role, or node misconfiguration — it only depends on the `getCodeHash()` implementation shown above, which is confirmed to lack persistence unlike its sibling `getCodeHashAt()`.

### Recommendation
Make `getCodeHash()` persist the computed digest to the `ContractCapsule` (mirroring `getCodeHashAt()`'s `contract.setCodeHash(codeHash); getContractState().updateContract(...)`) so the hash is computed at most once per contract, or ensure `codeHash` is always populated at contract-creation time so this fallback path is never taken in practice. Additionally, consider charging CALL-family opcodes an energy cost component proportional to the callee's code size when a codeHash/jumpdest-analysis cache miss occurs, so CPU cost stays proportional to charged energy.

  public byte[] getCodeHashAt(DataWord address) {
    byte[] tronAddr = address.toTronAddress();
    AccountCapsule account = getContractState().getAccount(tronAddr);
    if (account != null) {
      ContractCapsule contract = getContractState().getContract(tronAddr);
      byte[] codeHash;
      if (contract != null) {
        codeHash = contract.getCodeHash();
        if (ByteUtil.isNullOrZeroArray(codeHash)) {
          byte[] code = getCodeAt(address);
          codeHash = Hash.sha3(code);
          contract.setCodeHash(codeHash);
          getContractState().updateContract(tronAddr, contract);
        }
      } else {
        codeHash = Hash.sha3(new byte[0]);
      }
      return codeHash;
    } else {
      return EMPTY_BYTE_ARRAY;
    }
  }
