### Title
Gas fee truncates to zero when network base fee drops below 1 upc, allowing free UEA/CEA payload execution - (File: `x/uexecutor/keeper/fees.go`)

### Summary
`CalculateGasCost()` unwraps the `feemarket` module's `LegacyDec` base fee into a whole-`upc` `big.Int` using integer division by `1e18`. This mirrors the `getBurnOutputs()` precision-loss pattern: if the numerator (`baseFee` in its 18-decimal fixed-point form) is smaller than the divisor (`1e18`), the division truncates to `0` instead of a small positive value, and the resulting gas fee charged to the recipient becomes `0` regardless of `gasUsed`.

### Finding Description [1](#0-0) 

```go
baseFeeBig := baseFee.BigInt()
// ...This division unwraps the LegacyDec encoding back to the actual upc amount.
baseFeeBig.Div(baseFeeBig, big.NewInt(1e18))
...
effectiveGasPrice := new(big.Int).Set(baseFeeBig)
...
gasCost := new(big.Int).Mul(effectiveGasPrice, gasUsedBig)
``` [2](#0-1) 

The comment asserts "the base fee is always a whole number of upc -- no fractional upc exists," but that assumption depends entirely on the `feemarket` module's dynamic base-fee adjustment always staying at or above `1e18` (1 whole `upc`) in its internal `LegacyDec` representation. Cosmos EVM's EIP-1559-style fee market decreases the base fee geometrically when blocks are under-target (e.g., by ~12.5% per empty block), so on a low-traffic chain or immediately post-genesis/post-upgrade, `baseFee` can legitimately fall below `1.0` in `LegacyDec` terms. When that happens, `baseFeeBig.Div(baseFeeBig, big.NewInt(1e18))` truncates to `0`, `effectiveGasPrice` becomes `0`, and `gasCost = 0 * gasUsed = 0` in `DeductGasFeesFromReceipt()`, which then returns success without deducting or burning any fee via `DeductAndBurnFees()`. [3](#0-2) 

This is directly analogous to the `HifiPool.getBurnOutputs()` bug: a division whose result silently rounds down to zero when the numerator is smaller than the divisor, with no guard checking whether the pre-division value was non-zero/large enough to represent meaningfully in the target unit.

### Impact Explanation
If triggered, gas fees for `executeUniversalTx` payload execution (module-originated `DerivedEVMCall`/EVM execution charged to the UEA/CEA recipient) become `0` instead of the real, intended fee. This directly affects "corruption of ... gas fee accounting" and could let an unprivileged user execute arbitrary EVM payloads via universal execution without paying/burning gas, undermining the fee-burn invariant the code otherwise carefully enforces (`DeductAndBurnFees`, `applyGasRefund`, etc.). At scale, this is a free-execution/DoS vector against the chain's gas-accounting invariant.

### Likelihood Explanation
Uncertain/low-to-moderate. I could not confirm from the indexed code whether the `feemarket` module's parameters (min base fee, min gas price, base-fee-change-denominator) enforce a floor at or above `1e18` (1 whole `upc`) at all times. The comment in `fees.go` asserts this is guaranteed, and `app/cosmos/min_gas_price.go` / `app/ante/validator_tx_fee.go` suggest a separate min-gas-price ante concept exists, but I did not find code that clamps the `feemarket` base fee itself to `>= 1 upc`. Without confirming the `feemarket` params (`BaseFeeChangeDenominator`, `MinGasPrice`, `NoBaseFee`) actually prevent sub-1-upc base fees during low-activity periods, I cannot assert this is definitely reachable by an ordinary user — this needs verification against the live `feemarket` genesis/params configuration.

### Recommendation
In `CalculateGasCost()`, avoid truncating division on the base fee. Either keep the calculation entirely in `LegacyDec`/`sdk.Dec` precision until the very end (rounding up, not down, when converting to the final `upc` integer), or explicitly reject/round up when `baseFeeBig` would truncate to zero, mirroring the Hifi recommendation of validating the numerator against the divisor before dividing. Additionally, confirm (or add) a `feemarket` parameter floor that prevents the base fee from ever representing less than `1 upc`, and add a unit test asserting `CalculateGasCost` never returns `0` for `gasUsed > 0` when the true base fee is nonzero.

### Proof of Concept
Not independently reproducible from static analysis alone — requires confirming the live `feemarket` params allow `baseFee < 1e18` (in `LegacyDec` terms). If confirmed:
1. Let the chain run with low transaction throughput so `feemarket`'s dynamic base fee decays below `1 upc` (e.g., `0.9 * 1e18` internally).
2. Submit a UEA/CEA universal transaction with `maxFeePerGas >= 0` (trivially satisfied) and any `gasUsed > 0`.
3. `CalculateGasCost` computes `baseFeeBig.Div(...) = 0`, `gasCost = 0`; `DeductGasFeesFromReceipt` deducts and burns `0` upc, letting execution proceed without any real fee payment.

func (k Keeper) CalculateGasCost(
	baseFee sdkmath.LegacyDec,
	maxFeePerGas *big.Int,
	maxPriorityFeePerGas *big.Int,
	gasUsed uint64,
) (*big.Int, error) {
	baseFeeBig := baseFee.BigInt()
	// @dev: LegacyDec stores values with 18-decimal precision internally, so 1 upc = 1e18
	// in the LegacyDec representation. Since 1 upc is the smallest denomination (like wei
	// in Ethereum), the base fee is always a whole number of upc -- no fractional upc exists.
	// This division unwraps the LegacyDec encoding back to the actual upc amount.
	// Note: baseFee.BigInt() returns a reference to the internal big.Int; the in-place Div
	// mutates it, which is safe here since baseFee is a local value-type copy.
	baseFeeBig.Div(baseFeeBig, big.NewInt(1e18))

	// Step 1: Validate maxFeePerGas >= baseFee
	if maxFeePerGas.Cmp(baseFeeBig) < 0 {
		return nil, fmt.Errorf("maxFeePerGas (%s) cannot be less than baseFee (%s)", maxFeePerGas, baseFeeBig)
	}

	// Step 2: Calculate baseFee + maxPriorityFeePerGas (potential effective gas price)
	// @dev: Currently, we are not using maxPriorityFeePerGas in the calculation
	// tipPlusBase := new(big.Int).Add(baseFeeBig, maxPriorityFeePerGas)
	// tipPlusBase := maxFeePerGas

	// Step 3: Find effective gas price by taking minimum
	// @dev: Currently, since we are not using maxPriorityFeePerGas, effectiveGasPrice is just baseFee
	effectiveGasPrice := new(big.Int).Set(baseFeeBig)
	// if tipPlusBase.Cmp(maxFeePerGas) == -1 {
	// 	effectiveGasPrice = tipPlusBase
	// }

	// Step 4: Calculate final gas cost: effectiveGasPrice * gasUsed
	gasUsedBig := new(big.Int).SetUint64(gasUsed)
	gasCost := new(big.Int).Mul(effectiveGasPrice, gasUsedBig)

	k.Logger().Debug("gas cost calculated",
		"base_fee", baseFee.String(),
		"effective_gas_price", effectiveGasPrice.String(),
		"gas_used", gasUsed,
		"gas_cost", gasCost.String(),
	)

	return gasCost, nil
}

func (k Keeper) DeductGasFeesFromReceipt(
	ctx context.Context,
	sdkCtx sdk.Context,
	recipient common.Address,
	receipt *evmtypes.MsgEthereumTxResponse,
	universalPayload *types.UniversalPayload,
) error {
	if receipt == nil || receipt.GasUsed == 0 {
		return nil
	}
	if universalPayload == nil {
		return nil
	}

	abiPayload, err := types.NewAbiUniversalPayload(universalPayload)
	if err != nil {
		return fmt.Errorf("failed to parse payload for gas deduction: %w", err)
	}

	baseFee := k.feemarketKeeper.GetBaseFee(sdkCtx)
	if baseFee.IsNil() {
		return fmt.Errorf("base fee not found")
	}

	gasCost, err := k.CalculateGasCost(baseFee, abiPayload.MaxFeePerGas, abiPayload.MaxPriorityFeePerGas, receipt.GasUsed)
	if err != nil {
		return fmt.Errorf("failed to calculate gas cost: %w", err)
	}
	if gasCost.Sign() <= 0 {
		return nil
	}
