## Analysis

The Ramses bug is about **rounding direction favoring the wrong party** in a threshold/debt computation. The closest analog in this repo is a discrepancy between two independent implementations of the same "supermajority weight" concept: one rounds up (ceiling), the other rounds down (floor), even though both are supposed to enforce the same `NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD` (70%) supermajority bar.

**Ceiling (correct/strict) implementation** — used for the actual on-chain block-signature-weight check: [1](#0-0) 

```rust
pub fn compute_voting_weight_threshold(total_weight: u32) -> Result<u32, ChainstateError> {
    let threshold = NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD;
    let total_weight = u64::from(total_weight);
    let ceil = if (total_weight * threshold) % 10 == 0 { 0 } else { 1 };
    u32::try_from((total_weight * threshold) / 10 + ceil)...
}
```

**Floor (loose) implementation** — used by the signer-side `GlobalStateEvaluator` to decide whether "global agreement" among signers has been reached for burn-view, current-miner, protocol-version and tx-replay-set consensus: [2](#0-1) 

```rust
pub fn reached_agreement(&self, vote_weight: u32) -> bool {
    u64::from(vote_weight)
        >= u64::from(self.total_weight).strict_mul(NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD)
            / 10
}

pub fn reached_disagreement(&self, vote_weight: u32) -> bool {
    u64::from(vote_weight)
        > u64::from(self.total_weight).strict_mul(10 - NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD)
            / 10
}
```

`reached_agreement` truncates (`/10` floors) instead of taking the ceiling like `compute_voting_weight_threshold` does. Both functions are meant to answer "has this weight X met the 70% supermajority bar out of `total_weight`?" but they diverge whenever `total_weight * 7` isn't a multiple of 10.

Example: `total_weight = 13`. `compute_voting_weight_threshold(13)` = `ceil(91/10)` = `10` (76.9%). `reached_agreement(9)` evaluates `9 >= 91/10 = 9` → **true**, i.e. only `9/13 ≈ 69.2%` — *below* the true 70% bar — is treated as having reached agreement. This is used in `determine_latest_supported_signer_protocol_version`, `determine_global_burn_view`, and `determine_global_state` in the same file: [3](#0-2) [4](#0-3) 

### Title
Signer-side `GlobalStateEvaluator::reached_agreement`/`reached_disagreement` floor the supermajority threshold instead of rounding up, letting sub-70%-weight signers falsely trigger "global agreement" - ([File: libsigner/src/v0/signer_state.rs])

### Summary
`GlobalStateEvaluator::reached_agreement` and `reached_disagreement` compute the `NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD` (70%) supermajority weight using truncating integer division (`total_weight * 7 / 10`), whereas the authoritative on-chain equivalent, `NakamotoBlockHeader::compute_voting_weight_threshold`, explicitly rounds this quantity up (`ceil`). For any `total_weight` where `total_weight * 7` is not a multiple of 10, this yields two different thresholds for what is meant to be the identical 70%-of-weight bar.

### Finding Description
`compute_voting_weight_threshold` is the chain-enforced threshold used in `verify_signer_signatures` to decide whether a Nakamoto block has enough signer weight to be valid — it deliberately rounds up so that fewer than 70% weight can never pass. [5](#0-4) 

`reached_agreement`/`reached_disagreement`, by contrast, floor the same 70%/30% fractions. They are used purely on the signer side to decide whether the signer set has reached "global agreement" on the supported protocol version, the global burn view, and the global `SignerStateMachine` (which includes `current_miner` and `tx_replay_set`): [6](#0-5) 

Because the floor-based check accepts strictly less weight than the ceiling-based check for the same `total_weight` (whenever `total_weight * 7 % 10 != 0`), a coalition of signers holding weight in the gap between the floor and the ceiling thresholds (i.e. weight that is mathematically below the true 70% supermajority but numerically satisfies the floor-based `>=` check) can cause `determine_global_state`/`determine_global_burn_view`/`determine_latest_supported_signer_protocol_version` to report "agreement reached" when the actual chain-enforced signer threshold has not been met.

### Impact Explanation
This breaks the intended equality "signer agreement requires ≥70% of signer weight" between the value the chain enforces for block approval and the value signers themselves use to decide on their local/global view of state (current miner, burn view, protocol version, replay set). Signers that adopt this falsely-"agreed" state can diverge from the honest majority's view (e.g. capitulate to a different `current_miner` or `tx_replay_set` than warranted), producing a temporary tip/view disagreement among signers driven by weight that is provably under the real threshold. Per the given impact categories, this is a minority-triggerable static-validation-style divergence bounded to a temporary tip disagreement (High).

### Likelihood Explanation
No majority is required — any `total_weight` value where `total_weight * NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD` is not evenly divisible by 10 produces this gap automatically (this is the common case, not an edge case), and any signer coalition whose weight falls into the 1-unit gap between floor and ceiling triggers the divergence. This requires no special privileges — just being an active signer with weight in that band.

### Recommendation
Make `reached_agreement`/`reached_disagreement` use the same ceiling-rounding logic as `NakamotoBlockHeader::compute_voting_weight_threshold` (or better, call that function directly) so the signer-side supermajority computation is provably identical to the chain-enforced one.

### Proof of Concept
1. Configure a signer set with `total_weight = 13` and `NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD = 7`.
2. On-chain: `compute_voting_weight_threshold(13)` = `ceil(91/10)` = `10` — 10/13 weight units needed.
3. Signer-side: `reached_agreement(9)` evaluates `9 >= 91/10 (=9)` → `true`.
4. A coalition controlling weight 9 (≈69.2%, below the real 70% bar) causes `determine_global_state`/`determine_global_burn_view` to report agreement reached, while the same weight would not be sufficient to approve a block under `verify_signer_signatures`, producing a state view/decision inconsistent with the chain's actual supermajority requirement.

    /// Determine what the maximum signer protocol version that a majority of signers can support
    pub fn determine_latest_supported_signer_protocol_version(&self) -> Option<u64> {
        let mut protocol_versions = HashMap::new();
        for (address, update) in &self.address_updates {
            let Some(weight) = self.address_weights.get(address) else {
                continue;
            };
            let entry = protocol_versions
                .entry(update.local_supported_signer_protocol_version)
                .or_insert_with(|| 0);
            *entry += weight;
        }
        // find the highest version number supported by a threshold number of signers
        let mut protocol_versions: Vec<_> = protocol_versions.into_iter().collect();
        protocol_versions.sort_by_key(|(version, _)| *version);
        let mut total_weight_support: u32 = 0;
        for (version, weight_support) in protocol_versions.into_iter().rev() {
            total_weight_support += weight_support;
            if self.reached_agreement(total_weight_support) {
                return Some(version);
            }
        }
        None
    }

    /// Determine what the global burn view is if there is one
    pub fn determine_global_burn_view(&self) -> Option<(&ConsensusHash, u64)> {
        let mut burn_blocks = HashMap::new();
        for (address, update) in &self.address_updates {
            let Some(weight) = self.address_weights.get(address) else {
                continue;
            };
            let (burn_block, burn_block_height) = update.content.burn_block_view();

            let entry = burn_blocks
                .entry((burn_block, burn_block_height))
                .or_insert_with(|| 0);
            *entry += weight;
            if self.reached_agreement(*entry) {
                return Some((burn_block, burn_block_height));
            }
        }
        None
    }

    /// Check if there is an agreed upon global state
    pub fn determine_global_state(&self) -> Option<SignerStateMachine> {
        let active_signer_protocol_version =
            self.determine_latest_supported_signer_protocol_version()?;
        let mut state_views = HashMap::new();
        let mut tx_replay_sets = HashMap::new();
        let mut found_state_view = None;
        let mut found_replay_set = None;
        for (address, update) in &self.address_updates {
            let Some(weight) = self.address_weights.get(address) else {
                continue;
            };
            let (burn_block, burn_block_height) = update.content.burn_block_view();
            let current_miner = update.content.current_miner();
            let tx_replay_set = update.content.tx_replay_set();

            let state_machine = SignerStateMachine {
                burn_block: burn_block.clone(),
                burn_block_height,
                current_miner: current_miner.clone().into(),
                active_signer_protocol_version,
                // We need to calculate the threshold for the tx_replay_set separately
                tx_replay_set: ReplayTransactionSet::none(),
            };
            let key = SignerStateMachineKey(state_machine.clone());
            let entry = state_views.entry(key).or_insert_with(|| 0);
            *entry += weight;

            if self.reached_agreement(*entry) {
                found_state_view = Some(state_machine);
            }

            let replay_entry = tx_replay_sets
                .entry(tx_replay_set.clone())
                .or_insert_with(|| 0);
            *replay_entry += weight;

            if self.reached_agreement(*replay_entry) {
                found_replay_set = Some(tx_replay_set);
            }
            if found_replay_set.is_some() && found_state_view.is_some() {
                break;
            }
        }
        // Try to find agreed replay set, or find longest common prefix if no exact agreement
        let final_replay_set = if let Some(tx_replay_set) = found_replay_set {
            tx_replay_set
        } else {
            // No exact agreement found, try finding longest common prefix with majority support
            self.find_majority_prefix_replay_set(&tx_replay_sets)
                .unwrap_or_else(ReplayTransactionSet::none)
        };

        if let Some(state_view) = found_state_view.as_mut() {
            state_view.tx_replay_set = final_replay_set;
        }
        found_state_view
    }
