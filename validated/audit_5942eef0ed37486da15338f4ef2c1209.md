### Title
Factory Proxy Contract Left With Unset Owner After Genesis — Front-Runnable `initialize()` Ownership Seizure - (File: x/uexecutor/keeper/genesis.go)

### Summary
The external report's bug class is "no transfer-ownership pattern" — an `onlyOwner` contract whose ownership can end up assigned to an uncontrolled/attacker-influenced address due to a missing safety check in the ownership-assignment flow. The Push Chain analog is not a `transferOwnership()` call, but the equivalent failure mode in the UEA Factory's `initialize(address initialOwner)` initializer: genesis deploys the Factory's bytecode directly via `SetAccount`/`SetCode` (bypassing constructor execution) and never calls `initialize()` to bind an owner, leaving the `Ownable`/`Initializable` owner and `_initialized` guard unset on-chain at launch.

### Finding Description
`deployFactoryEA` in [1](#0-0)  deploys the Factory implementation, ProxyAdmin, and Factory proxy by directly writing runtime bytecode and storage slots with `evmKeeper.SetAccount`/`SetCode`/`SetState`: [2](#0-1) 

For the `ProxyAdmin` contract, genesis explicitly writes the `Ownable.owner` storage slot to the hardcoded `PROXY_ADMIN_OWNER_ADDRESS_HEX`: [3](#0-2) 

However, no equivalent step exists for the Factory contract itself. The Factory's ABI exposes `initialize(address initialOwner)` as a callable, unguarded (from the chain's perspective) function: [4](#0-3) 

A `grep` across `x/uexecutor/**` for the string `"initialize"` only matches the ABI definition file — it is never invoked from `x/uexecutor/keeper/genesis.go` or any other production keeper code path. The only place `initialize` is called on the Factory is in the test harness: [5](#0-4) 

Because the contracts are deployed by injecting bytecode directly instead of executing a constructor/CREATE transaction, any `_disableInitializers()` guard that would normally run in an OpenZeppelin `Initializable` constructor never executes. Combined with the absence of a genesis-time `initialize()` call, the Factory contract is left in a state where its `owner` slot is zero and its initializer has not been consumed on the live chain.

### Impact Explanation
The Factory contract's owner controls `setUEAProxyImplementation`, `registerNewChain`, and `registerUEA` — functions defined in the same ABI: [6](#0-5) 

`setUEAProxyImplementation` sets the implementation address that every deployed UEA proxy delegates execution to. If an unprivileged attacker can front-run the intended owner by calling `initialize(attackerAddress)` in the first block/transaction where this becomes possible, they gain the ability to point all future Universal Executor Account proxies at attacker-controlled bytecode — enabling unauthorized UEA execution and potential theft of any funds routed through UEAs, matching the "unauthorized UEA or CEA execution" and "unauthorized module-originated EVM execution" allowed-impact categories.

### Likelihood Explanation
This requires that in the actual production genesis/deploy sequence, no other code path (which I was not able to locate within the available iterations — e.g., a governance-only bootstrap message, a migration handler, or code outside `x/uexecutor` and `app/` that I could not fully enumerate) calls `initialize()` on the Factory before the chain accepts general user transactions. I confirmed via `grep_search` that no call exists in `x/uexecutor/**`, but I could not exhaustively verify the entire `app/` initialization path or the external `push-chain-core-contracts` constructor logic (referenced only by bytecode hash, source not present in this repo) within the remaining budget. If the production launch procedure includes an off-chain, pre-general-availability transaction that calls `initialize()` atomically with/before genesis is opened to public traffic, this issue is not exploitable by an unprivileged attacker and the analog would not hold.

### Recommendation
- Ensure genesis directly sets the Factory contract's `owner` storage slot (as is already done for `ProxyAdmin`) rather than relying on a callable `initialize()` that becomes racable once the chain accepts transactions.
- Alternatively, call `initialize()` synchronously inside `deployFactoryEA` during `InitGenesis`, atomically with bytecode deployment, so no block window exists where the function is callable by an external account.
- Audit all other system contracts deployed via direct bytecode injection (see the 47-entry `SYSTEM_CONTRACTS` map noted in `x/uregistry/keeper/genesis_internal_test.go`) for the same pattern — any `Initializable` contract deployed this way needs its initializer either disabled at genesis or its owner slot written directly, not left for a post-genesis call.

### Proof of Concept
1. Observe that `x/uexecutor/keeper/genesis.go:deployFactoryEA` deploys the Factory proxy/impl/admin via `SetAccount`/`SetCode`/`SetState` only, with no call to `initialize`.
2. Confirm (via `grep_search` across `x/uexecutor/**`) that `initialize` is invoked on the Factory only from `test/utils/contracts_setup.go`, a test-only helper — not from any production keeper/genesis/module-init code.
3. On a freshly launched chain, before any legitimate operator transaction calls `initialize(intendedOwner)`, an attacker submits `initialize(attackerAddress)` against the Factory proxy address (`FACTORY_PROXY_ADDRESS_HEX`).
4. If the Factory's initializer guard was never engaged (because its constructor never ran due to direct bytecode injection) and no owner was pre-set in genesis state, the attacker's call succeeds, and `owner()` now returns the attacker's address, matching the pattern demonstrated conceptually in `test/utils/contracts_setup.go:119-130` where a caller supplies its own address as `initialOwner`.

func deployFactoryProxy(ctx context.Context, evmKeeper types.EVMKeeper) {
	sdkCtx := sdk.UnwrapSDKContext(ctx)
	proxyAddress := common.HexToAddress(types.FACTORY_PROXY_ADDRESS_HEX)
	proxyAdminOwner := common.HexToAddress(types.PROXY_ADMIN_ADDRESS_HEX)
	factoryImplAddress := common.HexToAddress(types.FACTORY_IMPL_ADDRESS_HEX)

	// Compute the code hash from the runtime bytecode
	codeHash := crypto.Keccak256(types.ProxyRuntimeBytecode)

	// Create the EVM account object
	evmAccount := statedb.Account{
		Nonce:    1,             // to prevent tx nonce=0 conflicts
		Balance:  new(uint256.Int), // zero balance by default
		CodeHash: codeHash,      // link to deployed code
	}

	// Set the EVM account with the factory proxy contract
	err := evmKeeper.SetAccount(sdkCtx, proxyAddress, evmAccount)
	if err != nil {
		panic("failed to set factory proxy contract account: " + err.Error())
	}

	// Store the runtime bytecode linked to the code hash
	evmKeeper.SetCode(sdkCtx, codeHash, types.ProxyRuntimeBytecode)

	// Update proxyAdmin Slot with the proxyAdmin owner address (left padded to 32 bytes)
	evmKeeper.SetState(sdkCtx, proxyAddress, types.PROXY_ADMIN_SLOT, common.LeftPadBytes(proxyAdminOwner.Bytes(), 32))

	// Update proxyImplementation Slot with the factory implementation address (left padded to 32 bytes)
	evmKeeper.SetState(sdkCtx, proxyAddress, types.PROXY_IMPLEMENTATION_SLOT, common.LeftPadBytes(factoryImplAddress.Bytes(), 32))
}

func deployProxyAdminContract(ctx context.Context, evmKeeper types.EVMKeeper) {
	sdkCtx := sdk.UnwrapSDKContext(ctx)
	proxyAdminAddress := common.HexToAddress(types.PROXY_ADMIN_ADDRESS_HEX)
	owner := common.HexToAddress(types.PROXY_ADMIN_OWNER_ADDRESS_HEX)

	// Compute the code hash from the runtime bytecode
	codeHash := crypto.Keccak256(types.ProxyAdminRuntimeBytecode)

	// Create the EVM account object
	evmAccount := statedb.Account{
		Nonce:    1,             // to prevent tx nonce=0 conflicts
		Balance:  new(uint256.Int), // zero balance by default
		CodeHash: codeHash,      // link to deployed code
	}

	// Set the EVM account with the proxy admin contract
	err := evmKeeper.SetAccount(sdkCtx, proxyAdminAddress, evmAccount)
	if err != nil {
		panic("failed to set proxy admin contract account: " + err.Error())
	}

	// Store the runtime bytecode linked to the code hash
	evmKeeper.SetCode(sdkCtx, codeHash, types.ProxyAdminRuntimeBytecode)

	// Initialize storage slot 0 (Ownable.owner) with the owner address (left padded to 32 bytes)
	evmKeeper.SetState(sdkCtx, proxyAdminAddress, common.Hash{}, common.LeftPadBytes(owner.Bytes(), 32))
}

func setupFactoryContract(
	t *testing.T,
	app *app.ChainApp,
	ctx sdk.Context,
	factoryABI abi.ABI,
	opts AppSetupOptions,
	accounts TestAccounts,
) error {
	factoryAddr := opts.Addresses.FactoryAddr
	owner := common.BytesToAddress(accounts.DefaultAccount.GetAddress().Bytes())

	// Check initial factory owner
	ownerResult, err := app.EVMKeeper.CallEVM(ctx, factoryABI, owner, factoryAddr, true, nil, "owner")

	// Initialize factory with owner

	require.NoError(t, err)
