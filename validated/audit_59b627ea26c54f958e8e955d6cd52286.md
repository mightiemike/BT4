### Title
Auto-swap slippage protection in gas-abstraction inbound execution is derived from the same manipulable AMM spot price it swaps against, enabling sandwich extraction of bridged funds - (File: `x/uexecutor/keeper/execute_inbound_gas.go`, `x/uexecutor/keeper/evm.go`)

### Summary
When a `TxType_GAS` or `TxType_GAS_AND_PAYLOAD` inbound is finalized by validator quorum, `x/uexecutor` automatically swaps the bridged PRC20 token for native PC via the on-chain Uniswap-V3-style pool referenced by `UniversalCore`, in order to fund the user's gas. The code fetches a "quote" and then applies a 5% slippage bound, but the quote comes from the same pool's instantaneous state that the swap itself executes against, in the same call. This is functionally identical to the reported `get_lp_by_cake` bug class: a slippage check that is computed from the manipulable spot price rather than an independent/TWAP oracle provides no real protection against pool manipulation.

### Finding Description
`ExecuteInboundGas` (and the analogous `gasAndPayloadDepositAutoSwap` for `GAS_AND_PAYLOAD`) resolve the swap parameters like this: [1](#0-0) 

`GetSwapQuote` performs a static call to the QuoterV2 contract, which simulates the swap against the pool's *current* reserves/sqrtPrice: [2](#0-1) 

`minPCOut` is then computed as 95% of that same-block quote, and the real swap (`depositPRC20WithAutoSwap` → `CallPRC20DepositAutoSwap`) is executed immediately after, still within the same keeper call / same block: [3](#0-2) 

The identical pattern is duplicated for `GAS_AND_PAYLOAD` inbounds: [4](#0-3) 

Because both the "expected output" and the actual swap read from the same AMM state, the 5% bound only guards against slippage caused by the swap's *own* price impact — it does nothing to protect against an attacker who has already skewed the pool's price via a preceding trade in the same or an adjacent block. There is no TWAP, external oracle, or governance-set reference price anywhere in this path (confirmed: no `TWAP`/oracle usage exists in `x/uexecutor` or `uregistry` swap-related code).

This execution is not guarded by any privileged trigger: `ExecuteInboundGas`/`ExecuteInboundGasAndPayload` run automatically and synchronously the moment the honest validator quorum finalizes a `MsgVoteInbound` ballot, inside the message handler itself: [5](#0-4) 

An unprivileged external actor who observes the mempool (or simply predicts/races typical bridging cadence) can:
1. Submit a large swap on the same PRC20↔WPC pool to move the spot price adversely just before the quorum-crossing `MsgVoteInbound` transaction lands.
2. Let the gas-abstraction auto-swap execute at the skewed price — `GetSwapQuote` reflects the skew, so the "slippage check" is satisfied trivially.
3. Reverse the initial trade to restore the pool price and capture the value that should have gone to the user's PC balance (or the protocol) from the auto-swap.

### Impact Explanation
This falls under "corruption of ... gas fee accounting ... token mapping ... canonical UniversalTx state" and "stealing ... of user or protocol-controlled funds" in the allowed-impact scope. The bridged PRC20 principal being auto-swapped for gas is user/protocol funds; a sandwich attack against the swap directly siphons value out of that conversion, reducing the PC amount actually credited to the user's UEA versus fair value, with the difference captured by the attacker. This requires no validator, relayer, or admin compromise — it is executable by any address holding funds to trade on the pool.

### Likelihood Explanation
Every GAS or GAS_AND_PAYLOAD inbound triggers this code path automatically and deterministically on quorum finalization, so the attack surface is continuously present for any bridged inbound of meaningful size. The main constraints are pool liquidity depth (larger pools reduce attacker profit margin) and the fixed 5% band (bounds the attacker's maximum extractable slippage per transaction, but does not eliminate it, and can be maximized by repeated attacks against a stream of inbound swaps).

### Recommendation
Compute `minPCOut` from a manipulation-resistant reference (e.g., a time-weighted average price from the pool's `observe()`, or an off-chain oracle price already used elsewhere in the registry), rather than from a same-block spot quote of the pool being swapped against. Alternatively, cap the swap size relative to available on-chain liquidity, or split large gas-abstraction swaps to keep per-transaction price impact economically unattractive to sandwich.

### Proof of Concept
1. Deploy the WPC/PRC20 pool with modest liquidity depth used in test fixtures (as in `test/integration/uexecutor/execute_inbound_gas_test.go`).
2. Attacker submits a large one-sided swap against the pool to move price against the direction the gas-abstraction swap will take.
3. Submit/observe the `MsgVoteInbound` transaction that will cross quorum for a pending `TxType_GAS` inbound of significant `Amount` and ensure it lands after the attacker's price-moving trade (mempool ordering / same block).
4. On finalization, `ExecuteInboundGas` calls `GetSwapQuote` (reflecting the skewed price) then `CallPRC20DepositAutoSwap` with `minPCOut` derived from that skewed quote — the swap executes at the bad price and succeeds because the slippage check compares against itself.
5. Attacker reverses the initial trade, restoring price and net profiting the difference between fair value and the manipulated execution price, at the expense of the bridged funds' expected PC output.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}
