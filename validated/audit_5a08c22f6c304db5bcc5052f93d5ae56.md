## Analysis: Same-block AMM price manipulation of gas-abstraction and gas-refund autoswaps in `x/uexecutor`

The external report's core bug class — manipulating an AMM pool's spot price within a narrow, attacker-controlled window and having a protocol contract execute a swap against that manipulated price with only nominal slippage protection — maps directly onto Push Chain's gas-abstraction ("GAS"/"GAS_AND_PAYLOAD" inbound) and gas-refund flows in `x/uexecutor`.

### Root cause

`k.ExecuteInboundGas` (and the identical pattern in `gasAndPayloadDepositAutoSwap`, and again in `applyGasRefund`) computes its own slippage floor from the *same* spot-price quote it is about to trade against, with no external/TWAP reference price: [1](#0-0) 

`GetSwapQuote` calls `QuoterV2.quoteExactInputSingle` with `SqrtPriceLimitX96 = 0`, i.e. a pure current-pool spot-price quote: [2](#0-1) 

`minPCOut` is then derived as `quote * 95 / 100` and passed straight into `depositPRC20WithAutoSwap`: [3](#0-2) 

The same self-referential pattern (fee-tier fetch → spot quote → 95% floor → swap) repeats in the gas-refund path: [4](#0-3) [5](#0-4) 

Because the "slippage protection" floor is computed from the *manipulated* pool state itself rather than from an independent oracle/TWAP, it only bounds slippage from the swap's own price impact — it provides **no protection against externally manipulated pool price** at the moment of execution.

### Trigger path

This swap fires synchronously and deterministically inside `VoteInbound`, at the moment the finalizing (2/3-quorum) `MsgVoteInbound` transaction lands: [6](#0-5) [7](#0-6) 

Since the WPC↔PRC20 Uniswap-style pool referenced by `UniversalCore` lives on Push Chain's own EVM and is open to any user, an unprivileged attacker can:
1. Submit a large swap against the WPC/PRC20 pool to skew the spot price, timed/fee-bid to land in the same block just before the validator's quorum-finalizing `MsgVoteInbound`.
2. Let the finalizing vote execute `ExecuteInboundGas` — the quote and `minPCOut` are computed from the now-skewed price, so the victim's gas-abstraction deposit (or gas refund) executes at that bad price while still satisfying its own (self-referential) slippage check.
3. Reverse the initial swap in a follow-up transaction in the same block, extracting the price-impact fees/spread as MEV at the expense of the depositor/refund recipient, whose PRC20→WPC conversion silently nets far less native PC than fair value.

This is the direct on-chain analog of the flash-loan/liquidity-manipulation pattern in the report: the vulnerable step is not the liquidity add/remove itself, but a spot-price AMM swap gated only by a self-derived slippage bound, executed atomically as part of consensus-driven finalization that ordinary users can influence via transaction timing/fee-bidding within the same block.

### Title
Self-referential slippage check lets same-block AMM price manipulation drain value from gas-abstraction/gas-refund autoswaps - (File: x/uexecutor/keeper/execute_inbound_gas.go, x/uexecutor/keeper/evm.go, x/uexecutor/keeper/outbound.go)

### Summary
`ExecuteInboundGas`, `gasAndPayloadDepositAutoSwap`, and `applyGasRefund` each fetch a live Uniswap-V3-style spot-price quote (`GetSwapQuote`/`QuoterV2.quoteExactInputSingle`) and use it, with only a flat 5% haircut, as the `minPCOut` floor for the very same swap. Because the floor is derived from the pool's current (attacker-influenceable) state rather than an external oracle/TWAP, an attacker can skew the pool price immediately before the quorum-finalizing `MsgVoteInbound` transaction executes the swap, then unwind the skew afterward in the same block — a sandwich attack that extracts value from the depositor's/refund recipient's PRC20→PC conversion.

### Finding Description
See analysis above — the quote-then-swap sequence in `execute_inbound_gas.go:104-153` and `evm.go:500-593` uses no price protection independent of the manipulated pool, and this logic runs deterministically inside the transaction that finalizes 2/3 quorum on an inbound vote (`msg_vote_inbound.go:148-156`), a moment an unprivileged user can influence by controlling adjacent transactions/fee bidding in the same block.

### Impact Explanation
A successful sandwich causes the module to swap the victim's bridged PRC20 into PC at a manipulated (unfavorable) price, so the recipient UEA/refund recipient receives materially less native PC than fair value; the attacker captures the difference as MEV. This corrupts PRC20/native asset accounting and gas-fee/refund accounting for ordinary users' deposits, falling within the "corruption of ... gas fee accounting, refund accounting ... token mapping" allowed-impact category.

### Likelihood Explanation
Requires the attacker to have capital to move the WPC/PRC20 pool price and favorable transaction ordering within the block containing the quorum-finalizing vote — feasible for any unprivileged actor via fee-bidding/MEV techniques, without requiring validator, relayer, or admin privileges. Depth of pool liquidity determines the capital needed and the extractable value.

### Recommendation
Do not derive the slippage floor from the same live quote used for the swap. Use a manipulation-resistant reference (e.g., TWAP over multiple blocks, or an external price oracle) to bound `minPCOut`/`minPCOut` for refunds, and/or cap per-block price impact / require the swap to revert if the pool price deviates materially from a recent TWAP.

### Proof of Concept
1. Attacker observes a pending inbound GAS deposit about to reach quorum.
2. In the same target block, attacker submits tx A: large swap on the WPC/PRC20 pool to depress PRC20's price relative to WPC.
3. The validator's finalizing `MsgVoteInbound` lands (tx B), triggering `ExecuteInboundGas` → `GetSwapQuote` (reads manipulated price) → `minPCOut = quote*95/100` → `CallPRC20DepositAutoSwap` executes at the bad price, still passing its own slippage check.
4. Attacker submits tx C reversing the initial swap, restoring pool price and pocketing the spread, while the victim's UEA receives less PC than a fair-price swap would have produced.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)
}

// applyGasRefund computes the excess gas (gasFee - gasFeeUsed) and, if positive,
// calls UniversalCore refundUnusedGas. The result is recorded in outbound.PcRefundExecution.
// It is called for both successful and failed outbounds — gas is consumed on the
// external chain regardless of execution outcome.
func (k Keeper) applyGasRefund(ctx sdk.Context, outbound *types.OutboundTx, obs *types.OutboundObservation) {
	if obs.GasFeeUsed == "" || outbound.GasFee == "" || outbound.GasToken == "" {
		return
	}

	gasFee := new(big.Int)
	if _, ok := gasFee.SetString(outbound.GasFee, 10); !ok {
		return
	}

	gasFeeUsed := new(big.Int)
	if _, ok := gasFeeUsed.SetString(obs.GasFeeUsed, 10); !ok {
		return
	}

	// No excess gas to refund
	if gasFee.Cmp(gasFeeUsed) <= 0 {
		return
	}

	refundAmount := new(big.Int).Sub(gasFee, gasFeeUsed)
	gasToken := common.HexToAddress(outbound.GasToken)

	// Refund recipient: prefer fund_recipient in revert_instructions, fall back to sender
	refundRecipient := outbound.Sender
	if outbound.RevertInstructions != nil && outbound.RevertInstructions.FundRecipient != "" {
		refundRecipient = outbound.RevertInstructions.FundRecipient
	}
	recipientAddr := common.HexToAddress(refundRecipient)

	refundPcTx := &types.PCTx{
		Sender:      outbound.Sender,
		BlockHeight: uint64(ctx.BlockHeight()),
	}

	// Step 1: try refund with swap (gasToken → PC native)
	fee, swapErr := k.GetDefaultFeeTierForToken(ctx, gasToken)
	var swapFallbackReason string

	if swapErr == nil {
		quote, quoteErr := k.getSwapQuoteForRefund(ctx, gasToken, fee, refundAmount)
		if quoteErr == nil {
			minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
			minPCOut.Div(minPCOut, big.NewInt(100))

			resp, err := k.CallUniversalCoreRefundUnusedGas(ctx, gasToken, refundAmount, recipientAddr, true, fee, minPCOut)
			if err == nil {
				refundPcTx.TxHash = resp.Hash
				refundPcTx.GasUsed = resp.GasUsed
				refundPcTx.Status = "SUCCESS"
				outbound.PcRefundExecution = refundPcTx
				return
			}
			swapFallbackReason = fmt.Sprintf("swap refund failed: %s", err.Error())
		} else {
			swapFallbackReason = fmt.Sprintf("quote fetch failed: %s", quoteErr.Error())
		}
	} else {
		swapFallbackReason = fmt.Sprintf("fee tier fetch failed: %s", swapErr.Error())
	}
