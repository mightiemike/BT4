### Title
Stale/zero chain-meta gas price is used unchecked for outbound fee accounting, letting an attacker relay outbounds at protocol expense — (File: `x/uexecutor/keeper/gas_fee.go`, `x/uexecutor/keeper/chain_meta.go`)

### Summary
The `PegOracle` bug is about a price consumer that never checks a data-freshness/validity flag before using the value economically. Push Chain has a structurally identical pattern: the `ChainMeta` gas-price oracle written by `VoteChainMeta` exposes a `timestampObservedAtByChainNamespace` freshness getter on the `UniversalCore` contract, but every Go-side consumer of the price — `GetGasPriceByChain`, `GetOutboundTxGasAndFees`, `GetGasFeeInfoForRevertOutbound` — reads `gasPriceByChainNamespace` directly and never calls or checks the observed-at timestamp before using the value to compute the relayer gas fee charged to users.

### Finding Description
`VoteChainMeta` in [1](#0-0)  gates the *first* on-chain write behind `chainMetaMinVotesForFirstWrite` (3) fresh votes, but before that quorum is reached the vote is simply stored and `CallUniversalCoreSetChainMeta` is never invoked [2](#0-1) . Until quorum, or for any chain namespace that has never been voted on at all, `gasPriceByChainNamespace` on `UniversalCore` simply returns its default (zero) value.

`GetGasPriceByChain` and `GetOutboundTxGasAndFees` read this value with a bare `CallEVM` and unpack it with no zero-check and no freshness check: [3](#0-2)  and [4](#0-3) . The ABI does expose a `timestampObservedAtByChainNamespace` getter [5](#0-4) , but a repo-wide search shows it is referenced only in the generated ABI JSON — no keeper code ever calls it or gates fee computation on it.

This is the same class of bug as the PegOracle report: a consumer trusts an oracle-fed value for economically meaningful accounting (`gasFee`, `gasToken`, `gasLimit` for outbounds and their refunds, `applyGasRefund` in [6](#0-5) ) without verifying it is recent or even non-zero, even though the freshness primitive already exists in the contract but is simply not consumed.

### Impact Explanation
`GetOutboundTxGasAndFees`'s `gasFee`/`gasPrice` outputs directly determine how much the protocol charges (via `CallPRC20DepositAutoSwap`/outbound creation) or refunds (`applyGasRefund` → `CallUniversalCoreRefundUnusedGas`) for real gas the module must spend broadcasting a TSS-signed outbound on an external chain. If the value is stale or zero (never voted, chain quorum not yet reached, or votes on a low-traffic chain have gone stale under `chainMetaVoteStalenessSeconds`), the protocol computes and collects an incorrect (including zero) `gasFee` while it still has to pay real gas to the TSS coordinator/relayer to broadcast the outbound — this is a gas-fee/refund accounting corruption reachable by an ordinary unprivileged user who submits an outbound-triggering deposit/payload on a chain whose gas-meta oracle hasn't reached quorum or has gone stale, causing the protocol to subsidize relaying costs it cannot recover from the user.

### Likelihood Explanation
Reaching the zero/stale state does not require any privileged action — it occurs naturally for any newly enabled chain before 3 fresh votes accumulate, or any low-traffic chain whose votes age past 300 seconds (`chainMetaVoteStalenessSeconds`) between transactions. An attacker only needs to target such a chain with an ordinary transaction that produces an outbound to exploit the undercharged/zero fee. However, the concrete monetary loss per exploit is bounded by real relay gas cost and requires the attacker to specifically pick quiet/newly-enabled chains, which somewhat limits scale and makes this more of a systemic accounting gap than a directly draining exploit.

### Recommendation
Before using `gasPriceByChainNamespace`/`gasFee`/`gasPrice` for fee or refund computation, call `timestampObservedAtByChainNamespace` and reject or fall back to a safe default (e.g., a conservative admin-configured floor fee) if `block.timestamp - observedAt` exceeds a defined `chainMetaVoteStalenessSeconds`-aligned bound, and explicitly reject/floor a zero gas price before it is used to size a user-charged fee.

### Proof of Concept
Not independently reproducible from the indexed code alone — this is a design/data-flow analysis based on: (1) `VoteChainMeta`'s bootstrap gate leaving `gasPriceByChainNamespace` at its zero default until quorum [7](#0-6) , and (2) `GetOutboundTxGasAndFees`/`GetGasFeeInfoForRevertOutbound` consuming that value with no freshness or zero check [8](#0-7) . A background Devin session with full repo/toolchain access would be needed to trace `UniversalCore.sol`'s exact `getOutboundTxGasAndFees` implementation and confirm whether it applies its own internal floor/staleness guard that the Go layer doesn't show — this repository index does not include the Solidity source for `UniversalCore`, so that on-chain leg of the invariant could not be fully verified here.

func (k Keeper) VoteChainMeta(ctx context.Context, universalValidator sdk.ValAddress, observedChainId string, price, blockNumber uint64) error {
	sdkCtx := sdk.UnwrapSDKContext(ctx)
	now := uint64(sdkCtx.BlockTime().Unix())

	entry, _, err := k.GetChainMeta(ctx, observedChainId)
	if err != nil {
		return sdkerrors.Wrap(err, "failed to fetch chain meta entry")
	}
	bootstrapped := entry.LastAppliedChainHeight > 0

	// Stale-height check applies only after bootstrap. During cold-start there
	// is no committed reference height yet, so any positive vote is acceptable.
	if bootstrapped && blockNumber <= entry.LastAppliedChainHeight {
		k.Logger().Warn("chain meta vote rejected: stale block height",
			"chain_id", observedChainId,
			"validator", universalValidator.String(),
			"vote_height", blockNumber,
			"last_applied_height", entry.LastAppliedChainHeight,
		)
		return fmt.Errorf(
			"vote chain height %d is not greater than last applied chain height %d; re-vote with a newer block",
			blockNumber, entry.LastAppliedChainHeight,
		)
	}

	// Ensure the entry has its observed-chain id set on first-ever vote.
	if entry.ObservedChainId == "" {
		entry.ObservedChainId = observedChainId
	}

// GetGasPriceByChain reads the gas price for a chain from the UniversalCore contract.
func (k Keeper) GetGasPriceByChain(ctx sdk.Context, chainNamespace string) (*big.Int, error) {
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse UniversalCore ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	receipt, err := k.evmKeeper.CallEVM(ctx, abi, ueModuleAccAddress, handlerAddr, false, nil, "gasPriceByChainNamespace", chainNamespace)
	if err != nil {
		return nil, errors.Wrap(err, "failed to call gasPriceByChainNamespace")
	}

	results, err := abi.Methods["gasPriceByChainNamespace"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack gasPriceByChainNamespace result")
	}

	return results[0].(*big.Int), nil
}

// GetOutboundTxGasAndFees calls UniversalCore.getOutboundTxGasAndFees(prc20, gasLimitWithBaseLimit)
// to get gasToken, gasFee, protocolFee, gasPrice, and chainNamespace.
// Pass gasLimitWithBaseLimit=0 to use the contract's baseLimit.
func (k Keeper) GetOutboundTxGasAndFees(ctx sdk.Context, prc20 common.Address, gasLimitWithBaseLimit *big.Int) (*GasFeeInfo, error) {
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	ucABI, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse UniversalCore ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	receipt, err := k.evmKeeper.CallEVM(ctx, ucABI, ueModuleAccAddress, handlerAddr, false, nil,
		"getOutboundTxGasAndFees", prc20, gasLimitWithBaseLimit)
	if err != nil {
		return nil, errors.Wrap(err, "failed to call getOutboundTxGasAndFees")
	}

	results, err := ucABI.Methods["getOutboundTxGasAndFees"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack getOutboundTxGasAndFees result")
	}

	gasToken := results[0].(common.Address)
	gasFee := results[1].(*big.Int)
	// protocolFee := results[2].(*big.Int) — not needed for outbound fields
	gasPrice := results[3].(*big.Int)
	// chainNamespace := results[4].(string) — not needed for outbound fields
	// gasLimitUsed (results[5]) is the exact gas limit the contract resolved
	// (caller-supplied or per-chain baseGasLimitByChainNamespace fallback).
	// Reading it directly avoids the gasFee/gasPrice round-trip and keeps us
	// in lock-step with the contract's own resolution.
	gasLimit := results[5].(*big.Int)

	return &GasFeeInfo{
		GasToken: gasToken,
		GasFee:   gasFee,
		GasPrice: gasPrice,
		GasLimit: gasLimit,
	}, nil
}

// GetGasFeeInfoForRevertOutbound fetches gas info for an INBOUND_REVERT outbound using the

func (k Keeper) GetGasFeeInfoForRevertOutbound(ctx sdk.Context, prc20Addr string) (gasToken, gasFee, gasPrice, gasLimit string, err error) {
	prc20 := common.HexToAddress(prc20Addr)

// applyGasRefund computes the excess gas (gasFee - gasFeeUsed) and, if positive,
// calls UniversalCore refundUnusedGas. The result is recorded in outbound.PcRefundExecution.
// It is called for both successful and failed outbounds — gas is consumed on the
// external chain regardless of execution outcome.
func (k Keeper) applyGasRefund(ctx sdk.Context, outbound *types.OutboundTx, obs *types.OutboundObservation) {
	if obs.GasFeeUsed == "" || outbound.GasFee == "" || outbound.GasToken == "" {
		return
	}

	gasFee := new(big.Int)
	if _, ok := gasFee.SetString(outbound.GasFee, 10); !ok {
		return
	}

	gasFeeUsed := new(big.Int)
	if _, ok := gasFeeUsed.SetString(obs.GasFeeUsed, 10); !ok {
		return
	}

	// No excess gas to refund
	if gasFee.Cmp(gasFeeUsed) <= 0 {
		return
	}
