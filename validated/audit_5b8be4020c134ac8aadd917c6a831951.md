### Title
Auto-swap deposit and gas-refund paths rely on an unprotected spot QuoterV2 price, enabling sandwich extraction of value from every crosschain deposit/refund - (File: `x/uexecutor/keeper/evm.go`)

### Summary
Every Push Chain auto-swap path (`GAS` inbound deposit, `GAS_AND_PAYLOAD` inbound deposit, and gas-fee refund with swap) computes its slippage bound `minPCOut` from a live, single-block `QuoterV2.quoteExactInputSingle` call and then applies a fixed 5% buffer, mirroring exactly the fix pattern described in the external report (`quote * 95 / 100`). Because the quote is a spot simulation of the current pool state rather than a manipulation-resistant TWAP, and because the quote-fetch and the swap-execution both occur atomically inside the validator vote-finalization transaction, an unprivileged attacker can move the pool price with an ordinary swap immediately before the finalizing vote lands, causing the module's own quote (and therefore its 5%-buffered `minPCOut`) to already reflect the manipulated price. The attacker then reverses the trade, extracting the price impact the protocol's swap incurred, at the expense of the crosschain depositor / refund recipient.

### Finding Description
The three module-driven auto-swap call sites all follow the same pattern: [1](#0-0) 

- `GetDefaultFeeTierForToken` reads the pool fee tier from `UniversalCore` [2](#0-1) 
- `GetSwapQuote` calls `QuoterV2.quoteExactInputSingle` with `commit=false`, i.e. a spot simulation against the pool's current reserves, with no TWAP/observation-window protection [3](#0-2) 
- `minPCOut` is derived purely as `quote * 95 / 100` [4](#0-3) 
- `CallPRC20DepositAutoSwap` then executes the real swap via `DerivedEVMCall` using that `minPCOut` [5](#0-4) 

The identical `quote`→`minPCOut = quote*95/100`→swap pattern is repeated in `gasAndPayloadDepositAutoSwap` (used for `GAS_AND_PAYLOAD` deposits into UEAs and CEAs) [6](#0-5)  and in `applyGasRefund`'s swap-based gas refund path, which additionally recomputes the pool fee/quote for the gas token before refunding excess relayer gas to the sender or `FundRecipient` [7](#0-6) .

Because the pools referenced (`prc20Address` ↔ `wpcAddress`, i.e. PRC20 collateral to wrapped-PC) are Push Chain's own on-chain Uniswap V3 pools, any unprivileged user can submit an ordinary swap transaction against them. The finalizing `MsgVoteInbound`/`MsgVoteOutbound` transaction that triggers `ExecuteInboundGas`/`ExecuteInboundGasAndPayload`/`applyGasRefund` is publicly visible in the mempool before inclusion, so an attacker can:
1. Front-run it with a large swap that pushes the `prc20`↔`wpc` pool price away from fair value.
2. Let the module's `GetSwapQuote` call (executed moments later, same or adjacent block) return a quote that already reflects the manipulated price, so the module's swap still clears the 5%-buffered `minPCOut` check even though it executes far from the pre-manipulation fair price.
3. Back-run by reversing the original trade, capturing the price impact/slippage that the module's swap paid, funded directly by the value that should have landed in the depositor's UEA (or the gas-refund recipient).

This is the direct native analog of the external report's root cause (`amountOutMinimum`/`minPCOut` computed without accounting for realistic, adversarial slippage) — the fix applied here (fixed 5% buffer over a live quote) is the same "arbitrary buffer" mitigation Standard DAO shipped, and it shares the same residual weakness Cyfrin flagged as "not a perfect solution": it bounds *ordinary* slippage but does nothing to prevent an attacker from moving the reference price itself before the buffer is computed.

### Impact Explanation
Every crosschain deposit that is auto-swapped into PC (GAS, GAS_AND_PAYLOAD to UEA/CEA) and every gas-fee refund that goes through the swap-back leg is exposed to value extraction proportional to the attacker's ability to move the relevant pool within the 5% band (and beyond, since the buffer itself is computed from the already-manipulated price, not from a pre-manipulation reference). This is a direct, repeatable corruption of native/PRC20 asset accounting: depositors' UEAs and gas-refund recipients receive systematically less value than fair execution would produce, while the difference is captured by an unprivileged external actor. Because this executes on every eligible inbound/outbound, it is a scalable "MEV tax" against protocol-controlled swap flows rather than a one-off griefing bug.

### Likelihood Explanation
High for chains/pools with materially attackable liquidity: the trigger is a completely ordinary, permissionless DEX swap plus mempool front-running of an otherwise-public vote-finalization transaction. No validator, relayer, or admin collusion is required — only an unprivileged actor watching the mempool and trading against the same Push Chain-native Uniswap V3 pools the module itself swaps through.

### Recommendation
Do not derive `minPCOut` solely from a spot `QuoterV2` call taken immediately before the swap. Use a TWAP-based or otherwise manipulation-resistant reference price (e.g., a time-weighted observation window, or an oracle-anchored bound) to compute the slippage floor, and/or bound the maximum per-block price deviation the module will tolerate before aborting the swap and falling back to a non-swap deposit path (as already exists for the "fallback — refund without swap" branch in `applyGasRefund`).

### Proof of Concept
1. Identify a Push Chain-native `prc20`↔`wpc` Uniswap V3 pool used by `UniversalCore` for a given PRC20 asset (`defaultFeeTier[prc20]`).
2. Observe the mempool for a `MsgVoteInbound`/`MsgVoteOutbound` transaction that will bring an inbound/outbound to quorum and trigger `ExecuteInboundGas`/`ExecuteInboundGasAndPayload`/`applyGasRefund`.
3. Submit a swap transaction that lands just before the finalizing vote transaction, moving the pool price against the direction the module will trade (e.g., pre-buying `wpc` with `prc20` to push `wpc` price up before the module tries to buy `wpc` with the user's deposited `prc20`).
4. The module's `GetSwapQuote` call, executed after the attacker's trade lands, returns a quote already reflecting the worse price; `minPCOut = quote * 95/100` is computed from this degraded reference and the module's `depositPRC20WithAutoSwap`/`refundUnusedGas` swap still satisfies it.
5. Immediately reverse the original trade, extracting the price impact captured from the module's swap as profit, while the depositor's UEA (or gas-refund recipient) receives less `wpc`/PC than fair execution would have produced.

// GetDefaultFeeTierForToken reads defaultFeeTier[prc20] from UniversalCore.
func (k Keeper) GetDefaultFeeTierForToken(ctx sdk.Context, prc20Address common.Address) (*big.Int, error) {
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse UniversalCore ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	receipt, err := k.evmKeeper.CallEVM(ctx, abi, ueModuleAccAddress, handlerAddr, false, nil, "defaultFeeTier", prc20Address)
	if err != nil {
		return nil, errors.Wrap(err, "failed to call defaultFeeTier")
	}

	results, err := abi.Methods["defaultFeeTier"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack defaultFeeTier result")
	}

	// go-ethereum unpacks uint24 as *big.Int (non-standard widths always map to *big.Int)
	fee, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for defaultFeeTier: %T", results[0])
	}

	return fee, nil

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
