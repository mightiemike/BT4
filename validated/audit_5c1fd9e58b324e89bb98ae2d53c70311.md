Confirmed: `signer_coordinator.rs`/`stackerdb_listener.rs` set `weight_threshold` from `NakamotoBlockHeader::compute_voting_weight_threshold` (ceil-based), consistently used for block acceptance/rejection, tenure-extend timestamps, and pre-commit thresholds. This is the same ceil formula used in the actual on-chain `verify_signer_signatures` check. The `GlobalStateEvaluator::reached_agreement`/`reached_disagreement` in `libsigner/src/v0/signer_state.rs` independently reimplement a "70%" threshold using floor division (no ceiling adjustment), which is a separate, weaker threshold than the one used for actual block signature verification.

### Title
Floor-rounded global-state agreement threshold diverges from the ceil-rounded block-signature threshold - (File: libsigner/src/v0/signer_state.rs)

### Summary
`GlobalStateEvaluator::reached_agreement`/`reached_disagreement` compute the 70% signer-weight threshold using plain integer division (floor), while every consensus-critical weight check for actual block acceptance (`NakamotoBlockHeader::compute_voting_weight_threshold`, used in `verify_signer_signatures` and by `SignerCoordinator`/`StackerDBListener`) uses a ceiling-adjusted version of the same formula. For non-round `total_weight` values these two thresholds differ by up to 1 unit of weight, so a vote tally can satisfy the "global agreement" definition while falling below the actual weight required to sign/accept a block.

### Finding Description
`reached_agreement` at [1](#0-0)  computes `total_weight * THRESHOLD / 10` with truncating integer division and requires `vote_weight >= that`. In contrast, the canonical, consensus-enforced threshold used everywhere a block or tenure decision is actually finalized is [2](#0-1) , which explicitly adds a `ceil` correction when the division has a remainder, and is the value assigned to `weight_threshold` in [3](#0-2)  and consumed by block accept/reject logic in [4](#0-3) .

For example, with `total_weight = 13` and `NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD = 7`: `compute_voting_weight_threshold` returns `ceil(91/10) = 10`, but `reached_agreement` accepts any `vote_weight >= floor(91/10) = 9`. A weight of exactly 9 (69.2%) is treated by `GlobalStateEvaluator` as having "reached agreement" on the active signer protocol version, the global burn view, the current miner, or the transaction-replay set (`determine_latest_supported_signer_protocol_version`, `determine_global_burn_view`, `determine_global_state`, `get_global_tx_replay_set` — [5](#0-4) ), even though the same weight would be rejected as insufficient for an actual block signature per `verify_signer_signatures` [6](#0-5) .

This mirrors the reported LOC bug class: two boundary computations of the "same" 70% threshold, one strict/rounded-up and one lax/rounded-down, are used for supposedly-equivalent decisions, letting a minority set of signers (just below the true supermajority) cause the `GlobalStateEvaluator` to certify state (miner identity, burn view, tx replay set) that the rest of the protocol would not consider settled.

### Impact Explanation
Because `determine_global_state`/`get_global_tx_replay_set` feed the transaction-replay-set consensus used by signers when validating/rejecting reorg-related transactions, and `determine_global_burn_view`/current-miner agreement influence which miner signers consider canonical, a minority-triggered premature "agreement" can cause a subset of signers to diverge from others on which miner/tenure/replay-set is authoritative. This can manifest as a temporary tip/verdict disagreement among signers (a node or signer set accepting a miner/tenure state that a strict quorum has not actually endorsed), which fits the "High" category (minority-triggerable static-validation/state divergence, temporary tip disagreement) rather than a full chain split, since the actual block-signature gate (`compute_voting_weight_threshold`) still independently protects on-chain block acceptance.

### Likelihood Explanation
Triggering requires only that `total_weight` not be evenly divisible in a way that produces a truncation gap, and that an attacker or natural distribution of signer weights produces a vote tally in the 1-unit gap between floor and ceil thresholds — no majority or privileged access is needed, only ordinary signer participation just below the true supermajority. This condition is common because signer weights are apportioned by stacked amounts and are frequently non-multiples of 10.

### Recommendation
Make `GlobalStateEvaluator::reached_agreement` (and `reached_disagreement`) use the same ceiling-based `compute_voting_weight_threshold` logic (or call it directly) as `NakamotoBlockHeader`, so that "global agreement" among signers cannot be reached with less weight than would be required to actually approve a block. Add a property/unit test asserting `reached_agreement(w)` is true iff `w >= NakamotoBlockHeader::compute_voting_weight_threshold(total_weight)` for all `total_weight` in a wide range, including values that don't divide evenly by 10.

### Proof of Concept
1. Construct a reward set / `GlobalStateEvaluator` with `total_weight = 13` (e.g., three signers of weight 5, 4, 4).
2. Have signers totaling weight 9 (e.g., 5 + 4) submit `StateMachineUpdate`s agreeing on a given burn view / current miner / protocol version.
3. Call `GlobalStateEvaluator::determine_global_burn_view` / `determine_latest_supported_signer_protocol_version` — both return `Some(..)` because `reached_agreement(9)` evaluates `9 >= floor(13*7/10) = 9` → true.
4. Simultaneously, attempt to have the same 9-weight subset sign an actual Nakamoto block: `NakamotoBlockHeader::compute_voting_weight_threshold(13) = 10`, so `verify_signer_signatures`/`SignerCoordinator` would reject/refuse to treat 9 as sufficient.
5. This demonstrates the same tally (9/13) is simultaneously "agreed" by the global-state evaluator and "insufficient" for on-chain block approval — the equality/boundary mismatch analogous to the reported CCF/LCF issue.

    pub fn determine_latest_supported_signer_protocol_version(&self) -> Option<u64> {
        let mut protocol_versions = HashMap::new();
        for (address, update) in &self.address_updates {
            let Some(weight) = self.address_weights.get(address) else {
                continue;
            };
            let entry = protocol_versions
                .entry(update.local_supported_signer_protocol_version)
                .or_insert_with(|| 0);
            *entry += weight;
        }
        // find the highest version number supported by a threshold number of signers
        let mut protocol_versions: Vec<_> = protocol_versions.into_iter().collect();
        protocol_versions.sort_by_key(|(version, _)| *version);
        let mut total_weight_support: u32 = 0;
        for (version, weight_support) in protocol_versions.into_iter().rev() {
            total_weight_support += weight_support;
            if self.reached_agreement(total_weight_support) {
                return Some(version);
            }
        }
        None
    }

    pub fn determine_global_state(&self) -> Option<SignerStateMachine> {
        let active_signer_protocol_version =
            self.determine_latest_supported_signer_protocol_version()?;
        let mut state_views = HashMap::new();
        let mut tx_replay_sets = HashMap::new();
        let mut found_state_view = None;
        let mut found_replay_set = None;
        for (address, update) in &self.address_updates {
            let Some(weight) = self.address_weights.get(address) else {
                continue;
            };
            let (burn_block, burn_block_height) = update.content.burn_block_view();
            let current_miner = update.content.current_miner();
            let tx_replay_set = update.content.tx_replay_set();

            let state_machine = SignerStateMachine {
                burn_block: burn_block.clone(),
                burn_block_height,
                current_miner: current_miner.clone().into(),
                active_signer_protocol_version,
                // We need to calculate the threshold for the tx_replay_set separately
                tx_replay_set: ReplayTransactionSet::none(),
            };
            let key = SignerStateMachineKey(state_machine.clone());
            let entry = state_views.entry(key).or_insert_with(|| 0);
            *entry += weight;

            if self.reached_agreement(*entry) {
                found_state_view = Some(state_machine);
            }

            let replay_entry = tx_replay_sets
                .entry(tx_replay_set.clone())
                .or_insert_with(|| 0);
            *replay_entry += weight;

            if self.reached_agreement(*replay_entry) {
                found_replay_set = Some(tx_replay_set);
            }
            if found_replay_set.is_some() && found_state_view.is_some() {
                break;
            }
        }
        // Try to find agreed replay set, or find longest common prefix if no exact agreement
        let final_replay_set = if let Some(tx_replay_set) = found_replay_set {
            tx_replay_set
        } else {
            // No exact agreement found, try finding longest common prefix with majority support
            self.find_majority_prefix_replay_set(&tx_replay_sets)
                .unwrap_or_else(ReplayTransactionSet::none)
        };

        if let Some(state_view) = found_state_view.as_mut() {
            state_view.tx_replay_set = final_replay_set;
        }
        found_state_view
    }

    /// Compute the threshold for the minimum number of signers (by weight) required
    /// to approve a Nakamoto block.
    pub fn compute_voting_weight_threshold(total_weight: u32) -> Result<u32, ChainstateError> {
        let threshold = NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD;
        let total_weight = u64::from(total_weight);
        let ceil = if (total_weight * threshold) % 10 == 0 {
            0
        } else {
            1
        };
        u32::try_from((total_weight * threshold) / 10 + ceil).map_err(|_| {
            ChainstateError::InvalidStacksBlock(
                "Overflow when computing nakamoto block approval threshold".to_string(),
            )
        })
    }
