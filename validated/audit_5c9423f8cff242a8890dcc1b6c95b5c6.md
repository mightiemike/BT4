## Answer: Valid vulnerability (in scope)

### Title
Unauthenticated log-source in SVM outbound-observation parser allows forging finalize/revert/rescue observations for a victim's real outbound — (File: `universalClient/chains/svm/event_listener.go`, `universalClient/chains/svm/event_parser.go`)

### Summary
The SVM event listener treats **any** raw `"Program data: "` log line inside a transaction that merely *references* the gateway address as a legitimate gateway event, with no check that the log was actually emitted from within the gateway program's own CPI invocation. Since `outbound_id`/`universal_tx_id` values are deterministic, non-secret, and queryable, an attacker can replay a real victim's IDs inside a forged log from their own program and have every honest Universal Validator's client independently ingest and vote the fabricated observation.

### Finding Description
`processSignatureBatch` fetches transactions only by filtering `GetSignaturesForAddress(gatewayAddr, ...)`, which returns any transaction where the gateway address appears as an account key — including passively-referenced, non-invoked accounts [1](#0-0) . It then iterates over **every** log line in `tx.Meta.LogMessages` and classifies it purely by matching the 8-byte discriminator prefix, with no correlation to which program actually emitted the log (no "Program <id> invoke"/"Program <id> success" boundary tracking) [2](#0-1) .

`determineEventType` and `parseOutboundObservationEvent` only check the `"Program data: "` string prefix and decode the raw bytes; they never verify the log originated from the gateway program's own invocation depth [3](#0-2) [4](#0-3) . The parsed `TxID` (`sub_tx_id`) and `UniversalTxID` are taken verbatim from attacker-controlled bytes at fixed offsets [5](#0-4) .

This event is stored and later fed to `processOutboundEvent`, which builds an `OutboundObservation` and calls `VoteOutbound` to submit `MsgVoteOutbound` on-chain [6](#0-5) . On the chain side, `Keeper.VoteOutbound` only checks that `utxId` resolves to an existing `UniversalTx` and that `outboundId` matches an entry in `utx.OutboundTx` that is still `PENDING` [7](#0-6)  — both `utxId` and deterministic `outboundId` are public/derivable values (queryable via `GetUniversalTx`), not secrets.

Because the parsing bug is **deterministic and shared by all honest validator clients** (every UV runs the identical `universalClient` code), all honest UVs independently observing the same forged Solana transaction will derive the *same* forged observation and each submit a matching `MsgVoteOutbound`. This lets the ballot reach the >2/3 quorum in `VoteOnOutboundBallot`/`VoteOnBallot` honestly, with no validator behaving maliciously [8](#0-7) , flipping the victim's real outbound to `OBSERVED` (fake success, skipping real delivery) or `REVERTED` (triggering the refund/revert path) regardless of what actually happened on the destination chain.

### Impact Explanation
This forges accepted outbound/ballot state through honest validators for a real user's pending outbound, corrupting canonical `UniversalTx`/`OutboundTx` state and driving the wrong finalization/refund branch (`FinalizeOutbound`) — matching the in-scope impact "forged... outbound... state accepted through user-reachable flows with honest validators and honest nodes" and "corruption of ... revert destination ... or canonical UniversalTx state." Depending on which branch fires, this can cause incorrect fund release accounting, double-refund exposure, or a legitimate outbound being wrongly marked observed while never actually delivered — i.e., real fund-loss/mis-accounting for the victim.

### Likelihood Explanation
The attacker needs only: (1) knowledge of a real pending outbound's `outbound_id`/`utx_id` (publicly queryable), (2) ability to submit an ordinary, unprivileged Solana transaction that references the gateway address as an account and invokes their own program emitting a crafted `"Program data: "` log with a known (computable, non-secret) discriminator. No validator, relayer, or TSS compromise is required — the flaw is purely in unauthenticated log-source trust in `universalClient/chains/svm/event_listener.go`/`event_parser.go`. Cost is a single cheap Solana transaction.

### Recommendation
Bind log parsing to the actual gateway program invocation: track `"Program <id> invoke [depth]"` / `"Program <id> success"` boundaries (or use `tx.Meta.InnerInstructions`/`programIdIndex`) so that only `"Program data: "` lines emitted while execution is inside the gateway program's own call frame are treated as gateway events, rejecting any log line attributable to a different, attacker-controlled program even if it appears in the same transaction.

### Proof of Concept
1. Query a real pending outbound's `utx_id` and `outbound_id` (deterministic, publicly queryable via `GetUniversalTx`).
2. Deploy/use an attacker-controlled Solana program; build a transaction that lists the real gateway program pubkey as a passive account (so it's returned by `GetSignaturesForAddress`) and CPI-invokes the attacker's program.
3. From the attacker's program, call `sol_log_data` to emit `"Program data: " + base64(discriminator_for_finalize_universal_tx || sub_tx_id=victim_outbound_id || universal_tx_id=victim_utx_id || gas_fee || gas_used || ...)`.
4. Every honest `universalClient` SVM listener fetches this transaction, `determineEventType` matches the known discriminator, `parseOutboundObservationEvent` extracts the victim's real IDs, stores an `EventTypeOutbound` event, and `processOutboundEvent` submits `MsgVoteOutbound` referencing the real outbound.
5. Once quorum of honest validators (all fooled identically) is reached, `VoteOutbound` flips the victim's real outbound to `OBSERVED`/`REVERTED` based on attacker-chosen fields, without the destination-chain gateway ever actually emitting that event.

```go
// determineEventType determines the event type based on the log discriminator
func (el *EventListener) determineEventType(log string) string {
	if !strings.HasPrefix(log, "Program data: ") {
		return ""
	}

	eventData := strings.TrimPrefix(log, "Program data: ")
	decoded, err := base64.StdEncoding.DecodeString(eventData)
	if err != nil {
		return ""
	}

	if len(decoded) < 8 {
		return ""
	}

	discriminator := strings.ToLower(hex.EncodeToString(decoded[:8]))

	// Look up event type from discriminator map
	eventType, ok := el.discriminatorToEventType[discriminator]
	if !ok {
		return ""
	}

	return eventType
```

```go
func parseOutboundObservationEvent(log string, signature string, slot uint64, logIndex uint, chainID string, logger zerolog.Logger) *store.Event {
	if !strings.HasPrefix(log, "Program data: ") {
		return nil
	}

	eventData := strings.TrimPrefix(log, "Program data: ")
	decoded, err := base64.StdEncoding.DecodeString(eventData)
	if err != nil {
		return nil
	}

	// Minimum: 8 disc + 32 sub_tx_id + 32 universal_tx_id + 8 gas_fee + 8 gas_used
	// + 8 gas_to_refund + 1 ata_created = 97 bytes.
	if len(decoded) < 97 {
		logger.Warn().
			Int("data_len", len(decoded)).
			Msg("data too short for outboundObservation event; need at least 97 bytes")
		return nil
	}

	// Create EventID in format: signature:LogIndex
	eventID := fmt.Sprintf("%s:%d", signature, logIndex)

	logger.Debug().
		Str("event_id", eventID).
		Str("signature", signature).
		Uint("log_index", logIndex).
		Uint64("slot", slot).
		Msg("processing outboundObservation event")

	// Skip discriminator (8 bytes)
	offset := 8

	// Extract txID (32 bytes)
	txID := "0x" + hex.EncodeToString(decoded[offset:offset+32])
	offset += 32

	// Extract universalTxID (32 bytes)
	universalTxID := "0x" + hex.EncodeToString(decoded[offset:offset+32])
	offset += 32
```

```go
func (k Keeper) VoteOnOutboundBallot(
	ctx context.Context,
	universalValidator sdk.ValAddress,
	utxId string,
	outboundId string,
	observedTx types.OutboundObservation,
) (isFinalized bool,
	isNew bool,
	err error) {
	ballotKey, err := types.GetOutboundBallotKey(utxId, outboundId, observedTx)
	if err != nil {
		return false, false, err
	}

	universalValidatorSet, err := k.uvalidatorKeeper.GetEligibleVoters(ctx)
	if err != nil {
		return false, false, err
	}

	// number of validators
	totalValidators := len(universalValidatorSet)

	// votesNeeded = ceil(2/3 * totalValidators)
	// >2/3 quorum similar to tendermint
	votesNeeded := (types.VotesThresholdNumerator*totalValidators)/types.VotesThresholdDenominator + 1

	k.Logger().Debug("voting on outbound ballot",
		"ballot_key", ballotKey,
		"validator", universalValidator.String(),
		"utx_id", utxId,
		"outbound_id", outboundId,
		"total_validators", totalValidators,
		"votes_needed", votesNeeded,
	)

	// Convert []sdk.ValAddress → []string
	universalValidatorSetStrs := make([]string, len(universalValidatorSet))
	for i, v := range universalValidatorSet {
		universalValidatorSetStrs[i] = v.IdentifyInfo.CoreValidatorAddress
	}

	// Step 2: Call VoteOnBallot for this inbound synthetic
	_, isFinalized, isNew, err = k.uvalidatorKeeper.VoteOnBallot(
		ctx,
		ballotKey,
		uvalidatortypes.BallotObservationType_BALLOT_OBSERVATION_TYPE_OUTBOUND_TX,
		universalValidator.String(),
		uvalidatortypes.VoteResult_VOTE_RESULT_SUCCESS,
		universalValidatorSetStrs,
		int64(votesNeeded),
		int64(types.DefaultExpiryAfterBlocks),
	)
	if err != nil {
		return false, false, err
	}
```
