## Front-running / sandwich attack on the gas-abstraction auto-swap quote — ([File: x/uexecutor/keeper/execute_inbound_gas.go])

### Summary
The `matchOrders()` front-running bug class — an unprivileged actor extracting value from a price computed and consumed atomically inside a single transaction — has a direct analog in Push Chain's gas-abstraction inbound flow. `ExecuteInboundGas` (and the equivalent path in `execute_inbound_gas_and_payload.go` / `applyGasRefund`) fetches a live Uniswap V3 `QuoterV2` quote and immediately swaps against the same pool with only a fixed 5% slippage tolerance, all inside the state transition triggered by the finalizing `MsgVoteInbound` transaction. Because that transaction is visible in the public mempool before being included, any unprivileged external account can sandwich it on the `PRC20↔WPC` pool to force the auto-swap to execute near the worst allowed price.

### Finding Description
When an inbound `GAS` or `GAS_AND_PAYLOAD` tx is finalized, the keeper:
1. Fetches a live quote via `GetSwapQuote` → `QuoterV2.quoteExactInputSingle` [1](#0-0) 
2. Computes `minPCOut = quote * 95 / 100` (a fixed 5% slippage band) [2](#0-1) 
3. Immediately executes the swap via `CallPRC20DepositAutoSwap` against the same on-chain AMM pool [3](#0-2) 

The quote-then-swap sequence happens synchronously inside the EVM execution of a single Cosmos `MsgVoteInbound` transaction — the same transaction that finalizes the ballot and triggers `ExecuteInboundGas`. The chain-meta upgrade note itself documents that this replaced a previous "0-slippage" version specifically to add a 5% band [4](#0-3) . The same pattern (live quote, 5% slippage, immediate swap) is duplicated in `gasAndPayloadDepositAutoSwap` [5](#0-4)  and in the outbound gas-refund path `applyGasRefund`/`getSwapQuoteForRefund` [6](#0-5) .

Because Push Chain uses a standard CometBFT public mempool, the `MsgVoteInbound` transaction that will trigger this swap is visible to any observer before it lands in a block. An unprivileged, non-validator attacker can:
1. Watch the mempool for the quorum-crossing `MsgVoteInbound`/`MsgVoteOutbound` transaction.
2. Submit a front-running trade against the same `PRC20↔WPC` Uniswap V3 pool to push the price against the pending deposit/refund.
3. Let the protocol's auto-swap execute at the now-worse price (still within the 5% band, so it doesn't revert).
4. Submit a back-running trade to restore the price and capture the spread.

This mirrors the reported `matchOrders()` issue exactly: the party who can win the ordering race around a price-sensitive, on-chain-computed value extracts value at the expense of the party whose transaction contains it, and the only cost to the attacker is transaction/swap fees.

### Impact Explanation
This directly falls in scope under "corruption of PRC20 or native asset accounting" and value drain reachable "from ordinary user deposits ... alone," since:
- The victim is any user bridging gas-denominated funds through Push Chain's gas-abstraction inbound path (`TxType_GAS` / `TxType_GAS_AND_PAYLOAD`) or receiving an outbound gas refund.
- Up to 5% of the swapped amount can be systematically extracted per event by any unprivileged actor with capital to move the pool, with no validator or admin collusion required.
- Because this triggers on every gas-abstraction inbound/refund, it is a repeatable value drain rather than a one-off edge case.

### Likelihood Explanation
The trigger condition (an ordinary user submitting a gas-denominated inbound, or a completed outbound needing a gas refund) is part of normal user activity, not privileged. The attack additionally only requires standard DEX/mempool tooling (sandwich bots are commodity infrastructure on EVM chains), and the 5% slippage band is wide enough to make sandwiching profitable on any pool with realistic liquidity depth. The main friction is available liquidity in the specific `PRC20↔WPC` pool and MEV infrastructure targeting Push Chain's mempool specifically — moderate but realistic likelihood.

### Recommendation
- Reduce the fixed slippage tolerance and/or make it a function of trade size versus pool liquidity rather than a static 5%.
- Consider computing the quote and executing the swap through a private/commit-reveal path, or via a TWAP-based price reference instead of a spot-quote-then-swap in the same transaction.
- Consider batching or randomizing execution timing so the swap is not deterministically triggerable/observable by watching a specific validator's `MsgVoteInbound`/`MsgVoteOutbound`.

### Proof of Concept
1. Monitor Push Chain's mempool for a `MsgVoteInbound` that will cross the 2/3+ quorum threshold for a `GAS`/`GAS_AND_PAYLOAD` inbound (the vote tally logic is in `VoteOnInboundBallot`) [7](#0-6) .
2. Front-run with a large swap in the `PRC20↔WPC` Uniswap V3 pool that the `QuoterV2` and `CallPRC20DepositAutoSwap` will use, pushing price unfavorably.
3. Let the quorum-crossing vote land; `ExecuteInboundGas` computes `minPCOut` from the now-worse quote and swaps the user's bridged funds near that price [8](#0-7) .
4. Back-run with the reverse swap to restore price and realize the sandwich profit, extracted from the value that should have gone to the depositing user's UEA.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}

// applyGasRefund computes the excess gas (gasFee - gasFeeUsed) and, if positive,
// calls UniversalCore refundUnusedGas. The result is recorded in outbound.PcRefundExecution.
// It is called for both successful and failed outbounds — gas is consumed on the
// external chain regardless of execution outcome.
func (k Keeper) applyGasRefund(ctx sdk.Context, outbound *types.OutboundTx, obs *types.OutboundObservation) {
	if obs.GasFeeUsed == "" || outbound.GasFee == "" || outbound.GasToken == "" {
		return
	}

	gasFee := new(big.Int)
	if _, ok := gasFee.SetString(outbound.GasFee, 10); !ok {
		return
	}

	gasFeeUsed := new(big.Int)
	if _, ok := gasFeeUsed.SetString(obs.GasFeeUsed, 10); !ok {
		return
	}

	// No excess gas to refund
	if gasFee.Cmp(gasFeeUsed) <= 0 {
		return
	}

	refundAmount := new(big.Int).Sub(gasFee, gasFeeUsed)
	gasToken := common.HexToAddress(outbound.GasToken)

	// Refund recipient: prefer fund_recipient in revert_instructions, fall back to sender
	refundRecipient := outbound.Sender
	if outbound.RevertInstructions != nil && outbound.RevertInstructions.FundRecipient != "" {
		refundRecipient = outbound.RevertInstructions.FundRecipient
	}
	recipientAddr := common.HexToAddress(refundRecipient)

	refundPcTx := &types.PCTx{
		Sender:      outbound.Sender,
		BlockHeight: uint64(ctx.BlockHeight()),
	}

	// Step 1: try refund with swap (gasToken → PC native)
	fee, swapErr := k.GetDefaultFeeTierForToken(ctx, gasToken)
	var swapFallbackReason string

	if swapErr == nil {
		quote, quoteErr := k.getSwapQuoteForRefund(ctx, gasToken, fee, refundAmount)
		if quoteErr == nil {
			minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
			minPCOut.Div(minPCOut, big.NewInt(100))

			resp, err := k.CallUniversalCoreRefundUnusedGas(ctx, gasToken, refundAmount, recipientAddr, true, fee, minPCOut)
			if err == nil {
				refundPcTx.TxHash = resp.Hash
				refundPcTx.GasUsed = resp.GasUsed
				refundPcTx.Status = "SUCCESS"
				outbound.PcRefundExecution = refundPcTx
				return
			}
			swapFallbackReason = fmt.Sprintf("swap refund failed: %s", err.Error())
		} else {
			swapFallbackReason = fmt.Sprintf("quote fetch failed: %s", quoteErr.Error())
		}

func (k Keeper) VoteOnInboundBallot(
	ctx context.Context,
	universalValidator sdk.ValAddress,
	inbound types.Inbound,
) (isFinalized bool,
	isNew bool,
	err error) {
	ballotKey, err := types.GetInboundBallotKey(inbound)
	if err != nil {
		return false, false, err
	}

	universalValidatorSet, err := k.uvalidatorKeeper.GetEligibleVoters(ctx)
	if err != nil {
		return false, false, err
	}

	// number of validators
	totalValidators := len(universalValidatorSet)

	// votesNeeded = ceil(2/3 * totalValidators)
	// >2/3 quorum similar to tendermint
	votesNeeded := (types.VotesThresholdNumerator*totalValidators)/types.VotesThresholdDenominator + 1

	k.Logger().Debug("voting on inbound ballot",
		"ballot_key", ballotKey,
		"validator", universalValidator.String(),
		"total_validators", totalValidators,
		"votes_needed", votesNeeded,
	)

	// Convert []sdk.ValAddress → []string
	universalValidatorSetStrs := make([]string, len(universalValidatorSet))
	for i, v := range universalValidatorSet {
		universalValidatorSetStrs[i] = v.IdentifyInfo.CoreValidatorAddress
	}

	// Step 2: Call VoteOnBallot for this inbound synthetic
	_, isFinalized, isNew, err = k.uvalidatorKeeper.VoteOnBallot(
		ctx,
		ballotKey,
		uvalidatortypes.BallotObservationType_BALLOT_OBSERVATION_TYPE_INBOUND_TX,
		universalValidator.String(),
		uvalidatortypes.VoteResult_VOTE_RESULT_SUCCESS,
		universalValidatorSetStrs,
		int64(votesNeeded),
		int64(types.DefaultExpiryAfterBlocks),
	)
	if err != nil {
		return false, false, err
	}

	if isNew {
		k.Logger().Debug("inbound ballot created", "ballot_key", ballotKey)
	}
	if isFinalized {
		k.Logger().Info("inbound ballot finalized", "ballot_key", ballotKey, "source_chain", inbound.SourceChain)
	}

	return isFinalized, isNew, nil
