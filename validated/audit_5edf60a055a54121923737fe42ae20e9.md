### Title
Unvalidated `GasToken` in outbound creation allows minting/refund of an arbitrary PRC20 during `applyGasRefund` - (File: x/uexecutor/keeper/create_outbound.go, x/uexecutor/keeper/outbound.go)

### Summary
The OtterSec finding is a classic "unchecked account/field cross-reference" bug: a raffle-winner-supplied `liquidity_pool`/`collection_info` was never checked against the value actually stored on the `loan` account, letting the caller redirect settlement to a different, attacker-chosen pool. The closest reachable analog in Push Chain's `x/uexecutor` module is that `OutboundTx.GasToken` — the PRC20 address later used to compute and pay out the unused-gas refund — is taken verbatim from an EVM event log emitted during arbitrary user-triggered payload execution, and is never cross-checked against `x/uregistry`'s canonical token/chain configuration before being used to move value.

### Finding Description
When a `UniversalTxOutbound` event is emitted by the `UNIVERSAL_GATEWAY_PC` system contract (triggered from a user's own UEA/CEA `executeUniversalTx` payload call), `BuildOutboundsFromReceipt` decodes the log and copies the emitted `GasToken` field straight onto the `OutboundTx` record with no validation: [1](#0-0) 

Compare this to the same function's handling of the *bridged* asset, `event.Token`, which **is** validated via `GetTokenConfigByPRC20(ctx, event.ChainId, event.Token)` — confirming the (chain, PRC20) pair is a legitimate registered mapping: [2](#0-1) 

No equivalent check exists for `event.GasToken` / `outbound.GasToken`. The decoded event struct shows `GasToken` is just an arbitrary address parsed out of ABI-encoded log data with no further gate: [3](#0-2) 

This unvalidated `GasToken` value is later consumed directly by `applyGasRefund`, which uses it as the PRC20 to call into the `UniversalCore` system contract's `refundUnusedGas`, moving `refundAmount` of that token to `recipientAddr` (an address also derived from attacker-controllable `RevertInstructions.FundRecipient`/`Sender`): [4](#0-3) 

This mirrors the reported bug class exactly: two related identifiers (`external_asset_addr`/`prc20_asset_addr` vs. `gas_token`) originate from the same untrusted event, but only one of the two is bound back to the registry's source of truth (`uregistry` `TokenConfigs`/`ChainConfigs`). The other (`gas_token`) is trusted implicitly and fed straight into a fund-moving call, exactly as the OtterSec report's `liquidity_pool`/`collection_info` were trusted without a `has_one` check against the `loan` account.

### Impact Explanation
If the `UNIVERSAL_GATEWAY_PC` Solidity contract does not itself strictly bind `gasToken` to the canonical per-chain value returned by `UniversalCore.gasTokenPRC20ByChainNamespace` (a function that exists precisely to provide this canonical mapping — see the ABI in `x/uexecutor/types/abi.go`), then a user-supplied `gasToken` propagates unchecked through Push Chain's keeper into `applyGasRefund`/`CallUniversalCoreRefundUnusedGas`. Because the keeper performs no independent verification against `uregistry`, an attacker could get the protocol to compute a "gas refund" denominated in a PRC20 they do not legitimately hold gas-fee claims to, corrupting `PRC20`/gas-fee accounting and refund accounting on `UniversalTx.OutboundTx` — potentially resulting in unauthorized value transfer/mint via a token they should have no claim over, in violation of the "corruption of PRC20 accounting / refund accounting" and "unauthorized mint" invariants in scope.

### Likelihood Explanation
Likelihood is moderate rather than high: whether this is actually exploitable end-to-end depends on the behavior of the out-of-scope Solidity `UniversalGatewayPC`/`UniversalCore` contracts (i.e., whether they independently constrain `gasToken` before emitting/acting on it). At the Go/keeper layer in scope, however, the omission is concrete and unconditional — `event.GasToken` is trusted with zero registry cross-check, unlike the parallel `event.Token` field which is checked. This is directly reachable by any unprivileged user who can trigger `executeUniversalTx` / outbound-creating payloads (i.e., ordinary `MsgExecutePayload` flow), with no privileged actor required.

### Recommendation
Before storing `event.GasToken` on the `OutboundTx`, validate it against the registry, analogous to the existing `GetTokenConfigByPRC20` check for `event.Token`:
- Add a lookup (e.g., via `uregistryKeeper`, or a new canonical "gas token for chain" query mirroring the `UniversalCore.gasTokenPRC20ByChainNamespace` mapping) confirming `event.GasToken` is the expected/registered gas PRC20 for `event.ChainId`.
- Reject (or fall back to a chain-derived canonical gas token) outbound creation if `event.GasToken` does not match the expected value, the same way `MsgAddChainConfig`/`MsgAddTokenConfig` bind chain and token together as the single source of truth.

### Proof of Concept
1. As any unprivileged user, deploy/own a UEA (via `MsgExecutePayload`) and craft a `UniversalPayload` that calls the `UNIVERSAL_GATEWAY_PC` contract's outbound/withdraw entry point, supplying an attacker-chosen `gasToken` address (any PRC20 the attacker wants) and `revertRecipient`/target of their choosing, alongside legitimate `chainId`/`token`/`amount` values.
2. `BuildOutboundsFromReceipt` (`x/uexecutor/keeper/create_outbound.go:69-91`) decodes the log and creates an `OutboundTx` with `GasToken = event.GasToken` verbatim — no cross-check against `uregistry`.
3. When the outbound is later observed/finalized (`handleSuccessfulOutbound`/`handleFailedOutbound` → `applyGasRefund`, `x/uexecutor/keeper/outbound.go:174-256`), the keeper calls `CallUniversalCoreRefundUnusedGas` using the attacker-supplied `gasToken` and the attacker-controlled recipient address, moving `refundAmount` of that PRC20 — a value never validated to correspond to any legitimate gas-fee collection for that destination chain.

```go
func (k Keeper) applyGasRefund(ctx sdk.Context, outbound *types.OutboundTx, obs *types.OutboundObservation) {
	if obs.GasFeeUsed == "" || outbound.GasFee == "" || outbound.GasToken == "" {
		return
	}

	gasFee := new(big.Int)
	if _, ok := gasFee.SetString(outbound.GasFee, 10); !ok {
		return
	}

	gasFeeUsed := new(big.Int)
	if _, ok := gasFeeUsed.SetString(obs.GasFeeUsed, 10); !ok {
		return
	}

	// No excess gas to refund
	if gasFee.Cmp(gasFeeUsed) <= 0 {
		return
	}

	refundAmount := new(big.Int).Sub(gasFee, gasFeeUsed)
	gasToken := common.HexToAddress(outbound.GasToken)

	// Refund recipient: prefer fund_recipient in revert_instructions, fall back to sender
	refundRecipient := outbound.Sender
	if outbound.RevertInstructions != nil && outbound.RevertInstructions.FundRecipient != "" {
		refundRecipient = outbound.RevertInstructions.FundRecipient
	}
	recipientAddr := common.HexToAddress(refundRecipient)

	refundPcTx := &types.PCTx{
		Sender:      outbound.Sender,
		BlockHeight: uint64(ctx.BlockHeight()),
	}

	// Step 1: try refund with swap (gasToken → PC native)
	fee, swapErr := k.GetDefaultFeeTierForToken(ctx, gasToken)
	var swapFallbackReason string

	if swapErr == nil {
		quote, quoteErr := k.getSwapQuoteForRefund(ctx, gasToken, fee, refundAmount)
		if quoteErr == nil {
			minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
			minPCOut.Div(minPCOut, big.NewInt(100))

			resp, err := k.CallUniversalCoreRefundUnusedGas(ctx, gasToken, refundAmount, recipientAddr, true, fee, minPCOut)
			if err == nil {
				refundPcTx.TxHash = resp.Hash
				refundPcTx.GasUsed = resp.GasUsed
				refundPcTx.Status = "SUCCESS"
				outbound.PcRefundExecution = refundPcTx
				return
			}
			swapFallbackReason = fmt.Sprintf("swap refund failed: %s", err.Error())
		} else {
			swapFallbackReason = fmt.Sprintf("quote fetch failed: %s", quoteErr.Error())
		}
	} else {
		swapFallbackReason = fmt.Sprintf("fee tier fetch failed: %s", swapErr.Error())
	}

	// Step 2: fallback — refund without swap (deposit PRC20 directly to recipient)
	ctx.Logger().Error("applyGasRefund: swap refund failed, falling back to no-swap",
		"outbound_id", outbound.Id,
		"reason", swapFallbackReason,
	)

	resp, err := k.CallUniversalCoreRefundUnusedGas(ctx, gasToken, refundAmount, recipientAddr, false, big.NewInt(0), big.NewInt(0))
	if err != nil {
		refundPcTx.Status = "FAILED"
		refundPcTx.ErrorMsg = err.Error()
	} else {
		refundPcTx.TxHash = resp.Hash
		refundPcTx.GasUsed = resp.GasUsed
		refundPcTx.Status = "SUCCESS"
	}

	outbound.PcRefundExecution = refundPcTx
	outbound.RefundSwapError = swapFallbackReason
```
