### Title
`MsgMigrateUEA` performs real EVM execution via `CallUEAMigrateUEA` but never charges gas fees, unlike the sibling `ExecutePayload` flow - (File: `x/uexecutor/keeper/msg_migrate_uea.go`)

### Summary
`ExecutePayload` (via `ExecutePayloadV2`) wraps its EVM call and `DeductGasFeesFromReceipt` in a shared `CacheContext` so that EVM execution and gas-fee collection commit or revert atomically — explicitly closing what the code calls the "free-execution gap." `MigrateUEA`, which is structurally identical (gasless Cosmos message, triggers a real `DerivedEVMCall` against a UEA), has no equivalent fee-deduction step at all.

### Finding Description
`ExecutePayloadV2` deliberately couples EVM execution with fee collection: [1](#0-0) 

`DeductGasFeesFromReceipt` computes real gas cost from a `UniversalPayload`'s `MaxFeePerGas`/`MaxPriorityFeePerGas`/`GasLimit` and burns it from the target account's balance: [2](#0-1) 

`MsgMigrateUEA` is gasless at the Cosmos ante level exactly like `MsgExecutePayload`: [3](#0-2) 

But its keeper handler, `MigrateUEA`, calls `CallUEAMigrateUEA` (a real, committed `DerivedEVMCall`) and returns without ever calling `DeductGasFeesFromReceipt` or any other fee-accounting function: [4](#0-3) [5](#0-4) 

`MigrationPayload` doesn't even carry `MaxFeePerGas`/`GasLimit` fields the way `UniversalPayload` does, so there's no natural way to bill this call the way `ExecutePayload` is billed — the mechanism simply wasn't built for this entry point, unlike `Pools.removeLiquidity()` where IL protection exists in one caller (`Router`) but not the underlying function itself.

### Impact Explanation
Any unprivileged external account can submit `MsgMigrateUEA` for free (gasless at the Cosmos layer) targeting arbitrary `UniversalAccountId`s. Each submission causes the module to perform a real, committed EVM call (`CallFactoryToGetUEAAddressForOrigin` + `CallUEAMigrateUEA`) with no gas-cost recovery from anyone — even calls that ultimately revert inside the UEA contract (invalid signature) still consume real EVM computation up to the revert point. Because `MigrateUEA` never bills the target UEA (or anyone) for this, it is a real resource-consumption/DoS vector reachable without any privileged access, distinct from network-level spam, and it corrupts the intended gas-fee accounting invariant that the rest of the module (`ExecutePayloadV2`, `ExecuteInboundGasAndPayload`) enforces consistently.

### Likelihood Explanation
High. `MsgMigrateUEA` requires no special permission, no stake, and no Cosmos-level fee (it's in the `GaslessMsgTypes` allowlist). An attacker only needs to construct syntactically valid `UniversalAccountId` + `MigrationPayload` + junk `Signature` values (`ValidateBasic` only checks non-emptiness, not correctness) to trigger repeated, uncompensated EVM execution.

### Recommendation
Wrap `CallUEAMigrateUEA` in the same `CacheContext` + `DeductGasFeesFromReceipt`-style pattern used by `ExecutePayloadV2`, or otherwise rate-limit/charge for `MsgMigrateUEA` at the ante or keeper level so that EVM execution triggered by this gasless message is billed like every other derived call, closing the free-execution gap for this handler as it was closed for `ExecutePayload`.

### Proof of Concept
1. Craft `MsgMigrateUEA{Signer: attackerAddr, UniversalAccountId: <any valid CAIP-2 owner>, MigrationPayload: {Migration: <any address>, Nonce: "0", Deadline: "0"}, Signature: "0xdead"}`.
2. Submit repeatedly; since the message type is in `GaslessMsgTypes`, the Cosmos ante pipeline skips fee deduction (`app/ante/fee.go`) entirely.
3. Each submission reaches `msgServer.MigrateUEA` → `Keeper.MigrateUEA` → `CallUEAMigrateUEA` → `DerivedEVMCall(commit=true, gasless=false, isModuleSender=false)`, executing real EVM work on-chain.
4. The call reverts inside the UEA's signature check (per the README's authorization model), but `MigrateUEA` returns the error without ever invoking `DeductGasFeesFromReceipt` — no fee is billed to anyone regardless of outcome, unlike the parallel `ExecutePayload` path.

// DeductGasFeesFromReceipt calculates and deducts gas fees from a recipient address
// based on the EVM receipt and universal payload parameters.
// Returns nil if receipt is nil (Go-level error, no EVM tx was created).
// Returns error with gas details if deduction fails (insufficient balance, etc).
func (k Keeper) DeductGasFeesFromReceipt(
	ctx context.Context,
	sdkCtx sdk.Context,
	recipient common.Address,
	receipt *evmtypes.MsgEthereumTxResponse,
	universalPayload *types.UniversalPayload,
) error {
	if receipt == nil || receipt.GasUsed == 0 {
		return nil
	}
	if universalPayload == nil {
		return nil
	}

	abiPayload, err := types.NewAbiUniversalPayload(universalPayload)
	if err != nil {
		return fmt.Errorf("failed to parse payload for gas deduction: %w", err)
	}

	baseFee := k.feemarketKeeper.GetBaseFee(sdkCtx)
	if baseFee.IsNil() {
		return fmt.Errorf("base fee not found")
	}

	gasCost, err := k.CalculateGasCost(baseFee, abiPayload.MaxFeePerGas, abiPayload.MaxPriorityFeePerGas, receipt.GasUsed)
	if err != nil {
		return fmt.Errorf("failed to calculate gas cost: %w", err)
	}
	if gasCost.Sign() <= 0 {
		return nil
	}

	gasUsedBig := new(big.Int).SetUint64(receipt.GasUsed)
	if gasUsedBig.Cmp(abiPayload.GasLimit) > 0 {
		return fmt.Errorf("gas used (%d) exceeds gas limit (%s)", receipt.GasUsed, abiPayload.GasLimit.String())
	}

	recipientAccAddr := sdk.AccAddress(recipient.Bytes())
	balance := k.bankKeeper.GetBalance(sdkCtx, recipientAccAddr, pchaintypes.BaseDenom)

	if err := k.DeductAndBurnFees(ctx, recipientAccAddr, gasCost); err != nil {
		return fmt.Errorf("insufficient gas: required %s upc, available %s upc, gas_used %d, from %s: %w",
			gasCost.String(), balance.Amount.String(), receipt.GasUsed, recipient.Hex(), err)
	}

// CallUEAMigrateUEA migrates UEA through existing UEA
func (k Keeper) CallUEAMigrateUEA(
	ctx sdk.Context,
	from, ueaAddr common.Address,
	migration_payload *types.MigrationPayload,
	signature []byte,
) (*evmtypes.MsgEthereumTxResponse, error) {
	abi, err := types.ParseUeaABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse UEA ABI")
	}

	abiMigrationPayload, err := types.NewAbiMigrationPayload(migration_payload)
	if err != nil {
		return nil, errors.Wrapf(err, "failed to create universal payload")
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		from,
		ueaAddr,
		big.NewInt(0),
		nil,
		true,  // commit = true (real tx, not simulation)
		false, // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		false, // not a module sender
		nil,
		"migrateUEA",
		abiMigrationPayload,
		signature,
	)
}
