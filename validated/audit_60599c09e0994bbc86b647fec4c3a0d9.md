### Title
Self-referential spot-price slippage check in `GetSwapQuote`/`gasAndPayloadDepositAutoSwap` enables sandwich theft of user PRC20→PC deposit-swap proceeds - (File: `x/uexecutor/keeper/evm.go`, `x/uexecutor/keeper/execute_inbound_gas.go`, `x/uexecutor/keeper/execute_inbound_gas_and_payload.go`)

### Summary
Push Chain's inbound gas/payload processing pipeline auto-swaps a user's deposited PRC20 for PC via a Uniswap V3-style pool, computing a `minPCOut` slippage floor from a spot-price quote fetched immediately before the swap executes. Because the quote itself comes from the manipulable pool spot price rather than a TWAP/oracle, this "slippage protection" is self-referential: an attacker can move the pool price before the module's swap executes, causing the quote (and therefore `minPCOut`) to be computed off the already-skewed price, and then reverse the manipulation afterward — a classic sandwich attack, functionally identical to the reported Balancer `batchSwap()` infinite-limits bug, except here the guard exists on paper but is computed from attacker-influenced state instead of a bounded/oracle reference.

### Finding Description
In `GetSwapQuote`, the expected output amount is fetched via a live call to `QuoterV2.quoteExactInputSingle` against the current pool state: [1](#0-0) 

This spot quote is then used to derive the "slippage-protected" minimum via a flat 5% band computed from the same manipulable value, both in the gas-only inbound path and the gas+payload inbound path: [2](#0-1) [3](#0-2) 

The computed `minPCOut` is then passed straight into the actual on-chain swap execution via `CallPRC20DepositAutoSwap`: [4](#0-3) 

The same pattern is used again for gas refunds with `withSwap=true` in `CallUniversalCoreRefundUnusedGas`, where `minPCOut` is likewise pre-computed by the caller from a spot quote: [5](#0-4) 

Because the reference price (`quote`) and the enforced floor (`minPCOut = quote * 95 / 100`) are both derived from the pool's current spot price at the moment the module's read-only `CallEVM` runs, an attacker who can shift that pool's spot price in a block adjacent to (or the same block as) the module's swap execution can force the actual swap to clear near the manipulated price while still satisfying the module's own 5%-band check — since the check was calculated *from* the manipulated price, not an independent, time-weighted, or otherwise attacker-resistant reference.

### Impact Explanation
An unprivileged attacker holding capital to move the relevant Uniswap V3 pool can extract most of the value difference between the true market price and the artificially depressed swap-execution price on every PRC20→PC deposit-autoswap and swap-based gas refund. This directly reduces user PRC20 deposit proceeds (funds landing in the recipient's UEA as PC) and/or gas-refund proceeds, matching the "unauthorized ... loss of user or protocol-controlled funds" and "corruption of ... gas fee accounting, refund accounting" impact categories in scope. Because the deposit-autoswap path executes automatically as part of ordinary inbound processing (no privileged actor involved), any user depositing funds through the normal gas/payload inbound flow is exposed.

### Likelihood Explanation
The attack requires no validator, relayer, or admin collusion — only capital to manipulate the underlying liquidity pool's spot price around the time the module's deterministic swap executes, and awareness of the target inbound (which is observable on-chain once votes accumulate, before finalization completes). The 5% band is a large enough corridor that even modest price manipulation nets significant profit, and since the floor is computed from the same-block/near-block spot price rather than an oracle or TWAP, the manipulation directly defeats the intended protection rather than merely making it tighter or looser.

### Recommendation
Replace the spot-price-derived `minPCOut` calculation with a manipulation-resistant reference: use a time-weighted average price (TWAP) from the pool (e.g., Uniswap V3 `observe`), an external oracle, or a chain-registry-configured reference price, and bound acceptable slippage relative to that independent reference rather than to a quote taken from the same manipulable pool immediately before the swap. Alternatively, cap the maximum allowed single-block price deviation used for quoting, and/or require the quote to be sourced from a block prior to the one in which the swap executes, so an attacker cannot cheaply co-locate manipulation and execution in the same window.

### Proof of Concept
1. Attacker observes a pending inbound (PRC20 deposit) heading toward `ExecuteInboundGas`/`ExecuteInboundGasAndPayload`.
2. Immediately before the block in which Push Chain validators finalize/execute the inbound's auto-swap, attacker submits a large swap on the underlying PRC20/WPC pool that Push Chain's `QuoterV2` reads from, depressing the PRC20→WPC price.
3. The module calls `GetSwapQuote` (`x/uexecutor/keeper/evm.go:502-538`), which returns the now-depressed spot quote; `minPCOut` is computed as `quote * 95 / 100` on top of that depressed value (`execute_inbound_gas.go:142-146`).
4. `CallPRC20DepositAutoSwap` executes at the manipulated price, still satisfying its own `minPCOut` check because that check was derived from the same manipulated price.
5. Attacker reverses their initial swap to restore the pool price, pocketing the spread — the user's UEA receives materially less PC than it should have for the deposited PRC20 amount.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)

// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}
