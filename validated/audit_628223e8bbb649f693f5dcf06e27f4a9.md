### Title
Unbounded witness creation can DoS the consensus maintenance cycle on every full node - ([File: consensus/src/main/java/org/tron/consensus/dpos/MaintenanceManager.java])

### Summary
Any account can permissionlessly create a new witness via `WitnessCreateActuator` by paying a fixed `AccountUpgradeCost` fee, with no protocol-level cap on the total number of witnesses that can exist. Every full node, on every maintenance cycle (roughly every 6 hours, per block processing when `nextMaintenanceTime <= blockTime`), calls `MaintenanceManager.doMaintenance()`, which unconditionally iterates the *entire* witness set (not just the active/top set) multiple times via `consensusDelegate.getAllWitnesses()`. This mirrors the reported Alchemix `Voter#createGauge`/`Voter#distribute` bug class: an attacker pays once to add an entry to an unbounded, user-growable list, and that list is later iterated in full by a critical, non-skippable system function — except here the affected function is executed by every consensus node on every block crossing a maintenance boundary, rather than only by users who choose to call `distribute`.

### Finding Description
`WitnessCreateActuator.validate()`/`execute()` place no limit on the number of witnesses that can be created — the only checks are address validity, URL validity, witness not already existing, and sufficient balance for a fixed fee (`dynamicStore.getAccountUpgradeCost()`): [1](#0-0) 
The fee is fixed and paid to the black hole / burned, not scaled with the current number of witnesses, so the cost of adding the N-th witness is identical to adding the first: [2](#0-1) 

`WitnessStore.getAllWitnesses()` returns *every* witness ever created, with no bound: [3](#0-2) 

`MaintenanceManager.doMaintenance()`, invoked from `applyBlock()` on every full node whenever a maintenance boundary is crossed during normal block processing, iterates this same unbounded, full witness list multiple times per cycle: [4](#0-3) [5](#0-4) 

Specifically:
- `consensusDelegate.getAllWitnesses().forEach(...)` for `delegationStore.accumulateWitnessVi(...)` when `useNewRewardAlgorithm()` is enabled.
- `consensusDelegate.getAllWitnesses().forEach(witnessCapsule -> newWitnessAddressList.add(...))`.
- `consensusDelegate.getAllWitnesses().forEach(...)` again for `delegationStore.setBrokerage`/`setWitnessVote` when `allowChangeDelegation()` is enabled.

Unlike the reported Alchemix bug — where only users who *chose* to call `distribute()` were affected — this iteration is unconditional and executed by **every full node** as part of ordinary block/maintenance processing, since it is driven directly from `applyBlock()`, which runs for every incoming block. There is no equivalent to `killGauge`/removal semantics that shrinks this set; a witness, once created, remains in `WitnessStore` (there is no witness deletion actuator in this codebase, mirroring the report's observation that gauges cannot be removed once created).

### Impact Explanation
If an attacker (or attackers) repeatedly submits `WitnessCreateContract` transactions, each paying the fixed `AccountUpgradeCost`, they can grow `WitnessStore` arbitrarily. Because `doMaintenance()` performs multiple full-list iterations (including calls into `DelegationStore` and `AccountStore`/`WitnessStore` for every entry) on every maintenance cycle, and this work is mandatory on every full node (including SR nodes producing/validating blocks), an attacker can inflate per-maintenance-cycle CPU/DB-I/O cost network-wide. In the worst case this could push per-cycle processing time high enough to interfere with timely block production/validation, i.e. a DoS against the protocol's consensus/maintenance implementation rather than a single user's own transaction — a stronger blast radius than the original report's per-user freezing of funds, since it is not confined to the caller of a single function but affects block processing for the whole network.

### Likelihood Explanation
The cost is bounded by `AccountUpgradeCost` (a fixed, committee-configurable amount, not increasing with witness count), so the total capital required scales linearly with the number of witnesses added, same as in the original report's gauge-creation DoS. Given real economic cost is required per witness (unlike the reported bug's free `createGauge`), the practical likelihood of an attacker fully weaponizing this to visibly degrade consensus timing is lower and depends on the currently configured `AccountUpgradeCost`, current witness count, and how expensive the added iterations (`delegationStore.accumulateWitnessVi`/`setBrokerage`/`setWitnessVote`) are per entry, which was not directly benchmarked here. This is an architectural weakness (no cap on unbounded, permissionless list growth iterated in a consensus-critical hot path) rather than a proven, quantified breakage point, since I did not measure exact gas/DB-I/O cost per witness within this codebase.

### Recommendation
- Introduce an explicit cap on the total number of witnesses that can be created (e.g., enforce a maximum witness count in `WitnessCreateActuator.validate()`), or
- Scale the `AccountUpgradeCost` fee upward as the total witness count grows, and/or
- Refactor `MaintenanceManager.doMaintenance()` to only operate over the active/standby witness set (bounded by `WITNESS_STANDBY_LENGTH`, as already used in `WitnessStore.getWitnessStandby`) rather than the full unbounded `getAllWitnesses()` list wherever functionally possible.

### Proof of Concept
No PoC was executed against the live codebase; this analysis is based on static review of the code paths above. A conceptual PoC would:
1. Fund N accounts, each with balance ≥ `DynamicPropertiesStore.getAccountUpgradeCost()`.
2. Submit N `WitnessCreateContract` transactions (one per funded account) to grow `WitnessStore` from the current committee-configured witness count to a very large N.
3. Measure the wall-clock time of `MaintenanceManager.doMaintenance()` (or the surrounding `applyBlock()` call) at the next maintenance boundary before and after the witness-count increase, to quantify the added per-cycle overhead as a function of N, analogous to the gas-scaling measurement in the original report.

  private void createWitness(final WitnessCreateContract witnessCreateContract)
      throws BalanceInsufficientException {
    AccountStore accountStore = chainBaseManager.getAccountStore();
    DynamicPropertiesStore dynamicStore = chainBaseManager.getDynamicPropertiesStore();
    WitnessStore witnessStore = chainBaseManager.getWitnessStore();
    //Create Witness by witnessCreateContract
    final WitnessCapsule witnessCapsule = new WitnessCapsule(
        witnessCreateContract.getOwnerAddress(),
        0,
        witnessCreateContract.getUrl().toStringUtf8());

    logger.debug("createWitness,address[{}]", witnessCapsule.createReadableString());
    witnessStore.put(witnessCapsule.createDbKey(), witnessCapsule);
    AccountCapsule accountCapsule = accountStore
        .get(witnessCapsule.createDbKey());
    accountCapsule.setIsWitness(true);
    if (dynamicStore.getAllowMultiSign() == 1) {
      accountCapsule.setDefaultWitnessPermission(dynamicStore);
    }
    accountStore.put(accountCapsule.createDbKey(), accountCapsule);
    long cost = dynamicStore.getAccountUpgradeCost();
    adjustBalance(accountStore, witnessCreateContract.getOwnerAddress().toByteArray(), -cost);
    if (dynamicStore.supportBlackHoleOptimization()) {
      dynamicStore.burnTrx(cost);
    } else {
      adjustBalance(accountStore, accountStore.getBlackhole(), +cost);
    }
    dynamicStore.addTotalCreateWitnessCost(cost);
  }

  public void applyBlock(BlockCapsule blockCapsule) {
    long blockNum = blockCapsule.getNum();
    long blockTime = blockCapsule.getTimeStamp();
    long nextMaintenanceTime = consensusDelegate.getNextMaintenanceTime();
    boolean flag = consensusDelegate.getNextMaintenanceTime() <= blockTime;
    if (flag) {
      if (blockNum != 1) {
        updateWitnessValue(beforeWitness);
        beforeMaintenanceTime = nextMaintenanceTime;
        doMaintenance();
        updateWitnessValue(currentWitness);
      }
      consensusDelegate.updateNextMaintenanceTime(blockTime);
      if (blockNum != 1) {
        //pbft sr msg
        pbftManager.srPrePrepare(blockCapsule, currentWitness,
            consensusDelegate.getNextMaintenanceTime());
      }
    }
    consensusDelegate.saveStateFlag(flag ? 1 : 0);
    //pbft block msg
    if (blockNum == 1) {
      nextMaintenanceTime = consensusDelegate.getNextMaintenanceTime();
    }
    pbftManager.blockPrePrepare(blockCapsule, nextMaintenanceTime);
  }

  public void doMaintenance() {
    VotesStore votesStore = consensusDelegate.getVotesStore();

    tryRemoveThePowerOfTheGr();

    DynamicPropertiesStore dynamicPropertiesStore = consensusDelegate.getDynamicPropertiesStore();
    DelegationStore delegationStore = consensusDelegate.getDelegationStore();
    if (dynamicPropertiesStore.useNewRewardAlgorithm()) {
      long curCycle = dynamicPropertiesStore.getCurrentCycleNumber();
      consensusDelegate.getAllWitnesses().forEach(witness -> {
        delegationStore.accumulateWitnessVi(curCycle, witness.createDbKey(), witness.getVoteCount());
      });
    }

    Map<ByteString, Long> countWitness = countVote(votesStore);
    if (!countWitness.isEmpty()) {
      List<ByteString> currentWits = consensusDelegate.getActiveWitnesses();

      List<ByteString> newWitnessAddressList = new ArrayList<>();
      consensusDelegate.getAllWitnesses()
          .forEach(witnessCapsule -> newWitnessAddressList.add(witnessCapsule.getAddress()));

      countWitness.forEach((address, voteCount) -> {
        byte[] witnessAddress = address.toByteArray();
        WitnessCapsule witnessCapsule = consensusDelegate.getWitness(witnessAddress);
        if (witnessCapsule == null) {
          logger.warn("Witness capsule is null. address is {}", Hex.toHexString(witnessAddress));
          return;
        }
        AccountCapsule account = consensusDelegate.getAccount(witnessAddress);
        if (account == null) {
          logger.warn("Witness account is null. address is {}", Hex.toHexString(witnessAddress));
          return;
        }
        witnessCapsule.setVoteCount(witnessCapsule.getVoteCount() + voteCount);
        consensusDelegate.saveWitness(witnessCapsule);
        logger.info("address is {} , countVote is {}", witnessCapsule.createReadableString(),
            witnessCapsule.getVoteCount());
      });

      dposService.updateWitness(newWitnessAddressList);

      incentiveManager.reward(newWitnessAddressList);

      List<ByteString> newWits = consensusDelegate.getActiveWitnesses();
      if (!CollectionUtils.isEqualCollection(currentWits, newWits)) {
        currentWits.forEach(address -> {
          WitnessCapsule witnessCapsule = consensusDelegate.getWitness(address.toByteArray());
          witnessCapsule.setIsJobs(false);
          consensusDelegate.saveWitness(witnessCapsule);
        });
        newWits.forEach(address -> {
          WitnessCapsule witnessCapsule = consensusDelegate.getWitness(address.toByteArray());
          witnessCapsule.setIsJobs(true);
          consensusDelegate.saveWitness(witnessCapsule);
        });

        SRMetrics.recordSrSetChange(currentWits, newWits);
      }

      logger.info("Update witness success. \nbefore: {} \nafter: {}",
          getAddressStringList(currentWits),
          getAddressStringList(newWits));
    }

    if (dynamicPropertiesStore.allowChangeDelegation()) {
      long nextCycle = dynamicPropertiesStore.getCurrentCycleNumber() + 1;
      dynamicPropertiesStore.saveCurrentCycleNumber(nextCycle);
      consensusDelegate.getAllWitnesses().forEach(witness -> {
        delegationStore.setBrokerage(nextCycle, witness.createDbKey(),
            delegationStore.getBrokerage(witness.createDbKey()));
        delegationStore.setWitnessVote(nextCycle, witness.createDbKey(), witness.getVoteCount());
      });
    }
  }
