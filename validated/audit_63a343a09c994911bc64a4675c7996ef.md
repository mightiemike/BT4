## Analysis: AMM spot-price manipulation of protocol-executed auto-swap (`GetSwapQuote` / `CallPRC20DepositAutoSwap`)

The Sherlock H-3 bug is fundamentally about a manipulable, single-block-computed exchange rate that a *protocol-executed* action (later depositors' shares) is priced against, letting an attacker skew that rate before the victim's action lands. The closest analog in Push Chain is the on-chain Uniswap V3 spot quote used to protect module-initiated `depositPRC20WithAutoSwap` calls in `x/uexecutor`.

### Title
Module-executed PRC20→PC auto-swap is priced from a manipulable single-block AMM spot quote, letting an attacker sandwich depositors' funds - (File: `x/uexecutor/keeper/evm.go`)

### Summary
`GetSwapQuote` reads `QuoterV2.quoteExactInputSingle` at the moment the core validator executes a `GAS` / `GAS_AND_PAYLOAD` inbound, and the result is used to derive `minPCOut` with a fixed 5% slippage tolerance, which is then passed to `CallPRC20DepositAutoSwap` [1](#0-0) . This mirrors the H-3 pattern: a value used to protect a user-affecting operation is derived from live, attacker-influenceable pool state rather than from a manipulation-resistant source (e.g., a TWAP or a user-supplied minimum).

### Finding Description
`ExecuteInboundGas` and `gasAndPayloadDepositAutoSwap` compute `minPCOut` as `quote * 95 / 100` where `quote` comes directly from `GetSwapQuote`, a plain (non-committing) `CallEVM` call to the Uniswap V3 `QuoterV2.quoteExactInputSingle` [2](#0-1) [3](#0-2) . This quote reflects the pool's instantaneous reserves/price at the exact block in which the core validator executes the inbound. Because inbound execution timing is deterministic and observable (it happens right after the inbound ballot finalizes, itself driven by publicly-visible validator votes), an unprivileged actor who also controls a counter-trade in the PRC20/WPC Uniswap V3 pool can push the spot price down immediately before the module's auto-swap executes, then trade back afterward — a classic sandwich against the module's own transaction. The 5% slippage band is fixed and server-computed rather than being a manipulation-resistant TWAP or a value chosen by the depositor, so an attacker only needs to move the pool price by slightly more than 5% for one block to capture the difference at the depositor's expense. The same computation pattern also protects `applyGasRefund`'s excess-gas swap-back leg [4](#0-3) , so both deposit-time and refund-time swaps are exposed to the same class of manipulation.

### Impact Explanation
The depositor (an ordinary crosschain user bridging GAS or GAS_AND_PAYLOAD inbounds) never chooses their own slippage; the protocol swaps on their behalf using a value that can be manipulated within the attacker's control. A successful sandwich lets the attacker extract value out of every affected deposit/refund swap, permanently reducing the PC amount credited to the user's UEA — a real, unprivileged loss of protocol/user-controlled funds during "universal execution" / "PRC20 accounting" paths, matching the "corruption of ... gas fee accounting, refund accounting ... token mapping" and "unauthorized state transitions in universal execution flows" impact categories.

### Likelihood Explanation
Likelihood is constrained by liquidity depth of the specific PRC20/WPC Uniswap V3 pool and by the attacker's ability to time a trade around inbound-ballot finalization (which is observable on-chain, since it requires 2/3 UV votes that are themselves public). For pools with modest liquidity (early-launch tokens, since `liquidity_cap` in registry configs — see `config/testnet-donut/*/tokens/*.json` — governs mint amounts, not pool depth) this is straightforward and repeatable, requiring no validator or admin privilege, only ordinary EVM trades against the public Uniswap pool.

### Recommendation
Replace (or supplement) the instantaneous `quoteExactInputSingle` call with a TWAP-based quote (Uniswap V3 supports `observe`), and/or apply a much tighter, dynamically-computed slippage bound rather than a flat 5%. Where feasible, expose the minimum-output parameter as something the requesting/originating flow can constrain rather than deriving it solely from a spot read at execution time; alternatively, throttle/atomicize execution so the read-then-swap cannot be sandwiched (e.g., check price deviation against a longer-window reference before committing the swap and abort/fallback to a non-swap deposit if deviation exceeds a safe bound).

### Proof of Concept
1. Attacker identifies a PRC20 (e.g., `USDC.eth`) whose Uniswap V3 PRC20/WPC pool on Push Chain has shallow liquidity.
2. Attacker submits (or waits for) a legitimate user's `GAS`/`GAS_AND_PAYLOAD` inbound for that token to be observed by Universal Validators; ballot finalization height is publicly derivable from the vote count reaching threshold.
3. In the same or an adjacent block, before `ExecuteInboundGas`/`ExecuteInboundGasAndPayload` runs, attacker submits an EVM swap against the pool that pushes the PRC20→WPC price down by slightly more than 5%.
4. `GetSwapQuote` returns the depressed quote; `minPCOut = quote * 0.95` is computed against this already-depressed price, so it does not block the swap. `CallPRC20DepositAutoSwap` executes at the bad price, crediting the victim's UEA fewer WPC/PC tokens than fair value.
5. Attacker reverses their trade after the module's swap lands, capturing the price difference as profit, funded by the victim's deposit — analogous to the H-3 "donate then let the next depositor lose value to precision/price skew" pattern. [1](#0-0) [2](#0-1) [3](#0-2) [4](#0-3)

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}
