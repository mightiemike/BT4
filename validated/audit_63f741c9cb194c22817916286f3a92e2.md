## Analysis

Push Chain has a direct structural analog to the Zetachain M-2 finding. The consensus-gating checks for Universal Validator (UV) voting eligibility validate **bonded status** and **tombstoned status**, but never inspect the staking module's `Jailed` field directly — mirroring the exact gap (`IsNonTombstonedObserver` without a jailed check) that Zetachain fixed with `CheckObserverCanVote`.

### Title
Jailed Universal Validators can vote on inbound/outbound/TSS ballots during the jailing block due to missing explicit `Jailed` check - (File: `x/uvalidator/keeper/voting.go`, `x/uvalidator/keeper/validator.go`)

### Summary
`IsBondedUniversalValidator` and `GetEligibleVoters` gate voting/ballot eligibility solely on `validator.IsBonded()` and slashing's `IsTombstoned`, never checking `validator.Jailed` directly.

### Finding Description
`IsBondedUniversalValidator` only checks `validator.IsBonded()` [1](#0-0) , and `IsTombstonedUniversalValidator` only checks the slashing keeper's tombstone flag [2](#0-1) . Neither reads `validator.Jailed`. Both `VoteInbound` and `VoteOutbound` message handlers gate acceptance strictly on these two checks [3](#0-2) [4](#0-3) , as does `VoteTssKeyProcess` in `x/utss` [5](#0-4) .

Similarly, `GetEligibleVoters` — the function that snapshots the voter set and threshold denominator for every ballot — filters only on `sv.IsBonded()` and `SlashingKeeper.IsTombstoned`, not `sv.Jailed` [6](#0-5) .

In the Cosmos SDK staking lifecycle, when `slashing.BeginBlocker` jails a validator (for downtime or evidence-based infractions), it sets `validator.Jailed = true` and removes the validator from the power index immediately, but the `Bonded -> Unbonding` status transition is only applied later, in the staking module's `EndBlocker` (`ApplyAndReturnValidatorSetUpdates`) for that same block. Because `slashing.BeginBlocker` runs before `DeliverTx` for all transactions in that block, any `MsgVoteInbound`/`MsgVoteOutbound`/`MsgVoteTssKeyProcess` transaction included in the same block a UV gets jailed will still see `validator.Status == Bonded` when `IsBondedUniversalValidator`/`GetEligibleVoters` are evaluated, since only `EndBlocker` (after all txs) performs the status flip.

### Impact Explanation
A UV that has just been jailed (e.g., for downtime, or right after a slashable infraction is detected) can still cast a vote that is counted toward inbound/outbound/TSS ballot finalization for the remainder of that same block, before the staking status transition takes effect. This is the same invariant violated in the Zetachain report — an already-flagged-as-jailed validator participating in consensus voting when it should be excluded immediately.

### Likelihood Explanation
Low-to-medium. The window is limited to transactions processed within the exact block in which a UV is jailed, and by the following block `IsBondedUniversalValidator`/`GetEligibleVoters` will correctly exclude the validator. It requires the jailed validator (or an operator racing to get one last vote in) to submit the vote transaction in that same block, which is plausible but narrow in scope compared to the Zetachain original (which had no time-bound at all — tombstoned check alone allowed indefinite jailed voting).

### Recommendation
Add an explicit `validator.Jailed` check in `IsBondedUniversalValidator` (`x/uvalidator/keeper/voting.go`) and in the eligibility filter of `GetEligibleVoters` (`x/uvalidator/keeper/validator.go`), rejecting/excluding any validator with `Jailed == true` regardless of the currently-recorded `Bonded` status, closing the same-block race window.

### Proof of Concept
1. UV `V` is bonded and actively participating.
2. At height `H`, `V` misses enough blocks to trigger downtime jailing; `slashing.BeginBlocker` at height `H` sets `V.Jailed = true` but staking's `EndBlocker` (which transitions `Bonded -> Unbonding`) has not yet run for height `H`.
3. Within the same block `H`, `V` submits `MsgVoteInbound` (or `MsgVoteOutbound`/`MsgVoteTssKeyProcess`).
4. `IsBondedUniversalValidator` reads `validator.IsBonded() == true` (status not yet updated) and returns `true`; `IsTombstonedUniversalValidator` returns `false`.
5. The vote is accepted and recorded toward ballot quorum via `VoteOnInboundBallot` → `GetEligibleVoters`, which likewise still includes `V` because its staking status has not transitioned yet. [7](#0-6) [6](#0-5) [8](#0-7)

func (k Keeper) IsBondedUniversalValidator(ctx context.Context, universalValidator string) (bool, error) {
	k.Logger().Debug("checking bonded status of universal validator", "validator", universalValidator)

	accAddr, err := sdk.AccAddressFromBech32(universalValidator)
	if err != nil {
		return false, fmt.Errorf("invalid signer address: %w", err)
	}

	valAddr := sdk.ValAddress(accAddr)

	// Check if the universal validator is in the registered set
	exists, err := k.HasUniversalValidatorInSet(ctx, valAddr)
	if err != nil {
		return false, fmt.Errorf("failed to check universal validator set: %w", err)
	}
	if !exists {
		k.Logger().Debug("validator not found in universal validator set", "validator", universalValidator)
		return false, fmt.Errorf("validator %s not present in the registered universal validators set", valAddr.String())
	}

	// Ensure the universal validator exists in the staking module
	validator, err := k.StakingKeeper.GetValidator(ctx, valAddr)
	if err != nil {
		return false, fmt.Errorf("core validator not found: %w", err)
	}

	// Check that the validator is in bonded status
	if !validator.IsBonded() {
		k.Logger().Debug("universal validator is not bonded", "validator", universalValidator)
		return false, nil // exists but not bonded
	}

	k.Logger().Debug("universal validator is bonded", "validator", universalValidator)
	return true, nil
}

// VoteInbound implements types.MsgServer.
func (ms msgServer) VoteInbound(ctx context.Context, msg *types.MsgVoteInbound) (*types.MsgVoteInboundResponse, error) {
	signerAccAddr, err := sdk.AccAddressFromBech32(msg.Signer)
	if err != nil {
		return nil, fmt.Errorf("invalid signer address: %w", err)
	}

	// Convert account to validator operator address
	signerValAddr := sdk.ValAddress(signerAccAddr)

	// Lookup the linked universal validator for this signer
	isBonded, err := ms.k.uvalidatorKeeper.IsBondedUniversalValidator(ctx, msg.Signer)
	if err != nil {
		return nil, errors.Wrapf(err, "failed to check bonded status for signer %s", msg.Signer)
	}
	if !isBonded {
		return nil, fmt.Errorf("universal validator for signer %s is not bonded", msg.Signer)
	}

	isTombstoned, err := ms.k.uvalidatorKeeper.IsTombstonedUniversalValidator(ctx, msg.Signer)
	if err != nil {
		return nil, errors.Wrapf(err, "failed to check tombstoned status for signer %s", msg.Signer)
	}
	if isTombstoned {
		return nil, fmt.Errorf("universal validator for signer %s is tombstoned", msg.Signer)
	}

	// continue with inbound synthetic creation / voting logic here
	err = ms.k.VoteInbound(ctx, signerValAddr, *msg.Inbound)
	if err != nil {
		return nil, err
	}

	return &types.MsgVoteInboundResponse{}, nil
}

func (k Keeper) GetEligibleVoters(ctx context.Context) ([]types.UniversalValidator, error) {
	var voters []types.UniversalValidator
	sdkCtx := sdk.UnwrapSDKContext(ctx)

	err := k.UniversalValidatorSet.Walk(ctx, nil, func(addr sdk.ValAddress, val types.UniversalValidator) (stop bool, err error) {
		switch val.LifecycleInfo.CurrentStatus {
		case types.UVStatus_UV_STATUS_ACTIVE, types.UVStatus_UV_STATUS_PENDING_JOIN:
		default:
			return false, nil
		}

		sv, getErr := k.StakingKeeper.GetValidator(ctx, addr)
		if getErr != nil {
			// Validator removed from staking module, or some other read error:
			// treat as ineligible for this call rather than failing the whole
			// walk. This keeps quorum computable when one stranded entry would
			// otherwise crash the read path.
			k.Logger().Debug("eligible voter filter: staking GetValidator failed", "validator", addr.String(), "err", getErr)
			return false, nil
		}
		if !sv.IsBonded() {
			return false, nil
		}
		consAddr, caErr := sv.GetConsAddr()
		if caErr != nil {
			k.Logger().Debug("eligible voter filter: GetConsAddr failed", "validator", addr.String(), "err", caErr)
			return false, nil
		}
		if k.SlashingKeeper.IsTombstoned(sdkCtx, consAddr) {
			return false, nil
		}

		voters = append(voters, val)
		return false, nil
	})

	if err != nil {
		return nil, err
	}

	k.Logger().Debug("fetched eligible voters", "count", len(voters))
	return voters, nil
}
