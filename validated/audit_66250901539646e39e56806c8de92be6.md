### Title
Unchecked index accesses in stateless-compression `decompress` allow a malicious/malformed OS output to panic node processes reading state diffs - (File: crates/starknet_os/src/hints/hint_implementation/stateless_compression/utils.rs)

### Summary
The Rust `decompress` function that reconstructs a state diff from felt-packed, bucketed compressed data performs raw, unchecked indexing (`unique_values[*ptr]`, `all_values[*offset]`, `bucket_offset_trackers[bucket_index]`) into vectors whose sizes are derived from attacker/prover-influenced header fields, unlike its Cairo counterpart in `compression.cairo` which explicitly verifies bucket bounds via `dict_update`/`dict_squash` before trusting offsets.

### Finding Description
`decompress` ( [1](#0-0) ) parses a header of bucket lengths and repeated-value pointers directly from the felt stream with `unpack_chunk_to_usize`, then uses these values to index into `unique_values`/`all_values`/`bucket_offset_trackers` without validating that `ptr < unique_values.len()`, `bucket_index < bucket_offset_trackers.len()`, or `offset < all_values.len()`. This mirrors the CVE-2024-57850 root cause: decompression bounds are not fully checked before consuming attacker/prover-controlled length and index fields. The Cairo implementation of the same algorithm (`crates/apollo_starknet_os_program/.../compression.cairo:280-301`) explicitly re-verifies that no out-of-bounds access occurred by using `dict_update`/`dict_squash` on the final bucket offsets — a check that has no equivalent in the Rust port.

This function is reachable via `PartialOsStateDiff::try_from_output_iter` ( [2](#0-1) ), which decompresses the OS/program output stream when parsing a state-diff commitment produced by proof/OS output processing.

### Impact Explanation
Since Rust enforces memory safety, an out-of-bounds index here causes a `panic` (process abort) rather than the C-style memory corruption in the original JFFS2 bug — this is a crash/DoS of the process parsing OS output (e.g. during re-execution, proof verification, or state-diff ingestion), not silent memory corruption. If this parsing path is on the block-processing/re-execution critical path for nodes (validators/full nodes ingesting proof output), a malformed/adversarial compressed stream could crash node processes handling that data, which could translate into a liveness/availability issue for state-diff processing (nodes unable to confirm or advance state) if untrusted or unvalidated data reaches this decoder.

### Likelihood Explanation
I could not fully verify from the available index whether `PartialOsStateDiff::try_from_output_iter` is fed with data controlled by an unprivileged party (e.g., raw prover-submitted proof output before any correctness check) or only with values already constrained/verified elsewhere (e.g., only invoked on outputs whose validity was already checked by an accompanying Cairo `assert`/proof). The function is also referenced by `crates/starknet_os/src/hints/hint_implementation/aggregator/test.rs`, suggesting it may primarily be exercised in test/aggregator contexts rather than the hot execution path. Given the `#[allow(dead_code)]` annotation on `decompress` itself, this suggests it may not be fully wired into the mandatory execution path, reducing confidence that an untrusted single-transaction/L1-message actor can reach it directly.

### Recommendation
Add explicit bounds validation before each unchecked index operation in `decompress` (repeating-value pointer bound check against `unique_values.len()`, bucket-index bound check against `TOTAL_N_BUCKETS`, and offset bound check against `all_values.len()`), returning an `OsHintError`/`OsOutputError` instead of panicking, matching the Cairo implementation's dict-based bound verification.

/// Decompresses the given compressed data.
#[allow(dead_code)]
pub fn decompress(compressed: &mut impl Iterator<Item = Felt>) -> Vec<Felt> {
    fn unpack_chunk<const LENGTH: usize>(
        compressed: &mut impl Iterator<Item = Felt>,
        n_elms: usize,
    ) -> Vec<Felt> {
        let n_elms_per_felt = BitLength::min_bit_length(LENGTH).unwrap().n_elems_in_felt();
        let n_packed_felts = n_elms.div_ceil(n_elms_per_felt);
        let compressed_chunk: Vec<_> = compressed.take(n_packed_felts).collect();
        unpack_felts(&compressed_chunk, n_elms)
            .into_iter()
            .map(|bits: BitsArray<LENGTH>| felt_from_bits_le(&bits.0).unwrap())
            .collect()
    }

    fn unpack_chunk_to_usize(
        compressed: &mut impl Iterator<Item = Felt>,
        n_elms: usize,
        elm_bound: ElmBoundType,
    ) -> Vec<usize> {
        let n_elms_per_felt = get_n_elms_per_felt(elm_bound);
        let n_packed_felts = n_elms.div_ceil(n_elms_per_felt);

        let compressed_chunk: Vec<_> = compressed.take(n_packed_felts).collect();
        unpack_felts_to::<usize>(&compressed_chunk, n_elms, elm_bound)
    }

    let header = unpack_chunk_to_usize(compressed, HEADER_LEN, HEADER_ELM_BOUND);
    let version = &header[0];
    assert!(version == &usize::from(COMPRESSION_VERSION), "Unsupported compression version.");

    let data_len = &header[1];
    let unique_value_bucket_lengths: Vec<usize> = header[2..2 + N_UNIQUE_BUCKETS].to_vec();
    let n_repeating_values = &header[2 + N_UNIQUE_BUCKETS];

    let mut unique_values = Vec::new();
    unique_values.extend(compressed.take(unique_value_bucket_lengths[0])); // 252 bucket.
    unique_values.extend(unpack_chunk::<125>(compressed, unique_value_bucket_lengths[1]));
    unique_values.extend(unpack_chunk::<83>(compressed, unique_value_bucket_lengths[2]));
    unique_values.extend(unpack_chunk::<62>(compressed, unique_value_bucket_lengths[3]));
    unique_values.extend(unpack_chunk::<31>(compressed, unique_value_bucket_lengths[4]));
    unique_values.extend(unpack_chunk::<15>(compressed, unique_value_bucket_lengths[5]));

    let repeating_value_pointers = unpack_chunk_to_usize(
        compressed,
        *n_repeating_values,
        unique_values.len().try_into().unwrap(),
    );

    let repeating_values: Vec<_> =
        repeating_value_pointers.iter().map(|ptr| unique_values[*ptr]).collect();

    let mut all_values = unique_values;
    all_values.extend(repeating_values);

    let bucket_index_per_elm: Vec<usize> =
        unpack_chunk_to_usize(compressed, *data_len, TOTAL_N_BUCKETS.try_into().unwrap());

    let all_bucket_lengths: Vec<usize> =
        unique_value_bucket_lengths.into_iter().chain([*n_repeating_values]).collect();

    let bucket_offsets = get_bucket_offsets(&all_bucket_lengths);

    let mut bucket_offset_trackers: Vec<_> = bucket_offsets;

    let mut result = Vec::new();
    for bucket_index in bucket_index_per_elm {
        let offset = &mut bucket_offset_trackers[bucket_index];
        let value = all_values[*offset];
        *offset += 1;
        result.push(value);
    }
    result
}
