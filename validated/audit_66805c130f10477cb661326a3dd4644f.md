## Title
Sandwichable gas-abstraction auto-swap due to slippage bound derived from a manipulable spot quote taken in the same execution as the swap - (File: `x/uexecutor/keeper/execute_inbound_gas.go`, `x/uexecutor/keeper/evm.go`)

## Summary
When a user bridges a `GAS` or `GAS_AND_PAYLOAD` inbound, `ExecuteInboundGas`/`gasAndPayloadDepositAutoSwap` fetch a Uniswap V3 `QuoterV2` spot quote and immediately derive the swap's slippage floor from that same quote (`minPCOut = quote * 95 / 100`), then execute the swap against the same pool in the same call. Because the "protection" value is computed from the very price an unprivileged actor can move beforehand, it provides no real defense against price manipulation — it is the same class of bug as the reported "lack of fee/slippage protection lets an attacker sandwich the swap" finding, just applied to Push Chain's module-driven PRC20 deposit-and-autoswap path instead of a user-submitted AMM trade.

## Finding Description
`ExecuteInboundGas` (triggered when a `GAS` inbound's ballot finalizes) executes: [1](#0-0) 

It calls `GetSwapQuote` against the Uniswap V3 `QuoterV2` contract to get the current spot-price-equivalent quote for `prc20 → wpc`, then computes:
```
minPCOut := quote * 95 / 100
```
and immediately calls `CallPRC20DepositAutoSwap` with that `minPCOut`, which performs the real on-chain swap through `UniversalCore.depositPRC20WithAutoSwap`: [2](#0-1) [3](#0-2) 

The identical pattern is used for `GAS_AND_PAYLOAD` inbounds in `gasAndPayloadDepositAutoSwap`: [4](#0-3) 

The 5% band is only meaningful if the quote reflects an undisturbed market price. Since `GetSwapQuote` reads live pool reserves/ticks at the moment the finalizing validator vote lands (the transaction that crosses ballot quorum and triggers `ExecuteInboundGas`), and that finalizing vote is itself an ordinary, mempool-visible, gasless `MsgVoteInbound` transaction, an unprivileged actor can:
1. Observe the pending finalizing `MsgVoteInbound` in the mempool.
2. Front-run it with an ordinary swap against the same `wpc`/`prc20` Uniswap V3 pool used by `quoterAddr`, pushing the spot price so `quoteExactInputSingle` returns an artificially depressed `amountOut`.
3. Let the finalizing vote execute: `GetSwapQuote` returns the manipulated (low) quote, `minPCOut` is derived from that same manipulated quote (so it can never fail the swap), and `CallPRC20DepositAutoSwap` executes at the bad price, minting far fewer PC tokens to the user's UEA than a fair market price would.
4. Back-run with the reverse swap to restore the pool price, capturing the value difference as arbitrage profit extracted from the user's bridged gas deposit.

This mirrors the reported bug's root cause exactly: the slippage/fee mechanism is derived from the same instantaneously-manipulable price used to execute the trade, so "protection" is illusory and the attack costs only ordinary swap gas — no protocol fee or independent price source stands in the way.

## Impact Explanation
This causes unauthorized corruption of PRC20/native asset accounting for the victim's gas-abstraction deposit: the user's bridged asset is swapped at an attacker-manipulated price instead of fair market price, resulting in fewer native PC tokens credited to the user's UEA than deserved, with the difference captured by the attacker. This is a direct, repeatable value-extraction path against user funds reachable via a completely ordinary, honest-validator-finalized inbound deposit — no privileged actor is required.

## Likelihood Explanation
Every `GAS` and `GAS_AND_PAYLOAD` inbound that routes through the auto-swap path is exposed, since the finalizing `MsgVoteInbound` is gasless and observable pre-confirmation, and manipulating a Uniswap V3 pool with an ordinary swap transaction is trivial and requires no special access. The attack is economically bounded only by the size/depth of the specific `prc20`/`wpc` pool and by two ordinary EVM transaction costs (front-run + back-run) — comparable to or cheaper than the original report's cost model.

## Recommendation
Do not derive the slippage floor from a quote fetched atomically within the same execution as the swap. Options: use a time-weighted average price (TWAP) oracle instead of `quoteExactInputSingle` spot quotes for computing `minPCOut`; bound the acceptable price to a value tracked/committed before the manipulable event (e.g., over multiple blocks); or otherwise ensure `minPCOut` reflects an on-chain price to which the attacker cannot contribute in the same block as the swap.

## Proof of Concept
1. Attacker monitors mempool for a `MsgVoteInbound` that will finalize a `GAS`/`GAS_AND_PAYLOAD` ballot for victim's inbound deposit of `prc20AddressHex` token.
2. Attacker submits (front-run) a large swap on the `wpc`/`prc20` Uniswap V3 pool referenced by `quoterAddr`/`wpcAddr` (from `GetUniversalCoreQuoterAddress`/`GetUniversalCoreWPCAddress`), depressing the exchange rate.
3. Victim's finalizing vote lands; `k.GetSwapQuote` (`x/uexecutor/keeper/evm.go:502-538`) returns the depressed quote; `minPCOut = quote*95/100` (`x/uexecutor/keeper/execute_inbound_gas.go:142-148`) is computed from the same depressed value; `k.CallPRC20DepositAutoSwap` executes the swap and satisfies the (also depressed) `minPCOut` trivially.
4. Attacker submits a back-run swap restoring the pool price, realizing the arbitrage profit that was extracted from the victim's deposit's fair value.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}
