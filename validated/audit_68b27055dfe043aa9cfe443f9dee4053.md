### Title
Text-format injection via unvalidated `Any.type_url` in `prototext` marshaling - (File: encoding/prototext/encode.go)

### Summary
`prototext.Marshal` expands `google.protobuf.Any` messages by writing the field name `"[" + typeURL + "]"` directly into the text-format output via `text.Encoder.WriteName`, which performs **no escaping or character validation** on its input. Since `type_url` is an ordinary, attacker-controllable string field of `Any` (settable by whoever produced the binary message being marshaled), an attacker can embed textproto metacharacters (`"`, `{`, `}`, `:`, newlines) inside `type_url` and inject arbitrary fabricated fields/structure into the emitted textproto, corrupting the marshaled output in a way exactly analogous to the reported POP3 issue: a user-controlled string reaches a protocol/serialization sink without rejecting control characters, letting it inject additional "commands" (here, additional textproto fields/structure).

### Finding Description
`Any.TypeUrl` documentation explicitly states the invariant that should hold for text format: [1](#0-0) 

However, when `prototext.MarshalOptions.marshal` expands an `Any` value, `encoder.marshalAny` takes the raw `type_url` string and writes it unescaped as a field name: [2](#0-1) 

`FindMessageByURL` only validates the *suffix* of the URL after the last `/` (it must resolve to a registered message full name); everything before that slash is unconstrained and passed through verbatim into `WriteName`.

The sink, `text.Encoder.WriteName`, performs no escaping, quoting, or character filtering at all — it just appends the raw bytes followed by `:`: [3](#0-2) 

Contrast this with `WriteString` (used for field *values*), which properly escapes control characters, quotes, and backslashes via `appendString`: [4](#0-3) 

No such escaping path exists for `WriteName`. Because `marshalAny` constructs its field name by string concatenation (`"[" + typeURL + "]"`) and passes it straight into this unescaped sink, arbitrary structural tokens smuggled inside `type_url` (quotes, braces, colons, newlines) are emitted verbatim into the textproto stream, breaking the intended message-name/value token boundaries of the output.

### Impact Explanation
Any component that accepts an untrusted `Any`-typed submessage (default binary unmarshal, trusted schema, no special privilege needed — just a valid `type_url` suffix matching a registered type and a resolvable/parsable `value`) and later calls `prototext.Marshal`/`Format` on it (e.g., for logging, debugging output, audit trails, or forwarding as textproto to another component) will emit corrupted/forged textproto. This is an integrity issue on the produced text output: an attacker can forge extra fields, prematurely close message braces, or otherwise desynchronize the structure that a human or downstream textproto consumer relies on — the same class of "trusted stream now contains attacker-injected structure" impact as the CVE's POP3 command injection.

### Likelihood Explanation
Likelihood is realistic: `type_url` is a plain proto3 string field with no format enforcement anywhere in the encode/decode path prior to `prototext.Marshal`; any sender who can construct or forward an `Any` message (a very common pattern for polymorphic payloads) controls this field. The only constraint is that the suffix after the final `/` must name a message type known to the resolver — trivially satisfiable using any common well-known type (e.g., `google.protobuf.Empty`). No custom resolver, malicious peer privilege, or descriptor tampering is required.

### Recommendation
Validate/sanitize `type_url` before using it to construct the `"[...]"` field name in `encoder.marshalAny` — reject or escape characters outside the character set documented in `anypb.Any.TypeUrl` (alphanumerics, `/`, `-`, `.`, `~`, `_`, `!`, `$`, `&`, `(`, `)`, `*`, `+`, `,`, `;`, `=`, and percent-encoded escapes) before calling `WriteName`, or add a dedicated escaping/quoting routine for field names constructed from untrusted strings.

### Proof of Concept
```go
package main

import (
	"fmt"

	"google.golang.org/protobuf/encoding/prototext"
	anypb "google.golang.org/protobuf/types/known/anypb"
	emptypb "google.golang.org/protobuf/types/known/emptypb"
)

func main() {
	// type_url suffix after the last '/' must resolve to a real registered type
	// (google.protobuf.Empty), but everything before it is attacker-controlled
	// and contains textproto metacharacters.
	malicious := `evil"}` + "\n" + `injected_field: "PWNED"` + "\n" + `x/google.protobuf.Empty`

	a := &anypb.Any{
		TypeUrl: malicious,
		Value:   nil, // google.protobuf.Empty has no fields
	}

	out, err := prototext.MarshalOptions{Multiline: true}.Marshal(a)
	if err != nil {
		panic(err)
	}
	fmt.Println(string(out))
	// Output contains raw, unescaped '"', '}', and a newline followed by
	// a fabricated "injected_field" entry — the textproto structure is
	// corrupted/forged by attacker-controlled type_url content.
}
```

// marshalAny marshals the given google.protobuf.Any message in expanded form.
// It returns true if it was able to marshal, else false.
func (e encoder) marshalAny(any protoreflect.Message) bool {
	// Construct the embedded message.
	fds := any.Descriptor().Fields()
	fdType := fds.ByNumber(genid.Any_TypeUrl_field_number)
	typeURL := any.Get(fdType).String()
	mt, err := e.opts.Resolver.FindMessageByURL(typeURL)
	if err != nil {
		return false
	}
	m := mt.New().Interface()

	// Unmarshal bytes into embedded message.
	fdValue := fds.ByNumber(genid.Any_Value_field_number)
	value := any.Get(fdValue)
	err = proto.UnmarshalOptions{
		AllowPartial: true,
		Resolver:     e.opts.Resolver,
	}.Unmarshal(value.Bytes(), m)
	if err != nil {
		return false
	}

	// Get current encoder position. If marshaling fails, reset encoder output
	// back to this position.
	pos := e.Snapshot()

	// Field name is the proto field name enclosed in [].
	e.WriteName("[" + typeURL + "]")
	err = e.marshalMessage(m.ProtoReflect(), true)
	if err != nil {
		e.Reset(pos)
		return false
	}
	return true
}

func (e *Encoder) WriteString(s string) {
	e.prepareNext(scalar)
	e.out = appendString(e.out, s, e.outputASCII)
}

func appendString(out []byte, in string, outputASCII bool) []byte {
	out = append(out, '"')
	i := indexNeedEscapeInString(in)
	in, out = in[i:], append(out, in[:i]...)
	for len(in) > 0 {
		switch r, n := utf8.DecodeRuneInString(in); {
		case r == utf8.RuneError && n == 1:
			// We do not report invalid UTF-8 because strings in the text format
			// are used to represent both the proto string and bytes type.
			r = rune(in[0])
			fallthrough
		case r < ' ' || r == '"' || r == '\\' || r == 0x7f:
			out = append(out, '\\')
			switch r {
			case '"', '\\':
				out = append(out, byte(r))
			case '\n':
				out = append(out, 'n')
			case '\r':
				out = append(out, 'r')
			case '\t':
				out = append(out, 't')
			default:
				out = append(out, 'x')
				out = append(out, "00"[1+(bits.Len32(uint32(r))-1)/4:]...)
				out = strconv.AppendUint(out, uint64(r), 16)
			}
			in = in[n:]
		case r >= utf8.RuneSelf && (outputASCII || r <= 0x009f):
			out = append(out, '\\')
			if r <= math.MaxUint16 {
				out = append(out, 'u')
				out = append(out, "0000"[1+(bits.Len32(uint32(r))-1)/4:]...)
				out = strconv.AppendUint(out, uint64(r), 16)
			} else {
				out = append(out, 'U')
				out = append(out, "00000000"[1+(bits.Len32(uint32(r))-1)/4:]...)
				out = strconv.AppendUint(out, uint64(r), 16)
			}
			in = in[n:]
		default:
			i := indexNeedEscapeInString(in[n:])
			in, out = in[n+i:], append(out, in[:n+i]...)
		}
	}
	out = append(out, '"')
	return out
}
