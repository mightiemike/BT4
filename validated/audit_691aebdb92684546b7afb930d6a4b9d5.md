## Analog Vulnerability Found

### Title
Missing declared-class validation in Starknet OS `execute_replace_class` allows contracts to be bound to a non-existent/undeclared class - ([File: crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo])

### Summary
The reported CVE describes TeamPass failing to re-validate an attacker-controlled identifier (`item_id`) before performing a privileged state mutation (copy/edit/delete). The analogous bug class in this sequencer is a missing validation of an attacker-controlled identifier (`class_hash`) before committing a state mutation that changes a contract's class binding via the `replace_class` syscall.

### Finding Description
In the Rust `blockifier` execution engine, the `replace_class` syscall explicitly validates that the target `class_hash` is declared (and is a Cairo1 class) before mutating contract state: [1](#0-0) 

The deprecated (Cairo0) syscall handler enforces the same rule: [2](#0-1) 

However, the Starknet OS Cairo implementation of the identical syscall — which is the ground-truth specification used for block re-execution and STARK proving of the state transition — omits this check entirely, and the omission is explicitly flagged as a known TODO in the code itself: [3](#0-2) 

The comment at line 902 ("TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.") confirms the `execute_replace_class` function unconditionally reads the caller's state entry via the `GetContractAddressStateEntry` hint and overwrites `class_hash` in `contract_state_changes` with the caller-supplied `class_hash`, without cross-checking `contract_class_changes` (the dict that tracks which classes were actually declared and compiled) as is done for declare transactions: [4](#0-3) 

The deprecated (Cairo0) OS syscall path has the identical gap: [5](#0-4) 

### Impact Explanation
If a contract's class binding is committed with a `class_hash` that has no corresponding compiled class in `contract_class_changes`/state, the contract becomes permanently uncallable — any future invocation must resolve `get_compiled_class` for that hash and will fail, effectively bricking the contract and permanently freezing any funds or state it holds. Because the Starknet OS is the canonical specification consumed for proof generation and block re-execution consistency checks (see `blockifier_reexecution`), a soundness gap here means the proven/re-executed state transition does not actually enforce the "class must be declared" invariant that the Rust blockifier enforces, breaking the equivalence between the two execution engines for this syscall.

### Likelihood Explanation
Under the current architecture, the Rust `blockifier` (which builds blocks in the honest sequencer flow) already validates and rejects `replace_class` calls with undeclared class hashes before they can be included in a block (as shown by the existing test `crates/blockifier/src/execution/syscalls/syscall_tests/replace_class.rs::undeclared_class_hash`), so this specific gap is not directly triggerable through the primary block-building path today. The risk is latent: it surfaces wherever the Starknet OS program is treated as the authoritative execution rule set independent of the Rust-side guard (e.g., re-execution/proving pipelines, or if the Rust-side check is ever refactored/removed since the two implementations must otherwise stay in lock-step). The explicit developer TODO confirms this is a recognized, currently-unaddressed gap rather than an intentional design choice.

### Recommendation
Add the missing validation in both OS `execute_replace_class` implementations (`syscall_impls.cairo` and `deprecated_execute_syscalls.cairo`): before updating `contract_state_changes` with the new `class_hash`, assert that the class hash exists in `contract_class_changes` (i.e., has been declared with a non-zero compiled class hash), mirroring the `try_declare`/`get_compiled_class` checks already present in `crates/blockifier/src/execution/syscalls/syscall_base.rs` and `crates/blockifier/src/transaction/transactions.rs`.

### Proof of Concept
1. An account contract executes an ordinary `INVOKE` transaction calling `replace_class_syscall(class_hash)` on itself with a `class_hash` that was never declared via a prior `DECLARE` transaction.
2. In the Starknet OS Cairo execution path (`execute_replace_class`), the syscall proceeds unconditionally: it reads the current `StateEntry` via the `GetContractAddressStateEntry` hint and commits a `new_state_entry` with the attacker-supplied `class_hash`, with no check against `contract_class_changes`.
3. The resulting state diff sets the contract's class hash to a value with no corresponding compiled class, which — if this path is relied upon as the authoritative execution rule (e.g., in re-execution/proving) — commits a root/block hash reflecting an invalid, unenforceable contract binding, permanently freezing that contract.

    pub fn replace_class(&mut self, class_hash: ClassHash) -> SyscallResult<()> {
        // Ensure the class is declared (by reading it), and of type V1.
        let compiled_class = self.state.get_compiled_class(class_hash)?;

        if !is_cairo1(&compiled_class) {
            return Err(SyscallExecutionError::ForbiddenClassReplacement { class_hash });
        }
        self.state.set_class_hash_at(self.call.storage_address, class_hash)?;
        Ok(())
    }

func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
