### Title
Stale-vote GasPrice query response allows an unpruned validator's vote to bias the queried median gas price - (File: x/uexecutor/keeper/chain_meta.go, x/uexecutor/keeper/query_server.go)

### Summary
The `VoteChainMeta` function already implements the exact mitigation recommended by the external ZetaChain report: it filters votes older than `chainMetaVoteStalenessSeconds` (300s) before computing the median that is actually pushed on-chain via `CallUniversalCoreSetChainMeta`. [1](#0-0)  However, the `MedianIndex` field persisted on the `ChainMeta` entry — and exposed through the `GasPrice`/`AllGasPrices` gRPC queries consumed by `universalClient/pushcore.Client.GetGasPrice` — is computed over the **full, unfiltered** `entry.Prices` array, not the staleness-filtered set. [2](#0-1) 

### Finding Description
`computeMedianIndex(entry.Prices)` sorts and picks the median index across every signer that has ever voted for a given chain, with no staleness or liveness filtering. [3](#0-2)  This value is stored back on the entry and is the only median metadata surfaced to external readers via the `GasPrice` and `AllGasPrices` query endpoints, which map `ChainMeta` back to the legacy `GasPrice` shape (`chainMetaToGasPrice`). [4](#0-3)  A validator's vote stays in `entry.Signers`/`entry.Prices` indefinitely unless they are formally removed from the universal validator set, which triggers `PruneValidatorVotes`. [5](#0-4)  A validator that is merely offline/inactive but not administratively removed keeps its last submitted (potentially very old) price entry in the array forever, and that stale entry continues to participate in `computeMedianIndex`, exactly the scenario described in the external report.

By contrast, the actual value pushed to the EVM oracle (`medianPrice`/`medianChainHeight`) is correctly computed only from `fresh` votes within the staleness window. [6](#0-5)  The project's own integration test explicitly acknowledges this divergence: the `MedianIndex` on the stored entry does not reflect the value actually applied on-chain, so the test has to bypass the gRPC query and read directly from the EVM contract to get the true value. [7](#0-6) 

`universalClient/pushcore.Client.GetGasPrice`, whose doc comment states it "retrieves the median gas price for a specific chain from the on-chain oracle," reads exactly this stale/unfiltered `MedianIndex`/`Prices` pair from the query response. [8](#0-7) 

### Impact Explanation
Any consumer relying on the `GasPrice`/`AllGasPrices` gRPC queries (including `universalClient/pushcore.Client.GetGasPrice`) receives a median price/height that can be dragged toward stale values submitted by inactive-but-not-yet-removed validators, reproducing the exact "lagging median gas price" condition described in the external report — even though the on-chain EVM oracle used for actual gas-fee accounting is correctly computed from fresh votes only. If any part of the system (fee estimation, gas markup logic in `ChainMetaOracle`, or an off-chain component) trusts this query response as authoritative rather than reading the EVM contract state directly, it will act on an inaccurate, lagging gas price, echoing the underpriced-outbound risk from the original finding. This is a data-integrity/query-correctness issue rather than direct fund loss, since the actually-applied on-chain value (via `CallUniversalCoreSetChainMeta`) is unaffected.

### Likelihood Explanation
Requires no privileged action — any validator that stops actively voting (e.g., goes offline, has connectivity issues) without being formally removed from the universal validator set will passively leave a stale entry in `ChainMeta.Prices`/`Signers`, which then perpetually skews `MedianIndex` returned by the query layer. This is a naturally occurring, unprivileged condition (no attacker action needed beyond passive inactivity), making the divergence between "true" and "queried" median likely to occur over time as validator sets churn.

### Recommendation
Compute and store `MedianIndex` (or better, store the actual `medianPrice`/`medianChainHeight` values directly) from the same staleness-filtered `fresh` vote set used for the EVM oracle write, so that the `GasPrice`/`ChainMeta` query responses are consistent with what was actually applied on-chain. Alternatively, expose the filtered "fresh" price/height directly as dedicated response fields distinct from the raw historical `Prices`/`Signers` arrays, and clearly document that `MedianIndex` reflects only fresh votes.

### Proof of Concept
1. Three validators vote chain meta prices `[100, 300, 500]`; bootstrap median (`fresh`-based) = 300, and `entry.MedianIndex` also happens to equal 300 at this point (full and fresh sets coincide). [9](#0-8) 
2. Advance block time past `chainMetaVoteStalenessSeconds` (300s) so validator[1]'s vote (300, the historical median) becomes stale. [10](#0-9) 
3. Only validators[0] and [2] re-vote (100, 500). The EVM oracle correctly updates using only the two fresh votes. [6](#0-5) 
4. But `entry.MedianIndex = computeMedianIndex(entry.Prices)` is recomputed over the full `Prices` array — which still contains validator[1]'s stale entry of 300 alongside the two fresh values — so a `GasPrice` query can still return the stale-influenced index/value rather than the fresh, actually-applied median, as confirmed by the test's own note that the contract must be queried directly to see the real value. [7](#0-6)

// PruneValidatorVotes removes a validator's votes from all ChainMetas entries.
// Called when a validator is removed from the universal validator set to prevent stale votes
// from influencing the median calculations.
func (k Keeper) PruneValidatorVotes(ctx context.Context, validatorAddr string) {
	k.Logger().Debug("pruning validator votes from chain metas", "validator", validatorAddr)

	_ = k.ChainMetas.Walk(ctx, nil, func(chainId string, entry types.ChainMeta) (bool, error) {
		idx := -1
		for i, s := range entry.Signers {
			if s == validatorAddr {
				idx = i
				break
			}
		}
		if idx >= 0 && len(entry.Signers) > 1 {
			entry.Signers = append(entry.Signers[:idx], entry.Signers[idx+1:]...)
			entry.Prices = append(entry.Prices[:idx], entry.Prices[idx+1:]...)
			entry.ChainHeights = append(entry.ChainHeights[:idx], entry.ChainHeights[idx+1:]...)
			entry.StoredAts = append(entry.StoredAts[:idx], entry.StoredAts[idx+1:]...)
			entry.MedianIndex = uint64(computeMedianIndex(entry.Prices))
			_ = k.ChainMetas.Set(ctx, chainId, entry)
			k.Logger().Debug("pruned validator vote from chain meta",
				"validator", validatorAddr,
				"chain_id", chainId,
				"remaining_signers", len(entry.Signers),
			)
		} else if idx >= 0 && len(entry.Signers) == 1 {
			_ = k.ChainMetas.Remove(ctx, chainId)
			k.Logger().Debug("removed chain meta entry after last signer pruned",
				"validator", validatorAddr,
				"chain_id", chainId,
			)
		}
		return false, nil
	})
}

// computeMedianIndex returns index of the median element
func computeMedianIndex(values []uint64) int {
	type idxVal struct {
		Idx int
		Val uint64
	}
	arr := make([]idxVal, len(values))
	for i, v := range values {
		arr[i] = idxVal{Idx: i, Val: v}
	}
	sort.SliceStable(arr, func(i, j int) bool { return arr[i].Val < arr[j].Val })
	return arr[len(arr)/2].Idx
}

// GetGasPrice retrieves the median gas price for a specific chain from the on-chain oracle.
func (c *Client) GetGasPrice(ctx context.Context, chainID string) (*big.Int, error) {
	if chainID == "" {
		return nil, errors.New("pushcore: chainID is required")
	}

	return retryWithRoundRobin(
		len(c.uexecutorClients),
		&c.rr,
		func(idx int) (*big.Int, error) {
			resp, err := c.uexecutorClients[idx].GasPrice(ctx, &uexecutortypes.QueryGasPriceRequest{
				ChainId: chainID,
			})
			if err != nil {
				return nil, err
			}
			if resp.GasPrice == nil {
				return nil, errors.New("pushcore: GasPrice response is nil")
			}

			if len(resp.GasPrice.Prices) == 0 {
				return nil, fmt.Errorf("pushcore: no gas prices available for chain %s", chainID)
			}

			medianIdx := resp.GasPrice.MedianIndex
			if medianIdx >= uint64(len(resp.GasPrice.Prices)) {
				medianIdx = 0
			}

			medianPrice := resp.GasPrice.Prices[medianIdx]
			return new(big.Int).SetUint64(medianPrice), nil
		},
		"GetGasPrice",
		c.logger,
	)
}
