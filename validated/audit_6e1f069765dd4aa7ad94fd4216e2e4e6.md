## Analog Vulnerability Found

### Title
Spot-price Uniswap V3 quote used for gas-abstraction swap `minPCOut` enables sandwich/flash-loan style value extraction from the PRC20↔WPC swap - (File: `x/uexecutor/keeper/execute_inbound_gas.go`, `x/uexecutor/keeper/evm.go`)

### Summary
The Sandclock report's root cause is trusting an AMM's manipulable **spot price** (with no TWAP, and `_minLockPeriod == 0` giving no cooldown) as the sole input for both valuation and slippage protection, letting a flash-loan actor bracket the vault's trade and extract yield. Push Chain's GAS / GAS_AND_PAYLOAD inbound execution path has the same structural pattern: it derives `minPCOut` purely from a same-call Uniswap V3 `QuoterV2.quoteExactInputSingle` spot quote, then immediately executes the real swap against that same pool, with no TWAP, no external price feed, and no minimum holding/lock period between quote and execution.

### Finding Description
In `ExecuteInboundGas` [1](#0-0) , once an inbound gas deposit's ballot finalizes, the keeper:
1. Calls `GetSwapQuote` → `QuoterV2.quoteExactInputSingle(prc20, wpc, amount, fee, sqrtPriceLimitX96=0)` [2](#0-1)  — this reads the pool's **current spot price**, unbounded (`SqrtPriceLimitX96: big.NewInt(0)`).
2. Computes `minPCOut = quote * 95 / 100` (flat 5% slippage tolerance) [3](#0-2) .
3. Immediately calls `CallPRC20DepositAutoSwap` → `depositPRC20WithAutoSwap(prc20, amount, target, fee, minPCOut, deadline=0)` [4](#0-3) , executing the real swap in the same pool.

Because both the quote and the real swap read from the *same* pool state, and both happen back-to-back in the same keeper call with no TWAP averaging window and no delay/lock period, an attacker can:
- Submit their own gas-abstraction inbound deposit (fully permissionless — any user can trigger the GAS/GAS_AND_PAYLOAD route by depositing on a source chain).
- Immediately before the ballot-finalization block/tx that will trigger `ExecuteInboundGas`, execute a large swap against the same PRC20/WPC Uniswap V3 pool to skew the spot price in their favor.
- The manipulated spot price is used to compute `quote`/`minPCOut`, and the subsequent real swap executes at essentially the same manipulated price, letting the attacker extract more WPC than the deposited PRC20's fair value from the pool's liquidity.
- Reverse the manipulating trade afterward to restore the price, pocketing the arbitrage profit — the same "manipulate → get favorable execution → unwind → profit" pattern as the Sandclock PoC.

This is the same bug class as `[M-08]`: relying on an AMM spot price with no alternative feed (e.g., TWAP) and no protective delay for a fund-moving computation.

### Impact Explanation
Successful exploitation lets an unprivileged attacker extract value from the WPC/PRC20 liquidity used by the gas-abstraction swap, corrupting gas-fee/token accounting for that inbound and effectively causing unauthorized/mispriced release of protocol- or pool-provided WPC funds beyond what the attacker's deposited PRC20 is worth. This falls under the allowed-impact category of "corruption of PRC20 or native asset accounting, gas fee accounting... token mapping" and potential "unauthorized release... of user or protocol-controlled funds."

### Likelihood Explanation
Feasibility depends on: (a) the PRC20/WPC pool's liquidity depth relative to available capital (thin pools are highly exploitable, matching the original report's low-liquidity Uniswap V3 pool precondition), and (b) the attacker's ability to time a manipulating trade to land in the same block/close proximity to their own inbound's finalization-triggered swap. Since the inbound deposit is user-initiated and ballot finalization timing is largely deterministic once enough UV votes are cast, an attacker controlling their own inbound has meaningful influence over this timing, making the attack practically feasible for at least the smaller/newer token pools that would realistically be used for less-liquid source-chain gas tokens.

### Recommendation
- Do not rely solely on the pool's instantaneous spot price (`quoteExactInputSingle` with `sqrtPriceLimitX96=0`) for `minPCOut`. Use a TWAP-based quote (e.g., Uniswap V3 `observe`) or an external oracle, consistent with the original report's "consider an alternative price feed" recommendation.
- Add sanity bounds/circuit breakers comparing the spot quote against a longer-window reference price and reject/queue the swap if deviation exceeds a safe threshold.
- Consider introducing a minimum delay between quote computation and swap execution (analogous to enforcing `_minLockPeriod > 0`) so same-block manipulation cannot be trivially exploited.

### Proof of Concept
1. Attacker identifies a PRC20/WPC Uniswap V3 pool (as configured via `GetDefaultFeeTierForToken`/`GetUniversalCoreQuoterAddress`) with modest liquidity.
2. Attacker initiates a legitimate gas-abstraction deposit on a source chain for that PRC20-mapped asset, which Universal Validators observe and vote via `MsgVoteInbound`.
3. Just before/at the block where the ballot finalizes (attacker can time this since finalization is a function of validator votes reaching 2/3 threshold, often promptly after attacker's own deposit is observed), attacker swaps a large amount into/out of the WPC/PRC20 pool to skew the spot price favorably for their upcoming PRC20→WPC conversion.
4. `ExecuteInboundGas` runs: `GetSwapQuote` reads the manipulated spot price, computes `minPCOut` from it, and `CallPRC20DepositAutoSwap` executes the swap at the manipulated price, crediting the attacker's UEA with inflated WPC.
5. Attacker reverses the manipulating trade, restoring the pool price and pocketing the extracted value. [1](#0-0) [2](#0-1) [5](#0-4)

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)
}
