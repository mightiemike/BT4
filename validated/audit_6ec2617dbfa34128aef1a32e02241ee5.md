## Finding

### Title
Starknet OS `execute_replace_class` syscall handler omits declared-class validation, allowing state commitment to an undeclared/invalid class hash - (File: crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo)

### Summary
The external report's root cause is that `Pool.mintSynth` accepted an arbitrary `synth` address parameter and used it to mint tokens without verifying that the synth's underlying asset actually matched the pool it was minted from — a missing "does this identifier correspond to what I expect" check that let an attacker substitute one asset context for another. The Starknet-OS analog is the `execute_replace_class` syscall handler, which accepts an arbitrary `class_hash` and writes it into `contract_state_changes` without ever verifying that the class hash corresponds to a class actually declared in state, unlike every other execution path in the sequencer (blockifier VM, Native, and deprecated Cairo0 syscall handlers) which explicitly perform this check.

### Finding Description
In the blockifier (the execution engine used when the sequencer actually builds/validates a block), the `replace_class` syscall is implemented with an explicit declared-class check on all three code paths:
- Deprecated (Cairo0) syscalls: `syscall_handler.state.get_compiled_class(request.class_hash)?` before writing the new class hash. [1](#0-0) 
- Cairo1 VM and Native syscall handlers delegate to `base.replace_class`, and this is confirmed to raise an "is not declared" error for undeclared class hashes. [2](#0-1) [3](#0-2) 

However, the Starknet OS's own Cairo implementation of the same syscall — the code that re-executes the block to produce the STARK proof and drive the final state commitment — does **not** perform this check. The `execute_replace_class` function directly overwrites the contract's `StateEntry.class_hash` with the caller-supplied `class_hash`, with an explicit TODO acknowledging the gap:

```

``` [4](#0-3) 

The deprecated-syscall Cairo path in the OS has the identical omission: [5](#0-4) 

`replace_class` is a standard, unprivileged syscall reachable by any deployed contract from within a normal invoke transaction (e.g. upgradeable-proxy patterns), so the code path is directly reachable from an ordinary transaction sender.

### Impact Explanation
The Starknet OS is the constrained program whose correct execution is what the STARK proof attests to; its Cairo logic is supposed to independently re-derive and verify every state transition rather than trust externally supplied hints. Because `execute_replace_class` accepts any `class_hash` value without checking that it is declared, the OS will happily "prove" a state transition in which a contract's class pointer is set to a class hash that was never declared (or was declared in a way inconsistent with the block/proof inputs). This diverges from the blockifier's semantics (which reject such a transaction with "is not declared") and removes an invariant the proof is supposed to enforce on the committed contract-state Patricia tree. The result is a wrong committed state entry (and hence a potentially wrong/inconsistent committed root relative to what an honest full re-execution via the blockifier would produce), and any contract whose class hash is corrupted this way becomes permanently unusable (freezing all funds/logic reachable only through that contract) since its code no longer resolves to a real, executable class.

### Likelihood Explanation
Exploiting this requires whatever process feeds inputs/hints to the OS (the block/trace being proven) to contain a `REPLACE_CLASS` syscall whose declared-class precondition was not actually enforced — which should not happen if the blockifier is the only path that produces blocks, since it enforces the check. The bug is only latent as long as the blockifier's own enforcement never diverges from what is fed into the OS. It becomes concretely exploitable in any scenario where the OS's re-execution inputs are not perfectly derived/audited against the blockifier's live state, at which point the OS provides no defense-in-depth against an invalid `replace_class`, which is precisely the type of state-root soundness gap OS re-execution is intended to prevent. The explicit TODO in the code confirms this is a currently-known, unresolved gap rather than a theoretical one.

### Recommendation
Add the missing check in `execute_replace_class` (and the deprecated Cairo0 equivalent) to verify that `class_hash` corresponds to a class hash present in the OS's tracked `contract_class_changes` / declared-classes structure before updating `contract_state_changes`, mirroring the blockifier's `get_compiled_class`/`is_declared` checks, e.g.:
```
// Verify the class is declared before replacing.
assert_class_is_declared(class_hash=class_hash);
```
This restores parity between the blockifier and the OS and closes the soundness gap for the `REPLACE_CLASS` syscall.

### Proof of Concept
1. In `crates/blockifier/src/execution/syscalls/syscall_tests/replace_class.rs:17-29`, the blockifier test `undeclared_class_hash` demonstrates that calling `test_replace_class` with an undeclared class hash is correctly rejected ("is not declared") by the blockifier. [2](#0-1) 
2. In the equivalent OS Cairo hint implementation, the same syscall (`execute_replace_class`) writes the new `StateEntry` unconditionally, without any lookup against declared classes, as shown by the TODO comment marking the missing check. [6](#0-5) 
3. Any block/trace input presented to the OS containing a `replace_class(class_hash=X)` syscall for an undeclared `X` will be accepted and committed by the OS's proof generation, whereas the same transaction executed by the blockifier would fail — demonstrating the divergence.

func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

}
