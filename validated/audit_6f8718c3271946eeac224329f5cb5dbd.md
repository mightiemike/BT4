### Title
`prototext.Format`/`proto.Message.String()` never honors `FieldOptions.debug_redact`, so fields marked sensitive by the schema are emitted verbatim in debug output and logs - ([File: encoding/prototext/encode.go])

### Summary
`google.protobuf.FieldOptions.debug_redact` is the schema-level marker whose documented purpose is exactly to tell "debug formats" not to print a field's value because it "contains sensitive credentials" [1](#0-0) . In protobuf-go, this marker is only carried as inert descriptor metadata (`FieldOptions.DebugRedact` / `FieldOptions_DebugRedact_field_number`) and is never read back by the code paths that actually produce "debug format" output.

### Finding Description
The generated `String()` method on every message routes through `protoimpl.X.MessageStringOf`, which is a thin wrapper around `prototext.MarshalOptions{Multiline:false}.Format(m)`: [2](#0-1) 

`prototext`'s `Format`/`Marshal` entry point funnels every field through `marshalMessage` → `marshalField` → `marshalSingular`, which switches purely on `fd.Kind()` (string, bytes, message, etc.) and writes the literal value to the output buffer: [3](#0-2) 

At no point in this call chain — nor anywhere else in `encoding/prototext` or `encoding/protojson` — is `fd.Options().(*descriptorpb.FieldOptions).GetDebugRedact()` (or the equivalent `EnumValueOptions.DebugRedact`) consulted. A repo-wide search for `Redact`/`DebugRedact` outside the descriptor-generated files and the field-option accessor turns up nothing in `internal/impl/**` or `encoding/**`. The field option exists solely as descriptor bookkeeping (`internal/genid/descriptor_gen.go`, `reflect/protoreflect/source_gen.go`'s `SourcePath` formatter for descriptor paths), never as an enforcement point for marshaling.

This is the exact broken-invariant shape of the Airflow report: a "sensitive" flag is defined on a field/connection property, but the rendering/serialization code path that a low-privileged viewer (or the ordinary log pipeline) exercises does not check that flag before emitting the value.

### Impact Explanation
Any Go service built on protobuf-go that (a) defines `debug_redact = true` on a field carrying a credential/secret (following the documented intent of the option) and (b) logs or `%v`/`%s`-formats that message — a default, universally-used debugging idiom (`log.Printf("%v", req)`, `fmt.Println(msg)`, gRPC interceptor logging, etc.) — will leak the "protected" value in plaintext into logs or debug dumps that lower-privileged operators/viewers can read. This is a direct confidentiality loss (CWE-200) reachable on the default, unprivileged "print/log a trusted message" path, with no malicious peer, custom resolver, or attacker-supplied descriptor required — matching the report's C:H/I:N/A:N profile.

### Likelihood Explanation
High, given how ubiquitous `String()`/`%v` logging of proto messages is in Go services, and that the developer has already opted a field into `debug_redact=true` specifically to prevent this outcome, only to have that expectation silently unmet.

### Recommendation
Have `prototext` (and, if a similar hidden-field convention is desired for JSON, `protojson`) check `fd.Options()` for `debug_redact` (and `EnumValueOptions.debug_redact`) in `marshalSingular`/`marshalField`, and substitute a placeholder (e.g. the string used by other protobuf implementations) instead of the literal value when the flag is set. At minimum, document prominently (in `proto.Message.String()`'s and `prototext.Format`'s doc comments) that `debug_redact` is not enforced by protobuf-go, so callers are not misled into believing it provides confidentiality.

### Proof of Concept
```go
package main

import (
	"fmt"

	"google.golang.org/protobuf/proto"
	"google.golang.org/protobuf/types/descriptorpb"
	"google.golang.org/protobuf/reflect/protodesc"
	"google.golang.org/protobuf/reflect/protoreflect"
	"google.golang.org/protobuf/reflect/dynamicpb"
)

func main() {
	// Minimal schema: message Secret { string password = 1 [debug_redact=true]; }
	fdp := &descriptorpb.FileDescriptorProto{
		Name:    proto.String("secret.proto"),
		Syntax:  proto.String("proto3"),
		Package: proto.String("demo"),
		MessageType: []*descriptorpb.DescriptorProto{{
			Name: proto.String("Secret"),
			Field: []*descriptorpb.FieldDescriptorProto{{
				Name:     proto.String("password"),
				Number:   proto.Int32(1),
				Type:     descriptorpb.FieldDescriptorProto_TYPE_STRING.Enum(),
				Label:    descriptorpb.FieldDescriptorProto_LABEL_OPTIONAL.Enum(),
				Options:  &descriptorpb.FieldOptions{DebugRedact: proto.Bool(true)},
			}},
		}},
	}
	fd, err := protodesc.NewFile(fdp, nil)
	if err != nil {
		panic(err)
	}
	md := fd.Messages().Get(0)

	m := dynamicpb.NewMessage(md)
	m.Set(md.Fields().ByName("password"), protoreflect.ValueOfString("hunter2-super-secret"))

	// This is the ordinary "log the request" idiom used throughout Go services.
	fmt.Println(m) // calls proto.Message.String() -> prototext.Format
}
```
Expected (and actual) output shows the field's raw value in the debug/log string despite `debug_redact = true`:
```
password:"hunter2-super-secret"
```
No redaction placeholder is produced, confirming that `debug_redact` is not enforced anywhere in the marshal path.

// marshalMessage marshals the given protoreflect.Message.
func (e encoder) marshalMessage(m protoreflect.Message, inclDelims bool) error {
	messageDesc := m.Descriptor()
	if !flags.ProtoLegacy && messageset.IsMessageSet(messageDesc) {
		return errors.New("no support for proto1 MessageSets")
	}

	if inclDelims {
		e.StartMessage()
		defer e.EndMessage()
	}

	// Handle Any expansion.
	if messageDesc.FullName() == genid.Any_message_fullname {
		if e.marshalAny(m) {
			return nil
		}
		// If unable to expand, continue on to marshal Any as a regular message.
	}

	// Marshal fields.
	var err error
	order.RangeFields(m, order.IndexNameFieldOrder, func(fd protoreflect.FieldDescriptor, v protoreflect.Value) bool {
		if err = e.marshalField(fd.TextName(), v, fd); err != nil {
			return false
		}
		return true
	})
	if err != nil {
		return err
	}

	// Marshal unknown fields.
	if e.opts.EmitUnknown {
		e.marshalUnknown(m.GetUnknown())
	}

	return nil
}

// marshalField marshals the given field with protoreflect.Value.
func (e encoder) marshalField(name string, val protoreflect.Value, fd protoreflect.FieldDescriptor) error {
	switch {
	case fd.IsList():
		return e.marshalList(name, val.List(), fd)
	case fd.IsMap():
		return e.marshalMap(name, val.Map(), fd)
	default:
		e.WriteName(name)
		return e.marshalSingular(val, fd)
	}
}

// marshalSingular marshals the given non-repeated field value. This includes
// all scalar types, enums, messages, and groups.
func (e encoder) marshalSingular(val protoreflect.Value, fd protoreflect.FieldDescriptor) error {
	kind := fd.Kind()
	switch kind {
	case protoreflect.BoolKind:
		e.WriteBool(val.Bool())

	case protoreflect.StringKind:
		s := val.String()
		if !e.opts.allowInvalidUTF8 && strs.EnforceUTF8(fd) && !utf8.ValidString(s) {
			return errors.InvalidUTF8(string(fd.FullName()))
		}
		e.WriteString(s)

	case protoreflect.Int32Kind, protoreflect.Int64Kind,
		protoreflect.Sint32Kind, protoreflect.Sint64Kind,
		protoreflect.Sfixed32Kind, protoreflect.Sfixed64Kind:
		e.WriteInt(val.Int())

	case protoreflect.Uint32Kind, protoreflect.Uint64Kind,
		protoreflect.Fixed32Kind, protoreflect.Fixed64Kind:
		e.WriteUint(val.Uint())

	case protoreflect.FloatKind:
		// Encoder.WriteFloat handles the special numbers NaN and infinites.
		e.WriteFloat(val.Float(), 32)

	case protoreflect.DoubleKind:
		// Encoder.WriteFloat handles the special numbers NaN and infinites.
		e.WriteFloat(val.Float(), 64)

	case protoreflect.BytesKind:
		e.WriteString(string(val.Bytes()))

	case protoreflect.EnumKind:
		num := val.Enum()
		if desc := fd.Enum().Values().ByNumber(num); desc != nil {
			e.WriteLiteral(string(desc.Name()))
		} else {
			// Use numeric value if there is no enum description.
			e.WriteInt(int64(num))
		}

	case protoreflect.MessageKind, protoreflect.GroupKind:
		return e.marshalMessage(val.Message(), true)
