Based on my research, I found a concrete analog in the sequencer's Starknet OS Cairo program that mirrors the exact bug-class pattern from the Gravity Bridge exploit — a validation check that exists in one code path but was never wired into the parallel authoritative path.

### Title
Starknet OS `replace_class` syscall omits the declared-class check present in the Blockifier, allowing state-commitment divergence - ([File: crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo])

### Summary
The Blockifier (the sequencer's native Rust execution engine) enforces that a `replace_class` syscall may only target a **declared** Cairo1 class hash, and reverts the call otherwise. The Starknet OS Cairo program — the code that is actually proven and that produces the committed state root/block hash — implements the same syscall without that check; the check is marked with an explicit `TODO` and never executed. This is structurally identical to the Gravity Bridge bug: "a relevant lookup already existed elsewhere in the codebase... it was just never called in the right place."

### Finding Description
In the Blockifier, `replace_class` explicitly performs a state lookup to confirm the class is declared and is Cairo1 before mutating storage: [1](#0-0) 

The deprecated (Cairo0) syscall path enforces the same rule via `get_compiled_class`: [2](#0-1) 

Tests confirm this is a deliberate, load-bearing check: undeclared class hashes are rejected with `"is not declared"`, and Cairo0→Cairo1 downgrades are rejected too: [3](#0-2) 

However, the Starknet OS Cairo program — which independently re-derives the state transition that becomes the committed root and block hash — implements `execute_replace_class` with **no such check**, and the missing validation is called out in an unresolved `TODO`: [4](#0-3) 

The deprecated (Cairo0) OS syscall path has the identical gap — it reads the current state entry and unconditionally overwrites `class_hash` with the caller-supplied value, without ever calling into a declared-class lookup: [5](#0-4) 

Just as `deployERC20()` on Gravity Bridge accepted an arbitrary attacker string with no validation while a separate, correctly-checked code path existed elsewhere in the same file, here `execute_replace_class` in the Starknet OS accepts an arbitrary `class_hash` felt with no validation, while the semantically-equivalent Blockifier function two files away performs exactly the missing check.

### Impact Explanation
The Starknet OS Cairo program is the ground-truth, proven execution of the block; its state writes are what get folded into the Patricia tries and committed as the block's state root/hash. If a contract invokes `replace_class_syscall` with a class hash that was never declared, the Blockifier (used by the sequencer to build/validate the block) will revert that call, so the resulting state diff never contains the write. But an independent re-execution of the same transaction trace via the OS's Cairo semantics performs the write unconditionally, since it never checks the class is declared. Any place where the OS's accepted semantics for a syscall are broader than the Blockifier's actual (consensus) semantics is a systemic honest-node-divergence / wrong-committed-root risk: the value that ends up in the proven state can differ from what the sequencer's execution engine believed was valid, since the two implementations of the same protocol rule are not kept in sync via a shared check.

### Likelihood Explanation
`replace_class_syscall` is callable by any already-deployed Cairo1 (or Cairo0, via the deprecated path) contract — no privileged, proposer, or operator role is required, only a normal transaction that triggers execution of a contract that calls the syscall with an attacker-chosen felt as the class hash argument. The gap is explicitly flagged by the author as a known-missing check (`TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.`), confirming the omission is intentional/known but unresolved rather than a modeling assumption.

### Recommendation
Add the missing declared-class validation to `execute_replace_class` in both `syscall_impls.cairo` and `deprecated_execute_syscalls.cairo`, mirroring the check already implemented in `crates/blockifier/src/execution/syscalls/syscall_base.rs::replace_class` (verify the class hash is declared and is Cairo1 before performing the `dict_update`). Add a regression/consistency test that runs the same `replace_class` scenario through both the Blockifier and the OS Cairo program and asserts identical accept/reject behavior for undeclared class hashes, to prevent this class of Blockifier/OS semantic drift going forward.

### Proof of Concept
1. Deploy any contract exposing a `replace_class_syscall` call (e.g. the `fuzz_revert` scenario contract already in the test fixtures uses `Scenario::ReplaceClass`): [6](#0-5) 
2. Invoke it with an arbitrary, never-declared `class_hash` felt (e.g. `0xdeadbeef`).
3. Under Blockifier execution, this reverts with `"is not declared"` as shown by the existing test `undeclared_class_hash`: [7](#0-6) 
4. Trace the same syscall through `execute_replace_class` in the OS Cairo program: it performs `dict_update` unconditionally on `contract_state_changes` with the attacker-supplied `class_hash`, with no equivalent guard, per: [8](#0-7) 
This demonstrates the two "ground truth" implementations of the same syscall diverge for the identical malicious input, which is the exact class of bug ("relevant lookup exists elsewhere, but not called in the right function") that caused the Gravity Bridge registry-poisoning exploit.

    pub fn replace_class(&mut self, class_hash: ClassHash) -> SyscallResult<()> {
        // Ensure the class is declared (by reading it), and of type V1.
        let compiled_class = self.state.get_compiled_class(class_hash)?;

        if !is_cairo1(&compiled_class) {
            return Err(SyscallExecutionError::ForbiddenClassReplacement { class_hash });
        }
        self.state.set_class_hash_at(self.call.storage_address, class_hash)?;
        Ok(())
    }

// Replaces the class.
func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
