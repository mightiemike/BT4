### Title
Sandwiched auto-swap deposits: attacker-manipulable spot quote used both to compute and to "protect" `minPCOut`, letting a front-run drain value from GAS/GAS_AND_PAYLOAD deposits — ([File: x/uexecutor/keeper/evm.go], [File: x/uexecutor/keeper/execute_inbound_gas.go], [File: x/uexecutor/keeper/execute_inbound_gas_and_payload.go])

### Summary
For `GAS` and `GAS_AND_PAYLOAD` inbounds, the executor auto-swaps the bridged PRC20 for WPC on a UniswapV3-style pool by fetching a spot quote from `QuoterV2.quoteExactInputSingle` and deriving `minPCOut` as 95% of that same quote, then immediately executing the swap with that bound. Because the quote is read from the live, attacker-manipulable pool state at execution time rather than from a value the user committed to beforehand, the "slippage protection" only bounds *further* movement after the (possibly already-manipulated) quote — it does not protect against the quote itself being manipulated. This mirrors the Sherlock H-4 pattern: a slippage/minimum check exists, but it is computed from an amount that can already be skewed by a manipulator, so honest users still lose funds up to the check's tolerance while appearing "protected."

### Finding Description
The auto-swap deposit path is:
```
fee   := GetDefaultFeeTierForToken(prc20)
quote := GetSwapQuote(quoterAddr, prc20, wpc, fee, amount)   // QuoterV2.quoteExactInputSingle, spot price
minPCOut := quote * 95 / 100
CallPRC20DepositAutoSwap(prc20, ueaAddr, amount, fee, minPCOut)
``` [1](#0-0) [2](#0-1) 

`GetSwapQuote` is a read-only call into the live UniswapV3 quoter contract reflecting the pool's current tick/liquidity at the moment of execution: [3](#0-2) 

The inbound is executed synchronously the moment quorum (2/3+ UV votes) is reached on `MsgVoteInbound`, and both `GetSwapQuote` and the subsequent `CallPRC20DepositAutoSwap` run within the same keeper call/block — an attacker cannot interleave a transaction *between* the quote and the swap. However, nothing prevents an attacker from submitting an ordinary swap on the same PRC20/WPC UniswapV3 pool in a transaction that lands immediately before the quorum-finalizing `MsgVoteInbound` (the identity and approximate timing of the quorum-reaching vote is observable in the mempool, since it is just the Nth vote on a publicly known `UniversalTx` key). That prior swap moves the pool price; the subsequent `GetSwapQuote` call then returns a quote based on the manipulated price, and `minPCOut` is computed as 95% of that already-bad number. The deposit-swap then executes at the manipulated rate, crediting the user's UEA with far fewer WPC/PRC20 than an honest market would have produced, while the on-chain "slippage check" passes trivially because it was derived from the same corrupted price. The attacker can then reverse their manipulating swap (back-run) to recover their capital plus the value extracted from the victim's deposit.

This is structurally the same defect class as H-4: a minimum-output guard exists, but it is computed from a value that the attacker controls (there, LP share ratio computed from post-manipulation balanced reserves across fee tiers; here, `minPCOut` computed from a post-manipulation spot quote), so the guard cannot actually prevent the loss it is meant to prevent.

The same `GetSwapQuote`/`minPCOut` pattern is reused for the `GAS_AND_PAYLOAD` deposit-autoswap helper, so the flaw is not isolated to one tx type: [4](#0-3) 

### Impact Explanation
Every `GAS` and `GAS_AND_PAYLOAD` inbound routed through the auto-swap path is exposed to value loss bounded only by the pool's manipulable price impact plus the 5% buffer, with no cap tied to the user's actual intent (the user never supplied their own minimum-output parameter — the bound is entirely protocol-computed and manipulable). Because inbound execution is deterministic and triggered by publicly observable quorum-reaching votes, this is repeatable against every gas-abstraction deposit that uses this swap path, resulting in unbounded, unauthorized value extraction from ordinary users' bridged deposits — a "stealing/draining of user funds" impact directly in scope.

### Likelihood Explanation
The attacker needs only: (1) an unprivileged EOA capable of swapping on the PRC20/WPC pool referenced by `defaultFeeTier`, and (2) visibility into the mempool to time a swap immediately ahead of the quorum-finalizing `MsgVoteInbound`. No validator, relayer, or TSS collusion is required — this is a standard sandwich against a same-block, spot-price-derived slippage bound, a well-known and highly practical MEV pattern. Because inbound execution timing/keys are derivable from public UV voting activity, an attacker can predict and front-run the exact block/transaction that will trigger the swap.

### Recommendation
Do not derive the slippage protection from a spot quote fetched in the same execution path as the swap. Instead:
- Bind `minPCOut` (or an acceptable slippage percentage) to a value fixed at the time the inbound was *observed/voted*, not recomputed from live pool state at execution time, or
- Source the reference price from a manipulation-resistant mechanism (e.g., a TWAP over a meaningful window) rather than `QuoterV2.quoteExactInputSingle`'s instantaneous quote, or
- Allow/require the original depositor to specify their own acceptable minimum output on the source chain and carry it through the `Inbound` payload, so the bound reflects user intent rather than a value the protocol (and thus an attacker) can shift in the same block.

### Proof of Concept
1. Attacker monitors the mempool/UV vote stream and identifies that the next `MsgVoteInbound` for a given `UniversalTx` (GAS or GAS_AND_PAYLOAD inbound with a known synthetic `Amount`) will reach the 2/3+ quorum threshold.
2. Immediately before that vote lands (same block, prior tx, or preceding block), attacker submits a large swap on the PRC20/WPC UniswapV3 pool at `defaultFeeTier[prc20]` to push the PRC20 price down relative to WPC.
3. The quorum vote lands, triggering `ExecuteInboundGas` / `ExecuteInboundGasAndPayload`, which calls `GetSwapQuote` — this now returns a depressed `quote` reflecting the attacker's manipulation. [5](#0-4) 
4. `minPCOut := quote * 95 / 100` is computed from this depressed quote and passed to `CallPRC20DepositAutoSwap`, which executes the deposit + swap at the manipulated rate — the check trivially passes because it was self-referentially derived from the manipulated price. [6](#0-5) 
5. The user's UEA receives materially less WPC than it would have at the pre-manipulation price.
6. Attacker reverses the initial swap (back-run) to restore the pool price and capture the value difference, profiting at the depositing user's expense.

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil

// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)
