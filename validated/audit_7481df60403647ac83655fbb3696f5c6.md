### Title
Slippage guard derived from a same-block Uniswap V3 spot quote allows sandwich-attack value extraction on gas/fee auto-swaps - (File: x/uexecutor/keeper/execute_inbound_gas.go, x/uexecutor/keeper/execute_inbound_gas_and_payload.go, x/uexecutor/keeper/outbound.go)

### Summary
`IdleCDO.harvest()` computed a "minimum buy amount" instead of a "minimum price," which let an attacker manipulate Uniswap reserves and still satisfy the check while profiting via slippage. Push Chain's `uexecutor` module reproduces the same anti-pattern for every PRC20→PC auto-swap it performs on behalf of users: it fetches a spot quote from the on-chain Uniswap V3 `QuoterV2` and derives `minPCOut` as a fixed 95% of that just-read quote, then immediately executes the swap. Because the "minimum" is itself computed from the manipulable pool state at execution time rather than from an independent/robust price reference, an attacker who moves the pool price immediately before the swap executes can force both the quote and the enforced floor down together, extracting value from the swap while nominally satisfying slippage protection.

### Finding Description
`GetSwapQuote` calls `QuoterV2.quoteExactInputSingle` with `SqrtPriceLimitX96: big.NewInt(0)` (no price bound) to get a spot-price-based amount for swapping PRC20 → WPC: [1](#0-0) 

Every call site that performs an auto-swap derives its floor purely from that just-fetched quote, using a fixed 5% tolerance: [2](#0-1) [3](#0-2) [4](#0-3) 

The quote and the swap execution (`CallPRC20DepositAutoSwap` / `CallUniversalCoreRefundUnusedGas`, calling `depositPRC20WithAutoSwap` / `refundUnusedGas` on `UniversalCore`) both hit the same on-chain AMM pool, and the "minimum" enforced is a percentage of the pool's own instantaneous state rather than an attacker-independent reference price: [5](#0-4) 

This is architecturally identical to the `IdleCDO.harvest()` flaw: the guard is a "minimum buy amount" computed from data the attacker can influence just before the protected action executes, not a fixed/independent minimum price. Any unprivileged user can submit ordinary swap transactions against this Uniswap V3 pool (deployed via `UniversalCore.initialize(wpc_, uniswapV3Factory_, uniswapV3SwapRouter_, uniswapV3Quoter_)`), since the pool is a standard permissionless AMM: [6](#0-5) 

An attacker can: (1) submit a large swap against the PRC20/WPC pool immediately before the block/tx in which the module's inbound-gas or refund auto-swap executes (this can be timed via mempool observation of the validator votes that finalize the triggering inbound/outbound ballot), pushing the PRC20→WPC price down; (2) the module then reads the depressed spot price via `GetSwapQuote` and computes `minPCOut` as 95% of that already-depressed value — the guard offers no protection because it inherits the manipulation; (3) the module's swap executes at the manipulated price, causing the recipient UEA (or gas-refund recipient) to receive fewer WPC/PC tokens than fair value; (4) the attacker reverses their manipulation swap in a following transaction, extracting the difference as profit funded by the value lost from the protocol-initiated swap.

### Impact Explanation
This corrupts gas-abstraction, GAS_AND_PAYLOAD deposit, and gas-refund accounting: the amount of PC ultimately credited to a user's UEA (or the amount refunded from `applyGasRefund`) can be made materially lower than fair value, with the shortfall captured by the attacker. This is a permanent, unrecoverable loss of value for the inbound depositor / refund recipient, reachable purely through unprivileged use of a public AMM pool with no validator, relayer, or admin cooperation needed — matching the in-scope "permanent loss ... of user or protocol-controlled funds" and "corruption of ... gas fee accounting, refund accounting" impact categories.

### Likelihood Explanation
Likelihood depends on the depth/liquidity of the specific PRC20/WPC pool and on the attacker's ability to time a transaction immediately around the module-triggered swap (e.g., by observing the third/finalizing validator vote in the mempool before ballot execution, or via same-block ordering around EndBlocker-triggered execution). Because inbound gas-swap execution and gas refunds are frequent, automatic, unprivileged-triggerable flows (any user's bridged deposit or outbound triggers one), and the guard is fully derived from manipulable state read in the same transaction context as the protected swap, this is a realistic and repeatable attack path rather than a theoretical one, though actual profitability scales with pool depth and gas costs of the sandwich.

### Recommendation
Do not derive `minPCOut` solely from a spot quote fetched immediately before the swap. Instead: enforce a minimum acceptable *price* (e.g., an oracle-derived or TWAP-based reference price, or a configured floor price per token pair) that is independent of the instantaneous pool state read at execution time; alternatively, use Uniswap V3's TWAP oracle (`observe`) over a meaningful window instead of `quoteExactInputSingle`'s spot value, and/or bound the maximum single-block price deviation allowed before rejecting the auto-swap and falling back to a non-swap deposit path.

### Proof of Concept
1. Attacker monitors the mempool/finalizing votes for an inbound `GAS`/`GAS_AND_PAYLOAD` transfer that will trigger `ExecuteInboundGas` / `gasAndPayloadDepositAutoSwap`, or an outbound whose gas refund will trigger `applyGasRefund`.
2. Immediately before that vote/observation lands, attacker submits a large swap into the same PRC20/WPC Uniswap V3 pool, depressing the PRC20-denominated price of WPC.
3. The module calls `GetSwapQuote` (`x/uexecutor/keeper/evm.go:502-538`), which returns the now-depressed quote; `minPCOut` is computed as 95% of that depressed value (`execute_inbound_gas.go:142-146`).
4. `CallPRC20DepositAutoSwap` executes at the manipulated price, crediting the user's UEA with less WPC than fair value while still satisfying `minPCOut`.
5. Attacker reverses their initial swap, restoring the pool price and realizing the extracted value as profit.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)
}
