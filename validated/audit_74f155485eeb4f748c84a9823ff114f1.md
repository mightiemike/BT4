## Vulnerability Analog Found

### Title
Gasless `MsgExecutePayload` admission allows unprivileged, risk-free, unbounded spam of EVM-executing transactions - (File: `app/txpolicy/gasless.go`, `app/ante/fee.go`, `app/ante/account_init_decorator.go`, `x/uexecutor/keeper/msg_execute_payload.go`)

### Summary
The external report's core theme — "no penalty/cost barrier enables risk-free spam and grieving" — has a direct analog in Push Chain's gasless-transaction admission path. `MsgExecutePayload` is whitelisted as gasless and callable by *any unprivileged account* (unlike the other gasless messages, which require `IsBondedUniversalValidator`). Combined with `AccountInitDecorator`'s free account creation and `DeductFeeDecorator`/`MinGasPriceDecorator` skipping fee/min-gas-price checks for any gasless tx, an attacker can submit unlimited zero-fee transactions that trigger real EVM execution (UEA factory lookups, auto-deploy, EVM calls) at zero cost and zero risk.

### Finding Description
`IsGaslessTx` in [1](#0-0)  whitelists `MsgExecutePayload` alongside the UV-only vote messages, but per the module README, `MsgExecutePayload` is explicitly "any user, gasless" [2](#0-1) , unlike `MsgVoteInbound`/`MsgVoteOutbound`/`MsgVoteChainMeta` which are gated by `IsBondedUniversalValidator` in the msg server [3](#0-2) .

For any gasless tx:
- `MinGasPriceDecorator` skips the fee-market minimum-fee check entirely.
- `DeductFeeDecorator` skips fee deduction outright [4](#0-3) .
- `AccountInitDecorator` auto-creates a brand-new on-chain account mid-pipeline for any never-before-seen signer on a gasless tx, bypassing the ordinary account-creation cost [5](#0-4) .

`MsgExecutePayload.ValidateBasic()` performs only structural checks (non-nil fields, valid hex, well-formed `UniversalAccountId`/`UniversalPayload`) — it does **not** require the signer to have any relationship to the `UniversalAccountId.Owner`, and does not require any stake, deposit, or bond [6](#0-5) . This is by design (`Signer != Owner` binding lives in the UEA contract) per the module README [7](#0-6) , but the same "contract-only binding" design means the Cosmos-level admission path performs real EVM work — a factory address computation and (when the target address happens to hold a balance) an `DeployUEAV2` auto-deploy — before any cryptographic authorization is checked [8](#0-7) .

Because there is no per-signer cost, no bonded/allowlisted-sender requirement, and no penalty for repeated failed/invalid submissions (mirroring the external report's "zero-cost, risk-free" spam vectors), an attacker can:
1. Generate an unbounded number of fresh keypairs.
2. For each, submit a `MsgExecutePayload` (gasless) — `AccountInitDecorator` creates the account and admits the tx for free.
3. Repeat indefinitely from existing initialized accounts too, since gasless fee-skipping is not a one-time bootstrap allowance — it applies to every tx classified gasless, forever.

This lets an unprivileged external attacker flood the mempool/block space with real EVM-executing transactions (factory calls, auto-deploys) that consume node CPU/IO and chain storage (new `BaseAccount`s, `UniversalTx`-adjacent state where applicable) without ever paying a transaction fee or facing any penalty.

### Impact Explanation
This is a denial-of-service / resource-exhaustion vector reachable by any unprivileged, unfunded attacker, matching the "denial of service only when it is not network-level and is reachable without privileged control" allowed-impact category. It also degrades gasless UX for legitimate UEA users (the intended beneficiaries of the gasless allowlist) by competing for the same fee-free admission slot with zero-cost attacker spam, and permanently bloats on-chain account state with attacker-controlled zero-balance accounts.

### Likelihood Explanation
High. No special privilege, stake, deposit, or prior relationship to any UEA is required — only the ability to sign a well-formed but semantically bogus `MsgExecutePayload` (arbitrary `UniversalAccountId`, syntactically valid `VerificationData` hex, no funds needed for the fee-skipped happy path). The attack requires no on-chain balance and costs nothing to repeat.

### Recommendation
- Rate-limit or require a minimal anti-spam cost (e.g., per-signer or per-`UniversalAccountId` throttling, small refundable bond, or gas-price floor) even for gasless `MsgExecutePayload` submissions.
- Do not treat `MsgExecutePayload` identically to the UV-only gasless messages in `IsGaslessTx`; consider a distinct, more conservative gasless policy (e.g., cap free EVM work per block per signer, or require verification-data validity to be checked before any factory/auto-deploy EVM call is attempted).
- Reconsider `AccountInitDecorator` unconditionally creating a fresh account for any never-seen signer on any gasless tx — this effectively removes the Cosmos SDK's built-in account-creation cost as an anti-Sybil mechanism.

### Proof of Concept
1. Generate N fresh keypairs (no funding required).
2. For each keypair, sign a `MsgExecutePayload` with an arbitrary/garbage `UniversalAccountId` (structurally valid) and syntactically valid hex `VerificationData`.
3. Broadcast each as its own tx. `IsGaslessTx` returns true (message type whitelisted) → `MinGasPriceDecorator`/`DeductFeeDecorator` skip fee logic → `AccountInitDecorator` creates the account for free and short-circuits signature verification against the fresh `account_number=0,sequence=0`.
4. The keeper's `ExecutePayload` runs the factory-address lookup (and, if the target happens to carry a balance, an auto-deploy) before verification-data checking fails deep inside the EVM call — real state reads/writes and EVM overhead per tx, at zero fee, unbounded in count.

```go
func IsGaslessTx(tx sdk.Tx) bool {
	var (
		// GaslessMsgTypes defines the message types that are allowed in gasless transactions
		GaslessMsgTypes = []string{
			sdk.MsgTypeURL(&uexecutortypes.MsgMigrateUEA{}),
			sdk.MsgTypeURL(&uexecutortypes.MsgExecutePayload{}),
			sdk.MsgTypeURL(&uexecutortypes.MsgVoteInbound{}),
			sdk.MsgTypeURL(&uexecutortypes.MsgVoteOutbound{}),
			sdk.MsgTypeURL(&utsstypes.MsgVoteTssKeyProcess{}),
			sdk.MsgTypeURL(&utsstypes.MsgVoteFundMigration{}),
			sdk.MsgTypeURL(&uexecutortypes.MsgVoteChainMeta{}),
		}
	)

	msgs := tx.GetMsgs()
	if len(msgs) == 0 {
		return false
	}

	for _, msg := range msgs {
		switch m := msg.(type) {
		case *authz.MsgExec:
			// Only gasless if ALL inner messages are allowed
			for _, innerMsg := range m.Msgs {
				if !slices.Contains(GaslessMsgTypes, innerMsg.TypeUrl) {
					return false
				}
			}
		default:
			if !slices.Contains(GaslessMsgTypes, sdk.MsgTypeURL(msg)) {
				return false
			}
		}
	}
	return true
}
```

```go
func (msg *MsgExecutePayload) ValidateBasic() error {
	// Validate signer
	if _, err := sdk.AccAddressFromBech32(msg.Signer); err != nil {
		return errors.Wrap(err, "invalid signer address")
	}

	// Validate universalAccountId
	if msg.UniversalAccountId == nil {
		return errors.Wrap(sdkerrors.ErrInvalidRequest, "universal account cannot be nil")
	}

	// Validate universal payload
	if msg.UniversalPayload == nil {
		return errors.Wrap(sdkerrors.ErrInvalidRequest, "universal payload cannot be nil")
	}

	// Validate verificationData
	if len(msg.VerificationData) == 0 {
		return errors.Wrap(sdkerrors.ErrInvalidRequest, "verificationData cannot be empty")
	}
	if _, err := hex.DecodeString(strings.TrimPrefix(msg.VerificationData, "0x")); err != nil {
		return errors.Wrap(sdkerrors.ErrInvalidRequest, "invalid verificationData hex")
	}

	// Validate universalAccountId structure
	if err := msg.UniversalAccountId.ValidateBasic(); err != nil {
		return errors.Wrap(err, "invalid universalAccountId")
	}

	// Validate universal payload structure
	if err := msg.UniversalPayload.ValidateBasic(); err != nil {
		return errors.Wrap(err, "invalid universal payload")
	}

	return nil
}
```

```markdown
### Authorization model for `MsgExecutePayload` (contract-only binding)

`MsgExecutePayload` follows a **contract-only binding** authorization model. The Cosmos signer of the message and the owner of the target Universal Account are intentionally distinct roles:

- **`Signer`** identifies the Cosmos transaction signer — the party that delivers the owner's pre-authorized payload to Push Chain. `MsgExecutePayload` is a gasless message type (see `app/txpolicy/gasless.go`), so the signer pays no Cosmos transaction fee. Any account may submit the message.
- **`UniversalAccountId.Owner`** identifies the UEA whose pre-authorized payload is being executed. The actual EVM execution gas is deducted from this UEA;s balance (`DeductGasFeesFromReceipt`), not from the signer.

**The chain module deliberately does not enforce `Signer == EVM(Owner)`.** If it did, third-party delivery of owner-signed payloads would be impossible — every owner would have to submit their own Cosmos transactions even though the chain charges them no Cosmos fee for doing so, defeating the cross-chain UX promise of letting an external account act on Push Chain through delivered payloads.
```

```go
func (k Keeper) ExecutePayload(ctx context.Context, evmFrom common.Address, universalAccountId *types.UniversalAccountId, universalPayload *types.UniversalPayload, verificationData string) error {
	sdkCtx := sdk.UnwrapSDKContext(ctx)

	// Get Caip2Identifier for the universal account
	caip2Identifier := universalAccountId.GetCAIP2()

	k.Logger().Info("execute payload",
		"from", evmFrom.Hex(),
		"chain", caip2Identifier,
		"owner", universalAccountId.Owner,
	)

	// Step 1: Validate payload and verificationData early (fast-fail before EVM work)
	if _, err := types.NewAbiUniversalPayload(universalPayload); err != nil {
		return errors.Wrapf(err, "invalid universal payload")
	}

	verificationDataVal, err := utils.HexToBytes(verificationData)
	if err != nil {
		return errors.Wrapf(err, "invalid verificationData format")
	}

	chainConfig, err := k.uregistryKeeper.GetChainConfig(sdkCtx, caip2Identifier)
	if err != nil {
		return errors.Wrapf(err, "failed to get chain config for chain %s", caip2Identifier)
	}

	if !chainConfig.Enabled.IsInboundEnabled {
		k.Logger().Warn("execute payload rejected: chain inbound disabled", "chain", caip2Identifier)
		return fmt.Errorf("inbound is disabled for chain %s", caip2Identifier)
	}

	factoryAddress := common.HexToAddress(types.FACTORY_PROXY_ADDRESS_HEX)

	// Step 2: Compute smart account address
	// Calling factory contract to compute the UEA address
	ueaAddr, isDeployed, err := k.CallFactoryToGetUEAAddressForOrigin(sdkCtx, evmFrom, factoryAddress, universalAccountId)
	if err != nil {
		return err
	}

	if !isDeployed {
		// only deploy if the UEA address has funds and not deployed yet
		ueaAccAddr := sdk.AccAddress(ueaAddr.Bytes())
		balance := k.bankKeeper.GetBalance(sdkCtx, ueaAccAddr, pchaintypes.BaseDenom)
		if balance.Amount.Sign() == 0 {
			k.Logger().Warn("execute payload rejected: UEA not deployed and has no balance",
				"chain", caip2Identifier,
				"owner", universalAccountId.Owner,
			)
			return fmt.Errorf("UEA is not deployed")
		}

		k.Logger().Info("auto-deploying UEA before execute (pre-funded address)",
			"uea", ueaAddr.Hex(),
			"balance", balance.Amount.String(),
			"chain", caip2Identifier,
			"owner", universalAccountId.Owner,
		)
		if _, err := k.DeployUEAV2(ctx, evmFrom, universalAccountId); err != nil {
			return errors.Wrapf(err, "failed to auto-deploy pre-funded UEA")
		}
	}
```
