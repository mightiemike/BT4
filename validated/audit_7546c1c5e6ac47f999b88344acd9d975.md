### Title
Manipulatable Uniswap V3 spot-price quote used as auto-swap slippage floor for gas-abstraction inbound deposits enables sandwich extraction of bridged funds - (File: x/uexecutor/keeper/execute_inbound_gas.go, x/uexecutor/keeper/execute_inbound_gas_and_payload.go, x/uexecutor/keeper/evm.go)

### Summary
When a `GAS` or `GAS_AND_PAYLOAD` inbound is finalized, `ExecuteInboundGas`/`gasAndPayloadDepositAutoSwap` compute the minimum acceptable PC output for the module's auto-swap by calling Uniswap V3 `QuoterV2.quoteExactInputSingle` (a spot-price read) and then applying a fixed 5% slippage tolerance, exactly mirroring the reported pattern of deriving `_getAmountOutMin()`/`minPCOut` from manipulable AMM state instead of a robust price source.

### Finding Description
`k.GetSwapQuote` calls `quoteExactInputSingle` on the Uniswap V3 QuoterV2 contract deployed for the WPC/PRC20 pair to get `amountOut` for the bridged gas-token amount: [1](#0-0) 

That quote is then discounted by a hardcoded 5% to derive `minPCOut`, which is passed as the slippage floor to the real on-chain swap executed via `depositPRC20WithAutoSwap`: [2](#0-1) 

The identical pattern exists for `GAS_AND_PAYLOAD` inbounds: [3](#0-2) 

`quoteExactInputSingle` reads the pool's current `sqrtPriceX96`/reserves at call time — it is a spot price, not a TWAP or external oracle. Because the quote-then-swap sequence (`GetSwapQuote` → `CallPRC20DepositAutoSwap`) executes back-to-back inside normal, deterministic transaction processing with no external price validation, any unprivileged user can move the WPC/PRC20 pool price with an ordinary swap transaction landing in the same or an immediately preceding block, then let (or trigger) the module's auto-swap execute against that manipulated price. A fixed percentage slippage bound computed off a manipulated spot price provides no real protection — this is precisely the "manipulatable oracle breaking slippage protection" bug class from the external report, transplanted onto Push Chain's own on-chain AMM used for gas-token-to-PC conversion during bridging.

### Impact Explanation
An attacker can sandwich the module's `depositPRC20WithAutoSwap` call: push the pool price against PRC20 immediately before the module swap executes (so `quote`/`minPCOut` are computed and satisfied at a depressed rate), letting the deposited gas token convert into far less PC than fair value, then reverse the price move afterward to capture the extracted value. This directly corrupts PRC20/native-asset accounting for a legitimate bridging deposit and results in the depositor's UEA receiving degraded PC — a fund-draining outcome reachable purely through ordinary swap and bridging transactions, without any privileged role.

### Likelihood Explanation
Likelihood is Medium-to-High: no special access is required — an attacker only needs capital to move the specific WPC/PRC20 pool (likely to have limited initial liquidity) and to time an ordinary swap transaction around the deterministic execution of `ExecuteInboundGas`/`gasAndPayloadDepositAutoSwap`, which is public, predictable behavior tied to inbound vote finalization.

### Recommendation
Do not derive `minPCOut` from a live spot-price quote on the same pool that is about to be swapped against. Use a manipulation-resistant reference (e.g., TWAP over a sufficient window, or an external price oracle/chain-meta-style validator-attested price) to bound acceptable output, and/or cap the maximum single-block price impact allowed for the auto-swap, rather than relying on a fixed percentage applied to an instantaneous `QuoterV2` quote.

### Proof of Concept
1. Attacker identifies (or creates) a `GAS`/`GAS_AND_PAYLOAD` inbound that will be finalized and processed by `ExecuteInboundGas`.
2. Immediately before/at that block, attacker submits a large swap on the WPC/PRC20 Uniswap V3 pool that depresses the PRC20→WPC price.
3. `GetSwapQuote` (`x/uexecutor/keeper/evm.go:500-538`) returns a depressed `amountOut`; `minPCOut = quote * 95/100` (`x/uexecutor/keeper/execute_inbound_gas.go:142-146`) is computed from this manipulated value.
4. `CallPRC20DepositAutoSwap` executes the real swap against the still-depressed pool, satisfying the deflated `minPCOut` easily while delivering far less PC to the UEA than fair value.
5. Attacker reverses their initial swap, extracting the value difference — a classic sandwich enabled by using an unprotected spot-price AMM quote as the slippage bound.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}
