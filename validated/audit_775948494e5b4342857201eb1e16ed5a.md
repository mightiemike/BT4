### SVM event listener accepts `Program data:` logs from any program, allowing forged outbound observations - (`universalClient/chains/svm/event_listener.go`)

### Summary
The SVM event listener queries Solana transactions that reference the configured `gatewayAddress`, but it then parses every `Program data:` log in those transactions using only the first 8-byte discriminator to decide the event type. [1](#0-0) [2](#0-1)  `parseOutboundObservationEvent` builds an `EventTypeOutbound` record from the log payload without verifying which program emitted the log. [3](#0-2)  The resulting event is stored via `InsertEventIfNotExists`. [4](#0-3)  Because all honest universal validators run the same parser, a single attacker transaction can make the whole honest set converge on a forged outbound observation.

### Finding Description
`processSlotRange` fetches signatures for the configured gateway address and `processSignatureBatch` walks `tx.Meta.LogMessages`. [5](#0-4)  For each log line it calls `determineEventType`, which only checks the `Program data:` prefix and the 8-byte discriminator against the chain-config table. [2](#0-1)  `ParseEvent` then routes purely by that `eventType` string. [6](#0-5)  There is no check that the log was emitted by the real gateway program, nor that the transaction succeeded. [7](#0-6)  An attacker can therefore reference the gateway program id as a read-only account in a transaction to an attacker-controlled program, have that program emit a `Program data:` log whose first 8 bytes match `finalize_universal_tx`, `revert_universal_tx`, or `funds_rescued`, and supply arbitrary `sub_tx_id` / `universal_tx_id` / `gas_used` values.

### Impact Explanation
The bogus log is turned into a pending `EventTypeOutbound` record with attacker-chosen `TxID` and `UniversalTxID`. [8](#0-7)  Once stored, it enters the standard confirmation and voting pipeline and can be accepted as canonical by honest validators because they all parse the same on-chain log with the same unvalidated logic. [5](#0-4)  This corrupts the outbound / UniversalTx state for the targeted `UniversalTxID` and can cause incorrect finalization, revert, or funds-rescued status, leading to unauthorized release, refund, or accounting corruption depending on the downstream finalization logic.

### Likelihood Explanation
High for an attacker who can deploy a Solana program. The only prerequisites are: (1) submit a transaction that references the configured `gatewayAddress` (any account can be included read-only), and (2) know the configured 8-byte event discriminators, which are part of the public chain config / gateway program IDL. The attack does not require malicious nodes, validators, relayers, or governance; it is reachable from ordinary Solana transaction submission.

### Recommendation
- Track the active program from `Program <addr> invoke [N]` / `Program <addr> success` / `Program <addr> fail` log lines and only accept `Program data:` entries when the active program equals `gatewayAddress`.
- Skip failed transactions by checking `tx.Meta.Err` before parsing logs.
- Pass the expected gateway program id into `ParseEvent` / `parseOutboundObservationEvent` and reject any log whose emitting program does not match.

### Proof of Concept
1. Deploy a Solana program with an instruction that:
   - includes the configured `gatewayAddress` as a read-only account in its account list, and
   - calls `sol_log_data` with a payload whose first 8 bytes equal the configured `finalize_universal_tx` discriminator, followed by a forged 32-byte `sub_tx_id`, a forged 32-byte `universal_tx_id`, and any valid `gas_used` value.
2. Submit and confirm the transaction.
3. `GetSignaturesForAddress(gatewayAddress)` returns the transaction because the gateway account is referenced. [1](#0-0) 
4. The UV fetches the transaction, `determineEventType` matches the discriminator, `parseOutboundObservationEvent` creates an `EventTypeOutbound` event with the forged IDs, and `InsertEventIfNotExists` persists it. [5](#0-4) [3](#0-2) [4](#0-3) 
5. Every other honest UV does the same, so the forged observation reaches quorum and corrupts the canonical outbound/UTX record.

```go
// determineEventType determines the event type based on the log discriminator
func (el *EventListener) determineEventType(log string) string {
	if !strings.HasPrefix(log, "Program data: ") {
		return ""
	}

	eventData := strings.TrimPrefix(log, "Program data: ")
	decoded, err := base64.StdEncoding.DecodeString(eventData)
	if err != nil {
		return ""
	}

	if len(decoded) < 8 {
		return ""
	}

	discriminator := strings.ToLower(hex.EncodeToString(decoded[:8]))

	// Look up event type from discriminator map
	eventType, ok := el.discriminatorToEventType[discriminator]
	if !ok {
		return ""
	}

	return eventType
```

```go
func parseOutboundObservationEvent(log string, signature string, slot uint64, logIndex uint, chainID string, logger zerolog.Logger) *store.Event {
	if !strings.HasPrefix(log, "Program data: ") {
		return nil
	}

	eventData := strings.TrimPrefix(log, "Program data: ")
	decoded, err := base64.StdEncoding.DecodeString(eventData)
	if err != nil {
		return nil
	}

	// Minimum: 8 disc + 32 sub_tx_id + 32 universal_tx_id + 8 gas_fee + 8 gas_used
	// + 8 gas_to_refund + 1 ata_created = 97 bytes.
	if len(decoded) < 97 {
		logger.Warn().
			Int("data_len", len(decoded)).
			Msg("data too short for outboundObservation event; need at least 97 bytes")
		return nil
	}

	// Create EventID in format: signature:LogIndex
	eventID := fmt.Sprintf("%s:%d", signature, logIndex)

	logger.Debug().
		Str("event_id", eventID).
		Str("signature", signature).
		Uint("log_index", logIndex).
		Uint64("slot", slot).
		Msg("processing outboundObservation event")

	// Skip discriminator (8 bytes)
	offset := 8

	// Extract txID (32 bytes)
	txID := "0x" + hex.EncodeToString(decoded[offset:offset+32])
	offset += 32

	// Extract universalTxID (32 bytes)
	universalTxID := "0x" + hex.EncodeToString(decoded[offset:offset+32])
	offset += 32

	// Skip gas_fee (prepaid budget, 8 bytes); the audited finalize event reports
	// gas_used separately and that's the value we want to surface as GasFeeUsed.
	offset += 8

	// Extract gas_used (8 bytes, u64 little-endian lamports) — actual gas consumed.
	gasUsed := binary.LittleEndian.Uint64(decoded[offset : offset+8])

	// Create OutboundEvent payload
	payload := common.OutboundEvent{
		TxID:          txID,
		UniversalTxID: universalTxID,
		GasFeeUsed:    fmt.Sprintf("%d", gasUsed),
	}

	// Marshal payload to JSON
	payloadData, err := json.Marshal(payload)
	if err != nil {
		logger.Warn().
			Err(err).
			Str("signature", signature).
			Msg("failed to marshal outbound event payload")
		return nil
	}

	// Create store.Event
	event := &store.Event{
		EventID:           eventID,
		BlockHeight:       slot,
		Type:              store.EventTypeOutbound, // Outbound observation events
		Status:            store.StatusPending,
		ConfirmationType:  store.ConfirmationStandard, // Use STANDARD confirmation for outbound events
		ExpiryBlockHeight: 0,                          // 0 means no expiry
		EventData:         payloadData,
	}

	logger.Debug().
		Str("event_id", eventID).
		Str("tx_id", txID).
		Str("universal_tx_id", universalTxID).
		Str("gas_used", fmt.Sprintf("%d", gasUsed)).
		Msg("parsed outboundObservation event")

	return event
```
