### Title
Spot-price Uniswap V3 quote (no TWAP) used to compute `minPCOut` slippage floor for module-driven PRC20 auto-swaps enables sandwich/price-manipulation drain of inbound deposits and gas refunds - (File: `x/uexecutor/keeper/evm.go`, `x/uexecutor/keeper/execute_inbound_gas.go`, `x/uexecutor/keeper/execute_inbound_gas_and_payload.go`, `x/uexecutor/keeper/outbound.go`)

### Summary
`GetSwapQuote` calls Uniswap V3's `QuoterV2.quoteExactInputSingle`, which returns the amount out at the pool's **current spot price**, not a time-weighted average. This spot quote is the sole input used to compute `minPCOut` (a 95%-of-quote slippage floor) that is then passed into `depositPRC20WithAutoSwap` for GAS and GAS_AND_PAYLOAD inbound execution, and into the gas-fee-refund swap path. Because the slippage floor is derived from the manipulable spot price at the exact moment the module executes the swap, an unprivileged attacker can move the pool price immediately around the module's transaction to capture the difference between the fair price and the manipulated price, at the expense of the depositing user's/protocol's PRC20-to-WPC conversion. This is a direct analog of the Sherlock H-17 `UniswapImplementation.beforeSwap()` finding: using current market price instead of TWAP for a swap decision made on behalf of the protocol/user.

### Finding Description
`GetSwapQuote` fetches the amount out using the pool's live state via `quoteExactInputSingle`, with no TWAP or oracle cross-check: [1](#0-0) 

This is used to derive `minPCOut` with a fixed 5% slippage tolerance in three separate paths:

1. GAS-only inbound execution: [2](#0-1) 

2. GAS_AND_PAYLOAD inbound execution: [3](#0-2) 

3. Outbound gas-fee-refund swap: [4](#0-3) 

In every case, `minPCOut` is computed as `quote * 95 / 100` where `quote` is the manipulable spot-price quote, then passed straight into `CallPRC20DepositAutoSwap` / `CallUniversalCoreRefundUnusedGas`, which execute the actual on-chain swap via `depositPRC20WithAutoSwap` / `refundUnusedGas`: [5](#0-4) 

Since `minPCOut` is derived from the same manipulated price the swap itself will execute against, the floor provides no real protection — it merely codifies the attacker's manipulated price as the "acceptable" minimum. This mirrors the root cause in the external report: a swap-time decision (there, `beforeSwap`'s fee-liquidation swap; here, the module's deposit/refund auto-swap) is priced off `getSlot0`/`quoteExactInputSingle` spot state instead of a TWAP, letting an attacker sandwich the transaction:
1. Trade against the WPC/PRC20 pool to push the price against depositors right before the module's finalizing transaction executes in the same block.
2. Let the module's inbound execution (or gas refund) swap PRC20/gas token into WPC at the manipulated price — the 5%-slippage floor is calculated from that same manipulated price, so it does not block the bad fill.
3. Reverse the initial trade, capturing the spread as risk-free profit extracted from the value that should have gone to the depositing user or protocol-owned refund.

This flow is triggered by ordinary user actions — any cross-chain deposit (`ExecuteInboundGas` / `ExecuteInboundGasAndPayload`) or outbound observation that results in a gas refund (`applyGasRefund` → `getSwapQuoteForRefund`) — and requires no malicious validator, malicious relayer, or privileged actor; the attacker only needs to trade on the same Uniswap V3 pool that the module uses, timed around block inclusion of the finalizing transaction.

### Impact Explanation
Corruption of PRC20/native asset accounting and gas-fee/refund accounting: the amount of WPC (native PC) credited to a UEA on deposit, or refunded to a sender/fund-recipient on outbound completion, can be made to land at the attacker-chosen manipulated price rather than the honest market price, draining value from user deposits and protocol-controlled refund flows to the attacker. This falls squarely within the allowed impact "corruption of ... gas fee accounting, refund accounting ... token mapping" and "stealing, draining ... of user or protocol-controlled funds."

### Likelihood Explanation
Any unprivileged user can trade on the WPC/PRC20 Uniswap V3 pool deployed on Push Chain's own EVM. Because inbound/refund execution runs synchronously inside the finalizing validator vote transaction within an ordinary block, an attacker only needs to get manipulation and reversal trades ordered around that transaction (e.g., via gas-price-based mempool ordering) — no validator collusion is required. The fixed 5% slippage tolerance is a wide, non-adaptive bound that does not meaningfully constrain feasible single-block price manipulation on a low-liquidity pool.

### Recommendation
Do not derive `minPCOut` purely from an instantaneous `quoteExactInputSingle` call. Use a manipulation-resistant reference price (e.g., a Uniswap V3 TWAP over a sufficiently long window, or an external price oracle) to bound acceptable slippage, and/or clamp the slippage tolerance based on deviation from that reference rather than a fixed percentage of the spot quote itself.

### Proof of Concept
1. Attacker observes a pending cross-chain GAS or GAS_AND_PAYLOAD inbound (or an outbound about to be marked successful with excess gas to refund).
2. In the same block as the finalizing `MsgVoteInbound`/`MsgVoteOutbound` transaction, attacker submits (a) a swap that pushes the WPC/PRC20 pool price against the depositor, ordered before the finalizing tx, and (b) a reversing swap ordered after it.
3. When the finalizing tx executes, `GetSwapQuote` (`x/uexecutor/keeper/evm.go:500-538`) returns the manipulated spot quote; `minPCOut` is computed as 95% of that manipulated quote (`execute_inbound_gas.go:142-146` / `execute_inbound_gas_and_payload.go:374-376`); `CallPRC20DepositAutoSwap`/`CallUniversalCoreRefundUnusedGas` execute the swap at the manipulated price.
4. Attacker's reversing trade restores the price and captures the spread, which was extracted from the value that should have accrued to the depositing UEA or the refund recipient.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}

// getSwapQuoteForRefund fetches a Uniswap quote for the gas token refund swap.
func (k Keeper) getSwapQuoteForRefund(ctx sdk.Context, gasToken common.Address, fee *big.Int, amount *big.Int) (*big.Int, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(ctx)
	if err != nil {
		return nil, err
	}
	wpcAddr, err := k.GetUniversalCoreWPCAddress(ctx)
	if err != nil {
		return nil, err
	}
	return k.GetSwapQuote(ctx, quoterAddr, gasToken, wpcAddr, fee, amount)
}
