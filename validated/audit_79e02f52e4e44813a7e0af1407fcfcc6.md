### Title
Replayable signature verification in `ValidateMultiSign`/`BatchValidateSign` TVM precompiles enables paymaster-style drain of contracts built on top — (File: `actuator/src/main/java/org/tron/core/vm/PrecompiledContracts.java`)

### Summary
The `ValidateMultiSign` and `BatchValidateSign` precompiled contracts, reachable from any `TriggerSmartContract` call, verify off-chain ECDSA signatures against a fixed hash derived only from `(address, permissionId, data)` (or a caller-supplied hash), with no on-chain nonce, expiration, or "used" tracking. This is structurally identical to the root cause of the Biconomy `VerifyingSingletonPaymaster` bug: a signature-verification primitive that returns "valid" deterministically for the same input every time it is called, with the entire responsibility for anti-replay pushed onto the calling contract's state. Any Solidity contract deployed on TRON that uses these precompiles to authorize a one-time action (fee-sponsored relay, meta-transaction execution, delegated withdrawal, etc.) inherits the exact same drain-by-replay pattern described in the report, because the precompile itself never marks a signature/hash as consumed.

### Finding Description
`ValidateMultiSign.execute` computes:
```
combine = address || permissionId || data
hash = sha256(combine)
``` [1](#0-0) 
and then simply recovers signer addresses from the supplied signatures and checks accumulated weight against the account permission threshold, returning `dataOne()` (true) whenever the threshold is met: [2](#0-1) 

`BatchValidateSign.doExecute` similarly recovers addresses from a caller-supplied `hash` and signature array and returns a bitmap of matches, again with no persisted state: [3](#0-2) 

Both precompiles are stateless: they are pure functions of their inputs. There is no `usedHash`-style mapping, nonce field, or expiration baked into the hash or into any store, so a call with a given `(address, permissionId, data)`/`hash` plus a valid signature set will always return "success," no matter how many times it is invoked, in the same block or across many blocks, exactly like the pre-fix `validatePaymasterUserOp` in the referenced report.

The report's exploit specifically hinges on an attacker-controlled account contract that skips its own nonce enforcement (`MaliciousAccount.sol`) while still presenting a signature that the paymaster naively re-validates. On TRON, `TriggerSmartContract` calls are fully attacker-controlled contract execution — any contract that stores/receives a signature off-chain (e.g., a smart-contract wallet, exchange relayer, or fee-delegation service built with `ValidateMultiSign`) and uses it to gate a value-transferring action (TRX transfer, TRC20 transfer, resource delegation) is exposed to unlimited replay of that one signature unless *that specific contract* independently implements a used-hash/nonce map — which the precompile provides no help enforcing and does not itself warn against or make it easy to get right (no nonce component is included in the hash construction at all, unlike e.g. EIP-712 typed data with nonces).

### Impact Explanation
Any TRON smart contract that relies on `ValidateMultiSign`/`BatchValidateSign` as its sole authorization gate for a value-moving action can have that authorization replayed an unbounded number of times by any caller who possesses one valid signature, draining TRX/TRC10/TRC20 balances or resources held by that contract, up to its total balance — mirroring the "Paymaster ETH can be drained" impact in the source report. This is systemic risk introduced by the design of a security-critical precompiled contract rather than a bug confined to a single third-party deployment.

### Likelihood Explanation
High for any contract author who follows the natural/expected usage pattern of these precompiles (treat a valid multi-sig signature as sufficient authorization for an action) without separately implementing their own nonce/used-hash bookkeeping, since the precompile's hash format `(address, permissionId, data)` provides no anti-replay input by default and TRON documentation for `ValidateMultiSign`/`BatchValidateSign` does not mandate one. The attack requires only a normal, unprivileged `TriggerSmartContract` call with a previously observed valid signature.

### Recommendation
- Document prominently (and ideally provide a reference implementation) that any contract using `ValidateMultiSign`/`BatchValidateSign` for one-time authorizations MUST include a caller-managed nonce/expiration inside the signed `data`/`hash` and MUST track consumed hashes in contract storage before trusting the precompile's boolean result.
- Consider extending the `ValidateMultiSign` ABI to optionally accept and enforce a nonce/salt component as part of the hashed payload so replay protection is available at the precompile layer rather than being entirely delegated to (and often forgotten by) downstream contract authors.

### Proof of Concept
1. Deploy a TRON smart contract `Relay` that calls `ValidateMultiSign(ownerAddr, permissionId, data, signatures)` to authorize sending TRX/TRC20 out of its own balance whenever the check returns true, without tracking `data`/hash usage.
2. `ownerAddr`'s key holder signs one such `data` payload once, authorizing, e.g., "pay 100 TRX to X."
3. Attacker calls `Relay`'s payout function repeatedly with the same signature and same `data`; `ValidateMultiSign` returns success every time (no state changes across calls) at line ranges referenced above.
4. `Relay` drains its entire balance to the attacker, replaying a single authorization indefinitely — structurally identical to the `VerifyingSingletonPaymaster` replay in the source report. [4](#0-3) [5](#0-4)

    private static final int ENGERYPERSIGN = 1500;
    private static final int MAX_SIZE = 5;
    private static final int ABI_HEADER_WORDS = 5;
    private static final int ABI_ITEM_WORDS = 5;


    @Override
    public long getEnergyForData(byte[] data) {
      long cnt = (data.length / WORD_SIZE - 5) / 5;
      // one sign 1500, half of ecrecover
      return cnt * ENGERYPERSIGN;
    }

    @Override
    public Pair<Boolean, byte[]> execute(byte[] rawData) {
      if (VMConfig.allowTvmOsaka()
          && !isValidAbiEncoding(rawData, ABI_HEADER_WORDS, ABI_ITEM_WORDS)) {
        return Pair.of(false, EMPTY_BYTE_ARRAY);
      }
      DataWord[] words = DataWord.parseArray(rawData);
      byte[] address = words[0].toTronAddress();
      int permissionId = words[1].intValueSafe();
      byte[] data = words[2].getData();

      byte[] combine = ByteUtil.merge(address, ByteArray.fromInt(permissionId), data);
      byte[] hash = Sha256Hash.hash(CommonParameter
          .getInstance().isECKeyCryptoEngine(), combine);

      if (VMConfig.allowTvmSelfdestructRestriction()) {
        int sigArraySize = words[words[3].intValueSafe() / WORD_SIZE].intValueSafe();
        if (sigArraySize > MAX_SIZE) {
          return Pair.of(true, DATA_FALSE);
        }
      }
      byte[][] signatures = VMConfig.allowTvmSelfdestructRestriction() ?
          extractSigArray(words, words[3].intValueSafe() / WORD_SIZE, rawData) :
          extractBytesArray(words, words[3].intValueSafe() / WORD_SIZE, rawData);

      if (signatures.length == 0 || signatures.length > MAX_SIZE) {
        return Pair.of(true, DATA_FALSE);
      }

      AccountCapsule account = this.getDeposit().getAccount(address);
      if (account != null) {
        try {
          Permission permission = account.getPermissionById(permissionId);
          if (permission != null) {
            //calculate weight
            long totalWeight = 0L;
            List<byte[]> executedSignList = new ArrayList<>();
            for (byte[] sign : signatures) {
              byte[] recoveredAddr = recoverAddrBySign(sign, hash);

              sign = merge(recoveredAddr, sign);
              if (ByteArray.matrixContains(executedSignList, recoveredAddr)) {
                if (ByteArray.matrixContains(executedSignList, sign)) {
                  continue;
                }
                MUtil.checkCPUTime();
              }
              long weight = TransactionCapsule.getWeight(permission, recoveredAddr);
              if (weight == 0) {
                //incorrect sign
                return Pair.of(true, DATA_FALSE);
              }
              totalWeight += weight;
              executedSignList.add(sign);
              executedSignList.add(recoveredAddr);
            }

            if (totalWeight >= permission.getThreshold()) {
              return Pair.of(true, dataOne());
            }
          }
        } catch (Throwable t) {
          if (t instanceof OutOfTimeException) {
            throw t;
          }
          logger.info("ValidateMultiSign error:{}", t.getMessage());
        }
      }
      return Pair.of(true, DATA_FALSE);
    }

  public static class BatchValidateSign extends PrecompiledContract {

    private static final ExecutorService workers;
    private static final String workersName = "validate-sign-contract";
    private static final int ENGERYPERSIGN = 1500;
    private static final int MAX_SIZE = 16;
    private static final int ABI_HEADER_WORDS = 5;
    private static final int ABI_ITEM_WORDS = 6;

    static {
      workers = ExecutorServiceManager.newFixedThreadPool(workersName,
          Runtime.getRuntime().availableProcessors() / 2 + 1);
    }

    @Override
    public long getEnergyForData(byte[] data) {
      long cnt = (data.length / WORD_SIZE - 5) / 6;
      // one sign 1500, half of ecrecover
      return cnt * ENGERYPERSIGN;
    }

    @Override
    public Pair<Boolean, byte[]> execute(byte[] data) {
      try {
        return doExecute(data);
      } catch (Throwable t) {
        if (t instanceof InterruptedException){
          Thread.currentThread().interrupt();
        }
        return Pair.of(true, new byte[WORD_SIZE]);
      }
    }

    private Pair<Boolean, byte[]> doExecute(byte[] data)
        throws InterruptedException, ExecutionException {
      if (VMConfig.allowTvmOsaka()
          && !isValidAbiEncoding(data, ABI_HEADER_WORDS, ABI_ITEM_WORDS)) {
        return Pair.of(false, EMPTY_BYTE_ARRAY);
      }
      DataWord[] words = DataWord.parseArray(data);
      byte[] hash = words[0].getData();

      if (VMConfig.allowTvmSelfdestructRestriction()) {
        int sigArraySize = words[words[1].intValueSafe() / WORD_SIZE].intValueSafe();
        int addrArraySize = words[words[2].intValueSafe() / WORD_SIZE].intValueSafe();
        if (sigArraySize > MAX_SIZE || addrArraySize > MAX_SIZE) {
          return Pair.of(true, DATA_FALSE);
        }
      }

      byte[][] signatures = VMConfig.allowTvmSelfdestructRestriction() ?
          extractSigArray(words, words[1].intValueSafe() / WORD_SIZE, data) :
          extractBytesArray(words, words[1].intValueSafe() / WORD_SIZE, data);
      byte[][] addresses = extractBytes32Array(
          words, words[2].intValueSafe() / WORD_SIZE);
      int cnt = signatures.length;
      if (cnt == 0 || cnt > MAX_SIZE || signatures.length != addresses.length) {
        return Pair.of(true, DATA_FALSE);
      }
      byte[] res = new byte[WORD_SIZE];
      if (isConstantCall()) {
        //for constant call not use thread pool to avoid potential effect
        for (int i = 0; i < cnt; i++) {
          if (DataWord
              .equalAddressByteArray(addresses[i], recoverAddrBySign(signatures[i], hash))) {
            res[i] = 1;
          }
        }
      } else {
        // add check
        CountDownLatch countDownLatch = new CountDownLatch(cnt);
        List<Future<RecoverAddrResult>> futures = new ArrayList<>(cnt);

        for (int i = 0; i < cnt; i++) {
          Future<RecoverAddrResult> future = workers
              .submit(new RecoverAddrTask(countDownLatch, hash, signatures[i], i));
          futures.add(future);
        }
        boolean withNoTimeout = countDownLatch
            .await(getCPUTimeLeftInNanoSecond(), TimeUnit.NANOSECONDS);

        if (!withNoTimeout) {
          logger.info("BatchValidateSign timeout");
          throw Program.Exception.notEnoughTime("call BatchValidateSign precompile method");
        }

        for (Future<RecoverAddrResult> future : futures) {
          RecoverAddrResult result = future.get();
          int index = result.nonce;
          if (DataWord.equalAddressByteArray(result.addr, addresses[index])) {
            res[index] = 1;
          }
        }
      }
      return Pair.of(true, res);
    }
