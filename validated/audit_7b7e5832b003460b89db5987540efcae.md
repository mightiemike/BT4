### Title
PoisonMicroblock forgery via ECDSA signature malleability and missing content-divergence check - (`stackslib/src/chainstate/stacks/db/transactions.rs`)

### Summary
`check_microblock_header_signer` and `handle_poison_microblock` only verify that two microblock headers recover to the same public-key hash; they never verify that the headers actually encode conflicting content (differing `tx_merkle_root`/sequence/prev_block). Combined with `check_recover_pubkey` using `recover_to_pubkey_without_validating_low_s`, an attacker can take a single honestly-signed microblock header, mathematically derive its high-S malleated twin (no private key needed), and submit it as a "poison" report to have an honest, non-equivocating miner's reward slashed.

### Finding Description
The broken equality is: **"two headers recover to the same pubkey" == "the miner double-signed two conflicting microblocks."** The code only checks the former.

`StacksMicroblockHeader::check_recover_pubkey` computes the digest over the header with the signature field zeroed out, then recovers the pubkey via `StacksPublicKey::recover_to_pubkey_without_validating_low_s`, explicitly skipping low-S canonicalization [1](#0-0) . Because the digest excludes the signature bytes, a signature and its ECDSA-malleated counterpart `(r, n-s, flipped recovery id)` — derivable from any existing valid signature without the private key — recover to the identical pubkey hash over the identical message.

`check_microblock_header_signer` (the authoritative check used by `handle_poison_microblock` at Clarity-execution time) only compares `pkh1 != pkh2`; it does not check that the two headers differ in `sequence`, `prev_block`, or `tx_merkle_root`: [2](#0-1) 

`handle_poison_microblock` then only calls `check_microblock_header_signer` and checks maturity window — no content-divergence check is performed at all at the block-processing layer: [3](#0-2) 

The only place that checks any structural fields is the *mempool admission* pre-check (`will_admit_mempool_tx`), and even that omits `tx_merkle_root`: [4](#0-3) 

That mempool check is not on the authoritative chain-processing path — a miner (the attacker, who per the threat model holds a valid miner slot) can place a crafted `PoisonMicroblock` transaction directly into their own block, bypassing `will_admit_mempool_tx` entirely, and it will still be accepted by `process_transaction`/`handle_poison_microblock` because that path performs no equivalent check.

Exploit flow:
1. Attacker observes one honestly broadcast, signed microblock header `H1` (any real miner's real, non-conflicting microblock).
2. Attacker computes `H2` = `H1` with the signature malleated: `(r, n-s, recid^1)`. This requires no private key — pure elliptic-curve math on the existing signature.
3. `H1 != H2` byte-for-byte (signature bytes differ), satisfying any naive struct-equality guard.
4. `check_recover_pubkey(H1) == check_recover_pubkey(H2)` because malleated recoverable ECDSA signatures recover to the same pubkey for the same message.
5. Attacker crafts `TransactionPayload::PoisonMicroblock(H1, H2)`, includes it in their own mined block (or, if it slips past the incomplete mempool check, broadcasts it).
6. `handle_poison_microblock` accepts it as a genuine equivocation proof and marks the (honest) miner's coinbase/microblock reward for that block height as slashed, crediting the attacker as reporter.

### Impact Explanation
This is block-reward theft: an honest, non-equivocating miner has their block reward wrongfully forfeited and a portion paid to the attacker who fabricated proof of misbehavior. This matches the "Critical - block-reward theft/double-payment/loss" category. The attack can be repeated against any observed microblock header from any miner, at zero cost beyond broadcasting or self-mining a transaction, and requires no majority stake, only a single miner slot or the ability to get a transaction included/mined (which mempool admission does not even reliably block, since it omits the `tx_merkle_root` divergence check as well).

### Likelihood Explanation
Preconditions are minimal: the attacker needs to observe one signed microblock header whose public key hash was previously registered on-chain (`has_microblock_pubkey`/`get_microblock_pubkey_hash_height`), and the report must be submitted within `MINER_REWARD_MATURITY` blocks. No BTC spend beyond a standard transaction fee/mined block is required, and no coordination with other parties or majority stake is needed — this is exploitable by a single unprivileged participant, matching the "minority-triggerable" threat model, and is fully repeatable against every miner's every microblock.

### Recommendation
In `check_microblock_header_signer` (and/or `handle_poison_microblock`), in addition to checking `pkh1 == pkh2`, require that the two headers actually diverge in the fields that define equivocation (`sequence` equal, `prev_block` equal, but `tx_merkle_root` different — i.e., same slot, different content). Additionally, enforce low-S canonical signatures (reject malleated/high-S signatures) using a validating recovery function instead of `recover_to_pubkey_without_validating_low_s`, or explicitly compare the two signatures for the malleated relationship and reject if `H1` and `H2` are trivial malleations of one another over identical content.

### Proof of Concept
Rust integration test plan (in `stackslib/src/chainstate/stacks/db/transactions.rs` test module, alongside `process_poison_microblock_same_block`):
1. Sign a real microblock header `H1` with `block_privk` for a real `tx_merkle_root`/`prev_block`/`sequence`.
2. Implement a malleation helper: parse `H1.signature` into `(r, s, recid)`, compute `s' = SECP256K1_ORDER - s`, `recid' = recid ^ 1`, construct `H2 = H1.clone()` with `signature = (r, s', recid')`. Assert `H1 != H2` (raw struct inequality) — the equality-of-content check the question describes.
3. Assert `H1.check_recover_pubkey().unwrap() == H2.check_recover_pubkey().unwrap()` — proving the "same underlying key" equality holds even though `H1`'s and `H2`'s `tx_merkle_root` are identical (no real fork).
4. Register `block_pubkh` via `insert_microblock_pubkey_hash`.
5. Build `TransactionPayload::PoisonMicroblock(H1.header, H2.header)`, sign, and call `StacksChainState::process_transaction`.
6. Assert the call **succeeds** (i.e., `handle_poison_microblock` returns `Ok`, records a poison report, and would slash the honest miner's reward) despite `H1` and `H2` encoding the identical microblock content — demonstrating that the check accepts a self-malleated, non-equivocating pair as valid proof of misbehavior.

    pub fn check_recover_pubkey(&self) -> Result<Hash160, AuthError> {
        let mut bytes = vec![];
        self.serialize(&mut bytes, true)
            .expect("BUG: failed to serialize to a vec");
        let digest = Sha512Trunc256Sum::from_data(&bytes[..]);

        let mut pubk = StacksPublicKey::recover_to_pubkey_without_validating_low_s(
            digest.as_bytes(),
            &self.signature,
        )
        .map_err(|_ve| {
            AuthError::VerifyingError(
                "Failed to verify signature: failed to recover public key".to_string(),
            )
        })?;

        pubk.set_compressed(true);
        Ok(Hash160::from_node_public_key(&pubk))
    }

    fn check_microblock_header_signer(
        mblock_hdr_1: &StacksMicroblockHeader,
        mblock_hdr_2: &StacksMicroblockHeader,
    ) -> Result<Hash160, Error> {
        let pkh1 = mblock_hdr_1.check_recover_pubkey().map_err(|e| {
            Error::InvalidStacksTransaction(
                format!("Failed to recover public key: {:?}", &e),
                false,
            )
        })?;

        let pkh2 = mblock_hdr_2.check_recover_pubkey().map_err(|e| {
            Error::InvalidStacksTransaction(
                format!("Failed to recover public key: {:?}", &e),
                false,
            )
        })?;

        if pkh1 != pkh2 {
            let msg = format!(
                "Invalid PoisonMicroblock transaction -- signature pubkey hash {} != {}",
                &pkh1, &pkh2
            );
            warn!("{}", &msg);
            return Err(Error::InvalidStacksTransaction(msg, false));
        }
        Ok(pkh1)
    }

    pub fn handle_poison_microblock(
        env: &mut ExecutionState,
        invoke_ctx: &InvocationContext,
        mblock_header_1: &StacksMicroblockHeader,
        mblock_header_2: &StacksMicroblockHeader,
    ) -> Result<Value, Error> {
        let cost_before = env.global_context.cost_track.get_total();

        // encodes MARF reads for loading microblock height and current height, and loading and storing a
        // poison-microblock report
        runtime_cost(ClarityCostFunction::PoisonMicroblock, env, 0)
            .map_err(|e| Error::from_cost_error(e, cost_before.clone(), env.global_context))?;

        let sender_principal = match &invoke_ctx.sender {
            Some(ref sender) => {
                if let PrincipalData::Standard(sender) = sender.clone() {
                    sender
                } else {
                    panic!(
                        "BUG: tried to handle poison microblock without a standard principal sender"
                    );
                }
            }
            None => {
                panic!("BUG: tried to handle poison microblock without a sender");
            }
        };

        // is this valid -- were both headers signed by the same key?
        let pubkh =
            StacksChainState::check_microblock_header_signer(mblock_header_1, mblock_header_2)?;

        let microblock_height_opt = env
            .global_context
            .database
            .get_microblock_pubkey_hash_height(&pubkh)?;
        let current_height = env.global_context.database.get_current_block_height();

        // for the microblock public key hash we had to process
        env.add_memory(20)
            .map_err(|e| Error::from_cost_error(e, cost_before.clone(), env.global_context))?;

        // for the block height we had to load
        env.add_memory(4)
            .map_err(|e| Error::from_cost_error(e, cost_before.clone(), env.global_context))?;

        // was the referenced public key hash used anytime in the past
        // MINER_REWARD_MATURITY blocks?
        let mblock_pubk_height = match microblock_height_opt {
            None => {
                // public key has never been seen before
                let msg = format!(
                    "Invalid Stacks transaction: microblock public key hash {} never seen in this fork",
                    &pubkh
                );
                warn!("{}", &msg;
                      "microblock_pubkey_hash" => %pubkh
                );

                return Err(Error::InvalidStacksTransaction(msg, false));
            }
            Some(height) => {
                if height
                    .checked_add(
                        u32::try_from(MINER_REWARD_MATURITY).expect("FATAL: maturity > 2^32"),
                    )
                    .expect("BUG: too many blocks")
                    < current_height
                {
                    let msg = format!(
                        "Invalid Stacks transaction: microblock public key hash from height {} has matured relative to current height {}",
                        height, current_height
                    );
                    warn!("{}", &msg;
                          "microblock_pubkey_hash" => %pubkh
                    );

                    return Err(Error::InvalidStacksTransaction(msg, false));
                }
                height
            }
        };
