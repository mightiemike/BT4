### Title
Missing declared-class validation in Starknet OS `execute_replace_class` allows committing an undeclared class hash to state — ([File: crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo])

### Summary
The Starknet OS Cairo implementation of the `replace_class` syscall does not verify that the target `class_hash` corresponds to an actually declared contract class before writing it into `contract_state_changes`, unlike the Rust blockifier's deprecated (Cairo0) syscall handler, which explicitly performs this check.

### Finding Description
`execute_replace_class` in the Starknet OS program contains an explicit TODO acknowledging the missing validation: [1](#0-0) 

The function reads the requested `class_hash` from the syscall request and immediately writes it into the contract's `StateEntry` via `dict_update`, with no assertion that the class hash exists in `contract_class_changes` or any declared-class table — the comment at line 902 explicitly states this check is not yet implemented.

By contrast, the equivalent Rust blockifier logic for the deprecated (Cairo0) syscall path enforces the check by attempting to read the compiled class before mutating state: [2](#0-1) 

This is confirmed by a dedicated negative test that expects a `"is not declared"` error when a contract calls `replace_class` with an undeclared hash: [3](#0-2) 

The modern (Cairo1/native) syscall path routes `replace_class` through a shared `self.base.replace_class(...)` call: [4](#0-3) [5](#0-4) 

I was **not able to confirm within the available investigation budget** whether the shared `base.replace_class` implementation (in `crates/blockifier/src/execution/syscalls/syscall_base.rs`) performs the same "class must be declared" check as the deprecated Cairo0 path. My attempt to inspect that function's body did not return its contents before the tool budget was exhausted, so whether the Cairo1/native execution path in the Rust sequencer itself has this gap remains unverified. What is concretely and directly verified is that the **Starknet OS's own Cairo implementation of `replace_class` lacks this check entirely**, regardless of what the Rust blockifier enforces.

### Impact Explanation
The Starknet OS is the component responsible for re-executing a block to produce the state transition proof and to derive the final committed state (contract state changes feeding into the Patricia tree / state commitment). If the OS's `execute_replace_class` accepts and commits an undeclared `class_hash` for a contract:
- The contract's class hash entry in the committed state can point to a class hash that has no corresponding declared/compiled class, which is an invariant violation of the state model (every `class_hash` mapping should reference an actually declared class).
- Any code path (including in the Rust sequencer/full nodes) that assumes a `class_hash` recorded in state must be resolvable to a compiled class (e.g. `get_compiled_class`, which elsewhere unconditionally returns `StateError::UndeclaredClassHash` for un-declared hashes, as seen in `crates/blockifier/src/state/cached_state_test.rs:186-190`) would subsequently fail for that contract, permanently bricking it — a form of permanent freezing of contract state/funds reachable from a single unprivileged `replace_class` syscall call.
- If this gap is also present in the Rust blockifier's Cairo1/native execution path (unconfirmed), it would additionally cause an honest-node divergence risk between block-building assumptions and OS-provable state, or allow an attacker-controlled contract to intentionally self-brick with a class hash that nonetheless gets committed to the state root.

### Likelihood Explanation
The `replace_class` syscall is directly reachable by any contract executing normal, unprivileged transaction logic (no special roles required) — any account or contract can invoke it with an attacker-chosen `class_hash` value as part of ordinary invoke/execute calls. The missing check is unconditional and not gated by any feature flag, so it applies to every block re-executed/proven by the Starknet OS.

### Recommendation
- Add an explicit assertion/check in `execute_replace_class` (Starknet OS, `syscall_impls.cairo`) that the given `class_hash` is present in `contract_class_changes` (i.e., has been declared), mirroring the check already performed in the Rust blockifier's deprecated syscall handler (`state.get_compiled_class(request.class_hash)?`).
- Audit `crates/blockifier/src/execution/syscalls/syscall_base.rs`'s `replace_class` implementation to confirm it also performs the declared-class check for the Cairo1/native execution path, and add the check if missing, so behavior is consistent across Cairo0/Cairo1/native and the Starknet OS.

### Proof of Concept
1. Declare any contract type via a normal Declare transaction (satisfies unprivileged-attacker precondition).
2. Deploy an instance of that contract.
3. From within that contract, invoke the `replace_class` syscall (e.g. as exercised by the `test_replace_class` external function pattern) with an arbitrary, never-declared `class_hash` value (e.g. `felt!(1234_u16)` as used in the existing negative test at `deprecated_syscalls_test.rs:383-391`, but targeting the Cairo1/native syscall path or the Starknet OS re-execution flow instead of the deprecated Cairo0 path that is confirmed to check for declaration).
4. Because `execute_replace_class` in the Starknet OS (`syscall_impls.cairo:881-920`) does not verify the class is declared, the OS commits the undeclared `class_hash` into `contract_state_changes` for that contract address.
5. Subsequent calls to the contract fail with `UndeclaredClassHash`/equivalent errors when any component (RPC execution state reader, blockifier) attempts to resolve the compiled class, permanently freezing the contract.

// Replaces the class.
func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}

    fn replace_class(&mut self, class_hash: Felt, remaining_gas: &mut u64) -> SyscallResult<()> {
        self.pre_execute_syscall(
            remaining_gas,
            self.gas_costs().syscalls.replace_class.base_syscall_cost(),
            SyscallSelector::ReplaceClass,
        )?;

        self.base
            .replace_class(ClassHash(class_hash))
            .map_err(|err| self.handle_error(remaining_gas, err))?;
