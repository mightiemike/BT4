The concrete Push Chain analog to the Lido `_currentBalance` finding is the swap-quote/slippage logic in `x/uexecutor/keeper/evm.go`'s `GetSwapQuote`, used by the gas-abstraction auto-swap and gas-refund paths — it derives its "safe" minimum-output bound from the same manipulable spot price it is meant to protect against.

### Title
Auto-swap and gas-refund `minPCOut` derived from manipulable Uniswap V3 spot quote enables sandwich-style value extraction from bridged deposits - (File: `x/uexecutor/keeper/evm.go`, `x/uexecutor/keeper/execute_inbound_gas.go`, `x/uexecutor/keeper/outbound.go`)

### Summary
`GetSwapQuote` fetches the expected swap output by calling `QuoterV2.quoteExactInputSingle` against the live, on-chain Uniswap V3 PRC20/WPC pool state [1](#0-0) . The slippage bound (`minPCOut`) used to protect every gas-abstraction auto-swap and gas refund swap is computed as a fixed 95% of this same, freshly-read spot quote [2](#0-1) [3](#0-2) . Because the quote and the bound derived from it come from the same manipulable price, the check cannot catch price manipulation that happened before the quote was read — exactly the flaw in the Lido report, where `_currentBalance` priced stETH via a pool's `get_dy` return value that an attacker could skew with a large swap immediately beforehand.

### Finding Description
The Uniswap V3 pools used here are permissionless AMM pools (WPC ↔ PRC20 token pools), created and seeded with liquidity as part of the standard core-contracts deployment [4](#0-3) . Any unprivileged account can trade against these pools via the deployed `SwapRouter`/pool contracts, since nothing in the scoped uexecutor code gates who may execute swaps on-chain.

The vulnerable pattern appears in three call sites:
- `ExecuteInboundGas` (GAS-only inbound flow): fetches a quote via `GetSwapQuote`, computes `minPCOut = quote * 95 / 100`, and immediately calls `CallPRC20DepositAutoSwap` to execute `depositPRC20WithAutoSwap` on `UniversalCore` [5](#0-4) .
- `gasAndPayloadDepositAutoSwap` (GAS_AND_PAYLOAD inbound flow): identical pattern [6](#0-5) .
- `applyGasRefund` (outbound gas refund flow): identical pattern, swapping the excess gas token back to PC for the refund recipient [7](#0-6) .

In all three, `GetSwapQuote` is a `CallEVM` with `commit=false` — a static read of the pool's current state — executed by the module immediately before the real, `commit=true` `DerivedEVMCall` that performs the actual swap [8](#0-7) . There is no TWAP, external oracle, or delay between the quote and the trade; both reflect the same instantaneous pool price. A 5% slippage buffer only bounds price impact from the swap itself — it provides zero protection against the pool price having been pushed away from its fair value by a prior, attacker-controlled trade in the same block.

### Impact Explanation
An unprivileged attacker who trades against the relevant WPC/PRC20 pool immediately before a validator-triggered auto-swap or gas refund executes can sandwich the module's swap: skew the pool price so the module's `depositPRC20WithAutoSwap` (or `refundUnusedGas` swap leg) executes at an unfavorable rate that still clears the corrupted `minPCOut` floor, then reverse the trade to capture the difference. This drains value from bridging users' deposited gas tokens or refund amounts — falling under "stealing/draining ... of user or protocol-controlled funds" in the allowed-impact scope, reachable via ordinary inbound/outbound flows with no privileged access required.

### Likelihood Explanation
The trigger requires only the ability to submit a swap transaction against a permissionless pool at the right moment relative to inbound/outbound processing (front-running via gas price / mempool ordering), which is available to any unprivileged actor on an EVM-compatible chain. Every GAS, GAS_AND_PAYLOAD inbound, and every outbound gas refund with excess gas routes through this exact pattern, giving the attacker repeated, low-cost opportunities.

### Recommendation
Do not derive `minPCOut` from a same-block spot quote of a pool the attacker can trade against. Use a manipulation-resistant reference price (e.g., a TWAP over a sufficiently long window, or an external oracle) to bound acceptable output, and/or enforce protocol-level maximum price-impact checks independent of the instantaneous quote used to size the trade.

### Proof of Concept
1. Attacker monitors pending `MsgVoteInbound` transactions that will push an inbound (GAS or GAS_AND_PAYLOAD type) over quorum, triggering `ExecuteInboundGas` / `gasAndPayloadDepositAutoSwap` in the same block.
2. Attacker submits (with higher priority/gas) a large swap on the target PRC20/WPC Uniswap V3 pool to move the spot price unfavorably for the module's upcoming trade direction.
3. The quorum-triggering vote lands after the attacker's swap; `GetSwapQuote` reads the now-skewed price, and `minPCOut = quote*95/100` is computed from that skewed price [9](#0-8) .
4. `CallPRC20DepositAutoSwap` executes `depositPRC20WithAutoSwap` at the skewed price; it clears the corrupted `minPCOut` check because the check was computed off the same corrupted price.
5. Attacker reverses their initial swap, extracting the price-impact profit that was effectively paid by the bridging user's auto-swapped deposit (or by the gas-refund recipient in the `applyGasRefund` case).

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}
