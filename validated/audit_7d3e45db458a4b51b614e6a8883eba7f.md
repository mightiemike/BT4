### Title
Starknet OS Cairo `execute_replace_class` omits the declared-class check enforced by the blockifier, risking OS/blockifier state divergence - (File: crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo)

### Summary
The Rust blockifier enforces that a `replace_class` syscall may only set a contract's class hash to an already-declared class, by calling `get_compiled_class` before `set_class_hash_at` [1](#0-0) . The corresponding Cairo re-implementation of the same syscall inside the Starknet OS program, `execute_replace_class`, does not perform this check — it contains an explicit `TODO` acknowledging the missing validation and unconditionally updates `contract_state_changes` with the caller-supplied `class_hash` [2](#0-1) . The same gap exists in the deprecated-syscalls Cairo implementation `execute_replace_class` in `deprecated_execute_syscalls.cairo` [3](#0-2) .

### Finding Description
This mirrors the CVE-2026-81909 bug class: a state-mutating operation (aliasing/duplicating and then overwriting an object) that is missing a required precondition check that a different, "authoritative" code path enforces. In Concrete CMS, the alias route failed to verify the source block was genuinely orphaned/owned by the caller before duplicating and force-deleting it. Here, the "authoritative" execution engine (blockifier, in Rust) validates that a class hash is declared before allowing `replace_class` to succeed [4](#0-3) , and the same requirement is documented as an invariant relied on elsewhere in the state cache ("Replace class: verify the contract is deployed before running any code" / "verify the class is not declared through `get_compiled_class`") [5](#0-4) . The Starknet OS's Cairo re-implementation, used to independently re-execute and verify blocks (e.g. by provers / Starknet OS re-execution), skips this check entirely, as flagged by the code comment itself: `// TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.` [6](#0-5) .

An attacker (any contract deployer/caller who can trigger a `replace_class` syscall from their own contract) supplies an arbitrary, undeclared `class_hash`. The blockifier's sequencer execution would reject such a transaction (revert with "is not declared") as confirmed by tests [7](#0-6) [8](#0-7) . But the Cairo OS program that independently re-executes/verifies transactions when producing the STARK proof of the block does not perform an equivalent declared-class assertion in `execute_replace_class`, meaning the OS's local computation of `contract_state_changes` and thus the final state commitment for that contract's class hash could diverge from what a correctly-validating node would compute if any other path (e.g. a bug elsewhere, a race in hint computation, or reliance on unchecked prover-supplied hints such as `%{ GetContractAddressStateEntry %}`) allows an undeclared class hash to reach this function unfiltered.

### Impact Explanation
If the OS's un-validated `execute_replace_class` accepts a class hash that was never declared, the resulting state commitment/state diff produced during OS re-execution would not match the guarantee enforced by the "reference" blockifier execution engine — i.e., a wrong committed root for that contract's class-hash entry, or honest-node divergence between the OS-verified state and blockifier-verified state. This falls squarely under "wrong committed root or block hash" / "honest-node divergence" per the validation criteria.

### Likelihood Explanation
Likelihood is bounded by the fact that in the normal, correct pipeline the OS re-executes transactions that were already validated (and thus filtered) by the blockifier, so an undeclared class hash should not normally reach `execute_replace_class` in a legitimate block. However, the missing assertion removes a defense-in-depth check that the Rust implementation deliberately enforces and documents as a required invariant, and the presence of an explicit outstanding `TODO` in the code confirms this is a known, unresolved gap rather than an intentional simplification. Any future change to how syscalls are dispatched to the OS, or any prover/hint inconsistency that lets an unchecked hash flow into this function, would silently produce an incorrect state diff instead of failing loudly, which is a significant likelihood risk for a proving pipeline expected to be a strict, independent check on state transitions.

### Recommendation
Add an explicit assertion in the Cairo `execute_replace_class` (both `syscall_impls.cairo` and `deprecated_execute_syscalls.cairo`) that verifies the `class_hash` corresponds to a declared class (mirroring the Rust `get_compiled_class` check) before performing `dict_update` on `contract_state_changes`, resolving the outstanding `TODO(Yoni, 1/1/2026)` and closing the parity gap between the blockifier and Starknet OS execution semantics for this syscall.

### Proof of Concept
Not independently reproducible from static analysis alone: exploiting this requires demonstrating a concrete path by which an undeclared class hash reaches `execute_replace_class` in the OS Cairo program outside of the blockifier's normal pre-validation (e.g., through a divergent/adversarial hint value for `GetContractAddressStateEntry` or a future code path that invokes syscall execution without prior blockifier-style validation). This code-path analysis is based on static comparison of the Rust and Cairo implementations, and the actual reachability of an unvalidated `class_hash` to the OS execution outside the blockifier-filtered pipeline was not confirmed with a working exploit; this is flagged as unverified and would require dynamic testing (e.g., running the Starknet OS program against a crafted execution trace with an undeclared class hash) to fully confirm real-world exploitability.

// Replaces the class.
func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
