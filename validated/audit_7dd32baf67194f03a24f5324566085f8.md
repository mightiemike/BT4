### Title
Spot-price Uniswap V3 `QuoterV2` quote used to bound `minPCOut` for module-driven auto-swaps enables sandwich-style value extraction on inbound/refund PRC20→PC swaps - (File: x/uexecutor/keeper/evm.go, x/uexecutor/keeper/execute_inbound_gas.go, x/uexecutor/keeper/execute_inbound_gas_and_payload.go, x/uexecutor/keeper/outbound.go)

### Summary
The external report shows that pricing a position off a spot/instantaneous AMM invariant (Curve `virtual_price`) without manipulation resistance lets an attacker move the price within a single price-dependent operation to their advantage. Push Chain's `x/uexecutor` module has the same class of primitive: whenever it needs to swap a bridged PRC20 into native PC (on `GAS`/`GAS_AND_PAYLOAD` inbound execution and on outbound gas-refund with swap), it fetches a spot quote from the Uniswap V3 `QuoterV2.quoteExactInputSingle` and derives `minPCOut` as a fixed 95% of that instantaneous quote, with no TWAP, no oracle cross-check, and no protection against the underlying pool being moved immediately beforehand.

### Finding Description
`Keeper.GetSwapQuote` calls `quoteExactInputSingle` on the configured Uniswap V3 quoter to price `prc20 → WPC` [1](#0-0) . This spot quote is then used, unchecked against any historical/TWAP reference, to compute `minPCOut = quote * 95 / 100` before the module actually performs the swap via `CallPRC20DepositAutoSwap`: [2](#0-1) 
The identical pattern recurs in `gasAndPayloadDepositAutoSwap` for `GAS_AND_PAYLOAD` inbounds [3](#0-2) , and again in `applyGasRefund`/`getSwapQuoteForRefund` when refunding unused destination-chain gas fees through a swap back to PC [4](#0-3) .

Because `quoteExactInputSingle` reflects the pool's *current* reserves/`sqrtPriceX96`, any unprivileged actor can move the same Uniswap V3 pool (a normal, permissionless swap) immediately before the module's finalizing transaction executes in the same block, deflating the quote the module reads. Since `minPCOut` is derived directly from that deflated quote (with only a fixed 5% cushion), the module's own swap will then execute at that manipulated, unfavourable price and still satisfy the slippage check — the attacker un-does their price impact afterward (reversing the swap) and pockets the difference, exactly analogous to how the Curve LP attacker forced `virtual_price` down immediately before the price-dependent RiskEngine action and then reversed the pool state. No TWAP, oracle cross-check, or external gas-price/registry price bound is consulted anywhere in this path — the search for `TWAP`/`slippage`/`observe(` confirms only the fixed 5% constant exists as protection.

### Impact Explanation
This corrupts PRC20/native-asset accounting and refund accounting: the amount of native PC actually credited to a user's UEA on inbound (or refunded to a user on outbound gas-refund) can be pushed down to the 5%-below-spot floor by an attacker who sandwiches the module's own swap, with the difference captured as MEV/arbitrage profit by the attacker rather than delivered to the depositing/refunded user. Given deposits can be arbitrarily large and the discount is a flat percentage of notional, the extractable value scales with the size of each individual bridged deposit or refund, directly fitting the "corruption of PRC20 or native asset accounting... or refund accounting" allowed-impact category, reachable purely from ordinary unprivileged user/attacker interaction with the same on-chain Uniswap V3 pool (no validator, relayer, or governance privilege required).

### Likelihood Explanation
Likelihood is moderate-to-high: the attacker does not need to compromise any validator or relayer — they only need (a) visibility into a pending inbound/outbound finalization (observable on-chain state, e.g. ballot vote counts nearing 2/3 or `MsgVoteInbound`/`MsgVoteOutbound` transactions in the mempool) and (b) the ability to submit an ordinary swap transaction against the same Uniswap V3 pool with sufficient priority/gas to land before the module's finalizing transaction in the same block — both standard, permissionless MEV/front-running capabilities on an EVM-compatible chain. The fixed 5% band is the only defense, so the attack is bounded but reliably profitable whenever the pool's liquidity is thin relative to the swapped notional.

### Recommendation
Do not derive `minPCOut` purely from an instantaneous `QuoterV2` call. Use a manipulation-resistant reference price (e.g., a Uniswap V3 TWAP `observe()` window, or cross-check the quote against the `x/uexecutor` chain-meta/registry price data already collected by Universal Validators) before accepting the spot quote, and/or tighten the acceptable deviation between the spot quote and the TWAP reference rather than relying on a flat 5% cushion applied to a value the attacker can freely move.

### Proof of Concept
1. Attacker monitors Push Chain for a large pending `GAS_AND_PAYLOAD` (or `GAS`) inbound about to be finalized (visible via `MsgVoteInbound` votes approaching 2/3 quorum), or a pending outbound refund-with-swap.
2. Immediately before the finalizing transaction lands (same block, higher-priority tx), attacker swaps a large amount of the same `prc20` token into the Uniswap V3 pool used by `quoterAddr`/`wpcAddr` (`GetUniversalCoreQuoterAddress`/`GetUniversalCoreWPCAddress`), depressing the pool's `token/WPC` price.
3. The module's finalizing call executes `GetSwapQuote` [1](#0-0) , reading the now-depressed spot quote, and computes `minPCOut = quote * 95 / 100` [5](#0-4) .
4. `CallPRC20DepositAutoSwap` executes the module's real swap against the still-depressed pool, delivering less PC to the user's UEA (or refund recipient) than the true pre-manipulation value would have allowed.
5. Attacker reverses their initial swap in a subsequent transaction, restoring the pool price and capturing the price-impact difference as profit, net of pool fees — mirroring the report's "manipulate → act on stale/skewed price → reverse" pattern.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}

// getSwapQuoteForRefund fetches a Uniswap quote for the gas token refund swap.
func (k Keeper) getSwapQuoteForRefund(ctx sdk.Context, gasToken common.Address, fee *big.Int, amount *big.Int) (*big.Int, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(ctx)
	if err != nil {
		return nil, err
	}
	wpcAddr, err := k.GetUniversalCoreWPCAddress(ctx)
	if err != nil {
		return nil, err
	}
	return k.GetSwapQuote(ctx, quoterAddr, gasToken, wpcAddr, fee, amount)
}
