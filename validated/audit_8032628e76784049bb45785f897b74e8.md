## Finding

### Title
Starknet OS `replace_class` syscall implementation omits the "class must be declared" check enforced by Blockifier - ([File: crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo])

### Summary
The Blockifier (the actual transaction-execution engine that determines the committed state) rejects a `replace_class` syscall whose target `class_hash` is not a declared class (and, for Cairo 1, also rejects it if the class is not Cairo 1). The Starknet OS Cairo program, which re-executes the same transactions to build the proof of block correctness, implements `replace_class` without this validation at all — the check is explicitly called out as missing via a `TODO` comment.

### Finding Description
Blockifier's shared syscall logic validates the class before permitting a class replacement: [1](#0-0) 

The deprecated (Cairo 0) syscall path enforces an analogous check: [2](#0-1) 

If `class_hash` is not declared, `get_compiled_class` returns an error, the syscall (and therefore the enclosing call) reverts, and the resulting state diff for that transaction contains no class-hash change for the target contract.

In contrast, the Starknet OS Cairo implementation of the same syscall performs no such validation before writing the new `class_hash` into `contract_state_changes`: [3](#0-2) 

Note the explicit acknowledgment of the gap: `// TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.` The deprecated (Cairo 0) OS syscall implementation has the identical omission: [4](#0-3) 

Because the OS's `GetContractAddressStateEntry` hint simply supplies whatever prover-provided value it is given, and no Cairo `assert` enforces declaration, the OS unconditionally accepts and commits the class-hash update — even for an undeclared (or non-Cairo1, in the Cairo1 case) class hash that Blockifier would have reverted.

### Impact Explanation
This is a logic divergence between the node's real execution engine (Blockifier, which determines the state committed on-chain) and the Starknet OS program (which recomputes/proves that same state transition). For a transaction that calls `replace_class` with an undeclared class hash:
- Blockifier reverts the inner call, and the committed state diff shows no class-hash change (only the fee/nonce effects of a reverted transaction).
- The Starknet OS accepts the same call unconditionally and commits the class-hash change into `contract_state_changes`, which flows into the Patricia tree update and ultimately the state root.

This produces a wrong committed root relative to what the sequencer's real execution intended, i.e., an honest-node/OS divergence on the resulting state commitment for the same transaction. Since the OS output feeds block hash and state-root commitments used for proving, this can cause a mismatch that leaves the block unprovable/unverifiable, which can halt production of valid proofs for otherwise valid blocks — a network availability impact matching the CWE-285 "improper authorization"/DoS bug class in the reference advisory (there, missing authorization allowed unauthorized issuer-metadata mutation causing PKI mount DoS; here, missing declared-class validation allows the OS to accept a state mutation Blockifier itself would reject, causing a computed-state mismatch).

### Likelihood Explanation
Any account contract can trigger this by calling `replace_class` (a Cairo1 syscall exposed to every contract) with an arbitrary, undeclared class hash — no special privileges are required beyond deploying/controlling a contract and submitting an ordinary invoke transaction. The condition (an undeclared class hash) is trivially satisfiable by any sender.

### Recommendation
Add the same declared-class (and, for the Cairo1 execute_replace_class, Cairo1-type) validation to the OS's `execute_replace_class` in `syscall_impls.cairo` and to the deprecated variant in `deprecated_execute_syscalls.cairo`, mirroring the checks in `crates/blockifier/src/execution/syscalls/syscall_base.rs::replace_class` and `crates/blockifier/src/execution/deprecated_syscalls/hint_processor.rs::replace_class`, so that both execution paths behave identically and produce consistent state diffs.

### Proof of Concept
1. Deploy a Cairo 1 contract exposing an entry point that invokes the `replace_class` syscall with a caller-supplied `class_hash`.
2. Submit an invoke transaction calling this entry point with an arbitrary, never-declared `class_hash`.
3. Under Blockifier (actual sequencer execution): `get_compiled_class` fails, `replace_class` returns `SyscallExecutionError`, the call/transaction reverts, and no class-hash change is recorded in the state diff.
4. Under the Starknet OS Cairo re-execution (used to build the state/proof for the same block): `execute_replace_class` in `syscall_impls.cairo` performs the update unconditionally (no assertion on declaration), committing the class-hash change into `contract_state_changes` and thus into the computed state root — diverging from the Blockifier-committed result for the identical transaction.

    pub fn replace_class(&mut self, class_hash: ClassHash) -> SyscallResult<()> {
        // Ensure the class is declared (by reading it), and of type V1.
        let compiled_class = self.state.get_compiled_class(class_hash)?;

        if !is_cairo1(&compiled_class) {
            return Err(SyscallExecutionError::ForbiddenClassReplacement { class_hash });
        }
        self.state.set_class_hash_at(self.call.storage_address, class_hash)?;
        Ok(())
    }

func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    let revert_log = &revert_log[1];
