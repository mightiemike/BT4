### Title
Degenerate signer set with `signers = Some(vec![])` collapses the Nakamoto block-approval threshold to zero, allowing an unsigned block to pass `verify_signer_signatures` - (File: stackslib/src/chainstate/stacks/boot/mod.rs, stackslib/src/chainstate/nakamoto/mod.rs)

### Summary
`StacksChainState::make_signer_set` (the PoX-4/legacy reward-set signer computation used by `make_reward_set`) can legitimately return `Some(vec![])` — a signer list that is empty but not `None` — when every candidate signing key's `stacked_amt / threshold` floors to zero. `RewardSet::signers()` treats `Some(empty vec)` as "there is a signer set" (distinct from `None`), so `RewardSet::total_signing_weight()` returns `Ok(0)` instead of an error. `NakamotoBlockHeader::compute_voting_weight_threshold(0)` then evaluates to `0`. In `NakamotoBlockHeader::verify_signer_signatures`, a block with zero signer signatures has `total_weight_signed == 0`, and the check `total_weight_signed < threshold` (`0 < 0`) is false, so the function returns `Ok(0)` — signature verification succeeds with no signatures at all.

### Finding Description
This is the direct analog of the Balancer `WeightedPool` bug: an "empty balance" (here, zero total signer weight) causes the required "amount" (the signer approval threshold) to degrade to zero, letting an operation (block approval) succeed for free.

Root cause chain:
1. `StacksChainState::make_signer_set` [1](#0-0)  only returns `None` when the input `entries` slice itself is empty. If `entries` is non-empty but every entry's `stacked_amt / threshold` computes to `0`, the `filter_map` drops every entry and the function still returns `Some(signer_set)` with `signer_set` empty.
2. This is invoked from `StacksChainState::make_reward_set` [2](#0-1)  and packed into `RewardSet::V0(RewardSetV0 { signers: signer_set, .. })` [3](#0-2) , reachable from `OnChainRewardSetProvider::get_reward_set_epoch2` for the PoX-4 era of Nakamoto [4](#0-3) .
3. `RewardSet::signers()` distinguishes `None` (no set) from `Some(&vec![])` (an empty-but-present set) [5](#0-4) , and `total_signing_weight()` only errors on `None`, returning `Ok(0)` for an empty vec [6](#0-5) .
4. `compute_voting_weight_threshold` computes `(total_weight * 7) / 10`, which is `0` when `total_weight == 0` [7](#0-6) .
5. `verify_signer_signatures` fetches `signers` via the same `Some`/`None` distinction (so an empty-but-`Some` set passes the initial guard), computes `total_weight = 0`, `threshold = 0`, iterates zero signatures (`total_weight_signed = 0`), and the rejection check `total_weight_signed < threshold` fails to trigger, so the function returns `Ok(0)` instead of an error [8](#0-7) .

Notably, the newer PoX-5 signer-set computation path explicitly guards against this exact degenerate case (`if signer_set.is_empty() { return Err(ChainstateError::PoxNoRewardCycle) }`) [9](#0-8) , confirming that the legacy PoX-4/V0 path (`make_signer_set`/`make_reward_set`) is missing an equivalent safeguard. Downstream consumers of the reward set, such as `read_reward_set_at_calculated_block`, only check `rewarded_addresses().is_empty()` (a different field) and `signers().is_none()` — neither catches `signers() == Some(vec![])` [10](#0-9) .

### Impact Explanation
If this degenerate signer set is produced for a Nakamoto reward cycle (many distinct small stackers whose individual stacked amounts each floor below the per-slot threshold, while the aggregate participation still clears the coarser `enough_participation` check), the resulting `.signers` contract state and in-memory `RewardSet` yield a threshold of `0`. Any miner who wins sortition in that reward cycle can then produce and broadcast a Nakamoto block with an **empty `signer_signature` vector**, and `verify_signer_signatures` will accept it as validly signed. This breaks the core equality that a Nakamoto block must be approved by signer weight meeting a threshold — an invalid (unapproved) block would be accepted network-wide, since every node performs the same (buggy) verification. This matches the Critical bucket: "an invalid block accepted... network-wide."

### Likelihood Explanation
Triggering requires no majority/Sybil collusion and no privileged party — an unprivileged staker (or several independent small stackers) can structure PoX stacking amounts across enough distinct signing keys so that each individual key's share floors to zero slots under `make_signer_set`, while the aggregate still satisfies `enough_participation`. Because the miner role is separately, permissionlessly selected by sortition, a single miner who wins a sortition during such a reward cycle can exploit the zero threshold without any signer cooperation. This is minority-triggerable in the sense required by the rules: it needs a specific (but achievable) stacking distribution plus an ordinary winning-miner action, not majority signer collusion.

### Recommendation
- Add the same empty-signer-set guard used in the PoX-5 path to the legacy `make_signer_set`/`make_reward_set` path: treat `Some(vec![])` as equivalent to "no signer set" and fail reward-set computation (or fall back to `RewardSet::empty()`/an error) rather than silently producing a zero-weight signer set.
- In `RewardSet::total_signing_weight()` and `NakamotoBlockHeader::verify_signer_signatures`, explicitly reject (rather than silently succeed with) a `total_weight == 0` reward set, and require `threshold > 0` before comparing against `total_weight_signed`.
- Add a defensive check in `verify_signer_signatures` that a block claiming to be validly signed must have at least one signer and `threshold > 0`.

### Proof of Concept
1. Construct PoX-4-era stacking registrations for reward cycle `N` such that the aggregate stacked amount clears `enough_participation`, but the stacking is split across many distinct signing keys, each with `stacked_amt < threshold` (so each individual `stacked_amt / threshold == 0`).
2. During prepare-phase reward-set computation, `StacksChainState::make_reward_set` → `make_signer_set` returns `Some(vec![])` for the `.signers` field of the resulting `RewardSet::V0`.
3. `RewardSet::total_signing_weight()` returns `Ok(0)`; `NakamotoBlockHeader::compute_voting_weight_threshold(0)` returns `0`.
4. The miner who wins sortition in reward cycle `N` builds a Nakamoto block with `signer_signature = vec![]` (no signer approvals at all).
5. `NakamotoBlockHeader::verify_signer_signatures` computes `total_weight_signed = 0`, `threshold = 0`; since `0 < 0` is false, it returns `Ok(0)` — the block is treated as validly approved by signers and is accepted by all nodes evaluating the same reward set.

    pub fn make_signer_set(
        threshold: u128,
        entries: &[RawRewardSetEntry],
    ) -> Option<Vec<NakamotoSignerEntry>> {
        let Some(first_entry) = entries.first() else {
            // entries is empty: there's no signer set
            return None;
        };
        // signing keys must be all-or-nothing in the reward set
        let expects_signing_keys = first_entry.signer.is_some();
        for entry in entries.iter() {
            if entry.signer.is_some() != expects_signing_keys {
                panic!("FATAL: stacking-set contains mismatched entries with and without signing keys.");
            }
        }
        if !expects_signing_keys {
            return None;
        }

        let mut signer_set = BTreeMap::new();
        for entry in entries.iter() {
            let signing_key = entry
                .signer
                .expect("BUG: signing keys should all be set in reward-sets with any signing keys");
            if let Some(existing_entry) = signer_set.get_mut(&signing_key) {
                *existing_entry += entry.amount_stacked;
            } else {
                signer_set.insert(signing_key, entry.amount_stacked);
            };
        }

        let mut signer_set: Vec<_> = signer_set
            .into_iter()
            .filter_map(|(signing_key, stacked_amt)| {
                let weight = u32::try_from(stacked_amt / threshold)
                    .expect("CORRUPTION: Stacker claimed > u32::max() reward slots");
                if weight == 0 {
                    return None;
                }
                Some(NakamotoSignerEntry {
                    signing_key,
                    stacked_amt,
                    weight,
                })
            })
            .collect();

        // finally, we must sort the signer set: the signer participation bit vector depends
        //  on a consensus-critical ordering of the signer set.
        signer_set.sort_by_key(|entry| entry.signing_key);

        Some(signer_set)

    pub fn verify_signer_signatures(
        &self,
        reward_set: &RewardSet,
        epoch_id: StacksEpochId,
    ) -> Result<u32, ChainstateError> {
        let message = self.signer_signature_hash();
        let Some(signers) = reward_set.signers() else {
            return Err(ChainstateError::InvalidStacksBlock(
                "No signers in the reward set".to_string(),
            ));
        };

        // if this is a shadow block, then its signing weight is as if every signer signed it, even
        // though the signature vector is undefined.
        if self.is_shadow_block() {
            return Ok(self.get_shadow_signer_weight(reward_set)?);
        }

        let mut total_weight_signed: u32 = 0;
        // `last_index` is used to prevent out-of-order signatures
        let mut last_index = None;
        // Before Epoch 4.0, signature order check contained a bug, so gate the
        // strict ordering behavior on the epoch.
        let strict_order = epoch_id.enforces_strict_signature_order();

        let total_weight = reward_set
            .total_signing_weight()
            .map_err(|_| ChainstateError::NoRegisteredSigners(0))?;

        // HashMap of <PublicKey, (Signer, Index)>
        let mut signers_by_pk: HashMap<_, _> = signers
            .iter()
            .enumerate()
            .map(|(i, signer)| (&signer.signing_key, (signer, i)))
            .collect();

        for signature in self.signer_signature.iter() {
            let public_key = Secp256k1PublicKey::recover_to_pubkey_without_validating_low_s(
                message.bits(),
                signature,
            )
            .map_err(|_| {
                ChainstateError::InvalidStacksBlock(format!(
                    "Unable to recover public key from signature {}",
                    signature.to_hex()
                ))
            })?;

            let mut public_key_bytes = [0u8; 33];
            public_key_bytes.copy_from_slice(&public_key.to_bytes_compressed()[..]);

            let (signer, signer_index) = signers_by_pk.remove(&public_key_bytes).ok_or_else(|| {
                warn!(
                    "Found an invalid public key. Reward set has {} signers. Chain length {}. Signatures length {}",
                    signers.len(),
                    self.chain_length,
                    self.signer_signature.len(),
                );
                ChainstateError::InvalidStacksBlock(format!(
                    "Public key {} not found in the reward set",
                    public_key.to_hex()
                ))
            })?;

            // Enforce order of signatures
            if let Some(index) = last_index.as_ref() {
                if *index >= signer_index {
                    return Err(ChainstateError::InvalidStacksBlock(
                        "Signatures are out of order".to_string(),
                    ));
                }
                if strict_order {
                    last_index = Some(signer_index);
                }
            } else {
                last_index = Some(signer_index);
            }

            total_weight_signed = total_weight_signed
                .checked_add(signer.weight)
                .expect("FATAL: overflow while computing signer set threshold");
        }

        let threshold = Self::compute_voting_weight_threshold(total_weight)?;

        if total_weight_signed < threshold {
            return Err(ChainstateError::InvalidStacksBlock(format!(
                "Not enough signatures. Needed at least {} but got {} (out of {})",
                threshold, total_weight_signed, total_weight,
            )));
        }

        return Ok(total_weight_signed);

    /// Compute the threshold for the minimum number of signers (by weight) required
    /// to approve a Nakamoto block.
    pub fn compute_voting_weight_threshold(total_weight: u32) -> Result<u32, ChainstateError> {
        let threshold = NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD;
        let total_weight = u64::from(total_weight);
        let ceil = if (total_weight * threshold) % 10 == 0 {
            0
        } else {
            1
        };
        u32::try_from((total_weight * threshold) / 10 + ceil).map_err(|_| {
            ChainstateError::InvalidStacksBlock(
                "Overflow when computing nakamoto block approval threshold".to_string(),
            )
        })
    }
