## Analysis: Stale chain-meta gas price silently drives outbound/migration fee accounting

Push Chain's `x/uexecutor` chain-meta oracle is a direct structural analog to Olympus's RBS gas-price/oracle "heartbeat." Universal Validators periodically vote a per-chain gas price + block height into `x/uexecutor` via `MsgVoteChainMeta`, and `VoteChainMeta` explicitly implements a freshness gate for aggregating **new** votes: [1](#0-0) , filtering out any validator vote older than `chainMetaVoteStalenessSeconds` (300s) before computing the median that gets pushed on-chain [2](#0-1) .

However, that freshness gate only protects the *write* path. The *consumption* path has no equivalent check:

- `GetGasPriceByChain` reads `gasPriceByChainNamespace` straight from the `UniversalCore` contract with no timestamp check [3](#0-2) .
- `GetOutboundTxGasAndFees`, used to size the gas fee an ordinary user is charged for an outbound bridge transaction (and for `INBOUND_REVERT` outbounds via `buildRevertOutbound`), likewise reads `gasPrice`/`gasFee` with no freshness validation [4](#0-3) [5](#0-4) .

Notably, the `UniversalCore` contract's own ABI exposes `timestampObservedAtByChainNamespace`, i.e. it explicitly records `block.timestamp` for each chain's last-applied gas price (mirroring `beat()`'s `lastBeat`) [6](#0-5) . But a repo-wide search shows this getter is never called from any Go keeper code — it exists only in the ABI definition, never consumed. That is the smoking gun: the "heartbeat" data is recorded but nothing ever checks it before trusting the price for a financial calculation, exactly the gap the Olympus report flags for `Operator.operate()`/`swap()`.

If a specific external chain's RPC becomes unreachable or votes otherwise stop arriving for that `observedChainId` (a plausible, non-privileged operational condition — no validator dishonesty required), `LastAppliedChainHeight`/price on `UniversalCore` simply freezes indefinitely. Any ordinary user who submits an outbound-triggering transaction during that window still gets a gas fee computed from the frozen (stale) price via `GetOutboundTxGasAndFees`, with no rejection or fallback — the protocol keeps accepting outbounds priced against untrustworthy, unbounded-age data, just like OHM's walls kept swapping against an unsynced spread.

Given the required scope explicitly excludes "external chain compromise or oracle dishonesty *unless scoped code fails to authenticate, bind, or validate attacker-controlled data*," and this is a genuine missing validation in Push's own scoped keeper code (no staleness check gating consumption, despite the contract already tracking the needed timestamp), this qualifies as a valid analog finding.

### Title
Chain-meta gas price/oracle has no consumer-side staleness check, allowing outbound/revert fee accounting to silently rely on frozen data - (File: `x/uexecutor/keeper/gas_fee.go`, `x/uexecutor/keeper/evm.go`)

### Summary
`x/uexecutor` enforces a 300-second freshness window (`chainMetaVoteStalenessSeconds`) only when aggregating new validator votes into the chain-meta oracle. Every consumer of the resulting on-chain gas price (`GetGasPriceByChain`, `GetOutboundTxGasAndFees`, `GetGasFeeInfoForRevertOutbound`) reads the value with no check against its own recorded `timestampObservedAtByChainNamespace`, so if voting for a given external chain stalls (RPC outage, chain-specific downtime), the frozen price keeps being used indefinitely for real fee/gas accounting on outbound and revert transactions.

### Finding Description
`VoteChainMeta` only pushes a new price to `UniversalCore` once `chainMetaMinVotesForFirstWrite`/fresh-vote conditions are met, and filters stale votes before computing the median [7](#0-6) . If votes for a given `observedChainId` stop being submitted (any Universal Validator's `ChainMetaOracle.fetchAndVoteChainMeta` loop simply `continue`s forever on RPC failure with no alerting/circuit-breaker, e.g. [8](#0-7) ), `LastAppliedChainHeight` and the on-chain gas price never advance again, but nothing marks the stored value as expired.

Every downstream reader treats this frozen value as current:
- `GetGasPriceByChain` — direct read, no timestamp check [3](#0-2) .
- `GetOutboundTxGasAndFees` — used to compute `GasToken`/`GasFee`/`GasPrice`/`GasLimit` attached to every outbound tx built from a user's payload [4](#0-3) , consumed in `attachOutboundsToUtx`/event emission [9](#0-8) .
- `GetGasFeeInfoForRevertOutbound`/`buildRevertOutbound` — same unguarded read for `INBOUND_REVERT` outbounds [5](#0-4) .

The `UniversalCore` ABI defines exactly the getter (`timestampObservedAtByChainNamespace`) needed to implement a `beat()`-style freshness check [6](#0-5) , but it is never invoked by any keeper code path — confirmed by repo-wide search showing zero call sites outside its own ABI declaration.

### Impact Explanation
When the gas-price oracle for a specific external chain silently stalls, users can continue to submit funds/payload transactions that generate outbound transactions on that chain. The `GasFee`/`GasPrice` charged from the user's PRC20 balance is computed from the stale/frozen price rather than the true prevailing cost. If real-world gas costs on the destination chain have since risen, the protocol/TSS wallet absorbs the shortfall when actually broadcasting the outbound transaction (a form of unauthorized/uncompensated loss of protocol-controlled funds), while if real costs have fallen, users are systematically overcharged. This mirrors the Olympus impact class: mechanism keeps operating on data that is not "guaranteed synced," and the resulting mispriced value flow is drained/absorbed by the protocol without any circuit breaker.

### Likelihood Explanation
Likelihood is moderate: it requires only a naturally occurring, non-privileged condition (an RPC/chain outage or persistent vote failure for one specific observed chain) rather than any validator misbehavior or admin/governance abuse. Given `ChainMetaOracle.fetchAndVoteChainMeta` has no staleness alarm and simply retries silently on error, and `x/uexecutor` never gates consumption on `timestampObservedAtByChainNamespace`, any ordinary user transacting during such a window is unknowingly exposed to (or exploiting) mispriced fee accounting, with no on-chain safeguard to detect or reject it.

### Recommendation
Add a consumption-side staleness check mirroring the ingestion-side `chainMetaVoteStalenessSeconds` gate: before using `GetGasPriceByChain`/`GetOutboundTxGasAndFees` results, call `timestampObservedAtByChainNamespace` (or track `StoredAts`/`LastAppliedChainHeight` age in `x/uexecutor` state) and reject or fall back safely (e.g., pause outbound creation, or require an explicit re-quorum) when `block.timestamp - observedAt > SYNC_THRESHOLD`. This closes the same class of gap the Olympus report identified for `Operator.operate()`.

### Proof of Concept
1. UVs are actively voting `MsgVoteChainMeta` for `eip155:X`; oracle is bootstrapped and `LastAppliedChainHeight`/price are set on `UniversalCore`.
2. The public RPC endpoint(s) used by all UVs for `eip155:X` become unreachable (or the chain halts) — `fetchAndVoteChainMeta` errors and `continue`s every interval, so no new votes for `eip155:X` are ever recorded again.
3. Real gas prices on `eip155:X` subsequently spike (e.g., congestion).
4. A user submits a bridging/payload transaction whose outbound targets `eip155:X`. `BuildOutboundsFromReceipt`/`GetOutboundTxGasAndFees` compute `GasFee` from the long-frozen, now-understated on-chain price [10](#0-9) .
5. The outbound is queued and eventually broadcast by TSS at real (higher) cost; the protocol/TSS wallet covers the difference not collected from the user, with no mechanism having ever flagged the price as stale.

// GetGasPriceByChain reads the gas price for a chain from the UniversalCore contract.
func (k Keeper) GetGasPriceByChain(ctx sdk.Context, chainNamespace string) (*big.Int, error) {
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse UniversalCore ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	receipt, err := k.evmKeeper.CallEVM(ctx, abi, ueModuleAccAddress, handlerAddr, false, nil, "gasPriceByChainNamespace", chainNamespace)
	if err != nil {
		return nil, errors.Wrap(err, "failed to call gasPriceByChainNamespace")
	}

	results, err := abi.Methods["gasPriceByChainNamespace"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack gasPriceByChainNamespace result")
	}

	return results[0].(*big.Int), nil
}

func (k Keeper) GetOutboundTxGasAndFees(ctx sdk.Context, prc20 common.Address, gasLimitWithBaseLimit *big.Int) (*GasFeeInfo, error) {
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	ucABI, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse UniversalCore ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	receipt, err := k.evmKeeper.CallEVM(ctx, ucABI, ueModuleAccAddress, handlerAddr, false, nil,
		"getOutboundTxGasAndFees", prc20, gasLimitWithBaseLimit)
	if err != nil {
		return nil, errors.Wrap(err, "failed to call getOutboundTxGasAndFees")
	}

	results, err := ucABI.Methods["getOutboundTxGasAndFees"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack getOutboundTxGasAndFees result")
	}

	gasToken := results[0].(common.Address)
	gasFee := results[1].(*big.Int)
	// protocolFee := results[2].(*big.Int) — not needed for outbound fields
	gasPrice := results[3].(*big.Int)
	// chainNamespace := results[4].(string) — not needed for outbound fields
	// gasLimitUsed (results[5]) is the exact gas limit the contract resolved
	// (caller-supplied or per-chain baseGasLimitByChainNamespace fallback).
	// Reading it directly avoids the gasFee/gasPrice round-trip and keeps us
	// in lock-step with the contract's own resolution.
	gasLimit := results[5].(*big.Int)

	return &GasFeeInfo{
		GasToken: gasToken,
		GasFee:   gasFee,
		GasPrice: gasPrice,
		GasLimit: gasLimit,
	}, nil
}

func (k Keeper) attachOutboundsToUtx(
	ctx sdk.Context,
	utxId string,
	outbounds []*types.OutboundTx,
	revertMsg string, // revert msg if the outbound is for a inbound revert
) error {

	if len(outbounds) == 0 {
		return nil
	}
	return k.UpdateUniversalTx(ctx, utxId, func(utx *types.UniversalTx) error {

		for _, outbound := range outbounds {

			utx.OutboundTx = append(utx.OutboundTx, outbound)

			// Compute signature expiry deadline for the destination chain.
			var signingDeadline int64
			if chainCfg, err := k.uregistryKeeper.GetChainConfig(ctx, outbound.DestinationChain); err == nil {
				if chainCfg.TssSigningDeadline != nil && *chainCfg.TssSigningDeadline > 0 {
					signingDeadline = ctx.BlockTime().Unix() + int64(chainCfg.TssSigningDeadline.Seconds())
				}
			}

			// Write to pending outbounds index (inside UpdateUniversalTx closure for atomicity)
			if err := k.PendingOutbounds.Set(ctx, outbound.Id, types.PendingOutboundEntry{
				OutboundId:      outbound.Id,
				UniversalTxId:   utxId,
				CreatedAt:       ctx.BlockHeight(),
				SigningDeadline: signingDeadline,
			}); err != nil {
				return fmt.Errorf("failed to set pending outbound index for %s: %w", outbound.Id, err)
			}

			var pcTxHash string
			var logIndex string

			if outbound.PcTx != nil {
				pcTxHash = outbound.PcTx.TxHash
				logIndex = outbound.PcTx.LogIndex
			}

			evt, err := types.NewOutboundCreatedEvent(types.OutboundCreatedEvent{
				UniversalTxId:    utxId,
				TxID:             outbound.Id,
				DestinationChain: outbound.DestinationChain,
				Recipient:        outbound.Recipient,
				Amount:           outbound.Amount,
				AssetAddr:        outbound.ExternalAssetAddr,
				Sender:           outbound.Sender,
				Payload:          outbound.Payload,
				GasFee:           outbound.GasFee,
				GasLimit:         outbound.GasLimit,
				GasPrice:         outbound.GasPrice,
				GasToken:         outbound.GasToken,
				TxType:           outbound.TxType.String(),
				PcTxHash:         pcTxHash,
				LogIndex:         logIndex,
				RevertMsg:        revertMsg,
				SigningDeadline:  signingDeadline,
			})
			if err == nil {
				ctx.EventManager().EmitEvent(evt)
			}
		}
