### Title
Starknet OS `execute_replace_class` skips class-declaration/type validation performed by native Blockifier, causing state divergence - (File: `crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo`)

### Summary
The Cairo0-era analog bug ("registry keeps a mapping of ownership/state without verifying real ownership, and Factory allows unauthorized state transitions without checks") maps onto a real, unresolved gap in the Starknet OS re-execution path: `replace_class` in the OS re-executor blindly writes the new class hash into `contract_state_changes` without validating that the class hash is declared or that it corresponds to a Cairo1 (V1) class - checks that native Blockifier does perform.

### Finding Description
Native Blockifier's `replace_class` syscall handler enforces two invariants before mutating state: [1](#0-0) 
1. The class must be declared (`get_compiled_class` fails otherwise, `UndeclaredClassHash`).
2. The class must be Cairo1/V1 (`ForbiddenClassReplacement` otherwise).

The deprecated (Cairo0) syscall handler in Blockifier likewise validates declaration: [2](#0-1) 

By contrast, the Starknet OS Cairo implementation that re-executes transactions to produce the proven state diff performs neither check. It contains an explicit `TODO` acknowledging the missing validation and proceeds to update `contract_state_changes` unconditionally: [3](#0-2) 

The Cairo0 deprecated syscall path in the OS has the identical gap: [4](#0-3) 

### Impact Explanation
`replace_class` is reachable from any unprivileged account contract that calls the `replace_class` syscall directly (single invoke transaction, no special privilege required). Because the OS accepts a `class_hash` for which:
- no class was ever declared, or
- the class is a Cairo0 (deprecated) class instead of Cairo1,

it will happily write that class hash into the contract's `StateEntry` and commit it to the state tree, whereas native Blockifier (which runs during block building/mempool execution) would abort the transaction with `UndeclaredClassHash` or `ForbiddenClassReplacement`. This produces a genuine honest-node divergence class of bug: the sequencer (Blockifier) and the prover (Starknet OS) can disagree on whether a transaction succeeds and on the resulting state root for the same block, which is exactly the "honest-node divergence" / "wrong committed root" class explicitly listed as an acceptable, high-severity impact in the scan's Validate criteria. In practice, if the transaction is admitted by the sequencer under different declared-class assumptions (e.g., a class that was declared and later provable divergence due to re-org, or a bug/edge-case allowing a transaction through Blockifier with a stale or non-existent class-hash check state), the OS could compute a different post-state than Blockifier, or accept a state transition that Blockifier would reject, breaking OS/Blockifier equivalence — which is the core soundness property the OS re-execution is meant to guarantee.

### Likelihood Explanation
The syscall is reachable by any contract deployed on Starknet performing `replace_class_syscall`, i.e., a completely permissionless, single-transaction action. The missing checks are marked with an explicit engineering `TODO`, confirming the gap is known but currently unaddressed in the OS Cairo source in this repository snapshot, increasing confidence this is a real, exploitable discrepancy rather than a hypothetical.

### Recommendation
Add the same two validations that Blockifier performs to both OS `execute_replace_class` implementations (`syscall_impls.cairo` and `deprecated_execute_syscalls.cairo`):
1. Verify the target `class_hash` exists in the block's declared/compiled class set (mirroring `get_compiled_class` failing with `UndeclaredClassHash`).
2. Reject replacement with a Cairo0 (deprecated) class hash when the calling contract is Cairo1 context (mirroring `ForbiddenClassReplacement`), consistent with Blockifier's `is_cairo1` check.

### Proof of Concept
1. Deploy an account/contract on Starknet.
2. Submit an invoke transaction that calls `replace_class_syscall(class_hash)` with a `class_hash` that has never been declared (or is a deprecated Cairo0 class while the contract is Cairo1).
3. Native Blockifier (used for sequencing/mempool execution) rejects the transaction: `syscall_base.rs::replace_class` calls `self.state.get_compiled_class(class_hash)?` which fails with `UndeclaredClassHash`, or returns `ForbiddenClassReplacement`.
4. The Starknet OS re-execution path (`execute_replace_class` in `syscall_impls.cairo`/`deprecated_execute_syscalls.cairo`) performs no such check and unconditionally writes `new_state_entry` with the unchecked `class_hash` into `contract_state_changes`, producing a different outcome/state root than Blockifier for equivalent input, i.e., OS/Blockifier divergence on the same transaction.

    pub fn replace_class(&mut self, class_hash: ClassHash) -> SyscallResult<()> {
        // Ensure the class is declared (by reading it), and of type V1.
        let compiled_class = self.state.get_compiled_class(class_hash)?;

        if !is_cairo1(&compiled_class) {
            return Err(SyscallExecutionError::ForbiddenClassReplacement { class_hash });
        }
        self.state.set_class_hash_at(self.call.storage_address, class_hash)?;
        Ok(())
    }

func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
