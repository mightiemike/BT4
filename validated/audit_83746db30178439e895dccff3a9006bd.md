### Title
Missing "class is declared" check in Starknet OS `replace_class` syscall causes state-transition divergence from Blockifier - ([File: crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo])

### Summary
The Galaxy CVE stems from a code path that performs a state-mutating action (modifying/deleting a Page or Visualization) without validating that the caller is authorized to act on that specific object. The closest reachable analog in this sequencer is not an ownership bypass (the `replace_class` syscall is already scoped to `execution_context.execution_info.contract_address`, i.e., a contract can only ever replace its own class), but a **missing validity check that the target class hash is actually declared** in the Starknet OS (Cairo) implementation of `execute_replace_class`, while the equivalent Rust `blockifier` implementation *does* enforce this check. This asymmetry lets a transaction that the sequencer's `blockifier` execution engine rejects (or reverts) be silently accepted as a valid, undeclared-class state change when re-executed/proved by the Starknet OS.

### Finding Description
In the Rust `blockifier`, `replace_class` explicitly requires the class to be declared before allowing the state mutation: [1](#0-0) 

This is confirmed by tests that assert calling `replace_class` with an undeclared class hash fails with `"is not declared"`: [2](#0-1) [3](#0-2) 

However, the Cairo implementation of the same syscall inside the Starknet OS program — which is the code that gets re-executed and proved (the source of truth committed on L1) — has an explicit, acknowledged TODO showing the equivalent check was never implemented: [4](#0-3) 

The same gap exists in the deprecated (Cairo0) syscall path of the OS: [5](#0-4) 

Because the OS unconditionally performs the `dict_update` on `contract_state_changes` regardless of whether `class_hash` corresponds to a declared class, while the `blockifier` aborts/reverts the same call when the class is undeclared, the two execution engines can compute **different resulting states for the same transaction**. The `blockifier` is used by the sequencer to build and commit the block (compute the state diff / root), while the Starknet OS is the Cairo program that re-executes transactions to produce the STARK proof validating that state root on L1. A soundness/consistency gap between the two engines for a syscall that mutates a contract's class hash (i.e., attacker-controlled bytecode indirection) is a state-transition-function divergence bug.

### Impact Explanation
Any unprivileged user can call `replace_class` on a contract they control (an account or arbitrary contract that invokes the syscall) supplying an undeclared class hash:
- The `blockifier`, which the sequencer uses to execute and commit blocks, will reject/revert this call (class must be declared).
- The Starknet OS, used to re-derive and prove the same transaction's effect, will apply the class-hash overwrite unconditionally since the "declared" check is missing (per the TODO).

This produces honest-node/prover divergence: the state diff/root computed during proof generation would not match the state diff/root the sequencer actually committed, which can block state root finalization, cause proof verification failures, or in the worst case allow a state root to be finalized that reflects a class hash the network never validated as declared — undermining a fundamental invariant of the class-hash/CASM validation pipeline. This falls into "wrong committed root or block hash, honest-node divergence" and "network unable to confirm new transactions" categories.

### Likelihood Explanation
Likelihood is high: `replace_class` is a standard, unprivileged syscall reachable from any invoke transaction executed by a contract that calls it on itself (see `test_replace_class` external entry points in feature contracts). Triggering the divergence requires no special permissions — only supplying an arbitrary/undeclared class hash as the syscall argument, which any contract deployer/caller can do trivially.

### Recommendation
Implement the declared-class check in the Starknet OS `execute_replace_class` functions (both `syscall_impls.cairo` and `deprecated_execute_syscalls.cairo`) to mirror the blockifier's behavior — i.e., verify `class_hash` corresponds to a class present in `contract_class_changes` / previously declared state before performing the `dict_update`, and revert the syscall (write a failure response / propagate the error) otherwise, exactly as `syscall_handler.state.get_compiled_class(request.class_hash)?` does in `blockifier`. This must be resolved and audited before removing the TODO, ensuring identical revert semantics between blockifier and OS.

### Proof of Concept
1. Deploy any contract exposing a call to the `replace_class` syscall (e.g., `test_replace_class`, as in `crates/blockifier_test_utils/resources/feature_contracts/cairo0/test_contract.cairo` and `cairo1/test_contract.cairo`).
2. Submit an invoke transaction calling this entry point with an arbitrary, undeclared `class_hash`.
3. Observe that `blockifier`-based execution (sequencer path) rejects this call ("is not declared"), causing the invoke transaction to revert without changing `class_hash`.
4. Trace the equivalent transaction through the Starknet OS's `execute_replace_class` (`syscall_impls.cairo` lines 881-920 / `deprecated_execute_syscalls.cairo` lines 307-329): because the "is declared" check is absent (per the TODO comment at line 902), the OS applies the class-hash state change unconditionally — producing a different `contract_state_changes` result than the blockifier's actual execution, i.e., a state root/diff divergence between the two engines for the same transaction.

// Replaces the class.
func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
