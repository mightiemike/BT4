### Title
Unauthenticated access to LOOP plugin `pprof` debug endpoints - ([File: core/web/router.go])

### Summary
The `loopRoutes` function registers `/plugins/:name/debug/pprof/*profile` (GET) and `/plugins/:name/debug/pprof/symbol` (POST) directly on the shared `api` router group without any authentication middleware applied. Unlike `debugRoutes`, which explicitly wraps `/debug/vars` in `auth.Authenticate(...)`, and `sessionRoutes`/`v2Routes`, which create their own authenticated sub-groups, `loopRoutes` uses the bare `r` group inherited from `engine.Group("/", rateLimiter(...), sessions.Sessions(...))`, which has no auth requirement.

### Finding Description
In `core/web/router.go`, `NewRouter` builds the base group: [1](#0-0) 
This `api` group only has rate limiting and session-cookie middleware attached — no call to `auth.Authenticate`. Compare this with `debugRoutes`, which deliberately creates its own authenticated sub-group before exposing `/debug/vars`: [2](#0-1) 
and `sessionRoutes`, which splits unauthenticated vs authenticated sub-groups explicitly: [3](#0-2) 

However, `loopRoutes` registers its handlers directly on the passed-in `r` (the unauthenticated `api` group) with no auth wrapper at all: [4](#0-3) 

This means `pluginPPROFHandler` and `pluginPPROFPOSTSymbolHandler` in `core/web/loop_registry.go` are reachable by any unauthenticated client that can reach the Chainlink node's web server: [5](#0-4) 

These handlers proxy the request to the LOOP plugin's internal `/debug/pprof/*` endpoint (`net/http/pprof`) running at `l.loopHostName:p.EnvCfg.PrometheusPort`, forwarding attacker-controlled query parameters (`debug`, `gc`, `seconds`) and, for the symbol endpoint, the raw POST body, via `doRequest`: [6](#0-5) 

An unauthenticated attacker who can reach the node's HTTP API can:
- Hit `GET /plugins/:name/debug/pprof/profile?seconds=N` to force the plugin to perform CPU profiling for an attacker-chosen duration (bounded loosely by `PPROFOverheadSeconds` plus the `seconds` param), causing sustained CPU overhead/DoS on the plugin process.
- Hit `GET /plugins/:name/debug/pprof/heap`, `/goroutine`, `/allocs`, etc. to exfiltrate memory/goroutine dumps of the LOOP plugin process, which can leak sensitive internal state (stack traces, in-memory data, addresses) — an information disclosure issue.
- Repeatedly trigger these endpoints to cause resource exhaustion (many concurrent profiling requests), since only the generic authenticated-rate-limiter from `api` group config applies but no auth check prevents anonymous access.

The `/discovery` and `/plugins/:name/metrics` endpoints on the same unauthenticated group are less severe (only proxy Prometheus metrics), but the `pprof` endpoints are materially more dangerous because pprof exposes internal runtime/heap/goroutine data and allows attacker-triggered CPU-intensive profiling.

### Impact Explanation
This is a real information-disclosure and denial-of-service vector reachable by an unprivileged, unauthenticated attacker with network access to the node's web server: it discloses internal plugin process runtime data (heap/goroutine/stack dumps) and allows attacker-triggered CPU profiling for arbitrary durations, degrading plugin/node performance. This matches Chainlink bounty impact categories for "unauthorized information disclosure" and "denial of service of a node" without requiring any credentials.

### Likelihood Explanation
High feasibility: the only precondition is that the node has at least one LOOP plugin registered (so `l.registry.Get(pluginName)` succeeds) and that the attacker can reach the node's public web API on the configured port — the standard exposure model for the Chainlink node web server. No authentication, CSRF token, or session is required, and the endpoint accepts and forwards arbitrary query parameters and POST bodies directly to the plugin's `net/http/pprof` handlers.

### Recommendation
Wrap `loopRoutes`'s pprof (and ideally metrics/discovery) endpoints in the same authenticated group pattern used by `debugRoutes`/`sessionRoutes`, e.g.:
```go
func loopRoutes(app chainlink.Application, r *gin.RouterGroup) {
	loopRegistry := NewLoopRegistryServer(app)
	authed := r.Group("/", auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession))
	authed.GET("/discovery", ginHandlerFromHTTP(loopRegistry.discoveryHandler))
	authed.GET("/plugins/:name/metrics", loopRegistry.pluginMetricHandler)
	authed.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)
	authed.POST("/plugins/:name/debug/pprof/symbol", loopRegistry.pluginPPROFPOSTSymbolHandler)
}
```
At minimum, the pprof routes should require authentication (session or admin role), consistent with how `/debug/vars` is protected.

### Proof of Concept
Integration test plan for `core/web/router_test.go` (or `loop_registry_test.go`):
1. Start a test `chainlink.Application` with a mock LOOP plugin registered in the loop registry (as done in existing `loop_registry_test.go` tests), and build the router via `NewRouter`.
2. Without setting any session cookie or Authorization header, issue `GET /plugins/<pluginName>/debug/pprof/heap` against the test server.
3. Assert the response status is `200 OK` and the body contains valid pprof heap profile data (proving the request reached the plugin's `net/http/pprof` handler without authentication) — expected/desired behavior is `401 Unauthorized`.
4. Repeat with `GET /plugins/<pluginName>/debug/pprof/profile?seconds=5` and assert unauthenticated success, demonstrating an attacker can force CPU profiling without credentials.
5. As a regression check after the fix, assert the same unauthenticated requests now return `401`/`403`, and that a request with a valid session cookie succeeds.

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method string, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}
