### Title
Sandwichable spot-price quote in Uniswap V3 gas-refund swap drains value from refund recipients - (File: `x/uexecutor/keeper/outbound.go`)

### Summary
The excess-gas refund path (`applyGasRefund` → `getSwapQuoteForRefund` → `CallUniversalCoreRefundUnusedGas`) derives its slippage floor (`minPCOut`) from a live Uniswap V3 `QuoterV2.quoteExactInputSingle` spot-price read taken immediately before the refund swap executes. Because the "reference price" and the "protection floor" are both sourced from the same manipulable AMM state, an unprivileged actor who sandwiches the pool around the block that finalizes the refund can force the module-originated swap to execute at an attacker-manipulated price while still satisfying its own 5%-derived floor, extracting value from the honest refund recipient. This mirrors the reported `_tryFinalize`/`LLido.sellWsteth` sandwich pattern: a fixed-percentage slippage check computed from a spot price that the attacker controls is not real slippage protection.

### Finding Description
When an outbound is finalized (successfully or with failure) via `VoteOutbound` → `FinalizeOutbound` → `handleSuccessfulOutbound`/`handleFailedOutbound`, any unused gas fee is refunded through `applyGasRefund`: [1](#0-0) 

The quote used to compute `minPCOut` comes from `getSwapQuoteForRefund`, which calls the on-chain Uniswap V3 `QuoterV2` against the live pool state: [2](#0-1) [3](#0-2) 

`minPCOut` is then set to a flat `quote * 95 / 100` and passed straight into `CallUniversalCoreRefundUnusedGas`, which performs the real swap (`refundUnusedGas(... withSwap=true ...)`) in the same call: [4](#0-3) 

Because the quote is read from the same spot AMM state as the swap that follows it, an attacker who moves the pool price *before* the refund transaction lands (via a front-run swap in the WPC/gas-token pool) causes both the "fair value" reference and the 95% floor to shift together. The floor therefore does not protect against price manipulation — only against unrelated price drift between two calls that in this codebase happen back-to-back with zero elapsed time. The same anti-pattern (spot quote + flat 5% floor, no TWAP, no oracle) is repeated in the deposit-with-autoswap paths: [5](#0-4) [6](#0-5) 

Refund/deposit recipients are ordinary users (the outbound `Sender` or `RevertInstructions.FundRecipient`), not validators or TSS participants, so this is reachable purely from honest users' normal cross-chain flows plus an unprivileged MEV actor observing pending `MsgVoteOutbound`/gas-refund-triggering transactions and inserting sandwich trades around them.

### Impact Explanation
This corrupts refund/deposit accounting: the amount of native PC (or PRC20-to-PC value) actually delivered to a legitimate user can be siphoned by an attacker performing a classic sandwich around the swap-based refund or auto-swap deposit, since the "slippage protection" tracks the manipulated price rather than a fair, attacker-resistant reference. This falls under the allowed impact "corruption of ... gas fee accounting, refund accounting ... PRC20 or native asset accounting" caused by an unprivileged external actor, with honest validators/UVs behaving normally — the vote-outbound finalization itself is legitimate, only the swap execution is exploited.

### Likelihood Explanation
Any actor with capital to move the relevant Uniswap V3 pool and the ability to order transactions around the module's `DerivedEVMCall` (e.g., via gas-price bidding / block-builder access) can trigger this whenever a refund or gas-and-payload deposit routes through the swap path with `withSwap=true`. No validator, TSS, or admin privilege is required — only observation of pending outbound-vote transactions/pending gas deposits and normal DEX interaction, which is realistic for MEV searchers on any EVM-compatible chain that exposes a public Uniswap V3 pool for the gas-token/PC pair.

### Recommendation
Do not derive both the swap's reference price and its slippage floor from the same instantaneous AMM read. Use a manipulation-resistant reference (e.g., a time-weighted average price from the pool, or an external oracle/registry-configured price) to bound `minPCOut`, and/or widen protections with commit-reveal or same-block-only execution guarantees so the quote cannot be front-run. At minimum, tighten or make configurable the slippage tolerance and add a maximum single-block price-impact circuit breaker before allowing `withSwap=true` execution in `applyGasRefund`, `ExecuteInboundGas`, and `gasAndPayloadDepositAutoSwap`.

### Proof of Concept
1. Attacker observes a pending outbound (`PendingOutbounds`) or gas-and-payload inbound whose refund/deposit will use the swap-with-slippage path (`applyGasRefund` in `x/uexecutor/keeper/outbound.go` or `gasAndPayloadDepositAutoSwap`/`ExecuteInboundGas`).
2. Once the last vote needed to finalize is visible in the mempool (or imminent), attacker submits a front-run swap on the WPC/gas-token Uniswap V3 pool used by `GetSwapQuote`, moving the spot price unfavorably for the pending refund/deposit.
3. The finalizing transaction executes `getSwapQuoteForRefund`/`GetSwapQuote` against the now-manipulated pool, computes `minPCOut = quote * 95/100` off that manipulated price, and `CallUniversalCoreRefundUnusedGas`/`CallPRC20DepositAutoSwap` executes at the bad price — satisfying its own floor because the floor was derived from the same manipulated state.
4. Attacker back-runs with the reverse swap, capturing the spread as profit extracted from the refund recipient's/depositor's expected value.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// CallUniversalCoreRefundUnusedGas calls refundUnusedGas on UniversalCore to return excess gas fee
// to the recipient. withSwap=true swaps the gas token back to PC; withSwap=false deposits PRC20 directly.
func (k Keeper) CallUniversalCoreRefundUnusedGas(
	ctx sdk.Context,
	gasToken common.Address,
	amount *big.Int,
	recipient common.Address,
	withSwap bool,
	fee *big.Int,
	minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse UniversalCore ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	// fee is uint24 in Solidity — pass as *big.Int (go-ethereum ABI packs non-standard widths as *big.Int)
	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress,
		handlerAddr,
		big.NewInt(0),
		nil,
		true,
		false,
		true,
		&nonce,
		"refundUnusedGas",
		gasToken,
		amount,
		recipient,
		withSwap,
		fee,
		minPCOut,
	)
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
