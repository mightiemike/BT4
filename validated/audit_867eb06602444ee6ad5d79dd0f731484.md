### Title
Unauthenticated `MethodPublicKeyGet` fast-path lacks per-caller rate limiting, allowing flood of `fanOutToVaultNodes` calls to vault DON - ([File: core/services/gateway/handlers/vault/handler.go])

### Summary
`HandleJSONRPCUserMessage` explicitly bypasses `requestProcessor.ProcessRequest` authorization for `vaulttypes.MethodPublicKeyGet` and, whenever `cachedPublicKeyObject` is nil (cold start, TTL/cache-miss window, or if quorum on the key was never reached), forwards the request to every DON member via `fanOutToVaultNodes` for each unique request ID. No caller-scoped or IP-scoped rate limiter gates this path before nodes are contacted.

### Finding Description
In `HandleJSONRPCUserMessage` [1](#0-0) , requests with `Method == MethodPublicKeyGet` skip the `requestProcessor.ProcessRequest` authorization call entirely (that call only happens later, for `IsGatewaySecretsMethod`) [2](#0-1) . When `getCachedPublicKey()` returns `nil` (cache empty/stale), the handler calls `newActiveRequest` then `handlePublicKeyGet`, which itself re-checks the cache and, on miss, calls `fanOutToVaultNodes` [3](#0-2) . `fanOutToVaultNodes` iterates over every DON member and calls `h.don.SendToNode` for each [4](#0-3) .

The only defense against repeated calls is the response cache populated by `tryCachePublicKeyResponse`, which is written only after a full quorum of node responses is aggregated via `HandleNodeMessage` [5](#0-4) . This is a round-trip dependent, best-effort mechanism — not a hard rate limit. There is no per-caller/IP throttling in this code path: `writeMethodsEnabled` (a global gate, not per-caller) only guards `MethodSecretsCreate/Update/Delete` [6](#0-5) , and `nodeRateLimiter` only rate-limits inbound node *responses*, keyed by `nodeAddr`, in `HandleNodeMessage` [7](#0-6)  — it does nothing to limit inbound user *requests*.

Tracing the call path from the HTTP entrypoint confirms there is no caller/IP based limiter applied before `HandleJSONRPCUserMessage` is invoked: `gateway.ProcessRequest` decodes the raw request, resolves a handler, and calls `h.HandleJSONRPCUserMessage(ctx, jsonRequest, callback)` directly, with no rate-limit check on the caller [8](#0-7) . The only per-request guard is a request-ID length/emptiness check and a `newActiveRequest` duplicate-ID rejection — both trivially bypassed by an attacker generating unique random IDs for every request [9](#0-8) , [10](#0-9) .

### Impact Explanation
An unprivileged attacker able to reach the gateway's user HTTP/websocket port can flood `MethodPublicKeyGet` with unique request IDs during any window where the public-key cache is empty or stale (startup, after a restart, after failed quorum, or simply by racing many concurrent requests before the first successful cache population). Each such request causes a fan-out write to every vault DON node (`h.don.SendToNode` for all `donConfig.Members`), consuming DON node bandwidth/compute and gateway memory (`activeRequests` map entries, each held until `requestTimeout` or response). This matches a DoS impact on gateway/vault DON capacity.

### Likelihood Explanation
Feasibility is high: the request requires no authentication, no valid secrets, and no special JWT — the code comment itself documents that this method "doesn't require authorization." The precondition (stale/empty cache) is realistic at node/gateway startup and recurring failure windows, and an attacker can also race many concurrent requests to exploit the gap between cache-check and cache-population regardless of steady-state caching. The attack is trivially repeatable with only unique UUID request IDs.

### Recommendation
Add a per-caller (or per-source-IP, since the request is unauthenticated) rate limiter that gates the `MethodPublicKeyGet` fast path before `newActiveRequest`/`fanOutToVaultNodes` is invoked, independent of the `writeMethodsEnabled` gate and the `nodeRateLimiter` (which only limits node responses). Additionally, consider coalescing concurrent in-flight `MethodPublicKeyGet` cache-miss requests into a single outstanding fan-out (singleflight pattern) so that N simultaneous callers during a cache-miss window trigger only one round of `fanOutToVaultNodes`.

### Proof of Concept
Integration test plan (extending `handler_test.go`):
1. Construct a `handler` with an empty `cachedPublicKeyObject` (simulate cold start / cache miss).
2. Mock `don.SendToNode` to count invocations.
3. Concurrently issue N (e.g. 1000) `HandleJSONRPCUserMessage` calls with `Method: MethodPublicKeyGet` and unique UUID `req.ID`s, no `req.Auth`.
4. Assert that `SendToNode` is called `N * len(donConfig.Members)` times (proving no per-caller limiter deduplicates/throttles), and that this scales linearly with attacker request volume with no rejection (`api.LimitExceededError`) ever returned.
5. Contrast with an expected fix where a caller-scoped limiter causes `SendResponse` with `api.LimitExceededError` after a bounded number of requests, and `SendToNode` invocation count is bounded independent of N.

func (h *handler) newActiveRequest(req jsonrpc.Request[json.RawMessage], callback gwhandlers.Callback) (*activeRequest, error) {
	h.mu.Lock()
	defer h.mu.Unlock()
	if h.activeRequests[req.ID] != nil {
		h.lggr.Errorw("request id already exists", "requestID", req.ID)
		return nil, errors.New("request ID already exists: " + req.ID)
	}
	ar := &activeRequest{
		Callback:  callback,
		req:       req,
		createdAt: h.clock.Now(),
		responses: map[string]*jsonrpc.Response[json.RawMessage]{},
	}
	h.activeRequests[req.ID] = ar
	return ar, nil
}

func (h *handler) tryCachePublicKeyResponse(resp *jsonrpc.Response[json.RawMessage], l logger.Logger) {
	if resp.Result == nil {
		l.Debugw("no result in public key response, not caching")
		return
	}

	r := &vaultcommon.GetPublicKeyResponse{}
	err := h.unmarshal(bytes.NewReader(*resp.Result), r)
	if err != nil {
		l.Debugw("failed to unmarshal public key response, not caching", "error", err)
		return
	}

	if r.PublicKey == "" {
		l.Debugw("no public key in unmarshaled response, not caching", "response", resp, "result", r)
		return
	}
	masterPublicKey := tdh2easy.PublicKey{}
	masterPublicKeyBytes, err := hex.DecodeString(r.PublicKey)
	if err != nil {
		l.Debugw("failed to decode master public key string", "error", err)
		return
	}
	err = masterPublicKey.Unmarshal(masterPublicKeyBytes)
	if err != nil {
		l.Debugw("failed to unmarshal master public key", "error", err)
		return
	}

	h.mu.Lock()
	h.cachedPublicKeyGetResponse = *resp.Result
	h.cachedPublicKeyObject = &masterPublicKey
	h.mu.Unlock()
	l.Debugw("successfully cached public key response")
}

func (h *handler) handlePublicKeyGet(ctx context.Context, ar *activeRequest) error {
	l := logger.With(h.lggr, "method", ar.req.Method, "requestID", ar.req.ID)

	publicKeyResponseBytes, cachedPublicKey := h.getCachedPublicKey()
	if cachedPublicKey != nil {
		l.Debugw("returning cached public key response")
		return h.sendSuccessResponse(ctx, l, ar, &jsonrpc.Response[json.RawMessage]{
			Version: jsonrpc.JsonRpcVersion,
			ID:      ar.req.ID,
			Method:  ar.req.Method,
			Result:  (*json.RawMessage)(&publicKeyResponseBytes),
		})
	}

	l.Debugw("cache stale: forwarding request to nodes", "now", h.clock.Now())
	return h.fanOutToVaultNodes(ctx, l, ar)
}

func (h *handler) fanOutToVaultNodes(ctx context.Context, l logger.Logger, ar *activeRequest) error {
	var nodeErrors []error
	for _, node := range h.donConfig.Members {
		err := h.don.SendToNode(ctx, node.Address, &ar.req)
		if err != nil {
			nodeErrors = append(nodeErrors, err)
			l.Errorw("error sending request to node", "node", node.Address, "error", err)
		}
	}

	if len(nodeErrors) == len(h.donConfig.Members) && len(nodeErrors) > 0 {
		return h.sendResponse(ctx, ar, h.errorResponse(ar.req, api.FatalError, errors.New("failed to forward user request to nodes"), nil))
	}

	l.Debugw("successfully forwarded request to Vault nodes")
	return nil
}

func (g *gateway) ProcessRequest(ctx context.Context, rawRequest []byte, auth string) (rawResponse []byte, httpStatusCode int) {
	// decode
	jsonRequest, err := jsonrpc2.DecodeRequest[json.RawMessage](rawRequest, auth)
	if err != nil {
		return newError("", api.UserMessageParseError, err.Error())
	}
	msg, err := g.codec.DecodeJSONRequest(jsonRequest)
	if err != nil {
		return newError(jsonRequest.ID, api.UserMessageParseError, err.Error())
	}
	if len(jsonRequest.ID) > 200 {
		// Arbitrary limit to prevent abuse
		return newError(jsonRequest.ID, api.UserMessageParseError, "request ID is too long: "+strconv.Itoa(len(jsonRequest.ID))+". max is 200 characters")
	}
	var isLegacyRequest = false
	var h handlers.Handler
	var handlerKey string
	if msg == nil || msg.Body.DonId == "" {
		serviceName := jsonRequest.ServiceName()
		if handler, ok := g.serviceToMultiHandler[serviceName]; ok {
			h = handler
			handlerKey = serviceName
		} else if donID, ok := g.serviceNameToDonID[serviceName]; ok {
			// Fallback to legacy service name -> DON ID mapping
			if handler, ok := g.handlers[donID]; ok {
				h = handler
				handlerKey = donID
			}
		}
		if h == nil {
			return newError(jsonRequest.ID, api.HandlerError, "Service name not found: "+serviceName)
		}
	} else {
		// Legacy request with DON ID - validate and fetch handler
		isLegacyRequest = true
		if err = msg.Validate(); err != nil {
			return newError(jsonRequest.ID, api.UserMessageParseError, err.Error())
		}
		handlerKey = msg.Body.DonId
		var ok bool
		h, ok = g.handlers[handlerKey]
		if !ok {
			return newError(jsonRequest.ID, api.UnsupportedDONIdError, "Unsupported DON ID: "+handlerKey)
		}
	}

	startTime := time.Now()
	var method string
	callback := handlerscommon.NewCallback()
	if isLegacyRequest {
		method = msg.Body.Method
		err = h.HandleLegacyUserMessage(ctx, msg, callback)
	} else {
		method = jsonRequest.Method
		err = h.HandleJSONRPCUserMessage(ctx, jsonRequest, callback)
	}
	if err != nil {
		return newError(jsonRequest.ID, api.HandlerError, err.Error())
	}
