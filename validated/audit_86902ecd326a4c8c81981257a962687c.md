### Title
Unauthorized free minting of PRC20/PC via gas-refund on auto-generated `INBOUND_REVERT` outbounds - (File: `x/uexecutor/keeper/outbound.go`, `x/uexecutor/keeper/build_revert_outbound.go`)

### Summary
This is the Push Chain analog of the FlatMoney "free points via cheap deposit/withdraw cycling" bug class: a value-accrual mechanism (here, the excess-gas-fee refund) can be triggered by an ordinary, unprivileged user through a cheap, self-inflicted inbound failure, minting brand-new PRC20/PC tokens that were never actually collected from anyone.

### Finding Description
`buildRevertOutbound` ( [1](#0-0) ) constructs an `INBOUND_REVERT` outbound whenever an inbound fails validation/execution. It sets `Amount = inbound.Amount` (the full original amount, unreduced) and separately populates `GasFee`/`GasPrice`/`GasLimit`/`GasToken` from a **read-only contract quote** (`GetGasFeeInfoForRevertOutbound` → `UniversalCore.getOutboundTxGasAndFees(prc20, 0)`, see [2](#0-1) ). This quote is never debited from any balance — it's purely informational, meant to size the relayer's gas budget for broadcasting the revert transaction.

When this `INBOUND_REVERT` outbound is later finalized (either `OBSERVED` or `REVERTED`), `FinalizeOutbound` unconditionally calls `applyGasRefund` regardless of `TxType` ( [3](#0-2) ):

```go
// Refund excess gas regardless of tx type — gas was consumed on the external
// chain whether the execution succeeded or failed.
k.applyGasRefund(ctx, &outbound, obs)
```

`applyGasRefund` computes `refundAmount = outbound.GasFee - obs.GasFeeUsed` and, if positive, mints that difference directly to the recipient via `CallUniversalCoreRefundUnusedGas` ( [4](#0-3) ). This logic is only safe for outbound types where `GasFee` was actually pre-collected/deducted from the user's principal on-chain (e.g. real withdrawal outbounds built from a `UniversalTxOutbound` contract event in `BuildOutboundsFromReceipt`, [5](#0-4) ). For `INBOUND_REVERT`, no such deduction ever happens — `Amount` stays the full inbound amount and `GasFee` is synthesized after the fact from a keeper-side quote, so the "refund" mints tokens that were never paid for by anyone.

An unprivileged attacker who can get any of their own inbound deposits to fail post-quorum validation/execution (e.g., a source-chain event with a valid amount but an invalid/empty recipient field, which they fully control when calling the source-chain gateway — see the `execute_inbound_gas_test.go` cases at [6](#0-5) ) will automatically get an `INBOUND_REVERT` outbound created via `handleFailedInboundValidation` ( [7](#0-6) ). Once UVs honestly observe this revert transaction land on the source chain and report the real `gas_fee_used`, the attacker collects `gasFee(quoted) - gasFeeUsed(real)` as newly minted tokens on top of getting their principal delivered back on the source chain.

### Impact Explanation
Each cycle mints PRC20/PC tokens that were never backed by any deposit, fee lock, or burn — a direct, unauthorized-mint invariant break in `x/uexecutor`'s accounting. Because the trigger (an inbound that fails post-quorum validation) is cheap and fully attacker-controlled, and the reward (`gasFee_quote - gasFeeUsed_real`) recurs on every cycle, this is structurally identical to the referenced report's "large amount of points minted without any cost": a scarce, protocol-issued value is farmed for near-zero net cost via repeated self-triggered cycles, at the expense of the protocol's token supply/backing.

### Likelihood Explanation
High for a motivated attacker: the only requirement is a real (but arbitrarily small) source-chain deposit that fails execution validation on Push Chain for a reason fully within the attacker's control (e.g., malformed/empty recipient, or other execution-time failure paths in `ExecuteInboundGas`/`ExecuteInboundFundsAndPayload`/`ExecuteInboundGasAndPayload`). No validator collusion, no admin/governance action, and no privileged role is required — only honest UVs reporting real observed data.

### Recommendation
- Gate `applyGasRefund` by `outbound.TxType`, excluding `INBOUND_REVERT` (and any other auto-generated/non-fee-collecting outbound type) the same way the funds-remint block in `handleFailedOutbound` is already scoped to `FUNDS`/`GAS_AND_PAYLOAD`/`FUNDS_AND_PAYLOAD`.
- Alternatively, stop populating `GasFee`/`GasToken` on `buildRevertOutbound` altogether (they're only needed to size the relayer's broadcast gas, not to drive a refund), or explicitly zero them out before the outbound reaches `FinalizeOutbound`, so `applyGasRefund`'s early-return guard (`outbound.GasFee == ""`) naturally skips the revert path.
- Add a regression test asserting `PcRefundExecution` is never set on an `INBOUND_REVERT` outbound.

### Proof of Concept
1. Attacker calls the source-chain gateway to deposit a valid, non-trivial `amount` of a whitelisted token, but with a malformed/empty `recipient` (fully attacker-controlled calldata) — cost: one real source-chain deposit + gas.
2. Honest UVs observe the real event and vote it in via `MsgVoteInbound`; quorum passes, a `UniversalTx` is created.
3. `ValidateForExecution` rejects the empty recipient (mirrors `test/integration/uexecutor/execute_inbound_gas_test.go:445-472`), and `handleFailedInboundValidation` creates an `INBOUND_REVERT` outbound via `buildRevertOutbound` with `Amount = inbound.Amount` and `GasFee` populated from `getOutboundTxGasAndFees` — a value never debited anywhere.
4. UVs broadcast/observe the revert transaction on the source chain (delivering the full principal back) and vote `MsgVoteOutbound` with the real `gas_fee_used`.
5. `FinalizeOutbound` → `handleSuccessfulOutbound`/`handleFailedOutbound` → `applyGasRefund` computes `gasFee - gasFeeUsed > 0` and mints that excess as new PRC20/PC to the attacker's `RevertInstructions.FundRecipient` (or `Sender`), with nothing ever deducted to back it.
6. Repeat with new small deposits to accumulate free minted value at negligible net cost, exactly analogous to the referenced report's deposit/withdraw point-farming loop.

```go
// buildRevertOutbound creates an INBOUND_REVERT outbound with gas fields populated
// from the UniversalCore contract via getOutboundTxGasAndFees.
func (k Keeper) buildRevertOutbound(sdkCtx sdk.Context, inbound *types.Inbound) *types.OutboundTx {
	recipient := inbound.Sender
	if inbound.RevertInstructions != nil && inbound.RevertInstructions.FundRecipient != "" {
		recipient = inbound.RevertInstructions.FundRecipient
	}

	outbound := &types.OutboundTx{
		DestinationChain:  inbound.SourceChain,
		Recipient:         recipient,
		Amount:            inbound.Amount,
		ExternalAssetAddr: inbound.AssetAddr,
		Sender:            inbound.Sender,
		TxType:            types.TxType_INBOUND_REVERT,
		OutboundStatus:    types.Status_PENDING,
		Id:                types.GetOutboundRevertId(inbound.SourceChain, inbound.TxHash, inbound.LogIndex),
	}

	// Look up the PRC20 address for this external token
	tokenCfg, err := k.uregistryKeeper.GetTokenConfig(sdkCtx, inbound.SourceChain, inbound.AssetAddr)
	if err != nil || tokenCfg.NativeRepresentation == nil || tokenCfg.NativeRepresentation.ContractAddress == "" {
		k.Logger().Warn("failed to get PRC20 for revert outbound gas lookup, proceeding without gas fields",
			"chain", inbound.SourceChain,
			"asset", inbound.AssetAddr,
			"error", err,
		)
		return outbound
	}

	// Fetch gas fields from UniversalCore.getOutboundTxGasAndFees(prc20, 0)
	// 0 means use the contract's baseLimit for this chain
	gasToken, gasFee, gasPrice, gasLimit, err := k.GetGasFeeInfoForRevertOutbound(sdkCtx, tokenCfg.NativeRepresentation.ContractAddress)
	if err != nil {
		k.Logger().Warn("failed to fetch gas fee info for revert outbound, proceeding without gas fields",
			"chain", inbound.SourceChain,
			"prc20", tokenCfg.NativeRepresentation.ContractAddress,
			"error", err,
		)
		return outbound
	}

	outbound.GasToken = gasToken
	outbound.GasFee = gasFee
	outbound.GasPrice = gasPrice
	outbound.GasLimit = gasLimit

	return outbound
```

```go
// GetGasFeeInfoForRevertOutbound fetches gas info for an INBOUND_REVERT outbound using the
// inbound's PRC20 token address. Returns string values ready for OutboundTx fields.
func (k Keeper) GetGasFeeInfoForRevertOutbound(ctx sdk.Context, prc20Addr string) (gasToken, gasFee, gasPrice, gasLimit string, err error) {
	prc20 := common.HexToAddress(prc20Addr)
	info, err := k.GetOutboundTxGasAndFees(ctx, prc20, big.NewInt(0)) // 0 = use baseLimit
	if err != nil {
		return "", "", "", "", fmt.Errorf("failed to get gas fee info: %w", err)
	}

	return info.GasToken.Hex(), info.GasFee.String(), info.GasPrice.String(), info.GasLimit.String(), nil
}
```

```go
// applyGasRefund computes the excess gas (gasFee - gasFeeUsed) and, if positive,
// calls UniversalCore refundUnusedGas. The result is recorded in outbound.PcRefundExecution.
// It is called for both successful and failed outbounds — gas is consumed on the
// external chain regardless of execution outcome.
func (k Keeper) applyGasRefund(ctx sdk.Context, outbound *types.OutboundTx, obs *types.OutboundObservation) {
	if obs.GasFeeUsed == "" || outbound.GasFee == "" || outbound.GasToken == "" {
		return
	}

	gasFee := new(big.Int)
	if _, ok := gasFee.SetString(outbound.GasFee, 10); !ok {
		return
	}

	gasFeeUsed := new(big.Int)
	if _, ok := gasFeeUsed.SetString(obs.GasFeeUsed, 10); !ok {
		return
	}

	// No excess gas to refund
	if gasFee.Cmp(gasFeeUsed) <= 0 {
		return
	}

	refundAmount := new(big.Int).Sub(gasFee, gasFeeUsed)
	gasToken := common.HexToAddress(outbound.GasToken)

	// Refund recipient: prefer fund_recipient in revert_instructions, fall back to sender
	refundRecipient := outbound.Sender
	if outbound.RevertInstructions != nil && outbound.RevertInstructions.FundRecipient != "" {
		refundRecipient = outbound.RevertInstructions.FundRecipient
	}
	recipientAddr := common.HexToAddress(refundRecipient)

	refundPcTx := &types.PCTx{
		Sender:      outbound.Sender,
		BlockHeight: uint64(ctx.BlockHeight()),
	}

	// Step 1: try refund with swap (gasToken → PC native)
	fee, swapErr := k.GetDefaultFeeTierForToken(ctx, gasToken)
	var swapFallbackReason string

	if swapErr == nil {
		quote, quoteErr := k.getSwapQuoteForRefund(ctx, gasToken, fee, refundAmount)
		if quoteErr == nil {
			minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
			minPCOut.Div(minPCOut, big.NewInt(100))

			resp, err := k.CallUniversalCoreRefundUnusedGas(ctx, gasToken, refundAmount, recipientAddr, true, fee, minPCOut)
			if err == nil {
				refundPcTx.TxHash = resp.Hash
				refundPcTx.GasUsed = resp.GasUsed
				refundPcTx.Status = "SUCCESS"
				outbound.PcRefundExecution = refundPcTx
				return
			}
			swapFallbackReason = fmt.Sprintf("swap refund failed: %s", err.Error())
		} else {
			swapFallbackReason = fmt.Sprintf("quote fetch failed: %s", quoteErr.Error())
		}
	} else {
		swapFallbackReason = fmt.Sprintf("fee tier fetch failed: %s", swapErr.Error())
	}

	// Step 2: fallback — refund without swap (deposit PRC20 directly to recipient)
	ctx.Logger().Error("applyGasRefund: swap refund failed, falling back to no-swap",
		"outbound_id", outbound.Id,
		"reason", swapFallbackReason,
	)

	resp, err := k.CallUniversalCoreRefundUnusedGas(ctx, gasToken, refundAmount, recipientAddr, false, big.NewInt(0), big.NewInt(0))
	if err != nil {
		refundPcTx.Status = "FAILED"
		refundPcTx.ErrorMsg = err.Error()
	} else {
		refundPcTx.TxHash = resp.Hash
		refundPcTx.GasUsed = resp.GasUsed
		refundPcTx.Status = "SUCCESS"
	}

	outbound.PcRefundExecution = refundPcTx
	outbound.RefundSwapError = swapFallbackReason
}
```
