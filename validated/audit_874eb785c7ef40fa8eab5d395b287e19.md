## Title
Sandwichable single-block AMM quote with fixed 5% slippage lets an attacker front-run/back-run module-driven auto-swaps to drain value from inbound deposits and gas refunds — ([File: x/uexecutor/keeper/evm.go], [File: x/uexecutor/keeper/execute_inbound_gas.go], [File: x/uexecutor/keeper/outbound.go])

### Summary
The Ajna report's bug class is "an unprivileged actor front-runs a state-dependent, protocol-driven calculation to shift an aggregate value used for a critical financial outcome, at the expense of an honest party who did not request or control the timing of that calculation." Push Chain's `x/uexecutor` module has a direct analog: every GAS / GAS_AND_PAYLOAD inbound deposit-with-autoswap and every outbound gas-refund-with-swap reads a live Uniswap V3 `QuoterV2` spot quote and immediately consumes it in the same call with only a fixed 5% slippage tolerance, with no TWAP, no user-supplied minimum, and no attacker-independent snapshot.

### Finding Description
`GetSwapQuote` calls `QuoterV2.quoteExactInputSingle` to read the current pool price at execution time: [1](#0-0) 

This quote is used, in the very same keeper call, to compute `minPCOut = quote * 95 / 100` — a hardcoded 5% slippage band with no external input or delay: [2](#0-1) [3](#0-2) 

The same pattern recurs in the outbound gas-refund path, where `getSwapQuoteForRefund` fetches a quote and `applyGasRefund` immediately swaps with 5% slippage: [4](#0-3) [5](#0-4) 

Both `CallPRC20DepositAutoSwap` and `CallUniversalCoreRefundUnusedGas` execute the actual swap via `DerivedEVMCall` against the on-chain `UniversalCore`/AMM pool: [6](#0-5) 

Because these swaps are triggered deterministically by ordinary user actions — an inbound observed and voted by Universal Validators (`MsgVoteInbound`), or an outbound observation vote (`MsgVoteOutbound`) — an unprivileged attacker who watches the mempool for the finalizing vote transaction (the vote that pushes the ballot over its 2/3 threshold, per the generic ballot machine) can:
1. Front-run with a large swap on the same pool to move the price unfavorably for the pending deposit/refund direction.
2. Let the module's `depositPRC20WithAutoSwap` / `refundUnusedGas` execute against the now-skewed price, still within the 5% band, so it doesn't revert.
3. Back-run to reverse their own trade and restore the pool price, capturing the difference extracted from the module-controlled swap.

This is structurally identical to the Ajna MOMP-manipulation griefing pattern: an aggregate/market-derived value (MOMP there, AMM spot price here) that feeds a critical payout calculation is read and consumed atomically, and an unprivileged actor can shift it beforehand to disadvantage a third party (the kicker there, the inbound recipient or gas-refund recipient here) — except here the attacker directly profits from the extracted slippage rather than merely griefing, and the loss lands on user/protocol-controlled PRC20↔PC swap proceeds.

### Impact Explanation
Each exploitation event skims up to ~5% of the swapped notional (bounded by the slippage tolerance) from either:
- A user's inbound GAS/GAS_AND_PAYLOAD deposit auto-swap (`execute_inbound_gas.go`, `execute_inbound_gas_and_payload.go`), reducing the PC amount the user's UEA actually receives, or
- The excess-gas refund swap on outbound completion (`outbound.go`), reducing the refund paid back to the sender/fund-recipient.

This is a corruption of PRC20↔native-PC accounting reachable purely from ordinary user cross-chain activity (deposits, outbound execution) with no privileged role required by the attacker, falling under the in-scope "corruption of PRC20 or native asset accounting" and unauthorized extraction of user/protocol-controlled funds.

### Likelihood Explanation
The trigger conditions (a public AMM pool, a finalizing vote transaction visible in the mempool before inclusion) are realistic and repeatable for every GAS-type inbound and every outbound refund with excess gas — this is routine protocol traffic, not a rare edge case. The cost to the attacker is just gas plus temporary capital for the sandwich trade, and the extractable amount scales with swap size and pool liquidity, similar to standard MEV sandwich economics.

### Recommendation
Replace the single-block spot quote + fixed 5% band with a manipulation-resistant price source, e.g.:
- Use a TWAP (time-weighted average price) from the Uniswap V3 pool observation oracle instead of `quoteExactInputSingle`'s instantaneous quote.
- Tighten and/or make the slippage tolerance configurable per-pool-liquidity rather than a constant 95%.
- Consider executing swaps through a mechanism resistant to same-block price shifts (e.g., commit-reveal or batching), or cap swap size relative to pool depth.

### Proof of Concept
1. Attacker monitors the mempool for a `MsgVoteInbound` (or `MsgVoteOutbound`) transaction that will finalize a ballot for a GAS-type inbound/outbound whose eventual `DerivedEVMCall` will invoke `depositPRC20WithAutoSwap` / `refundUnusedGas`.
2. Attacker submits a large swap on the same Uniswap V3 pool (prc20 ⇄ WPC) in the same or immediately preceding block to move the spot price against the pending deposit/refund direction.
3. The finalizing vote lands; `GetSwapQuote` (`x/uexecutor/keeper/evm.go:500-538`) returns the now-skewed quote; `minPCOut` is computed as 95% of it and the auto-swap/refund executes without reverting.
4. Attacker submits a reverse trade to restore the pool price, netting the value difference extracted from the module's swap, at the expense of the deposit recipient's or refund recipient's received PC amount.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)
}

	amount *big.Int,
	recipient common.Address,

		return nil, errors.Wrap(err, "failed to parse UniversalCore ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err

		return nil, err

		ueModuleAccAddress,
		handlerAddr,

		nil,
		true,

		&nonce,
		"refundUnusedGas",

		amount,
		recipient,

	)

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)

// getSwapQuoteForRefund fetches a Uniswap quote for the gas token refund swap.
func (k Keeper) getSwapQuoteForRefund(ctx sdk.Context, gasToken common.Address, fee *big.Int, amount *big.Int) (*big.Int, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(ctx)
	if err != nil {
		return nil, err
	}
	wpcAddr, err := k.GetUniversalCoreWPCAddress(ctx)
	if err != nil {
		return nil, err
	}
	return k.GetSwapQuote(ctx, quoterAddr, gasToken, wpcAddr, fee, amount)
}
