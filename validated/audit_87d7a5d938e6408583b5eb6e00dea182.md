### Title
Starknet OS `replace_class` syscall skips declared-class validation enforced by the sequencer's blockifier - ([File: crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo])

### Summary
The pure-Cairo Starknet OS implementation of the `replace_class` syscall (`execute_replace_class`) unconditionally overwrites a contract's `class_hash` in `contract_state_changes` without verifying that the target class hash was ever declared. The sequencer's actual execution engine, `blockifier`, enforces this check. The Cairo file itself documents the gap with an explicit TODO, making this a concrete, root-caused inconsistency between the two components that must otherwise agree bit-for-bit on every state transition.

### Finding Description
`replace_class` is an unprivileged syscall: any contract, invoked by any transaction sender, can call it on itself during `__execute__`/any entry point to swap its own `class_hash`. In `blockifier`, both the current and deprecated syscall handlers enforce that the new class hash must already be declared before the class-hash update is applied: [1](#0-0) 

and the corresponding test explicitly documents the rejection ("is not declared"): [2](#0-1) 

The new-syscalls path routes through `syscall_base`/`base.replace_class`, which is likewise gated by state-reader class lookups (`get_compiled_class`) as used elsewhere for class validation (e.g. `is_declared` checks in `state_reader_and_contract_manager.rs`).

However, the Starknet OS's own Cairo re-execution of the same syscall — the code that is actually constrained/proven and that the sequencer relies on to certify the block's state transition — has no such check: [3](#0-2) 

Note line 902's explicit acknowledgement of the missing constraint:
```
// TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
```
The same gap exists in the deprecated syscalls Cairo path: [4](#0-3) 

Because the OS program is the component whose execution is arithmetized and proven (i.e., it is the actual source of truth for what state transition is "valid" once proven), the missing assertion means the OS will happily accept and commit a `contract_state_changes` entry that sets a contract's `class_hash` to an arbitrary, undeclared felt value — something the blockifier would reject outright. This is directly analogous to the reported governance attack pattern: a party is able to swap a contract's active implementation (class) for an implementation that was never vetted/declared through the proper declaration process, bypassing the "must be a real, hashed, and declared Sierra/CASM class" invariant that every other component in the system relies on (e.g., `class_hash` used for gas accounting, `get_compiled_class` lookups by RPC/full nodes, or subsequent `library_call`/`deploy` flows).

### Impact Explanation
If OS-computed state diffs/roots are treated as authoritative (which is the entire purpose of `apollo_starknet_os_program`), a state root or state diff produced by the OS could commit a contract to an undeclared/nonexistent class hash. This breaks the invariant "every `class_hash` referenced on-chain is backed by a declared class," causing:
- Divergence between the honestly-computed blockifier state (which would reject the syscall) and the OS-verified/committed state (which accepts it) — a honest-node/committed-root divergence.
- A contract whose class hash points to a class no execution engine can resolve, effectively freezing or corrupting that contract permanently (denial of the contract's future calls, since `get_compiled_class` for the "declared" invariant would fail everywhere else in the system, per `is_declared` and `UndeclaredClassHash` checks used pervasively, e.g. `crates/apollo_rpc_execution/src/state_reader.rs:115-141` and `crates/blockifier/src/state/state_reader_and_contract_manager.rs:66-104`).

This qualifies as "wrong committed root or block hash" / "honest-node divergence" per the validation criteria, and is High severity given it undermines a core state-integrity invariant reachable from a single unprivileged transaction.

### Likelihood Explanation
The syscall is reachable by any account/contract with zero privilege — a single `invoke` transaction executing `replace_class_syscall(arbitrary_felt)` is sufficient to hit this code path in the OS re-execution/proving pipeline. The bug is not hypothetical; it is explicitly flagged by the maintainers via the `TODO(Yoni, 1/1/2026)` comment, confirming the check is known-missing and not yet scheduled/completed.

### Recommendation
Add the same declared-class assertion in the Cairo `execute_replace_class` (and the deprecated-syscalls equivalent) that `blockifier` already performs: verify the requested `class_hash` corresponds to a declared class (via the `contract_class_changes` dict / declared-classes commitment) before updating `contract_state_changes`, mirroring `syscall_handler.state.get_compiled_class(request.class_hash)?` in `crates/blockifier/src/execution/deprecated_syscalls/hint_processor.rs`.

### Proof of Concept
1. Deploy any contract that exposes a `replace_class_syscall` wrapper (as in `test_contract.cairo`'s `test_forbidden_syscall_in_virtual_mode`/`test_replace_class` helpers, cf. [5](#0-4) ).
2. Send an `invoke` transaction calling `replace_class_syscall(class_hash=<never-declared felt>)`.
3. In `blockifier`, this reverts/fails with `UndeclaredClassHash` (as shown by the existing test `test_replace_class` at `crates/blockifier/src/execution/deprecated_syscalls/deprecated_syscalls_test.rs:375-392`).
4. In the Starknet OS's Cairo `execute_replace_class`, the same call would proceed and record `contract_state_changes[contract_address].class_hash = <undeclared hash>` with no validation, since the check is documented as missing (TODO comment at `syscall_impls.cairo:902`), demonstrating the OS/blockifier semantic divergence.

// Replaces the class.
func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}

    // Tests forbidden syscalls in virtual OS mode.
    // Gets valid class_hash and contract_address from the current contract.
    // syscall_selector should be one of: 'Deploy', 'GetBlockHash', 'ReplaceClass', 'MetaTxV0'.
    #[external(v0)]
    fn test_forbidden_syscall_in_virtual_mode(self: @ContractState, syscall_selector: felt252) {
        let execution_info = get_execution_info().unbox();
        let contract_address = execution_info.contract_address;
        let class_hash = syscalls::get_class_hash_at_syscall(contract_address).unwrap_syscall();

        if syscall_selector == 'GetBlockHash' {
            syscalls::get_block_hash_syscall(0).unwrap_syscall();
        } else if syscall_selector == 'ReplaceClass' {
            syscalls::replace_class_syscall(class_hash).unwrap_syscall();
        } else if syscall_selector == 'Deploy' {
            // Pass constructor arguments (two felt252 values).
            syscalls::deploy_syscall(class_hash, 0, array![0, 0].span(), false).unwrap_syscall();

                array![].span(),
            )
                .unwrap_syscall();
        } else {
            panic!("Unexpected syscall selector");
        }
    }
