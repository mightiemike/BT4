### Title
Global contract class cache returns unverified stale entries for Cairo0 (deprecated) classes - (File: `crates/blockifier/src/state/state_reader_and_contract_manager.rs`)

### Summary
`StateReaderAndContractManager::get_compiled_from_class_manager` serves compiled classes from a shared, cross-block `GlobalContractCache`/`ContractClassManager` without re-checking current declaration status whenever the cached entry is a `RunnableCompiledClass::V0` (deprecated Cairo0) class, mirroring the reported TWAP bug class of "returning a cached value without an update/freshness check before returning."

### Finding Description
`get_compiled_from_class_manager` first attempts to serve a class from the process-wide `contract_class_manager` cache (a `GlobalContractCache`, shared across blocks/transactions and populated once per class hash). For non-V0 (Cairo1) classes it explicitly re-verifies the class is still declared in the *current* state before returning the cached value, precisely because "existence in the cache does not guarantee that (it might contain a declared class from a reverted block, for example)": [1](#0-0) 

However, the branch matching `RunnableCompiledClass::V0(_) => {}` deliberately skips this freshness/declaration check and returns the cached value immediately, exactly like `LibTWAPOracle::consult()` returning `ts.price0Average`/`ts.price1Average` without first calling `update()`. The comment on the same code path acknowledges the cache "might contain a declared class from a reverted block," but the mitigation (`is_declared` check) is applied only to the `_` (non-V0) arm, not to V0.

### Impact Explanation
If a Cairo0 class hash is cached (e.g., via a `DECLARE` transaction that lands in a block that is later reverted, reorganized, or whose declaration ends up not committed to canonical state — a scenario the code's own comment anticipates), the stale cache entry can still be served to any later transaction that references that class hash (e.g. `DEPLOY`/`library_call`/class-hash-based execution), without the state reader confirming the class is currently declared. This can let an unprivileged transaction sender execute code for a class hash that is not actually declared in the canonical state, producing execution/state results inconsistent with what an honest re-derivation from state would produce — a potential honest-node divergence or incorrect state transition, since different sequencer instances (with warm vs. cold caches) could diverge on whether a given class hash is executable.

### Likelihood Explanation
The check is skipped unconditionally for all V0 classes (not merely as a rare edge case), so any operational event that can populate the global cache with a class hash whose declaration doesn't survive to canonical state (block revert/reorg, non-committed declare, or via any reused cache instance across chain reorganizations) triggers the divergence for every subsequent Cairo0 class-hash-based call.

### Recommendation
Apply the same `is_declared` verification to the `RunnableCompiledClass::V0` cache-hit path as is already done for the non-V0 branch, i.e., remove the special-cased `V0(_) => {}` no-op and always confirm current declaration status via `self.state_reader.is_declared(class_hash)?` before returning a cached compiled class, regardless of Cairo version.

### Proof of Concept
Not independently reproducible from static analysis alone — the read-path logic is fully visible and shows the asymmetric check: [2](#0-1) 
A concrete PoC would require constructing a scenario where a V0 class is cached in a `GlobalContractCache`/`ContractClassManager` instance and then the canonical state's declaration for that class hash is reverted/rolled back (e.g., via a reorg or non-committed block), followed by a transaction referencing that class hash — this would need to be validated with a running sequencer/test harness, which is outside the scope of this read-only review.

impl<S: FetchCompiledClasses> StateReaderAndContractManager<S> {
    fn get_compiled_from_class_manager(
        &self,
        class_hash: ClassHash,
    ) -> StateResult<RunnableCompiledClass> {
        if let Some(runnable_class) =
            self.contract_class_manager.get_runnable(&class_hash, &self.native_classes_whitelist)
        {
            match &runnable_class {
                RunnableCompiledClass::V0(_) => {}
                _ => {
                    // The Cairo1 class is cached; verify it is declared,
                    // since existence in the cache does not guarantee that
                    // (it might contain a declared class from a reverted block, for example).
                    if !self.state_reader.is_declared(class_hash)? {
                        return Err(StateError::UndeclaredClassHash(class_hash));
                    }
                }
            }
            self.increment_cache_hit_metric();
            self.update_native_metrics(&runnable_class);
            return Ok(runnable_class);
        }
        self.increment_cache_miss_metric();

        let compiled_class = self.state_reader.get_compiled_classes(class_hash)?;
