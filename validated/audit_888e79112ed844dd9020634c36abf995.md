### Title
PoisonMicroblock accepts a signature-malleated duplicate of a single honestly-signed microblock as "proof" of equivocation, enabling reward theft from a miner who never double-signed - ([File: stackslib/src/chainstate/stacks/db/transactions.rs])

### Summary
`check_microblock_header_signer` (used by `handle_poison_microblock`) only verifies that the two microblock headers recover to the same public-key hash via `check_recover_pubkey`, which calls `recover_to_pubkey_without_validating_low_s` and therefore accepts non-canonical (high-S) signatures. Because ECDSA signatures are malleable (`s → n-s` with the recovery bit flipped), an attacker can derive a second, byte-distinct `MessageSignature` over the *identical* `(version, sequence, prev_block, tx_merkle_root)` content of one legitimately broadcast microblock, and submit it as `PoisonMicroblock(header_1, header_2)`. No code path checks that the header *contents* (e.g. `tx_merkle_root`/`block_hash`) actually differ, only that `sequence`, `prev_block`, `version` match and that both recover to the same key.

### Finding Description
The invariant the poison-microblock mechanism is supposed to enforce is:

`poison_reward_paid == exactly_one_valid_double_signature_by_the_miner`

i.e., a reporter is paid only if the miner produced **two distinct microblocks** at the same stream position (same `sequence`/`prev_block`) — genuine equivocation.

`check_recover_pubkey` in [1](#0-0)  recovers the pubkey using `recover_to_pubkey_without_validating_low_s`, which (per [2](#0-1) ) explicitly skips the low-S canonicalization check. This means both the canonical (low-S) and the malleated (high-S, flipped recovery id) encodings of a signature over the *same* message digest are accepted as "valid," and both recover to the *same* public key.

`check_microblock_header_signer` in [3](#0-2)  only compares `pkh1 == pkh2` — it never compares `mblock_hdr_1.block_hash()` vs `mblock_hdr_2.block_hash()`, nor `tx_merkle_root`, nor the raw `signature` bytes for non-triviality. `handle_poison_microblock` ( [4](#0-3) ) uses exactly this check before recording a poison report keyed on the miner's `microblock_pubkey_hash`, which later redirects the miner's coinbase/commission to the reporter.

The mempool admission gate ( [5](#0-4) ) only enforces that `sequence`, `prev_block`, and `version` are *equal* between the two headers (a sanity check that they claim the same stream position) and that `pkh1 == pkh2`. It never requires `tx_merkle_root` (or the full header) to *differ*, so two headers with identical content but a malleated signature pass this gate too.

Exploit flow: attacker observes one honestly broadcast, validly signed `StacksMicroblockHeader` (`header_1`, low-S). Attacker computes the malleated signature `header_2.signature = (r, n-s, 1-v)` over the identical digest (same `version, sequence, prev_block, tx_merkle_root`), producing `header_2` that is byte-different from `header_1` only in its `signature` field, yet still recovers to the miner's `pkh`. Attacker submits `TransactionPayload::PoisonMicroblock(header_1, header_2)`. `check_microblock_header_signer` passes since `pkh1 == pkh2`; the mempool/tx-processing checks pass since `sequence`/`prev_block`/`version` trivially match. `handle_poison_microblock` records a poison report against the honest miner's `microblock_pubkey_hash`, even though the miner produced only one distinct microblock body.

Existing guards (`validate_parent_microblock_stream`'s internal "deliberate miner fork" detection at [6](#0-5) , which does compare `block_hash()`) do not apply here — that code path is for the *chainstate itself* generating a poison tx from a genuinely forked stream, not for validating a poison tx submitted independently through the mempool via `handle_poison_microblock`.

### Impact Explanation
An honest miner who signed exactly one microblock at a given sequence can be falsely flagged as an equivocator, causing their coinbase/microblock-mining reward to be redirected (in whole or part) to the malicious reporter at coinbase maturation. This is block-reward theft from an honest party who never double-signed, matching the Critical category (block-reward theft/double-payment/loss). It is repeatable against any miner whose microblock signature the attacker can observe (which is every broadcast microblock, since signatures are public), and needs no stake, no majority position, and no privileged role — only the ability to broadcast an ordinary transaction.

### Likelihood Explanation
The attacker needs only: (1) to observe one publicly broadcast, validly signed microblock header from any miner (trivial — headers are gossiped/public), (2) to compute the standard secp256k1 signature malleation (`s' = n - s`, flip recovery bit) — a well-known, cheap operation, and (3) to submit a normal `PoisonMicroblock` transaction, paying only the ordinary transaction fee. No burn-chain operations, no stake, no special timing beyond the `MINER_REWARD_MATURITY` window during which the pubkey-hash height record is still valid. This is fully feasible by any unprivileged participant and repeatable against every miner/microblock.

### Recommendation
Enforce canonical low-S signatures in `check_recover_pubkey`/`StacksMicroblockHeader::verify` (use the low-S-enforcing recovery routine), and additionally have `check_microblock_header_signer` (or `handle_poison_microblock`) explicitly reject the case where `mblock_hdr_1.block_hash() == mblock_hdr_2.block_hash()` or where the headers are otherwise content-identical (e.g., same `tx_merkle_root`), since that cannot represent genuine equivocation — only a re-encoded signature over the same message. A genuine poison proof must show two different signed message digests recovering to the same key.

### Proof of Concept
Rust integration test plan (in `stackslib/src/chainstate/stacks/db/transactions.rs` test module, alongside existing poison-microblock tests):
1. Build a `TestChainstateBuilder` chainstate, register a miner's `microblock_pubkey_hash` via `insert_microblock_pubkey_hash` (mirroring `process_poison_microblock_multiple_same_block`).
2. Construct exactly one `StacksMicroblockHeader` (`header_1`) signed once by the miner's private key with a fixed `(version, sequence, prev_block, tx_merkle_root)`.
3. Derive `header_2` by cloning `header_1` and replacing only `signature` with the malleated signature: parse `header_1.signature` into `(r, s, v)`, set `s' = secp256k1_order - s`, `v' = 1 - v`, re-encode as `MessageSignature`. Assert `header_1 != header_2` (different bytes) but `header_1.check_recover_pubkey().unwrap() == header_2.check_recover_pubkey().unwrap()`.
4. Build `TransactionPayload::PoisonMicroblock(header_1.clone(), header_2)`, sign as an arbitrary unprivileged reporter, and call `StacksChainState::process_transaction`.
5. Assert the equality violation: `StacksChainState::get_poison_microblock_report(&mut conn, height).unwrap()` returns `Some((reporter_addr, header_1.sequence))` — i.e., a poison report was recorded — despite the miner having signed only one distinct microblock body (`header_1`), demonstrating `poison_reward_paid` is true while `exactly_one_valid_double_signature_by_the_miner` is false.

    pub fn check_recover_pubkey(&self) -> Result<Hash160, AuthError> {
        let mut bytes = vec![];
        self.serialize(&mut bytes, true)
            .expect("BUG: failed to serialize to a vec");
        let digest = Sha512Trunc256Sum::from_data(&bytes[..]);

        let mut pubk = StacksPublicKey::recover_to_pubkey_without_validating_low_s(
            digest.as_bytes(),
            &self.signature,
        )
        .map_err(|_ve| {
            AuthError::VerifyingError(
                "Failed to verify signature: failed to recover public key".to_string(),
            )
        })?;

        pubk.set_compressed(true);
        Ok(Hash160::from_node_public_key(&pubk))
    }

        msg: &[u8],
        sig: &MessageSignature,
        verify_low_s: bool,
    ) -> Result<Secp256k1PublicKey, &'static str> {

                "Invalid message: failed to decode data hash: must be a 32-byte hash"
            })?;

            let secp256k1_sig = sig
                .to_secp256k1_recoverable()
                .ok_or("Invalid signature: failed to decode recoverable signature")?;

                let mut secp256k1_sig_low_s = secp256k1_sig_standard;
                secp256k1_sig_low_s.normalize_s();
                if secp256k1_sig_low_s != secp256k1_sig_standard {
                    return Err("Invalid signature: high-S");
                }
            }

                .recover_ecdsa(&msg, &secp256k1_sig)
                .map_err(|_e| "Invalid signature: failed to recover public key")?;

            Ok(Secp256k1PublicKey {
                key: recovered_pubkey,
                compressed: true,
            })
        })
    }

    ) -> Result<Hash160, Error> {

                false,

                "Invalid PoisonMicroblock transaction -- signature pubkey hash {} != {}",
                &pkh1, &pkh2
            );
            warn!("{}", &msg);
            return Err(Error::InvalidStacksTransaction(msg, false));
        }
        Ok(pkh1)
    }

    pub fn handle_poison_microblock(
        env: &mut ExecutionState,
        invoke_ctx: &InvocationContext,
        mblock_header_1: &StacksMicroblockHeader,
        mblock_header_2: &StacksMicroblockHeader,
    ) -> Result<Value, Error> {
        let cost_before = env.global_context.cost_track.get_total();

        // encodes MARF reads for loading microblock height and current height, and loading and storing a
        // poison-microblock report
        runtime_cost(ClarityCostFunction::PoisonMicroblock, env, 0)
            .map_err(|e| Error::from_cost_error(e, cost_before.clone(), env.global_context))?;

        let sender_principal = match &invoke_ctx.sender {
            Some(ref sender) => {
                if let PrincipalData::Standard(sender) = sender.clone() {
                    sender
                } else {
                    panic!(
                        "BUG: tried to handle poison microblock without a standard principal sender"
                    );
                }
            }
            None => {
                panic!("BUG: tried to handle poison microblock without a sender");
            }
        };

        // is this valid -- were both headers signed by the same key?
        let pubkh =
            StacksChainState::check_microblock_header_signer(mblock_header_1, mblock_header_2)?;

        let microblock_height_opt = env
            .global_context
            .database
            .get_microblock_pubkey_hash_height(&pubkh)?;
        let current_height = env.global_context.database.get_current_block_height();

        // for the microblock public key hash we had to process
        env.add_memory(20)
            .map_err(|e| Error::from_cost_error(e, cost_before.clone(), env.global_context))?;

        // for the block height we had to load
        env.add_memory(4)
            .map_err(|e| Error::from_cost_error(e, cost_before.clone(), env.global_context))?;

        // was the referenced public key hash used anytime in the past
        // MINER_REWARD_MATURITY blocks?
        let mblock_pubk_height = match microblock_height_opt {
            None => {
                // public key has never been seen before
                let msg = format!(
                    "Invalid Stacks transaction: microblock public key hash {} never seen in this fork",
                    &pubkh
                );
                warn!("{}", &msg;
                      "microblock_pubkey_hash" => %pubkh
                );

                return Err(Error::InvalidStacksTransaction(msg, false));
            }
            Some(height) => {
                if height
                    .checked_add(
                        u32::try_from(MINER_REWARD_MATURITY).expect("FATAL: maturity > 2^32"),
                    )
                    .expect("BUG: too many blocks")
                    < current_height
                {
                    let msg = format!(
                        "Invalid Stacks transaction: microblock public key hash from height {} has matured relative to current height {}",
                        height, current_height
                    );
                    warn!("{}", &msg;
                          "microblock_pubkey_hash" => %pubkh
                    );

                    return Err(Error::InvalidStacksTransaction(msg, false));
                }
                height
            }
        };

        // add punishment / commission record, if one does not already exist at lower sequence
        let (reporter_principal, reported_seq) = if let Some((reporter, seq)) = env
            .global_context
            .database
            .get_microblock_poison_report(mblock_pubk_height)?
        {
            // account for report loaded
            env.add_memory(u64::from(TypeSignature::PrincipalType.size().map_err(
                |_| Error::Expects("Failed to get size of PrincipalType".into()),
            )?))
            .map_err(|e| Error::from_cost_error(e, cost_before.clone(), env.global_context))?;

            // u128 sequence
            env.add_memory(16)
                .map_err(|e| Error::from_cost_error(e, cost_before.clone(), env.global_context))?;

            if mblock_header_1.sequence < seq {
                // this sender reports a point lower in the stream where a fork occurred, and is now
                // entitled to a commission of the punished miner's coinbase
                debug!("Sender {} reports a better poison-miroblock record (at {}) for key {} at height {} than {} (at {})", &sender_principal, mblock_header_1.sequence, &pubkh, mblock_pubk_height, &reporter, seq;
                    "sender" => %sender_principal,
                    "microblock_pubkey_hash" => %pubkh
                );
                env.global_context.database.insert_microblock_poison(
                    mblock_pubk_height,
                    &sender_principal,
                    mblock_header_1.sequence,
                )?;
                (sender_principal, mblock_header_1.sequence)
            } else {
                // someone else beat the sender to this report
                debug!("Sender {} reports an equal or worse poison-microblock record (at {}, but already have one for {}); dropping...", &sender_principal, mblock_header_1.sequence, seq;
                    "sender" => %sender_principal,
                    "microblock_pubkey_hash" => %pubkh
                );
                (reporter, seq)
            }
        } else {
            // first-ever report of a fork
            debug!(
                "Sender {} reports a poison-microblock record at seq {} for key {} at height {}",
                &sender_principal, mblock_header_1.sequence, &pubkh, &mblock_pubk_height;
                "sender" => %sender_principal,
                "microblock_pubkey_hash" => %pubkh
            );
            env.global_context.database.insert_microblock_poison(
                mblock_pubk_height,
                &sender_principal,
                mblock_header_1.sequence,
            )?;
            (sender_principal, mblock_header_1.sequence)
        };
