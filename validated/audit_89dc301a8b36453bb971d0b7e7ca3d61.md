This confirms the sender field is cryptographically derived, not attacker-controlled. `BlobWithSender::new(seq_comm.body, seq_comm.public_key, hash, wtxid)` is only pushed when `seq_comm.get_sig_verified_hash().is_some()` succeeds, which requires a valid ECDSA/Schnorr signature verification against `seq_comm.public_key()` over the body [1](#0-0) , and `extract_relevant_sequencer_commitments` additionally checks `seq_comm.public_key() == sequencer_da_pub_key` before treating a commitment as attributable to the sequencer [2](#0-1) . Both `verify_transactions` and the completeness-proof extraction path independently construct `BlobWithSender` only using the self-reported `public_key` field paired with a verified signature over the body, so `blob.sender()` at the point it reaches `run_l1_block` is the ECDSA-verified signer of that specific blob body [3](#0-2) .     /// Verifies the signature of the inscription and returns the hash of the body
    /// Returns None if the signature is unparsable or doesn't belong to the body.
    fn get_sig_verified_hash(&self) -> Option<[u8; 32]> {
        if let Ok(key) = k256::ecdsa::VerifyingKey::from_sec1_bytes(self.public_key()) {
            use k256::ecdsa::signature::DigestVerifier;
            let hash = sha2::Sha256::new_with_prefix(self.body());
            let signature = k256::ecdsa::Signature::from_slice(self.signature());
            if signature.is_ok() && key.verify_digest(hash.clone(), &signature.unwrap()).is_ok() {
                return Some(hash.finalize().into());
            }
        }

        None
    }
