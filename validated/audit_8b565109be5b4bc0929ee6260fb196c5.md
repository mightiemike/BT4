## Analysis

The reported bug class is: **a price used to bound a value-affecting operation is read from a manipulable, too-short/instantaneous source instead of a robust time-weighted source, letting an attacker force a worse execution price and extract value.** In UXD, the wrong TWAP interval (15s instead of 900s) let the mark price be pushed by short-term manipulation, inflating allowed rebalances.

The Push Chain analog is the **Uniswap V3 spot quote used for auto-swap slippage protection** in `x/uexecutor`. [1](#0-0) 

`GetSwapQuote` calls `QuoterV2.quoteExactInputSingle`, which simulates a swap against the **current** pool state (an instantaneous spot price, effectively a "0-second TWAP") rather than any time-weighted/robust price source. The result feeds directly into the slippage bound: [2](#0-1) 

`minPCOut = quote * 95 / 100` is computed from the *same* manipulable pool state that the swap will immediately execute against, in `CallPRC20DepositAutoSwap`. The same pattern is repeated for `GAS_AND_PAYLOAD` inbound processing: [3](#0-2) 

and for excess-gas refunds on outbound finalization: [4](#0-3) 

Because the quote and the slippage floor are derived from the identical (attacker-manipulable) pool state right before the swap executes, the 95% bound only protects against price drift *within* that single keeper call — it provides no protection against pool manipulation that occurred in a prior transaction within the same block. An unprivileged attacker can sandwich the protocol's auto-swap: push the PRC20/WPC pool price down beforehand (any ordinary swap transaction), let the protocol's deposit-auto-swap mint synthetic WPC to the user's UEA at the depressed price (still "passing" the 95% check because the check is computed from the same depressed price), then restore the price, profiting from the value the protocol/user should have received.

This is more exploitable than in a typical DeFi context because the qualifying inbound-triggered swap is driven by `MsgVoteInbound`, which is on the **gasless** whitelist: [5](#0-4) 

Gasless transactions are commonly deprioritized relative to fee-paying transactions in the mempool/block-inclusion ordering, making it straightforward for a fee-paying attacker to have their pool-manipulating swap ordered immediately before the module's auto-swap execution in the same block — a purely unprivileged, no-special-access attack path.

### Title
Uniswap V3 spot-quote used as slippage floor for PRC20 auto-swap deposits/refunds enables sandwich extraction of protocol/user value - (File: x/uexecutor/keeper/evm.go)

### Summary
`GetSwapQuote` fetches an instantaneous `QuoterV2.quoteExactInputSingle` spot quote and uses it, unmodified apart from a flat 95% haircut, as the minimum-output guard (`minPCOut`) for `depositPRC20WithAutoSwap` and `refundUnusedGas` swap legs. Because the quote and the guard are derived from the same manipulable pool state the swap executes against, the protection is void against price manipulation performed in a prior transaction of the same block.

### Finding Description
- `x/uexecutor/keeper/evm.go:GetSwapQuote` reads a live spot quote from the Uniswap V3 `QuoterV2` contract, with no TWAP or historical-average safeguard.
- `x/uexecutor/keeper/execute_inbound_gas.go` and `execute_inbound_gas_and_payload.go` (GAS / GAS_AND_PAYLOAD inbound routes) and `x/uexecutor/keeper/outbound.go:applyGasRefund` (excess-gas refund swap) all compute `minPCOut = quote * 95 / 100` from that same spot quote and immediately invoke the swap in the same keeper call.
- An unprivileged actor can place a transaction that manipulates the PRC20/WPC pool price immediately before the block containing the module's `MsgVoteInbound`/`MsgVoteOutbound`-triggered swap executes, since these voting messages are gasless and thus typically less competitive for block-inclusion ordering than a fee-paying manipulation transaction.
- The subsequent auto-swap then executes against the manipulated price, and the "slippage protection" trivially passes because it was computed from that same manipulated price, not from an independent, harder-to-move reference.

### Impact Explanation
This allows extraction of value from users' deposited funds (less synthetic PC/WPC minted to the recipient UEA than the fair price implies) and/or from protocol-held gas-refund funds, satisfying the in-scope impact of "unauthorized... loss of user or protocol-controlled funds" and "corruption of PRC20 or native asset accounting" reachable through ordinary user deposit/refund flows with no privileged actor required.

### Likelihood Explanation
Medium-High. It requires capital to move the specific pool and correctly time a transaction ahead of the module's swap in the same block, but no validator, relayer, or TSS collusion is needed — an ordinary fee-paying user can outcompete the gasless voting transaction for inclusion ordering, and Uniswap-style pools are commonly thin enough on new chains for this to be economically attractive.

### Recommendation
Bound `minPCOut` using a robust, harder-to-manipulate reference (e.g., a Uniswap V3 TWAP observation over a meaningful window, or an oracle-reported price with a fixed maximum deviation), independent of the just-fetched spot quote, or require the quote to be validated against a stored/oracle reference price before accepting it as the slippage floor.

### Proof of Concept
1. Attacker observes a pending `MsgVoteInbound` (or the last confirming vote) for a `GAS`/`GAS_AND_PAYLOAD` inbound that will trigger `ExecuteInboundGas` → `CallPRC20DepositAutoSwap`.
2. Attacker submits a fee-paying EVM swap that heavily tilts the PRC20/WPC Uniswap V3 pool in the same block, ordered before the gasless vote tx.
3. `GetSwapQuote` returns a depressed quote reflecting the manipulated pool; `minPCOut = quote*95%` is computed from this depressed value.
4. `CallPRC20DepositAutoSwap` executes the swap at the manipulated price, minting less WPC than fair value to the user's UEA — the depressed value is captured by the attacker after reversing the manipulation later in the same or next block.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}
