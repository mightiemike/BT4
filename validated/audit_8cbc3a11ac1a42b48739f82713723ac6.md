Analysis: In `calculate_miner_reward` at `stackslib/src/chainstate/stacks/db/accounts.rs`, the `parent_miner_reward` tuple element is built solely from `parent.address`, `parent.recipient`, and `parent_tx_fees_streamed_produced` (derived from `participant.tx_fees`'s streamed/parent_fees value), with `coinbase: 0` and `tx_fees_anchored: 0` hardcoded [1](#0-0) . The `punished` flag, which is set only when `poison_reporter_opt` is `Some` and only zeroes/redirects the child's `coinbase_reward`, `tx_fees_anchored`, and `tx_fees_streamed_confirmed`, never enters the `parent_tx_fees_streamed_produced` computation branch at all [2](#0-1) . The `poison_recipient_opt` passed into `calculate_miner_reward` is derived from `get_poison_microblock_report` scoped to `reward_height` (the child block's height), and is only used inside the `if let Some(reporter_address) = poison_reporter_opt` branch that mutates `coinbase_reward`/`child_address`/`punished`, none of which feed into `parent_miner_reward` [3](#0-2) . The unit test `miner_reward_tx_fees` confirms the parent's reward is computed independently from any punishment path, only from the parent's produced streamed fees [4](#0-3) .

The claimed equality break does not exist: `parent_miner_reward` is invariant to the child's poison status because `punished` is never referenced in the code path that computes `parent_tx_fees_streamed_produced`, `parent.address`, or `parent.recipient`. Both sides of the equality (parent's reward before and after a child-only poison report) are identical, since the only quantity affected by poison is the child's own coinbase/anchored/confirmed-streamed fee fields, not the parent's produced-streamed-fee field.

    #[test]
    fn miner_reward_tx_fees() {
        let miner_1 =
            StacksAddress::from_string("SP1A2K3ENNA6QQ7G8DVJXM24T6QMBDVS7D0TRTAR5").unwrap();

        let parent_miner_1 =
            StacksAddress::from_string("SP2QDF700V0FWXVNQJJ4XFGBWE6R2Y4APTSFQNBVE").unwrap();

        let participant = make_dummy_miner_payment_schedule(&miner_1, 500, 100, 105, 1000, 1000);
        let parent_participant =
            make_dummy_miner_payment_schedule(&parent_miner_1, 500, 100, 395, 1000, 1000);

        let (parent_reward, miner_reward) = StacksChainState::calculate_miner_reward(
            false,
            StacksEpochId::Epoch2_05,
            &participant,
            &participant,
            &[],
            &parent_participant,
            None,
        );

        // miner should have received the entire coinbase
        assert_eq!(miner_reward.coinbase, 500);
        assert_eq!(miner_reward.tx_fees_anchored, 100);
        assert_eq!(miner_reward.tx_fees_streamed_produced, 0); // not rewarded yet
        assert_eq!(miner_reward.tx_fees_streamed_confirmed, (105 * 3) / 5);

        // parent gets produced stream fees
        assert_eq!(parent_reward.coinbase, 0);
        assert_eq!(parent_reward.tx_fees_anchored, 0);
        assert_eq!(parent_reward.tx_fees_streamed_produced, (395 * 2) / 5);
        assert_eq!(parent_reward.tx_fees_streamed_confirmed, 0);
    }
