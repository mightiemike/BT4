### Title
Precision loss in `BuiltinInstanceLimits::induced_gas_costs()` produces per-builtin proving-gas costs biased downward, allowing transactions to under-report proving gas and evade bouncer capacity/fee accounting - (File: crates/blockifier/src/bouncer.rs)

### Summary
`BuiltinInstanceLimits::induced_gas_costs()` computes each Cairo primitive's per-instance proving-gas cost as `floor(proving_gas / limit)` — a division performed *before* the value is later multiplied by the transaction's per-primitive usage counts in `cairo_primitives_to_gas()`. This is structurally identical to the GMX `getNextFundingAmountPerSize()` bug: dividing a large fixed value by a large divisor first, then multiplying the (rounded-down) quotient by a usage count, instead of multiplying first and dividing once at the end. When `proving_gas / limit` rounds down significantly (i.e., is small in magnitude relative to the true fractional rate), every unit of usage systematically undercounts proving gas.

### Finding Description
`BuiltinInstanceLimits::induced_gas_costs()` derives a per-block, per-primitive gas price: [1](#0-0) 

```rust
pub fn induced_gas_costs(&self, proving_gas: GasAmount) -> BuiltinGasCosts {
    let derive = |limit: NonZeroU64| -> u64 { proving_gas.0 / limit.get() };
    ...
}
```

This truncates any fractional part of `proving_gas / limit` at this step. The resulting per-unit cost (`BuiltinGasCosts`) is stored and later multiplied by the transaction's builtin/opcode usage counts in `cairo_primitives_to_gas()`: [2](#0-1) 

```rust
pub fn cairo_primitives_to_gas(
    cairo_primitives_counters: &CairoPrimitiveCounterMap,
    cairo_primitives_gas_costs: &BuiltinGasCosts,
) -> GasAmount {
    let cairo_primitives_gas =
        cairo_primitives_counters.iter().fold(0u64, |accumulated_gas, (name, &count)| {
            let cairo_primitive_weight =
                cairo_primitives_gas_costs.get_cairo_primitive_gas_cost(name).unwrap();
            cairo_primitive_weight.checked_mul(u64_from_usize(count))...
        });
    GasAmount(cairo_primitives_gas)
}
```

This is exactly the "divide, then multiply" ordering flagged in the GMX report: instead of computing `usage * proving_gas / limit` (multiply first, divide once), the code computes `(proving_gas / limit) * usage`, truncating the rate before scaling by usage. The codebase elsewhere is explicitly careful to avoid this exact pattern — e.g. `calculate_next_base_gas_price()` in `crates/apollo_consensus_orchestrator/src/fee_market/mod.rs` has an explicit comment: "Calculate price change by multiplying first, then dividing. This avoids the precision loss that occurs when dividing before multiplying" [3](#0-2)  — confirming this is a known anti-pattern the team otherwise guards against, but `induced_gas_costs` was not built with that safeguard.

The proving-gas budget default is `5_000_000_000` and the smallest default instance limit is `ecdsa: 3_000` [4](#0-3) , giving `derive(ecdsa) = 5_000_000_000 / 3_000 = 1_666_666` with a remainder of `1_000_000/1_500_000`-scale truncation per instance — i.e. a systematic ~0.05%–low-single-digit-percent undercount is baked in at default config, and the undercount fraction grows arbitrarily large as `proving_gas` shrinks relative to `limit` (e.g., for a builtin whose limit is close to or exceeds proving_gas, `derive()` truncates to 0, entirely zeroing that primitive's proving-gas price).

### Impact Explanation
`proving_gas` (computed via `compute_proving_gas` → `get_tx_weights` → `BouncerWeights.proving_gas`) is a bouncer capacity dimension used both to reject over-large transactions (`within_max_capacity_or_err`) and to decide whether a block is "full" (`try_update`/`has_room`) [5](#0-4) . Because the per-primitive gas price is silently rounded down before being scaled by usage counts, every transaction containing Cairo-primitive/builtin usage is charged less proving gas than the true proportional share of the block's proving budget its builtins consume. This lets a sequencer accept more total "true" proving work into a block than the configured `block_max_capacity.proving_gas` intends, i.e. transactions can under-report the resource they actually cost the prover, undermining the bouncer's core guarantee of bounding proof generation cost per block. Since bouncer weights (and the underlying `BouncerConfig`/`BuiltinInstanceLimits`) are consensus-relevant sizing/config values baked into `VersionedConstants`/`BouncerConfig` used identically by every honest node re-executing the block, this is a systematic (not maliciously exploitable in a way that causes state divergence) precision defect rather than a consensus-fork bug — all honest nodes compute the same (wrong) truncated value deterministically, so it does not cause honest-node divergence, but it does allow the aggregate proving workload admitted into a block to silently and systematically exceed the intended `block_max_capacity.proving_gas` ceiling.

### Likelihood Explanation
This triggers on essentially every transaction that uses any Cairo builtin/opcode — i.e., nearly all transactions — since `get_tx_weights` is called on every transaction processed by the batcher/bouncer [6](#0-5) . No special transaction crafting or privileged access is required; it is a deterministic effect of the default configuration values themselves (`proving_gas / limit` for each builtin), so the systematic undercount is present at every block under current default `BouncerConfig`/`BuiltinInstanceLimits` values.

### Recommendation
Refactor `induced_gas_costs` (and its consumer `cairo_primitives_to_gas`) to defer the division until after multiplying by usage, e.g. compute per-transaction proving gas for a primitive as `(proving_gas.0 as u128 * count as u128) / limit.get() as u128` (using a wide integer type to avoid overflow, mirroring the `U256` approach already used in `calculate_next_base_gas_price`), rather than pre-computing and truncating a per-instance rate via `proving_gas.0 / limit.get()` and then multiplying that truncated rate by `count`.

### Proof of Concept
1. Configure (or use default) `BouncerConfig.builtin_instance_limits.ecdsa = 3_000` and `block_max_capacity.proving_gas = 5_000_000_000` (defaults in `BuiltinInstanceLimits::default()` / `BouncerWeights::default()`) [7](#0-6) .
2. Call `BuiltinInstanceLimits::default().induced_gas_costs(GasAmount(5_000_000_000))`; observe `ecdsa` cost = `5_000_000_000 / 3_000 = 1_666_666` (truncated from `1_666_666.67`), matching the snapshot test pattern already in the repo (`test_induced_builtin_gas_costs_from_default_limits`, using `6_000_000_000` and showing exact-truncated integer outputs like `ecop: 46153`, `bitwise: 571`, etc., all of which are floor-divided, non-exact ratios) [8](#0-7) .
3. Submit N transactions each using `ecdsa` `k` times; each is charged `1_666_666 * k` proving gas via `cairo_primitives_to_gas`, whereas the "correct" (multiply-first) proportional charge would be `(5_000_000_000 * k) / 3_000`, which for non-multiple-of-3000 aggregate `k` totals diverges from the truncated per-transaction sum, letting the aggregate admitted block workload creep above the intended `block_max_capacity.proving_gas` bound as more such transactions are packed into the block.

pub fn cairo_primitives_to_gas(
    cairo_primitives_counters: &CairoPrimitiveCounterMap,
    // NOTE: 'blake' is currently the only supported opcode, by being included in the
    // builtin_gas_costs.
    cairo_primitives_gas_costs: &BuiltinGasCosts,
) -> GasAmount {
    let cairo_primitives_gas =
        cairo_primitives_counters.iter().fold(0u64, |accumulated_gas, (name, &count)| {
            let cairo_primitive_weight =
                cairo_primitives_gas_costs.get_cairo_primitive_gas_cost(name).unwrap();
            cairo_primitive_weight
                .checked_mul(u64_from_usize(count))
                .and_then(|builtin_gas| accumulated_gas.checked_add(builtin_gas))
                .unwrap_or_else(|| {
                    panic!(
                        "Overflow while converting cairo primitives counters to gas.\nCairo \
                         primitive: {name:?}, Weight: {cairo_primitive_weight}, Count: {count}, \
                         Accumulated gas: {accumulated_gas}"
                    )
                })
        });

    GasAmount(cairo_primitives_gas)
}

#[allow(clippy::too_many_arguments)]
pub fn get_tx_weights<S: StateReader>(
    state_reader: &S,
    executed_class_hashes: &HashSet<ClassHash>,
    n_visited_storage_entries: usize,
    tx_resources: &TransactionResources,
    state_changes_keys: &StateChangesKeys,
    versioned_constants: &VersionedConstants,
    tx_cairo_primitives_counters: &CairoPrimitiveCounterMap,
    bouncer_config: &BouncerConfig,
    receipt_l2_gas: GasAmount,
) -> TransactionExecutionResult<TxWeights> {
    let message_resources = &tx_resources.starknet_resources.messages;
    let message_starknet_l1gas = usize_from_u64(message_resources.get_starknet_gas_cost().l1_gas.0)
        .expect("This conversion should not fail as the value is a converted usize.");

    // Casm hash resources.
    let class_hash_to_casm_hash_computation_resources =
        map_class_hash_to_casm_hash_computation_resources(state_reader, executed_class_hashes)?;

    // Patricia update + transaction resources.
    let patricia_update_resources = get_patricia_update_resources(
        n_visited_storage_entries,
        // TODO(Yoni): consider counting here the global contract tree and the aliases as well.
        state_changes_keys.storage_keys.len(),
    );
    let vm_resources =
        &tx_resources.computation.total_extended_vm_resources() + &patricia_update_resources;

    // Builtin gas costs for stone and for stwo.
    let sierra_builtin_gas_costs = &versioned_constants.os_constants.gas_costs.builtins;
    let proving_builtin_gas_costs = &bouncer_config.builtin_gas_costs();

    // Casm hash migration resources.
    let migration_data = CasmHashMigrationData::from_state(
        state_reader,
        executed_class_hashes,
        versioned_constants,
    )?;
    // Total state changes keys are the sum of marginal state changes keys and the
    // migration state changes.
    let mut total_state_changes_keys = StateChangesKeys {
        compiled_class_hash_keys: migration_data.class_hashes_to_migrate.keys().cloned().collect(),
        ..Default::default()
    };
    total_state_changes_keys.extend(state_changes_keys);

    // Migration occurs once per contract and is not included in the CASM hash computation, which
    // is performed every time a contract is loaded.
    let sierra_migration_gas = migration_data.to_gas(sierra_builtin_gas_costs, versioned_constants);
    let proving_migration_gas =
        migration_data.to_gas(proving_builtin_gas_costs, versioned_constants);

    // Sierra gas computation.
    let (total_sierra_gas, casm_hash_computation_data_sierra_gas, vm_resources_sierra_gas) =
        compute_sierra_gas(
            &vm_resources,
            sierra_builtin_gas_costs,
            versioned_constants,
            tx_resources,
            sierra_migration_gas,
            &class_hash_to_casm_hash_computation_resources,
        );

    // Proving gas computation.
    let cairo_primitives_for_proving_gas = get_cairo_primitives_for_proving_gas_computation(
        patricia_update_resources.prover_builtins(),
        tx_resources.computation.os_vm_resources.prover_builtins(),
        tx_cairo_primitives_counters,
    );

    let (total_proving_gas, casm_hash_computation_data_proving_gas) = compute_proving_gas(
        &cairo_primitives_for_proving_gas,
        vm_resources_sierra_gas,
        versioned_constants,
        proving_builtin_gas_costs,
        sierra_builtin_gas_costs,
        proving_migration_gas,
        &class_hash_to_casm_hash_computation_resources,
    );

    let bouncer_weights = BouncerWeights {
        l1_gas: message_starknet_l1gas,
        message_segment_length: message_resources.message_segment_length,
        n_events: tx_resources.starknet_resources.archival_data.event_summary.n_events,
        state_diff_size: get_onchain_data_segment_length(&total_state_changes_keys.count()),
        sierra_gas: total_sierra_gas,
        n_txs: 1,
        proving_gas: total_proving_gas,
        receipt_l2_gas,
    };
