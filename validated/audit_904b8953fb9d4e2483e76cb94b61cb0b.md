### Title
Missing "class is declared" check in Starknet OS `replace_class` syscall diverges from blockifier's enforcement, causing OS/native execution state divergence - (File: `crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo`)

### Summary
The reported bug pattern — a security-critical parameter (`secp256k1_signer`) that is checked by one code path (verification) but can be mutated without re-validation, undermining a downstream trust check — has a direct analog in this sequencer: the `replace_class` syscall's requirement that the target `class_hash` be a **declared** class is enforced in the native/blockifier execution engine, but the equivalent check is explicitly missing (and flagged with a `TODO`) in the Starknet OS (SNOS) Cairo implementation used for block re-execution/proving.

### Finding Description
`replace_class` lets a contract change the class it executes as. Because a malicious/unverified class could otherwise be attached to an already-trusted contract address, the blockifier enforces that the new `class_hash` corresponds to a **declared** class before allowing the update:

- Deprecated (Cairo0) syscalls: `syscall_handler.state.get_compiled_class(request.class_hash)?` is called before `set_class_hash_at`, explicitly ensuring the class is declared. [1](#0-0) 
- This is confirmed by tests, both for the deprecated (Cairo0) and VM/Native (Cairo1) syscall implementations, asserting `"is not declared"` errors when an undeclared `class_hash` is used. [2](#0-1) [3](#0-2) 

However, the corresponding logic in the Starknet OS's own Cairo implementation of the syscall (used when SNOS re-executes a block to build the validity proof) has **no such check**:

```
   900|    let class_hash = request.class_hash;
   901|
   902|    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
   903|    local state_entry: StateEntry*;
``` [4](#0-3) 

The same missing check exists in the deprecated syscall path of the OS program: [5](#0-4) 

This is analogous to the oracle bug: the value that establishes the contract's identity/trust (`class_hash`, playing the role of `secp256k1_signer`) is validated by the "verifier" (blockifier, analogous to the enclave/quote verification), but the equivalent check is missing in the component that re-derives/re-proves the same computation (SNOS, analogous to signature verification against the key later in the flow). The two implementations are supposed to be semantically identical re-executions of the same transaction, and any silent divergence in accepted/rejected syscall behavior between them is a correctness bug in the OS.

### Impact Explanation
Since blockifier rejects `replace_class` calls that target an undeclared class hash (causing that call/transaction to fail or revert), but the OS's implementation blindly accepts and commits the state change regardless of whether the class is declared, an unprivileged contract deployer can craft a contract that invokes `replace_class` with an undeclared class hash. Under block re-execution by SNOS (used to generate the block's validity proof and, in the Starknet architecture, to authoritatively determine the committed state/root for proof-based flows), the resulting contract state (and hence contract/global state commitment) diverges from what the blockifier-based sequencer actually committed to storage/state diffs. This is a genuine "wrong committed root" / honest-node divergence class of bug between the two independent re-implementations of the same syscall, not merely a resource/no-impact issue.

### Likelihood Explanation
Likelihood is high for triggering the divergence itself: no privileged role is required. Any account can deploy a simple Cairo contract exposing an entrypoint that calls the `replace_class` syscall with an arbitrary, undeclared `class_hash`, and invoke it via an ordinary `INVOKE` transaction. Whether this divergence is actually exploitable end-to-end (i.e., whether it survives into a final committed/proved state, or is caught by other consistency checks such as declared-class checks during state-diff commitment) would need further confirmation with a live re-execution run, since I could not trace the full state-diff commitment/consistency-check pipeline within the available context.

### Recommendation
Add the same "class must be declared" check to the Starknet OS Cairo implementations of `execute_replace_class` (both `syscall_impls.cairo` and `deprecated_execute_syscalls.cairo`) that the blockifier's Rust syscall handlers already perform, so that the OS and blockifier stay in lockstep and reject `replace_class` calls with undeclared class hashes identically.

### Proof of Concept
1. Deploy a contract (unprivileged transaction sender / contract deployer) whose entrypoint calls the `replace_class` syscall with a `class_hash` that has never been declared on-chain.
2. Invoke that entrypoint via a regular `INVOKE` transaction.
3. Under blockifier (native sequencer execution), the syscall handler in `hint_processor.rs`/`syscall_base.rs` calls `get_compiled_class`/declared-check first and errors out with `"is not declared"`, so the state change is rejected. [6](#0-5) 
4. Under Starknet OS re-execution (`execute_replace_class` in `syscall_impls.cairo`), the same call proceeds without any declared-class check and unconditionally updates `contract_state_changes` with the undeclared class hash. [7](#0-6) 
5. This produces two different final states for the same transaction/block depending on which execution engine processed it — a state/commitment divergence between the sequencer's committed chain state and the SNOS-derived proof state.

func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
