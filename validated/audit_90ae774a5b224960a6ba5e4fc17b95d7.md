### Title
Unbounded recursion in `bytecode_hash_node` during compiled class hash validation - (File: `crates/starknet_api/src/contract_class/compiled_class_hash.rs`)

### Summary
The compiled-class-hash computation used to validate a `DECLARE` transaction's `compiled_class_hash` recursively walks a `NestedIntList` bytecode-segment structure with plain Rust function recursion and no depth cap, mirroring the ALPINE-CVE-2018-6544 class of bug (recursive object-stream/structure walk that can exhaust the call stack).

### Finding Description
`bytecode_hash_node` in `crates/starknet_api/src/contract_class/compiled_class_hash.rs` recurses once per nesting level of the `bytecode_segment_lengths: NestedIntList` field of a `CasmContractClass`: [1](#0-0) 

There is no depth check comparable to the `RecursionDepthGuard` used for Cairo entry-point calls: [2](#0-1) 

This function is invoked from `HashableCompiledClass::hash` / `hash_inner`, which is the routine used to (re)compute and validate a declared class's `compiled_class_hash`: [3](#0-2) 

The same unbounded pattern is duplicated in the Starknet OS bytecode-segment reconstruction path used during OS re-execution: [4](#0-3) 
and in its Cairo-hint counterpart which itself uses unbounded tail recursion (`bytecode_hash_internal_node` calls itself with no depth guard): [5](#0-4) 

The `NestedIntList` value is produced by the trusted Sierra→CASM compiler subprocess when compiling a user-submitted Sierra program (`SierraToCasmCompiler::compile`, `crates/apollo_compile_to_casm/src/compiler.rs`), which is only bounded by CPU-time/memory `ResourceLimits`, not by structural nesting depth of its *output*: [6](#0-5) 

A declarer who crafts a Sierra program that induces deeply nested branch/segment structure in the compiled CASM (e.g., many levels of nested control flow so the compiler emits a deeply nested segment tree) can cause the resulting `bytecode_segment_lengths` to have a recursion depth far exceeding what Rust's default thread stack can sustain, without violating the compiler's CPU/memory limits (a deep but narrow tree is cheap in both CPU and memory but expensive in native call-stack frames).

### Impact Explanation
If the recursion depth of `bytecode_hash_node` (or its OS/Cairo counterparts) exceeds the available stack, the process handling the recursion (gateway validating the `DECLARE`, blockifier computing/validating the compiled class hash, or the Starknet OS re-execution process hashing bytecode segments) aborts via stack overflow. Because this hashing runs on the direct validation path of a single `DECLARE` transaction and again during OS re-execution/proving, a successfully declared malicious class could cause repeatable crashes for any node (or the prover) that re-validates or re-hashes it — a network-wide denial of service on transaction/block processing (a network unable to confirm/re-execute the class), matching the "Medium" severity DoS profile of the source CVE.

### Likelihood Explanation
Reachability requires only a normal `DECLARE` transaction from an unprivileged contract declarer; no privileged role is needed. Feasibility is uncertain because: (1) the actual segmentation algorithm (which chooses how deep `NestedIntList` gets) lives in the external `cairo-lang-starknet-classes`/compiler dependency, not in this repository, so this repo does not control how deep the compiler's output can go; (2) the compiler subprocess is resource-limited by CPU time and memory, which may indirectly bound practical nesting depth; (3) I could not fully verify, within tool budget, the exact recursion depth achievable from realistic Sierra programs, nor confirm whether the compiler already flattens/limits segmentation depth. This uncertainty should be resolved before treating this as a confirmed, exploitable bug.

### Recommendation
- Convert `bytecode_hash_node` (and its OS counterpart `create_bytecode_segment_structure_inner` / `BytecodeSegmentNode::hash`) to iterative, explicit-stack traversal, or enforce a maximum nesting depth consistent with a hard cap on `NestedIntList` depth validated right after compilation/deserialization.
- Reject `CasmContractClass` instances whose `bytecode_segment_lengths` nesting depth exceeds a sane bound (e.g., proportional to `max_bytecode_size`) before they are hashed or stored.
- Apply the same bound in the Starknet OS Cairo hints so a malicious class cannot crash provers during re-execution.

### Proof of Concept
Not independently verified — would require confirming that the external Sierra→CASM compiler (`cairo-lang-starknet-classes`, outside this repo) can be driven, via a crafted but resource-limit-compliant Sierra program, to emit a `NestedIntList` with a nesting depth (e.g., tens of thousands of levels) sufficient to overflow the default stack when `bytecode_hash_node` recurses over it during `DECLARE` validation. This is flagged as an analog concern based on the unbounded-recursion pattern found in the sequencer's own hashing code, not as a confirmed working exploit.

fn bytecode_hash_node<H, NL>(iter: &mut impl Iterator<Item = Felt>, node: &NL) -> (usize, Felt)
where
    H: StarkHash,
    NL: HashableNestedIntList,
{
    if node.is_leaf() {
        let len = node.get_segment_length();
        let data = iter.take(len).collect_vec();
        assert_eq!(data.len(), len);
        (len, H::hash_array(&data))
    } else {
        // Compute `1 + poseidon(len0, hash0, len1, hash1, ...)`.
        let inner_nodes = node
            .iter_children()
            .map(|child| bytecode_hash_node::<H, NL>(iter, child))
            .collect_vec();
        let hash = H::hash_array(
            &inner_nodes.iter().flat_map(|(len, hash)| [Felt::from(*len), *hash]).collect_vec(),
        ) + Felt::ONE;
        (inner_nodes.iter().map(|(len, _)| len).sum(), hash)
    }
}

// Ensure that the recursion depth does not exceed the maximum allowed depth.
struct RecursionDepthGuard {
    current_depth: Arc<RefCell<usize>>,
    max_depth: usize,
}

impl RecursionDepthGuard {
    fn new(current_depth: Arc<RefCell<usize>>, max_depth: usize) -> Self {
        Self { current_depth, max_depth }
    }

    // Tries to increment the current recursion depth and returns an error if the maximum depth
    // would be exceeded.
    fn try_increment_and_check_depth(&mut self) -> Result<(), EntryPointExecutionError> {
        *self.current_depth.borrow_mut() += 1;
        if *self.current_depth.borrow() > self.max_depth {
            return Err(EntryPointExecutionError::RecursionDepthExceeded);
        }
        Ok(())
    }
}

/// Helper function for `create_bytecode_segment_structure`.
/// Returns the bytecode segment structure and the total length of the processed segment.
pub(crate) fn create_bytecode_segment_structure_inner(
    bytecode: &[Felt],
    bytecode_segment_lengths: NestedIntList,
    bytecode_offset: usize,
) -> (BytecodeSegmentNode, usize) {
    match bytecode_segment_lengths {
        NestedIntList::Leaf(length) => {
            let segment_end = bytecode_offset + length;
            let bytecode_segment = bytecode[bytecode_offset..segment_end].to_vec();

            (BytecodeSegmentNode::Leaf(BytecodeSegmentLeaf { data: bytecode_segment }), length)
        }
        NestedIntList::Node(lengths) => {
            let mut segments = vec![];
            let mut total_len = 0;
            let mut bytecode_offset = bytecode_offset;

            for item in lengths {
                let (current_structure, item_len) =
                    create_bytecode_segment_structure_inner(bytecode, item, bytecode_offset);

                segments.push(BytecodeSegment { length: item_len, node: current_structure });

                bytecode_offset += item_len;
                total_len += item_len;
            }

            (BytecodeSegmentNode::InnerNode(BytecodeSegmentInnerNode { segments }), total_len)
        }
    }
}

// Helper function for bytecode_hash_node.
// Computes the hash of an internal node by adding its children to the hash state.
func bytecode_hash_internal_node{
    range_check_ptr, poseidon_ptr: PoseidonBuiltin*, poseidon_state: PoseidonBuiltinState
}(data_ptr: felt*, data_length: felt, full_contract: felt) {
    if (data_length == 0) {
        %{ AssertEndOfBytecodeSegments %}
        return ();
    }

    alloc_locals;
    local is_leaf_and_loaded;
    local load_segment;
    local segment_length;

    %{ IterCurrentSegmentInfo %}

    if (is_leaf_and_loaded != FALSE) {
        // Repeat the code of bytecode_hash_node() for performance reasons, instead of calling it.
        let (current_segment_hash) = poseidon_hash_many(n=segment_length, elements=data_ptr);
        tempvar range_check_ptr = range_check_ptr;
        tempvar poseidon_ptr = poseidon_ptr;
        tempvar current_segment_hash = current_segment_hash;
    } else {
        if (load_segment != FALSE) {
            let current_segment_hash = bytecode_hash_node(
                data_ptr=data_ptr, data_length=segment_length, full_contract=full_contract
            );
        } else {
            // If `full_contract` is true, this flow is not allowed.
            assert full_contract = FALSE;

            // Set the first felt of the bytecode to -1 to make sure that the execution cannot jump
            // to this segment (-1 is an invalid opcode).
            // The hash in this case is guessed and the actual bytecode is unconstrained (except for
            // the first felt).
            %{ DeleteMemoryData %}
            assert data_ptr[0] = -1;

            assert [range_check_ptr] = segment_length;
            tempvar range_check_ptr = range_check_ptr + 1;
            tempvar poseidon_ptr = poseidon_ptr;
            let current_segment_hash = [ap];
            %{ SetApToSegmentHashPoseidon %}
            ap += 1;
        }
    }

    // Add the segment length and hash to the hash state.
    // Use the poseidon builtin directly for performance reasons.
    assert poseidon_ptr.input = PoseidonBuiltinState(
        s0=poseidon_state.s0 + segment_length,
        s1=poseidon_state.s1 + current_segment_hash,
        s2=poseidon_state.s2,
    );
    let poseidon_state = poseidon_ptr.output;
    let poseidon_ptr = &poseidon_ptr[1];

    %{ vm_exit_scope() %}

    return bytecode_hash_internal_node(
        data_ptr=&data_ptr[segment_length],
        data_length=data_length - segment_length,
        full_contract=full_contract,
    );
}
