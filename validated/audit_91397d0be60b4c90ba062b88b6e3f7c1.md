## Analog Identified: Self-referential spot-price slippage bound in module-driven AMM swaps (sandwichable within the same block)

### Title
Self-referential Uniswap V3 spot-price quote used as its own slippage bound lets an attacker sandwich module-driven PRC20→PC swaps (auto-swap on inbound deposits, gas refunds) - (File: `x/uexecutor/keeper/evm.go`, `x/uexecutor/keeper/execute_inbound_gas.go`, `x/uexecutor/keeper/execute_inbound_gas_and_payload.go`, `x/uexecutor/keeper/outbound.go`)

### Summary
The external report shows that reading a live, attacker-timeable price feed and immediately using it to settle value in the same execution window creates a risk-free arbitrage window. Push Chain's `x/uexecutor` module reproduces the same failure mode with an on-chain AMM: whenever the module needs to convert a user's PRC20 gas token into native PC (auto-swap on `GAS`/`GAS_AND_PAYLOAD` inbound processing, and again on outbound gas-fee refunds), it fetches the *current spot price* from the UniversalCore/Uniswap V3 `QuoterV2` and derives its own slippage floor (`minPCOut = quote * 95 / 100`) from that very same instantaneous read, then immediately executes the swap against it.

### Finding Description
`GetSwapQuote` performs a static `CallEVM` to `quoteExactInputSingle` on the Uniswap V3 QuoterV2 to get the current spot conversion rate: [1](#0-0) 

That same value is then used, with a fixed 5% haircut, to bound the very swap that consumes it — there is no independent oracle, no TWAP, and no minimum-output supplied by the user: [2](#0-1) 

The identical self-referential pattern also drives `gasAndPayloadDepositAutoSwap` for `GAS_AND_PAYLOAD` inbounds: [3](#0-2) 

and `applyGasRefund`, invoked automatically when an outbound is finalized (both on success and on failure), computing `minPCOut` from the same spot quote right before calling `refundUnusedGas`: [4](#0-3) 

Because `quote` and `minPCOut` are derived in the same call stack, in the same block, from the pool's current reserves, an attacker who can place a transaction immediately before the triggering `MsgVoteInbound`/`MsgVoteOutbound` finalization tx (front-run) and one immediately after (back-run) — ordinary unprivileged actions on a public EVM mempool with no privileged access required — can push the pool price down before the module's swap executes and pull it back afterward, capturing the difference at the expense of the user's deposit or refund. The upgrade changelog confirms this exact spot-quote design was intentionally introduced (replacing a "0-slippage" call) without any TWAP or user-supplied minimum: [5](#0-4) 

This is the same root-cause class as the referenced Pyth issue: a protocol-critical price value that updates continuously within the same settlement window is read and consumed atomically by the same logic that is supposed to be protected by it, giving an unprivileged actor a free, low-risk arbitrage window at the expense of the counterparty (here, the depositing/refunded user) instead of the protocol.

### Impact Explanation
Every `GAS` and `GAS_AND_PAYLOAD` inbound deposit, and every successful/failed outbound with an excess-gas refund, routes PRC20→PC conversion through this self-referential quote. An attacker can systematically sandwich these module-triggered swaps to skim value out of user deposits/refunds, directly corrupting PRC20/native asset accounting and draining value from ordinary users through a purely user-reachable trigger (submitting or having others submit deposits/outbounds) — this falls under "corruption of PRC20 or native asset accounting" and "stealing... funds of user or protocol-controlled" in the allowed impact set.

### Likelihood Explanation
High reachability: any external, unprivileged user (or third party observing the mempool) can trigger the vulnerable path merely by causing an inbound `GAS`/`GAS_AND_PAYLOAD` deposit to be finalized, or by waiting for any outbound refund to finalize — no special permissions or validator/relayer collusion needed. The only requirement is the ability to place transactions before/after the triggering finalization tx in the same block, which is ordinary transaction-ordering/MEV behavior available to any EVM user, not a "malicious validator" or "malicious peer" scenario excluded by the impact gate.

### Recommendation
Do not derive the slippage floor from the same spot read that is about to be consumed. Options:
- Use a manipulation-resistant price source (TWAP over N blocks, or the `ChainMeta`/gas-price oracle median mechanism already used elsewhere) to compute `minPCOut` independently of the instantaneous pool state.
- Enforce a protocol-level maximum single-block price-impact check on the pool itself, or route swaps through a private/atomic execution path that cannot be sandwiched (e.g., disallow same-block front/back-run by using a commit-reveal or a pre-agreed rate).
- At minimum, tighten the slippage tolerance and add a circuit breaker comparing the spot quote against the `ChainMeta` gas-price oracle or a longer-window TWAP, rejecting swaps when they diverge beyond a safe bound.

### Proof of Concept
1. Attacker monitors the mempool for a `MsgVoteInbound` (or the vote that will cross the 2/3 threshold) carrying a `GAS`/`GAS_AND_PAYLOAD` inbound with a sizable PRC20 gas-token amount, or an outbound about to be finalized with an excess-gas refund.
2. Attacker submits a swap transaction with higher gas price/priority to execute *before* the finalizing tx, pushing the PRC20/WPC pool price down.
3. The finalizing tx executes `k.GetSwapQuote(...)` — [1](#0-0)  — reading the now-depressed spot price, computes `minPCOut = quote * 95 / 100`, and calls `CallPRC20DepositAutoSwap`/`CallUniversalCoreRefundUnusedGas`, settling the user's PRC20 for PC at the manipulated rate — [6](#0-5) .
4. Attacker submits a back-run swap immediately after, restoring the pool price and realizing the arbitrage profit extracted from the user's deposit/refund, with no risk beyond ordinary trading fees.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}
