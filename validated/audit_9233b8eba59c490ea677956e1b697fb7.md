### Title
Unbounded, permissionless witness registration causes unbounded per-cycle work in `MaintenanceManager.doMaintenance()` - (File: `consensus/src/main/java/org/tron/consensus/dpos/MaintenanceManager.java`)

### Summary
`WitnessCreateActuator` allows any account with sufficient balance to register itself as a witness, with no cap on the total number of witnesses and no actuator to unregister/remove one. `MaintenanceManager.doMaintenance()`, which runs on every maintenance-cycle boundary as part of ordinary block application, performs several unbounded full scans over the entire witness set (and the entire `VotesStore`) each time it runs. This mirrors the `TwapOracle` finding: an attacker-controlled, unboundedly growing collection is iterated in full by a routine that cannot be skipped or split, so the cost of that routine grows without bound and can eventually threaten the timing budget of consensus-critical processing.

### Finding Description
`WitnessCreateActuator.validate()`/`createWitness()` only checks address validity, URL validity, non-duplication, and that the caller's balance covers `dynamicStore.getAccountUpgradeCost()` — a fixed, publicly known fee. [1](#0-0) 
There is no limit on the total number of witness records that can be created, and there is no actuator anywhere in the codebase that removes a witness from `WitnessStore` once created.

Every time a maintenance-cycle boundary is crossed, `MaintenanceManager.applyBlock()` calls `doMaintenance()` as part of normal block application (reachable by any block, produced from ordinary broadcast transactions triggering the maintenance timestamp check): [2](#0-1) 

Inside `doMaintenance()`, the full witness set is iterated multiple separate times unconditionally on each cycle:
- `consensusDelegate.getAllWitnesses().forEach(...)` for VI accumulation,
- `consensusDelegate.getAllWitnesses().forEach(...)` to build `newWitnessAddressList`,
- `consensusDelegate.getAllWitnesses().forEach(...)` again for brokerage/vote persistence,

and the entire `VotesStore` is scanned via `countVote(votesStore)`: [3](#0-2) [4](#0-3) 

Since witness registration is permissionless and unbounded, and there is no pruning/removal mechanism, the size of the collections iterated here grows monotonically with attacker-supplied input (repeated `WitnessCreateContract` transactions from many funded addresses), exactly matching the `TwapOracle.registerPair`/`update` bug pattern: unlimited additions, no removal, and a mandatory full-collection scan on a critical path.

### Impact Explanation
`doMaintenance()` runs synchronously as part of block application on every full node and witness, at a fixed cadence (maintenance interval). As the number of registered witnesses (and stale `VotesStore` entries) grows without bound, the work done in this method grows correspondingly, increasing block-processing latency at maintenance boundaries across the entire network. In the worst case this degrades consensus performance/timing (missed blocks, slower cycle processing) for all nodes simultaneously — a network-wide DoS vector rooted in the protocol implementation, not a single node's configuration.

### Likelihood Explanation
Registering a witness only requires an unprivileged account with balance ≥ `getAccountUpgradeCost()` and is exposed via anonymous RPC/HTTP endpoints (`createWitness`/`createWitness2` gRPC calls, `CreateWitnessServlet`), so any funded, non-privileged actor can repeatedly submit `WitnessCreateContract` transactions to grow the witness set indefinitely. No governance/permission gate exists to stop this beyond the fixed fee, so the likelihood of gradual accumulation is high, though the cost scales linearly with the number of registrations, making a sudden severe DoS require sustained fee expenditure rather than a single transaction.

### Recommendation
Add an upper bound on the number of concurrently registered witnesses (or a market-driven pruning/removal mechanism for inactive/zero-vote witnesses), and avoid performing multiple independent full scans of the witness set per maintenance cycle in `MaintenanceManager.doMaintenance()`. Consider consolidating the three separate `getAllWitnesses().forEach` passes into one, and bound/paginate the `VotesStore` scan in `countVote()` so that per-cycle cost cannot grow unbounded with unprivileged witness registrations.

### Proof of Concept
1. From N distinct unprivileged accounts, each funded with at least `AccountUpgradeCost` TRX, broadcast `WitnessCreateContract` transactions (via `createWitness2` gRPC or `CreateWitnessServlet`) to register N witnesses; `WitnessCreateActuator.validate()` imposes no cap on N. [5](#0-4) 
2. On the next maintenance-cycle boundary, `MaintenanceManager.applyBlock()` triggers `doMaintenance()`, which performs `O(N)` work in three separate full iterations over `getAllWitnesses()` plus a full `VotesStore` scan. [3](#0-2) 
3. As N is repeatedly increased with no removal path available, the cost of every future maintenance cycle increases without bound, analogous to `TwapOracle.update()` becoming unusable as pairs accumulate.

  public void doMaintenance() {
    VotesStore votesStore = consensusDelegate.getVotesStore();

    tryRemoveThePowerOfTheGr();

    DynamicPropertiesStore dynamicPropertiesStore = consensusDelegate.getDynamicPropertiesStore();
    DelegationStore delegationStore = consensusDelegate.getDelegationStore();
    if (dynamicPropertiesStore.useNewRewardAlgorithm()) {
      long curCycle = dynamicPropertiesStore.getCurrentCycleNumber();
      consensusDelegate.getAllWitnesses().forEach(witness -> {
        delegationStore.accumulateWitnessVi(curCycle, witness.createDbKey(), witness.getVoteCount());
      });
    }

    Map<ByteString, Long> countWitness = countVote(votesStore);
    if (!countWitness.isEmpty()) {
      List<ByteString> currentWits = consensusDelegate.getActiveWitnesses();

      List<ByteString> newWitnessAddressList = new ArrayList<>();
      consensusDelegate.getAllWitnesses()
          .forEach(witnessCapsule -> newWitnessAddressList.add(witnessCapsule.getAddress()));

      countWitness.forEach((address, voteCount) -> {
        byte[] witnessAddress = address.toByteArray();
        WitnessCapsule witnessCapsule = consensusDelegate.getWitness(witnessAddress);
        if (witnessCapsule == null) {
          logger.warn("Witness capsule is null. address is {}", Hex.toHexString(witnessAddress));
          return;
        }
        AccountCapsule account = consensusDelegate.getAccount(witnessAddress);
        if (account == null) {
          logger.warn("Witness account is null. address is {}", Hex.toHexString(witnessAddress));
          return;
        }
        witnessCapsule.setVoteCount(witnessCapsule.getVoteCount() + voteCount);
        consensusDelegate.saveWitness(witnessCapsule);
        logger.info("address is {} , countVote is {}", witnessCapsule.createReadableString(),
            witnessCapsule.getVoteCount());
      });

      dposService.updateWitness(newWitnessAddressList);

      incentiveManager.reward(newWitnessAddressList);

      List<ByteString> newWits = consensusDelegate.getActiveWitnesses();
      if (!CollectionUtils.isEqualCollection(currentWits, newWits)) {
        currentWits.forEach(address -> {
          WitnessCapsule witnessCapsule = consensusDelegate.getWitness(address.toByteArray());
          witnessCapsule.setIsJobs(false);
          consensusDelegate.saveWitness(witnessCapsule);
        });
        newWits.forEach(address -> {
          WitnessCapsule witnessCapsule = consensusDelegate.getWitness(address.toByteArray());
          witnessCapsule.setIsJobs(true);
          consensusDelegate.saveWitness(witnessCapsule);
        });

        SRMetrics.recordSrSetChange(currentWits, newWits);
      }

      logger.info("Update witness success. \nbefore: {} \nafter: {}",
          getAddressStringList(currentWits),
          getAddressStringList(newWits));
    }

    if (dynamicPropertiesStore.allowChangeDelegation()) {
      long nextCycle = dynamicPropertiesStore.getCurrentCycleNumber() + 1;
      dynamicPropertiesStore.saveCurrentCycleNumber(nextCycle);
      consensusDelegate.getAllWitnesses().forEach(witness -> {
        delegationStore.setBrokerage(nextCycle, witness.createDbKey(),
            delegationStore.getBrokerage(witness.createDbKey()));
        delegationStore.setWitnessVote(nextCycle, witness.createDbKey(), witness.getVoteCount());
      });
    }
  }

  private Map<ByteString, Long> countVote(VotesStore votesStore) {
    final Map<ByteString, Long> countWitness = Maps.newHashMap();
    Iterator<Entry<byte[], VotesCapsule>> dbIterator = votesStore.iterator();
    long sizeCount = 0;
    while (dbIterator.hasNext()) {
      Entry<byte[], VotesCapsule> next = dbIterator.next();
      VotesCapsule votes = next.getValue();
      votes.getOldVotes().forEach(vote -> {
        ByteString voteAddress = vote.getVoteAddress();
        long voteCount = vote.getVoteCount();
        if (countWitness.containsKey(voteAddress)) {
          countWitness.put(voteAddress, countWitness.get(voteAddress) - voteCount);
        } else {
          countWitness.put(voteAddress, -voteCount);
        }
      });
      votes.getNewVotes().forEach(vote -> {
        ByteString voteAddress = vote.getVoteAddress();
        long voteCount = vote.getVoteCount();
        if (countWitness.containsKey(voteAddress)) {
          countWitness.put(voteAddress, countWitness.get(voteAddress) + voteCount);
        } else {
          countWitness.put(voteAddress, voteCount);
        }
      });
      sizeCount++;
      votesStore.delete(next.getKey());
    }
    logger.info("There is {} new votes in this epoch", sizeCount);
    return countWitness;
  }
