### Title
On-chain-triggered PRC20↔PC swaps (gas-refund and gas-auto-swap) use a single-block spot quote with only 5% slippage protection, letting an unprivileged attacker sandwich the swap to steal value from users' refunds/deposits - (File: x/uexecutor/keeper/outbound.go, x/uexecutor/keeper/evm.go, x/uexecutor/keeper/execute_inbound_gas.go)

### Summary
The Folks Finance report shows how an adversary can transiently manipulate a rate-determining input (pool utilization/variable rate) via a flashloan, trigger a state-locking operation (`rebalanceUp`) on a victim's position using that manipulated input, and then revert the manipulation — leaving the victim permanently worse off. Push Chain has a structurally similar pattern: several module-originated EVM calls compute a swap output using a **single spot quote** from the on-chain Uniswap V3 `QuoterV2` (`GetSwapQuote` in [1](#0-0) ) and then execute the swap atomically with only a fixed 5% slippage tolerance (`minPCOut = quote * 95 / 100`). Because the underlying Uniswap V3 pool price is freely tradable by any unprivileged account, an attacker can move the pool price immediately before the swap-triggering transaction lands and reverse it immediately after (a classic sandwich), extracting value at the expense of the user whose funds are being converted.

### Finding Description
Two production code paths compute `minPCOut` this way and then immediately execute a real swap against the pool in the same transaction:

1. **Gas-fee refund on outbound finalization** — `applyGasRefund` in [2](#0-1)  is invoked from both `handleSuccessfulOutbound` and `handleFailedOutbound`, which run the moment a `MsgVoteOutbound` ballot reaches quorum (an ordinary, gasless, honest-UV-triggered transaction, see [3](#0-2) ). It calls `getSwapQuoteForRefund` → `GetSwapQuote` to get a spot quote, applies a flat 5% slippage buffer, and immediately calls `CallUniversalCoreRefundUnusedGas` with `withSwap=true`, executing the swap at essentially the manipulated price: [4](#0-3) 

2. **Deposit auto-swap on inbound GAS / GAS_AND_PAYLOAD execution** — the same quote→95%→swap pattern is used in `ExecuteInboundGas` and `gasAndPayloadDepositAutoSwap` when a user's bridged gas token is auto-swapped into native PC: [5](#0-4) [6](#0-5) 

In both cases the quote comes from `QuoterV2.quoteExactInputSingle`, a pure/view read of the pool's current reserves/tick at call time: [1](#0-0) 

Because these calls run inside ordinary block execution (module-originated `DerivedEVMCall`s triggered by user-reachable events — an inbound deposit, or a UV's outbound vote reaching quorum), the price used is whatever the pool's state is *at that exact moment in that block*. An unprivileged attacker who can also submit EVM transactions on Push Chain can trade against the same Uniswap V3 pool (buy/sell the gas token vs WPC) to push the price in the direction that minimizes `quote` right before the module's swap executes, then trade back afterward to restore the price and recover their capital (a same-block sandwich, functionally equivalent in effect to the flashloan-driven rate manipulation in the source report — capital is round-tripped, and only the victim's outcome is left in a worse state). The 5% band is a fixed slippage tolerance, not a TWAP or a protection against intra-block manipulation, so it does not prevent this: the attacker can move the price by more than 5% and still have the module's swap clear the `minPCOut` check while receiving far less PC than a fair price would produce.

The unfair difference (fair value − manipulated value) is captured by the attacker's counter-trade, and the shortfall comes directly out of:
- the outbound sender/`fund_recipient`'s gas refund (`applyGasRefund` recipient), or
- the UEA owner's deposited/auto-swapped PC amount (`ExecuteInboundGas` / `gasAndPayloadDepositAutoSwap` recipient).

This matches the "corruption of PRC20 or native asset accounting ... refund accounting ... token mapping" and "Universal execution path ... refund flow ... must preserve ... fund invariants" impact categories, triggered purely by an unprivileged external attacker trading on a public AMM pool — no malicious validator, relayer, or admin action is required.

### Impact Explanation
Every gas refund (on any successful or failed outbound with excess gas) and every gas-token deposit auto-swap (GAS / GAS_AND_PAYLOAD inbound routes) is exposed. Users receive systematically less PC than a fair-price swap would produce whenever an attacker chooses to sandwich these deterministic, publicly-observable trigger events (UV outbound votes reaching quorum, or inbound ballot finalization are both externally observable/predictable). Because these swaps happen automatically and are baked into the protocol's core crosschain flows (used on essentially every inbound/outbound with a gas leg), this is a systemic, repeatable value-extraction vector rather than a one-off edge case — directly reducing user/protocol-controlled funds, matching "stealing ... funds" in scope.

### Likelihood Explanation
Medium-to-High. The attacker needs only: (1) an unprivileged EVM account able to trade on the PRC20/WPC Uniswap V3 pool on Push Chain, and (2) the ability to time trades around the block(s) in which a `MsgVoteOutbound`/inbound-finalization transaction executes (mempool visibility or simply monitoring pending votes/ballots, which are on-chain and predictable once 2/3 quorum is nearly reached). No validator or admin collusion is required, matching the "unprivileged external attacker" constraint. Liquidity depth of the specific PRC20↔WPC pool determines how much value can be extracted per event, but the fixed 5% band is generous enough to make sandwiching profitable on any pool with realistic (non-infinite) depth.

### Recommendation
- Do not rely on a single-block spot quote from `QuoterV2` for slippage protection on protocol-triggered swaps. Use a time-weighted average price (TWAP) oracle, or require the resulting `minPCOut` bound to be substantially tighter and computed from a manipulation-resistant reference price.
- Consider decoupling the swap execution from the vote-finalization/inbound-finalization transaction (e.g., have the recipient claim/trigger their own swap with their own slippage tolerance, or split the swap into a separate step with a commit-then-execute pattern across blocks) so a single attacker cannot atomically sandwich the exact trigger transaction.
- Alternatively, refund/deposit the raw PRC20 by default and make the swap-to-PC an explicit, user-initiated, user-slippage-controlled action, rather than a module-forced swap embedded in the finalization path.

### Proof of Concept
1. Attacker holds `gasToken` and `WPC`(or PC) and observes a pending `MsgVoteOutbound` that is one vote away from quorum for an outbound with a non-trivial `GasFee - GasFeeUsed` excess (visible via `PendingOutbounds`/`GetUniversalTx` queries), or a pending inbound `GAS`/`GAS_AND_PAYLOAD` ballot about to finalize.
2. Immediately before the finalizing transaction lands in a block, attacker submits a large swap against the `gasToken`/`WPC` Uniswap V3 pool used by `GetUniversalCoreQuoterAddress`/`GetUniversalCoreWPCAddress` (see [7](#0-6) ), pushing the effective exchange rate against the token being swapped into PC.
3. The finalizing transaction executes `applyGasRefund` (or `gasAndPayloadDepositAutoSwap`/`ExecuteInboundGas`), calling `GetSwapQuote` at the now-manipulated price, computing `minPCOut = quote * 0.95`, and executing the swap via `CallUniversalCoreRefundUnusedGas`/`CallPRC20DepositAutoSwap` — the victim receives PC based on the manipulated rate.
4. Attacker immediately submits the reverse trade, restoring the pool price and recovering their capital plus the value skimmed from the victim's swap, in the same or next block.
5. Net result: attacker's capital is returned intact (round-tripped, analogous to a flashloan), while the victim's refunded/deposited PC amount is permanently reduced below fair value.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// applyGasRefund computes the excess gas (gasFee - gasFeeUsed) and, if positive,
// calls UniversalCore refundUnusedGas. The result is recorded in outbound.PcRefundExecution.
// It is called for both successful and failed outbounds — gas is consumed on the
// external chain regardless of execution outcome.
func (k Keeper) applyGasRefund(ctx sdk.Context, outbound *types.OutboundTx, obs *types.OutboundObservation) {
	if obs.GasFeeUsed == "" || outbound.GasFee == "" || outbound.GasToken == "" {
		return
	}

	gasFee := new(big.Int)
	if _, ok := gasFee.SetString(outbound.GasFee, 10); !ok {
		return
	}

	gasFeeUsed := new(big.Int)
	if _, ok := gasFeeUsed.SetString(obs.GasFeeUsed, 10); !ok {
		return
	}

	// No excess gas to refund
	if gasFee.Cmp(gasFeeUsed) <= 0 {
		return
	}

	refundAmount := new(big.Int).Sub(gasFee, gasFeeUsed)
	gasToken := common.HexToAddress(outbound.GasToken)

	// Refund recipient: prefer fund_recipient in revert_instructions, fall back to sender
	refundRecipient := outbound.Sender
	if outbound.RevertInstructions != nil && outbound.RevertInstructions.FundRecipient != "" {
		refundRecipient = outbound.RevertInstructions.FundRecipient
	}
	recipientAddr := common.HexToAddress(refundRecipient)

	refundPcTx := &types.PCTx{
		Sender:      outbound.Sender,
		BlockHeight: uint64(ctx.BlockHeight()),
	}

	// Step 1: try refund with swap (gasToken → PC native)
	fee, swapErr := k.GetDefaultFeeTierForToken(ctx, gasToken)
	var swapFallbackReason string

	if swapErr == nil {
		quote, quoteErr := k.getSwapQuoteForRefund(ctx, gasToken, fee, refundAmount)
		if quoteErr == nil {
			minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
			minPCOut.Div(minPCOut, big.NewInt(100))

			resp, err := k.CallUniversalCoreRefundUnusedGas(ctx, gasToken, refundAmount, recipientAddr, true, fee, minPCOut)
			if err == nil {
				refundPcTx.TxHash = resp.Hash
				refundPcTx.GasUsed = resp.GasUsed
				refundPcTx.Status = "SUCCESS"
				outbound.PcRefundExecution = refundPcTx
				return
			}
			swapFallbackReason = fmt.Sprintf("swap refund failed: %s", err.Error())
		} else {
			swapFallbackReason = fmt.Sprintf("quote fetch failed: %s", quoteErr.Error())
		}
	} else {
		swapFallbackReason = fmt.Sprintf("fee tier fetch failed: %s", swapErr.Error())
	}

	// Step 2: fallback — refund without swap (deposit PRC20 directly to recipient)
	ctx.Logger().Error("applyGasRefund: swap refund failed, falling back to no-swap",
		"outbound_id", outbound.Id,
		"reason", swapFallbackReason,
	)

	resp, err := k.CallUniversalCoreRefundUnusedGas(ctx, gasToken, refundAmount, recipientAddr, false, big.NewInt(0), big.NewInt(0))
	if err != nil {
		refundPcTx.Status = "FAILED"
		refundPcTx.ErrorMsg = err.Error()
	} else {
		refundPcTx.TxHash = resp.Hash
		refundPcTx.GasUsed = resp.GasUsed
		refundPcTx.Status = "SUCCESS"
	}

	outbound.PcRefundExecution = refundPcTx
	outbound.RefundSwapError = swapFallbackReason
}

// getSwapQuoteForRefund fetches a Uniswap quote for the gas token refund swap.
func (k Keeper) getSwapQuoteForRefund(ctx sdk.Context, gasToken common.Address, fee *big.Int, amount *big.Int) (*big.Int, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(ctx)
	if err != nil {
		return nil, err
	}
	wpcAddr, err := k.GetUniversalCoreWPCAddress(ctx)
	if err != nil {
		return nil, err
	}
	return k.GetSwapQuote(ctx, quoterAddr, gasToken, wpcAddr, fee, amount)
}

func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}
