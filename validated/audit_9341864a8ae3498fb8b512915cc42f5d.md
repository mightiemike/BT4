### Title
Unauthenticated outbound creation from arbitrary user EVM transactions via `EVMHooks.PostTxProcessing` log matching - (File: x/uexecutor/keeper/evm_hooks.go, x/uexecutor/keeper/create_outbound.go)

### Summary
`BuildOutboundsFromReceipt` treats any `UniversalTxOutboundEventSig` log emitted by the `UniversalGatewayPC` contract address as authoritative proof of an intended outbound, regardless of which account or contract called the gateway. Since `EVMHooks.PostTxProcessing` fires on every EVM transaction (not just module-originated `DerivedEVMCall`s), and the gateway is a normal EVM contract callable by anyone, an attacker who finds any caller path into the gateway that emits this event (even indirectly, e.g. by driving execution of their own UEA/contract that calls the gateway) can trigger creation of a real `UniversalTx` + `PENDING` `OutboundTx` that TSS will eventually sign and broadcast — funded from the vault, not from the attacker.

### Finding Description
This is the closest node-side analog to the C4 "MoneyMarketHook lacks reentrancy/step-isolation, so a later untrusted step can spend value meant for the caller" pattern: a downstream side-effect (fund release) is triggered purely by observing an event, with no binding to how/why that event was produced or by whom the underlying value was authorized.

`BuildOutboundsFromReceipt` iterates over `receipt.Logs`, matching solely on `lg.Address` and `lg.Topics[0]`: [4](#0-3) 

It performs no check that the log originated from a `DerivedEVMCall` issued by the `uexecutor` module for a validated, funded inbound. Any EVM transaction whose execution trace ends up emitting `UniversalTxOutboundEventSig` from the gateway address — regardless of `msg.sender`, and regardless of whether real value was locked/burned to back it — is converted into a canonical outbound instruction: [5](#0-4) 

The hook wiring confirms this fires for ordinary EVM transactions, not only protocol derived calls: [6](#0-5) 

Whether the gateway contract itself enforces `msg.sender`/authorization checks before emitting `UniversalTxOutboundEventSig` is defined in `push-chain-core-contracts` (a separate repository), which is **not included in this repo's index**, so I cannot confirm from this codebase alone whether the Solidity-side gateway restricts who can trigger this event. If the gateway allows any caller (or any UEA acting on a user's own signed payload) to invoke a code path that emits this event without actually locking/burning corresponding value, the Go-side consumer (`BuildOutboundsFromReceipt`) has no independent value-conservation check and will happily queue a TSS-signed release of real vault funds.

### Impact Explanation
If reachable, this breaks the "funds must be locked/burned before an outbound is created" invariant. It would let an unprivileged attacker mint arbitrary `OutboundTx` entries that honest UVs and TSS will treat as legitimate and eventually broadcast/release funds on the destination chain — draining the vault. This matches "unauthorized release... of protocol-controlled funds" and "corruption of canonical UniversalTx state" in the allowed-impact list.

### Likelihood Explanation
Likelihood is **uncertain/low-to-unknown** from this repo alone: the actual gatekeeping (whether an arbitrary EVM caller/contract can cause the gateway to emit `UniversalTxOutboundEventSig` without real value backing) lives in the Solidity gateway contract, which is out of this repository's scope and not present in the indexed code. Within the Go node code, there is no additional authorization or value-conservation check on top of the raw log match, so if any Solidity-side path allows unauthorized emission, this Go consumer offers zero defense-in-depth.

### Recommendation
- Add defense-in-depth on the Go side: bind `BuildOutboundsFromReceipt`/`CreateUniversalTxFromReceiptIfOutbound` to only accept outbound events from receipts produced by module-issued `DerivedEVMCall`s (e.g., pass an explicit flag/context proving the call originated from `x/uexecutor`'s own inbound-execution flow), rather than trusting any receipt with a matching log.
- Independently verify, in the Go layer, that the value implied by the outbound event corresponds to funds actually deposited/burned for the referencing UTX before creating a `PENDING` outbound.
- Confirm in `push-chain-core-contracts` that `UniversalGatewayPC`'s outbound-emitting functions strictly enforce that only value-locking calls (with real transferred/burned amounts) can emit `UniversalTxOutboundEventSig`, and that arbitrary externally-owned accounts or attacker-controlled contracts cannot trigger it "for free."

### Proof of Concept
Not able to construct a concrete on-chain PoC from this repository alone, since the trigger condition depends on Solidity-side authorization in `UniversalGatewayPC` (external repo, not indexed here). The Go-side gap is demonstrated structurally: `BuildOutboundsFromReceipt` in `x/uexecutor/keeper/create_outbound.go:16-105` performs no sender/authorization check beyond `lg.Address == gatewayAddress`, and `EVMHooks.PostTxProcessing` in `x/uexecutor/keeper/evm_hooks.go:28-66` invokes it for every EVM transaction's receipt.

---

**Caveat:** I was unable to fully verify whether the external gateway contract enforces sufficient authorization to prevent unprivileged triggering of this event, because the Solidity contracts live in `pushchain/push-chain-core-contracts`, a repository not present in this index. If that contract strictly gates outbound-emission behind value-locking logic that cannot be bypassed by an unprivileged caller, this finding reduces to informational (defense-in-depth only) rather than an exploitable vulnerability. I recommend starting a full Devin session with access to both repositories to confirm the Solidity-side authorization before treating this as a confirmed, actionable vulnerability.

// PostTxProcessing is called by the EVM module after transaction execution.
// It inspects the receipt and creates UniversalTx + Outbound only if
// UniversalTxWithdraw event is detected.
func (h EVMHooks) PostTxProcessing(
	ctx sdk.Context,
	sender common.Address,
	msg core.Message,
	receipt *ethtypes.Receipt,
) error {
	if receipt == nil || len(receipt.Logs) == 0 {
		return nil
	}

	h.k.Logger().Debug("evm hook post-tx processing",
		"tx_hash", receipt.TxHash.Hex(),
		"sender", sender.Hex(),
		"log_count", len(receipt.Logs),
		"gas_used", receipt.GasUsed,
	)

	protoReceipt := &evmtypes.MsgEthereumTxResponse{
		Hash:    receipt.TxHash.Hex(),
		GasUsed: receipt.GasUsed,
		Logs:    convertReceiptLogs(receipt.Logs),
	}

	// Build pcTx representation
	pcTx := types.PCTx{
		Sender:      sender.Hex(),
		TxHash:      protoReceipt.Hash,
		GasUsed:     protoReceipt.GasUsed,
		BlockHeight: uint64(ctx.BlockHeight()),
		Status:      "SUCCESS",
	}

	// Handle normal outbounds (UniversalTxOutbound events → new UTX + outbounds).
	if err := h.k.CreateUniversalTxFromReceiptIfOutbound(ctx, protoReceipt, pcTx); err != nil {
		return err
	}

	// Handle rescue outbounds (RescueFundsOnSourceChain events → attach to original UTX).
	return h.k.AttachRescueOutboundFromReceipt(ctx, protoReceipt, pcTx)

func (k Keeper) BuildOutboundsFromReceipt(
	ctx context.Context,
	utxId string,
	receipt *evmtypes.MsgEthereumTxResponse,
) ([]*types.OutboundTx, error) {

	outbounds := []*types.OutboundTx{}
	universalGatewayPC := strings.ToLower(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_GATEWAY_PC"].Address)

	k.Logger().Debug("building outbounds from receipt", "utx_id", utxId, "tx_hash", receipt.Hash, "log_count", len(receipt.Logs))

	for _, lg := range receipt.Logs {
		if lg.Removed {
			continue
		}

		if strings.ToLower(lg.Address) != universalGatewayPC {
			continue
		}

		if len(lg.Topics) == 0 {
			continue
		}

		if strings.ToLower(lg.Topics[0]) != strings.ToLower(types.UniversalTxOutboundEventSig) {
			continue
		}

		event, err := types.DecodeUniversalTxOutboundFromLog(lg)
		if err != nil {
			return nil, fmt.Errorf("failed to decode UniversalTxWithdraw: %w", err)
		}

		// Check if outbound is enabled for the destination chain
		outboundEnabled, err := k.uregistryKeeper.IsChainOutboundEnabled(ctx, event.ChainId)
		if err != nil {
			return nil, fmt.Errorf("failed to check outbound enabled for chain %s: %w", event.ChainId, err)
		}
		if !outboundEnabled {
			k.Logger().Warn("outbound disabled for chain", "chain_id", event.ChainId, "utx_id", utxId)
			return nil, fmt.Errorf("outbound is disabled for chain %s", event.ChainId)
		}

		// Get the external asset addr
		tokenCfg, err := k.uregistryKeeper.GetTokenConfigByPRC20(
			ctx,
			event.ChainId,
			event.Token, // PRC20 address
		)
		if err != nil {
			return nil, err
		}

		outbound := &types.OutboundTx{
			DestinationChain:  event.ChainId,
			Recipient:         event.Target,
			Amount:            event.Amount.String(),
			ExternalAssetAddr: tokenCfg.Address,
			Prc20AssetAddr:    event.Token,
			Sender:            event.Sender,
			Payload:           event.Payload,
			GasFee:            event.GasFee.String(),
			GasLimit:          event.GasLimit.String(),
			GasPrice:          event.GasPrice.String(),
			GasToken:          event.GasToken,
			TxType:            event.TxType,
			PcTx: &types.OriginatingPcTx{
				TxHash:   receipt.Hash,
				LogIndex: fmt.Sprintf("%d", lg.Index),
			},
			RevertInstructions: &types.RevertInstructions{
				FundRecipient: event.RevertRecipient,
			},
			OutboundStatus: types.Status_PENDING,
			Id:             strings.TrimPrefix(event.TxID, "0x"),
		}

		k.Logger().Debug("outbound built from receipt",
			"utx_id", utxId,
			"outbound_id", outbound.Id,
			"dest_chain", outbound.DestinationChain,
			"amount", outbound.Amount,
			"tx_type", outbound.TxType.String(),
		)
		outbounds = append(outbounds, outbound)
	}

	k.Logger().Debug("outbounds built from receipt", "utx_id", utxId, "count", len(outbounds))
	return outbounds, nil
}

// CreateUniversalTxFromReceiptIfOutbound
// Creates a UniversalTx ONLY if outbound events exist in the receipt.
// Safe to call from ExecutePayload, EVM hooks
func (k Keeper) CreateUniversalTxFromReceiptIfOutbound(
	ctx sdk.Context,
	receipt *evmtypes.MsgEthereumTxResponse,
	pcTx types.PCTx,
) error {
	universalTxKey, err := k.BuildPcUniversalTxKey(ctx, pcTx)
	if err != nil {
		return errors.Wrap(err, "failed to create UniversalTx key")
	}

	outbounds, err := k.BuildOutboundsFromReceipt(ctx, universalTxKey, receipt)
	if err != nil {
		return err
	}

	if len(outbounds) == 0 {
		return nil
	}

	utx, err := k.CreateUniversalTxFromPCTx(ctx, pcTx)
	if err != nil {
		return err
	}

	return k.attachOutboundsToUtx(ctx, utx.Id, outbounds, "")
}
