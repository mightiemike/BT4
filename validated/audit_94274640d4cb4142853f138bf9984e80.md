## Analysis: Missing gas-fee accounting guard in `MigrateUEA` (sibling to `ExecutePayload`)

The H-7 bug class is: a state-mutating, user-reachable function omits a safety check that an almost-identical sibling function in the same codebase *does* enforce, letting an unprivileged caller trigger state changes under conditions the protocol explicitly designed the sibling function to reject/guard against.

### Title
`MigrateUEA` skips the gas-fee-accounting guard that `ExecutePayload` enforces, enabling free/unaccounted EVM execution via a gasless message - (File: `x/uexecutor/keeper/msg_migrate_uea.go`)

### Summary
`MsgExecutePayload` and `MsgMigrateUEA` are both gasless, unprivileged, user-reachable message types that route into a real `DerivedEVMCall` against a deployed UEA contract [1](#0-0) . `ExecutePayloadV2` wraps its EVM call and `DeductGasFeesFromReceipt` in one `CacheContext` specifically "to close the free-execution gap when the recipient contract has no native UPC to cover gas" [2](#0-1) . `MigrateUEA`, which follows the identical shape (parse payload → resolve UEA → `DerivedEVMCall` with `commit=true`), has no equivalent fee-deduction step at all [3](#0-2) .

### Finding Description
`MsgMigrateUEA` is in the gasless allowlist, so the Cosmos-level `DeductFeeDecorator` skips fee collection from the tx signer entirely [4](#0-3) . The only other place gas cost could be recovered is inside the keeper, by billing the UEA whose EVM state is actually being mutated — exactly what `ExecutePayloadV2` does via `DeductGasFeesFromReceipt` [5](#0-4) . `Keeper.MigrateUEA` calls `CallUEAMigrateUEA` (a `commit=true` `DerivedEVMCall`, i.e. real chain state mutation with real EVM gas consumption) and returns immediately after logging success — no `DeductGasFeesFromReceipt`, no `CacheContext` fee-rollback safety net exists in this path [6](#0-5) . `CallUEAMigrateUEA` itself explicitly documents that `gasless=false` because "we need gas to be emitted in the tx receipt" — i.e., the design assumes something downstream will read and bill that gas, but nothing does for this call site [7](#0-6) .

Since `Signer ≠ Owner` is an intentional design allowance (any third party may submit a payload on someone else's behalf, exactly as documented for `ExecutePayload`) [8](#0-7) , an unprivileged external caller can submit an arbitrary number of `MsgMigrateUEA` transactions (gasless at the Cosmos layer) against any deployed UEA address. Each submission forces the node to execute a real `DerivedEVMCall` into the UEA's `migrateUEA` entry point — consuming real EVM computation/storage-touch resources — with the resulting gas neither charged to the Cosmos signer (gasless bypass) nor to the UEA (no `DeductGasFeesFromReceipt` call, unlike the sibling `ExecutePayload` flow).

### Impact Explanation
This breaks the gas-fee-accounting invariant that the rest of `x/uexecutor` is built around (every derived EVM call site is expected to have its cost recovered from either the Cosmos fee payer or the UEA balance, per `DERIVED_TRANSACTIONS.md`'s explicit gasless/receipt accounting model). An unprivileged actor gets free, unbounded, protocol-subsidized EVM execution against the module-account-derived call path, which is a denial-of-service surface reachable purely through ordinary user transaction submission (no validator, admin, or key compromise required) — squarely inside the allowed-impact gate's "denial of service only when it is not network-level and is reachable without privileged control."

### Likelihood Explanation
`MsgMigrateUEA` is always accepted as gasless as long as it's the only message type in the tx (or nested in an all-gasless `authz.MsgExec`) [9](#0-8) ; no bonded/whitelisted status is required to submit it (unlike vote messages, which require bonded universal-validator status). This makes the missing fee-deduction step trivially and repeatedly reachable by any external account, with no auction/quorum/timing prerequisites — comparable in ease to the H-7 scenario where `mergeOrRemoveCollateral` could be called "at will."

### Recommendation
Add the same `CacheContext` + `DeductGasFeesFromReceipt` pattern used in `ExecutePayloadV2` to `Keeper.MigrateUEA`, billing the UEA (or otherwise metering/rate-limiting the gasless `MsgMigrateUEA` path) so that the EVM execution triggered by `CallUEAMigrateUEA` cannot be invoked for free by an unprivileged, unbonded caller.

### Proof of Concept
1. Attacker (any funded-or-unfunded Cosmos account, no bonding/whitelisting required) crafts `MsgMigrateUEA{Signer: attacker, UniversalAccountId: <any deployed UEA>, MigrationPayload: <arbitrary/garbage>, Signature: <arbitrary>}`.
2. Submits it alone in a tx — `IsGaslessTx` returns true, so `DeductFeeDecorator` and `MinGasPriceDecorator` skip entirely; no Cosmos-level fee is required.
3. `msgServer.MigrateUEA` → `Keeper.MigrateUEA` resolves the UEA and calls `CallUEAMigrateUEA`, a real `commit=true` `DerivedEVMCall` [10](#0-9) .
4. Even if the EVM call reverts inside the UEA (invalid signature/nonce), the EVM execution and its resource consumption have already occurred; unlike `ExecutePayloadV2`, no compensating fee is ever collected from anyone.
5. Repeating this at scale allows unpriced resource consumption purely from unprivileged, gasless transaction submission.

	// commit/revert together. If fee deduction fails, the EVM state changes

	// gap when the UEA has no native UPC to cover gas.
	cacheCtx, writeCache := sdkCtx.CacheContext()
	receipt, execErr := k.CallUEAExecutePayload(cacheCtx, evmFrom, ueaAddr, universalPayload, verificationDataVal)

	// Step 3: Try fee deduction in the same cache. DeductGasFeesFromReceipt
	// is a no-op if the receipt is nil or GasUsed == 0 (EVM call produced
	// nothing to bill).
	if feeErr := k.DeductGasFeesFromReceipt(cacheCtx, cacheCtx, ueaAddr, receipt, universalPayload); feeErr != nil {
		// Cache discarded — EVM state and any partial fee work both roll back.
		return receipt, fmt.Errorf("gas fee deduction failed: %w", feeErr)
	}

	if execErr != nil {
		// EVM execution failed — cache discarded by not calling writeCache.
		return receipt, execErr

func (k Keeper) MigrateUEA(ctx context.Context, evmFrom common.Address, universalAccountId *types.UniversalAccountId, migrationPayload *types.MigrationPayload, signature string) error {
	sdkCtx := sdk.UnwrapSDKContext(ctx)

	// Get Caip2Identifier for the universal account
	caip2Identifier := universalAccountId.GetCAIP2()

	k.Logger().Info("migrate UEA",
		"from", evmFrom.Hex(),
		"chain", caip2Identifier,
		"owner", universalAccountId.Owner,
	)

	// Step 1: Parse and validate payload and signature
	_, err := types.NewAbiMigrationPayload(migrationPayload)
	if err != nil {
		return errors.Wrapf(err, "invalid migration payload")
	}

	// add signature verification
	signatureVal, err := utils.HexToBytes(signature)
	if err != nil {
		return errors.Wrapf(err, "invalid signature format")
	}

	chainConfig, err := k.uregistryKeeper.GetChainConfig(sdkCtx, caip2Identifier)
	if err != nil {
		return errors.Wrapf(err, "failed to get chain config for chain %s", caip2Identifier)
	}

	// TODO: Decide later if migration should be disabled if inbound is disabled
	if !chainConfig.Enabled.IsInboundEnabled {
		k.Logger().Warn("migrate UEA rejected: chain not enabled", "chain", caip2Identifier)
		return fmt.Errorf("chain %s is not enabled", caip2Identifier)
	}

	factoryAddress := common.HexToAddress(types.FACTORY_PROXY_ADDRESS_HEX)

	// Step 2: Compute smart account address
	// Calling factory contract to compute the UEA address
	ueaAddr, isDeployed, err := k.CallFactoryToGetUEAAddressForOrigin(sdkCtx, evmFrom, factoryAddress, universalAccountId)
	if err != nil {
		return err
	}

	if !isDeployed {
		k.Logger().Warn("migrate UEA rejected: UEA not deployed", "chain", caip2Identifier, "owner", universalAccountId.Owner)
		return fmt.Errorf("UEA is not deployed")
	}

	k.Logger().Debug("migrating UEA",
		"uea", ueaAddr.Hex(),
		"chain", caip2Identifier,
		"from", evmFrom.Hex(),
	)

	// Step 3: Migrate UEA through UEA
	receipt, err := k.CallUEAMigrateUEA(sdkCtx, evmFrom, ueaAddr, migrationPayload, signatureVal)
	if err != nil {
		return err
	}

	k.Logger().Info("UEA migrated",
		"chain", caip2Identifier,
		"uea", ueaAddr.Hex(),
		"tx_hash", receipt.Hash,
		"gas_used", receipt.GasUsed,
	)

	return nil
```

### Authorization model for `MsgExecutePayload` (contract-only binding)

`MsgExecutePayload` follows a **contract-only binding** authorization model. The Cosmos signer of the message and the owner of the target Universal Account are intentionally distinct roles:

- **`Signer`** identifies the Cosmos transaction signer — the party that delivers the owner's pre-authorized payload to Push Chain. `MsgExecutePayload` is a gasless message type (see `app/txpolicy/gasless.go`), so the signer pays no Cosmos transaction fee. Any account may submit the message.
- **`UniversalAccountId.Owner`** identifies the UEA whose pre-authorized payload is being executed. The actual EVM execution gas is deducted from this UEA;s balance (`DeductGasFeesFromReceipt`), not from the signer.

**The chain module deliberately does not enforce `Signer == EVM(Owner)`.** If it did, third-party delivery of owner-signed payloads would be impossible — every owner would have to submit their own Cosmos transactions even though the chain charges them no Cosmos fee for doing so, defeating the cross-chain UX promise of letting an external account act on Push Chain through delivered payloads.
```
