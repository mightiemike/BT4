## Analog Found

### Title
Auto-swap and gas-refund `minPCOut` slippage floor is derived from the same manipulable spot quote it is meant to protect against - (File: `x/uexecutor/keeper/evm.go`)

### Summary
The TOKE-16 root cause is a caller that computes/uses a price without validating that the price is *safe* (manipulation-resistant) before acting on it — the safety flag existed but was never consulted. Push Chain's `x/uexecutor` module has the same class of defect in its Uniswap V3 auto-swap and gas-refund paths: the "safe" minimum-output bound (`minPCOut`) used to protect a protocol-initiated swap is derived entirely from the instantaneous spot quote returned by the same pool the swap will execute against, with no TWAP, no external price reference, and no sanity/deviation check.

### Finding Description
`GetSwapQuote` calls `QuoterV2.quoteExactInputSingle` — a pure read of the pool's *current* reserves/sqrtPrice — and returns that value directly: [1](#0-0) 

Every caller then derives the "safety" bound purely from that same instantaneous number:

```go
quote, execErr = k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
...
minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
minPCOut.Div(minPCOut, big.NewInt(100))
receipt, execErr = k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
``` [2](#0-1) 

The identical pattern is repeated in `gasAndPayloadDepositAutoSwap` [3](#0-2)  and in the excess-gas refund swap path `applyGasRefund`/`getSwapQuoteForRefund` [4](#0-3) .

This mirrors the reported bug's structure exactly: a helper function returns a price that carries an implicit "is this safe to use" caveat (in the report, an explicit `isSpotSafe` bool; here, the implicit assumption that a single-block `quoteExactInputSingle` read is not attacker-influenced), and the caller — whose responsibility it is to validate that assumption — never does. The 95% slippage tolerance only bounds movement *relative to the just-read price*; it does nothing if that just-read price is itself the product of manipulation, because the floor and the executed swap are computed against the same pool state in the same transaction/block.

### Impact Explanation
`CallPRC20DepositAutoSwap` and `CallUniversalCoreRefundUnusedGas` move protocol/user-controlled PRC20 and native-PC value through the module account (`isModuleSender=true`) as part of ordinary GAS / GAS_AND_PAYLOAD inbound execution and outbound gas-fee refunds — both reachable by any unprivileged user simply by sending a supported crosschain deposit or triggering an outbound. If the underlying Uniswap V3 pool can be moved (thin liquidity, or a pool an attacker can also trade against in the same block via a normal EVM transaction on Push Chain), the attacker can push the spot price down immediately before the module's auto-swap/refund executes, causing the module's swap to receive materially less PC than fair value while still satisfying its own self-referential `minPCOut` check — silently corrupting PRC20/native accounting and value transferred out of protocol-controlled swaps (a subset of the "corruption of ... gas fee accounting, refund accounting ... token mapping" allowed-impact category). This is a genuine value-extraction/loss vector distinct from ordinary user-initiated slippage.

### Likelihood Explanation
Requires only an unprivileged actor able to trade against the same on-chain Uniswap V3 pool the protocol uses for PRC20→WPC conversion, and to trigger (or wait for) a GAS/GAS_AND_PAYLOAD inbound execution or an outbound gas refund — both of which happen routinely as part of normal cross-chain traffic and are not gated by any privileged role. Feasibility depends on pool liquidity/MEV conditions on Push Chain's EVM, which is the same dependency the original TOKE-16 report flagged as "outside the safe threshold."

### Recommendation
Do not derive the slippage floor solely from the instantaneous `quoteExactInputSingle` result. Cross-check the spot quote against a manipulation-resistant reference (TWAP observation, a maximum-deviation bound against a recently observed/stored price, or an oracle) before using it to compute `minPCOut`, and abort/skip the swap (falling back to the existing no-swap deposit path, which already exists in `applyGasRefund`) if the spot price deviates beyond a safe threshold — i.e., give `GetSwapQuote` (or its callers) the equivalent of the missing `isSpotSafe` check and actually enforce it.

### Proof of Concept
1. Attacker identifies the Uniswap V3 pool backing a PRC20 token's auto-swap route on Push Chain's EVM (address obtained via `GetUniversalCoreQuoterAddress`/pool config).
2. Attacker submits a large swap against that pool within Push Chain's EVM to depress the PRC20→WPC price.
3. In the same or an adjacent block, attacker (or any user) triggers a GAS/GAS_AND_PAYLOAD inbound that causes `x/uexecutor` to call `GetSwapQuote` → compute `minPCOut = quote*95%` → `CallPRC20DepositAutoSwap`, executing the module's swap at the manipulated price.
4. Attacker reverses their initial trade (arbitrage back), pocketing the PC value the module's auto-swap lost versus fair market price, while the module's own `minPCOut` check passes because it was computed from the already-manipulated quote.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
```

func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}

// getSwapQuoteForRefund fetches a Uniswap quote for the gas token refund swap.
func (k Keeper) getSwapQuoteForRefund(ctx sdk.Context, gasToken common.Address, fee *big.Int, amount *big.Int) (*big.Int, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(ctx)
	if err != nil {
		return nil, err
	}
	wpcAddr, err := k.GetUniversalCoreWPCAddress(ctx)
	if err != nil {
		return nil, err
	}
	return k.GetSwapQuote(ctx, quoterAddr, gasToken, wpcAddr, fee, amount)
