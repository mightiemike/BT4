The reported Gitea issue is an application-level authorization bug: a persisted `official` boolean on a PR review record is computed once against a branch's approval whitelist and never re-evaluated when the PR's target branch changes, letting a stale trust decision satisfy a different branch protection policy. This requires concepts protobuf-go does not have — persisted authorization state, reviewer whitelists, retargetable approval workflows, or any per-request access-control decision that could go stale across a "context change." [1](#0-0) 

Searching the protobuf-go codebase for analogous "compute-once, reuse stale flag" patterns turned up only internal correctness mechanisms with no security-relevant trust/authorization semantics:
- The marshal size cache (`sizecacheOffset`) can become stale relative to lazily-normalized submessages, but this is a documented, self-detected inconsistency (returns a "size mismatch" error) affecting wire-format correctness, not an authorization bypass. [2](#0-1) [3](#0-2) 
- `needsInitCheck`/`checkInitializedPointer` cache whether a message descriptor needs required-field checking, and lazy fields skip re-validation once already "checked on unmarshal," but this only affects whether `proto.CheckInitialized` returns an error for a trusted, schema-conformant message — not a reachable authorization decision. [4](#0-3) [5](#0-4) 

None of these map onto the report's actual bug class (stale authorization flag surviving a context/target change and being trusted at a merge/permission-check sink) in a way that produces a concrete confidentiality/integrity impact on an unprivileged protobuf-go request path. Per the rules, this is rejected as not applicable to protobuf-go.

func (mi *MessageInfo) sizePointer(p pointer, opts marshalOptions) (size int) {
	mi.init()
	if p.IsNil() {
		return 0
	}
	if opts.UseCachedSize() && mi.sizecacheOffset.IsValid() {
		// The size cache contains the size + 1, to allow the
		// zero value to be invalid, while also allowing for a
		// 0 size to be cached.
		if size := atomic.LoadInt32(p.Apply(mi.sizecacheOffset).Int32()); size > 0 {
			return int(size - 1)
		}
	}
	return mi.sizePointerSlow(p, opts)
}
