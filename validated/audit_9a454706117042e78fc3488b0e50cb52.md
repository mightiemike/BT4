### Title
Missing staleness check when reading the ChainMeta gas-price oracle for outbound fee/refund accounting - (File: `x/uexecutor/keeper/gas_fee.go`, `x/uexecutor/keeper/evm.go`)

### Summary
The eETH bug is a case where two composed oracle inputs are used to derive a price, but only one input's staleness is validated before use. Push Chain's ChainMeta gas-price oracle has the analogous structural gap: `VoteChainMeta` carefully enforces a `chainMetaVoteStalenessSeconds` window when *writing* the median price/height to the `UniversalCore` EVM contract, but every consumer that later *reads* that stored value for fee, swap, and refund accounting does so with no freshness check at all.

### Finding Description
`x/uexecutor/keeper/chain_meta.go` gates the on-chain write path carefully: individual validator votes older than `chainMetaVoteStalenessSeconds` (300s) are excluded from the median computation before `CallUniversalCoreSetChainMeta` is invoked. [1](#0-0) 

However, once that value is written to the `UniversalCore` contract, it is treated as durable state. `GetGasPriceByChain` and `GetL1GasFeeByChain` read the value straight out of the EVM contract via `gasPriceByChainNamespace`/`l1GasFeeByChainNamespace` with no timestamp/age check on the read side. [2](#0-1) 

`GetOutboundTxGasAndFees` (in `x/uexecutor/keeper/gas_fee.go`) further composes this unchecked gas price with a swap-quote (`GetSwapQuote`) to derive `gasFee`, `gasPrice`, and `gasLimit` used for outbound transaction accounting and gas refunds (`applyGasRefund` in `x/uexecutor/keeper/outbound.go`), again without any check that the underlying `ChainMeta` entry is still fresh (i.e., that `StoredAts`/`LastAppliedChainHeight` for that chain has been updated recently by universal validators). [3](#0-2) [4](#0-3) 

If a destination chain's universal validators stop reporting fresh votes for any reason (chain temporarily disabled/re-enabled, all UVs briefly down for that chain, or the chain simply has low traffic and no new votes arrive), the last-applied gas price/height in `UniversalCore` remains frozen indefinitely. Every subsequent inbound/outbound flow for that chain — reachable purely by ordinary users submitting deposits or triggering outbounds — will silently use this stale, unvalidated price to compute swap slippage bounds, gas fee deduction, and gas refunds, exactly mirroring the structural flaw in the EETH report where a downstream computation trusted a component price value with no freshness guarantee.

### Impact Explanation
Using a stale gas price for `GetOutboundTxGasAndFees`/`applyGasRefund` can misprice the gas fee charged to or refunded to users on outbound transactions — either overcharging users (fund loss to the user) or under-collecting fees relative to real destination-chain cost (protocol subsidizes the shortfall, effectively a mispriced/incorrect accounting of protocol-controlled funds). This falls under "corruption of ... gas fee accounting, refund accounting ... token mapping" in the allowed impact gate.

### Likelihood Explanation
This requires no privileged actor and is reachable by any ordinary user submitting an inbound/outbound on a chain whose validator vote cadence has lapsed past the write-time staleness window without a fresh EVM update landing — a plausible, non-adversarial condition (e.g., low-traffic chains, temporary vote gaps). The bug is latent structural code (missing read-side staleness check), not requiring malicious validators.

### Recommendation
Store and check the last-applied timestamp (not just `LastAppliedChainHeight`) alongside the `ChainMeta` entry, and have `GetGasPriceByChain`/`GetOutboundTxGasAndFees`/`applyGasRefund` (or the `UniversalCore` contract itself) reject or flag stale gas-price reads older than a defined staleness threshold, mirroring the write-time `chainMetaVoteStalenessSeconds` gate.

### Proof of Concept
1. Chain X is enabled and bootstrapped with 3+ fresh votes; `UniversalCore.gasPriceByChainNamespace(X)` is set to price P at time T.
2. Universal validators for chain X stop submitting `MsgVoteChainMeta` (e.g., due to low activity or a temporary outage) for a period well beyond `chainMetaVoteStalenessSeconds` (300s) — no new EVM write occurs, so P remains stored indefinitely.
3. A regular, unprivileged user submits a normal inbound/outbound transaction on chain X, whose gas-fee/refund path calls `GetOutboundTxGasAndFees` → `GetGasPriceByChain`.
4. The stale price P (now potentially very different from chain X's real current gas price) is used unconditionally to compute `gasFee`/refund amounts in `applyGasRefund`, with no staleness check anywhere in the read path.

// GetGasPriceByChain reads the gas price for a chain from the UniversalCore contract.
func (k Keeper) GetGasPriceByChain(ctx sdk.Context, chainNamespace string) (*big.Int, error) {
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse UniversalCore ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	receipt, err := k.evmKeeper.CallEVM(ctx, abi, ueModuleAccAddress, handlerAddr, false, nil, "gasPriceByChainNamespace", chainNamespace)
	if err != nil {
		return nil, errors.Wrap(err, "failed to call gasPriceByChainNamespace")
	}

	results, err := abi.Methods["gasPriceByChainNamespace"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack gasPriceByChainNamespace result")
	}

	return results[0].(*big.Int), nil
}

// Pass gasLimitWithBaseLimit=0 to use the contract's baseLimit.
func (k Keeper) GetOutboundTxGasAndFees(ctx sdk.Context, prc20 common.Address, gasLimitWithBaseLimit *big.Int) (*GasFeeInfo, error) {
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	ucABI, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse UniversalCore ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	receipt, err := k.evmKeeper.CallEVM(ctx, ucABI, ueModuleAccAddress, handlerAddr, false, nil,
		"getOutboundTxGasAndFees", prc20, gasLimitWithBaseLimit)
	if err != nil {
		return nil, errors.Wrap(err, "failed to call getOutboundTxGasAndFees")
	}

	results, err := ucABI.Methods["getOutboundTxGasAndFees"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack getOutboundTxGasAndFees result")
	}

	gasToken := results[0].(common.Address)
	gasFee := results[1].(*big.Int)
	// protocolFee := results[2].(*big.Int) — not needed for outbound fields
	gasPrice := results[3].(*big.Int)
	// chainNamespace := results[4].(string) — not needed for outbound fields
	// gasLimitUsed (results[5]) is the exact gas limit the contract resolved
	// (caller-supplied or per-chain baseGasLimitByChainNamespace fallback).
	// Reading it directly avoids the gasFee/gasPrice round-trip and keeps us
	// in lock-step with the contract's own resolution.
	gasLimit := results[5].(*big.Int)

	return &GasFeeInfo{
		GasToken: gasToken,
		GasFee:   gasFee,
		GasPrice: gasPrice,
		GasLimit: gasLimit,
	}, nil
}

// applyGasRefund computes the excess gas (gasFee - gasFeeUsed) and, if positive,
// calls UniversalCore refundUnusedGas. The result is recorded in outbound.PcRefundExecution.
// It is called for both successful and failed outbounds — gas is consumed on the
// external chain regardless of execution outcome.
func (k Keeper) applyGasRefund(ctx sdk.Context, outbound *types.OutboundTx, obs *types.OutboundObservation) {
	if obs.GasFeeUsed == "" || outbound.GasFee == "" || outbound.GasToken == "" {
		return
	}

	gasFee := new(big.Int)
	if _, ok := gasFee.SetString(outbound.GasFee, 10); !ok {
		return
	}

	gasFeeUsed := new(big.Int)
	if _, ok := gasFeeUsed.SetString(obs.GasFeeUsed, 10); !ok {
		return
	}

	// No excess gas to refund
	if gasFee.Cmp(gasFeeUsed) <= 0 {
		return
	}

	refundAmount := new(big.Int).Sub(gasFee, gasFeeUsed)
	gasToken := common.HexToAddress(outbound.GasToken)

	// Refund recipient: prefer fund_recipient in revert_instructions, fall back to sender
	refundRecipient := outbound.Sender
	if outbound.RevertInstructions != nil && outbound.RevertInstructions.FundRecipient != "" {
		refundRecipient = outbound.RevertInstructions.FundRecipient
	}
	recipientAddr := common.HexToAddress(refundRecipient)

	refundPcTx := &types.PCTx{
		Sender:      outbound.Sender,
		BlockHeight: uint64(ctx.BlockHeight()),
	}

	// Step 1: try refund with swap (gasToken → PC native)
	fee, swapErr := k.GetDefaultFeeTierForToken(ctx, gasToken)
	var swapFallbackReason string

	if swapErr == nil {
		quote, quoteErr := k.getSwapQuoteForRefund(ctx, gasToken, fee, refundAmount)
		if quoteErr == nil {
			minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
			minPCOut.Div(minPCOut, big.NewInt(100))

			resp, err := k.CallUniversalCoreRefundUnusedGas(ctx, gasToken, refundAmount, recipientAddr, true, fee, minPCOut)
			if err == nil {
				refundPcTx.TxHash = resp.Hash
				refundPcTx.GasUsed = resp.GasUsed
				refundPcTx.Status = "SUCCESS"
				outbound.PcRefundExecution = refundPcTx
				return
			}
			swapFallbackReason = fmt.Sprintf("swap refund failed: %s", err.Error())
		} else {
			swapFallbackReason = fmt.Sprintf("quote fetch failed: %s", quoteErr.Error())
		}
	} else {
		swapFallbackReason = fmt.Sprintf("fee tier fetch failed: %s", swapErr.Error())
	}

	// Step 2: fallback — refund without swap (deposit PRC20 directly to recipient)
	ctx.Logger().Error("applyGasRefund: swap refund failed, falling back to no-swap",
		"outbound_id", outbound.Id,
		"reason", swapFallbackReason,
	)

	resp, err := k.CallUniversalCoreRefundUnusedGas(ctx, gasToken, refundAmount, recipientAddr, false, big.NewInt(0), big.NewInt(0))
	if err != nil {
		refundPcTx.Status = "FAILED"
		refundPcTx.ErrorMsg = err.Error()
	} else {
		refundPcTx.TxHash = resp.Hash
		refundPcTx.GasUsed = resp.GasUsed
		refundPcTx.Status = "SUCCESS"
	}

	outbound.PcRefundExecution = refundPcTx
	outbound.RefundSwapError = swapFallbackReason
}
