## Analysis

Push Chain's native analog of this bug lives in the gas-abstraction/refund swap paths in `x/uexecutor`, which use the exact "swap-router with no independent price reference" pattern the external report flags, just wrapped in a two-step quote→swap call instead of a hardcoded `amountOutMinimum: 0`.

### Title
Sandwichable AMM auto-swaps due to self-referential (non-TWAP) slippage protection in `GetSwapQuote` / `CallPRC20DepositAutoSwap` - (File: `x/uexecutor/keeper/evm.go`, `x/uexecutor/keeper/execute_inbound_gas.go`, `x/uexecutor/keeper/execute_inbound_gas_and_payload.go`, `x/uexecutor/keeper/outbound.go`)

### Summary
All three PRC20 ↔ WPC auto-swap paths (GAS inbound top-up, GAS_AND_PAYLOAD inbound top-up, and outbound gas-refund) compute their slippage floor (`minPCOut`) by calling `QuoterV2.quoteExactInputSingle` against the *same* Uniswap V3 pool, immediately before executing the real swap against that same pool, with `sqrtPriceLimitX96: 0` and no TWAP/oracle reference [1](#0-0) . Because the "protection" value is derived from the pool's own instantaneous state rather than an independent price source, an attacker who manipulates the pool immediately beforehand causes the quote itself to reflect the manipulated price, so `minPCOut = quote * 95%` still passes even though the user's PRC20 is converted at a manipulated rate — a classic sandwich, functionally equivalent to `amountOutMinimum: 0` from the external report.

### Finding Description
`GetSwapQuote` calls the router's quoter with the live pool state and no price-limit guard: [2](#0-1) . This quote is used, unmodified except for a flat 5% haircut, as the minimum acceptable output for the subsequent real swap:

- `ExecuteInboundGas` (gas top-up on inbound): fetches quote then calls `CallPRC20DepositAutoSwap` with `minPCOut = quote*95/100` [3](#0-2) .
- `gasAndPayloadDepositAutoSwap` (GAS_AND_PAYLOAD inbound): identical pattern [4](#0-3) .
- `applyGasRefund` (outbound excess-gas refund, swap leg): identical pattern via `getSwapQuoteForRefund` [5](#0-4) .

In all three, `GetSwapQuote` and the actual `depositPRC20WithAutoSwap`/`refundUnusedGas` swap execute back-to-back against the same on-chain AMM pool, so both the "reference price" and the "execution price" are drawn from the exact same manipulable pool state [6](#0-5) . This is the well-known DeFi anti-pattern of using an AMM's own current/spot state as its own slippage reference: an attacker can push the pool price against the user right before this state is read, causing the "protected" minimum to reflect the manipulated (unfavorable) price rather than fair value, then reverse the manipulation afterward to capture the difference — economically identical to no slippage protection at all, just with an extra multiplication step.

The when/how of the trigger is externally observable and public: `ExecuteInboundGas`/`ExecuteInboundGasAndPayload` fire deterministically the moment 2/3+1 quorum of `MsgVoteInbound` votes for a given inbound is reached [7](#0-6) , and `applyGasRefund` fires the moment `MsgVoteOutbound` quorum is reached. Both vote counts and the underlying WPC/PRC20 pool are public on-chain state, so any unprivileged party can watch for the (n-1)th vote and time a manipulation swap to land immediately before the quorum-triggering vote's execution in the same or adjacent block.

### Impact Explanation
This directly causes user/protocol fund loss inside Push Chain's own accounting: the amount of native WPC/PC credited to a user's UEA for gas top-ups (or refunded to a sender/fund-recipient) can be made materially less than fair value, with the difference extracted by the attacker via the sandwich, while the deficit is absorbed by the user (their deposited PRC20 buys less PC than it should) or by the pool/protocol liquidity. This falls squarely in-scope: "corruption of ... native asset accounting, gas fee accounting, refund accounting ... or canonical UniversalTx state" reachable "from ordinary user deposits ... alone," with no privileged actor required.

### Likelihood Explanation
Likelihood is moderate-to-high wherever these swap pools have real, attacker-tradable liquidity: the trigger conditions (quorum vote finalization) are publicly observable, the pool used is a standard Uniswap V3 pool addressable and tradable by anyone, and no code path introduces an independent price oracle, TWAP, or min-liquidity/impact check — the 5% band is trivially eaten by even a modest manipulation given typically thin PRC20/WPC pool depth on a young chain.

### Recommendation
Replace the self-referential spot quote with an independently sourced reference price (e.g., a TWAP observation over a window prior to the triggering block, or an off-chain oracle price fed via governance/registry) to compute `minPCOut`, and/or introduce a maximum allowed price-impact check comparing the pre-trade and post-trade pool price so a single-block manipulation is rejected. Do not compute the "minimum acceptable output" from the same instantaneous pool state that the swap itself will execute against.

### Proof of Concept
1. Attacker observes an inbound (or outbound) approaching vote quorum on a chain/token pair with a live, attacker-tradable PRC20/WPC pool.
2. Immediately before the quorum-finalizing `MsgVoteInbound`/`MsgVoteOutbound` is processed, attacker submits a large swap against the same pool to depress the PRC20→WPC exchange rate.
3. `GetSwapQuote` executes after the manipulation and returns a depressed `amountOut`; `minPCOut = quote*95/100` is computed from this depressed value [8](#0-7) .
4. `CallPRC20DepositAutoSwap` executes the real swap at the still-manipulated price, which trivially clears the depressed `minPCOut` floor, crediting the user's UEA with less WPC/PC than fair value.
5. Attacker reverses their manipulation swap, restoring the pool price and pocketing the difference extracted from the user's deposited PRC20.

```go
// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}
```

```go
// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)
```
