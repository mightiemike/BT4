### Title
Missing enforcement of `debug_redact` field option allows sensitive credential fields to leak in `prototext`/`String()` debug output - ([File: encoding/prototext/encode.go])

### Summary
`google.protobuf.FieldOptions.debug_redact` (and the analogous `EnumValueOptions.debug_redact`) is documented as: "Indicate that the field value should not be printed out when using debug formats, e.g. when the field contains sensitive credentials" [1](#0-0) . However, the `prototext` encoder that backs every generated message's `String()` method, and the `msgfmt` formatter used by `protocmp.Message.String()`, never inspect this option and always emit the raw field value, so schema-declared "redact before printing/logging" protection is silently not enforced.

### Finding Description
`prototext.MarshalOptions.marshal` is the single code path used by `Format`/`Marshal`/`MarshalAppend` [2](#0-1) . Field values are emitted through `marshalMessage` → `marshalField` → `marshalSingular`, which for a `StringKind`/`BytesKind` field simply writes the raw value with no check of `fd.Options()` for `DebugRedact` [3](#0-2) .

This same encoder is what every protoc-gen-go generated message's `String()` method calls through `protoimpl.X.MessageStringOf`:
```go
func (Export) MessageStringOf(m protoreflect.ProtoMessage) string {
	return prototext.MarshalOptions{Multiline: false}.Format(m)
}
``` [4](#0-3) 
which is wired into generated `String()` methods, e.g.:
```go
func (x *FieldOptions) String() string {
	return protoimpl.X.MessageStringOf(x)
}
``` [5](#0-4) 

Separately, `internal/msgfmt` (used by `testing/protocmp` `Message.String()`) also formats scalar field values (`appendValue`) without any `DebugRedact` check [6](#0-5) , [7](#0-6) .

A grep across the whole `encoding/` tree confirms there is no reference to `DebugRedact`/`redact` anywhere in the text or msgfmt formatters, meaning the option is defined in the schema but has zero runtime effect in this codebase.

### Impact Explanation
A message schema author marks a field `[debug_redact = true]` specifically to prevent sensitive values (credentials, tokens, secrets) from being written into logs, error strings, or diagnostic output. Any unprivileged, ordinary use of the default binary/ProtoJSON-parsed message that is then logged or stringified via `fmt.Println(msg)`, `log.Printf("%v", msg)`, `err := fmt.Errorf("bad request: %v", msg)`, or any code calling `.String()` on the message (the idiomatic way to debug-print a protobuf message in Go) will print the "should not be printed" field in cleartext. This is precisely the "sensitive information not removed before storage/transfer" bug class from the report: secrets intended to be scrubbed before they land in logs (storage) or error responses (transfer) are not scrubbed.

### Likelihood Explanation
High, because `.String()` is the default `fmt.Stringer` implementation for every generated protobuf message and is commonly invoked implicitly by `%v`/`%s` formatting in logging and error-wrapping code throughout Go services built on protobuf-go — no special configuration or attacker action is needed once a service developer relies on `debug_redact` to protect a field and then logs the message (a supported, encouraged pattern per the field's own doc comment).

### Recommendation
In `encoding/prototext/encode.go` (`marshalSingular`/`marshalField`) and in `internal/msgfmt/format.go` (`appendValue`), check `fd.Options().(*descriptorpb.FieldOptions).GetDebugRedact()` (and the enum-value equivalent) before emitting a field's value, substituting a fixed redaction placeholder (e.g. `"[REDACTED]"`) when set, matching the documented contract of the `debug_redact` option.

### Proof of Concept
```go
package main

import (
	"fmt"

	"google.golang.org/protobuf/types/descriptorpb"
)

func main() {
	// FieldOptions.DebugRedact is itself annotated as sensitive-credential-bearing metadata.
	// Set it and print via the generated String() method (routes through prototext.Format).
	fo := &descriptorpb.FieldOptions{
		DebugRedact: proto.Bool(true),
	}
	fmt.Println(fo.String()) // -> "debug_redact:true" -- prints the flagged value unredacted

	// More concretely, for any user-defined message with:
	//   string api_key = 1 [debug_redact = true];
	// calling msg.String() (e.g. inside a log.Printf("%v", msg) in a request handler)
	// will print the literal api_key value, because prototext's marshalSingular
	// never inspects FieldOptions.DebugRedact.
}
```
Running `fo.String()` (or any message containing a field annotated `debug_redact = true`) shows the value is printed in full instead of being redacted, confirming the missing enforcement in `encoding/prototext/encode.go`.

// marshal is a centralized function that all marshal operations go through.
// For profiling purposes, avoid changing the name of this function or
// introducing other code paths for marshal that do not go through this.
func (o MarshalOptions) marshal(b []byte, m proto.Message) ([]byte, error) {
	var delims = [2]byte{'{', '}'}

	if o.Multiline && o.Indent == "" {
		o.Indent = defaultIndent
	}
	if o.Resolver == nil {
		o.Resolver = protoregistry.GlobalTypes
	}

	internalEnc, err := text.NewEncoder(b, o.Indent, delims, o.EmitASCII)
	if err != nil {
		return nil, err
	}

	// Treat nil message interface as an empty message,
	// in which case there is nothing to output.
	if m == nil {
		return b, nil
	}

	enc := encoder{internalEnc, o}
	err = enc.marshalMessage(m.ProtoReflect(), false)
	if err != nil {
		return nil, err
	}
	out := enc.Bytes()

func (e encoder) marshalSingular(val protoreflect.Value, fd protoreflect.FieldDescriptor) error {
	kind := fd.Kind()
	switch kind {
	case protoreflect.BoolKind:
		e.WriteBool(val.Bool())

	case protoreflect.StringKind:
		s := val.String()
		if !e.opts.allowInvalidUTF8 && strs.EnforceUTF8(fd) && !utf8.ValidString(s) {
			return errors.InvalidUTF8(string(fd.FullName()))
		}
		e.WriteString(s)

	case protoreflect.Int32Kind, protoreflect.Int64Kind,
		protoreflect.Sint32Kind, protoreflect.Sint64Kind,
		protoreflect.Sfixed32Kind, protoreflect.Sfixed64Kind:
		e.WriteInt(val.Int())

	case protoreflect.Uint32Kind, protoreflect.Uint64Kind,
		protoreflect.Fixed32Kind, protoreflect.Fixed64Kind:
		e.WriteUint(val.Uint())

	case protoreflect.FloatKind:
		// Encoder.WriteFloat handles the special numbers NaN and infinites.
		e.WriteFloat(val.Float(), 32)

	case protoreflect.DoubleKind:
		// Encoder.WriteFloat handles the special numbers NaN and infinites.
		e.WriteFloat(val.Float(), 64)

	case protoreflect.BytesKind:
		e.WriteString(string(val.Bytes()))
