## Analysis

The concern is legitimate. Looking at `x/uexecutor/keeper/execute_inbound_gas.go`, the `ExecuteInboundGas` flow computes `minPCOut` directly from a single, instantaneous on-chain quote and applies a static 5% tolerance: [1](#0-0) 

The quote itself comes from `GetSwapQuote`, which calls Uniswap V3 `QuoterV2.quoteExactInputSingle` as a plain read-only `CallEVM` — i.e., it reads the pool's *current* spot state with no TWAP, no historical averaging, and no manipulation-resistance check: [2](#0-1) 

`CallPRC20DepositAutoSwap` then executes the real swap using that just-computed `minPCOut` as the sole floor, and the recipient of the swap output is the sender's own UEA (`ueaAddr`), meaning any excess extracted from the pool accrues directly to the same account that triggered the inbound: [3](#0-2) 

The same pattern (spot quote → 5% slippage → auto-swap) is repeated in `gasAndPayloadDepositAutoSwap` for the `GAS_AND_PAYLOAD` route and in `applyGasRefund`/`getSwapQuoteForRefund` for outbound gas refunds: [4](#0-3) [5](#0-4) 

This confirms the exact mechanism described in the question: an unprivileged attacker who controls both (a) the timing/amount of their own inbound gas deposit and (b) an ordinary swap transaction against the same Uniswap V3 pool can push the pool's spot price to a favorable point immediately before their inbound is finalized. Since `minPCOut` is derived from that same manipulated spot price with only a fixed 5% band, it provides no real protection — the swap executes against the pool at the manipulated rate, and the attacker's own UEA (destination of the swap output) receives value extracted from the pool's actual reserves rather than a fair, manipulation-resistant price. The attacker can then reverse their setup trade to complete a self-sandwich, realizing a profit funded by the pool's liquidity.

The e2e setup confirms these pools are protocol-created with thin liquidity (e.g., `1/4` token/WPC by default, `50/200` for pSOL), which makes spot-price manipulation cheap in practice: [6](#0-5) 

Note that the trigger timing (when `ExecuteInboundGas` actually runs) depends on Universal Validator vote finalization rather than the attacker directly, but vote finalization and pending inbound status are observable on-chain, so an attacker can time their manipulation swap(s) to land in the same or an adjacent block once they see their inbound about to finalize — no privileged access is required.

### Title
Spot-price Uniswap V3 quote with fixed 5% slippage in gas-abstraction auto-swap enables AMM pool-reserve extraction via attacker-timed price manipulation - (File: `x/uexecutor/keeper/execute_inbound_gas.go`)

### Summary
`ExecuteInboundGas` (and its `GAS_AND_PAYLOAD` / refund counterparts) computes `minPCOut` for the module-executed `depositPRC20WithAutoSwap` call using a single instantaneous `QuoterV2.quoteExactInputSingle` read (`GetSwapQuote`) taken immediately before the swap, with only a static 95% floor. Because this quote reflects whatever pool state exists at execution time, and pool state is trivially moved by an ordinary, unprivileged swap transaction, the slippage guard offers no real manipulation resistance.

### Finding Description
`GetSwapQuote` is a synchronous, uncommitted `CallEVM` against the live Uniswap V3 `QuoterV2` contract — it returns the current spot-derived quote, not a time-weighted average. `ExecuteInboundGas` uses this quote directly to compute `minPCOut = quote * 95/100` and immediately passes it to `CallPRC20DepositAutoSwap`, which performs the real swap and sends the output to the depositing user's own UEA. An attacker who (1) initiates their own cross-chain gas deposit and (2) submits an ordinary swap against the same Uniswap pool timed just before their inbound's finalization can shift the pool's price so that the quote (and thus `minPCOut`) reflects a manipulated, favorable rate, letting the module's auto-swap execute against distorted reserves and extract value that a fair, TWAP-protected price would have prevented. The attacker can subsequently reverse the setup trade to lock in a profit taken from the pool's liquidity.

### Impact Explanation
This corrupts PRC20/native accounting by allowing fund extraction from AMM pool reserves that the protocol seeds and relies on for the gas-abstraction swap path (also reused for gas refunds on outbound), at the expense of pool liquidity/LPs, funded by ordinary unprivileged user action alone.

### Likelihood Explanation
Requires only an unprivileged actor able to submit ordinary swap transactions and time them relative to their own publicly observable pending inbound — no validator, relayer, or admin collusion needed. Feasibility scales inversely with pool depth; the project's own bootstrap pools are thinly seeded, making manipulation cheap in practice.

### Recommendation
Replace or augment the instantaneous `QuoterV2` spot quote with a manipulation-resistant reference price (e.g., Uniswap V3 TWAP over a sufficient window, or an external oracle-bounded sanity check) before deriving `minPCOut`, and/or widen protections with circuit breakers on abnormal single-block price deviation for these module-originated swaps.

### Proof of Concept
Property/simulation test: seed a shallow Uniswap V3 pool, execute an ordinary large swap to shift spot price, then immediately invoke `ExecuteInboundGas`'s quote→`minPCOut`→`CallPRC20DepositAutoSwap` sequence, and assert the realized swap output relative to the pre-manipulation fair price exceeds the bound expected under non-manipulated conditions — demonstrating the attacker's UEA receives excess value drawn from pool reserves.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)
}
