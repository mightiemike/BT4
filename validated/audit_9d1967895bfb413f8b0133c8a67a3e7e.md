## Analysis

The ZivoeYDL bug class is "a value read live from manipulable on-chain state (total supply) is used to allocate assets/rewards, and that value can be swung by an unprivileged actor within a single atomic operation before the allocation is computed, at another party's expense." Searching for a Push Chain analog in the deposit/execution accounting paths in `x/uexecutor`, the same pattern shows up in the built-in auto-swap logic used for `GAS` and `GAS_AND_PAYLOAD` inbound routes.

`Keeper.GetSwapQuote` in [1](#0-0)  calls the Uniswap V3 `QuoterV2.quoteExactInputSingle` against the live pool state to price a `prc20 → wpc` swap. Immediately after, this quote is turned into a `minPCOut` slippage bound of a flat 5%, and the swap is executed via `CallPRC20DepositAutoSwap` [2](#0-1) . This exact "fetch spot quote → apply fixed 5% band → swap" sequence is used in three separate module-originated flows:

- Gas-only inbound auto-swap: [3](#0-2) 
- Gas+payload inbound auto-swap: [4](#0-3) 
- Excess-gas refund swap on outbound finalization: [5](#0-4) 

In all three cases, the quote and the swap are both driven by the module's own live read of the AMM pool immediately before the swap executes, with no TWAP, no user-supplied slippage tolerance, and only a fixed 5% band as protection — this is functionally the same "manipulable live-state snapshot feeds an unprotected allocation" pattern as the ZivoeYDL `totalSupply()` issue, just applied to an AMM price rather than a staking ratio.

### Title
Fixed 5% slippage on live QuoterV2 spot price enables sandwich-style value extraction from module-driven PRC20→WPC auto-swaps - (File: x/uexecutor/keeper/evm.go)

### Summary
The Push Chain node module autonomously swaps deposited PRC20 gas tokens to native WPC on behalf of users during inbound `GAS`/`GAS_AND_PAYLOAD` processing and outbound gas refunds. The swap's minimum-output protection is derived from a live on-chain quote fetched at execution time and then discounted by a hard-coded 5%, with no TWAP and no user-controlled slippage. This mirrors the ZivoeYDL bug class: a value read from mutable on-chain state right before use, protected only by a fixed static-percentage band, which an unprivileged actor can move before the protocol snapshot is taken.

### Finding Description
`GetSwapQuote` reads the current QuoterV2 price for the exact input amount being swapped, and the resulting `minPCOut = quote * 95/100` is passed straight into `CallPRC20DepositAutoSwap`/`CallUniversalCoreRefundUnusedGas` [6](#0-5) . Because the swap is executed by the module deterministically once ballot/observation quorum finalizes, and the destination-chain pool being priced is Push Chain's own Uniswap V3-style pool, any unprivileged party can observe the pending finalization and place a large trade against the same pool in the same or adjacent block to move the spot price by more than the fixed 5% tolerance before the module's auto-swap executes. Because `minPCOut` is derived from the same manipulated spot price rather than an independent/TWAP reference, the swap still clears "successfully" even though the recipient receives a materially worse rate than fair value, and the attacker (or a colluding taker) captures the difference by reversing their position afterward. This affects value belonging to the deposit recipient/UEA — not the attacker's own funds — matching the "unauthorized... corruption of ... gas fee accounting, refund accounting ... token mapping" impact category.

### Impact Explanation
Any user whose inbound deposit or outbound gas refund triggers an auto-swap can have their PRC20→WPC conversion executed at a manipulated price, resulting in a measurable, attacker-extractable loss of value versus fair execution, i.e. partial draining of user/protocol-controlled funds through routine, unprivileged, ordinary transaction flow (deposits/refunds), without any validator or admin misbehavior.

### Likelihood Explanation
Likelihood depends on the depth/liquidity of the specific PRC20/WPC pool being swapped and on an attacker's ability to time a trade around the module's swap execution. On a pool with modest liquidity this is a standard, well-understood MEV sandwich pattern requiring no privileged access — only capital and block-level timing — making it a realistic, non-theoretical class of exploit; it is comparable in mechanics (though not in exact target) to the acknowledged-but-still-Medium ZivoeYDL finding.

### Recommendation
Replace the fixed 5% band around a single live spot quote with either: (a) a time-weighted average price (TWAP) reference for computing `minPCOut`, (b) a protocol-configurable maximum price-impact check independent of the same-block spot price, or (c) routing through a venue/mechanism resistant to single-block manipulation. At minimum, tighten and make the slippage tolerance a function of pool depth rather than a constant, and consider deferring/aggregating auto-swaps to reduce predictability of execution timing.

### Proof of Concept
1. Attacker monitors pending inbound observations on Push Chain destined for `ExecuteInboundGas` / `ExecuteInboundGasAndPayload` (or a pending outbound refund).
2. Immediately before/around the block where validator quorum finalizes and the module calls `GetSwapQuote` + `CallPRC20DepositAutoSwap`, the attacker executes a large trade against the same Uniswap V3 pool to move the PRC20/WPC spot price beyond 5%.
3. `GetSwapQuote` returns the manipulated price; `minPCOut` (95% of that manipulated quote) is still satisfied by the module's swap, so it does not revert.
4. The deposit recipient/UEA receives WPC at the manipulated (unfavorable) rate; attacker reverses their trade to realize the captured spread. [1](#0-0) [3](#0-2) [5](#0-4)

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)
}

func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,

		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err

	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)

		return nil, err
