### Title
Empty-but-`Some` Nakamoto signer set bypasses the 70% signature threshold, letting an unsigned block be accepted network-wide - ([File: stackslib/src/chainstate/stacks/boot/mod.rs])

### Summary
`StacksChainState::make_signer_set` can legally return `Some(vec![])` (a present-but-empty signer list) instead of `None` when every individual signing key's aggregated stacked amount falls below the PoX slot `threshold`. Because `RewardSet::signers()` returns `Some(&vec![])` in that case, every downstream consumer that only checks `.is_none()` to detect "no registered signers" is bypassed. The chain then computes `total_signing_weight() == 0`, `compute_voting_weight_threshold(0) == 0`, and `verify_signer_signatures` accepts a Nakamoto block with **zero** signer signatures (`0 >= 0`). This is the same bug class as the Yamcs IDOR: a per-item authorization/threshold check silently passes vacuously when the collection it iterates is empty, instead of being rejected up front.

### Finding Description
`make_signer_set` groups PoX-4 stacking entries **by signing key** and drops any key whose aggregated `stacked_amt / threshold` floors to `0`: [1](#0-0) 

If *every* signing key present in the reward cycle floors to weight `0`, the final filtered `signer_set` is an empty `Vec`, but the function still returns `Some(signer_set)` — i.e. `Some(vec![])` — rather than `None`. This is only prevented at the very top of the function when `entries` itself is empty; it is not re-checked after filtering.

`RewardSet::total_signing_weight()` then computes over that empty vector and returns `Ok(0)` rather than erroring, because it only treats `None` as "no signers": [2](#0-1) 

The guard that is supposed to reject reward cycles with no usable signer set, `NakamotoChainState::read_reward_set_at_calculated_block`, checks `rewarded_addresses().is_empty()` (a check keyed by **PoX reward address**) and `signers().is_none()` (keyed by **signing key**) — neither of which catches "signers is `Some` but empty": [3](#0-2) 

Because reward addresses and signing keys are aggregated independently (many distinct stackers can pool into one reward address while each using a unique, individually-under-threshold signing key), it is fully possible for `rewarded_addresses` to be non-empty (so that guard passes) while `signers` is `Some(vec![])` (so the `is_none()` guard also passes). Note the PoX-5 path (`pox_5_compute_and_update_signers`) added an explicit `if signer_set.is_empty() { ... return Err(PoxNoRewardCycle) }` guard for exactly this reason: [4](#0-3) 
but the classic PoX-4 path (`pox_4_compute_and_update_signers` / `make_signer_set`) has no equivalent check: [5](#0-4) 

Finally, `NakamotoBlockHeader::verify_signer_signatures` derives `total_weight` from `reward_set.total_signing_weight()` and the threshold from `compute_voting_weight_threshold(total_weight)`. With `total_weight == 0`, the threshold is `0`, so a block whose `signer_signature` vector is empty satisfies `total_weight_signed (0) >= threshold (0)` and is accepted: [6](#0-5) [7](#0-6) 

This same routine is what every full node uses on block ingest (`check_nakamoto_block_signer_signature` in the p2p layer and the store path in `stackslib/src/chainstate/nakamoto/mod.rs`), so the bypass is deterministic and network-wide, not tied to a single miner's local check: [8](#0-7) [9](#0-8) 

### Impact Explanation
The signer-threshold check is the core equality that Nakamoto consensus relies on to gate block acceptance: "≥70% of signer weight must have signed." When the reward cycle's signer set collapses to `Some(vec![])` (empty but present), that equality degenerates to `0 >= 0`, which is trivially true for a block carrying **no signatures at all**. Every honest node runs the identical deterministic check, so such an unsigned block would be accepted uniformly — this is an "invalid block accepted network-wide" condition (Critical), not merely a local divergence, since the check itself (not an attacker's forged proof) is broken for that reward cycle.

### Likelihood Explanation
Triggering the empty-but-`Some` signer set requires a reward cycle where every individual signing key's aggregated stacked amount is below the per-slot `threshold`, while at least one PoX reward address still clears the (address-grouped) reward threshold — e.g., a pool/custodian stacking on behalf of many small, independently-keyed delegators to one reward address. This is a naturally occurring PoX participation pattern (not requiring majority collusion or an admin key), so it is minority/participant-triggerable rather than needing 51% control. It is, however, contingent on the specific PoX stacking distribution for a cycle, so likelihood is bounded by how PoX participation happens to be shaped in a given cycle rather than by an attacker's unilateral action alone.

### Recommendation
- In `make_signer_set` (stackslib/src/chainstate/stacks/boot/mod.rs), return `None` (not `Some(vec![])`) when the filtered signer set is empty, mirroring the `entries.is_empty()` early return.
- In `read_reward_set_at_calculated_block` (stackslib/src/chainstate/nakamoto/coordinator/mod.rs), replace `reward_set.signers().is_none()` with a check that also rejects `Some(v) if v.is_empty()`.
- In `RewardSet::total_signing_weight` / `verify_signer_signatures`, explicitly reject (rather than silently accept with threshold 0) the case where the signer list is present but empty, matching the guard already added for PoX-5 (`pox_5_compute_and_update_signers`'s `signer_set.is_empty()` check).

### Proof of Concept
1. Construct PoX-4 stacking entries for a reward cycle such that: (a) several distinct stackers delegate to the same PoX reward address with combined `amount_stacked` above the address-grouped `threshold` (so `rewarded_addresses` is non-empty), and (b) each stacker uses a unique signing key whose *individual* `amount_stacked` is below `threshold` (so every signing key's `stacked_amt / threshold == 0`).
2. Call `StacksChainState::make_reward_set(threshold, entries, epoch)`; observe `reward_set.signers() == Some(vec![])` while `reward_set.rewarded_addresses()` is non-empty — confirmed by `make_signer_set`'s filter-then-wrap logic at [10](#0-9) .
3. Feed this `RewardSet` through `read_reward_set_at_calculated_block`; both its guards pass (address list non-empty, `signers().is_none()` is false).
4. Build a `NakamotoBlockHeader` for that reward cycle with `signer_signature = vec![]` and call `header.verify_signer_signatures(&reward_set, epoch_id)`; per the logic at [11](#0-10) , `total_weight == 0`, `threshold == 0`, and the call returns `Ok(0)` — i.e., an unsigned block is treated as validly signed.

    pub fn make_signer_set(
        threshold: u128,
        entries: &[RawRewardSetEntry],
    ) -> Option<Vec<NakamotoSignerEntry>> {
        let Some(first_entry) = entries.first() else {
            // entries is empty: there's no signer set
            return None;
        };
        // signing keys must be all-or-nothing in the reward set
        let expects_signing_keys = first_entry.signer.is_some();
        for entry in entries.iter() {
            if entry.signer.is_some() != expects_signing_keys {
                panic!("FATAL: stacking-set contains mismatched entries with and without signing keys.");
            }
        }
        if !expects_signing_keys {
            return None;
        }

        let mut signer_set = BTreeMap::new();
        for entry in entries.iter() {
            let signing_key = entry
                .signer
                .expect("BUG: signing keys should all be set in reward-sets with any signing keys");
            if let Some(existing_entry) = signer_set.get_mut(&signing_key) {
                *existing_entry += entry.amount_stacked;
            } else {
                signer_set.insert(signing_key, entry.amount_stacked);
            };
        }

        let mut signer_set: Vec<_> = signer_set
            .into_iter()
            .filter_map(|(signing_key, stacked_amt)| {
                let weight = u32::try_from(stacked_amt / threshold)
                    .expect("CORRUPTION: Stacker claimed > u32::max() reward slots");
                if weight == 0 {
                    return None;
                }
                Some(NakamotoSignerEntry {
                    signing_key,
                    stacked_amt,
                    weight,
                })
            })
            .collect();

        // finally, we must sort the signer set: the signer participation bit vector depends
        //  on a consensus-critical ordering of the signer set.
        signer_set.sort_by_key(|entry| entry.signing_key);

        Some(signer_set)
    }

    pub fn verify_signer_signatures(
        &self,
        reward_set: &RewardSet,
        epoch_id: StacksEpochId,
    ) -> Result<u32, ChainstateError> {
        let message = self.signer_signature_hash();
        let Some(signers) = reward_set.signers() else {
            return Err(ChainstateError::InvalidStacksBlock(
                "No signers in the reward set".to_string(),
            ));
        };

        // if this is a shadow block, then its signing weight is as if every signer signed it, even
        // though the signature vector is undefined.
        if self.is_shadow_block() {
            return Ok(self.get_shadow_signer_weight(reward_set)?);
        }

        let mut total_weight_signed: u32 = 0;
        // `last_index` is used to prevent out-of-order signatures
        let mut last_index = None;
        // Before Epoch 4.0, signature order check contained a bug, so gate the
        // strict ordering behavior on the epoch.
        let strict_order = epoch_id.enforces_strict_signature_order();

        let total_weight = reward_set
            .total_signing_weight()
            .map_err(|_| ChainstateError::NoRegisteredSigners(0))?;

        // HashMap of <PublicKey, (Signer, Index)>
        let mut signers_by_pk: HashMap<_, _> = signers
            .iter()
            .enumerate()
            .map(|(i, signer)| (&signer.signing_key, (signer, i)))
            .collect();

        for signature in self.signer_signature.iter() {
            let public_key = Secp256k1PublicKey::recover_to_pubkey_without_validating_low_s(
                message.bits(),
                signature,
            )
            .map_err(|_| {
                ChainstateError::InvalidStacksBlock(format!(
                    "Unable to recover public key from signature {}",
                    signature.to_hex()
                ))
            })?;

            let mut public_key_bytes = [0u8; 33];
            public_key_bytes.copy_from_slice(&public_key.to_bytes_compressed()[..]);

            let (signer, signer_index) = signers_by_pk.remove(&public_key_bytes).ok_or_else(|| {
                warn!(
                    "Found an invalid public key. Reward set has {} signers. Chain length {}. Signatures length {}",
                    signers.len(),
                    self.chain_length,
                    self.signer_signature.len(),
                );
                ChainstateError::InvalidStacksBlock(format!(
                    "Public key {} not found in the reward set",
                    public_key.to_hex()
                ))
            })?;

            // Enforce order of signatures
            if let Some(index) = last_index.as_ref() {
                if *index >= signer_index {
                    return Err(ChainstateError::InvalidStacksBlock(
                        "Signatures are out of order".to_string(),
                    ));
                }
                if strict_order {
                    last_index = Some(signer_index);
                }
            } else {
                last_index = Some(signer_index);
            }

            total_weight_signed = total_weight_signed
                .checked_add(signer.weight)
                .expect("FATAL: overflow while computing signer set threshold");
        }

        let threshold = Self::compute_voting_weight_threshold(total_weight)?;

        if total_weight_signed < threshold {
            return Err(ChainstateError::InvalidStacksBlock(format!(
                "Not enough signatures. Needed at least {} but got {} (out of {})",
                threshold, total_weight_signed, total_weight,
            )));
        }

        return Ok(total_weight_signed);
    }

    pub fn compute_voting_weight_threshold(total_weight: u32) -> Result<u32, ChainstateError> {
        let threshold = NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD;
        let total_weight = u64::from(total_weight);
        let ceil = if (total_weight * threshold) % 10 == 0 {
            0
        } else {
            1
        };
        u32::try_from((total_weight * threshold) / 10 + ceil).map_err(|_| {
            ChainstateError::InvalidStacksBlock(
                "Overflow when computing nakamoto block approval threshold".to_string(),
            )
        })
    }

    /// Check the signature of a NakamotoBlock against its sortition's reward cycle.
    /// The reward cycle must be recent. `epoch_id` is the epoch of the block's

    pub(crate) fn check_nakamoto_block_signer_signature(
        &mut self,
        reward_cycle: u64,
        epoch_id: StacksEpochId,
        nakamoto_block: &NakamotoBlock,
    ) -> bool {
        let Some(rc_data) = self.current_reward_sets.get(&reward_cycle) else {
            info!(
                "{:?}: Failed to validate Nakamoto block {}/{}: no reward set for cycle {reward_cycle}",
                self.get_local_peer(),
                &nakamoto_block.header.consensus_hash,
                &nakamoto_block.header.block_hash(),
            );
            return false;
        };
        let Some(reward_set) = rc_data.reward_set() else {
            info!(
                "{:?}: No reward set for reward cycle {}",
                self.get_local_peer(),
                reward_cycle
            );
            return false;
        };

        if let Err(e) = nakamoto_block
            .header
            .verify_signer_signatures(reward_set, epoch_id)
        {
            info!(
                "{:?}: signature verification failure for Nakamoto block {}/{} in reward cycle {}: {:?}", self.get_local_peer(), &nakamoto_block.header.consensus_hash, &nakamoto_block.header.block_hash(), reward_cycle, &e
            );
            return false;
        }
        true
    }
