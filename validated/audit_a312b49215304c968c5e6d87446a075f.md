## Analysis

Reviewing the deposit-with-autoswap path confirms a genuine price-manipulation exposure, entirely reachable by an unprivileged user through ordinary transaction submission (DEX trades on Push Chain's own quoter/pool) combined with ordinary cross-chain deposits.

### Title
Spot-price quote used as its own slippage baseline enables sandwich extraction on protocol-initiated autoswap - (File: `x/uexecutor/keeper/execute_inbound_gas_and_payload.go`)

### Summary
`gasAndPayloadDepositAutoSwap` derives its own manipulation-resistance check from the same manipulable spot price it is trying to protect against, so the 5% slippage band provides no real protection against a same-block sandwich around the module's forced swap.

### Finding Description
In `gasAndPayloadDepositAutoSwap`, the fee tier and swap quote are fetched immediately before the actual swap is executed: [1](#0-0) 

`GetSwapQuote` reads the *current on-chain spot price* from `QuoterV2.quoteExactInputSingle` on the configured quoter contract: [2](#0-1) 

`minPCOut` is then computed as `quote * 95 / 100` — a static 5% tolerance band around that same spot-derived quote — and passed straight into `CallPRC20DepositAutoSwap`, which performs the real committed swap against the identical pool: [3](#0-2) 

Because the quote and the guarded execution both read/act on the *same* pool state, and that pool's price is fully attacker-manipulable via ordinary swap transactions the attacker can submit into the same block (before the deposit's finalization/EndBlocker processing), an attacker can:
1. Push the `prc20`→`wpc` pool price down with a large swap just before the module's inbound-deposit processing executes.
2. The module then calls `GetSwapQuote`, which returns an already-depressed price, and computes `minPCOut` from that depressed price — the tolerance is anchored to the manipulated state, not to a fair/TWAP price.
3. `CallPRC20DepositAutoSwap` executes at (or above) that depressed `minPCOut`, so the swap "succeeds" while crediting the UEA with far less PC/PRC20 value than the deposit's fair value.
4. The attacker reverses their initial trade afterward, capturing the value gap extracted from the protocol-initiated swap (classic sandwich), at the UEA/depositor's expense.

There is no TWAP, external fair-value reference, or manipulation-resistant oracle used anywhere in this path — only the spot quote from the same pool being swapped against.

### Impact Explanation
This corrupts the PRC20/PC accounting credited to the victim's UEA on every GAS_AND_PAYLOAD and isCEA deposit-with-autoswap inbound, directly transferring value from depositing users to the attacker executing the sandwich. This matches the in-scope impact category of "corruption of PRC20 or native asset accounting" and unauthorized value extraction from user-controlled funds via the module's own `DerivedEVMCall`-driven autoswap.

### Likelihood Explanation
Any unprivileged actor can submit ordinary swap transactions against the same pool the quoter reads from, with no special privileges, validator collusion, or node compromise required — only ordinary DEX trading and deposit submission. The severity scales inversely with the depth of the quoter pool's liquidity relative to attacker capital; for thinly-liquidated PRC20/WPC pairs this is straightforward to execute.

### Recommendation
Do not derive the slippage floor from the same spot price being executed against. Use a manipulation-resistant reference (e.g., a time-weighted average price over a sufficiently long window, or an independent price oracle) to compute `minPCOut`, and/or bound the maximum permissible deviation between the quote and a longer-horizon reference price before allowing the autoswap to proceed.

### Proof of Concept
An integration test would: (1) seed the quoter's underlying pool at a fair price; (2) as an attacker, submit a large swap to depress the `prc20→wpc` price; (3) trigger an inbound deposit that invokes `ExecuteInboundGasAndPayload` → `gasAndPayloadDepositAutoSwap` in the same block, and observe that `GetSwapQuote` returns the depressed price, `minPCOut` is computed from it, and `CallPRC20DepositAutoSwap` succeeds while crediting the UEA with materially less PC value than the deposit's pre-manipulation fair value; (4) have the attacker reverse the initial trade and show a net profit equal to the value extracted from the deposit.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)
}
