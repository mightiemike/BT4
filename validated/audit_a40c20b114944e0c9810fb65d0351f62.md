**Reasoning:**

The premise doesn't hold up against the actual code. `ContractEvent::try_v2_typed` first calls `self.try_v2()`, which returns `None` for any `ContractEvent::V1` variant before the `type_tag` comparison ever happens: [1](#0-0) 

This means a V1-originated event (stored as `ContractEvent::V1(ContractEventV1)`) can never reach the `bcs::from_bytes` call inside `try_v2_typed` regardless of byte content — the enum discriminant itself gates decoding, not just the `type_tag` string. There is no "byte-level" ambiguity to exploit here.

Additionally, even hypothetically bypassing the enum check, the `type_tag`s for the V1 and V2 royalty-mutate schemas are distinct struct names, so a `type_tag` equality check would still reject cross-decoding: [2](#0-1) [3](#0-2) 

`RoyaltyMutate` (V2, `MoveEventV2Type`) uses struct name `"RoyaltyMutate"`, while `RoyaltyMutateEvent` (V1, `MoveEventV1Type`) uses `"RoyaltyMutateEvent"` — different `TypeTag`s, so `try_v2_typed`'s `&v2.type_tag == event_type` check would never match across schemas even if it could inspect V1 data.

The only place `RoyaltyMutate::try_from_bytes` and `RoyaltyMutateEvent::new` appear together is in the indexer's `RoyaltyMutateTranslator`, which explicitly and intentionally decodes real V2 `ContractEventV2` bytes into `RoyaltyMutate`, then re-encodes as a synthetic `RoyaltyMutateEvent` for the internal indexer DB — it never operates on genuine V1-originated bytes: [4](#0-3) 

This translation path only touches the internal indexer's auxiliary database, not the accumulator root, transaction/event proofs, JMT state, or any consensus-committed data structure. The field-layout coincidence between `RoyaltyMutate` and `RoyaltyMutateEvent` is a deliberate design choice (used for legacy-format synthesis), not an unguarded decode collision, and no unprivileged input path reaches `try_v2_typed` with mismatched V1 bytes.

    pub fn try_v2_typed<T: DeserializeOwned>(&self, event_type: &TypeTag) -> Result<Option<T>> {
        if let Some(v2) = self.try_v2() {
            if &v2.type_tag == event_type {
                return Ok(Some(bcs::from_bytes(&v2.event_data)?));
            }
        }

        Ok(None)
    }
