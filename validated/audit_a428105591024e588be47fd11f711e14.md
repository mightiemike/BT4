### Title
Blockifier `deploy` syscall omits the OS's reserved-address check, permitting a contract to be deployed onto the block-hash-table / alias / reserved special addresses - (File: crates/blockifier/src/execution/syscalls/syscall_base.rs)

### Summary
The Starknet OS Cairo implementation of contract deployment explicitly rejects deployment onto the four OS-reserved special addresses (`0`, `BLOCK_HASH_CONTRACT_ADDRESS=0x1`, `ALIAS_CONTRACT_ADDRESS=0x2`, `RESERVED_CONTRACT_ADDRESS=0x3`) via an `assert_not_zero` product check in `deploy_contract`. The Rust `blockifier` implementation of the same `deploy` syscall, which is what the sequencer actually runs to build/execute blocks, has no equivalent check before calling `execute_deployment`. An attacker-controlled `contract_address_salt`/`class_hash`/`constructor_calldata` combination that happens to hash to one of these reserved addresses would be accepted by blockifier but rejected by the OS re-execution, causing a divergence.

### Finding Description
The Cairo OS enforces reservation of special addresses when deploying a contract: [1](#0-0) 

This check runs for every OS-side deploy (both `execute_deploy` and `execute_deploy_syscall`, the Cairo0/Cairo1 deploy syscall entry points): [2](#0-1) 

The blockifier (Rust) implementation of the same `deploy` syscall — used by the sequencer for actual transaction execution/fee estimation/block building — computes `calculate_contract_address` and immediately proceeds to `execute_deployment` with no check against the reserved addresses (`ContractAddress::default()` = 0, `BLOCK_HASH_TABLE_ADDRESS` = 0x1, or the OS's `ALIAS_CONTRACT_ADDRESS`/`RESERVED_CONTRACT_ADDRESS`): [3](#0-2) 

The same omission exists in the deprecated (Cairo0) syscall handler path: [4](#0-3) 

`ContractAddress` itself only forbids values in `[0, BLOCK_HASH_TABLE_ADDRESS]` when validating *sender* addresses at the gateway (`validate_contract_address`), which is not invoked on deployment-computed addresses: [5](#0-4) [6](#0-5) 

Since salt, class hash, and constructor calldata are all attacker-supplied inputs to the `deploy` syscall (reachable from any unprivileged transaction's `__execute__`), an attacker only needs to grind a salt value such that `get_contract_address(salt, class_hash, calldata, deployer_address)` collides with `0x1`/`0x2`/`0x3` (a Pedersen-hash pre-image search, feasible off-chain). Blockifier would accept and commit the deployment; the OS, which re-executes the same block to produce the proof, would reject it via the `assert_not_zero` check, producing a different result (the OS's transaction would abort/revert) than the sequencer's blockifier-computed state.

### Impact Explanation
This is an honest-node/prover divergence bug: the sequencer's blockifier execution and the Starknet OS's re-execution of the identical block would disagree on whether the deployment transaction succeeds and what the resulting state (and therefore the state root and block hash) is. Because the OS's output is what ultimately gets committed/proven on L1, a mismatch here can make a proposed block unprovable (the OS execution would fail against the trace blockifier produced), or, if not caught before proving, corrupt the reserved special-address storage (`0x1` is the block-hash table used to enforce the `STORED_BLOCK_HASH_BUFFER` mechanism, and `0x2` is the address-aliasing table used for stateful compression). Corruption of either table can produce an incorrect block hash mapping or broken alias-based compression, both of which affect the correctness of the committed state root/block hash and can stall block finalization — a network unable to confirm new transactions until the divergence is resolved.

### Likelihood Explanation
Exploitation requires only a standard `deploy` syscall call from any account's `__execute__`, with attacker-chosen `class_hash`, `contract_address_salt`, and `constructor_calldata`/`deploy_from_zero`. Finding a salt that hashes (via Pedersen) to one of 3 target values (`0x1`, `0x2`, `0x3`) out of the full felt domain requires a large but not infeasible grinding effort (comparable in cost class to other known Starknet address-grinding techniques); it does not require special privileges, only computational effort by any unprivileged user submitting a transaction.

### Recommendation
Add the same reserved-address check that exists in the Cairo OS (`deploy_contract.cairo` lines 44-49) to the Rust `deploy` implementations in `crates/blockifier/src/execution/syscalls/syscall_base.rs::deploy` and `crates/blockifier/src/execution/deprecated_syscalls/hint_processor.rs::deploy`, rejecting (returning a syscall error) whenever the computed `deployed_contract_address` equals `0`, `BLOCK_HASH_TABLE_ADDRESS` (0x1), `ALIAS_CONTRACT_ADDRESS` (0x2), or `RESERVED_CONTRACT_ADDRESS` (0x3), matching the OS's behavior exactly so the two execution engines can never diverge.

### Proof of Concept
1. An attacker computes, off-chain, a `contract_address_salt` (and/or exploits `deploy_from_zero=true` with a known `class_hash`/`constructor_calldata`) such that `get_contract_address(salt, class_hash, constructor_calldata, deployer_address)` equals `0x1`, `0x2`, or `0x3` (brute-force search over salts).
2. The attacker submits an `invoke` transaction whose `__execute__` calls the `deploy` syscall with these parameters.
3. Blockifier's `SyscallHintProcessor::deploy` (`syscall_base.rs:380-426`) computes the same address and calls `execute_deployment`, succeeding and writing the new class hash into the reserved storage slot for that address, with no rejection.
4. When the block is later re-executed/proven by the Starknet OS via `execute_deploy`/`execute_deploy_syscall` (`syscall_impls.cairo` / `deprecated_execute_syscalls.cairo`), the OS's `deploy_contract` function hits the `assert_not_zero(...)` check on line 45-49 of `deploy_contract.cairo` and fails, producing a state/output divergent from what blockifier already committed.

    pub fn deploy(
        &mut self,
        class_hash: ClassHash,
        contract_address_salt: ContractAddressSalt,
        constructor_calldata: Calldata,
        deploy_from_zero: bool,
        remaining_gas: &mut u64,
    ) -> SyscallResult<(ContractAddress, CallInfo)> {
        self.increment_syscall_linear_factor_by(
            &SyscallSelector::Deploy,
            constructor_calldata.0.len(),
        );
        let versioned_constants = &self.context.tx_context.block_context.versioned_constants;
        if should_reject_deploy(
            versioned_constants.disable_deploy_in_validation_mode,
            self.context.execution_mode,
        ) {
            self.reject_syscall_in_validate_mode("deploy")?;
        }

        let deployer_address = self.call.storage_address;
        let deployer_address_for_calculation = match deploy_from_zero {
            true => ContractAddress::default(),
            false => deployer_address,
        };
        let deployed_contract_address = calculate_contract_address(
            contract_address_salt,
            class_hash,
            &constructor_calldata,
            deployer_address_for_calculation,
        )?;

        let ctor_context = ConstructorContext {
            class_hash,
            code_address: Some(deployed_contract_address),
            storage_address: deployed_contract_address,
            caller_address: deployer_address,
        };
        let call_info = execute_deployment(
            self.state,
            self.context,
            ctor_context,
            constructor_calldata,
            remaining_gas,
        )?;
        Ok((deployed_contract_address, call_info))
    }

    fn deploy(
        request: DeployRequest,
        _vm: &mut VirtualMachine,
        syscall_handler: &mut Self,
    ) -> DeprecatedSyscallResult<DeployResponse> {
        let versioned_constants =
            &syscall_handler.context.tx_context.block_context.versioned_constants;
        if should_reject_deploy(
            versioned_constants.disable_deploy_in_validation_mode,
            syscall_handler.execution_mode(),
        ) {
            return Err(DeprecatedSyscallExecutionError::InvalidSyscallInExecutionMode {
                syscall_name: "deploy".to_string(),
                execution_mode: syscall_handler.execution_mode(),
            });
        }

        let deployer_address = syscall_handler.storage_address;
        let deployer_address_for_calculation = match request.deploy_from_zero {
            true => ContractAddress::default(),
            false => deployer_address,
        };
        let deployed_contract_address = calculate_contract_address(
            request.contract_address_salt,
            request.class_hash,
            &request.constructor_calldata,
            deployer_address_for_calculation,
        )?;

        // Increment the Deploy syscall's linear cost counter by the number of elements in the
        // constructor calldata.
        let syscall_usage = syscall_handler
            .syscalls_usage
            .get_mut(&DeprecatedSyscallSelector::Deploy)
            .expect("syscalls_usage entry for Deploy must be initialized");
        syscall_usage.linear_factor += request.constructor_calldata.0.len();

        let ctor_context = ConstructorContext {
            class_hash: request.class_hash,
            code_address: Some(deployed_contract_address),
            storage_address: deployed_contract_address,
            caller_address: deployer_address,
        };
        let mut remaining_gas = syscall_handler.context.gas_costs().base.default_initial_gas_cost;
        let call_info = execute_deployment(
            syscall_handler.state,
            syscall_handler.context,
            ctor_context,
            request.constructor_calldata,
            &mut remaining_gas,
        )?;
        syscall_handler.inner_calls.push(call_info);

        Ok(DeployResponse { contract_address: deployed_contract_address })
    }

impl ContractAddress {
    /// Validates the contract address is in the valid range for external access.
    /// The lower bound is above the special saved addresses and the upper bound is congruent with
    /// the storage var address upper bound.
    pub fn validate(&self) -> Result<(), StarknetApiError> {
        let value = self.0.0;
        let l2_address_upper_bound = Felt::from(*L2_ADDRESS_UPPER_BOUND);
        if (value > BLOCK_HASH_TABLE_ADDRESS.0.0) && (value < l2_address_upper_bound) {
            return Ok(());
        }

        Err(StarknetApiError::OutOfRange { string: format!("[0x2, {l2_address_upper_bound})") })
    }
}
