### Title
Broken Access Control in GEIC PrivilegedWebContents MojoJS Bindings Enables Arbitrary-Origin Access to the Browser Mojo Surface - (File: chrome/browser/geic/geic_pwc_manager.cc)

### Summary
The GEIC PrivilegedWebContents manager grants MojoJS bindings to every primary main frame without verifying the committed origin against the capability allowlist, mirroring OpenEMR's `message_list.php` CSV export that executes sensitive queries with only a CSRF token and no role check. [1](#0-0) [2](#0-1) 

### Finding Description
In `GeicPwcManager::TabEntry::RenderFrameCreated` and `ReadyToCommitNavigation`, `EnableMojoJsBindings(/*features=*/nullptr)` is called for any `IsInPrimaryMainFrame()` frame, and the inline TODO explicitly notes that the committed origin is not checked against the capability allowlist. [1](#0-0)  The same missing authorization appears in `ChromeContentBrowserClient::ShouldAllowMojoJsBindingsForFrame`, which returns true for any outermost main frame inside a `PrivilegedWebContents`. [2](#0-1)  The PWC's policy delegate does define a capability allowlist from `dev_url_`, but it is never consulted before enabling MojoJS. [3](#0-2)  By contrast, the Glic guest observer enables MojoJS only after `IsOriginAllowedGlicApi(url::Origin::Create(navigation_handle->GetURL()))` succeeds. [4](#0-3)  Because the privileged process registers privileged binders such as `geic::mojom::GeicApi` and `pwc::mojom::PrivilegedBridge`, an arbitrary origin loaded in that process can attempt to bind them. [5](#0-4)  `BindGeicApi` does invoke `pwc::EnforceCapabilityGate` and a component check, but that gate is reached only after the renderer has already been given a Mojo context. [6](#0-5) 

### Impact Explanation
A remote page loaded into a GEIC PrivilegedWebContents—through navigation, redirect, or a same-process cross-origin frame—gains JavaScript access to the full Mojo interface surface, allowing it to request browser-side interfaces that are normally restricted to allowlisted privileged origins. [1](#0-0) [5](#0-4)  Successful binding of these interfaces can lead to cross-origin disclosure of browser state and can be chained to SOP bypass or universal XSS, analogous to OpenEMR's low-privileged user exporting the entire sensitive message list. [6](#0-5) [5](#0-4) 

### Likelihood Explanation
The vulnerability is reachable from a single malicious web page loaded in the PWC, because MojoJS is enabled before any origin verification and the privileged process exposes privileged Mojo binders. [1](#0-0) [5](#0-4)  The TODO comments identify this as a deliberate prototype shortcut (crbug.com/539909218), and the Glic implementation already demonstrates the correct origin-gated pattern. [4](#0-3) 

### Recommendation
Before calling `EnableMojoJsBindings`, verify the frame's committed origin against `PwcPolicyDelegate::IsCapabilityOrigin` (or the `FixedPwcPolicyDelegate` capability allowlist used at PWC creation), and only then enable MojoJS. [3](#0-2) [4](#0-3)  `ChromeContentBrowserClient::ShouldAllowMojoJsBindingsForFrame` should perform the same origin/capability check rather than returning true for every outermost PWC frame. [2](#0-1)  Privileged binders in `PopulateChromeFrameBinders` should also be registered only for frames whose origin is in the allowlist, and the crbug.com/539909218 shortcut should be removed once scoped capability binding is implemented. [5](#0-4) 

### Proof of Concept
An attacker hosts `https://evil.example.com/poc.html` and causes a GEIC PWC to navigate to it. Because `RenderFrameCreated` and `ReadyToCommitNavigation` call `EnableMojoJsBindings` without checking the origin, the page has `window.Mojo` available. [1](#0-0)  The page then runs:
```javascript
const pipe = Mojo.createMessagePipe();
Mojo.bindInterface('geic.mojom.GeicApi', pipe.handle0);
// or other privileged-process interfaces such as pwc.mojom.PrivilegedBridge
```
The privileged process's frame binder map includes `geic::mojom::GeicApi` and `pwc::mojom::PrivilegedBridge`, so the bind request reaches the browser. [5](#0-4)  Although `BindGeicApi` attempts a capability-gate check, the renderer has already obtained MojoJS and can probe other interfaces that may lack origin checks, leading to unauthorized access to browser-provided data. [6](#0-5)  The root cause is the unconditional `EnableMojoJsBindings` calls in `geic_pwc_manager.cc` and the matching unconditional `ShouldAllowMojoJsBindingsForFrame` path. [2](#0-1)

```text
bool ChromeContentBrowserClient::ShouldAllowMojoJsBindingsForFrame(
    content::RenderFrameHost& render_frame_host) {
  content::WebContents* web_contents =
      content::WebContents::FromRenderFrameHost(&render_frame_host);
  if (web_contents && glic::IsGlicGuest(web_contents) &&
      !render_frame_host.GetParentOrOuterDocument()) {
    return true;
  }
  // TODO(crbug.com/539909218): Prototype shortcut. Enabling MojoJS for any PWC
  // exposes the entire Mojo interface surface rather than only GeicApi, and the
  // committed origin is not checked against the capability allowlist here.
  // Gating on the outermost main frame is a stopgap while erikchen@ designs a
  // scoped capability binding mechanism in follow-ups. We check
  // `!render_frame_host.GetParentOrOuterDocument()` rather than
  // `IsInPrimaryMainFrame()` because this predicate is consulted from
  // `ReadyToCommitNavigation` before the frame commits, where
  // lifecycle-dependent queries return false.
  if (!render_frame_host.GetParentOrOuterDocument() && web_contents &&
      pwc::PrivilegedWebContents::FromWebContents(web_contents)) {
    return true;
  }
#if BUILDFLAG(ENABLE_EXTENSIONS_CORE)
  const GURL& site_url = render_frame_host.GetSiteInstance()
                             ->GetSecurityPrincipal()
                             .GetDeprecatedSiteURL();
  if (site_url.SchemeIs(extensions::kExtensionScheme)) {
    content::BrowserContext* browser_context =
        render_frame_host.GetBrowserContext();
    const extensions::Extension* extension =
        extensions::ExtensionRegistry::Get(browser_context)
            ->enabled_extensions()
            .GetByID(site_url.GetHost());
    if (!extension) {
      return false;
    }
    const auto* registry =
        extensions::ExtensionMojoBinderRegistryFactory::GetForBrowserContext(
            browser_context);
    return registry && registry->IsMojoJsEnabledForFrame(*extension);
  }
#endif
  return false;
}
```

```text
void GlicGuestObserver::MaybeEnableMojoJsBindings(
    content::NavigationHandle* navigation_handle) {
  if (!navigation_handle->IsInPrimaryMainFrame()) {
    return;
  }
  // Enable MojoJS bindings if the pending navigation is targeting an allowed
  // origin so Blink can initialize the Mojo context during document load.
  // The frame's committed origin is checked in `BindGlicWebClientHandler()`
  // when the page attempts to bind the pipe.
  if (IsOriginAllowedGlicApi(
          url::Origin::Create(navigation_handle->GetURL()))) {
    navigation_handle->GetRenderFrameHost()->EnableMojoJsBindings(
        /*features=*/nullptr);
  }
}
```

```text
void BindGeicApi(content::RenderFrameHost* render_frame_host,
                 mojo::PendingReceiver<mojom::GeicApi> receiver) {
  // The shared gate enforces the full capability policy (and terminates the
  // renderer itself on a renderer-controllable violation); null simply means
  // do not bind.
  pwc::PrivilegedWebContents* privileged =
      pwc::EnforceCapabilityGate(render_frame_host);
  if (!privileged) {
    return;
  }

  // The gate is component-agnostic; GeicApi additionally requires the
  // component to be GEIC. A request from another component's frame is again a
  // compromised renderer.
  if (privileged->component() != pwc::PrivilegedComponent::kGeic) {
    bad_message::ReceivedBadMessage(render_frame_host->GetProcess(),
                                    bad_message::PWC_BRIDGE_UNQUALIFIED_FRAME);
    return;
  }

  if (!GeicHost::Get(privileged->unowned_user_data_host())) {
    // The frame qualifies, but the GEIC component has not attached its GeicHost
    // to this PrivilegedWebContents. That is a browser-side setup gap, not a
    // compromised renderer, so drop the request rather than terminating the
    // renderer.
    return;
  }
  GeicApiBinding::Create(render_frame_host, std::move(receiver));
}
```
