### Title
Starknet OS `replace_class` syscall omits the "class must be declared" check enforced by the Blockifier, causing prover/sequencer state divergence - (File: `crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo`)

### Summary
The Union Finance report describes a class of bug where a state-mutating admin action (`removeAdapter`/`removeToken`) omits a required precondition check (verifying no funds are held) that a parallel/complementary code path implicitly relies on, causing permanent inconsistency between recorded and actual state. The sequencer analog is a validation-omission bug in the `replace_class` syscall handling: the Rust Blockifier enforces that the target class hash must be declared before the class-hash change is applied, but the Cairo Starknet OS re-execution implementation of the very same syscall performs no such check, leaving a `TODO` in place of the validation.

### Finding Description
When a contract invokes the `replace_class` syscall, the Blockifier's syscall handler explicitly reads/validates the target class before mutating the contract's class hash: [1](#0-0) 
This call to `state.get_compiled_class(request.class_hash)?` fails with `StateError::UndeclaredClassHash` if the class hash was never declared, causing the syscall (and typically the enclosing transaction) to error/revert.

The Starknet OS's Cairo implementation of the same syscall — used by the OS to independently re-execute block transactions and recompute the committed state root — does not perform this check. It directly overwrites the contract's `StateEntry.class_hash` with the caller-supplied, unvalidated `class_hash`: [2](#0-1) 
The comment at line 902 makes the gap explicit: `// TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.`

The same omission exists in the deprecated (Cairo0) syscall execution path: [3](#0-2) 

Because the Starknet OS is meant to independently re-derive the same execution results (and hence the same state diff/commitment) that the Blockifier produced when building/validating the block, any divergence in per-syscall validation logic between the two implementations is a correctness bug in the "Starknet OS re-execution" component, which is explicitly in scope.

### Impact Explanation
An unprivileged transaction sender can trigger `replace_class_syscall(undeclared_class_hash)` from any contract (e.g., via `test_replace_class` in test contracts, or any contract that exposes/calls this syscall). Two independent execution engines then produce two different outcomes for the same transaction:
- Blockifier (used at block-building time) rejects/reverts the transaction because the class hash is not declared, so the class-hash state change is not applied and is not part of the committed state diff for the block.
- The Starknet OS (used to re-execute the block and derive/verify the committed state commitment for proving) applies the class-hash change unconditionally, since it never checks declaration.

This produces a genuine divergence between the sequencer's committed state diff/root and the OS's independently recomputed state diff/root for the same block and transaction set. This falls squarely under "wrong committed root ... honest-node divergence" — the OS would either fail to reproduce the sequencer's claimed commitment (blocking proof generation / block finalization, i.e. the network becomes unable to confirm/prove new transactions), or, if the OS's diff were trusted, it could commit a state in which a contract's class hash points to a class that was never declared — an unrecoverable/incorrect state analogous to the "funds/state permanently inconsistent" impact in the original report.

### Likelihood Explanation
Likelihood is high: `replace_class` is a standard, unprivileged syscall reachable from any Cairo contract via `starknet::replace_class_syscall`, and there is no special permission required. Triggering the divergence merely requires calling it with a class hash that was never declared on-chain — trivial for any user/contract deployer to do intentionally, and it is explicitly marked as an unresolved `TODO` in the OS source, confirming the gap is a known-but-unfixed omission rather than a hypothetical.

### Recommendation
Add the equivalent declared-class validation to both Cairo OS implementations of `execute_replace_class` (`syscall_impls.cairo` and `deprecated_execute_syscalls.cairo`), mirroring the Blockifier's `get_compiled_class`/declaration check, before writing the new `StateEntry` with the updated `class_hash`. This keeps the OS's independent re-execution semantics consistent with the Blockifier so that both computed state diffs (and hence commitments) always agree for this syscall.

### Proof of Concept
1. Deploy an account and a contract exposing `test_replace_class(class_hash)` (e.g. `FeatureContract::TestContract`), as already used in the existing Blockifier test: [4](#0-3) 
2. Submit an invoke transaction that calls `test_replace_class` with a class hash that has never been declared.
3. Observe that the Blockifier rejects/reverts this call with `StateError::UndeclaredClassHash` (per the check at `hint_processor.rs:801`), so no class-hash state change enters the block's committed state diff.
4. Run the same transaction through the Starknet OS re-execution path (`execute_replace_class` in `syscall_impls.cairo`); because no declared-class check exists there, the OS applies the class-hash change unconditionally into `contract_state_changes`, producing a state diff/commitment that differs from the one the sequencer committed for the block — a concrete, reproducible root/commitment mismatch.

// Replaces the class.
func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
