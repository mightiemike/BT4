### Title
Same-block spot-price quoting lets an unprivileged trader manipulate gas-swap and gas-refund exchange rates, extracting value from inbound/outbound gas conversions - (File: x/uexecutor/keeper/evm.go, execute_inbound_gas.go, execute_inbound_gas_and_payload.go, outbound.go)

### Summary
The external report describes a manipulable exchange-ratio bug: an attacker skews a pool's ratio just before a victim's deposit is priced against it, causing the victim to receive fewer output tokens than they should (value theft via rounding on a manipulated ratio). Push Chain's `uexecutor` module has a structurally identical pattern in its gas-abstraction auto-swap flow: the "price" used to protect a deposit/refund swap is fetched from a live, manipulable Uniswap V3 pool in the same transaction the swap executes in, with no TWAP or external price check.

### Finding Description
`GetSwapQuote` (`x/uexecutor/keeper/evm.go:502-538`) calls `QuoterV2.quoteExactInputSingle` with `SqrtPriceLimitX96: big.NewInt(0)` — i.e., it reads whatever the pool's current spot price is at that instant: [1](#0-0) 

This quote is used, unmodified except for a flat 5% haircut, to compute `minPCOut`, which is then passed straight into the same-transaction swap call:
- `ExecuteInboundGas` (GAS inbound route): fetches quote, computes `minPCOut = quote*95/100`, and immediately calls `CallPRC20DepositAutoSwap` in the same keeper invocation. [2](#0-1) 
- `gasAndPayloadDepositAutoSwap` (GAS_AND_PAYLOAD inbound route): identical pattern. [3](#0-2) 
- `applyGasRefund` (outbound gas-fee refund route): same pattern — quote fetched via `getSwapQuoteForRefund`, `minPCOut` derived, immediately used in `CallUniversalCoreRefundUnusedGas`. [4](#0-3) 

Because the quote and the swap execution happen back-to-back inside one module-originated EVM call sequence within a single validator-submitted `MsgVoteInbound`/`MsgVoteOutbound` transaction, there is no separation in time or block height between "observe price" and "execute at that price." An unprivileged, external party who can see the pending finalizing vote transaction in the mempool (the transaction that will push the ballot over quorum and trigger execution) can submit ordinary swap transactions against the same public Uniswap V3 pool (deployed with deliberately thin initial liquidity per `e2e-tests/setup.sh`, e.g. `pool_token_amount=1` : `pool_wpc_amount=4`) to push the spot price down immediately before the module's deposit-swap executes, and then swap back afterward. Because `minPCOut` is derived from the very same (attacker-manipulated) spot price, the 5% slippage guard does not protect against this: the guard only bounds deviation from a price the attacker already controls, not deviation from a fair/reference price.

### Impact Explanation
This lets an unprivileged actor extract value from every gas-abstraction swap and every gas-fee refund swap processed by the protocol: the UEA/sender that should receive PC (or PRC20) proceeds from the auto-swap receives less value than the true market rate, while the attacker captures the difference via the surrounding swap/counter-swap (a classic sandwich). This directly corrupts gas fee accounting and refund accounting values (an in-scope impact) and constitutes value being drained from users/protocol-controlled swap flows without any privileged access — reachable purely through ordinary user deposits (GAS/GAS_AND_PAYLOAD inbound transactions) and ordinary public DEX trades.

### Likelihood Explanation
The attack requires no validator, node, or admin compromise — any address able to trade on the public swap pool and observe pending `MsgVoteInbound`/`MsgVoteOutbound` transactions (which are gasless and broadcast, per `app/txpolicy/gasless.go`) can execute it. Thin initial pool liquidity (documented in `e2e-tests/setup.sh` pool creation, e.g. 1:4 ratios) makes price impact from a modest trade large, increasing profitability of the sandwich, especially early after token listing.

### Recommendation
Do not derive `minPCOut` from a same-block spot quote pulled from a manipulable pool. Use a time-weighted average price (TWAP) from the Uniswap V3 pool (`observe`) over a sufficiently long window, or accept a caller/validator-specified minimum output bound derived from an external reference price with a fixed maximum-deviation check against the pool's TWAP, so that the slippage bound reflects a price the attacker cannot control within a single block.

### Proof of Concept
1. Attacker observes a pending `MsgVoteInbound` (or the vote that will reach quorum) for a `GAS` or `GAS_AND_PAYLOAD` inbound with token X.
2. Attacker submits a large swap of X→WPC on the public pool used by `GetSwapQuote`/`CallPRC20DepositAutoSwap`, depressing the X price.
3. The validator's finalizing vote executes; `ExecuteInboundGas` calls `GetSwapQuote` (now depressed) and computes `minPCOut` from it, then calls `CallPRC20DepositAutoSwap`, executing at the depressed price.
4. Attacker swaps back WPC→X, restoring the price and pocketing the spread that should have gone to the UEA recipient. [1](#0-0) [2](#0-1) [4](#0-3)

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,

		return nil, err
