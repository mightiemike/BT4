## Analysis Summary

I mapped the Zap `redeem()` bug class — *accepting a caller-influenced asset-selector parameter and acting on it without validating it against an allowed set* — onto Push Chain's registry/accounting path in `x/uexecutor`. Note: the on-chain `UniversalGatewayPC` Solidity contract itself lives outside this scoped repository (only its ABI/bytecode fixtures are present here, e.g. `test/utils/contracts_setup.go`), so I could not verify from this repo alone whether the deployed contract constrains `gasToken` to a registry-approved value before emitting it. What I *can* verify from the scoped Go code is a concrete, internally-inconsistent trust boundary: the module validates one asset field from the same event but not the other before performing privileged financial actions.

### Title
Unvalidated `GasToken` address from `UniversalTxOutbound` event drives Uniswap swap and PC mint in gas-refund accounting - (File: `x/uexecutor/keeper/outbound.go`)

### Summary
`BuildOutboundsFromReceipt` decodes the `UniversalTxOutbound` event and validates the bridged asset (`event.Token`) against the `uregistry` PRC20 allowlist via `GetTokenConfigByPRC20`, rejecting the outbound if it isn't a registered token. The sibling field `event.GasToken`, decoded from the exact same event by the same function, receives no equivalent registry check before being persisted as `OutboundTx.GasToken` and later consumed by `applyGasRefund`.

### Finding Description
`DecodeUniversalTxOutboundFromLog` decodes both `Token` and `GasToken` as raw `address` values from event data with no cross-check against `uregistry`. [1](#0-0) [2](#0-1) 

In `BuildOutboundsFromReceipt`, `event.Token` is checked against the token registry (`GetTokenConfigByPRC20`) and the call fails if unregistered, but `event.GasToken` is copied straight into `OutboundTx.GasToken` with no such lookup: [3](#0-2) 

That unvalidated `GasToken` is later trusted as a legitimate PRC20 in `applyGasRefund`, which is invoked on both the success and failure paths of outbound finalization (`FinalizeOutbound` → `handleSuccessfulOutbound` / `handleFailedOutbound`): [4](#0-3) [5](#0-4) 

`applyGasRefund` uses `outbound.GasToken` directly (no allowlist re-check) to fetch a Uniswap fee tier, obtain a swap quote, and finally call `UniversalCore.refundUnusedGas`, which either swaps the token for PC or deposits it directly to the refund recipient: [6](#0-5) [7](#0-6) 

This mirrors the Zap `redeem()` pattern exactly: one asset parameter (`Token`, analogous to Zap's implicit wBTC/renBTC constraint) is checked against the intended allowlist, while a second, functionally equivalent asset parameter used in the same financial action (`GasToken`) is not — the module trusts whatever address the event supplies and performs privileged swap/mint accounting against it.

### Impact Explanation
If the value that ends up in the `gasToken` slot of the `UniversalTxOutbound` event can be influenced by the calling payload (the inbound path executes an attacker-supplied `UniversalPayload` through the user's own UEA, which is what invokes the gateway contract producing this event — see `x/uexecutor/README.md` TxType semantics and the `FUNDS_AND_PAYLOAD`/`GAS_AND_PAYLOAD` flows), then a user could cause the module to run `GetDefaultFeeTierForToken`/`GetSwapQuoteForRefund`/`CallUniversalCoreRefundUnusedGas` against an arbitrary, non-registered ERC20/PRC20-shaped address instead of the chain's real registered gas token. Depending on how `UniversalCore.refundUnusedGas` and the Uniswap V3 quoter behave for an unregistered/malicious token address, this could misroute gas-fee accounting, attempt swaps against attacker-controlled contracts, or corrupt the `pc_refund_execution`/`refund_swap_error` bookkeeping recorded on-chain — falling under "corruption of ... gas fee accounting, refund accounting ... token mapping" in the allowed-impact gate.

### Likelihood Explanation
Medium-to-low confidence on exploitability, and this should be treated as a scoped-code weakness rather than a confirmed live exploit: the actual constraint (whether the deployed `UniversalGatewayPC.withdraw()`/`withdrawAndExecute()` derives `gasToken` strictly from `gasTokenPRC20ByChainNamespace(chainId)` rather than from caller-supplied calldata) is enforced, if at all, in the Solidity gateway contract, which is **not part of this repository's scope** — only its ABI is referenced here (`x/uexecutor/types/abi.go`) and a test-only stub contract exists in `test/utils/contracts_setup.go` that explicitly skips this validation ("DO NOT run validation") for test purposes only. I was unable to confirm from this repo whether the production contract enforces the mapping. What is certain and verifiable in-scope is that the Go module itself performs asymmetric trust: it defensively validates `Token` via the registry but not `GasToken`, which is a maintenance/defense-in-depth gap regardless of current contract-side guarantees.

### Recommendation
Before persisting `OutboundTx.GasToken` and before every use in `applyGasRefund`, validate `event.GasToken` against the `uregistry` module's known gas-token/PRC20 configuration for the relevant chain (mirroring the `GetTokenConfigByPRC20` check already applied to `event.Token`), and reject or fall back safely when it does not match a registered mapping.

### Proof of Concept
Not independently reproducible from this repository alone: constructing a concrete PoC requires confirming whether the production `UniversalGatewayPC` contract (external to this repo) allows the `gasToken` value emitted in `UniversalTxOutbound` to be influenced by attacker-controlled calldata/payload rather than being strictly derived from the chain's registered `gasTokenPRC20ByChainNamespace` mapping. If confirmed, the PoC path is: submit a `FUNDS_AND_PAYLOAD`/`GAS_AND_PAYLOAD` inbound whose payload calls the gateway's withdraw path with a crafted `gasToken` address → `BuildOutboundsFromReceipt` records it unchecked (`x/uexecutor/keeper/create_outbound.go:80`) → after UV quorum on `MsgVoteOutbound` with `gas_fee_used < gas_fee`, `applyGasRefund` executes swap/refund logic against the attacker-chosen address (`x/uexecutor/keeper/outbound.go:178-256`).

```go
func (k Keeper) FinalizeOutbound(ctx context.Context, utxId string, outbound types.OutboundTx) error {
	// If not observed yet, do nothing
	if outbound.OutboundStatus != types.Status_OBSERVED {
		return nil
	}

	obs := outbound.ObservedTx
	if obs == nil {
		return nil
	}

	sdkCtx := sdk.UnwrapSDKContext(ctx)

	k.Logger().Info("finalizing outbound",
		"utx_id", utxId,
		"outbound_id", outbound.Id,
		"success", obs.Success,
		"dest_chain", outbound.DestinationChain,
		"tx_type", outbound.TxType.String(),
	)

	if !obs.Success {
		return k.handleFailedOutbound(sdkCtx, utxId, outbound, obs)
	}

	return k.handleSuccessfulOutbound(sdkCtx, utxId, outbound, obs)
}
```

```go
func (k Keeper) applyGasRefund(ctx sdk.Context, outbound *types.OutboundTx, obs *types.OutboundObservation) {
	if obs.GasFeeUsed == "" || outbound.GasFee == "" || outbound.GasToken == "" {
		return
	}

	gasFee := new(big.Int)
	if _, ok := gasFee.SetString(outbound.GasFee, 10); !ok {
		return
	}

	gasFeeUsed := new(big.Int)
	if _, ok := gasFeeUsed.SetString(obs.GasFeeUsed, 10); !ok {
		return
	}

	// No excess gas to refund
	if gasFee.Cmp(gasFeeUsed) <= 0 {
		return
	}

	refundAmount := new(big.Int).Sub(gasFee, gasFeeUsed)
	gasToken := common.HexToAddress(outbound.GasToken)

	// Refund recipient: prefer fund_recipient in revert_instructions, fall back to sender
	refundRecipient := outbound.Sender
	if outbound.RevertInstructions != nil && outbound.RevertInstructions.FundRecipient != "" {
		refundRecipient = outbound.RevertInstructions.FundRecipient
	}
	recipientAddr := common.HexToAddress(refundRecipient)

	refundPcTx := &types.PCTx{
		Sender:      outbound.Sender,
		BlockHeight: uint64(ctx.BlockHeight()),
	}

	// Step 1: try refund with swap (gasToken → PC native)
	fee, swapErr := k.GetDefaultFeeTierForToken(ctx, gasToken)
	var swapFallbackReason string

	if swapErr == nil {
		quote, quoteErr := k.getSwapQuoteForRefund(ctx, gasToken, fee, refundAmount)
		if quoteErr == nil {
			minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
			minPCOut.Div(minPCOut, big.NewInt(100))

			resp, err := k.CallUniversalCoreRefundUnusedGas(ctx, gasToken, refundAmount, recipientAddr, true, fee, minPCOut)
			if err == nil {
				refundPcTx.TxHash = resp.Hash
				refundPcTx.GasUsed = resp.GasUsed
				refundPcTx.Status = "SUCCESS"
				outbound.PcRefundExecution = refundPcTx
				return
			}
			swapFallbackReason = fmt.Sprintf("swap refund failed: %s", err.Error())
		} else {
			swapFallbackReason = fmt.Sprintf("quote fetch failed: %s", quoteErr.Error())
		}
	} else {
		swapFallbackReason = fmt.Sprintf("fee tier fetch failed: %s", swapErr.Error())
	}

	// Step 2: fallback — refund without swap (deposit PRC20 directly to recipient)
	ctx.Logger().Error("applyGasRefund: swap refund failed, falling back to no-swap",
		"outbound_id", outbound.Id,
		"reason", swapFallbackReason,
	)

	resp, err := k.CallUniversalCoreRefundUnusedGas(ctx, gasToken, refundAmount, recipientAddr, false, big.NewInt(0), big.NewInt(0))
	if err != nil {
		refundPcTx.Status = "FAILED"
		refundPcTx.ErrorMsg = err.Error()
	} else {
		refundPcTx.TxHash = resp.Hash
		refundPcTx.GasUsed = resp.GasUsed
		refundPcTx.Status = "SUCCESS"
	}

	outbound.PcRefundExecution = refundPcTx
	outbound.RefundSwapError = swapFallbackReason
```

```go
// CallUniversalCoreRefundUnusedGas calls refundUnusedGas on UniversalCore to return excess gas fee
// to the recipient. withSwap=true swaps the gas token back to PC; withSwap=false deposits PRC20 directly.
func (k Keeper) CallUniversalCoreRefundUnusedGas(
	ctx sdk.Context,
	gasToken common.Address,
	amount *big.Int,
	recipient common.Address,
	withSwap bool,
	fee *big.Int,
	minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse UniversalCore ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	// fee is uint24 in Solidity — pass as *big.Int (go-ethereum ABI packs non-standard widths as *big.Int)
	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress,
		handlerAddr,
		big.NewInt(0),
		nil,
		true,
		false,
		true,
		&nonce,
		"refundUnusedGas",
		gasToken,
		amount,
		recipient,
		withSwap,
		fee,
		minPCOut,
	)
}
```
