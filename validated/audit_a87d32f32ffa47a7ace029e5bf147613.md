### Title
Unbounded busy-loop in `processSigned` allows unprivileged deposits to stall the SVM/EVM outbound broadcaster indefinitely - (File: `universalClient/tss/txbroadcaster/broadcaster.go`, `universalClient/tss/txbroadcaster/svm.go`)

### Summary
`Broadcaster.processSigned` fetches up to `processSignedBatchSize` (100) `SIGNED` events and loops, re-fetching another batch, until the fetched batch is smaller than 100 or empty [1](#0-0) . `GetSignedSignEvents` deterministically returns the same top-N `SIGNED` rows (ordered by `block_height ASC, created_at ASC`) each call, with no exclusion of rows already attempted in the current invocation [2](#0-1) . If an attacker can sustain ≥100 events whose SVM broadcasts permanently fail while remaining inside their signing deadline, `broadcastOutboundSVM` leaves the event in `SIGNED` on every attempt [3](#0-2) , so the batch count never drops below 100 and the outer `for` loop in `processSigned` never exits — with no context-cancellation check inside that loop.

### Finding Description
Each iteration of the stuck loop reprocesses the same ~100 events, and for SVM each event costs at least: one `BroadcastOutboundSigningRequest` RPC (which internally calls `rpcClient.BroadcastTransaction`) and, on failure, one `IsAlreadyExecuted` RPC race-check [4](#0-3) . Events whose serialized instruction data exceeds `maxDirectTxSize` are additionally routed through `broadcastRefRoute`, adding a `storedPDAExists` (`GetAccountData`) RPC call plus a separate `BroadcastTransaction` call for the store/finalize step [5](#0-4) , further increasing the per-event, per-iteration RPC cost. Because the `run` loop invokes `processSigned` synchronously inside its `select` on the ticker [6](#0-5) , a stuck invocation also blocks all future ticks — halting broadcast processing for both SVM and EVM sign events on that node until the process is killed or the events eventually cross their signing deadline and get force-flipped to `BROADCASTED` [7](#0-6) .

An unprivileged actor can reach this by submitting ordinary deposits whose resulting SVM outbound instructions are large enough to trigger the ref-route path and are crafted to deterministically fail simulation/broadcast (e.g., malformed destination token accounts), while each such event still has a signing deadline far enough in the future to remain retried rather than force-completed.

### Impact Explanation
This is a non-network-level, node-local denial of service reachable purely through unprivileged deposit crafting: no malicious validator, TSS participant, or admin is required. The impact is bounded to liveness of the outbound broadcaster subsystem (continuous unbounded RPC hammering and stalled tick processing), not fund loss or state corruption, since `broadcastOutboundSVM`/`broadcastRefRoute` never mutate on-chain funds on failure — they only retry or eventually mark the event for the resolver's revert path.

### Likelihood Explanation
Feasible but non-trivial: the attacker needs ≥100 SIGNED events simultaneously alive, all deterministically failing broadcast, requiring them to get many honestly-signed (TSS-quorum) outbound events whose destination/target is crafted to always fail on Solana while staying inside their deadline window. This requires volume and careful crafting but no privileged access.

### Recommendation
Add a `ctx.Done()` check inside the `processSigned` for-loop to allow cancellation, and track per-event failure counts/backoff so permanently-failing events are excluded from repeated immediate re-fetch within the same tick (e.g., skip events already attempted in the current invocation, or cap total iterations/RPC calls per tick).

### Proof of Concept
Seed ≥100 `SIGNED` SVM events, each: (a) built to exceed `maxDirectTxSize` so `BroadcastOutboundSigningRequest` routes to `broadcastRefRoute` [8](#0-7) , and (b) mocked so both the store/finalize broadcasts and `IsAlreadyExecuted` deterministically return errors/false. Invoke `Broadcaster.processSigned(ctx)` with a bounded test timeout and assert: the call does not return within the timeout, while the mocked RPC call counter grows unbounded (exceeding a fixed multiple of the batch size) because `GetSignedSignEvents` keeps returning the same top-100 `SIGNED` rows every outer-loop iteration.

const processSignedBatchSize = 100

// processSigned drains all SIGNED events in batches.
func (b *Broadcaster) processSigned(ctx context.Context) {
	if b.chains == nil {
		return
	}
	for {
		events, err := b.eventStore.GetSignedSignEvents(processSignedBatchSize)
		if err != nil {
			b.logger.Warn().Err(err).Msg("failed to get signed events")
			return
		}
		if len(events) == 0 {
			return
		}
		for i := range events {
			b.broadcastEvent(ctx, &events[i])
		}
		if len(events) < processSignedBatchSize {
			return
		}
	}
}

// GetSignedSignEvents returns SIGN events with status SIGNED (ready to be broadcast).
func (s *Store) GetSignedSignEvents(limit int) ([]store.Event, error) {
	if limit <= 0 {
		limit = 50
	}
	var events []store.Event
	if err := s.db.Where("type IN (?, ?) AND status = ?", store.EventTypeSignOutbound, store.EventTypeSignFundMigrate, store.StatusSigned).
		Order("block_height ASC, created_at ASC").
		Limit(limit).
		Find(&events).Error; err != nil {
		return nil, fmt.Errorf("failed to query signed sign events: %w", err)
	}
	return events, nil
}

func (tb *TxBuilder) broadcastRefRoute(
	ctx context.Context,
	req *common.UnsignedSigningReq,
	data *uetypes.OutboundCreatedEvent,
	signature []byte,
) (string, error) {
	storeTx, refTx, storedPDA, err := tb.BuildRefRouteTransactions(ctx, req, data, signature)
	if err != nil {
		return "", fmt.Errorf("failed to build ref-route transactions: %w", err)
	}

	if tb.storedPDAExists(ctx, storedPDA) {
		refHash, err := tb.rpcClient.BroadcastTransaction(ctx, refTx)
		if err != nil {
			return "", fmt.Errorf("failed to broadcast finalize_universal_tx_with_ix_data_ref: %w", err)
		}
		tb.logger.Info().
			Str("tx_hash", refHash).
			Str("stored_pda", storedPDA.String()).
			Msg("ref-finalize broadcast successfully")
		return refHash, nil
	}

	storeHash, broadcastErr := tb.rpcClient.BroadcastTransaction(ctx, storeTx)
	if broadcastErr != nil {
		return "", fmt.Errorf("failed to broadcast store_execute_ix_data: %w", broadcastErr)
	}
	tb.logger.Info().
		Str("store_tx_hash", storeHash).
		Str("stored_pda", storedPDA.String()).
		Msg("store_execute_ix_data broadcast; finalize deferred to next tick")
	return "", fmt.Errorf("store_execute_ix_data broadcast; finalize will be attempted on next broadcaster tick")
}
