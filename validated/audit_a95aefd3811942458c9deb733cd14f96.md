### Title
Unbounded iteration over all registered witnesses in `MaintenanceManager.doMaintenance()` enables a low-cost DoS of the maintenance-cycle reward/vote-count logic - (File: `consensus/src/main/java/org/tron/consensus/dpos/MaintenanceManager.java`)

### Summary
`MaintenanceManager.doMaintenance()` is the java-tron analog of the reported `updatePeriod()`/`distributeAll()` bug: instead of a bounded, targeted operation (e.g. only active/standby witnesses), it repeatedly calls `consensusDelegate.getAllWitnesses()` and iterates over the **entire** witness set stored in `WitnessStore` several times per maintenance cycle, performing a DB read/write for every entry. Because any account can permissionlessly create a new witness via `WitnessCreateActuator` for a fixed fee with no cap on the total number of witnesses, an attacker can grow this set arbitrarily, making the mandatory, synchronous per-cycle maintenance step arbitrarily expensive for every full node.

### Finding Description
`doMaintenance()` performs three unbounded, full-table iterations over `WitnessStore` in every maintenance cycle: [1](#0-0) [2](#0-1) [3](#0-2) 

Each of these calls `consensusDelegate.getAllWitnesses()`, which in turn calls `WitnessStore.getAllWitnesses()` and materializes **every** witness ever created: [4](#0-3) [5](#0-4) 

Unlike the `getWitnessStandby()`/active-witness paths, this set is **not bounded** to the 127-witness standby list or the top active witnesses - it is the full set of all witnesses that have ever registered. Witness registration is permissionless and only gated by a fixed TRX cost (`getAccountUpgradeCost()`, default configurable), with no limit on the total number of witnesses that can exist: [6](#0-5) [7](#0-6) 

`doMaintenance()` is not an optional, user-invoked call - it is executed synchronously by every full node as part of ordinary block processing whenever the maintenance time boundary is crossed: [8](#0-7) [9](#0-8) 

This mirrors the reported bug class exactly: a periodic, protocol-critical distribution/accounting routine that loops over an attacker-growable, unbounded collection (gauges ↔ witnesses) instead of a fixed/bounded set (Satin/$CASH LP gauge ↔ active/standby witnesses).

### Impact Explanation
As the number of registered witnesses grows, the cost (DB reads/writes, CPU) of `doMaintenance()` grows linearly and is paid by **every** node on every maintenance cycle (default interval is configurable, typically hours), not just the block producer. Because this logic runs inline inside `processBlock()`/`applyBlock()`, a sufficiently large witness set can materially slow down or stall block processing at the maintenance boundary across the whole network, degrading liveness/consensus timing for all nodes simultaneously - a protocol-wide DoS vector rather than a single-transaction revert, but with the same root cause (unbounded loop in mandatory periodic accounting).

### Likelihood Explanation
Exploitation only requires broadcasting enough `WitnessCreateContract` transactions from funded accounts (cost = `getAccountUpgradeCost()` TRX per witness, refundable/no burn benefit to attacker but a sunk cost); there is no cap preventing an attacker with sufficient capital (or via many low-cost accounts if the cost is low on some networks/testnets) from inflating the witness table indefinitely. This is reachable by any unprivileged, anonymous account via ordinary broadcast transactions, matching the required reachability bar.

### Recommendation
Bound the iterations in `doMaintenance()` to the relevant subset of witnesses (e.g., active + standby witnesses, as already computed via `getWitnessStandby()`) instead of `getAllWitnesses()`, or paginate/cap the per-cycle processing so that costs remain bounded independent of the total historical witness count. Consider also capping the maximum number of registerable witnesses or scaling `AccountUpgradeCost` to disincentivize unbounded growth of the witness table.

### Proof of Concept
1. Fund N accounts and broadcast N `WitnessCreateContract` transactions, each paying `getAccountUpgradeCost()`, to register N witnesses (no upper bound enforced by `WitnessCreateActuator.validate()`). [10](#0-9) 
2. Wait for a maintenance-time boundary block; `MaintenanceManager.doMaintenance()` will call `consensusDelegate.getAllWitnesses()` three times and iterate over all N witnesses performing DB writes for each, on every full node. [11](#0-10) 
3. As N grows (bounded only by attacker capital, not protocol logic), the per-cycle cost of this mandatory step grows proportionally for every node in the network.

  public void doMaintenance() {
    VotesStore votesStore = consensusDelegate.getVotesStore();

    tryRemoveThePowerOfTheGr();

    DynamicPropertiesStore dynamicPropertiesStore = consensusDelegate.getDynamicPropertiesStore();
    DelegationStore delegationStore = consensusDelegate.getDelegationStore();
    if (dynamicPropertiesStore.useNewRewardAlgorithm()) {
      long curCycle = dynamicPropertiesStore.getCurrentCycleNumber();
      consensusDelegate.getAllWitnesses().forEach(witness -> {
        delegationStore.accumulateWitnessVi(curCycle, witness.createDbKey(), witness.getVoteCount());
      });
    }

    Map<ByteString, Long> countWitness = countVote(votesStore);
    if (!countWitness.isEmpty()) {
      List<ByteString> currentWits = consensusDelegate.getActiveWitnesses();

      List<ByteString> newWitnessAddressList = new ArrayList<>();
      consensusDelegate.getAllWitnesses()
          .forEach(witnessCapsule -> newWitnessAddressList.add(witnessCapsule.getAddress()));

      countWitness.forEach((address, voteCount) -> {
        byte[] witnessAddress = address.toByteArray();
        WitnessCapsule witnessCapsule = consensusDelegate.getWitness(witnessAddress);
        if (witnessCapsule == null) {
          logger.warn("Witness capsule is null. address is {}", Hex.toHexString(witnessAddress));
          return;
        }
        AccountCapsule account = consensusDelegate.getAccount(witnessAddress);
        if (account == null) {
          logger.warn("Witness account is null. address is {}", Hex.toHexString(witnessAddress));
          return;
        }
        witnessCapsule.setVoteCount(witnessCapsule.getVoteCount() + voteCount);
        consensusDelegate.saveWitness(witnessCapsule);
        logger.info("address is {} , countVote is {}", witnessCapsule.createReadableString(),
            witnessCapsule.getVoteCount());
      });

      dposService.updateWitness(newWitnessAddressList);

      incentiveManager.reward(newWitnessAddressList);

      List<ByteString> newWits = consensusDelegate.getActiveWitnesses();
      if (!CollectionUtils.isEqualCollection(currentWits, newWits)) {
        currentWits.forEach(address -> {
          WitnessCapsule witnessCapsule = consensusDelegate.getWitness(address.toByteArray());
          witnessCapsule.setIsJobs(false);
          consensusDelegate.saveWitness(witnessCapsule);
        });
        newWits.forEach(address -> {
          WitnessCapsule witnessCapsule = consensusDelegate.getWitness(address.toByteArray());
          witnessCapsule.setIsJobs(true);
          consensusDelegate.saveWitness(witnessCapsule);
        });

        SRMetrics.recordSrSetChange(currentWits, newWits);
      }

      logger.info("Update witness success. \nbefore: {} \nafter: {}",
          getAddressStringList(currentWits),
          getAddressStringList(newWits));
    }

    if (dynamicPropertiesStore.allowChangeDelegation()) {
      long nextCycle = dynamicPropertiesStore.getCurrentCycleNumber() + 1;
      dynamicPropertiesStore.saveCurrentCycleNumber(nextCycle);
      consensusDelegate.getAllWitnesses().forEach(witness -> {
        delegationStore.setBrokerage(nextCycle, witness.createDbKey(),
            delegationStore.getBrokerage(witness.createDbKey()));
        delegationStore.setWitnessVote(nextCycle, witness.createDbKey(), witness.getVoteCount());
      });
    }
  }

  private void createWitness(final WitnessCreateContract witnessCreateContract)
      throws BalanceInsufficientException {
    AccountStore accountStore = chainBaseManager.getAccountStore();
    DynamicPropertiesStore dynamicStore = chainBaseManager.getDynamicPropertiesStore();
    WitnessStore witnessStore = chainBaseManager.getWitnessStore();
    //Create Witness by witnessCreateContract
    final WitnessCapsule witnessCapsule = new WitnessCapsule(
        witnessCreateContract.getOwnerAddress(),
        0,
        witnessCreateContract.getUrl().toStringUtf8());

    logger.debug("createWitness,address[{}]", witnessCapsule.createReadableString());
    witnessStore.put(witnessCapsule.createDbKey(), witnessCapsule);
    AccountCapsule accountCapsule = accountStore
        .get(witnessCapsule.createDbKey());
    accountCapsule.setIsWitness(true);
    if (dynamicStore.getAllowMultiSign() == 1) {
      accountCapsule.setDefaultWitnessPermission(dynamicStore);
    }
    accountStore.put(accountCapsule.createDbKey(), accountCapsule);
    long cost = dynamicStore.getAccountUpgradeCost();
    adjustBalance(accountStore, witnessCreateContract.getOwnerAddress().toByteArray(), -cost);
    if (dynamicStore.supportBlackHoleOptimization()) {
      dynamicStore.burnTrx(cost);
    } else {
      adjustBalance(accountStore, accountStore.getBlackhole(), +cost);
    }
    dynamicStore.addTotalCreateWitnessCost(cost);
  }
