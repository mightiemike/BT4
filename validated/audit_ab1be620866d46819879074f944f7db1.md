### Title
Starknet OS `replace_class` syscall omits declared-class and Cairo version validation performed by Blockifier, causing state-root divergence — (File: crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo)

### Summary
The Starknet OS's Cairo implementations of the `replace_class` syscall (both the current and deprecated/Cairo0 execution paths) unconditionally update a contract's class hash in `contract_state_changes` without verifying that the target class hash corresponds to an actually declared class, and without verifying the class is a Cairo1 (V1) class. Blockifier — the reference execution engine used to build blocks — enforces both checks and reverts the call when they fail. This mismatch is a classic "improper input validation" bug class (CWE-20, matching the Struts advisory's root cause of insufficiently constrained input reaching a dispatch/state-mutation path), reachable from a single unprivileged invoke transaction that calls `replace_class_syscall`.

### Finding Description
Blockifier's `SyscallHandlerBase::replace_class` explicitly validates the target class before mutating state: [1](#0-0) 

This is invoked from both the native and deprecated syscall handlers: [2](#0-1) [3](#0-2) 

If the class hash is not declared, `state.get_compiled_class` returns an error and the syscall/call is treated as reverted (state change discarded, transaction still included but marked reverted). If the class is declared but is a Cairo0 (V0) class, Blockifier explicitly rejects the replacement with `ForbiddenClassReplacement`.

In contrast, the Starknet OS's Cairo implementation of the same syscall (used for the STARK-provable re-execution that ultimately produces the committed state root and block hash) performs neither check. It directly updates the contract's class hash in the state dictionary: [4](#0-3) 

The `TODO(Yoni, 1/1/2026)` comment at line 902 explicitly acknowledges the missing declared-class check. The same omission exists in the deprecated (Cairo0) syscall execution path: [5](#0-4) 

Neither Cairo function reads or asserts against `compiled_class_facts_bundle` before writing the new `class_hash`, nor does either check the class's Cairo version, unlike Blockifier's `is_cairo1` guard.

### Impact Explanation
Because the OS is the component whose execution trace determines the final committed contract state (and hence the state commitment/global state root and block hash for validity proofs), a divergence between what Blockifier computes (the source of truth for the sequencer's block) and what the OS computes for the same transaction is a correctness-critical bug: honest-node divergence and wrong committed state root. If Blockifier ever reverts/fails a `replace_class` call for an undeclared or wrong-version class hash (which is a normal, permitted outcome — Blockifier does not reject the surrounding transaction, only marks the call as reverted, so the transaction still gets included in the block), while the OS unconditionally applies the class-hash mutation for the same call, the two systems will compute different final contract states for the same block, causing the OS-computed commitment/proof to disagree with the actual block state produced by the sequencer.

### Likelihood Explanation
This is trivially reachable by any account contract executing `replace_class_syscall(class_hash)` with an undeclared felt value or with a Cairo0 class hash, from a single ordinary invoke transaction — no privileged operator, prover, or network role is required. The bug is deterministic and always exercised whenever this syscall path is hit with such input, since the OS logic contains no gating condition at all (not even a partial/faulty check) — it is a straightforward missing-validation defect, explicitly flagged by an outstanding TODO in the code.

### Recommendation
Add the missing validation in both `execute_replace_class` (native path in `syscall_impls.cairo`) and the deprecated Cairo0 `execute_replace_class` (in `deprecated_execute_syscalls.cairo`):
1. Assert that `class_hash` exists in `compiled_class_facts_bundle` (i.e., is declared), mirroring Blockifier's `state.get_compiled_class(class_hash)?` check.
2. Assert that the declared class is a Cairo1 (V1) class, mirroring Blockifier's `is_cairo1` / `ForbiddenClassReplacement` check.
3. On failure, follow the same revert semantics Blockifier uses (mark the call reverted / propagate failure through the OS's revert-log mechanism) rather than unconditionally committing the state mutation, so that OS-computed state transitions stay bit-for-bit consistent with Blockifier for all reachable inputs.

### Proof of Concept
1. Submit an invoke transaction from any deployed account/contract that calls a function invoking `replace_class_syscall(undeclared_class_hash)` (a felt value with no corresponding declared class), as exercised by the test helper contract function: [6](#0-5) 
2. Under Blockifier, this call reverts (see `undeclared_class_hash` test asserting `"is not declared"`): [7](#0-6) 
3. The block, as built by the sequencer using Blockifier, records the call as reverted and the contract's class hash unchanged.
4. When the same block/transaction trace is re-executed by the Starknet OS for proof generation, `execute_replace_class` in `syscall_impls.cairo` performs no declared-class check and unconditionally writes `new_state_entry` with the undeclared `class_hash` into `contract_state_changes`, producing a different final class hash for the contract than what Blockifier computed — a state-root divergence for the same transaction/block.

    pub fn replace_class(&mut self, class_hash: ClassHash) -> SyscallResult<()> {
        // Ensure the class is declared (by reading it), and of type V1.
        let compiled_class = self.state.get_compiled_class(class_hash)?;

        if !is_cairo1(&compiled_class) {
            return Err(SyscallExecutionError::ForbiddenClassReplacement { class_hash });
        }
        self.state.set_class_hash_at(self.call.storage_address, class_hash)?;
        Ok(())
    }

func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
