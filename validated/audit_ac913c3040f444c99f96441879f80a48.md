**Analysis:** `stringifyQueryForAdmin` (packages/apps/shopify-api/lib/utils/hmac-validator.ts:51-58) is not a validator — it's a query-string serialization helper that always returns a `string`, used only to build the local HMAC input. It has no boolean return path and is never used for a pass/fail decision, so there is no "truthy-coercion" surface here. [1](#0-0) 

The actual gating logic lives in `validateHmac` and `validateHmacString`, both of which return the result of `safeCompare` directly, and `safeCompare` always returns a strict boolean (`true`/`false`) via `timingSafeEqual`'s `out === 0` or the early `return false` — never a non-boolean. [2](#0-1) [3](#0-2) 

Regarding hex-case vs lower-case signature values: `safeCompare` does a byte-for-byte comparison of the JSON-stringified values via `timingSafeEqual`, so an attacker submitting a hex-cased signature that differs in case from the locally computed lowercase hex HMAC would simply fail the comparison (mismatched bytes), not bypass it — there is no case-normalization step that would make a mismatched-case forgery succeed. Since `validateHmacFromRequestFactory` also strictly checks `if (!validHmac)` against the boolean result, there's no coercion bug to exploit. [4](#0-3)

```typescript
function stringifyQueryForAdmin(query: AuthQuery): string {
  const processedQuery = new ProcessedQuery();
  Object.keys(query)
    .sort((val1, val2) => val1.localeCompare(val2))
    .forEach((key: string) => processedQuery.put(key, query[key]));

  return processedQuery.stringify(true);
}
```

```typescript
export const safeCompare: SafeCompare = (strA, strB) => {
  if (typeof strA === typeof strB) {
    const enc = new TextEncoder();
    const buffA = enc.encode(JSON.stringify(strA));
    const buffB = enc.encode(JSON.stringify(strB));

    if (buffA.length === buffB.length) {
      return timingSafeEqual(buffA, buffB);
    }
  } else {
    throw new ShopifyErrors.SafeCompareError(
      `Mismatched data types provided: ${typeof strA} and ${typeof strB}`,
    );
  }
  return false;
};
```
