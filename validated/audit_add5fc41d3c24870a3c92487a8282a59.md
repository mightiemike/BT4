### Title
Starknet OS `execute_replace_class` skips the "class must be declared" check enforced by blockifier, causing OS/blockifier state divergence - ([File: crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo])

### Summary
The `replace_class` syscall is reachable by any contract executing an ordinary transaction: it lets the calling contract point its own storage entry to a new class hash. In the Rust `blockifier` execution engine this write is gated by a validity check that the target `class_hash` corresponds to an actually-declared class, and rejects the syscall with an `"is not declared"` error otherwise. The Starknet OS (Cairo) re-implementation of the same syscall, `execute_replace_class`, omits this check entirely — the code contains an explicit `TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.` and unconditionally writes the attacker-supplied `class_hash` into `contract_state_changes`.

### Finding Description
`replace_class` is implemented twice:

- In `blockifier` (the sequencer's actual execution engine), the syscall handler validates the class hash before permitting the write, as proven by the test `undeclared_class_hash` which asserts execution fails with `"is not declared"` when an arbitrary/undeclared class hash is supplied: [1](#0-0) 

- In the Starknet OS Cairo implementation, `execute_replace_class` performs no such validation. It reads the request's `class_hash`, immediately notes via a TODO comment that the declared-class check is missing, and then unconditionally updates the contract's `StateEntry.class_hash` and appends a revert-log entry: [2](#0-1) 

This is directly analogous to the FreeIPA bug class described: a privileged state-mutating operation (rewriting a contract's identity — its class hash, analogous to trust/identity data in the AD trust example) is gated by a weaker check in one code path (the OS) than the authoritative check enforced elsewhere (blockifier), letting an unprivileged caller (any account/contract issuing a normal transaction) trigger the privileged mutation through the weaker path.

### Impact Explanation
The Starknet OS is the component that re-executes a block's transactions in Cairo to produce the state-transition proof (and is also exercised directly for reexecution/validation, per `starknet_os_flow_tests`). Because `execute_replace_class` accepts any `class_hash`, including ones with no declared class or CASM, an attacker-controlled contract can invoke `replace_class` with a bogus class hash. If the OS is used to independently execute or verify the block (rather than merely re-checking blockifier's already-computed diff), this divergence means:
- The OS-computed state diff for that contract (`address_to_class_hash` set to an undeclared class) can differ from what blockifier would have produced (a reverted/failed call), producing wrong committed state/class-hash data and honest-node divergence between blockifier-driven full nodes and OS-based re-execution/proving paths.
- A contract's class hash could end up pointing at a class with no compiled CASM, which downstream code paths (that assume class hash validity established at replace-class time) may not handle safely.

This matches the FreeIPA analogy precisely: the "read-only"/weak-gated path (OS, missing the declared-class assertion) permits a privileged identity/state mutation that the authoritative, properly-gated path (blockifier) would reject.

### Likelihood Explanation
`replace_class` is a standard permissionless syscall available to any Cairo1 contract in a normal transaction — no special privilege, staking, or operator role is required. The only precondition is calling the syscall with an arbitrary (undeclared) `class_hash`, which is trivial for any transaction sender or contract deployer to construct. The missing check is unconditional (not behind a feature flag), so any code path that relies on the Starknet OS Cairo execution semantics is affected whenever this syscall is exercised.

### Recommendation
Add the same "class hash must be declared" validation in `execute_replace_class` in `crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo` that `blockifier` already performs, i.e., assert that `contract_class_changes` (or the equivalent declared-classes structure available to the OS) contains a non-zero compiled entry for `request.class_hash` before writing the new `StateEntry`, mirroring the check validated by `crates/blockifier/src/execution/syscalls/syscall_tests/replace_class.rs::undeclared_class_hash`. Resolve the referenced TODO before this OS code path is relied upon for consensus-relevant execution or proving.

### Proof of Concept
1. Deploy any Cairo1 contract exposing a function that calls the `replace_class` syscall with a caller-supplied `class_hash` parameter (as the `TestContract`'s `test_replace_class` entry point already does, per `crates/blockifier/src/execution/syscalls/syscall_tests/replace_class.rs`).
2. Invoke that function with an arbitrary, never-declared `class_hash` (e.g. `felt!(1234_u16)`).
3. In `blockifier`, execution fails with `"is not declared"` (as shown in `undeclared_class_hash` test) — the syscall is rejected.
4. Feed the same transaction/calldata through the Starknet OS's `execute_replace_class` (`crates/apollo_starknet_os_program/.../syscall_impls.cairo:882-921`): no equivalent assertion exists, so the OS accepts the write and updates `contract_state_changes` with the undeclared class hash — producing a state transition that blockifier would never allow, demonstrating the divergence.

// Replaces the class.
func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
