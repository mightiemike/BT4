### Title
Slippage bound derived from a manipulable same-block AMM spot quote enables sandwich extraction on GAS/GAS_AND_PAYLOAD autoswap deposits - (File: `x/uexecutor/keeper/evm.go`, `x/uexecutor/keeper/execute_inbound_gas.go`, `x/uexecutor/keeper/execute_inbound_gas_and_payload.go`)

### Summary
The GAS and GAS_AND_PAYLOAD inbound execution paths derive the minimum acceptable output (`minPCOut`) for the mandatory PRC20→WPC autoswap directly from `GetSwapQuote`, which reads Uniswap V3 QuoterV2's live pool state at the time of execution. Because the quote and the swap execution both occur atomically inside the same validator-triggered `MsgVoteInbound` transaction, and because Push Chain's PRC20/WPC pool is an ordinary on-chain AMM pool that any unprivileged address can trade against in a prior block or earlier in the same block, an attacker can move the pool price beforehand, causing `minPCOut` to be computed from the already-skewed spot price. The swap then executes at that skewed price and the attacker reverses the trade afterward, extracting the difference — a classic sandwich attack against protocol-owned gas-abstraction funds. This is the same underlying invariant break as the external report (deriving a "safe" price bound from live, attacker-influenceable on-chain AMM state instead of a resistant reference price), just instantiated via a Uniswap V3 spot quote instead of `balanceOf`.

### Finding Description
`ExecuteInboundGas` and `gasAndPayloadDepositAutoSwap` compute the slippage floor as:
```go
quote, execErr = k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
minPCOut.Div(minPCOut, big.NewInt(100))
receipt, execErr = k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
``` [4](#0-3) 

`GetSwapQuote` calls `QuoterV2.quoteExactInputSingle`, which computes `amountOut` from the pool's current `sqrtPriceX96` — i.e., the pool's instantaneous, freely tradeable spot price: [1](#0-0) 

There is no TWAP, external oracle, or independently-sourced reference price used to bound the slippage; the "safety" bound and the trade are both derived from the same manipulable state, with only a nominal 5% margin. Any unprivileged actor can:
1. Swap a large amount of WPC into (or PRC20 out of) the pool in a preceding block/transaction to skew the spot price against gas-inbound depositors.
2. Wait for (or trigger, since inbound votes are processed as ordinary transactions once quorum is reached) the validator-submitted `MsgVoteInbound` that finalizes a pending GAS/GAS_AND_PAYLOAD inbound, whose autoswap will now execute at the skewed price (still "succeeding" because `minPCOut` was computed from the same skewed price).
3. Reverse the initial trade afterward, capturing the value that would otherwise have gone to the depositor/protocol.

This directly parallels `ConnextPriceOracle.getPriceFromDex`'s flaw: deriving a price/slippage bound from spot AMM state that the attacker themselves can move, rather than from `getReserves()`-based TWAP or an external reference price resistant to single-transaction manipulation.

### Impact Explanation
Each exploited inbound deposit results in the UEA/recipient receiving fewer WPC (native gas token) than the fair-market value of the deposited PRC20 amount, with the difference captured by the attacker. This is an unauthorized redirection of protocol/user-controlled value during universal execution's PRC20→native accounting step — falling under "corruption of PRC20 or native asset accounting" and value drained from users during a default, unprivileged transaction submission path (any user's gas-inbound deposit). Given autoswap runs for every GAS and GAS_AND_PAYLOAD inbound, this is systematically exploitable, not a one-off edge case.

### Likelihood Explanation
Likelihood is high in principle for any AMM pool with realistic depth constraints relative to attacker capital, since the only barrier is a flat 5% band computed off the same block's spot price — well within normal single-block AMM manipulation ranges for low/medium liquidity pools. No privileged access, validator collusion, or protocol bug is required; only the ability to submit ordinary swap transactions against the PRC20/WPC pool, which is by design open to any external user.

### Recommendation
Do not derive `minPCOut` solely from `GetSwapQuote`'s live spot quote. Instead:
- Use a time-weighted average price (TWAP) from the pool (Uniswap V3 supports `observe`/TWAP-based quoting) as the reference price for computing `minPCOut`, or
- Cap the deviation between the live quote and a longer-window TWAP/oracle price, rejecting or retrying the swap if they diverge beyond a safe bound, or
- Route protocol-critical autoswaps through a pool guarded by minimum liquidity/maximum price-impact checks independent of the same-transaction quote.

### Proof of Concept
1. Attacker observes the PRC20/WPC pool used for gas-abstraction autoswap (`GetUniversalCoreQuoterAddress` / `GetUniversalCoreWPCAddress` resolve this pool) has moderate depth.
2. Attacker submits a large swap (buying WPC with PRC20, or vice versa depending on desired skew) to move the pool's spot price unfavorably for depositors.
3. A pending GAS or GAS_AND_PAYLOAD inbound reaches quorum and is executed via `ExecuteInboundGas`/`ExecuteInboundGasAndPayload`; `GetSwapQuote` reads the now-skewed spot price, and `minPCOut` (95% of that skewed quote) is satisfied trivially by `depositPRC20WithAutoSwap`.
4. Attacker reverses their initial swap, restoring the pool price and pocketing the value difference extracted from the inbound deposit.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}
