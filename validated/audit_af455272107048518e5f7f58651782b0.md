Based on my investigation, I found a concrete divergence between the blockifier's `replace_class` syscall implementation and the Starknet OS's Cairo implementation of the same syscall.

### Title
Missing declared-class validation in OS `execute_replace_class` causes honest-node divergence from Blockifier - (File: crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo)

### Summary
The Rust blockifier `replace_class` syscall handler requires that the target class hash be declared (and Cairo1) before allowing a contract to replace its class, via `self.state.get_compiled_class(class_hash)?` and an `is_cairo1` check [1](#0-0) . The Starknet OS Cairo implementation of the same syscall (`execute_replace_class`) performs the state-entry update without any such check, and explicitly documents this gap with a TODO [2](#0-1) .

### Finding Description
`SyscallHandlerBase::replace_class` in the blockifier enforces two invariants before permitting a class replacement: the class must be declared (fetched via `get_compiled_class`, which errors with `UndeclaredClassHash` otherwise) and it must be a Cairo1 class [1](#0-0) . This mirrors the deprecated (Cairo0) syscall handler which also calls `get_compiled_class` before allowing the class hash write [3](#0-2) , and is covered by a dedicated negative test asserting rejection of undeclared class hashes [4](#0-3) .

In contrast, the Cairo implementation of `execute_replace_class` used by the Starknet OS (SNOS) for block re-execution/proving directly updates `contract_state_changes` with the caller-supplied `class_hash` with no declaration check, and contains a TODO comment acknowledging the missing validation: `// TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.` [5](#0-4) . The legacy (deprecated) Cairo0 OS syscall path has the identical omission [6](#0-5) .

This is directly analogous to the Swaprum root-cause pattern: an unrestricted class/implementation-replacement mechanism with no verification that the new implementation is a legitimate, vetted class — except here the missing guard lives in the code path responsible for the network's canonical state computation (the OS), rather than in an application contract.

### Impact Explanation
The Starknet OS's execution trace is what is ultimately proven and used to attest the block's state transition; the blockifier is the reference execution engine that the sequencer runs live, and the two must agree bit-for-bit for the system to be sound. Since the blockifier rejects a `replace_class` syscall call with an undeclared class hash (returning `UndeclaredClassHash`, causing the calling transaction to revert or fail), while the OS's Cairo implementation would silently accept the same undeclared/never-declared class hash and write it into `contract_state_changes`, any path where the OS independently derives execution behavior (rather than purely replaying already-blockifier-validated state diffs) could permit a divergent state root: a class hash that was never declared (and thus has no corresponding CASM/Sierra data for future execution or proving) could become permanently associated with a contract address in the committed state, which is either a proof-generation failure or a canonical/local state divergence for that contract address.

### Likelihood Explanation
Reachable from any account executing an ordinary Cairo1 or Cairo0 contract call that invokes the `replace_class` syscall with an arbitrary, attacker-chosen (undeclared) class hash — a completely permissionless, single-transaction action requiring no special privileges. The TODO comment in the OS source confirms this is a known, currently-unaddressed gap rather than a hardening measure that's redundant with an upstream check.

### Recommendation
Add an explicit check in `execute_replace_class` (both `syscall_impls.cairo` and `deprecated_execute_syscalls.cairo`) to verify that `class_hash` corresponds to a declared contract class in `contract_class_changes`/the OS's declared-class facts, mirroring the blockifier's `get_compiled_class` check, before writing the new class hash into `contract_state_changes`. This should be prioritized ahead of the currently-scheduled TODO date.

### Proof of Concept
1. Declare no class (or reference an arbitrary unused felt as a "class hash").
2. From any contract, invoke the `replace_class` syscall with this undeclared class hash.
3. In the blockifier, `SyscallHandlerBase::replace_class` calls `state.get_compiled_class(class_hash)` which fails with `StateError::UndeclaredClassHash`, causing the syscall/transaction to fail — as demonstrated by the existing test `test_replace_class` asserting `"is not declared"` on the negative flow [7](#0-6) .
4. In the corresponding OS Cairo function `execute_replace_class`, no such declaration check exists — the function proceeds directly to `dict_update` on `contract_state_changes` with the supplied `class_hash` [8](#0-7) , demonstrating the code-level discrepancy between the two execution engines for the identical syscall.

    pub fn replace_class(&mut self, class_hash: ClassHash) -> SyscallResult<()> {
        // Ensure the class is declared (by reading it), and of type V1.
        let compiled_class = self.state.get_compiled_class(class_hash)?;

        if !is_cairo1(&compiled_class) {
            return Err(SyscallExecutionError::ForbiddenClassReplacement { class_hash });
        }
        self.state.set_class_hash_at(self.call.storage_address, class_hash)?;
        Ok(())
    }

// Replaces the class.
func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
