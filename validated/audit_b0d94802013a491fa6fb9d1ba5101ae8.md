### Title
Missing `supportUnfreezeDelay()` Committee Gate in TVM-Native Freeze/Unfreeze/WithdrawExpireUnfreeze Processors - (File: `actuator/src/main/java/org/tron/core/vm/nativecontract/FreezeBalanceV2Processor.java`, `UnfreezeBalanceV2Processor.java`, `WithdrawExpireUnfreezeProcessor.java`)

### Summary
The transaction-level actuators for the v2 freeze/unfreeze lifecycle (`FreezeBalanceV2Actuator`, `UnfreezeBalanceV2Actuator`, `WithdrawExpireUnfreezeActuator`) all enforce a committee-controlled feature flag `dynamicStore.supportUnfreezeDelay()` before allowing the operation. However, the TVM-native counterparts of these same operations — `FreezeBalanceV2Processor`, `UnfreezeBalanceV2Processor`, and `WithdrawExpireUnfreezeProcessor`, which are invoked from Solidity smart contracts via `Program.java`'s native-contract opcodes — never check this flag at all.

### Finding Description
Each Actuator's `validate()` gates the entire v2 freeze mechanism on the committee proposal flag: [1](#0-0) [2](#0-1) [3](#0-2) 

The corresponding TVM-native processors, reachable via `Program.java` opcodes (e.g. `withdrawExpireUnfreeze()`), perform their own independent validation logic but omit this check entirely: [4](#0-3) [5](#0-4) [6](#0-5) 

This is the same bug class as the reported `withdraw_impl`/`gateway.move` issue: two mirrored entry points for the same security-sensitive operation (deposit/lock vs. withdraw/unlock, or in this case, direct-transaction vs. smart-contract-triggered call), where one path enforces the security/pause gate and the other does not. Here, the inconsistency is between the "human-initiated transaction" path (gated) and the "smart-contract-initiated" path (ungated), invoked through `Program.java`: [7](#0-6) 

### Impact Explanation
`supportUnfreezeDelay()` is the committee toggle that gates the entire "new" freeze/unfreeze/delayed-withdraw resource model. If this feature flag has not been enabled by the committee, or is disabled again after being enabled (proposal parameters are designed to be reversible via governance), the direct-transaction path (`FreezeBalanceV2Contract`, `UnfreezeBalanceV2Contract`, `WithdrawExpireUnfreezeContract`) correctly rejects the operation with `ContractValidateException`. However, any smart contract that invokes the equivalent native opcode (via `Program.java`'s `freezeBalanceV2()`/`unfreezeBalanceV2()`/`withdrawExpireUnfreeze()`) bypasses this governance control completely, since the Processor classes never call `supportUnfreezeDelay()`. This allows the v2 freeze/unfreeze/delayed-withdraw state machine (including balance transitions, `unfrozenV2` list mutation, and total resource weight accounting) to be exercised from contract code even when the feature is supposed to be disabled network-wide — an invalid-state/divergence issue between the two mirrored code paths for the same accounting-critical resource lifecycle.

### Likelihood Explanation
Reachability is high: the native processors are called directly from EVM-visible precompiled opcodes exposed to any deployed smart contract via `Program.java`, requiring no privileged role — only a deployed contract capable of invoking the native freeze/unfreeze/withdraw-expire-unfreeze opcode. The precondition is that the committee flag `supportUnfreezeDelay` is off (default state before activation, or toggled off again), which is an ordinary governance/config state, not a rare edge case.

### Recommendation
Add the same `dynamicStore.supportUnfreezeDelay()` check to `FreezeBalanceV2Processor.validate()`, `UnfreezeBalanceV2Processor.validate()`, and `WithdrawExpireUnfreezeProcessor.validate()` that already exists in their respective Actuators, throwing `ContractValidateException` when the flag is not enabled, to keep the transaction path and the TVM-native path consistent.

### Proof of Concept
Not independently reproduced in a running environment; this is inferred from static comparison of the Actuator vs. Processor validation logic. To confirm exploitability: deploy a contract invoking the TVM `freezeBalanceV2`/`unfreezeBalanceV2`/`withdrawExpireUnfreeze` opcodes on a network/testnet where `supportUnfreezeDelay` is set to `0`, and observe whether the native call succeeds where the equivalent `FreezeBalanceV2Contract`/`UnfreezeBalanceV2Contract`/`WithdrawExpireUnfreezeContract` transaction is rejected with "Not support ... transaction, need to be opened by the committee".

    if (repo == null) {

    byte[] ownerAddress = param.getOwnerAddress();
    if (!DecodeUtil.addressValid(ownerAddress)) {
      throw new ContractValidateException("Invalid address");
    }
    AccountCapsule ownerCapsule = repo.getAccount(ownerAddress);
    if (ownerCapsule == null) {
      String readableOwnerAddress = StringUtil.createReadableString(ownerAddress);

    long frozenBalance = param.getFrozenBalance();

      throw new ContractValidateException("FrozenBalance must be positive");
    } else if (frozenBalance < TRX_PRECISION) {
      throw new ContractValidateException("FrozenBalance must be greater than or equal to 1 TRX");
    } else if (frozenBalance > ownerCapsule.getBalance()) {
      throw new ContractValidateException(
          "FrozenBalance must be less than or equal to accountBalance");
    }

    // validate arg @resourceType
    switch (param.getResourceType()) {
      case BANDWIDTH:
      case ENERGY:

      case TRON_POWER:
        if (!repo.getDynamicPropertiesStore().supportAllowNewResourceModel()) {
          throw new ContractValidateException(
              "Unknown ResourceCode, valid ResourceCode[BANDWIDTH、ENERGY]");
        }
        break;
      default:
        if (repo.getDynamicPropertiesStore().supportAllowNewResourceModel()) {
          throw new ContractValidateException(
              "Unknown ResourceCode, valid ResourceCode[BANDWIDTH、ENERGY、TRON_POWER]");
        } else {
          throw new ContractValidateException(
              "Unknown ResourceCode, valid ResourceCode[BANDWIDTH、ENERGY]");
        }
    }

  public void validate(UnfreezeBalanceV2Param param, Repository repo)
      throws ContractValidateException {
    if (repo == null) {
      throw new ContractValidateException(STORE_NOT_EXIST);
    }

    byte[] ownerAddress = param.getOwnerAddress();
    DynamicPropertiesStore dynamicStore = repo.getDynamicPropertiesStore();
    if (!DecodeUtil.addressValid(ownerAddress)) {
      throw new ContractValidateException("Invalid address");
    }
    AccountCapsule accountCapsule = repo.getAccount(ownerAddress);
    if (accountCapsule == null) {
      String readableOwnerAddress = StringUtil.createReadableString(ownerAddress);
      throw new ContractValidateException(
          ACCOUNT_EXCEPTION_STR + readableOwnerAddress + "] does not exist");
    }
    long now = dynamicStore.getLatestBlockHeaderTimestamp();
    int unfreezingCount = accountCapsule.getUnfreezingV2Count(now);
    if (UnfreezeBalanceV2Actuator.getUNFREEZE_MAX_TIMES() <= unfreezingCount) {
      throw new ContractValidateException("Invalid unfreeze operation, unfreezing times is over limit");
    }
    switch (param.getResourceType()) {
      case BANDWIDTH:
        // validate frozen balance
        if (!this.checkExistFrozenBalance(accountCapsule, Common.ResourceCode.BANDWIDTH)) {
          throw new ContractValidateException("no frozenBalance(BANDWIDTH)");
        }
        break;
      case ENERGY:
        // validate frozen balance
        if (!this.checkExistFrozenBalance(accountCapsule, Common.ResourceCode.ENERGY)) {
          throw new ContractValidateException("no frozenBalance(ENERGY)");
        }
        break;
      case TRON_POWER:
        if (dynamicStore.supportAllowNewResourceModel()) {
          if (!this.checkExistFrozenBalance(accountCapsule, Common.ResourceCode.TRON_POWER)) {
            throw new ContractValidateException("no frozenBalance(TRON_POWER)");
          }
        } else {
          throw new ContractValidateException("Unknown ResourceCode, valid ResourceCode[BANDWIDTH、ENERGY]");
        }
        break;
      default:
        if (dynamicStore.supportAllowNewResourceModel()) {
          throw new ContractValidateException("Unknown ResourceCode, valid ResourceCode[BANDWIDTH、ENERGY、TRON_POWER]");
        } else {
          throw new ContractValidateException("Unknown ResourceCode, valid ResourceCode[BANDWIDTH、ENERGY]");
        }
    }

    if (!checkUnfreezeBalance(accountCapsule, param.getUnfreezeBalance(), param.getResourceType())) {
      throw new ContractValidateException(
          "Invalid unfreeze_balance, [" + param.getUnfreezeBalance() + "] is invalid");
    }
  }

  public void validate(WithdrawExpireUnfreezeParam param, Repository repo) throws ContractValidateException {
    if (repo == null) {
      throw new ContractValidateException(STORE_NOT_EXIST);
    }

    byte[] ownerAddress = param.getOwnerAddress();
    DynamicPropertiesStore dynamicStore = repo.getDynamicPropertiesStore();
    if (!DecodeUtil.addressValid(ownerAddress)) {
      throw new ContractValidateException("Invalid address");
    }
    AccountCapsule accountCapsule = repo.getAccount(ownerAddress);
    if (Objects.isNull(accountCapsule)) {
      String readableOwnerAddress = StringUtil.createReadableString(ownerAddress);
      throw new ContractValidateException(ACCOUNT_EXCEPTION_STR
          + readableOwnerAddress + NOT_EXIST_STR);
    }

    long now = dynamicStore.getLatestBlockHeaderTimestamp();
    List<Protocol.Account.UnFreezeV2> unfrozenV2List = accountCapsule.getInstance()
        .getUnfrozenV2List();
    long totalWithdrawUnfreeze = getTotalWithdrawUnfreeze(unfrozenV2List, now);
    if (totalWithdrawUnfreeze < 0) {
      throw new ContractValidateException("no unFreeze balance to withdraw ");
    }
    try {
      LongMath.checkedAdd(accountCapsule.getBalance(), totalWithdrawUnfreeze);
    } catch (ArithmeticException e) {
      logger.debug(e.getMessage(), e);
      throw new ContractValidateException(e.getMessage());
    }
  }
