### Title
Missing declared-class check in Starknet OS `execute_replace_class` causes divergence from Blockifier's `replace_class` syscall enforcement - ([File: crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo])

### Summary
The Blockifier's Rust implementation of the `replace_class` syscall enforces two checks before allowing a contract to change its class: (1) the target class hash must be declared (readable), and (2) it must be a Cairo 1 (V1) class. The Starknet OS's Cairo re-implementation of the same syscall, `execute_replace_class`, omits the "declared class" check entirely (marked with an explicit `TODO`), creating a state-transition divergence between block execution (Blockifier) and OS re-execution/proving.

### Finding Description
In `crates/blockifier/src/execution/syscalls/syscall_base.rs`, `replace_class` reads the compiled class before mutating state: [1](#0-0) 
This call to `state.get_compiled_class(class_hash)` returns a `StateError` (undeclared class) if the class hash was never declared, causing the syscall — and typically the whole transaction — to fail/revert during actual block building/execution.

In the Starknet OS's Cairo implementation of the same syscall, `execute_replace_class`, the equivalent check is missing, with an explicit acknowledgment in the code: [2](#0-1) 
The OS directly updates `contract_state_changes` with the attacker-supplied `class_hash` regardless of whether that class hash was ever declared, via `GetContractAddressStateEntry` and `dict_update`, with no equivalent to `get_compiled_class`/declared-check.

This is directly analogous to the reported bug class: a validation (here, "class hash must be declared before use", analogous to "representative must be an EOA") is correctly enforced on one code path (Blockifier's `replace_class`) but missing on a second, logically-equivalent code path (the OS's `execute_replace_class`) that performs the same state-changing operation, allowing the check to be bypassed depending on which path processes the transaction.

### Impact Explanation
The Starknet OS is what re-executes committed transactions to prove correctness of the state transition and produce the block hash / state commitment used for L1 verification. If a transaction containing a `replace_class` syscall with an undeclared class hash succeeds under the OS's execution path (because the declared-check is missing) while it fails/reverts under the Blockifier's sequencer-side execution (because the check IS enforced there), the state root computed by re-execution will diverge from the state root computed by the sequencer during block building. This causes an honest-node/prover divergence and can result in an incorrect committed state root/class hash being accepted, or the OS being unable to reconcile execution results with the Blockifier-produced state diff — a wrong committed root / block-hash class of impact.

### Likelihood Explanation
An unprivileged contract can trigger `replace_class_syscall` with an arbitrary, undeclared `class_hash` from its own execution context in an ordinary invoke transaction — no special privileges required. Because the check is simply absent (confirmed by the explicit `TODO` comment in the code) rather than gated behind unusual conditions, this is reachable by any transaction sender that controls a deployed contract capable of calling `replace_class_syscall`.

### Recommendation
Add the missing declared-class check to `execute_replace_class` in `crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo`, mirroring the Blockifier's `syscall_base.rs::replace_class`: before writing the new `StateEntry`, verify that `class_hash` corresponds to a declared compiled class (and, if OS parity with the Cairo1-only restriction is desired, verify it is not a deprecated/Cairo0 class), returning a failure/rejecting the syscall analogous to `ForbiddenClassReplacement`/undeclared-class errors on the Blockifier side.

### Proof of Concept
1. Deploy a Cairo 1 contract exposing `replace_class_syscall`.
2. Invoke that contract's function to call `replace_class_syscall(class_hash)` where `class_hash` is a value that was never declared on-chain.
3. Under the Blockifier execution path, `syscall_base::replace_class` calls `state.get_compiled_class(class_hash)` which fails with an undeclared-class error, causing the syscall/transaction to fail as shown in tests such as: [3](#0-2) 
4. Under the Starknet OS's `execute_replace_class` Cairo implementation, no such check exists — the state entry is unconditionally updated with the undeclared class hash, producing a different state diff/output than the Blockifier execution for the same transaction, as evidenced by the absent check and explicit `TODO(Yoni, 1/1/2026)` comment: [4](#0-3) 

Note: I was not able to fully trace whether an additional guard exists elsewhere in the OS pipeline (e.g., a later commitment-phase check that would reject an undeclared class hash before the block hash is finalized) that might mitigate this; the `apollo_starknet_os_program` Cairo sources for later commitment/output stages were not fully inspected in this pass. I recommend a Devin session with full repository access to confirm no downstream check intercepts this divergence before treating this as fully confirmed at Critical/High severity versus Medium.

    pub fn replace_class(&mut self, class_hash: ClassHash) -> SyscallResult<()> {
        // Ensure the class is declared (by reading it), and of type V1.
        let compiled_class = self.state.get_compiled_class(class_hash)?;

        if !is_cairo1(&compiled_class) {
            return Err(SyscallExecutionError::ForbiddenClassReplacement { class_hash });
        }
        self.state.set_class_hash_at(self.call.storage_address, class_hash)?;
        Ok(())
    }

// Replaces the class.
func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
