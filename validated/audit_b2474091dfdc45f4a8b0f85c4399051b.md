### Title
Starknet OS `execute_replace_class` omits the "class must be declared" check enforced by the Blockifier, causing OS/Blockifier state divergence - ([File: crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo])

### Summary
The Starknet OS's Cairo implementation of the `replace_class` syscall does not verify that the target `class_hash` has actually been declared before writing it into the contract's state entry, whereas the Rust Blockifier's implementation of the same syscall performs this check and rejects undeclared/invalid class hashes. This is the same class of bug as the referenced ENS report: a state-mutating function is missing a precondition check ("live"/validity check) that its sibling implementations enforce, allowing state transitions that should not be permitted.

### Finding Description
In the Blockifier (used by the sequencer to execute transactions when building blocks), `replace_class` explicitly ensures the class is declared and is a Cairo1 class before mutating state: [1](#0-0) 

The equivalent deprecated-syscall handler in the Blockifier also enforces the declared-class check: [2](#0-1) 

Tests explicitly confirm this is a load-bearing check ("Replace with undeclared class hash" → error "is not declared"): [3](#0-2) 

However, the Starknet OS's own Cairo implementation of the same syscall — used for re-executing/proving the block that the Blockifier already produced — updates the contract's class hash directly from the hinted state entry, with an explicit `TODO` acknowledging the missing check: [4](#0-3) 

Specifically, line 902 reads: `// TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.` — the OS simply trusts the prover-supplied hint (`%{ GetContractAddressStateEntry %}`) and writes `new_state_entry` with the requested `class_hash` unconditionally, with no verification that the class was declared in this state, and no check on Cairo0/Cairo1 compatibility (which the Rust Blockifier also enforces via `is_cairo1`).

### Impact Explanation
Because block building (Blockifier) and block proving (Starknet OS re-execution) are separate implementations that must agree bit-for-bit on the resulting state diff for a given set of transactions, any divergence in per-syscall validation logic between them is a correctness bug. If the Blockifier rejects/reverts a call because `replace_class` targets an undeclared (or Cairo0) class hash, but the OS's Cairo implementation of the same syscall unconditionally accepts and applies the class hash change, the OS-computed state diff/state root for that block will differ from the state actually committed by the sequencer. Since the Starknet OS's output is what gets proven and is expected to match the sequencer's committed state, this divergence can result in a wrong committed root/block hash or an inability to generate a consistent, valid proof for an otherwise-accepted block — i.e., honest-node divergence between the executing sequencer and the proving OS.

### Likelihood Explanation
The `replace_class` syscall is reachable by any deployed contract (via `library_call`/direct invocation) from a single, ordinary transaction — no privileged operator or off-chain access is required. An attacker only needs a contract that calls `replace_class` with a `class_hash` that has never been declared (or a Cairo0 hash on a Cairo1 contract) to trigger a Blockifier revert during normal execution while the OS's parallel logic path — explicitly marked incomplete via the `TODO` — lacks the corresponding guard.

### Recommendation
Add the same "class must be declared" (and Cairo0/Cairo1 compatibility) check to `execute_replace_class` in `crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo`, mirroring the Rust Blockifier logic in `crates/blockifier/src/execution/syscalls/syscall_base.rs` (`replace_class`), before writing the new class hash into `contract_state_changes`. Resolve/remove the `TODO(Yoni, 1/1/2026)` comment as part of the fix and add a Cairo-level negative test analogous to `crates/blockifier/src/execution/syscalls/syscall_tests/replace_class.rs::undeclared_class_hash`.

### Proof of Concept
1. Deploy a Cairo1 contract that, on some entry point, calls `replace_class_syscall(class_hash)` with a `class_hash` that has never been declared on-chain (or is a Cairo0 class hash).
2. When the sequencer's Blockifier executes this transaction during block building, `syscall_base::replace_class` calls `self.state.get_compiled_class(class_hash)?`, which fails with `UndeclaredClassHash`/similar, causing the call (and likely the transaction) to revert — see `crates/blockifier/src/execution/syscalls/syscall_tests/replace_class.rs` lines 17-29.
3. When the same block/transaction is later re-executed by the Starknet OS for proving, `execute_replace_class` in `syscall_impls.cairo` performs no declared-class check (line 902 TODO) and unconditionally updates `contract_state_changes` with the new (undeclared) class hash, producing a different state diff than what the Blockifier actually committed for that transaction.

    pub fn replace_class(&mut self, class_hash: ClassHash) -> SyscallResult<()> {
        // Ensure the class is declared (by reading it), and of type V1.
        let compiled_class = self.state.get_compiled_class(class_hash)?;

        if !is_cairo1(&compiled_class) {
            return Err(SyscallExecutionError::ForbiddenClassReplacement { class_hash });
        }
        self.state.set_class_hash_at(self.call.storage_address, class_hash)?;
        Ok(())
    }

// Replaces the class.
func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
