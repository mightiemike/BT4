## Analog Found: Missing Class-Hash Declaration Check in Starknet OS `replace_class` Syscall Implementation

### Title
Starknet OS `execute_replace_class` accepts undeclared/arbitrary class hashes, diverging from Blockifier's enforced check - ([File: crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo])

### Summary
The Wido report describes a class of bug where an address/implementation reference used to redirect execution control is never verified against a canonical registry before being trusted. The sequencer analog is the `replace_class` syscall: the Rust Blockifier (used for block building/execution) explicitly verifies the supplied `class_hash` is declared before allowing a contract to replace its own class, but the Cairo Starknet OS program (used for OS re-execution / proof generation) performs no such check — it is marked with an explicit unresolved TODO.

### Finding Description
In the Rust blockifier, `replace_class` is guarded: [1](#0-0) 
This calls `state.get_compiled_class(request.class_hash)?`, which fails if the class hash was never declared, and additionally the syscall executor enforces `ForbiddenClassReplacement` for Cairo0/Cairo1 mismatches. [2](#0-1) 

In contrast, the Starknet OS's Cairo implementation of the same syscall (used to re-execute transactions and produce the committed state root / block hash) contains no declaration check at all, and explicitly documents this gap as a pending TODO: [3](#0-2) 
The same missing check exists in the deprecated (Cairo0) OS syscall path: [4](#0-3) 

The blockifier-level unit tests confirm the intended, enforced behavior — replacing with an undeclared class hash must fail with "is not declared": [5](#0-4) [6](#0-5) 

This is precisely the "unverified address/target used to redirect execution control" bug class from the report, transposed onto Starknet's class-hash indirection mechanism: a contract can point its own execution to any felt value as if it were a legitimate declared class, and — in the OS re-execution path only — nothing rejects an undeclared or otherwise invalid value.

### Impact Explanation
The Starknet OS re-executes every transaction in a block to independently derive the state diff, state commitment, and block hash that the sequencer/committer asserts. If a transaction that the blockifier would reject (because the target class hash is undeclared) is nonetheless accepted by the OS's `execute_replace_class`, the OS will compute a *different* state entry (class hash) for the contract than the one the blockifier produced during block building — or, conversely, a block built for one which the OS is not able to fault-check consistently. This causes honest-node divergence between the block-building/execution result and the OS's independently re-derived result, which is exactly the class of impact this scan accepts: "wrong committed root or block hash, honest-node divergence." An undeclared/attacker-controlled class hash accepted downstream could also let a contract's storage be reinterpreted under an arbitrary (bogus) class layout when re-executed by the OS, which is a state-integrity/control-flow correctness issue reachable purely through a single `replace_class` syscall call from any unprivileged transaction sender's contract.

### Likelihood Explanation
Likelihood is high in terms of reachability: any account or contract that is permitted to invoke `replace_class_syscall` (which is a standard, unprivileged, Cairo-level operation available in any Cairo0/Cairo1 contract) can pass any felt as `class_hash`, including one that was never declared. Reaching the OS re-execution path only requires the transaction/block to be processed through the OS (Starknet OS is used by every node re-executing/proving blocks, not just special operators), and this is a normal path — not one that requires a malicious operator or peer. The bug is explicitly acknowledged in-code via the `TODO(Yoni, 1/1/2026)` comment, confirming it is a known, currently-unfixed gap rather than a false positive.

### Recommendation
Add the same "class is declared" verification in the Starknet OS's `execute_replace_class` (both `syscall_impls.cairo` and `deprecated_execute_syscalls.cairo`) that the Rust blockifier already performs — i.e., before writing the new `class_hash` into the contract's `StateEntry`, assert that `contract_class_changes` (or the equivalent declared-classes dictionary) contains an entry for that class hash, mirroring `state.get_compiled_class(request.class_hash)?` in `hint_processor.rs`. This keeps the OS's acceptance criteria for `replace_class` consistent with the blockifier's, preventing honest-node/state divergence.

### Proof of Concept
1. A contract with a `replace_class` external entry point (e.g., `test_replace_class`, as used in feature-contract test fixtures) is deployed and invoked by any regular account transaction. [7](#0-6) 
2. The caller supplies an arbitrary, never-declared `class_hash` (e.g., `1234`) as calldata.
3. During normal block building (blockifier), this transaction would revert with "is not declared" as shown in the test at lines 17-29 of `replace_class.rs`.
4. If for any reason the block/transaction reaches the Starknet OS re-execution path with this call already applied/assumed (e.g., through separately-crafted state diffs or a block containing this state transition), `execute_replace_class` in `syscall_impls.cairo` performs the state update unconditionally (no declared-class check, per the TODO at line 902), producing a state root inconsistent with what a compliant blockifier execution would have produced or accepted.

// Replaces the class.
func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
