### Title
Factory (UEA registry) proxy is deployed via genesis without ever calling `initialize()`, leaving `Ownable` owner unset/front-runnable - (File: `x/uexecutor/keeper/genesis.go`)

### Summary
This is a direct analog of the C4 Covalent H-01 finding: an upgradeable contract's `Ownable`/`initializer` state is never properly set at deployment time, so `onlyOwner` protections either become permanently inaccessible or — worse in this codebase — remain claimable by whoever calls `initialize()` first.

### Finding Description
`x/uexecutor` deploys the UEA `Factory` system contract triple (implementation, `ProxyAdmin`, and `TransparentUpgradeableProxy`) directly from Go at genesis in `deployFactoryEA`: [1](#0-0) 

This function only calls `deployFactoryImplContract`, `deployProxyAdminContract`, and `deployFactoryProxy`. `deployProxyAdminContract` writes the `ProxyAdmin`'s own `Ownable` storage slot 0 directly via `SetState`: [2](#0-1) 

However, no equivalent step ever performs an EVM call to `Factory.initialize(owner)` on the newly deployed proxy. The embedded `FactoryImplRuntimeBytecode` exposes a `c4d66de8` selector (the canonical OpenZeppelin `initialize(address)` selector) alongside `8da5cb5b` (`owner()`), `715018a6` (`renounceOwnership()`), and `f2fde38b` (`transferOwnership(address)`) — the standard `OwnableUpgradeable` + `Initializable` pattern: [3](#0-2) 

In the project's own test helper (which mirrors the real production flow), `initialize(owner)` has to be called explicitly and separately after proxy deployment before the Factory's owner is set: [4](#0-3) 

Since `InitGenesis` never issues this call in production (`x/uexecutor/keeper/keeper.go` only invokes `deployFactoryEA` and then sets module params/state, with no `CallEVM`/`DerivedEVMCall` to `initialize` on the Factory proxy): [5](#0-4) 

the Factory proxy's `owner` storage variable is left at its zero-value at chain start. Under the standard OpenZeppelin `Initializable` pattern, `initialize()` is guarded only by the `initializer` modifier (i.e., "callable exactly once, by whoever calls it first"), not by `onlyOwner` or any allowlist. This means the Factory's ownership state is either (a) never claimable, permanently bricking `onlyOwner`-gated admin functions such as `setUEAProxyImplementation`, `registerNewChain`, and `registerUEA` (same end-state as the original H-01 finding), or (b) claimable by the first unprivileged party — including an external attacker — who submits an `initialize(attacker)` transaction against the well-known Factory proxy address before any legitimate operator does.

### Impact Explanation
If an unprivileged attacker wins the initialization race and becomes `owner` of the Factory:
- They can call `setUEAProxyImplementation` to redirect every future UEA (Universal Execution Account) deployed through the factory to a malicious implementation, hijacking universal-execution flows and funds routed to UEAs.
- They can call `registerNewChain`/`registerUEA` to inject forged chain/VM hash mappings or forcibly register arbitrary UEA-address bindings, corrupting the canonical account-identity mapping that `CallFactoryToDeployUEA`/`CallFactoryGetOriginForUEA` rely on: [6](#0-5) 

This falls squarely within the "unauthorized UEA or CEA execution" / "unauthorized module-originated EVM execution" allowed-impact categories, and can lead to draining or permanent freezing of user/protocol funds routed through UEAs.

### Likelihood Explanation
Medium-to-high, but with important caveats I could not fully resolve given index limitations: I confirmed from Go-level code that no `initialize` call is ever issued against the Factory proxy during `InitGenesis`, and the embedded bytecode exposes an OZ-style `initialize(address)` initializer selector. I was **not able to inspect the actual Solidity source** of the Factory implementation (only compiled bytecode constants and the ABI are indexed) to confirm definitively that `initialize()` lacks any additional access-control guard (e.g., a deployer-only check) beyond the standard `initializer` modifier, nor could I confirm whether some out-of-repo deployment/upgrade tooling (e.g., a one-time governance-run script) reliably calls `initialize()` in the same atomic step as genesis before the chain accepts external transactions. This uncertainty should be resolved by inspecting the actual Factory Solidity source (likely in a separate `contracts/` repo not covered by this index) and by checking whether any post-genesis migration handler performs the missing `initialize()` call.

### Recommendation
- Call `Factory.initialize(<intended owner, e.g. governance/module account>)` atomically within `InitGenesis`/`deployFactoryEA`, in the same way `deployProxyAdminContract` directly writes the `ProxyAdmin` owner slot, rather than relying on a separate, front-runnable transaction.
- Alternatively, have the Factory implementation's `initialize()` restrict the caller (e.g., only callable by a hardcoded deployer/module address), consistent with how `PROXY_ADMIN_OWNER_ADDRESS_HEX` is hardcoded for the `ProxyAdmin`.
- Add a genesis-level invariant test (mirroring `x/uregistry/keeper/genesis_internal_test.go`'s `TestDeploySystemContracts_ReportEveryProxyAdminOwner`) that asserts the Factory proxy's `owner()` equals the expected owner immediately after `InitGenesis`, to catch this class of bug automatically.

### Proof of Concept
1. Start a fresh chain; `InitGenesis` runs `deployFactoryEA`, deploying the Factory proxy/impl/ProxyAdmin triple at the well-known addresses (`FACTORY_PROXY_ADDRESS_HEX = 0x...eA`) without calling `initialize()`. [7](#0-6) 
2. Before any legitimate operator submits an `initialize(owner)` transaction, an unprivileged attacker submits `cast send 0x00...eA "initialize(address)" <attacker>`.
3. If unguarded (per the standard OZ `initializer` modifier semantics implied by the embedded bytecode's `c4d66de8` selector), the attacker becomes `owner`, verifiable via `cast call 0x00...eA "owner()"`.
4. The attacker then calls `setUEAProxyImplementation(<malicious impl>)` on the Factory, compromising all subsequently deployed UEAs.

*(Confirming step 3's exact guard requires the Factory's Solidity source, which was not available in this index — flagged above as an open verification item.)*

func deployProxyAdminContract(ctx context.Context, evmKeeper types.EVMKeeper) {
	sdkCtx := sdk.UnwrapSDKContext(ctx)
	proxyAdminAddress := common.HexToAddress(types.PROXY_ADMIN_ADDRESS_HEX)
	owner := common.HexToAddress(types.PROXY_ADMIN_OWNER_ADDRESS_HEX)

	// Compute the code hash from the runtime bytecode
	codeHash := crypto.Keccak256(types.ProxyAdminRuntimeBytecode)

	// Create the EVM account object
	evmAccount := statedb.Account{
		Nonce:    1,             // to prevent tx nonce=0 conflicts
		Balance:  new(uint256.Int), // zero balance by default
		CodeHash: codeHash,      // link to deployed code
	}

	// Set the EVM account with the proxy admin contract
	err := evmKeeper.SetAccount(sdkCtx, proxyAdminAddress, evmAccount)
	if err != nil {
		panic("failed to set proxy admin contract account: " + err.Error())
	}

	// Store the runtime bytecode linked to the code hash
	evmKeeper.SetCode(sdkCtx, codeHash, types.ProxyAdminRuntimeBytecode)

	// Initialize storage slot 0 (Ownable.owner) with the owner address (left padded to 32 bytes)
	evmKeeper.SetState(sdkCtx, proxyAdminAddress, common.Hash{}, common.LeftPadBytes(owner.Bytes(), 32))
}

// InitGenesis initializes the module's state from a genesis state.
func (k *Keeper) InitGenesis(ctx context.Context, data *types.GenesisState) error {

	if err := data.Params.ValidateBasic(); err != nil {
		return err
	}

	// Only deploy factory contracts on fresh genesis, not on import from export.
	// Re-deploying on import would overwrite existing EVM state or cause nonce collisions.
	if !data.Exported {
		deployFactoryEA(ctx, k.evmKeeper)
	}

	if err := k.Params.Set(ctx, data.Params); err != nil {
		return err
	}

// CallFactoryToGetUEAAddressForOrigin calls FactoryV1.getUEAForOrigin(...)
func (k Keeper) CallFactoryToGetUEAAddressForOrigin(
	ctx sdk.Context,
	from, factoryAddr common.Address,
	universalAccount *types.UniversalAccountId,
) (common.Address, bool, error) {
	abi, err := types.ParseFactoryABI()
	if err != nil {
		return common.Address{}, false, errors.Wrap(err, "failed to parse factory ABI")
	}

	abiUniversalAccount, err := types.NewAbiUniversalAccountId(universalAccount)
	if err != nil {
		return common.Address{}, false, errors.Wrapf(err, "failed to create universal account")
	}

	receipt, err := k.evmKeeper.CallEVM(
		ctx,
		abi,
		from,
		factoryAddr,
		false, // commit
		nil,
		"getUEAForOrigin",
		abiUniversalAccount,
	)
	if err != nil {
		return common.Address{}, false, err
	}

	results, err := abi.Methods["getUEAForOrigin"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return common.Address{}, false, errors.Wrap(err, "failed to decode result")
	}

	ueaAddress := results[0].(common.Address)
	isDeployed := results[1].(bool)

	return ueaAddress, isDeployed, nil
}
