### Title
Manipulable spot-price Uniswap V3 quote used as its own slippage guard for PRC20→PC auto-swaps, allowing sandwich-extraction of user deposit / gas-refund value - (File: `x/uexecutor/keeper/execute_inbound_gas.go`, `x/uexecutor/keeper/execute_inbound_gas_and_payload.go`, `x/uexecutor/keeper/outbound.go`, `x/uexecutor/keeper/evm.go`)

### Summary
The Salty.IO report shows that when a fee/reward is computed from an AMM state that can itself be manipulated (WBTC/WETH ratio), the "protection" derived from that manipulated state (the reward formula) is meaningless, letting an attacker sandwich the operation to extract value. Push Chain has a structurally identical pattern in the `x/uexecutor` PRC20→PC auto-swap path: the module fetches a Uniswap V3 `QuoterV2.quoteExactInputSingle` spot quote and then derives its own slippage floor (`minPCOut = quote * 95 / 100`) from that same spot quote, immediately before executing the real swap on the same pool.

### Finding Description
`k.GetSwapQuote` [1](#0-0)  reads a live, un-averaged spot price from the Uniswap V3 `QuoterV2` contract for the `PRC20 → WPC` pair. This quote is used to compute `minPCOut`, the slippage-protection parameter passed straight into the same-block swap execution, in three call sites:

- `ExecuteInboundGas` (GAS inbound route): fetches quote then swaps via `CallPRC20DepositAutoSwap` [2](#0-1) 
- `gasAndPayloadDepositAutoSwap` (GAS_AND_PAYLOAD inbound route) [3](#0-2) 
- `applyGasRefund` (outbound excess-gas refund route) [4](#0-3) 

In every case, `minPCOut` is `quote * 95 / 100` — a bound computed from the *same* spot price that will be used to actually execute the trade moments later [5](#0-4) . This is not a real slippage protection against price manipulation; it only bounds *additional* movement after the (already possibly manipulated) quote was taken. Exactly like the Salty.IO liquidation reward that assumed an un-manipulable 50:50 WBTC/WETH ratio, this code assumes the Uniswap V3 spot price at quote-time reflects fair value, with no TWAP, oracle, or manipulation-resistant reference price.

An unprivileged attacker who can trade against the same `PRC20/WPC` Uniswap V3 pool (any user can, since these pools are ordinary on-chain AMM pools with public swap access) can push the pool's spot price for the target `PRC20` down in the same block just before the module's `GetSwapQuote` call fires (e.g., front-running the finalizing `MsgVoteInbound`/`MsgVoteOutbound` transaction that triggers this code path once quorum is reached), then reverse the trade afterward. Because the module's own `minPCOut` is derived from the manipulated quote, the deposit/refund swap will still pass the check while executing at a depressed rate, so the depositing user (`ueaAddr`/UEA recipient in `CallPRC20DepositAutoSwap`) or the refund recipient in `CallUniversalCoreRefundUnusedGas` receives less native PC than fair value, with the difference captured by the attacker's own reversed trade against the same pool.

### Impact Explanation
This directly corrupts native/PRC20 asset accounting for ordinary, unprivileged inbound deposit and outbound gas-refund flows — the exact "corruption of PRC20 or native asset accounting... reachable from ordinary user deposits" impact category in scope. Victims are:
- Ordinary bridge users depositing gas/gas_and_payload inbound transactions whose PRC20 is auto-swapped to PC for their UEA.
- Users owed an excess-gas refund on outbound execution, whose refund amount is swapped gasToken → PC.

The attacker profits by capturing the price impact of the manipulated round-trip swap, effectively siphoning value that should have gone to the depositor/refund recipient, or draining protocol-owned liquidity depending on which side of the swap absorbs the loss.

### Likelihood Explanation
Likelihood is moderate: it requires the target PRC20/WPC pool to have low liquidity relative to the deposit/refund amount (making a single-block price move economical), and the attacker needs to time a swap immediately around the validator vote that finalizes the inbound/outbound (a public, predictable, mempool-visible event). No privileged access, validator collusion, or external chain compromise is needed — only ordinary swap transactions against a public AMM pool, matching the "unprivileged external attacker" threat model.

### Recommendation
- Short term: derive `minPCOut` from a manipulation-resistant reference (e.g., a stored oracle/registry price, or a TWAP quote from the Uniswap V3 pool) rather than from the same spot quote used to execute the trade; alternatively, apply a much larger, config-driven slippage bound tied to an independent price source, not the just-fetched spot quote itself.
- Long term: introduce a canonical price oracle (TWAP-based or external) for all PRC20/PC conversions used in protocol-critical accounting (inbound deposits, gas refunds), and reject swaps whose spot price deviates materially from that oracle price.

### Proof of Concept
1. Attacker identifies a low-liquidity `PRC20 X` / `WPC` Uniswap V3 pool used by `defaultFeeTier[X]` in `UniversalCore`.
2. Attacker observes a pending `MsgVoteInbound` (GAS or GAS_AND_PAYLOAD, asset = X) reaching quorum, or a pending outbound gas-refund vote for gas token X.
3. Immediately before/alongside that vote transaction lands, attacker submits a large `X → WPC` swap on the pool, depressing X's spot price.
4. The module's `GetSwapQuote` (`x/uexecutor/keeper/evm.go:502-538`) reads the depressed spot price; `minPCOut = quote*95/100` is computed from this depressed price and passed to `CallPRC20DepositAutoSwap` / `CallUniversalCoreRefundUnusedGas`.
5. The module's swap executes at the manipulated rate, crediting the UEA/refund recipient less PC than fair value.
6. Attacker reverses the initial swap (`WPC → X`) in the same or following block, recovering X and capturing the value difference extracted from the module's swap.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}
