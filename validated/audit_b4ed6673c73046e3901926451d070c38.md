### Title
Missing "class is declared" validation in Starknet OS `execute_replace_class` diverges from Blockifier's `replace_class` check, enabling a state-diff/state-root mismatch - ([File: crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo])

### Summary
The reported bug class is "a critical state variable is mutated without validating the value against a required precondition (declared/authorized), reachable by any unprivileged caller." The Starknet sequencer has an exact structural analog: the `replace_class` syscall mutates a contract's `class_hash` — a critical piece of committed contract state — and the Rust `blockifier` execution engine enforces the precondition that the target class hash must be a **declared** class before allowing the write, but the Cairo Starknet-OS implementation of the very same syscall (the code that is actually replayed to produce the STARK-proved state transition and commitment) omits this check, as explicitly flagged by a developer `TODO`.

### Finding Description
`replace_class` is a syscall any deployed contract can invoke on itself via a normal `INVOKE` transaction from an unprivileged account, changing the `class_hash` stored for that contract address.

In the Rust `blockifier` (used by the sequencer to decide whether a transaction succeeds and what state diff to produce), the syscall handler explicitly requires the target class to be declared before mutating state: [1](#0-0) 

and this is verified by tests that assert an "is not declared" error for undeclared class hashes: [2](#0-1) 

However, the corresponding Cairo implementation used by the Starknet OS (which independently re-executes syscalls to produce the block's committed state diff / state root for STARK proving) performs **no such check**. The developer left a self-documenting `TODO` acknowledging the gap: [3](#0-2) 

Specifically, line 902's comment `// TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.` sits directly before the code unconditionally overwrites the `StateEntry.class_hash` with the caller-supplied, unverified `class_hash`, and updates `contract_state_changes` and the `revert_log` as if the operation is always valid.

The same missing validation is also present in the older/deprecated Cairo0 syscall path: [4](#0-3) 

### Impact Explanation
The `class_hash` field of a contract is part of the committed contract state that is hashed into the state tree (`get_contract_state_hash`, `calculate_global_state_root`) and ultimately into the block's global state root: [5](#0-4) 

Because the Starknet OS is the component whose execution is proven and whose resulting state diff/commitment is what is ultimately verified/settled (not the blockifier's own internal bookkeeping), any divergence between what the blockifier considers valid (reject replace_class to an undeclared class hash) and what the OS considers valid (accept it unconditionally) is a root-cause honest-node/engine divergence: the two engines that are required to agree on the exact same state transition for the same transaction can disagree specifically on this syscall. This can manifest as:
- The OS computing and committing a different `address_to_class_hash` entry (and therefore a different state root / block hash) than the one derived by the blockifier-driven sequencing pipeline.
- A contract's committed class hash being set to a class hash that was never declared, breaking the invariant that every reachable `class_hash` in state corresponds to a declared class (which downstream tooling, the class-hash-to-compiled-class-hash commitment, and RPC clients rely on).

This maps to "wrong committed root or block hash" / "honest-node divergence" acceptance criteria, and is High severity because it undermines the core soundness guarantee that OS re-execution faithfully mirrors blockifier semantics for state mutation.

### Likelihood Explanation
The syscall is trivially reachable: any account or contract can invoke `replace_class_syscall(class_hash)` from a standard, unprivileged `INVOKE` transaction, as demonstrated by the feature-contract helper: [6](#0-5) 

No special privilege, staking, prover-only, or operator access is required — only supplying an arbitrary (including undeclared) class hash as calldata. The missing check is unconditional in the OS Cairo code path, not tied to any edge case.

### Recommendation
Add the missing declared-class-hash check to the Starknet OS's `execute_replace_class` (in `syscall_impls.cairo`) and to the deprecated Cairo0 equivalent (`deprecated_execute_syscalls.cairo`), mirroring the check already performed in the Rust `blockifier`'s `replace_class` handler (`state.get_compiled_class(request.class_hash)?` before `set_class_hash_at`). The OS must fail/abort the syscall (and thus the transaction, consistent with blockifier behavior) when `class_hash` is not a declared class, ensuring both execution engines enforce identical preconditions on this state mutation.

### Proof of Concept
1. Deploy (or use) a contract exposing `test_replace_class(class_hash)` which calls `replace_class_syscall(class_hash)`, e.g. as in the test contract: [6](#0-5) 
2. Submit a normal `INVOKE` transaction from any account calling `test_replace_class` with an arbitrary, never-declared felt as `class_hash`.
3. In the Rust blockifier execution path, this reverts with "is not declared" (as validated by `crates/blockifier/src/execution/syscalls/syscall_tests/replace_class.rs`).
4. When the same syscall trace is executed by the Starknet OS Cairo program (`execute_replace_class` in `syscall_impls.cairo`), no equivalent declaration check exists — the OS would unconditionally accept the mutation, writing the undeclared `class_hash` into `contract_state_changes`, producing a state diff/state root inconsistent with what the blockifier-driven sequencer would have produced for the same transaction.

func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}

// Calculates and returns the global state root given the contract state root and
// the contract class state root.
// If both the contract class and contract state trees are empty, the global root is set to 0.
// If the contract class tree is empty, the global state root is equal to the
// contract state root (for backward compatibility);
// Otherwise, the global root is obtained by:
//     global_root = H(GLOBAL_STATE_VERSION, contract_state_root, contract_class_root).
func calculate_global_state_root{poseidon_ptr: PoseidonBuiltin*, range_check_ptr}(
    contract_state_root: felt, contract_class_root: felt
) -> (global_root: felt) {
    if (contract_state_root == 0 and contract_class_root == 0) {
        // The state is empty.
        return (global_root=0);
    }

    tempvar elements: felt* = new (GLOBAL_STATE_VERSION, contract_state_root, contract_class_root);
    let (global_root) = poseidon_hash_many(n=3, elements=elements);
    return (global_root=global_root);
}
