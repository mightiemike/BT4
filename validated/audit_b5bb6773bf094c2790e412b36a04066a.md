## Analysis: Missing Slippage Protection Analog in Push Chain's Gas-Abstraction Auto-Swap

The reported bug class — a mint/conversion amount derived from a live, manipulable on-chain price with no meaningful slippage protection — has a direct analog in Push Chain's gas-abstraction (`GAS` / `GAS_AND_PAYLOAD`) inbound execution path, where PRC20→PC swaps are quoted via a Uniswap V3 **spot-price** call and protected only by a protocol-hardcoded 5% tolerance instead of user-supplied `minAmountOut`.

### Title
Hardcoded 5% slippage on spot-price swap quote in gas-abstraction auto-swap enables value extraction - (File: x/uexecutor/keeper/execute_inbound_gas.go, x/uexecutor/keeper/execute_inbound_gas_and_payload.go)

### Summary
When a user bridges native/PRC20 gas funds into Push Chain via a `GAS` or `GAS_AND_PAYLOAD` inbound, the `uexecutor` module deposits the PRC20 representation and immediately auto-swaps it into WPC/PC through the UniversalCore's Uniswap V3 integration. The expected output is obtained via `GetSwapQuote`, a **spot-price** call (`QuoterV2.quoteExactInputSingle` with `SqrtPriceLimitX96=0`), and the acceptable slippage is a fixed, non-configurable 5% band computed from that same spot quote, exactly analogous to the SafEth `preDepositPrice`/`mintAmount` pattern with no user-controlled `minMintAmountOut`.

### Finding Description
`ExecuteInboundGas` [1](#0-0)  and `gasAndPayloadDepositAutoSwap` [2](#0-1)  both:
1. Fetch a live swap quote via `k.GetSwapQuote`, which performs a static call to `QuoterV2.quoteExactInputSingle` using the pool's current spot state (`SqrtPriceLimitX96: big.NewInt(0)`), i.e. no TWAP or manipulation-resistant price source. [3](#0-2) 
2. Compute `minPCOut = quote * 95 / 100` — a hardcoded 5% slippage tolerance derived from that same spot quote, with no way for the depositing user to specify a tighter or context-aware `minAmountOut`.
3. Immediately execute `CallPRC20DepositAutoSwap` / `depositPRC20WithAutoSwap` using this `minPCOut`. [4](#0-3) 

The same pattern recurs in outbound gas-refund swaps via `applyGasRefund`, which uses `GetDefaultFeeTierForToken` + `getSwapQuoteForRefund` and the identical `quote * 95 / 100` formula before calling `CallUniversalCoreRefundUnusedGas`. [5](#0-4) 

Because the quote source is the pool's instantaneous spot price rather than a time-weighted or otherwise manipulation-resistant oracle, and the tolerance band is a fixed 5% rather than a caller-supplied minimum, an unprivileged actor who can influence the PRC20/WPC pool's spot price (via ordinary swaps against the same pool, which is reachable by any external user with no privileged role) can cause every gas-abstraction deposit or gas-refund swap processed while the price is skewed to execute at a degraded rate, extracting the difference. This mirrors the SafEth finding precisely: reliance on a live, unprotected price feed for a value-conversion step, with the "slippage protection" being a fixed percentage computed from the same corruptible price rather than an independently-set, user-supplied bound.

### Impact Explanation
Each `GAS` / `GAS_AND_PAYLOAD` inbound and each outbound gas refund passes user or protocol-owned PRC20/native value through this quote-then-swap flow. A skewed spot price at swap time directly reduces the PC/WPC actually credited to the user's UEA (or refund recipient) relative to fair value, while the difference is realized as extractable value in the pool — this is a fund-drain vector against ordinary bridging users, falling under "unauthorized... corruption of ... gas fee accounting, refund accounting ... token mapping" in the allowed impact set, triggered purely by unprivileged, default transaction submission (ordinary swaps on the pool) with no compromised validator or admin action required.

### Likelihood Explanation
Gas-abstraction inbounds and gas refunds are core, frequently-exercised paths (every bridged transaction using PRC20-denominated gas triggers this swap). The quote is fetched and consumed non-atomically relative to the user's original bridge transaction — inbound execution happens only after UV quorum is reached across multiple blocks, giving an attacker a practical window to move the pool's spot price beforehand, especially against lower-liquidity PRC20/WPC pairs. The 5% band is generous enough to absorb typical single-block manipulation without reverting, so the attack does not even require reverting/retrying transactions.

### Recommendation
Replace the fixed 5%-of-spot-quote tolerance with either: (a) a TWAP-based or otherwise manipulation-resistant reference price for computing `minPCOut`, and/or (b) a caller/context-supplied maximum-slippage parameter validated against a sane protocol ceiling, rather than deriving both the reference price and the tolerance from the same single spot-price read immediately before executing the swap.

### Proof of Concept
1. Attacker observes a large `GAS`/`GAS_AND_PAYLOAD` inbound awaiting UV quorum (visible from pending inbound votes).
2. Attacker swaps a large amount through the same PRC20/WPC Uniswap V3 pool used by UniversalCore, shifting the spot price unfavorably for the pending deposit's swap direction.
3. When UV quorum finalizes the inbound, `GetSwapQuote` [6](#0-5)  returns the now-skewed spot quote; `minPCOut = quote*95/100` is computed from this already-bad price and the swap executes without reverting. [7](#0-6) 
4. Attacker reverses their initial swap, capturing the spread; the bridging user receives materially less PC/WPC than fair value for their bridged funds.

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)
}
