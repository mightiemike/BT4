### Title
Textproto Field-Name Injection via Unvalidated `Any.type_url` in `marshalAny` - ([File: encoding/prototext/encode.go])

### Summary
`prototext.MarshalOptions.marshal` expands `google.protobuf.Any` fields when the resolver can resolve their `type_url`. The expansion writes the raw, attacker-controlled `type_url` string directly into the text-format output as a field name via `WriteName`, which performs **no escaping or validation** of special text-format syntax characters (`]`, `"`, `{`, `}`, newlines). An attacker who controls the bytes of an `Any.type_url` field inside an otherwise normal, trusted-schema protobuf message can inject arbitrary fabricated field/value text into the serialized textproto output, exactly analogous to the HTTPX2 report where unvalidated `content_type`/header values were spliced into multipart headers without checking for CR/LF/field-terminating characters.

### Finding Description
`FindMessageByURL` in `reflect/protoregistry/registry.go` only checks the substring **after the last `/`** against the registered full name; everything before that slash (the "URL prefix") is completely unvalidated: [1](#0-0) 

`prototext`'s `marshalAny` uses the resolved `typeURL` (attacker-controlled, taken straight from the decoded `Any.type_url` field) and writes it unescaped as a field name: [2](#0-1) 

`Encoder.WriteName` performs zero escaping — it simply appends the raw bytes followed by `:`, unlike `WriteString`, which properly escapes quotes, backslashes and control characters: [3](#0-2) [4](#0-3) 

Because `WriteName` is only ever meant to be called with trusted schema-derived names (field names, map key/value literals such as `"key"`/`"value"`, unknown-field numbers), it was never designed to sanitize its input. `marshalAny`, however, is the one call site where the name is not schema-derived but comes from message *content* (`Any.type_url`), which is fully attacker-controlled whenever an unprivileged caller can supply a protobuf message containing an `Any` field over an ordinary binary/ProtoJSON API. If `type_url` contains a `]` character, it prematurely closes the `[...]` any-name token; anything that follows (including newlines, additional `name: "value"` pairs, or nested `{ }` blocks) becomes indistinguishable from genuinely emitted text-format content.

### Impact Explanation
Any service that decodes an untrusted (but schema-conformant) protobuf/ProtoJSON message containing a `google.protobuf.Any` field and later re-serializes that message with `prototext.Marshal`/`Format` (common for logging, debug dumps, or textproto-based inter-service payloads) can have its output text-format stream corrupted with attacker-fabricated fields. If that emitted textproto is subsequently parsed again by another component (e.g., a debug tool, log processor, or a second service that trusts the textproto shape), the injected fields could spoof values or alter structure that was never present in the original decoded message — a parser-confusion/injection primitive structurally identical to the CRLF header-injection class in the report. This is capped at Medium because it requires a downstream consumer that re-parses or otherwise trusts the generated textproto; it does not by itself corrupt in-memory state or bypass in-process checks.

### Likelihood Explanation
Reaching this requires only: (1) a service parsing ordinary, schema-known protobuf/JSON from an unprivileged client, where the message includes (or an attacker can nest) a `google.protobuf.Any` submessage, and (2) that service subsequently calling `prototext.Marshal`/`Format` on the message (very common for logging/debugging text output of protobuf messages). No malicious resolver, custom descriptors, or privileged access are required — `protoregistry.GlobalTypes.FindMessageByURL` with its standard, unmodified "match suffix after last `/`" behavior is sufficient.

### Recommendation
In `encoding/prototext/encode.go`'s `marshalAny`, validate/escape `typeURL` before embedding it as a field name (reject or percent-encode characters `]`, `"`, control characters, and other text-format-significant bytes), or restrict the type-name/name payload to the same character class enforced by the decoder's `parseTypeName` (`internal/encoding/text/decode.go`, lines 427-524) so that emitted output is guaranteed re-parseable and free of injected syntax.

### Proof of Concept
```go
package main

import (
	"fmt"

	"google.golang.org/protobuf/encoding/prototext"
	"google.golang.org/protobuf/proto"
	"google.golang.org/protobuf/types/known/anypb"
	"google.golang.org/protobuf/types/known/wrapperspb"
)

func main() {
	inner := wrapperspb.String("hello")
	valueBytes, _ := proto.Marshal(inner)

	// Attacker-controlled Any.type_url, decoded from an ordinary
	// binary/ProtoJSON request. FindMessageByURL only checks the suffix
	// after the last '/', so this still resolves to StringValue.
	maliciousURL := "malicious]\n  injected_field: \"evil\"\n[type.googleapis.com/google.protobuf.StringValue"

	any := &anypb.Any{
		TypeUrl: maliciousURL,
		Value:   valueBytes,
	}

	out, err := prototext.MarshalOptions{Multiline: true}.Marshal(any)
	if err != nil {
		panic(err)
	}
	fmt.Println(string(out))
	// Output contains an injected, unescaped "injected_field" text-format
	// field that was never part of the original decoded message.
}
```

func (r *Types) FindMessageByURL(url string) (protoreflect.MessageType, error) {
	// This function is similar to FindMessageByName but
	// truncates anything before and including '/' in the URL.
	if r == nil {
		return nil, NotFound
	}
	if r == GlobalTypes {
		globalMutex.RLock()
		defer globalMutex.RUnlock()
	}
	message := protoreflect.FullName(url)
	if i := strings.LastIndexByte(url, '/'); i >= 0 {
		message = message[i+len("/"):]
	}

	if v := r.typesByName[message]; v != nil {
		if mt, _ := v.(protoreflect.MessageType); mt != nil {
			return mt, nil
		}
		return nil, errors.New("found wrong type: got %v, want message", typeName(v))
	}
	return nil, NotFound
}

func appendString(out []byte, in string, outputASCII bool) []byte {
	out = append(out, '"')
	i := indexNeedEscapeInString(in)
	in, out = in[i:], append(out, in[:i]...)
	for len(in) > 0 {
		switch r, n := utf8.DecodeRuneInString(in); {
		case r == utf8.RuneError && n == 1:
			// We do not report invalid UTF-8 because strings in the text format
			// are used to represent both the proto string and bytes type.
			r = rune(in[0])
			fallthrough
		case r < ' ' || r == '"' || r == '\\' || r == 0x7f:
			out = append(out, '\\')
			switch r {
			case '"', '\\':
				out = append(out, byte(r))
			case '\n':
				out = append(out, 'n')
			case '\r':
				out = append(out, 'r')
			case '\t':
				out = append(out, 't')
			default:
				out = append(out, 'x')
				out = append(out, "00"[1+(bits.Len32(uint32(r))-1)/4:]...)
				out = strconv.AppendUint(out, uint64(r), 16)
			}
			in = in[n:]
		case r >= utf8.RuneSelf && (outputASCII || r <= 0x009f):
			out = append(out, '\\')
			if r <= math.MaxUint16 {
				out = append(out, 'u')
				out = append(out, "0000"[1+(bits.Len32(uint32(r))-1)/4:]...)
				out = strconv.AppendUint(out, uint64(r), 16)
			} else {
				out = append(out, 'U')
				out = append(out, "00000000"[1+(bits.Len32(uint32(r))-1)/4:]...)
				out = strconv.AppendUint(out, uint64(r), 16)
			}
			in = in[n:]
		default:
			i := indexNeedEscapeInString(in[n:])
			in, out = in[n+i:], append(out, in[:n+i]...)
		}
	}
	out = append(out, '"')
	return out
}
