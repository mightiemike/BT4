This confirms the analog vulnerability. `MsgMigrateUEA` is registered as a gasless message type alongside `MsgExecutePayload` in `app/txpolicy/gasless.go`, meaning the Cosmos-level tx fee is skipped for both. But `k.Keeper.ExecutePayload` (in `x/uexecutor/keeper/msg_execute_payload.go`) enforces `DeductGasFeesFromReceipt` after `CallUEAExecutePayload` to bill the UEA's own on-chain balance for the real EVM gas consumed — while `k.Keeper.MigrateUEA` (in `x/uexecutor/keeper/msg_migrate_uea.go`) calls `CallUEAMigrateUEA` (which internally uses the same `DerivedEVMCall` primitive, `commit=true`, `gasless=false`, `isModuleSender=false`) but never calls `DeductGasFeesFromReceipt` or any other fee-accounting step afterward.

### Title
Missing gas-fee accounting in `MsgMigrateUEA` allows free, unbilled EVM execution against any UEA - (File: `x/uexecutor/keeper/msg_migrate_uea.go`)

### Summary
`MsgMigrateUEA` is a gasless Cosmos message (`app/txpolicy/gasless.go`) whose EVM-side execution goes through the same `DerivedEVMCall` primitive as `MsgExecutePayload`. `ExecutePayload` closes the accounting gap by calling `k.DeductGasFeesFromReceipt` right after the derived EVM call so the UEA's own `upc` balance pays for the real gas consumed. `MigrateUEA` performs the analogous derived EVM call (`CallUEAMigrateUEA`) but has no equivalent fee-deduction step, so the gas cost of executing `migrateUEA` on the target UEA is never billed to anyone.

### Finding Description
`k.Keeper.MigrateUEA` in [1](#0-0)  resolves the target UEA and calls `k.CallUEAMigrateUEA(sdkCtx, evmFrom, ueaAddr, migrationPayload, signatureVal)` and then returns `nil` on success — no `DeductGasFeesFromReceipt` call, no `CacheContext` fee-rollback wrapper, unlike every other production entry point that performs a real, gas-consuming `DerivedEVMCall` against a UEA:

- `ExecutePayload` bills the UEA via `DeductGasFeesFromReceipt` and rolls back the whole Cosmos tx if fee deduction fails: [2](#0-1) 
- `ExecutePayloadV2` wraps the EVM call and fee deduction in a `CacheContext` so a failed deduction discards the EVM state change: [3](#0-2) 
- Inbound CEA smart-contract execution paths do the same cache-wrap + `DeductGasFeesFromReceipt` pattern: [4](#0-3) 

`CallUEAMigrateUEA` issues the migration call through `DerivedEVMCall` with `commit=true, gasless=false, isModuleSender=false`: [5](#0-4) . Per `DERIVED_TRANSACTIONS.md`, "every Push Chain call site passes `gasless=false`" purely so the receipt carries `gas_used` for observability — the actual billing of that gas is a keeper-level responsibility performed explicitly via `DeductGasFeesFromReceipt`, exactly as the README documents for `MsgExecutePayload`: "The actual EVM execution gas is deducted from this UEA's balance (`DeductGasFeesFromReceipt`), not from the signer." [6](#0-5) . `MigrateUEA` never performs this step, so `DerivedEVMCall`'s "commit" simply mutates EVM state (the UEA's implementation pointer) with `gas_used` populated in the receipt for observability only — nobody's balance is ever debited for it.

Additionally, the README states this message path was supposed to be removed entirely ("There used to be a separate `MsgMigrateUEA` message; that path has been removed... The Cosmos layer no longer has a dedicated migration message") [7](#0-6) , yet the message, its `MsgServer.MigrateUEA` handler, and its gasless registration are all still live in the codebase: [8](#0-7) [9](#0-8) . This is the direct structural analog of the external report: a documented/expected authorization or accounting invariant ("gas execution is always billed to the UEA") is enforced on the primary path (`ExecutePayload`) but silently missing on an alternate, still-reachable path (`MigrateUEA`) that performs the equivalent underlying state-changing operation.

### Impact Explanation
Any unprivileged external account can submit `MsgMigrateUEA` (gasless — the Cosmos-level tx fee is waived per `IsGaslessTx`) targeting an arbitrary `UniversalAccountId`/UEA, triggering a real, state-changing EVM call (`migrateUEA`) whose gas is fully unaccounted: not charged to the Cosmos signer (gasless), not charged to the UEA (no `DeductGasFeesFromReceipt` call), and not charged to any module account either. This breaks the gas-fee/refund accounting invariant this codebase otherwise enforces uniformly across all UEA-execution paths, letting an attacker force the network to process arbitrary amounts of free EVM computation via repeated `MsgMigrateUEA` submissions (bounded only by the UEA's own migration-authorization check inside the contract, i.e. a valid signature for *some* owner's UEA is still required to change that UEA's implementation, but the call is executed and receipted regardless of signature success up to the point of revert, and even reverting calls burn real validator CPU for free).

### Likelihood Explanation
High. The message type is already gasless-allowlisted and fully wired end-to-end (proto, `MsgServer`, keeper). No privileged role, validator cooperation, or race condition is required — a single unprivileged account submitting `MsgMigrateUEA` with a syntactically valid `MigrationPayload`/`UniversalAccountId` reaches the vulnerable code path deterministically every time.

### Recommendation
Either remove `MsgMigrateUEA` entirely (per the README's stated intent, since migration is meant to happen exclusively through `MsgExecutePayload` payloads calling the UEA's own migration entry point) and drop it from `GaslessMsgTypes`, or bring `k.Keeper.MigrateUEA` in line with `ExecutePayload`/`ExecutePayloadV2`: wrap `CallUEAMigrateUEA` in a `CacheContext`, call `k.DeductGasFeesFromReceipt` against the resolved UEA address afterward, and roll back the EVM state if fee deduction fails.

### Proof of Concept
1. Attacker (any funded-or-unfunded Cosmos account, since the tx is gasless) submits `MsgMigrateUEA{ Signer: attacker, UniversalAccountId: <any owner>, MigrationPayload: {...}, Signature: <any/attacker-forged> }`.
2. `msgServer.MigrateUEA` → `k.Keeper.MigrateUEA` resolves the UEA via `CallFactoryToGetUEAAddressForOrigin`, requires only that the UEA be already deployed (`isDeployed == true`) — no relation to the attacker's identity required: [10](#0-9) .
3. `k.CallUEAMigrateUEA` issues a real `DerivedEVMCall` (`commit=true`) that executes and receipts `gas_used`, but the function returns without ever calling `DeductGasFeesFromReceipt` or any other fee/refund step: [11](#0-10) .
4. Repeat arbitrarily — each call is a real state-changing/computation-consuming EVM transaction billed to no one, since the outer Cosmos tx is also gasless per `IsGaslessTx`.

	sdkCtx := sdk.UnwrapSDKContext(ctx)

	// Get Caip2Identifier for the universal account
	caip2Identifier := universalAccountId.GetCAIP2()

	k.Logger().Info("migrate UEA",
		"from", evmFrom.Hex(),
		"chain", caip2Identifier,
		"owner", universalAccountId.Owner,
	)

	// Step 1: Parse and validate payload and signature
	_, err := types.NewAbiMigrationPayload(migrationPayload)
	if err != nil {
		return errors.Wrapf(err, "invalid migration payload")
	}

	// add signature verification
	signatureVal, err := utils.HexToBytes(signature)
	if err != nil {
		return errors.Wrapf(err, "invalid signature format")
	}

	chainConfig, err := k.uregistryKeeper.GetChainConfig(sdkCtx, caip2Identifier)
	if err != nil {
		return errors.Wrapf(err, "failed to get chain config for chain %s", caip2Identifier)
	}

	// TODO: Decide later if migration should be disabled if inbound is disabled
	if !chainConfig.Enabled.IsInboundEnabled {
		k.Logger().Warn("migrate UEA rejected: chain not enabled", "chain", caip2Identifier)
		return fmt.Errorf("chain %s is not enabled", caip2Identifier)
	}

	factoryAddress := common.HexToAddress(types.FACTORY_PROXY_ADDRESS_HEX)

	// Step 2: Compute smart account address
	// Calling factory contract to compute the UEA address
	ueaAddr, isDeployed, err := k.CallFactoryToGetUEAAddressForOrigin(sdkCtx, evmFrom, factoryAddress, universalAccountId)
	if err != nil {
		return err
	}

	if !isDeployed {
		k.Logger().Warn("migrate UEA rejected: UEA not deployed", "chain", caip2Identifier, "owner", universalAccountId.Owner)
		return fmt.Errorf("UEA is not deployed")
	}

	k.Logger().Debug("migrating UEA",
		"uea", ueaAddr.Hex(),
		"chain", caip2Identifier,
		"from", evmFrom.Hex(),
	)

	// Step 3: Migrate UEA through UEA
	receipt, err := k.CallUEAMigrateUEA(sdkCtx, evmFrom, ueaAddr, migrationPayload, signatureVal)
	if err != nil {
		return err
	}

	k.Logger().Info("UEA migrated",
		"chain", caip2Identifier,
		"uea", ueaAddr.Hex(),
		"tx_hash", receipt.Hash,
		"gas_used", receipt.GasUsed,
	)

	return nil
}
