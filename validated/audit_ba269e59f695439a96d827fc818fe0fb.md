### Title
Refund swap uses an on-chain spot quote with fixed 5% slippage, allowing sandwich manipulation of gas-refund value - ([File: x/uexecutor/keeper/outbound.go])

### Summary
The excess-gas refund path (`applyGasRefund` → `getSwapQuoteForRefund` → `CallUniversalCoreRefundUnusedGas`) prices the gas-token-to-PC swap using a live Uniswap V3 quoter call taken at the moment the outbound vote finalizes, then only enforces a fixed 95%-of-quote (`minPCOut`) slippage floor. This mirrors the C4 Particle bug class: a value used to determine how much of a protocol-held asset is paid out is read as a spot on-chain price at settlement time rather than being bounded/committed earlier, letting an unprivileged actor manipulate the pool immediately before settlement to skew the payout. [1](#0-0) 

### Finding Description
When an outbound vote reaches quorum, `handleSuccessfulOutbound`/`handleFailedOutbound` call `applyGasRefund`, which computes `refundAmount = gasFee - gasFeeUsed` and then attempts a swap-based refund: [2](#0-1) 

`getSwapQuoteForRefund` fetches quoter/WPC addresses and calls `GetSwapQuote`, a static `CallEVM` against the on-chain Uniswap V3 quoter, evaluated at the exact block/tx in which the finalizing `MsgVoteOutbound` lands: [3](#0-2) 

The quote is then used to derive `minPCOut` with a hardcoded 5% tolerance and passed straight into `CallUniversalCoreRefundUnusedGas`, which performs the actual swap and pays out PC to the refund recipient: [4](#0-3) [5](#0-4) 

Because the vote that triggers this swap is a normal, publicly visible mempool transaction (any of the quorum-completing `MsgVoteOutbound` submissions), and the pool used for the swap is a permissionless on-chain Uniswap V3 pool, an unprivileged actor can:
1. Observe the pending `MsgVoteOutbound` that will push the outbound to quorum (2/3 UV threshold).
2. Submit a trade against the `gasToken`/WPC pool in the same block, immediately before that vote transaction, to move the spot price in a favorable direction.
3. The quote read inside `getSwapQuoteForRefund` reflects the manipulated spot price, and `minPCOut` is derived from that same manipulated quote (not from an independent, pre-committed price), so the 5% floor does not protect against price manipulation — it only bounds slippage relative to an already-skewed reference.
4. The attacker can then reverse their trade after the refund swap executes (or arbitrage against it), extracting value that would otherwise go to the refund recipient/protocol, analogous to how the Particle lender manipulated Uniswap V3 fee growth to inflate the value read at settlement time.

This is the same root cause pattern as the C4 finding: a payout-determining numeric value is sourced from a manipulable, unbonded live on-chain price/fee oracle at the exact settlement instant, with only a percentage-of-that-same-value guard rather than a guard anchored to an independent reference.

### Impact Explanation
A successful sandwich reduces the PC amount actually delivered to the refund recipient (or extracts value that should net to the protocol/recipient), i.e., unauthorized diversion of protocol/user-controlled funds during the refund/accounting path — in scope under "corruption of ... refund accounting" and "unauthorized ... refund of user or protocol-controlled funds." The magnitude is bounded by the 5% slippage window per refund event, and requires an attacker to have capital in the specific gasToken/WPC pool and to win the same-block ordering race, which limits practicality similar to the original Particle finding (judged Medium there due to impracticality but non-zero feasibility).

### Likelihood Explanation
Low-to-Medium. The attacker needs: (a) visibility of pending outbound votes about to reach quorum (public mempool), (b) enough capital to move the specific gas-token pool's spot price meaningfully within the 5% tolerance, and (c) to land a trade in the same block ahead of the quorum vote. Refund amounts (excess gas fee) tend to be small relative to the capital needed to manipulate a pool profitably, similar to the original finding's economic-impracticality caveat, but the mechanism itself is a genuine reachable, unprivileged manipulation path with no confirmed guard against it in this code.

### Recommendation
- Do not derive `minPCOut` purely as a percentage of a spot quote fetched in the same transaction that performs the swap; use a TWAP (time-weighted average price) from the pool, or a price bounded by a previously observed/attested reference (e.g., last chain-meta gas price or an oracle-anchored value) instead of the instantaneous quoter result.
- Alternatively, cap or fix the refund's acceptable slippage against a governance/keeper-configured reference price rather than self-referential spot quote, similar to the audit's own recommendation to cap premium/fee rather than trust spot values.
- Consider decoupling refund-swap execution timing from the exact block of the quorum-completing vote (e.g., process in a later block) to reduce the attacker's ability to predict and front-run the settlement instant.

### Proof of Concept
Conceptual PoC (cannot be executed without live pool/state):
1. Attacker monitors mempool for the 2nd/3rd `MsgVoteOutbound` on a given `utxId` that will cross UV quorum for an outbound with a swap-eligible `GasToken` refund.
2. Attacker submits a large trade against the `gasToken`⇄WPC Uniswap V3 pool referenced by `GetUniversalCoreQuoterAddress`/`GetUniversalCoreWPCAddress`, timed to land in the same block immediately before the quorum vote transaction.
3. The quorum vote executes `applyGasRefund` → `getSwapQuoteForRefund`, reading the now-skewed spot quote, and computes `minPCOut` as 95% of that skewed value. [6](#0-5) 
4. `CallUniversalCoreRefundUnusedGas` executes the swap using this skewed `minPCOut`, and the attacker reverses their initial trade afterward, capturing the spread while the refund recipient/protocol receives a suboptimal PC amount within the "protected" but manipulated 5% band.

Note: I was not able to inspect the `UniversalCore.sol` contract's `refundUnusedGas` implementation (out of this repo's Go-only scope) to confirm exactly how `minPCOut` is enforced on-chain; this analysis is based on the Go-side call construction in `x/uexecutor/keeper/outbound.go` and `evm.go`, which is what this repository controls.

// applyGasRefund computes the excess gas (gasFee - gasFeeUsed) and, if positive,
// calls UniversalCore refundUnusedGas. The result is recorded in outbound.PcRefundExecution.
// It is called for both successful and failed outbounds — gas is consumed on the
// external chain regardless of execution outcome.
func (k Keeper) applyGasRefund(ctx sdk.Context, outbound *types.OutboundTx, obs *types.OutboundObservation) {
	if obs.GasFeeUsed == "" || outbound.GasFee == "" || outbound.GasToken == "" {
		return
	}

	gasFee := new(big.Int)
	if _, ok := gasFee.SetString(outbound.GasFee, 10); !ok {
		return
	}

	gasFeeUsed := new(big.Int)
	if _, ok := gasFeeUsed.SetString(obs.GasFeeUsed, 10); !ok {
		return
	}

	// No excess gas to refund
	if gasFee.Cmp(gasFeeUsed) <= 0 {
		return
	}

	refundAmount := new(big.Int).Sub(gasFee, gasFeeUsed)
	gasToken := common.HexToAddress(outbound.GasToken)

	// Refund recipient: prefer fund_recipient in revert_instructions, fall back to sender
	refundRecipient := outbound.Sender
	if outbound.RevertInstructions != nil && outbound.RevertInstructions.FundRecipient != "" {
		refundRecipient = outbound.RevertInstructions.FundRecipient
	}
	recipientAddr := common.HexToAddress(refundRecipient)

	refundPcTx := &types.PCTx{
		Sender:      outbound.Sender,
		BlockHeight: uint64(ctx.BlockHeight()),
	}

	// Step 1: try refund with swap (gasToken → PC native)
	fee, swapErr := k.GetDefaultFeeTierForToken(ctx, gasToken)
	var swapFallbackReason string

	if swapErr == nil {
		quote, quoteErr := k.getSwapQuoteForRefund(ctx, gasToken, fee, refundAmount)
		if quoteErr == nil {
			minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
			minPCOut.Div(minPCOut, big.NewInt(100))

			resp, err := k.CallUniversalCoreRefundUnusedGas(ctx, gasToken, refundAmount, recipientAddr, true, fee, minPCOut)
			if err == nil {
				refundPcTx.TxHash = resp.Hash
				refundPcTx.GasUsed = resp.GasUsed
				refundPcTx.Status = "SUCCESS"
				outbound.PcRefundExecution = refundPcTx
				return
			}
			swapFallbackReason = fmt.Sprintf("swap refund failed: %s", err.Error())
		} else {
			swapFallbackReason = fmt.Sprintf("quote fetch failed: %s", quoteErr.Error())
		}

// getSwapQuoteForRefund fetches a Uniswap quote for the gas token refund swap.
func (k Keeper) getSwapQuoteForRefund(ctx sdk.Context, gasToken common.Address, fee *big.Int, amount *big.Int) (*big.Int, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(ctx)
	if err != nil {
		return nil, err
	}
	wpcAddr, err := k.GetUniversalCoreWPCAddress(ctx)
	if err != nil {
		return nil, err
	}
	return k.GetSwapQuote(ctx, quoterAddr, gasToken, wpcAddr, fee, amount)
}

// CallUniversalCoreRefundUnusedGas calls refundUnusedGas on UniversalCore to return excess gas fee
// to the recipient. withSwap=true swaps the gas token back to PC; withSwap=false deposits PRC20 directly.
func (k Keeper) CallUniversalCoreRefundUnusedGas(
	ctx sdk.Context,
	gasToken common.Address,
	amount *big.Int,
	recipient common.Address,
	withSwap bool,
	fee *big.Int,
	minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse UniversalCore ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	// fee is uint24 in Solidity — pass as *big.Int (go-ethereum ABI packs non-standard widths as *big.Int)
	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress,
		handlerAddr,
		big.NewInt(0),
		nil,
		true,
		false,
		true,
		&nonce,
		"refundUnusedGas",
		gasToken,
		amount,
		recipient,
		withSwap,
		fee,
		minPCOut,
	)
}
