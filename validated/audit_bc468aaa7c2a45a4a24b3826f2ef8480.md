### Title
Starknet OS `replace_class` syscall re-execution skips class-declaration and version checks enforced by blockifier - ([File: crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo])

### Summary
The Starknet OS (used for re-execution/proving of a sequenced block) implements `execute_replace_class` for both the modern and deprecated syscall interfaces without verifying that the target `class_hash` corresponds to a declared class, and without rejecting a Cairo0 (V0) class hash. The Rust-side hint executors backing this Cairo code also return success unconditionally. This is inconsistent with the sequencer's actual execution engine (blockifier), which enforces both checks before mutating state. A single unprivileged transaction whose execution invokes `replace_class` with an undeclared or wrong-version class hash will therefore be handled differently by the sequencer (reverts) than by the OS re-execution that proves the block (silently "succeeds"), causing state/root divergence.

### Finding Description
Any account-abstraction contract can invoke the `replace_class` syscall from calldata supplied by an ordinary, unprivileged invoke transaction (`replace_class_syscall(class_hash)`), e.g. via `test_contract.cairo`'s `test_replace_class` entry point [1](#0-0) .

In blockifier (the engine that actually builds/validates blocks in the sequencer), `replace_class` performs two mandatory checks before mutating contract state:
1. The class must be declared (`get_compiled_class` fails otherwise).
2. The class must be Cairo1 (`is_cairo1`), otherwise `ForbiddenClassReplacement` is returned. [2](#0-1) 

The deprecated (Cairo0) syscall path in blockifier enforces the declared-class check as well: [3](#0-2) 

These checks are exercised and confirmed by blockifier's own tests, which expect an error for an undeclared class hash and for a Cairo0-replaces-Cairo1 attempt: [4](#0-3) 

However, the Starknet OS Cairo program - which re-executes the same transactions to compute the state diff/commitment that is proven and posted on-chain - implements `execute_replace_class` for the new syscall ABI with an explicit TODO acknowledging the missing check, and performs the class-hash swap unconditionally: [5](#0-4) 

The same unconditional behavior exists in the deprecated (Cairo0) syscall path of the OS program: [6](#0-5) 

The Rust hint executors that back these Cairo functions during OS execution (used both for native-blockifier-as-OS testing and for the SNOS hint processor) simply return `Ok(...)` without performing any validation, confirming that no out-of-band (hint-side) check compensates for the missing Cairo-level check: [7](#0-6) [8](#0-7) 

Root cause: the OS's `execute_replace_class` (both new-syscalls and deprecated-syscalls variants) never reads/validates the class-hash-to-compiled-class mapping (`contract_class_changes`/declared classes) before writing the new `class_hash` into `contract_state_changes`, unlike blockifier's `state.get_compiled_class(class_hash)?` + `is_cairo1` guard.

### Impact Explanation
Because the sequencer commits to blocks using blockifier's execution result (which reverts a call that performs `replace_class` with an undeclared or invalid-version class hash), but the Starknet OS - which computes the canonical state diff/commitment used for the STARK proof and L1 state update - performs the class replacement unconditionally, the two execution paths diverge on the very same transaction and block:
- Blockifier: entry point call reverts, class hash unchanged, transaction may still succeed as a whole (revert-log entry, no state change to `class_hash`).
- OS: class hash is unconditionally overwritten, potentially with a class hash that was never declared (a raw, attacker-chosen felt) or that violates the V1-cannot-be-downgraded-to-V0 invariant.

This is an "honest-node divergence" / "wrong committed root" condition per the sequencer's threat model: the state diff the OS proves does not match the state the sequencer's execution engine actually produced. Any user submitting an ordinary invoke transaction that triggers `replace_class` with a made-up/undeclared class hash can force this divergence deterministically and for free (aside from normal gas), without any privileged role. Consequences include: OS proof computing/committing an incorrect state root relative to actual sequencer state (breaking state-transition-function soundness), or an unrecoverable mismatch that halts block proving/finalization for the network.

### Likelihood Explanation
High likelihood of reachability: `replace_class_syscall` is a standard, unprivileged Cairo1 syscall reachable from any contract executed as part of any ordinary invoke transaction; no special permission or authorized account is required. The class hash parameter is fully attacker-controlled calldata. The bug is deterministic (not probabilistic) and is explicitly acknowledged by an in-code TODO in the OS Cairo source, indicating the omission is a known gap rather than a hypothetical edge case.

### Recommendation
Add the same validation to the OS's `execute_replace_class` (both `syscall_impls.cairo` and `deprecated_execute_syscalls.cairo`) that blockifier performs:
1. Look up the class in `contract_class_changes`/the declared-classes mapping and fail (or emit the same failure response blockifier would produce) if the class hash was never declared.
2. Reject the replacement if the new class is Cairo0 while being installed over/at a context that requires Cairo1 (mirroring `ForbiddenClassReplacement`), keeping semantics identical to blockifier's `is_cairo1` check.
Ensure the corresponding Rust hint executors (`snos_syscall_executor.rs`, `snos_deprecated_syscall_executor.rs`) surface this validation (or that the Cairo-level check alone is sufficient and provably equivalent to blockifier's), and add regression tests exercising an undeclared class hash and a V1→V0 downgrade through `replace_class` in the OS/virtual-OS test suite (e.g., extending `starknet_os_flow_tests`) to assert identical accept/revert behavior to blockifier.

### Proof of Concept
1. Deploy any Cairo1 account/contract exposing `test_replace_class(class_hash)` (already present as `test_contract.cairo::test_replace_class`, backed by `replace_class_syscall`).
2. Submit an ordinary invoke transaction from any funded account calling `test_replace_class` with a `class_hash` felt that has never been declared on the network (e.g., an arbitrary felt like `0xdeadbeef`).
3. In blockifier (the sequencer's actual execution), this call reverts with "... is not declared" (per `crates/blockifier/src/execution/syscalls/syscall_tests/replace_class.rs`), and the contract's class hash in the committed state is unchanged.
4. Re-run the identical block through the Starknet OS (`execute_replace_class` in `syscall_impls.cairo`/`deprecated_execute_syscalls.cairo`), which contains no equivalent declared-class check (see the TODO at `syscall_impls.cairo:902`); the OS unconditionally records `class_hash = 0xdeadbeef` into `contract_state_changes` for the contract, producing a state diff that differs from the one blockifier actually committed for that block.
5. The divergence between the sequencer's committed state and the OS-computed state diff/commitment demonstrates the vulnerability; no special privileges were used beyond sending a normal transaction.

    pub fn replace_class(&mut self, class_hash: ClassHash) -> SyscallResult<()> {
        // Ensure the class is declared (by reading it), and of type V1.
        let compiled_class = self.state.get_compiled_class(class_hash)?;

        if !is_cairo1(&compiled_class) {
            return Err(SyscallExecutionError::ForbiddenClassReplacement { class_hash });
        }
        self.state.set_class_hash_at(self.call.storage_address, class_hash)?;
        Ok(())
    }

// Replaces the class.
func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
