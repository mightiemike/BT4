Confirmed: `k.GetSwapQuote` calls the standard Uniswap V3 `QuoterV2.quoteExactInputSingle` (spot-price simulation of `swapRouter`) with `sqrtPriceLimitX96 = 0`, i.e. no bound and no TWAP — it purely reads the pool's current instantaneous price. This quote is then used to derive `minPCOut` (95% of that same spot quote) that gates the module's own real swap. Since both the quote and the slippage bound derive from the identical manipulable spot price, this is a self-referential check, structurally equivalent to the VaderPoolV2 flaw: an attacker can move the pool price first, then let the protocol's swap execute against the manipulated price under its own "protection," and reverse the manipulation afterward to extract value.

### Title
Self-referential Uniswap V3 spot-price quote lets an attacker sandwich protocol-executed gas-abstraction and gas-refund swaps to drain WPC/PRC20 pool liquidity - (File: x/uexecutor/keeper/evm.go, x/uexecutor/keeper/execute_inbound_gas.go, x/uexecutor/keeper/execute_inbound_gas_and_payload.go, x/uexecutor/keeper/outbound.go)

### Summary
Every place Push Chain's `uexecutor` module autonomously swaps a user's bridged/PRC20 asset for the chain's native `WPC` (or vice versa for gas refunds), it derives the swap's `minPCOut` slippage floor directly from a live, unprotected `QuoterV2.quoteExactInputSingle` spot-price call against the same Uniswap-V3-style pool the swap will execute in [1](#0-0) . Because the "protection" and the manipulated value share the same manipulable source, an unprivileged attacker can move the pool price immediately before the module-triggered swap and reverse it afterward, extracting the difference — the same root cause as the VaderPoolV2 finding, applied to Push Chain's on-chain gas-abstraction AMM instead of Vader's synth pool.

### Finding Description
`GetSwapQuote` queries the pool's instantaneous price via `quoteExactInputSingle` with `SqrtPriceLimitX96: big.NewInt(0)` (no bound) [2](#0-1) . This value is then multiplied by 95% to become `minPCOut`, and passed into the actual protocol-executed swap:

- `ExecuteInboundGas` — for `TxType_GAS` inbound bridging, computes `minPCOut` from the live quote and immediately calls `CallPRC20DepositAutoSwap` with it [3](#0-2) .
- `gasAndPayloadDepositAutoSwap` — identical pattern for `GAS_AND_PAYLOAD` inbounds [4](#0-3) .
- `applyGasRefund` / `getSwapQuoteForRefund` — for outbound gas refunds swapping the leftover gas token back to PC [5](#0-4) , [6](#0-5) .

In all three cases the "5% slippage protection" bounds the swap against a price the attacker themselves can set moments earlier via ordinary, permissionless swaps on the same pool (the pool and its Uniswap V3 `SwapRouter`/`Quoter` are ordinary EVM contracts reachable by any user, as configured via `UniversalCore.initialize(wpc_, uniswapV3Factory_, uniswapV3SwapRouter_, uniswapV3Quoter_)` [7](#0-6) ). Nothing in `GetSwapQuote` or its callers consults a TWAP, an external oracle, or any manipulation-resistant reference price — it is exactly the "exchange rate calculated from mutable reserves, then used unguarded for value-transferring mint/swap logic" pattern described in the source report.

### Impact Explanation
The `uexecutor` module executes these swaps as the module account (protocol-derived transactions, not user-signed), moving real `WPC`/native value and PRC20 balances out of the pool on behalf of users' bridged funds and gas refunds [8](#0-7) . An attacker who first depresses the PRC20→WPC price and then triggers/uses their own gas-abstraction inbound (or refund) will have the module swap at the manipulated rate, causing the pool to release more WPC than fair value to the attacker's UEA; the attacker then reverses their initial trade to restore the price and pocket the gap. This directly drains protocol/LP-controlled pool liquidity and corrupts gas-fee/refund accounting, matching the in-scope impact of "draining of protocol-controlled funds" and "corruption of PRC20 or native asset accounting, gas fee accounting, refund accounting."

### Likelihood Explanation
The trigger requires only unprivileged, ordinary user actions: (1) submit normal swap transactions against the pool to move its price, and (2) submit a normal bridge inbound (or trigger a gas refund) that goes through the honest, unmodified `ExecuteInboundGas`/`gasAndPayloadDepositAutoSwap`/`applyGasRefund` code paths with honest validators/nodes. No validator collusion, TSS compromise, or admin action is needed — the attacker only needs enough capital/leverage to move the pool for one block, and the 5% band offers no real protection since it is derived from the same manipulated price.

### Recommendation
Do not derive `minPCOut` solely from the current-block `QuoterV2` spot quote. Compare the spot quote against an independent, manipulation-resistant reference (e.g., a TWAP over several blocks from the same pool, or the `chainMeta`/gas-price oracle already used elsewhere for cross-chain pricing) and reject or clamp swaps whose spot price deviates too far from that reference. Alternatively, cap the per-block price impact allowed for module-triggered swaps, or route these mandatory swaps through a protected/whitelisted liquidity source rather than an open, freely swappable AMM pool.

### Proof of Concept
1. Attacker holds PRC20 and WPC and observes the `WPC`/`PRC20` Uniswap-V3-style pool referenced by `UniversalCore` (`uniswapV3Quoter`, `WPC` getters in `x/uexecutor/types/abi.go` lines 369–382).
2. Attacker submits an ordinary large swap through the pool's `SwapRouter` to push the PRC20→WPC spot price far above fair value.
3. Attacker (or any user, but easiest for the attacker's own account) triggers a `GAS`/`GAS_AND_PAYLOAD` bridge inbound for a modest PRC20 amount; once validators vote it to quorum, `ExecuteInboundGas`/`gasAndPayloadDepositAutoSwap` calls `GetSwapQuote` which returns the inflated quote, computes `minPCOut = quote*95/100` from it, and calls `CallPRC20DepositAutoSwap`, which the module executes against the same manipulated pool — releasing an outsized amount of WPC to the attacker's UEA [9](#0-8) .
4. Attacker reverses step 2 (sells the WPC back for PRC20), restoring the pool to its original price and net-realizing the manipulated spread as profit, paying only pool fees and gas.
5. Repeat for each new inbound/refund, and analogously for `applyGasRefund` swapping gas tokens back to PC on outbound completion.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}
