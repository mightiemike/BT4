### Title
Spot-price Uniswap V3 quote used as slippage protection for PRC20 gas-abstraction auto-swap enables sandwich/flash-loan value extraction - (File: x/uexecutor/keeper/execute_inbound_gas.go, x/uexecutor/keeper/execute_inbound_gas_and_payload.go, x/uexecutor/keeper/evm.go)

### Summary
`GetSwapQuote` [1](#0-0)  calls `QuoterV2.quoteExactInputSingle` against the pool configured via `GetUniversalCoreQuoterAddress`, reading the instantaneous on-chain price rather than a time-weighted average. This quote is used, in the very same transaction, to compute `minPCOut` (a 5% fixed-slippage floor) which is passed straight into `CallPRC20DepositAutoSwap`, executing the real swap in `ExecuteInboundGas` [2](#0-1)  and in `gasAndPayloadDepositAutoSwap` [3](#0-2) . Because quote-then-swap happens atomically inside a single Push Chain block/transaction with no TWAP or external reference price, this is the same class of bug as the reported oracle: the pool's spot state can be pushed away from fair value and back within the same block by an attacker who front-runs the honest module-originated swap (e.g. via a bot submitting a large swap against the same pool just before the validator-driven inbound execution lands, since inbound processing timing/ordering is observable and not attacker-authenticated).

### Finding Description
The gas-abstraction auto-swap flow (`ExecuteInboundGas` / `ExecuteInboundGasAndPayload`) is triggered automatically whenever a user submits a cross-chain inbound deposit that needs its native asset PRC20 converted to WPC to pay gas. The flow:
1. Fetches `quoterAddr`, `wpcAddr`, `fee` from `UniversalCore` [4](#0-3) .
2. Calls `GetSwapQuote` → `quoteExactInputSingle` for a **read-only, current-block, current-pool-state** quote [1](#0-0) .
3. Derives `minPCOut = quote * 95 / 100` and immediately calls `depositPRC20WithAutoSwap` with that bound [5](#0-4) .

Because the quote and the swap execute back-to-back with no time separation and no TWAP, an unprivileged attacker can manipulate the pool's spot price immediately before this module-originated swap executes (the pool is presumably an ordinary Uniswap-V3-style pool on Push Chain that anyone can trade against), causing `GetSwapQuote` to return a price that is temporarily depressed. Since `minPCOut` is derived directly from that same manipulated `quote`, the 5% slippage tolerance does not protect against this — the attacker can push the price down by more than 5% and then let the module's auto-swap execute against the manipulated pool state, extracting value (arbitrage/sandwich) at the expense of the user's PRC20 deposit that is meant to be swapped for gas.

### Impact Explanation
The auto-swap is module-originated (`ueModuleAccAddress` sender via `DerivedEVMCall`) and processes user deposit funds without user-supplied slippage input — the protocol computes the bound itself from a manipulable spot price. A successful sandwich attack causes the user's deposited PRC20 to convert into fewer WPC/native gas tokens than fair value, i.e., unauthorized loss of protocol/user-controlled funds during a canonical universal-execution state transition, matching the in-scope impact of "stealing ... permanent loss ... of user or protocol-controlled funds" and "corruption of ... gas fee accounting."

### Likelihood Explanation
Likelihood is constrained by: (a) whether the underlying Uniswap V3 pool used by `UniversalCore.uniswapV3Quoter()` has sufficient liquidity depth that manipulation is capital-efficient, and (b) whether an attacker can reliably predict/front-run when a given inbound's `ExecuteInboundGas`/`ExecuteInboundGasAndPayload` will execute (block inclusion of validator-driven inbound processing). Since inbound processing follows ballot finalization by honest Universal Validators and is not secret, an attacker monitoring pending inbounds and pool state could time a sandwich. This mirrors the external report's classification (impact: High, likelihood: Low) since it depends on pool liquidity conditions and successful transaction ordering/timing.

### Recommendation
Do not derive the slippage floor from a same-block spot quote taken immediately before the swap. Instead:
- Use a TWAP-based reference price (e.g., Uniswap V3 `observe`/oracle cardinality) for computing `minPCOut`, or
- Source an independent price reference (e.g., the `ChainMeta`/gas price oracle pattern already used elsewhere in this codebase [6](#0-5) , which aggregates multiple validator-submitted, staleness-filtered, median-computed values) rather than a single live pool read, or
- Cap acceptable price deviation against a longer-window average and abort/queue the swap if the spot price deviates beyond a safe bound.

### Proof of Concept
1. Attacker observes a pending cross-chain inbound deposit destined for gas-abstraction auto-swap (visible via mempool/ballot state prior to finalization).
2. Immediately before the Universal Validators execute `ExecuteInboundGas`, attacker submits a large swap against the same Uniswap V3 pool referenced by `uniswapV3Quoter()`/`WPC()`, depressing the PRC20→WPC price.
3. `GetSwapQuote` [1](#0-0)  returns the manipulated low quote; `minPCOut` is computed as 95% of this already-depressed value.
4. `CallPRC20DepositAutoSwap` executes against the manipulated pool, converting the user's deposit at an unfavorable rate that still satisfies the artificially-lowered `minPCOut` floor.
5. Attacker reverses their manipulating trade in a follow-up transaction, capturing the price difference extracted from the user's deposit.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

func (k Keeper) VoteChainMeta(ctx context.Context, universalValidator sdk.ValAddress, observedChainId string, price, blockNumber uint64) error {
	sdkCtx := sdk.UnwrapSDKContext(ctx)
	now := uint64(sdkCtx.BlockTime().Unix())

	entry, _, err := k.GetChainMeta(ctx, observedChainId)
	if err != nil {
		return sdkerrors.Wrap(err, "failed to fetch chain meta entry")
	}
	bootstrapped := entry.LastAppliedChainHeight > 0

	// Stale-height check applies only after bootstrap. During cold-start there
	// is no committed reference height yet, so any positive vote is acceptable.
	if bootstrapped && blockNumber <= entry.LastAppliedChainHeight {
		k.Logger().Warn("chain meta vote rejected: stale block height",
			"chain_id", observedChainId,
			"validator", universalValidator.String(),
			"vote_height", blockNumber,
			"last_applied_height", entry.LastAppliedChainHeight,
		)
		return fmt.Errorf(
			"vote chain height %d is not greater than last applied chain height %d; re-vote with a newer block",
			blockNumber, entry.LastAppliedChainHeight,
		)
	}

	// Ensure the entry has its observed-chain id set on first-ever vote.
	if entry.ObservedChainId == "" {
		entry.ObservedChainId = observedChainId
	}

	// Update or insert vote for this validator.
	var updated bool
	for i, s := range entry.Signers {
		if s == universalValidator.String() {
			entry.Prices[i] = price
			entry.ChainHeights[i] = blockNumber
			entry.StoredAts[i] = now
			updated = true
			break
		}
	}
	if !updated {
		entry.Signers = append(entry.Signers, universalValidator.String())
		entry.Prices = append(entry.Prices, price)
		entry.ChainHeights = append(entry.ChainHeights, blockNumber)
		entry.StoredAts = append(entry.StoredAts, now)
	}

	// Build a filtered pool: only votes stored within the staleness window.
	type voteSnapshot struct {
		price       uint64
		chainHeight uint64
	}
	var fresh []voteSnapshot
	for i := range entry.Signers {
		if entry.StoredAts[i] > now {
			continue // clock skew guard — skip future-stamped votes
		}
		age := now - entry.StoredAts[i]
		if age <= chainMetaVoteStalenessSeconds {
			fresh = append(fresh, voteSnapshot{
				price:       entry.Prices[i],
				chainHeight: entry.ChainHeights[i],
			})
		}
	}

	// Cold-start gate: the first EVM write requires at least N fresh votes
	// so the oracle is never defined by a single validator. Once bootstrapped,
	// the existing fresh-votes-median path handles every subsequent vote.
	if !bootstrapped && len(fresh) < chainMetaMinVotesForFirstWrite {
		k.Logger().Info("chain meta vote recorded, awaiting bootstrap quorum",
			"chain_id", observedChainId,
			"validator", universalValidator.String(),
			"have_fresh_votes", len(fresh),
			"need_fresh_votes", chainMetaMinVotesForFirstWrite,
		)
		if err := k.SetChainMeta(ctx, observedChainId, entry); err != nil {
			return sdkerrors.Wrap(err, "failed to set chain meta entry during bootstrap")
		}
		return nil
	}

	if len(fresh) == 0 {
		k.Logger().Debug("chain meta vote recorded, no fresh votes for EVM update",
			"chain_id", observedChainId,
			"validator", universalValidator.String(),
		)
		if err := k.SetChainMeta(ctx, observedChainId, entry); err != nil {
			return sdkerrors.Wrap(err, "failed to set updated chain meta entry")
		}
		return nil
	}

	// Compute independent upper medians (len/2) for price and chain height.
	medianPrice := upperMedianUint64(fresh, func(v voteSnapshot) uint64 { return v.price })
	medianChainHeight := upperMedianUint64(fresh, func(v voteSnapshot) uint64 { return v.chainHeight })

	k.Logger().Debug("chain meta medians computed",
		"chain_id", observedChainId,
		"fresh_votes", len(fresh),
		"median_price", medianPrice,
		"median_chain_height", medianChainHeight,
	)

	// Update MedianIndex to reflect the price median position in the full slice
	// (best-effort; used for storage/querying only).
	entry.MedianIndex = uint64(computeMedianIndex(entry.Prices))

	priceBig := math.NewUint(medianPrice).BigInt()
	chainHeightBig := math.NewUint(medianChainHeight).BigInt()
	if _, evmErr := k.CallUniversalCoreSetChainMeta(sdkCtx, observedChainId, priceBig, chainHeightBig); evmErr != nil {
		return sdkerrors.Wrap(evmErr, "failed to call EVM setChainMeta")
	}

	entry.LastAppliedChainHeight = medianChainHeight
	if err := k.SetChainMeta(ctx, observedChainId, entry); err != nil {
		return sdkerrors.Wrap(err, "failed to set updated chain meta entry")
	}

	k.Logger().Info("chain meta updated",
		"chain_id", observedChainId,
		"median_price", medianPrice,
		"median_chain_height", medianChainHeight,
	)

	return nil
}
