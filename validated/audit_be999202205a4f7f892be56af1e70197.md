Analysis: The Quagga CVE describes a size-calculation routine (`aspath_put`) that double-counts bytes, so the buffer eventually written diverges from the pre-computed length header, producing a malformed message sent to a peer. I searched protobuf-go for the same broken invariant — "size computed once, then writer produces a different number of bytes" — across the exact places this class of bug could occur: message field encoding, repeated/opaque message fields, map value encoding, extensions, and the legacy `message_set` wire format.

In every one of these locations, protobuf-go already computes `calculatedSize`, records `before := len(b)` prior to the actual append/marshal call, and then explicitly compares `measuredSize := len(b) - before` against `calculatedSize`, returning `errors.MismatchedSizeCalculation` if they differ, rather than silently emitting an invalid length-prefixed message: [1](#0-0) [2](#0-1) [3](#0-2) [4](#0-3) 

This is a deliberate defensive mechanism (`internal/errors.MismatchedSizeCalculation`, referencing golang/protobuf#1609) designed specifically to prevent the class of bug described in the report — a size/write divergence silently producing a corrupt wire message: [5](#0-4) 

The one path that does not perform this explicit re-check is the top-level fast-path `marshal()`, which uses generated `Size()`/`Marshal()` methods to pre-size the output buffer via `growcap` before calling `Marshal`: [6](#0-5) 
However, this doesn't reproduce the Quagga bug class: both `Size` and `Marshal` are generated from the same schema/descriptor and are self-consistent, and even if capacity were underestimated, Go's `append` semantics guarantee memory-safe reallocation rather than a buffer overflow (unlike the C-based Quagga code). There is no unprivileged, trusted-schema request path where a size/write mismatch escapes detection and produces an invalid or memory-unsafe result.

func appendMessage(b []byte, m proto.Message, wiretag uint64, opts marshalOptions) ([]byte, error) {
	mopts := opts.Options()
	calculatedSize := mopts.Size(m)
	b = protowire.AppendVarint(b, wiretag)
	b = protowire.AppendVarint(b, uint64(calculatedSize))
	before := len(b)
	b, err := mopts.MarshalAppend(b, m)
	if measuredSize := len(b) - before; calculatedSize != measuredSize && err == nil {
		return nil, errors.MismatchedSizeCalculation(calculatedSize, measuredSize)
	}
	return b, err
}
