### Title
`block_direct_execute_call` protection can be bypassed via `library_call` syscall - (File: crates/blockifier/src/execution/syscalls/hint_processor.rs)

### Summary
Sudo's bug lets a permitted "run specific commands" policy be bypassed because the intercept check only covers `execve`, not the equivalent `execveat`/`fexecve` entry points. In this codebase, an analogous "specific-entry-point block" exists for the `__execute__` selector: `call_contract` explicitly calls `maybe_block_direct_execute_call` to reject calls that target the `__execute__` entry point name, but the sibling `library_call` syscall — which reaches the exact same `execute_inner_call`/entry-point dispatch machinery — never performs this check.

### Finding Description
`call_contract` in both the VM and native syscall handlers invokes the guard before dispatching: [1](#0-0) [2](#0-1) 
which rejects `EXECUTE_ENTRY_POINT_NAME` when `versioned_constants.block_direct_execute_call` is set, returning `Revert{INVALID_ARGUMENT_FELT}` (this is confirmed by the dedicated regression test `test_direct_execute_call`). [3](#0-2) 

However, `library_call` in the same file builds a `CallEntryPoint` with an arbitrary caller-supplied `entry_point_selector` (`request.function_selector`) and routes straight to `execute_inner_call` without any call to `maybe_block_direct_execute_call`: [4](#0-3) 

The same gap exists in the native (Cairo Native) syscall handler's `library_call`: [5](#0-4) 

And in the deprecated (Cairo0) syscall path, `execute_library_call` also omits the check that `call_contract` performs: [6](#0-5) 
compared to `call_contract`'s check at: [7](#0-6) 

The Starknet OS Cairo re-execution mirrors this same asymmetry: `execute_deprecated_syscalls` explicitly asserts `call_contract_syscall.request.function_selector != EXECUTE_ENTRY_POINT_SELECTOR` for `CALL_CONTRACT_SELECTOR`, but performs no equivalent assertion for `LIBRARY_CALL_SELECTOR`/`LIBRARY_CALL_L1_HANDLER_SELECTOR`: [8](#0-7) [9](#0-8) 

Since `library_call` (`CallType::Delegate`) executes the target class's code in the *caller's own storage context* — with `storage_address`/`caller_address` unchanged from the calling frame — invoking a class's `__execute__` entry point via `library_call` instead of `call_contract` reaches the identical `__execute__` code path (identical semantics, since delegate call just changes which bytecode runs against the same storage/context) while completely evading the `block_direct_execute_call` policy.

### Impact Explanation
`block_direct_execute_call` exists specifically to prevent contracts from invoking an account's `__execute__` entry point directly (outside of the protocol's normal validate→execute transaction flow), which the project's own tests treat as a security invariant (`test_direct_execute_call`, `test_direct_execute_call` in `starknet_os_flow_tests`). Bypassing it via `library_call` allows an unprivileged contract deployer/caller to trigger arbitrary account `__execute__` logic outside the intended transaction-flow guarantees (e.g., without going through `__validate__`, or from within another contract's call context), undermining the fee/tip and reentrancy-shape assumptions this constant was introduced to protect and causing Starknet OS re-execution (which enforces the block only for `CALL_CONTRACT_SELECTOR`) to diverge from actual blockifier execution results, since the OS assertion for CASM programs also only guards `call_contract`.

### Likelihood Explanation
High reachability: any contract can call `library_call_syscall(class_hash, selector!("__execute__"), calldata)` from a single ordinary transaction — no special privileges, staking, or operator control required. This is a straightforward gap between two syscalls implementing conceptually equivalent "call another class's entry point" functionality, one of which was patched and the other left unguarded.

### Recommendation
Add the same `maybe_block_direct_execute_call(request.function_selector)` check (or the Cairo `assert_not_equal` for `EXECUTE_ENTRY_POINT_SELECTOR`) to all `library_call` implementations — VM (`crates/blockifier/src/execution/syscalls/hint_processor.rs`), native (`crates/blockifier/src/execution/native/syscall_handler.rs`), deprecated (`crates/blockifier/src/execution/deprecated_syscalls/hint_processor.rs`), and the Starknet OS Cairo re-execution paths (`execute_syscalls.cairo`, `deprecated_execute_syscalls.cairo`) for both `LIBRARY_CALL_SELECTOR` and `LIBRARY_CALL_L1_HANDLER_SELECTOR`.

### Proof of Concept
1. Deploy an account contract class `A` with a normal `__execute__` entry point.
2. Deploy any contract `B` (does not need to be an account) whose external function calls `starknet::library_call_syscall(class_hash_of_A, selector!("__execute__"), calldata)`.
3. Submit an ordinary `INVOKE` transaction calling `B`'s function.
4. With `versioned_constants.block_direct_execute_call = true`, `call_contract_syscall(A, "__execute__", ...)` would be rejected with `Invalid argument` (per `test_direct_execute_call`), but the `library_call_syscall` variant succeeds and executes `A`'s `__execute__` logic against `B`'s storage/caller context, bypassing the intended restriction.

    fn library_call(
        request: LibraryCallRequest,
        vm: &mut VirtualMachine,
        syscall_handler: &mut Self,
        remaining_gas: &mut u64,
    ) -> Result<LibraryCallResponse, Self::Error> {
        let entry_point = CallEntryPoint {
            class_hash: Some(request.class_hash),
            code_address: None,
            entry_point_type: EntryPointType::External,
            entry_point_selector: request.function_selector,
            calldata: request.calldata,
            // The call context remains the same in a library call.
            storage_address: syscall_handler.storage_address(),
            caller_address: syscall_handler.caller_address(),
            call_type: CallType::Delegate,
            // NOTE: this value might be overridden later on.
            initial_gas: *remaining_gas,
        };

        let retdata_segment = execute_inner_call(entry_point, vm, syscall_handler, remaining_gas)
            .map_err(|error| match error {
            SyscallExecutionError::Revert { .. } => error,
            _ => error.as_lib_call_execution_error(
                request.class_hash,
                syscall_handler.storage_address(),
                request.function_selector,
            ),
        })?;

        Ok(LibraryCallResponse { segment: retdata_segment })
    }

    pub(crate) fn maybe_block_direct_execute_call(
        &mut self,
        selector: EntryPointSelector,
    ) -> SyscallResult<()> {
        let versioned_constants = &self.context.tx_context.block_context.versioned_constants;
        if versioned_constants.block_direct_execute_call
            && selector == selector_from_name(EXECUTE_ENTRY_POINT_NAME)
        {
            return Err(SyscallExecutionError::Revert { error_data: vec![INVALID_ARGUMENT_FELT] });
        }
        Ok(())
    }

    fn library_call(
        &mut self,
        class_hash: Felt,
        function_selector: Felt,
        calldata: &[Felt],
        remaining_gas: &mut u64,
    ) -> SyscallResult<Vec<Felt>> {
        self.pre_execute_syscall(
            remaining_gas,
            self.gas_costs().syscalls.library_call.base_syscall_cost(),
            SyscallSelector::LibraryCall,
        )?;

        let class_hash = ClassHash(class_hash);

        let wrapper_calldata = Calldata(Arc::new(calldata.to_vec()));

        let selector = EntryPointSelector(function_selector);

        let entry_point = CallEntryPoint {
            class_hash: Some(class_hash),
            code_address: None,
            entry_point_type: EntryPointType::External,
            entry_point_selector: selector,
            calldata: wrapper_calldata,
            // The call context remains the same in a library call.
            storage_address: self.base.call.storage_address,
            caller_address: self.base.call.caller_address,
            call_type: CallType::Delegate,
            initial_gas: *remaining_gas,
        };

        let error_wrapper_function =
            |e: SyscallExecutionError,
             class_hash: ClassHash,
             storage_address: ContractAddress,
             selector: EntryPointSelector| {
                e.as_lib_call_execution_error(class_hash, storage_address, selector)
            };

        Ok(self
            .execute_inner_call(entry_point, remaining_gas, class_hash, error_wrapper_function)?
            .0)
    }
