Found a valid, in-scope analog: a **cache/pointer-replacement bug with missing declared-target validation**, structurally identical to the DSProxy issue (replacing what a "call" points to without validating the target is a live/legitimate entity), located in the `replace_class` syscall handling of the **Starknet OS** (used for re-execution/proving), which diverges from the blockifier's (sequencer's) enforcement of the same invariant.

### Title
Starknet OS `execute_replace_class` omits the "class must be declared" check enforced by the blockifier, causing sequencer/OS state divergence - (File: crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo)

### Summary
The `replace_class` syscall lets a contract change the class hash it points to for subsequent calls — Starknet's analog of DSProxy re-pointing a cached call target. The blockifier (execution engine used by the sequencer) validates that the new `class_hash` is actually declared before applying the change, causing a revert otherwise. The Starknet OS Cairo implementation of the same syscall does not perform this check — a `TODO` in the code explicitly documents the gap — and unconditionally writes the new (possibly undeclared/garbage) class hash into `contract_state_changes`.

### Finding Description
In the blockifier, `replace_class` fetches the compiled class for the requested hash before mutating state, which fails for an undeclared class and reverts the transaction: [1](#0-0) 
The same enforcement is exercised and asserted by tests for both Cairo0 and Cairo1/Native execution paths, confirming "undeclared class hash" reliably reverts in the blockifier: [2](#0-1) [3](#0-2) 

In contrast, the Starknet OS's `execute_replace_class` (used for block re-execution / STARK proving) reads the requested `class_hash` from calldata and directly writes it into `contract_state_changes` for the calling contract's address, with no lookup or validation that the class is declared: [4](#0-3) 
The missing check is explicitly acknowledged in the code: [5](#0-4) 

This is the same bug class as the DSProxy report: a mechanism that lets execution be redirected to a different "target" (a class hash acting like DSProxy's cached contract address) is not validated to point to a legitimate/live entity before the redirection is committed, so downstream consumers of the cache/state (here, the OS's committed state diff) can end up with data inconsistent with what the trusted execution engine (the blockifier) would ever allow.

### Impact Explanation
Any unprivileged account contract can invoke `replace_class` with an arbitrary, undeclared `class_hash` (e.g., in an `__execute__` or `__validate__` call, or any entry point). 
- The blockifier, executing the block for the sequencer, will revert this call (`UndeclaredClassHash`), so it never commits the class-hash change to the contract's storage/state.
- The OS, re-executing the identical block/transactions to produce the state commitment/proof, applies the class-hash change unconditionally, since it performs no declared-class validation for `replace_class`.

This causes the OS's computed final state (and consequently the committed state root produced by the OS for proving) to diverge from the state actually computed and agreed upon by the sequencer/blockifier for that block — an honest-node divergence / wrong committed root, which is one of the explicitly accepted high-impact outcomes for this exercise.

### Likelihood Explanation
The `replace_class` syscall is available to any unprivileged deployed contract; supplying an arbitrary, unused felt as the "class_hash" argument requires no special permission, capital, or reliance on `selfdestruct`-like Starknet-specific hazards — it is a single-transaction, one-syscall trigger. The precondition (existence of the TODO / missing check) is confirmed directly in the source.

### Recommendation
Add a declared-class check to `execute_replace_class` in the OS (mirroring the blockifier's `get_compiled_class` check), ensuring the class hash is present among declared classes (or the current block's `contract_class_changes`) before writing it into `contract_state_changes`. This should be done before the OS reaches production; until fixed, block-hash equivalence between the sequencer and the OS cannot be relied upon whenever `replace_class` is invoked with an undeclared class hash.

### Proof of Concept
1. Deploy account/contract `A` (Cairo0 or Cairo1).
2. From any calling context, have `A` invoke the `replace_class` syscall with `class_hash = <undeclared/garbage felt>`.
3. Sequencer/blockifier execution: the call reverts with `UndeclaredClassHash`, tx is `REVERTED`, `A`'s class hash is unchanged in the sequencer's committed state. [6](#0-5) 
4. Starknet OS re-execution of the same block: `execute_replace_class` performs the `dict_update` unconditionally, setting `A`'s class hash to the undeclared value in `contract_state_changes`, with no equivalent failure path. [7](#0-6) 
5. The resulting state diffs (and therefore the final committed roots) computed by the sequencer and by the OS for this block differ for contract `A`.

// Replaces the class.
func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
