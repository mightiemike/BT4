### Title
Excess outbound gas fee (`gasFee - gasFeeUsed`) is permanently lost with no accounting or recovery path when `refundUnusedGas` fails - (File: `x/uexecutor/keeper/outbound.go`)

### Summary
`applyGasRefund` in `x/uexecutor/keeper/outbound.go` mirrors the `EscrowedToken._claim()` pattern: it computes a "leftover" amount that is owed back to a user (`refundAmount = gasFee - gasFeeUsed`, analogous to `removedAmount`), and attempts to redistribute it via a downstream call. Just like the original report's `ratePerToken` guard silently drops `removedAmount` when `totalVesting == 0`, this code silently drops `refundAmount` (with only a log line and a `"FAILED"` status string) when both the swap-refund and no-swap-refund attempts to `UniversalCore.refundUnusedGas` fail. There is no `unclaimableFunds`-style ledger variable and no admin/recovery function to reconcile or retry the loss.

### Finding Description
`applyGasRefund` computes `refundAmount := gasFee - gasFeeUsed` [1](#0-0) , an amount that was already collected/reserved as part of the outbound's `GasFee` at outbound-creation time via `GetOutboundTxGasAndFees` on `UniversalCore` [2](#0-1) , and is meant to be returned to the user once the actual gas used on the destination chain is known.

The function then tries two derived EVM calls to `UniversalCore.refundUnusedGas`:
1. With swap (`gasToken` → PC) — requires `GetDefaultFeeTierForToken` and a Uniswap quote to succeed [3](#0-2) .
2. Fallback, without swap — direct PRC20 deposit [4](#0-3) .

If the fallback call also fails (e.g. `CallUniversalCoreRefundUnusedGas` reverts because the destination `UniversalCore` module lacks a registered handler for `gasToken`, insufficient balance, or a paused contract state), the function simply records:

```go
refundPcTx.Status = "FAILED"
refundPcTx.ErrorMsg = err.Error()
...
outbound.PcRefundExecution = refundPcTx
outbound.RefundSwapError = swapFallbackReason
``` [5](#0-4) 

There is no variable that increments to track the `refundAmount` that failed to be paid out, and no exposed message/keeper function anywhere in the module to retry or claim it later — a search for `PcRefundExecution` and `refundUnusedGas` usages across the repo shows the value is written once into `outbound.PcRefundExecution.Status = "FAILED"` and never read again for reconciliation. This is functionally identical to the reported bug class: a computed "amount owed" that is dropped on the floor the moment the redistribution mechanism can't complete, with no bookkeeping trail and no recovery function.

Both `handleSuccessfulOutbound` and `handleFailedOutbound` call `applyGasRefund` unconditionally, including on the failed-outbound path where funds are also being re-minted back via revert [6](#0-5) , so this loss path triggers on ordinary, honest-validator-observed outbound flows — not merely a hypothetical.

### Impact Explanation
Whenever the refund call to `UniversalCore.refundUnusedGas` fails in both the swap and no-swap forms (which can occur for gas tokens that lack a Uniswap pool/fee tier, or if the module account interacting with `UniversalCore` hits any revert condition in that contract), the excess gas fee that was already deducted from the user's `outbound.GasFee` becomes permanently unaccounted for and unrecoverable by the affected user or by governance. This matches the reported impact category of "permanent loss of protocol/user-controlled funds" with no built-in remediation path — analogous to the `EscrowedToken` `removedAmount` staying stuck forever.

### Likelihood Explanation
The trigger does not require a privileged actor: an ordinary user submitting a cross-chain outbound with a `gasToken` that has no default Uniswap fee tier configured (or any gas token whose `refundUnusedGas` call reverts in the underlying `UniversalCore` contract, e.g. due to per-token pause or missing liquidity) is sufficient to reach the unrecoverable fallback branch, since `applyGasRefund` runs automatically as part of normal outbound-observation voting (`handleSuccessfulOutbound`/`handleFailedOutbound`), reachable through the standard `MsgVoteOutbound` flow with honest validators. However, I was not able to inspect the Solidity source of `UniversalCore.refundUnusedGas` itself (not present in the indexed Go/JSON ABI content), so I cannot confirm with certainty every condition under which the on-chain call reverts, or whether that contract has its own internal accounting/retry safety net that would fully neutralize this Go-level gap.

### Recommendation
Add a per-outbound (or global) `unclaimableRefund` accounting mechanism: when both refund attempts fail, increment a durable, queryable ledger entry (e.g. a new field/store keyed by `outbound.Id` or `gasToken`) with `refundAmount`, and add an admin- or permissionless-triggerable `MsgRetryGasRefund`/`MsgClaimUnrefundedGas` message that re-attempts (or lets the affected `refundRecipient` re-claim) the stuck amount, clearing the ledger entry on success — mirroring the report's suggested `recoveUnclaimableFunds()` pattern but keyed to the correct recipient instead of a team-only sweep, since here the funds are owed to a specific user rather than being an undistributed common pool.

Conceptual reproduction (Go-level, using the existing integration test harness in `test/integration/uexecutor/gas_fee_refund_test.go`):
1. Set up an outbound whose `GasToken` is a PRC20 address that has no registered `defaultFeeTier` in the mock/real `UniversalCore` (causing `GetDefaultFeeTierForToken` to error) and additionally simulate/force the underlying `CallUniversalCoreRefundUnusedGas(..., withSwap=false, ...)` fallback call to also fail (e.g. `UniversalCore` mock returns a revert for an unrecognized `gasToken`).
2. Drive the vote-outbound flow with `gasFeeUsed < gasFee` (as in the existing `"swap fallback reason stored when swap refund fails"` subtest) so `applyGasRefund` computes a positive `refundAmount`.
3. Observe that `outbound.PcRefundExecution.Status == "FAILED"` is recorded (as already asserted in `test/integration/uexecutor/gas_fee_refund_test.go:189-197`), but assert further that no keeper state anywhere tracks `refundAmount` for later recovery, and no message exists to retrieve it — the funds are permanently gone from the perspective of both the user and the protocol, with only a log/error string as evidence. // handleFailedOutbound mints back the bridged tokens to the revert recipient,
// then attempts to refund any excess gas (gasFee - gasFeeUsed) just like a
// successful outbound would. Both operations are recorded on the outbound.
func (k Keeper) handleFailedOutbound(ctx sdk.Context, utxId string, outbound types.OutboundTx, obs *types.OutboundObservation) error {
	// Only revert bridged funds for funds-related tx types
	if outbound.TxType == types.TxType_FUNDS || outbound.TxType == types.TxType_GAS_AND_PAYLOAD ||
		outbound.TxType == types.TxType_FUNDS_AND_PAYLOAD {

		// Decide revert recipient safely
		recipient := outbound.Sender
		if outbound.RevertInstructions != nil &&
			outbound.RevertInstructions.FundRecipient != "" {
			recipient = outbound.RevertInstructions.FundRecipient
		}

		amount := new(big.Int)
		amount, ok := amount.SetString(outbound.Amount, 10)
		if !ok {
			return fmt.Errorf("invalid amount: %s", outbound.Amount)
		}
		receipt, err := k.CallPRC20Deposit(ctx, common.HexToAddress(outbound.Prc20AssetAddr), common.HexToAddress(recipient), amount)

		pcTx := types.PCTx{
			Sender:      outbound.Sender,
			BlockHeight: uint64(ctx.BlockHeight()),
		}
		// Capture tx hash from receipt even on EVM revert for debugging.
		if receipt != nil {
			pcTx.TxHash = receipt.Hash
			pcTx.GasUsed = receipt.GasUsed
		}
		if err != nil {
			pcTx.Status = "FAILED"
			pcTx.ErrorMsg = err.Error()
			outbound.PcRevertExecution = &pcTx
			// Re-mint failed — mark as ABORTED for manual intervention
			return k.AbortOutbound(ctx, utxId, outbound,
				fmt.Sprintf("failed to re-mint tokens for revert: %s", err.Error()))
		}
		pcTx.TxHash = receipt.Hash
		pcTx.GasUsed = receipt.GasUsed
		pcTx.Status = "SUCCESS"
		outbound.PcRevertExecution = &pcTx
		k.Logger().Info("outbound failed: funds re-minted for revert",
			"utx_id", utxId,
			"outbound_id", outbound.Id,
			"tx_hash", receipt.Hash,
		)
	}

	outbound.OutboundStatus = types.Status_REVERTED
	k.Logger().Info("outbound reverted",
		"utx_id", utxId,
		"outbound_id", outbound.Id,
		"dest_chain", outbound.DestinationChain,
	)

	// Refund excess gas regardless of tx type — gas was consumed on the external
	// chain whether the execution succeeded or failed.
	k.applyGasRefund(ctx, &outbound, obs)

	return k.UpdateOutbound(ctx, utxId, outbound)
}

// applyGasRefund computes the excess gas (gasFee - gasFeeUsed) and, if positive,
// calls UniversalCore refundUnusedGas. The result is recorded in outbound.PcRefundExecution.
// It is called for both successful and failed outbounds — gas is consumed on the
// external chain regardless of execution outcome.
func (k Keeper) applyGasRefund(ctx sdk.Context, outbound *types.OutboundTx, obs *types.OutboundObservation) {
	if obs.GasFeeUsed == "" || outbound.GasFee == "" || outbound.GasToken == "" {
		return
	}

	gasFee := new(big.Int)
	if _, ok := gasFee.SetString(outbound.GasFee, 10); !ok {
		return
	}

	gasFeeUsed := new(big.Int)
	if _, ok := gasFeeUsed.SetString(obs.GasFeeUsed, 10); !ok {
		return
	}

	// No excess gas to refund
	if gasFee.Cmp(gasFeeUsed) <= 0 {
		return
	}

	refundAmount := new(big.Int).Sub(gasFee, gasFeeUsed)
	gasToken := common.HexToAddress(outbound.GasToken)

	// Refund recipient: prefer fund_recipient in revert_instructions, fall back to sender
	refundRecipient := outbound.Sender
	if outbound.RevertInstructions != nil && outbound.RevertInstructions.FundRecipient != "" {
		refundRecipient = outbound.RevertInstructions.FundRecipient
	}
	recipientAddr := common.HexToAddress(refundRecipient)

	refundPcTx := &types.PCTx{
		Sender:      outbound.Sender,
		BlockHeight: uint64(ctx.BlockHeight()),
	}

	// Step 1: try refund with swap (gasToken → PC native)
	fee, swapErr := k.GetDefaultFeeTierForToken(ctx, gasToken)
	var swapFallbackReason string

	if swapErr == nil {
		quote, quoteErr := k.getSwapQuoteForRefund(ctx, gasToken, fee, refundAmount)
		if quoteErr == nil {
			minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
			minPCOut.Div(minPCOut, big.NewInt(100))

			resp, err := k.CallUniversalCoreRefundUnusedGas(ctx, gasToken, refundAmount, recipientAddr, true, fee, minPCOut)
			if err == nil {
				refundPcTx.TxHash = resp.Hash
				refundPcTx.GasUsed = resp.GasUsed
				refundPcTx.Status = "SUCCESS"
				outbound.PcRefundExecution = refundPcTx
				return
			}
			swapFallbackReason = fmt.Sprintf("swap refund failed: %s", err.Error())
		} else {
			swapFallbackReason = fmt.Sprintf("quote fetch failed: %s", quoteErr.Error())
		}
	} else {
		swapFallbackReason = fmt.Sprintf("fee tier fetch failed: %s", swapErr.Error())
	}

	// Step 2: fallback — refund without swap (deposit PRC20 directly to recipient)
	ctx.Logger().Error("applyGasRefund: swap refund failed, falling back to no-swap",
		"outbound_id", outbound.Id,
		"reason", swapFallbackReason,
	)

	resp, err := k.CallUniversalCoreRefundUnusedGas(ctx, gasToken, refundAmount, recipientAddr, false, big.NewInt(0), big.NewInt(0))
	if err != nil {
		refundPcTx.Status = "FAILED"
		refundPcTx.ErrorMsg = err.Error()
	} else {
		refundPcTx.TxHash = resp.Hash
		refundPcTx.GasUsed = resp.GasUsed
		refundPcTx.Status = "SUCCESS"
	}

	outbound.PcRefundExecution = refundPcTx
	outbound.RefundSwapError = swapFallbackReason
}

// GetOutboundTxGasAndFees calls UniversalCore.getOutboundTxGasAndFees(prc20, gasLimitWithBaseLimit)
// to get gasToken, gasFee, protocolFee, gasPrice, and chainNamespace.
// Pass gasLimitWithBaseLimit=0 to use the contract's baseLimit.
func (k Keeper) GetOutboundTxGasAndFees(ctx sdk.Context, prc20 common.Address, gasLimitWithBaseLimit *big.Int) (*GasFeeInfo, error) {
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	ucABI, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse UniversalCore ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	receipt, err := k.evmKeeper.CallEVM(ctx, ucABI, ueModuleAccAddress, handlerAddr, false, nil,
		"getOutboundTxGasAndFees", prc20, gasLimitWithBaseLimit)
	if err != nil {
		return nil, errors.Wrap(err, "failed to call getOutboundTxGasAndFees")
	}

	results, err := ucABI.Methods["getOutboundTxGasAndFees"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack getOutboundTxGasAndFees result")
	}

	gasToken := results[0].(common.Address)
	gasFee := results[1].(*big.Int)
	// protocolFee := results[2].(*big.Int) — not needed for outbound fields
	gasPrice := results[3].(*big.Int)
	// chainNamespace := results[4].(string) — not needed for outbound fields
	// gasLimitUsed (results[5]) is the exact gas limit the contract resolved
	// (caller-supplied or per-chain baseGasLimitByChainNamespace fallback).
	// Reading it directly avoids the gasFee/gasPrice round-trip and keeps us
	// in lock-step with the contract's own resolution.
	gasLimit := results[5].(*big.Int)

	return &GasFeeInfo{
		GasToken: gasToken,
		GasFee:   gasFee,
		GasPrice: gasPrice,
		GasLimit: gasLimit,
	}, nil
