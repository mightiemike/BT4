### Title
Auto-swap deposit and gas-refund paths use manipulable spot-price Uniswap V3 quotes for slippage protection, enabling value extraction from bridged funds - (File: `x/uexecutor/keeper/execute_inbound_gas.go`, `x/uexecutor/keeper/execute_inbound_gas_and_payload.go`, `x/uexecutor/keeper/outbound.go`, `x/uexecutor/keeper/evm.go`)

### Summary
The external report describes a vault whose share-price/exchange-rate computation trusts a single, manipulable external read (`maxWithdraw`) to protect depositors — if that read is temporarily depressed, depositors lose funds. Push Chain has a structurally identical pattern: when depositing GAS/GAS_AND_PAYLOAD inbounds (and when refunding unused gas), the `uexecutor` module derives the acceptable minimum output (`minPCOut`) for a PRC20→WPC swap from a single, same-block, spot-price read of `QuoterV2.quoteExactInputSingle`, then applies a flat 5% slippage margin computed off that very same reading. There is no TWAP or external reference price; the "safety" check is entirely self-referential to the price at execution time.

### Finding Description
`GetSwapQuote` calls `QuoterV2.quoteExactInputSingle` with `commit=false` to fetch the instantaneous Uniswap V3 pool price: [1](#0-0) 

This quote is used, unmodified except for a fixed 5% haircut, as the slippage floor for the actual on-chain auto-swap deposit: [2](#0-1) 

The same pattern is repeated for `GAS_AND_PAYLOAD` inbounds in `gasAndPayloadDepositAutoSwap`: [3](#0-2) 

and again for excess-gas refunds via `applyGasRefund` → `getSwapQuoteForRefund` → `CallUniversalCoreRefundUnusedGas`: [4](#0-3) [5](#0-4) 

Because `quoteExactInputSingle` reads the pool's current instantaneous sqrt-price/liquidity state rather than a time-weighted average, any unprivileged user can submit an ordinary EVM transaction on Push Chain (a large swap against the same Uniswap V3 pool used by `QuoterV2`) immediately before the block containing the `MsgVoteInbound`/`MsgVoteOutbound` that triggers `ExecuteInboundGas`, `ExecuteInboundGasAndPayload`, or the outbound gas refund. Because the quote and the module's actual swap execution both read the already-manipulated pool state, the 5% slippage bound provides no real protection — it is 5% below an attacker-controlled number, not 5% below fair value. This is the direct analog of the PoolTogether issue: an accounting value that is supposed to reflect "real" collateral/value is instead sourced from state an unprivileged actor can distort, and the code's own safety margin is computed from that same distorted value.

### Impact Explanation
A user's bridged GAS/GAS_AND_PAYLOAD deposit (a PRC20 gas token deposited via `depositPRC20WithAutoSwap`) can be swapped into WPC at an attacker-manipulated unfavorable rate, so the user's UEA receives materially less PC-denominated value than the fair-market amount of their deposit — a direct, unauthorized loss of user funds during a core universal-execution flow (`ExecuteInboundGas` / `ExecuteInboundGasAndPayload`). The same mechanism also applies to the protocol-controlled excess-gas refund flow (`applyGasRefund`), so relayer/protocol-held gas-fee surplus can likewise be siphoned via price manipulation. This falls squarely under "corruption of PRC20 or native asset accounting" and "unauthorized ... refund accounting" in the allowed-impact scope, reachable purely from an ordinary unprivileged user's default transaction submission path (a normal swap plus a normal cross-chain deposit), with fully honest validators/TSS.

### Likelihood Explanation
Likelihood is high on any deployment where the Uniswap V3 pool backing `QuoterV2` for a given PRC20/WPC pair has shallow liquidity relative to the attacker's available capital (including flash-loan-funded capital, since Push Chain is EVM-compatible and flash loans are a normal unprivileged primitive). The attacker only needs to control transaction ordering within a block relative to the module's swap execution, which is achievable through normal fee-based transaction submission (no validator, relayer, or TSS collusion required).

### Recommendation
Replace the single spot `quoteExactInputSingle` read with a manipulation-resistant reference, e.g.:
- Use a TWAP (time-weighted average price) oracle over a sufficiently long window rather than the instantaneous quoter, and/or
- Cap the deviation between the spot quote and a longer-window TWAP before accepting `minPCOut`, and/or
- Allow governance/registry-configured maximum acceptable slippage/price-impact thresholds per token pair, rejecting swaps when pool liquidity is too thin, and/or
- Consider a circuit breaker that reverts (creating an `INBOUND_REVERT`) rather than proceeding with auto-swap when the observed price deviates significantly from a recent moving average.

### Proof of Concept
1. Attacker identifies a GAS_AND_PAYLOAD-eligible PRC20/WPC Uniswap V3 pool with limited liquidity on Push Chain used by `UniversalCore`'s `defaultFeeTier`/`QuoterV2`.
2. Attacker (optionally using a flash loan) submits a large swap against that pool, moving the spot price sharply against the token the victim will deposit.
3. In the same block (or before the block containing the manipulation trade reverts to equilibrium), a legitimate user's cross-chain GAS inbound is finalized by honest validators, triggering `ExecuteInboundGas` → `GetSwapQuote` (reads the now-manipulated price) → `minPCOut = quote * 95/100` → `CallPRC20DepositAutoSwap`.
4. The module's swap executes against the manipulated pool at the bad price; `minPCOut` does not protect the user because it was derived from the same manipulated quote.
5. Attacker reverses their initial trade, capturing the value difference; the victim's UEA receives WPC worth significantly less than the fair value of their bridged deposit.

```go
// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
```

```go
// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
```

```go
// getSwapQuoteForRefund fetches a Uniswap quote for the gas token refund swap.
func (k Keeper) getSwapQuoteForRefund(ctx sdk.Context, gasToken common.Address, fee *big.Int, amount *big.Int) (*big.Int, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(ctx)
	if err != nil {
		return nil, err
	}
	wpcAddr, err := k.GetUniversalCoreWPCAddress(ctx)
	if err != nil {
		return nil, err
	}
	return k.GetSwapQuote(ctx, quoterAddr, gasToken, wpcAddr, fee, amount)
```
