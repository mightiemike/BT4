### Title
PoisonMicroblock accepts two non-conflicting, sequential microblocks from the same miner, redirecting an honest miner's coinbase to an unrelated reporter - (File: stackslib/src/chainstate/stacks/db/transactions.rs)

### Summary
`check_microblock_header_signer` only verifies that `mblock_header_1` and `mblock_header_2` were signed by the same microblock private key; it never checks that the two headers share the same `sequence` number or have differing content (the actual definition of an equivocation/fork). `handle_poison_microblock` then unconditionally records the reporter and slashes the miner based solely on this same-signer check, so two honestly-produced, sequential microblocks at different sequence numbers are accepted as "poison" evidence.

### Finding Description
The broken equality is: **reward paid should equal exactly one proven double-signature (two headers at the same sequence, differing content) by the slashed miner**, but the code allows reward payment when **zero equivocations exist** — any two headers signed by the same key, regardless of sequence relationship.

In `check_microblock_header_signer` [1](#0-0) , the only validation performed is recovering `pkh1` and `pkh2` from each header's signature via `check_recover_pubkey()` and asserting `pkh1 == pkh2`. There is no comparison of `mblock_header_1.sequence` vs `mblock_header_2.sequence`, and no check that the headers differ (i.e., represent a genuine fork at the same height).

`handle_poison_microblock` [2](#0-1)  calls this check, then looks up `microblock_height_opt` for the pubkey hash and verifies the maturity window, but performs no additional structural validation of the two headers relative to each other. It proceeds to call `env.global_context.database.insert_microblock_poison(mblock_pubk_height, &sender_principal, mblock_header_1.sequence)` unconditionally when no prior report exists [3](#0-2) .

Because sequence numbers are never compared, an attacker can take `mblock_header_1` = the header at sequence `N` and `mblock_header_2` = the header at sequence `N+1` (or any later sequence) from a single, honestly-produced, non-forking microblock stream by miner M. Both are signed by M's real key, so `pkh1 == pkh2` trivially holds, and the transaction is accepted as valid poison evidence — even though no fork or duplicate-sequence conflict ever occurred.

The only structural check that exists for genuine forks (same sequence, different tx_merkle_root/hash) lives in `validate_parent_microblock_stream` in `blocks.rs`, which is used when nodes are *detecting* forks and constructing poison payloads themselves [4](#0-3) . That function is a producer of PoisonMicroblock payloads, not a consumer-side validation gate; nothing in the actual transaction-processing path (`handle_poison_microblock`/`check_microblock_header_signer`) re-verifies that the submitted headers satisfy the "same sequence, different hash" invariant before slashing the miner.

### Impact Explanation
This allows block-reward theft: an unprivileged reporter submits a crafted `PoisonMicroblock` transaction using two genuine, non-conflicting microblock headers from an honest miner's own tenure. `insert_microblock_poison` records the report, and later `find_mature_miner_rewards`/`calculate_miner_reward` (per the question's stated call chain) redirects the honest miner's matured coinbase to the reporter, despite no actual equivocation. This is a direct reward misdirection from an honest miner to an attacker-controlled account, matching the Critical "block-reward theft/double-payment/loss" category.

### Likelihood Explanation
Preconditions are minimal and attainable by an unprivileged participant: any tenure with two or more honestly-mined microblocks at different sequence numbers, both within the `MINER_REWARD_MATURITY` window. The attacker needs no special stake, no signer role, and no compromise of the miner's key — they only need to observe publicly broadcast microblocks (which are gossip-visible) and submit a normal transaction. This is trivially repeatable against any miner who produces microblocks, for every tenure, at negligible cost (one transaction fee).

### Recommendation
In `check_microblock_header_signer` (or `handle_poison_microblock` immediately after it), require that the two headers represent a genuine equivocation: either `mblock_header_1.sequence == mblock_header_2.sequence` and the headers are not identical (differing `tx_merkle_root`/hash), following the same invariant already enforced when the node itself detects and constructs poison payloads in `validate_parent_microblock_stream`. Reject the transaction with `InvalidStacksTransaction` if the sequences differ or if the headers are otherwise not evidence of a fork.

### Proof of Concept
Rust integration test plan (mirroring `stackslib/src/chainstate/stacks/tests/block_construction.rs` harness):
1. Set up one tenure for miner M with microblock private key `k`, and mine 3 sequential, honestly-signed microblocks at sequence 0, 1, 2, each with distinct, non-conflicting transaction content (e.g., using `microblock_builder.mine_next_microblock_from_txs`).
2. From an unrelated account (the "reporter"), construct `TransactionPayload::PoisonMicroblock(header_at_seq_0, header_at_seq_1)` using the real signed headers (no forgery, no forking) — i.e., `make_user_poison_microblock` analog with two genuinely sequential headers.
3. Submit this transaction via `mempool.submit_raw` / block construction so it gets processed by `handle_poison_microblock`.
4. Assert (LHS) `env.global_context.database.get_microblock_poison_report(mblock_pubk_height)` returns `Some((reporter_principal, 0))` even though (RHS) no two microblocks at the same sequence with differing hashes ever existed in the stream — assert the equality that should hold (`report exists` == `real fork exists`) is violated, i.e., `report exists == true` while `real_fork_exists == false`.
5. Assert the miner's matured coinbase reward (via `find_mature_miner_rewards`/`calculate_miner_reward`) is reduced or redirected to the reporter despite the honest, non-forking tenure.

    fn check_microblock_header_signer(
        mblock_hdr_1: &StacksMicroblockHeader,
        mblock_hdr_2: &StacksMicroblockHeader,
    ) -> Result<Hash160, Error> {
        let pkh1 = mblock_hdr_1.check_recover_pubkey().map_err(|e| {
            Error::InvalidStacksTransaction(
                format!("Failed to recover public key: {:?}", &e),
                false,
            )
        })?;

        let pkh2 = mblock_hdr_2.check_recover_pubkey().map_err(|e| {
            Error::InvalidStacksTransaction(
                format!("Failed to recover public key: {:?}", &e),
                false,
            )
        })?;

        if pkh1 != pkh2 {
            let msg = format!(
                "Invalid PoisonMicroblock transaction -- signature pubkey hash {} != {}",
                &pkh1, &pkh2
            );
            warn!("{}", &msg);
            return Err(Error::InvalidStacksTransaction(msg, false));
        }
        Ok(pkh1)
    }

    pub fn handle_poison_microblock(
        env: &mut ExecutionState,
        invoke_ctx: &InvocationContext,
        mblock_header_1: &StacksMicroblockHeader,
        mblock_header_2: &StacksMicroblockHeader,
    ) -> Result<Value, Error> {
        let cost_before = env.global_context.cost_track.get_total();

        // encodes MARF reads for loading microblock height and current height, and loading and storing a
        // poison-microblock report
        runtime_cost(ClarityCostFunction::PoisonMicroblock, env, 0)
            .map_err(|e| Error::from_cost_error(e, cost_before.clone(), env.global_context))?;

        let sender_principal = match &invoke_ctx.sender {
            Some(ref sender) => {
                if let PrincipalData::Standard(sender) = sender.clone() {
                    sender
                } else {
                    panic!(
                        "BUG: tried to handle poison microblock without a standard principal sender"
                    );
                }
            }
            None => {
                panic!("BUG: tried to handle poison microblock without a sender");
            }
        };

        // is this valid -- were both headers signed by the same key?
        let pubkh =
            StacksChainState::check_microblock_header_signer(mblock_header_1, mblock_header_2)?;

        let microblock_height_opt = env
            .global_context
            .database
            .get_microblock_pubkey_hash_height(&pubkh)?;
        let current_height = env.global_context.database.get_current_block_height();

        // for the microblock public key hash we had to process
        env.add_memory(20)
            .map_err(|e| Error::from_cost_error(e, cost_before.clone(), env.global_context))?;

        // for the block height we had to load
        env.add_memory(4)
            .map_err(|e| Error::from_cost_error(e, cost_before.clone(), env.global_context))?;

        // was the referenced public key hash used anytime in the past
        // MINER_REWARD_MATURITY blocks?
        let mblock_pubk_height = match microblock_height_opt {
            None => {
                // public key has never been seen before
                let msg = format!(
                    "Invalid Stacks transaction: microblock public key hash {} never seen in this fork",
                    &pubkh
                );
                warn!("{}", &msg;
                      "microblock_pubkey_hash" => %pubkh
                );

                return Err(Error::InvalidStacksTransaction(msg, false));
            }
            Some(height) => {
                if height
                    .checked_add(
                        u32::try_from(MINER_REWARD_MATURITY).expect("FATAL: maturity > 2^32"),
                    )
                    .expect("BUG: too many blocks")
                    < current_height
                {
                    let msg = format!(
                        "Invalid Stacks transaction: microblock public key hash from height {} has matured relative to current height {}",
                        height, current_height
                    );
                    warn!("{}", &msg;
                          "microblock_pubkey_hash" => %pubkh
                    );

                    return Err(Error::InvalidStacksTransaction(msg, false));
                }
                height
            }
        };

        // add punishment / commission record, if one does not already exist at lower sequence
        let (reporter_principal, reported_seq) = if let Some((reporter, seq)) = env
            .global_context
            .database
            .get_microblock_poison_report(mblock_pubk_height)?
        {
            // account for report loaded
            env.add_memory(u64::from(TypeSignature::PrincipalType.size().map_err(
                |_| Error::Expects("Failed to get size of PrincipalType".into()),
            )?))
            .map_err(|e| Error::from_cost_error(e, cost_before.clone(), env.global_context))?;

            // u128 sequence
            env.add_memory(16)
                .map_err(|e| Error::from_cost_error(e, cost_before.clone(), env.global_context))?;

            if mblock_header_1.sequence < seq {
                // this sender reports a point lower in the stream where a fork occurred, and is now
                // entitled to a commission of the punished miner's coinbase
                debug!("Sender {} reports a better poison-miroblock record (at {}) for key {} at height {} than {} (at {})", &sender_principal, mblock_header_1.sequence, &pubkh, mblock_pubk_height, &reporter, seq;
                    "sender" => %sender_principal,
                    "microblock_pubkey_hash" => %pubkh
                );
                env.global_context.database.insert_microblock_poison(
                    mblock_pubk_height,
                    &sender_principal,
                    mblock_header_1.sequence,
                )?;
                (sender_principal, mblock_header_1.sequence)
            } else {
                // someone else beat the sender to this report
                debug!("Sender {} reports an equal or worse poison-microblock record (at {}, but already have one for {}); dropping...", &sender_principal, mblock_header_1.sequence, seq;
                    "sender" => %sender_principal,
                    "microblock_pubkey_hash" => %pubkh
                );
                (reporter, seq)
            }
        } else {
            // first-ever report of a fork
            debug!(
                "Sender {} reports a poison-microblock record at seq {} for key {} at height {}",
                &sender_principal, mblock_header_1.sequence, &pubkh, &mblock_pubk_height;
                "sender" => %sender_principal,
                "microblock_pubkey_hash" => %pubkh
            );
            env.global_context.database.insert_microblock_poison(
                mblock_pubk_height,
                &sender_principal,
                mblock_header_1.sequence,
            )?;
            (sender_principal, mblock_header_1.sequence)
        };
