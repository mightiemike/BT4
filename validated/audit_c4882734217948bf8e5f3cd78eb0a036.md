### Title
Unauthenticated log-source binding lets an unprivileged attacker forge gateway `send_funds` events and mint unbacked value on Push Chain - (File: universalClient/chains/svm/event_listener.go, universalClient/chains/svm/event_parser.go)

### Summary
The SVM listener discovers candidate transactions with `GetSignaturesForAddress(gatewayAddr, …)` [1](#0-0) , but Solana's `getSignaturesForAddress` matches *any* transaction whose account-key list contains the given address, whether or not that address's program was ever invoked. Once a transaction is fetched, `processSignatureBatch` blindly iterates **every** line of `tx.Meta.LogMessages` and classifies it purely by an 8-byte discriminator prefix, with no check on which program actually emitted the line: [2](#0-1) . `determineEventType` and `decodeUniversalTxEvent` operate on raw log text/bytes only — there is no correlation to `Program <id> invoke`/`success` boundaries or to `tx.Meta.InnerInstructions` [3](#0-2) [4](#0-3) .

### Finding Description
On Solana, any program invoked in a transaction may call `sol_log_data`, which produces a `"Program data: <base64>"` log line indistinguishable in the log stream from one emitted by the real gateway program. An unprivileged attacker can:
1. Deploy their own (permissionless) Solana program.
2. Build a single transaction that includes the real gateway program's pubkey merely as an account key (satisfying `getSignaturesForAddress`) and also invokes their own program.
3. Have their own program emit a `"Program data: "` log whose first 8 bytes match the configured `send_funds` discriminator, followed by an attacker-chosen Borsh payload matching `decodeUniversalTxEvent`'s layout: `sender(32)`, `recipient(20)`, `bridge_token(32)`, `bridge_amount(8)`, `data(len+bytes)`, `revert_recipient(32)`, `tx_type(1)`, `sig_len+sig_data`, `from_cea(1)` [5](#0-4) .

`determineEventType`/`ParseEvent` accept this forged line exactly like a genuine one, because they only check `strings.HasPrefix(log, "Program data: ")` and the 8-byte discriminator — never the emitting program ID [6](#0-5) [7](#0-6) . The resulting `store.Event` is deduplicated only by `signature:logIndex` (`InsertEventIfNotExists`) [8](#0-7) , which does not validate provenance either.

Because this bug is deterministic and present in every honest Universal Validator's identical client code, all honest UVs independently parse the same forged transaction and derive the identical `Inbound` payload/ballot key (`GetInboundBallotKey`), so the ballot reaches PASSED with unanimous *honest* votes — no malicious validator or TSS participant is required [9](#0-8) . `VoteInbound` then creates a `UniversalTx` and executes the inbound (mint PRC20 / run payload) once finalized [10](#0-9) . The only downstream check is confirmation depth and `tx.Meta.Err == nil` [11](#0-10) ; neither validates that any real SOL/SPL asset was actually locked in the gateway/vault, nor that the log came from the gateway's own invocation.

### Impact Explanation
If the attacker chooses `bridge_token` to match a registered `TokenConfigs` entry for the SVM chain, Push Chain will mint PRC20 tokens (or otherwise credit value) to an attacker-controlled `recipient`/UEA with no real deposit ever occurring on Solana — an unauthorized mint of protocol-backed value, i.e., direct fund creation from thin air with no economic backing. This is a critical, direct loss/insolvency vulnerability reachable by any unprivileged actor with the ability to deploy a Solana program and submit one transaction.

### Likelihood Explanation
High. No privileged role is required; deploying a Solana program and submitting a transaction referencing the gateway pubkey is completely permissionless. Because all honest UVs run the same vulnerable client, the attack does not depend on validator collusion — the ballot naturally reaches consensus.

### Recommendation
- Attribute each `"Program data:"` log line to the actual invoking program by tracking `Program <id> invoke [depth]` / `success`/`failed` boundaries (or, better, use `tx.Meta.InnerInstructions`/`tx.Meta.LogMessages` in conjunction with each instruction's `programIdIndex`) and only accept gateway events whose emitting program equals the configured `gatewayAddress`.
- Additionally verify actual token movement (pre/post balance deltas for the vault/mint) matches the claimed `bridge_amount`/`bridge_token` before treating a parsed event as authoritative.
- Reject events whose owning transaction did not genuinely invoke the gateway program as a top-level or CPI instruction.

### Proof of Concept
1. Deploy a minimal Solana program that CPI-logs `sol_log_data(discriminator_send_funds || sender(32) || attacker_recipient(20) || registered_token_pubkey(32) || amount(8) || 0u32 || revert_recipient(32) || tx_type(1) || 0u32)`.
2. Submit one transaction including the real gateway program's pubkey as a non-invoked account (to satisfy `getSignaturesForAddress`) plus a CPI call to the attacker's program.
3. Observe the universalClient store a `send_funds` inbound `store.Event` for this signature/log-index, get confirmed after the configured depth, and get voted `VoteInbound` by honest validators, finalizing a `UniversalTx` that mints PRC20 to the attacker's chosen recipient — with no real SOL/SPL ever locked.

// determineEventType determines the event type based on the log discriminator
func (el *EventListener) determineEventType(log string) string {
	if !strings.HasPrefix(log, "Program data: ") {
		return ""
	}

	eventData := strings.TrimPrefix(log, "Program data: ")
	decoded, err := base64.StdEncoding.DecodeString(eventData)
	if err != nil {
		return ""
	}

	if len(decoded) < 8 {
		return ""
	}

	discriminator := strings.ToLower(hex.EncodeToString(decoded[:8]))

	// Look up event type from discriminator map
	eventType, ok := el.discriminatorToEventType[discriminator]
	if !ok {
		return ""
	}

	return eventType
}

// decodeUniversalTxEvent decodes a TxWithFunds event
func decodeUniversalTxEvent(data []byte, logger zerolog.Logger) (*common.UniversalTx, error) {
	if len(data) < 120 {
		logger.Warn().
			Int("data_len", len(data)).
			Msg("data might be too short for complete TxWithFunds event")
	}

	offset := 8
	payload := &common.UniversalTx{}

	// Parse sender (32 bytes)
	if len(data) < offset+32 {
		return nil, fmt.Errorf("not enough data for sender")
	}
	sender := solana.PublicKey(data[offset : offset+32])
	// Convert sender to hex format
	senderHex, err := base58ToHex(sender.String())
	if err != nil {
		logger.Warn().Err(err).Msg("failed to convert sender to hex, using base58")
		payload.Sender = sender.String()
	} else {
		payload.Sender = senderHex
	}
	offset += 32

	// Parse recipient (20 bytes - byte20 format)
	if len(data) < offset+20 {
		return nil, fmt.Errorf("not enough data for recipient")
	}
	// Convert 20 bytes to hex string (0x + 40 hex chars)
	recipientBytes := data[offset : offset+20]
	payload.Recipient = "0x" + hex.EncodeToString(recipientBytes)
	offset += 20

	// Parse bridge_token (32 bytes)
	if len(data) < offset+32 {
		return nil, fmt.Errorf("not enough data for bridge_token")
	}
	bridgeToken := solana.PublicKey(data[offset : offset+32])
	payload.Token = bridgeToken.String()
	offset += 32

	// Parse bridge_amount (8 bytes)
	if len(data) < offset+8 {
		return nil, fmt.Errorf("not enough data for bridge_amount")
	}
	bridgeAmount := binary.LittleEndian.Uint64(data[offset : offset+8])
	payload.Amount = fmt.Sprintf("%d", bridgeAmount)
	offset += 8

	// Parse data field length (4 bytes)
	if len(data) < offset+4 {
		logger.Warn().Msg("not enough data for data field length")
		return payload, nil
	}
	dataLen := binary.LittleEndian.Uint32(data[offset : offset+4])
	offset += 4

	// Parse data field
	if len(data) < offset+int(dataLen) {
		logger.Warn().
			Uint32("expected_len", dataLen).
			Int("available", len(data)-offset).
			Msg("not enough data for data field")
		return payload, nil
	}
	if dataLen > 0 {
		dataField := data[offset : offset+int(dataLen)]
		payload.RawPayload = "0x" + hex.EncodeToString(dataField)
		offset += int(dataLen)
	}

	// Parse revert_recipient (Pubkey)
	if len(data) < offset+32 {
		logger.Warn().Msg("not enough data for revert recipient")
		return payload, nil
	}
	revertRecipient := solana.PublicKey(data[offset : offset+32])
	payload.RevertFundRecipient = revertRecipient.String()
	offset += 32

	// Parse tx_type (TxType enum)
	if len(data) <= offset {
		logger.Warn().Msg("not enough data for tx_type, defaulting to Funds")
		payload.TxType = uint(0)
		return payload, nil
	}
	txType := data[offset]
	payload.TxType = uint(txType)
	offset++

	// Parse signature data length (4 bytes)
	if len(data) < offset+4 {
		logger.Warn().Msg("not enough data for signature length")
		return payload, nil
	}
	sigLen := binary.LittleEndian.Uint32(data[offset : offset+4])
	offset += 4

	remainingBytes := len(data) - offset
	if int(sigLen) > remainingBytes {
		logger.Warn().
			Uint32("expected_len", sigLen).
			Int("available", remainingBytes).
			Msg("signature data length exceeds available data, skipping")
		return payload, nil
	}

	if sigLen > 0 {
		sigData := data[offset : offset+int(sigLen)]
		payload.VerificationData = "0x" + hex.EncodeToString(sigData)
		offset += int(sigLen)
	}

	// Parse fromCEA (bool, 1 byte) - if not present, defaults to false
	if len(data) > offset {
		payload.FromCEA = data[offset] != 0
		offset++
	}

func (cs *ChainStore) InsertEventIfNotExists(event *store.Event) (bool, error) {
	if cs.database == nil {
		return false, fmt.Errorf("database is nil")
	}

	// Check for existing event
	var existing store.Event
	err := cs.database.Client().Where("event_id = ?", event.EventID).First(&existing).Error
	if err == nil {
		// Event already exists
		return false, nil
	}
	if err != gorm.ErrRecordNotFound {
		return false, fmt.Errorf("failed to check existing event: %w", err)
	}

	// Store new event
	if err := cs.database.Client().Create(event).Error; err != nil {
		// UNIQUE constraint violation means another goroutine or poll cycle already
		// inserted this event between our check and insert — treat as duplicate.
		if strings.Contains(err.Error(), "UNIQUE constraint failed") {
			return false, nil
		}
		return false, fmt.Errorf("failed to create event: %w", err)
	}

	return true, nil
}
