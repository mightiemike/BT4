The `OldTssPubkey` field in `FundMigrationInitiatedEventData` is populated exclusively from `oldKey.TssPubkey`, fetched from `k.TssKeyHistory.Get(ctx, oldKeyId)` in the on-chain `InitiateFundMigration` keeper function, which is only invoked as part of the protocol's own migration workflow (governance/validator-driven TSS key rotation), not by an arbitrary unprivileged user transaction.
