### Title
Unvalidated Attacker-Controlled `gasToken` Address Trusted for Privileged Module-Originated EVM Calls in Gas Refund Path - (File: x/uexecutor/keeper/outbound.go)

### Summary
The audited `RequestOracle.request` bug class is "user-controlled address parameter (`_mailbox`) trusted and dispatched to by protocol code, with no whitelist against the intended target set." The same shape appears in Push Chain's outbound gas-refund path: `OutboundTx.GasToken` originates from the `UniversalTxOutbound` EVM event emitted by the `UNIVERSAL_GATEWAY_PC` system contract [1](#0-0) , and is later used, without any registry/whitelist check, as the target/argument for privileged module-originated EVM calls (`GetDefaultFeeTierForToken`, `GetSwapQuote`, `CallUniversalCoreRefundUnusedGas`) in `applyGasRefund` [2](#0-1) .

### Finding Description
`BuildOutboundsFromReceipt` decodes the `UniversalTxOutbound` event log emitted at the `UNIVERSAL_GATEWAY_PC` address and copies `event.GasToken` directly into `OutboundTx.GasToken` with no validation that this address corresponds to a registered/whitelisted PRC20 gas token in `x/uregistry`: [3](#0-2) 

Unlike the `ExternalAssetAddr`/`Prc20AssetAddr` fields, which are resolved via `uregistryKeeper.GetTokenConfigByPRC20` and thus constrained to configured tokens [4](#0-3) , `GasToken` has no equivalent registry lookup — it is accepted verbatim from the on-chain event.

Later, when the outbound is observed/finalized, `applyGasRefund` takes this unchecked `outbound.GasToken` string, converts it to an address, and uses it as an argument in a chain of privileged, module-account-signed EVM calls:
- `k.GetDefaultFeeTierForToken(ctx, gasToken)` 
- `k.getSwapQuoteForRefund(ctx, gasToken, fee, refundAmount)` → `k.GetSwapQuote(...)`
- `k.CallUniversalCoreRefundUnusedGas(ctx, gasToken, refundAmount, recipientAddr, ...)` [2](#0-1) 

`CallUniversalCoreRefundUnusedGas` executes as `DerivedEVMCall` from the `ueModuleAccAddress` (the module's own EVM identity) against the `UNIVERSAL_CORE` system contract, passing `gasToken` as a parameter: [5](#0-4) . `UniversalCore.refundUnusedGas` (Solidity, out of Go scope) is expected to treat `gasToken` as an ERC20/PRC20 contract to swap or transfer from — since the address is attacker-supplied via the payload that triggered the withdraw event, this is directly analogous to `RequestOracle`'s pattern of trusting a user-supplied contract address (`_mailbox`) for a sensitive dispatch operation instead of using a `trustedMailBox`/whitelist.

This matches the "Registry and accounting path" pivot: gas token selection is not registry-validated, so downstream refund/swap logic can be pointed at attacker-chosen contract code.

### Impact Explanation
If `UniversalCore.refundUnusedGas` or the fee-tier/quote helper calls make external calls into an attacker-supplied `gasToken` contract (e.g., calling `balanceOf`, `transfer`, `approve`, or a Uniswap-style pool interaction) without itself independently validating that the address is a registered PRC20/gas asset, an attacker who controls the payload that triggers a withdraw (and therefore controls `GasToken` in the emitted event) can:
- Force the module account to make external calls into malicious contract code (analogous to "unofficial contract" dispatch).
- Potentially manipulate fee/quote computations (`GetDefaultFeeTierForToken`, `GetSwapQuote`) via a malicious ERC20-like contract that returns crafted values, corrupting `refundAmount`/`minPCOut` used for the swap.
- In the worst case, if `UniversalCore` does not itself re-validate the token as an authorized PRC20 gas asset, the module could attempt to interact with (or be tricked regarding) an asset it does not actually control, risking gas-refund accounting corruption (wrong asset semantics / misrouted refund value) — matching the "corruption of PRC20 or native asset accounting … or refund accounting" allowed-impact category.

The exact blast radius (whether real fund loss/mint/drain occurs) depends on `UniversalCore.refundUnusedGas`'s own internal checks, which are implemented in the (out-of-Go-scope) EVM system contract and were not available to inspect in this pass. This is a genuine gap in the Go-level keeper logic: there is no whitelist/registry check on `GasToken` at the point it is captured from the event or at the point it is used for the privileged calls, unlike every other asset field in the same struct.

### Likelihood Explanation
Reachability is low-friction for an unprivileged attacker: any user can trigger a `FUNDS`/`FUNDS_AND_PAYLOAD`/`PAYLOAD` inbound whose `UniversalPayload` calls the Gateway's withdraw function with an arbitrary `gasToken` parameter (as already exercised in `TestInboundInitiatedOutbound`/`TestPostTxProcessing_WithSyntheticOutboundEvent`, which show `GasToken` flowing straight from a synthetically encoded ABI event into `OutboundTx.GasToken` with no keeper-side validation) [6](#0-5) . Once such an outbound is voted OBSERVED/finalized with an excess-gas condition (`gasFeeUsed < gasFee`), `applyGasRefund` unconditionally proceeds with the attacker-chosen `GasToken`.

### Recommendation
- Validate `event.GasToken` against `x/uregistry`'s configured gas-token/PRC20 whitelist (mirroring the `GetTokenConfigByPRC20` check already applied to `ExternalAssetAddr`/`Prc20AssetAddr`) before persisting it into `OutboundTx.GasToken` in `BuildOutboundsFromReceipt`.
- Add a defense-in-depth check in `applyGasRefund` that rejects/aborts the refund (marking `PcRefundExecution` as FAILED with a clear reason) if `outbound.GasToken` is not a recognized/whitelisted gas asset, rather than unconditionally calling `GetDefaultFeeTierForToken`/`CallUniversalCoreRefundUnusedGas` with an arbitrary address.
- Confirm (and if missing, add) that `UniversalCore.refundUnusedGas` in the Solidity system contract itself independently validates `gasToken` against its own registered token list — Go-side validation should not be the sole safeguard given the multi-layer trust model.

### Proof of Concept
1. Attacker submits an inbound (`FUNDS_AND_PAYLOAD`) whose `UniversalPayload.Data` calls the `UNIVERSAL_GATEWAY_PC.withdraw(...)` function, supplying an arbitrary `gasToken` address they control (a contract with attacker-defined `balanceOf`/ERC20-like behavior) as shown in the ABI-encoding of `UniversalTxOutbound` in `encodeUniversalTxOutboundData` (`gasToken common.Address` is a plain caller-suppliable field) [7](#0-6) .
2. Honest validators vote the inbound to quorum; `BuildOutboundsFromReceipt` decodes the log and stores `outbound.GasToken = event.GasToken` verbatim, without any registry check [8](#0-7) .
3. Validators later vote `MsgVoteOutbound` reporting `gas_fee_used < gas_fee`, triggering `applyGasRefund`, which calls `GetDefaultFeeTierForToken`, `GetSwapQuote`, and `CallUniversalCoreRefundUnusedGas` all keyed on the attacker-supplied `gasToken` address, executed from the trusted module EVM account [9](#0-8) .
4. Because there is no whitelist step in the Go keeper analogous to the `GetTokenConfigByPRC20` check used for the bridged asset, the module is forced to interact with an attacker-chosen contract for the fee/quote/refund flow — the exact "unofficial contract dispatch" pattern flagged in the source report, now reachable purely through unprivileged inbound/payload submission and honest-validator voting.

**Caveat**: I could not retrieve the Solidity source of `UniversalCore.refundUnusedGas` / `GetDefaultFeeTierForToken`'s EVM-side implementation in this session (file reads for `x/uexecutor/keeper/evm.go` full body and `gateway_pc_event_decode.go` did not complete due to tool errors on the final iteration), so I cannot confirm whether the EVM contract layer independently re-validates `gasToken` against a registry before acting on it. If it does perform such validation, this finding's impact is reduced to wasted gas/reverted refund calls rather than fund-safety impact; if it does not, the impact is as described above. This uncertainty should be resolved by a Devin session with full file access before treating this as confirmed-exploitable.

func (k Keeper) applyGasRefund(ctx sdk.Context, outbound *types.OutboundTx, obs *types.OutboundObservation) {
	if obs.GasFeeUsed == "" || outbound.GasFee == "" || outbound.GasToken == "" {
		return
	}

	gasFee := new(big.Int)
	if _, ok := gasFee.SetString(outbound.GasFee, 10); !ok {
		return
	}

	gasFeeUsed := new(big.Int)
	if _, ok := gasFeeUsed.SetString(obs.GasFeeUsed, 10); !ok {
		return
	}

	// No excess gas to refund
	if gasFee.Cmp(gasFeeUsed) <= 0 {
		return
	}

	refundAmount := new(big.Int).Sub(gasFee, gasFeeUsed)
	gasToken := common.HexToAddress(outbound.GasToken)

	// Refund recipient: prefer fund_recipient in revert_instructions, fall back to sender
	refundRecipient := outbound.Sender
	if outbound.RevertInstructions != nil && outbound.RevertInstructions.FundRecipient != "" {
		refundRecipient = outbound.RevertInstructions.FundRecipient
	}
	recipientAddr := common.HexToAddress(refundRecipient)

	refundPcTx := &types.PCTx{
		Sender:      outbound.Sender,
		BlockHeight: uint64(ctx.BlockHeight()),
	}

	// Step 1: try refund with swap (gasToken → PC native)
	fee, swapErr := k.GetDefaultFeeTierForToken(ctx, gasToken)
	var swapFallbackReason string

	if swapErr == nil {
		quote, quoteErr := k.getSwapQuoteForRefund(ctx, gasToken, fee, refundAmount)
		if quoteErr == nil {
			minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
			minPCOut.Div(minPCOut, big.NewInt(100))

			resp, err := k.CallUniversalCoreRefundUnusedGas(ctx, gasToken, refundAmount, recipientAddr, true, fee, minPCOut)
			if err == nil {
				refundPcTx.TxHash = resp.Hash
				refundPcTx.GasUsed = resp.GasUsed
				refundPcTx.Status = "SUCCESS"
				outbound.PcRefundExecution = refundPcTx
				return
			}
			swapFallbackReason = fmt.Sprintf("swap refund failed: %s", err.Error())
		} else {
			swapFallbackReason = fmt.Sprintf("quote fetch failed: %s", quoteErr.Error())
		}
	} else {
		swapFallbackReason = fmt.Sprintf("fee tier fetch failed: %s", swapErr.Error())
	}

	// Step 2: fallback — refund without swap (deposit PRC20 directly to recipient)
	ctx.Logger().Error("applyGasRefund: swap refund failed, falling back to no-swap",
		"outbound_id", outbound.Id,
		"reason", swapFallbackReason,
	)

	resp, err := k.CallUniversalCoreRefundUnusedGas(ctx, gasToken, refundAmount, recipientAddr, false, big.NewInt(0), big.NewInt(0))
	if err != nil {
		refundPcTx.Status = "FAILED"
		refundPcTx.ErrorMsg = err.Error()
	} else {
		refundPcTx.TxHash = resp.Hash
		refundPcTx.GasUsed = resp.GasUsed
		refundPcTx.Status = "SUCCESS"
	}

	outbound.PcRefundExecution = refundPcTx
	outbound.RefundSwapError = swapFallbackReason
}

// CallUniversalCoreRefundUnusedGas calls refundUnusedGas on UniversalCore to return excess gas fee
// to the recipient. withSwap=true swaps the gas token back to PC; withSwap=false deposits PRC20 directly.
func (k Keeper) CallUniversalCoreRefundUnusedGas(
	ctx sdk.Context,
	gasToken common.Address,
	amount *big.Int,
	recipient common.Address,
	withSwap bool,
	fee *big.Int,
	minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse UniversalCore ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	// fee is uint24 in Solidity — pass as *big.Int (go-ethereum ABI packs non-standard widths as *big.Int)
	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress,
		handlerAddr,
		big.NewInt(0),
		nil,
		true,
		false,
		true,
		&nonce,
		"refundUnusedGas",
		gasToken,
		amount,
		recipient,
		withSwap,
		fee,
		minPCOut,
	)
}

func encodeUniversalTxOutboundData(
	chainId string,
	target []byte,
	amount *big.Int,
	gasToken common.Address,
	gasFee *big.Int,
	gasLimit *big.Int,
	payload []byte,
	protocolFee *big.Int,
	revertRecipient common.Address,
	txType uint8,
	gasPrice *big.Int,
) ([]byte, error) {
	stringType, _ := abi.NewType("string", "", nil)
	bytesType, _ := abi.NewType("bytes", "", nil)
	uint256Type, _ := abi.NewType("uint256", "", nil)
	addressType, _ := abi.NewType("address", "", nil)
	uint8Type, _ := abi.NewType("uint8", "", nil)

	args := abi.Arguments{
		{Type: stringType},  // chainId
		{Type: bytesType},   // target
		{Type: uint256Type}, // amount
		{Type: addressType}, // gasToken
		{Type: uint256Type}, // gasFee
		{Type: uint256Type}, // gasLimit
		{Type: bytesType},   // payload
		{Type: uint256Type}, // protocolFee
		{Type: addressType}, // revertRecipient
		{Type: uint8Type},   // txType
		{Type: uint256Type}, // gasPrice
	}

	return args.Pack(
		chainId, target, amount, gasToken, gasFee, gasLimit,
		payload, protocolFee, revertRecipient, txType, gasPrice,
	)
}
