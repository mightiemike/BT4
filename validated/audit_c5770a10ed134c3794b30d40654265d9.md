### Title
Slippage protection anchored to a manipulable same-block spot quote allows sandwich-style value extraction from PRC20-to-WPC auto-swaps during inbound gas execution - (File: x/uexecutor/keeper/evm.go, execute_inbound_gas.go, execute_inbound_gas_and_payload.go)

### Summary
Push Chain's inbound gas/payload execution auto-swaps a user's bridged PRC20 into WPC (wrapped Push Coin) via a Uniswap-V3-style pool, using `GetSwapQuote` to compute `minPCOut = quote * 95 / 100` right before calling `depositPRC20WithAutoSwap`. This mirrors exactly the VectorBonding bug class: the "slippage protection" is anchored to a live, attacker-manipulable spot price fetched from the same on-chain AMM pool that executes the swap, in the same execution window, rather than to an external/trusted or time-weighted reference price.

### Finding Description
`VoteInbound` (`x/uexecutor/keeper/msg_vote_inbound.go`) synchronously calls `ExecuteInbound` → `ExecuteInboundGas`/`ExecuteInboundGasAndPayload` as soon as the ballot finalizes on the last needed validator's `MsgVoteInbound` transaction [4](#0-3) . Inside that same transaction, `GetSwapQuote` calls the live `QuoterV2.quoteExactInputSingle` spot quoter [1](#0-0)  and immediately derives `minPCOut` as 95% of that same instantaneous quote [5](#0-4) , then executes the swap through `CallPRC20DepositAutoSwap`/`depositPRC20WithAutoSwap` [6](#0-5) .

Because the quote and swap both read from the same live pool in the same block, an unprivileged attacker who front-runs the finalizing `MsgVoteInbound` transaction (validator vote transactions are ordinary, publicly broadcast Cosmos transactions visible in mempool before inclusion) by submitting a large swap against the WPC/PRC20 pool can push the spot price against the victim inbound before the quote is taken. `minPCOut` is then computed as 95% of this already-manipulated price, so the 5% band bounds only *additional* slippage during the swap call itself — it provides no protection against the pool having been moved beforehand. The attacker then back-runs by reversing their swap, extracting value from the victim's PRC20→WPC conversion, exactly as described in the sandwich-attack report (front-run swap, victim swap, back-run swap for profit).

### Impact Explanation
Every user whose inbound bridge deposit triggers the `GAS` or `GAS_AND_PAYLOAD` auto-swap path (PRC20 → WPC conversion to fund gas for a UEA) is exposed to a sandwich attack that extracts value from their bridged funds — a direct "stealing/draining of user-controlled funds" impact scoped in-bounds by the assessment rules. The loss per inbound is bounded to roughly the 5% slippage band per swap, but is systematically extractable on every qualifying inbound, and larger swings are possible for the segment fetched-quote-vs-executed-swap gap if pool liquidity is thin, or if multiple inbounds land in the same block.

### Likelihood Explanation
Exploitation requires only observing pending `MsgVoteInbound` transactions in mempool (public, unprivileged) and having capital to move the specific WPC/PRC20 pool used for that token, both realistic for a public chain with public mempools and modest-liquidity pools. No validator, TSS, or admin compromise is needed — this is purely an unprivileged, market-based attack matching the "no privileged actor" constraint of the scope.

### Recommendation
Do not derive `minPCOut` from a same-block spot quote of the exact pool being swapped against. Instead:
- Use a time-weighted average price (TWAP) oracle from the pool (e.g., Uniswap V3 `observe`) with a lookback window an attacker cannot manipulate within a single block, or
- Bound the swap amount/price against an external, validator-attested reference price (as the report's own recommendation suggested for VectorBonding: reliable off-chain-sourced prices), and/or
- Cap the maximum single-inbound swap size relative to pool depth to limit the price impact achievable in one block, and/or
- Consider allowing bridged PRC20 to be used directly for gas without forcing a swap for supported chains, removing the AMM dependency entirely for the common case.

### Proof of Concept
1. Attacker observes a `MsgVoteInbound` transaction in mempool that will finalize an inbound ballot for a large PRC20 gas deposit (public information).
2. Attacker submits, and gets included immediately before, a large PRC20 → WPC (or WPC → PRC20) swap against the same Uniswap-V3-style pool referenced in `GetUniversalCoreQuoterAddress`/`GetUniversalCoreWPCAddress`, moving the spot price unfavorably for the upcoming victim swap.
3. The finalizing `MsgVoteInbound` executes; `GetSwapQuote` reads the now-manipulated spot price, and `minPCOut` is computed as 95% of this bad price at [7](#0-6) .
4. `depositPRC20WithAutoSwap` executes the victim's swap at the manipulated price, still satisfying the (already-bad) `minPCOut` floor.
5. Attacker submits a back-run transaction reversing their initial swap, capturing the price impact caused by the victim's forced conversion, netting a profit at the victim/protocol's expense.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}
