### Title
Starknet OS `execute_replace_class` omits the declared-class check enforced by Blockifier, causing sequencer/OS state divergence - (File: `crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo`)

### Summary
The reported bug class is a validation mismatch: one code path enforces an authorization/consistency check against the correct object, while a second path that performs the actual state mutation skips that check, letting an unprivileged caller drive the system into a state its own authorization model would otherwise forbid. The sequencer contains a structurally identical mismatch in the `ReplaceClass` syscall: Blockifier (the execution engine used to build blocks) requires the target class hash to be a *declared* class before mutating a contract's class hash, but the Starknet OS's re-execution implementation of the same syscall performs the mutation unconditionally, with an explicit TODO acknowledging the missing check.

### Finding Description
`ReplaceClass` lets any contract change its own `class_hash` in `contract_state_changes`. Blockifier enforces that the requested `class_hash` must already be declared before performing this update: [1](#0-0) 

The equivalent test for the current (non-deprecated) VM/Native syscall confirms the same check exists and rejects undeclared class hashes with `"is not declared"`: [2](#0-1) 

In contrast, the Starknet OS's Cairo implementation of the same syscall, `execute_replace_class` in `syscall_impls.cairo`, updates `contract_state_changes` for the calling `contract_address` unconditionally and contains an explicit TODO stating the missing check: [3](#0-2) 

This is dispatched from `execute_syscalls` for the `REPLACE_CLASS_SELECTOR`: [4](#0-3) 

Blockifier is the authoritative execution engine that builds the block and computes the state diff that gets committed; the Starknet OS is meant to *re-execute* the same transactions and independently verify that the resulting state diff (and therefore the committed state root / block hash) matches. Because the OS's `execute_replace_class` does not verify that the requested class is declared, a code path that is reachable, revert-causing, or state-mutation-blocking in Blockifier is instead silently accepted in the OS, i.e. the two execution engines can disagree about whether/how a transaction mutates state.

### Impact Explanation
An attacker can craft an `Invoke` transaction to any contract that internally invokes the `replace_class` syscall (any account, an attacker-deployed contract, or an account whose logic exposes such a call) with an undeclared class hash argument. In Blockifier, this call fails with `StateError::UndeclaredClassHash`/`"is not declared"`, causing the calling frame (and typically the whole transaction, depending on revertibility) to fail or revert — meaning the sequencer's committed state diff does **not** contain this class-hash replacement. When the Starknet OS re-executes the same transaction to produce/verify the proof of the block, its `execute_replace_class` applies the class-hash replacement to `contract_state_changes` unconditionally, producing a different final state (and hence a different computed state commitment/block hash) than what Blockifier actually committed to storage. This is a concrete "wrong committed root / honest-node divergence" class of bug: the OS proof would not faithfully attest to the state transition the sequencer actually persisted, undermining the integrity guarantee that the OS is supposed to provide over the sequencer's execution.

### Likelihood Explanation
Triggering the divergence requires only a standard `Invoke` transaction from any user calling into a contract that exposes (or itself performs) the `replace_class` syscall with an attacker-chosen, undeclared class hash — no special privileges, staking, or operator/prover access are needed. The Cairo0 test contract in the repo even ships a trivially callable wrapper, `test_replace_class`, demonstrating how directly reachable this syscall is from ordinary transaction execution: [5](#0-4) 

The presence of the maintainers' own `TODO(Yoni, 1/1/2026)` comment confirms the check is knowingly absent in the OS implementation as of this snapshot.

### Recommendation
Add the same "class is declared" verification in `execute_replace_class` in `crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo` (and the deprecated variant in `deprecated_execute_syscalls.cairo`) that Blockifier performs — i.e., look up `class_hash` in the OS's tracked declared-class dictionary and fail/short-circuit the syscall consistently with Blockifier's `UndeclaredClassHash` behavior before mutating `contract_state_changes`.

### Proof of Concept
1. Deploy or use a contract exposing a `replace_class`-invoking entry point (e.g., the `test_replace_class` feature contract entry point).
2. Submit an `Invoke` transaction (or nested `call_contract`) that calls this entry point with a `class_hash` that has never been declared on-chain.
3. Observe that Blockifier rejects this specific execution path with `StateError::UndeclaredClassHash` (see `crates/blockifier/src/execution/syscalls/syscall_tests/replace_class.rs:17-29`), so the class-hash replacement does not appear in the block's committed state diff.
4. Feed the same transaction into the Starknet OS's execution flow that reaches `execute_replace_class` (`syscall_impls.cairo:881-920`); because there is no declared-class check, the OS applies the class-hash replacement to `contract_state_changes` regardless, producing a different final state than the one Blockifier actually committed.

// Replaces the class.
func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
