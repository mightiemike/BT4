### Title
Missing size bound on `RequestData.Secrets` in `HandleOffchainRequest` allows unbounded-size CBOR/decrypt processing that the onchain `parseCBOR`/`getMaxCBORsize` gate would have rejected - ([File: core/services/functions/listener.go])

### Summary
`handleOracleRequestV1` bounds the entire onchain CBOR blob (which embeds `Secrets`) via `l.parseCBOR(..., l.getMaxCBORsize(flags))` before any field is used, while `HandleOffchainRequest` passes an attacker-supplied, already-decoded `RequestData` straight into `l.handleRequest`/`l.getSecrets` with no equivalent upper bound on `RequestData.Secrets`. Because `getSecrets` calls `cbor.ParseDietCBORToStruct(requestData.Secrets, &donSecrets)` (for `LocationDONHosted`) and `eaClient.FetchEncryptedSecrets`/`l.decryptor.Decrypt` (for `LocationRemote`) before the only size check in `handleRequest` (`getMaxSecretsSize`) runs, an oversized `Secrets` payload is fully processed/parsed before being rejected.

### Finding Description
`handleOracleRequestV1` enforces a size cap on the raw CBOR bytes with `l.parseCBOR(request.RequestId, request.Data, l.getMaxCBORsize(request.Flags))` [1](#0-0)  before `RequestData` (including its `Secrets` field) is ever materialized, so `Secrets` can never exceed the configured CBOR max size [2](#0-1) .

`HandleOffchainRequest` never performs this step; it takes `request.Data` as an already-typed `RequestData` (populated via JSON unmarshalling in the gateway handler) and calls `l.handleRequest` directly with `RequestFlags{}` [3](#0-2) . Inside `handleRequest`, `l.getSecrets` is invoked with the raw `requestData` before any size check [4](#0-3) . For `LocationDONHosted`, `getSecrets` calls `cbor.ParseDietCBORToStruct(requestData.Secrets, &donSecrets)` with no size gate at all [5](#0-4) ; for `LocationRemote`, the full attacker-controlled `requestData.Secrets` is forwarded to `eaClient.FetchEncryptedSecrets` [6](#0-5) ; and eventually `l.decryptor.Decrypt` is invoked on the resulting `secrets` bytes [7](#0-6) . The only size check, `getMaxSecretsSize`, is applied afterward to the post-processing `nodeProvidedSecrets` result, not the raw `requestData.Secrets` input [8](#0-7)  and [9](#0-8) .

The offchain path is reachable from `functionsConnectorHandler.handleHeartbeat`, which unmarshals gateway JSON into `*OffchainRequest` and forwards it to `h.listener.HandleOffchainRequest` [10](#0-9)  and [11](#0-10) . This path is gated by `h.allowlist.Allow(fromAddr)`, `h.rateLimiter.Allow`, and membership in the configured `h.allowedHeartbeatInitiators` set [12](#0-11)  and [13](#0-12) , so only addresses explicitly configured as heartbeat initiators can trigger it — this is not an unauthenticated endpoint, but neither is it a node-operator/admin privilege in the traditional sense (it's a config-driven allowlist for external heartbeat callers).

### Impact Explanation
An allowlisted heartbeat initiator can submit a crafted `OffchainRequest.Data.Secrets` of arbitrary size (bounded only by JSON transport limits, if any, which were not verified in this review) that bypasses the onchain-path's `getMaxCBORsize`-derived indirect bound on secrets. This causes: (1) unbounded CBOR parsing via `cbor.ParseDietCBORToStruct` for `LocationDONHosted`, (2) an unbounded network payload sent to the external adapter for `LocationRemote`, and (3) an unbounded-size threshold decryption call — all before the `maxSecretsSize` check rejects the result. This is a resource-exhaustion / inconsistent-enforcement issue (CPU/memory DoS on the node running the listener), matching a "DoS" class bounty impact rather than fund loss or transaction tampering.

### Likelihood Explanation
Exploitability requires the attacker to be a preconfigured heartbeat initiator address present in `allowedHeartbeatInitiators` and passing `allowlist.Allow`/rate-limit checks — this is a real but narrower attacker model than a fully unauthenticated caller. Given that precondition, the exploit is deterministic and trivially repeatable: any oversized `Secrets` value will always skip `parseCBOR`/`getMaxCBORsize` since that code path is structurally absent from `HandleOffchainRequest`.

### Recommendation
Enforce a size check on `requestData.Secrets` (and/or the whole `OffchainRequest.Data`) in `HandleOffchainRequest`/`handleRequest` before calling `getSecrets`, using the same `getMaxSecretsSize`/`getMaxCBORsize`-style bound applied to the onchain path, so both ingestion paths enforce equivalent size limits prior to CBOR parsing, external-adapter calls, and decryption.

### Proof of Concept
Add a unit test in `core/services/functions/listener_test.go` that:
1. Constructs an `OffchainRequest` with `Data.SecretsLocation = LocationDONHosted` and `Data.Secrets` set to a large (e.g., several MB) byte slice that is not valid CBOR for `DONHostedSecrets`.
2. Calls `listener.HandleOffchainRequest(ctx, request)` and asserts that `cbor.ParseDietCBORToStruct` is invoked with the full oversized payload (e.g., via a mock/spy on `s4Storage`/decryptor or by measuring elapsed CPU/time), demonstrating no size check occurs before parsing.
3. Compares against a parallel test calling `handleOracleRequestV1` with an equivalently oversized raw CBOR blob and a configured `MaxRequestSizesList`, asserting that `parseCBOR` rejects it via `"request too big"` before `getSecrets` is ever reached.
4. Assert the differential: the offchain path proceeds into `getSecrets`/CBOR parsing/decrypt calls while the onchain path is rejected at `parseCBOR`.

func (l *functionsListener) HandleOffchainRequest(ctx context.Context, request *OffchainRequest) error {
	if request == nil {
		return errors.New("HandleOffchainRequest: received nil request")
	}
	if len(request.RequestId) != RequestIDLength {
		return fmt.Errorf("HandleOffchainRequest: invalid request ID length %d", len(request.RequestId))
	}
	if len(request.SubscriptionOwner) != common.AddressLength || len(request.RequestInitiator) != common.AddressLength {
		return errors.New("HandleOffchainRequest: SubscriptionOwner and RequestInitiator must be set to valid addresses")
	}
	if request.Timestamp < uint64(time.Now().Unix()-int64(l.pluginConfig.RequestTimeoutSec)) {
		return errors.New("HandleOffchainRequest: request timestamp is too old")
	}

	var requestId RequestID
	copy(requestId[:], request.RequestId[:32])
	subscriptionOwner := common.BytesToAddress(request.SubscriptionOwner)
	senderAddr := common.BytesToAddress(request.RequestInitiator)
	emptyTxHash := common.Hash{}
	zeroCallbackGasLimit := uint32(0)
	newReq := &Request{
		RequestID:        requestId,
		RequestTxHash:    &emptyTxHash,
		ReceivedAt:       time.Now(),
		Flags:            []byte{},
		CallbackGasLimit: &zeroCallbackGasLimit,
		// use sender address in place of coordinator contract to keep batches uniform
		CoordinatorContractAddress: &senderAddr,
		OnchainMetadata:            []byte(OffchainRequestMarker),
	}
	if err := l.pluginORM.CreateRequest(ctx, newReq); err != nil {
		if errors.Is(err, ErrDuplicateRequestID) {
			l.logger.Warnw("HandleOffchainRequest: received duplicate request ID", "requestID", formatRequestId(requestId), "err", err)
		} else {
			l.logger.Errorw("HandleOffchainRequest: failed to create a DB entry for new request", "requestID", formatRequestId(requestId), "err", err)
		}
		return err
	}
	return l.handleRequest(ctx, requestId, request.SubscriptionId, subscriptionOwner, RequestFlags{}, &request.Data)
}

func (l *functionsListener) parseCBOR(requestId RequestID, cborData []byte, maxSizeBytes uint32) (*RequestData, error) {
	if maxSizeBytes > 0 && uint32(len(cborData)) > maxSizeBytes {
		l.logger.Errorw("request too big", "requestID", formatRequestId(requestId), "requestSize", len(cborData), "maxRequestSize", maxSizeBytes)
		return nil, fmt.Errorf("request too big (max %d bytes)", maxSizeBytes)
	}

	var requestData RequestData
	if err := cbor.ParseDietCBORToStruct(cborData, &requestData); err != nil {
		l.logger.Errorw("failed to parse CBOR", "requestID", formatRequestId(requestId), "err", err)
		return nil, errors.New("CBOR parsing error")
	}

	return &requestData, nil
}

func (h *functionsConnectorHandler) HandleGatewayMessage(ctx context.Context, gatewayID string, req *jsonrpc.Request[json.RawMessage]) error {
	msg, err := hc.ValidatedMessageFromReq(req)
	if err != nil {
		h.lggr.Errorw("failed to decode request", "id", gatewayID, "err", err)
		return nil
	}
	body := &msg.Body
	fromAddr := ethCommon.HexToAddress(body.Sender)
	if !h.allowlist.Allow(fromAddr) {
		h.lggr.Errorw("allowlist prevented the request from this address", "id", gatewayID, "address", fromAddr)
		return nil
	}
	if !h.rateLimiter.Allow(body.Sender) {
		h.lggr.Errorw("request rate-limited", "id", gatewayID, "address", fromAddr)
		return nil
	}
	h.lggr.Debugw("handling gateway request", "id", gatewayID, "method", body.Method)

	switch body.Method {
	case functions.MethodSecretsList:
		h.handleSecretsList(ctx, gatewayID, body, fromAddr)
	case functions.MethodSecretsSet:
		if balance, err := h.subscriptions.GetMaxUserBalance(fromAddr); err != nil || balance.Cmp(h.minimumBalance.ToInt()) < 0 {
			h.lggr.Errorw("user subscription has insufficient balance", "id", gatewayID, "address", fromAddr, "balance", balance, "minBalance", h.minimumBalance)
			response := functions.ResponseBase{
				Success:      false,
				ErrorMessage: "user subscription has insufficient balance",
			}
			h.sendResponseAndLog(ctx, gatewayID, body, response)
			return nil
		}
		h.handleSecretsSet(ctx, gatewayID, body, fromAddr)
	case functions.MethodHeartbeat:
		h.handleHeartbeat(ctx, gatewayID, body, fromAddr)
	default:
		h.lggr.Errorw("unsupported method", "id", gatewayID, "method", body.Method)
	}
	return nil
}

func (h *functionsConnectorHandler) handleHeartbeat(ctx context.Context, gatewayId string, requestBody *api.MessageBody, fromAddr ethCommon.Address) {
	var request *OffchainRequest
	err := json.Unmarshal(requestBody.Payload, &request)
	if err != nil {
		h.sendResponseAndLog(ctx, gatewayId, requestBody, internalErrorResponse(fmt.Sprintf("failed to unmarshal request: %v", err)))
		return
	}
	if _, ok := h.allowedHeartbeatInitiators[requestBody.Sender]; !ok {
		h.sendResponseAndLog(ctx, gatewayId, requestBody, internalErrorResponse("sender not allowed to send heartbeat requests"))
		return
	}
	if !bytes.Equal(request.RequestInitiator, fromAddr.Bytes()) {
		h.sendResponseAndLog(ctx, gatewayId, requestBody, internalErrorResponse("RequestInitiator doesn't match sender"))
		return
	}
	if !bytes.Equal(request.SubscriptionOwner, fromAddr.Bytes()) {
		h.sendResponseAndLog(ctx, gatewayId, requestBody, internalErrorResponse("SubscriptionOwner doesn't match sender"))
		return
	}
	if request.Timestamp < uint64(time.Now().Unix())-uint64(h.requestTimeoutSec) {
		h.sendResponseAndLog(ctx, gatewayId, requestBody, internalErrorResponse("Request is too old"))
		return
	}

	internalId := InternalId(fromAddr.Bytes(), request.RequestId)
	request.RequestId = internalId[:]
	h.lggr.Infow("handling offchain heartbeat", "messageId", requestBody.MessageId, "internalId", internalId, "sender", requestBody.Sender)
	h.mu.Lock()
	response, ok := h.heartbeatRequests[internalId]
	if !ok { // new request
		response = &HeartbeatResponse{
			Status:     RequestStatePending,
			ReceivedTs: uint64(time.Now().Unix()),
		}
		h.cacheNewRequestLocked(internalId, response)
		h.shutdownWaitGroup.Add(1)
		go h.handleOffchainRequest(request)
	}
	responseToSend := *response
	h.mu.Unlock()
	requestBody.Receiver = requestBody.Sender
	h.sendResponseAndLog(ctx, gatewayId, requestBody, responseToSend)
}

func (h *functionsConnectorHandler) handleOffchainRequest(request *OffchainRequest) {
	defer h.shutdownWaitGroup.Done()
	ctx, cancel := h.chStop.CtxWithTimeout(time.Duration(h.requestTimeoutSec) * time.Second)
	defer cancel()
	err := h.listener.HandleOffchainRequest(ctx, request)
	if err != nil {
		h.lggr.Errorw("internal error while processing", "id", request.RequestId, "err", err)
		h.mu.Lock()
		defer h.mu.Unlock()
		state, ok := h.heartbeatRequests[RequestID(request.RequestId)]
		if !ok {
			h.lggr.Errorw("request unexpectedly disappeared from local cache", "id", request.RequestId)
			return
		}
		state.CompletedTs = uint64(time.Now().Unix())
		state.Status = RequestStateInternalError
		state.InternalError = err.Error()
	} else {
		// no error - results will be sent to OCR aggregation and returned via reportLoop()
		h.lggr.Infow("request processed successfully, waiting for aggregation ...", "id", request.RequestId)
	}
}
