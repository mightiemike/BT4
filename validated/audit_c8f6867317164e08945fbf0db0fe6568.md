## Assessment: Valid Finding

This traces to a real gap: the "unused gas" refund budget is set from a **momentary, attacker-influenceable oracle snapshot** rather than the actual amount that will later be spent, and the code applies no bound on the delta it hands out.

### Title
Refund accounting trusts a single-snapshot chain-meta gas price, letting an attacker inflate SVM prioritization fees to extract an oversized `refundUnusedGas` payout - (`x/uexecutor/keeper/outbound.go`, `x/uexecutor/keeper/build_revert_outbound.go`, `x/uexecutor/keeper/chain_meta.go`)

### Summary
`buildRevertOutbound` snapshots `outbound.GasFee` once, at the moment an inbound reverts, by calling `UniversalCore.getOutboundTxGasAndFees`, which reads the on-chain gas-price oracle populated by `VoteChainMeta`/`ChainMetaOracle`. That oracle's price for Solana comes straight from `GetRecentPrioritizationFees` (an unauthenticated read of current network conditions) with only a light median-of-recent-votes/staleness filter, no cap, and no dampening against short-lived spikes. Later, when the honestly-broadcast revert transaction lands, `VoteOutbound` reports the real `gasFeeUsed`, and `applyGasRefund` blindly computes `refundAmount = gasFee - gasFeeUsed` and pays it out via `CallUniversalCoreRefundUnusedGas` to `outbound.RevertInstructions.FundRecipient` — a field the attacker fully controls on their own inbound. [1](#0-0) [2](#0-1) [3](#0-2) [4](#0-3) 

### Finding Description
1. An unprivileged attacker submits an ordinary bridging deposit on Solana whose inbound payload is crafted to fail on Push Chain (e.g., an invalid payload / unsupported target), with `RevertInstructions.FundRecipient` pointed at their own address — a field a user fully controls on their own inbound. [5](#0-4) 
2. Concurrently (and continuously, to survive the staleness window and reach a majority of independently-polling validators), the attacker spams the Solana network with high-priority-fee transactions of their own, driving up `GetRecentPrioritizationFees` — a global, unauthenticated network read with no per-attacker filtering. [6](#0-5) 
3. Each honest Universal Validator's `ChainMetaOracle.fetchAndVoteChainMeta` reads this inflated fee and votes it in via `VoteChainMeta`; enough concurrently-fresh votes push the on-chain median up. [7](#0-6) 
4. When the attacker's inbound fails, `buildRevertOutbound` fetches `GasFee` from `UniversalCore.getOutboundTxGasAndFees` using the now-inflated oracle price and stores it on the `INBOUND_REVERT` outbound. [3](#0-2) 
5. Honest TSS validators later sign and broadcast the actual revert transaction on Solana at the real, by-then-normal market fee, and honestly report the true `gasFeeUsed` via `MsgVoteOutbound`.
6. `applyGasRefund` computes `refundAmount = gasFee(inflated) - gasFeeUsed(real, low)` with no sanity bound, no cross-check against a longer-window average, and no cap relative to the actual amount ever collected/reserved for this outbound, then calls `CallUniversalCoreRefundUnusedGas`, transferring the excess to the attacker-controlled recipient. [8](#0-7) 

The path requires no malicious validator, relayer, or admin — every Universal Validator and TSS signer behaves honestly and reports what they actually observed. The exploitable gap is that scoped code (`buildRevertOutbound`/`applyGasRefund`/`chain_meta.go`) trusts a transient, attacker-manipulable snapshot of an external fee market as a hard budget, and pays out the full delta against a later honest, lower observation with no clamping.

### Impact Explanation
A successful run drains protocol-held PRC20/native balance equal to the delta between the inflated gas budget and the real gas cost, sent directly to an attacker-chosen address via `refundUnusedGas`. This is an unauthorized refund of protocol-controlled funds and a corruption of gas-fee/refund accounting, both explicitly in-scope impacts.

### Likelihood Explanation
Moderate-to-low in practice: the attacker must sustain an elevated median across Solana's *entire* recent-fee window long enough for a majority of independently-polling Universal Validators to converge their votes within `chainMetaVoteStalenessSeconds`, and must pay real SOL fees to do so (paid to Solana validators, not recovered). The payoff is bounded by how much the refund delta exceeds the attacker's spamming cost, and by liquidity/route limits in `getSwapQuoteForRefund`. Still, the attack requires only permissionless actions (ordinary Solana transactions + a crafted bridging deposit) and no privileged role, so it is reachable by any unprivileged actor with sufficient capital to move the fee market briefly.

### Recommendation
- Do not use a single-point oracle snapshot as a hard gas budget for refund purposes; use a time-weighted/smoothed average over a longer window resistant to short bursts.
- Bound `refundAmount` in `applyGasRefund` to a sane multiple of the gasLimit × a robust (e.g., trimmed-mean or capped) price rather than the raw oracle delta.
- Consider capping or rate-limiting how much of `outbound.GasFee` can be refunded relative to a rolling baseline price for the chain, and/or require the refund path to reconcile against actual observed price at the time the outbound was signed/broadcast (closer in time to `gasFeeUsed`) rather than at outbound-creation time.

### Proof of Concept
Integration-test outline (mirrors the existing `test/integration/uexecutor/gas_fee_refund_test.go` patterns): stub the SVM chain-meta oracle/mock UniversalCore to return an inflated `GasFee` (simulating attacker-inflated prioritization fees) when `buildRevertOutbound` is invoked for a crafted failing inbound with `RevertInstructions.FundRecipient` = attacker address; then complete `MsgVoteOutbound` with a low, honest `gasFeeUsed`; assert `OutboundTx.PcRefundExecution` reflects a `refundAmount` (`GasFee - gasFeeUsed`) sent to the attacker's recipient that exceeds any amount the attacker actually spent for their own transaction. // GetGasPrice fetches the current gas price (prioritization fee) from Solana
func (rc *RPCClient) GetGasPrice(ctx context.Context) (*big.Int, error) {
	// Use executeWithFailover to handle RPC calls with automatic failover
	type prioritizationFee struct {
		Slot              uint64
		PrioritizationFee uint64
	}
	var result []prioritizationFee

	err := rc.executeWithFailover(ctx, "get_gas_price", func(client *rpc.Client) error {
		fees, err := client.GetRecentPrioritizationFees(ctx, nil)
		if err != nil {
			return fmt.Errorf("failed to get recent prioritization fees: %w", err)
		}
		// Convert to our local type
		for _, fee := range fees {
			result = append(result, prioritizationFee{
				Slot:              fee.Slot,
				PrioritizationFee: fee.PrioritizationFee,
			})
		}
		return nil
	})

	if err != nil {
		return nil, err
	}

	if len(result) == 0 {
		// No recent fees, return a default minimum
		return big.NewInt(1000), nil // 1000 lamports per compute unit as default
	}

	// Collect all non-zero fees
	var fees []uint64
	for _, fee := range result {
		if fee.PrioritizationFee > 0 {
			fees = append(fees, fee.PrioritizationFee)
		}
	}

	// If no non-zero fees, use default
	if len(fees) == 0 {
		return big.NewInt(1000), nil
	}

	// Calculate median fee
	medianFee := calculateMedian(fees)
	return big.NewInt(int64(medianFee)), nil
}

func (k Keeper) applyGasRefund(ctx sdk.Context, outbound *types.OutboundTx, obs *types.OutboundObservation) {
	if obs.GasFeeUsed == "" || outbound.GasFee == "" || outbound.GasToken == "" {
		return
	}

	gasFee := new(big.Int)
	if _, ok := gasFee.SetString(outbound.GasFee, 10); !ok {
		return
	}

	gasFeeUsed := new(big.Int)
	if _, ok := gasFeeUsed.SetString(obs.GasFeeUsed, 10); !ok {
		return
	}

	// No excess gas to refund
	if gasFee.Cmp(gasFeeUsed) <= 0 {
		return
	}

	refundAmount := new(big.Int).Sub(gasFee, gasFeeUsed)
	gasToken := common.HexToAddress(outbound.GasToken)

	// Refund recipient: prefer fund_recipient in revert_instructions, fall back to sender
	refundRecipient := outbound.Sender
	if outbound.RevertInstructions != nil && outbound.RevertInstructions.FundRecipient != "" {
		refundRecipient = outbound.RevertInstructions.FundRecipient
	}
	recipientAddr := common.HexToAddress(refundRecipient)

	refundPcTx := &types.PCTx{
		Sender:      outbound.Sender,
		BlockHeight: uint64(ctx.BlockHeight()),
	}

	// Step 1: try refund with swap (gasToken → PC native)
	fee, swapErr := k.GetDefaultFeeTierForToken(ctx, gasToken)
	var swapFallbackReason string

	if swapErr == nil {
		quote, quoteErr := k.getSwapQuoteForRefund(ctx, gasToken, fee, refundAmount)
		if quoteErr == nil {
			minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
			minPCOut.Div(minPCOut, big.NewInt(100))

			resp, err := k.CallUniversalCoreRefundUnusedGas(ctx, gasToken, refundAmount, recipientAddr, true, fee, minPCOut)
			if err == nil {
				refundPcTx.TxHash = resp.Hash
				refundPcTx.GasUsed = resp.GasUsed
				refundPcTx.Status = "SUCCESS"
				outbound.PcRefundExecution = refundPcTx
				return
			}
			swapFallbackReason = fmt.Sprintf("swap refund failed: %s", err.Error())
		} else {
			swapFallbackReason = fmt.Sprintf("quote fetch failed: %s", quoteErr.Error())
		}
	} else {
		swapFallbackReason = fmt.Sprintf("fee tier fetch failed: %s", swapErr.Error())
	}

	// Step 2: fallback — refund without swap (deposit PRC20 directly to recipient)
	ctx.Logger().Error("applyGasRefund: swap refund failed, falling back to no-swap",
		"outbound_id", outbound.Id,
		"reason", swapFallbackReason,
	)

	resp, err := k.CallUniversalCoreRefundUnusedGas(ctx, gasToken, refundAmount, recipientAddr, false, big.NewInt(0), big.NewInt(0))
	if err != nil {
		refundPcTx.Status = "FAILED"
		refundPcTx.ErrorMsg = err.Error()
	} else {
		refundPcTx.TxHash = resp.Hash
		refundPcTx.GasUsed = resp.GasUsed
		refundPcTx.Status = "SUCCESS"
	}

	outbound.PcRefundExecution = refundPcTx
	outbound.RefundSwapError = swapFallbackReason
