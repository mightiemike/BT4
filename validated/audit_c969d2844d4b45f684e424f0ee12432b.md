### Title
Missing declared-class validation in Starknet OS `replace_class` syscall causes Blockifier/OS state divergence - (File: crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo)

### Summary
The external report's root cause is "lack of check function parameter legitimate" — the vulnerable contract accepted attacker-controlled `MigrateParams` (pair/token/tick/price) without validating they were legitimate/consistent with the actual position being acted upon, letting the caller dictate improper state changes. The sequencer analog is the `class_hash` parameter passed to the `replace_class` syscall: the Rust execution engine (Blockifier) validates that the supplied class hash is legitimate (declared and of the correct Cairo version) before committing the class replacement, but the Starknet OS's Cairo implementation of the same syscall performs the class-hash-to-contract-address update unconditionally, with an explicit acknowledged gap.

### Finding Description
In the blockifier (the component the sequencer uses to execute transactions and build blocks), `replace_class` explicitly checks that the target class hash is declared and Cairo1 before mutating state: [1](#0-0) 

The deprecated (Cairo0) syscall handler enforces the same rule ("Ensure the class is declared (by reading it)"): [2](#0-1) 

However, the Starknet OS — which re-executes the same block to produce the proof that is ultimately used to commit state to L1 — implements `execute_replace_class` for the current syscall ABI with an explicit TODO acknowledging the missing check, and performs the `dict_update` on `contract_state_changes` unconditionally based on the caller-supplied `class_hash`: [3](#0-2) 

The legacy Cairo0 OS execution path (`deprecated_execute_syscalls.cairo`) has the identical gap — no check that `class_hash` corresponds to a declared class before updating the contract's class assignment: [4](#0-3) 

This is directly analogous to the TeamFinance root cause: a critical, attacker/user-suppliable parameter (`class_hash`, reachable from any unprivileged contract via `replace_class_syscall`, e.g. as exercised in `test_replace_class`) is trusted and acted upon by one component (the OS/proving system) without the legitimacy check ("is this actually a declared class hash?") that the other authoritative component (Blockifier) enforces: [5](#0-4) 

### Impact Explanation
Because the check is asserted in Blockifier (the reference execution engine used to build and validate blocks) but not asserted in the Starknet OS (the proven re-execution used to justify the committed state root / block hash), the two components can disagree on whether a given `replace_class` invocation with an illegitimate `class_hash` is valid. Any place where the OS accepts a state transition that Blockifier would have rejected (or vice versa) is a path toward the OS proving an incorrect state root/class assignment for a contract, i.e. a wrong committed root, honest-node divergence, or unauthorized account action (a contract's class silently reassigned to an undeclared/arbitrary hash without the safety check other paths enforce). This maps to the explicitly accepted impact categories (wrong committed root/block hash, honest-node divergence, unauthorized account action).

### Likelihood Explanation
`replace_class_syscall` is callable by any unprivileged contract from a normal `__execute__` entry point — no special privilege is required, matching the "single submitted transaction/contract call" scope requirement. The gap is not hypothetical: it is called out by an explicit `// TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.` comment in the OS source itself, confirming the check is known-missing rather than merely undiscovered.

### Recommendation
Add the same "class must be declared" (and, if applicable, Cairo-version) check to both Starknet OS implementations of `execute_replace_class` (`syscall_impls.cairo` and `deprecated_execute_syscalls.cairo`) that Blockifier already performs in `syscall_base.rs::replace_class`, so that the OS's accepted state transitions for this syscall are constrained identically to the Blockifier's, eliminating any possibility of divergence between the two authoritative execution paths.

### Proof of Concept
1. Deploy/using any contract exposing `replace_class_syscall` (e.g. `test_contract.cairo`'s `test_replace_class`), an unprivileged sender submits an `__execute__` invoke transaction calling `replace_class_syscall(class_hash)` with an undeclared/arbitrary `class_hash`. [6](#0-5) 
2. Blockifier's `replace_class` rejects this at execution time via `get_compiled_class(class_hash)` returning `UndeclaredClassHash`, exactly as demonstrated in the negative-flow unit test: [7](#0-6) 
3. The corresponding Starknet OS execution routine for the same syscall performs the `contract_state_changes` update unconditionally without re-deriving/asserting that `class_hash` is declared, as shown by the TODO and unconditional `dict_update`: [8](#0-7) 
4. This asymmetry between the two independently-implemented "ground truth" execution engines for the identical syscall parameter is the sequencer analog of the TeamFinance bug class: an unvalidated, attacker-suppliable parameter accepted by one enforcement layer but not cross-checked for legitimacy by the other.

    pub fn replace_class(&mut self, class_hash: ClassHash) -> SyscallResult<()> {
        // Ensure the class is declared (by reading it), and of type V1.
        let compiled_class = self.state.get_compiled_class(class_hash)?;

        if !is_cairo1(&compiled_class) {
            return Err(SyscallExecutionError::ForbiddenClassReplacement { class_hash });
        }
        self.state.set_class_hash_at(self.call.storage_address, class_hash)?;
        Ok(())
    }

func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
