Based on my research, I found a concrete analog in the gas-token swap logic used for automatic PRC20↔PC conversions on inbound GAS deposits and outbound gas refunds. The parallel to the Tracer finding is structural rather than literal: in both cases, a value-transfer mechanism trusts a market price that an unprivileged actor can distort immediately before the mechanism consumes it, and the distortion is realized inside a single, deterministic, chain-triggered operation with no external protection against the manipulation.

### Title
Spot-price Uniswap V3 quote used as sole slippage guard for module-executed PRC20↔PC swaps enables sandwich extraction from protocol-routed swaps - (File: x/uexecutor/keeper/evm.go, x/uexecutor/keeper/execute_inbound_gas.go, x/uexecutor/keeper/outbound.go)

### Summary
The `GAS`/`GAS_AND_PAYLOAD` inbound path and the outbound excess-gas refund path both compute a `minPCOut` slippage floor from a live, single-block Uniswap V3 `QuoterV2.quoteExactInputSingle` call, then immediately execute the real swap against that same, freshly-read AMM state in the same keeper invocation. Because the quote is a spot price read moments before consumption rather than a manipulation-resistant (e.g. TWAP) reference, any unprivileged actor able to trade against the same pool in the same block can skew the quote and the subsequent swap outcome, extracting value from the pool/protocol side of the swap that the "5% slippage" floor was meant to bound.

### Finding Description
`GetSwapQuote` in [1](#0-0)  calls `QuoterV2.quoteExactInputSingle` with `commit=false` to read the instantaneous exchange rate for `prc20 → wpc`. This value is then used directly to derive `minPCOut = quote * 95 / 100` in the inbound `GAS` handler [2](#0-1) , and again in the outbound gas-refund path via `getSwapQuoteForRefund`/`applyGasRefund` [3](#0-2) . Immediately afterward, `CallPRC20DepositAutoSwap` / `CallUniversalCoreRefundUnusedGas` executes the real swap with `commit=true` against the same pool [4](#0-3) [5](#0-4) .

Both the quote read and the swap execution happen inside the same deterministic, block-processing keeper call (triggered by an ordinary honest-validator `MsgVoteInbound`/`MsgVoteOutbound` reaching quorum — no privileged action required to *trigger* it, only to *time* it). Because Push Chain's EVM state, including the Uniswap V3 pool used here, is a normal permissionless AMM, any unprivileged account can submit ordinary swap transactions into the same block (front-running the vote-finalizing transaction) to move the pool price, causing `quoteExactInputSingle` to return a skewed value at the moment the module reads it. The 95% floor is computed from that same skewed value, so it provides no protection against the manipulation that produced it — the guard is self-referential rather than externally anchored.

This mirrors the root cause of the Tracer M-11 finding: a settlement mechanism (there, `executeTrade`+`claimReceipt`; here, the module-driven autoswap) assumes the price/outcome it observes is fair, when in fact an unprivileged party can manufacture the very market condition the mechanism relies on, immediately before the mechanism consumes it.

### Impact Explanation
An attacker who manipulates the `gasToken/WPC` pool right before their own (or any) inbound `GAS`/`GAS_AND_PAYLOAD` deposit or outbound gas refund is processed can cause the module-executed swap to settle at a distorted price. Because the module (via `UniversalCore`/Handler contract) is the party supplying or receiving liquidity in that swap, this misprices the PRC20↔PC conversion for protocol-routed value, corrupting gas/refund accounting (`OutboundTx.PcRefundExecution`, deposited PC amounts) and allowing extraction of value from the pool/protocol side of the transaction via the classic sandwich pattern — buy in front, let the mispriced module swap execute, sell back after.

### Likelihood Explanation
Every `GAS` and `GAS_AND_PAYLOAD` inbound, and every outbound with `gasFee > gasFeeUsed`, triggers this code path automatically once honest validators reach quorum — this is routine traffic, not a rare edge case. The manipulation itself requires no validator, relayer, or admin privilege: it only requires the ability to submit ordinary EVM swap transactions on Push Chain around the same block as the vote-finalizing transaction, which is available to any unprivileged user, including the same user who initiated the inbound/outbound (who can predict/trigger the timing of their own transaction's finalization).

### Recommendation
Replace the single-block spot quote with a manipulation-resistant reference (e.g., a time-weighted average price over multiple blocks, or a governance/registry-configured price band) before computing `minPCOut`, and/or require the swap to be evaluated against a price reference that cannot be moved atomically by the same actor within the block that finalizes the deposit/refund.

### Proof of Concept
1. Attacker identifies the `gasToken`/`WPC` Uniswap V3 pool used by `GetUniversalCoreQuoterAddress`/`GetUniversalCoreWPCAddress`.
2. Attacker submits their own inbound `GAS` deposit (or waits for an outbound they control to reach the refund-eligible state).
3. In the same block as the third/quorum-reaching `MsgVoteInbound`/`MsgVoteOutbound`, attacker front-runs with a large swap that skews the pool price against `gasToken`.
4. The vote-finalizing transaction executes `GetSwapQuote` → skewed low value → `minPCOut` computed off that skewed value → `CallPRC20DepositAutoSwap`/`CallUniversalCoreRefundUnusedGas` executes at the skewed price, still satisfying the (also skewed) floor.
5. Attacker back-runs to restore the pool price, capturing the price difference at the module swap's expense.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)

// CallUniversalCoreRefundUnusedGas calls refundUnusedGas on UniversalCore to return excess gas fee
// to the recipient. withSwap=true swaps the gas token back to PC; withSwap=false deposits PRC20 directly.
func (k Keeper) CallUniversalCoreRefundUnusedGas(
	ctx sdk.Context,
	gasToken common.Address,
	amount *big.Int,
	recipient common.Address,
	withSwap bool,
	fee *big.Int,
	minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse UniversalCore ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	// fee is uint24 in Solidity — pass as *big.Int (go-ethereum ABI packs non-standard widths as *big.Int)
	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress,
		handlerAddr,
		big.NewInt(0),
		nil,
		true,
		false,
		true,
		&nonce,
		"refundUnusedGas",
		gasToken,
		amount,
		recipient,
		withSwap,
		fee,
		minPCOut,
	)
}

// applyGasRefund computes the excess gas (gasFee - gasFeeUsed) and, if positive,
// calls UniversalCore refundUnusedGas. The result is recorded in outbound.PcRefundExecution.
// It is called for both successful and failed outbounds — gas is consumed on the
// external chain regardless of execution outcome.
func (k Keeper) applyGasRefund(ctx sdk.Context, outbound *types.OutboundTx, obs *types.OutboundObservation) {
	if obs.GasFeeUsed == "" || outbound.GasFee == "" || outbound.GasToken == "" {
		return
	}

	gasFee := new(big.Int)
	if _, ok := gasFee.SetString(outbound.GasFee, 10); !ok {
		return
	}

	gasFeeUsed := new(big.Int)
	if _, ok := gasFeeUsed.SetString(obs.GasFeeUsed, 10); !ok {
		return
	}

	// No excess gas to refund
	if gasFee.Cmp(gasFeeUsed) <= 0 {
		return
	}

	refundAmount := new(big.Int).Sub(gasFee, gasFeeUsed)
	gasToken := common.HexToAddress(outbound.GasToken)

	// Refund recipient: prefer fund_recipient in revert_instructions, fall back to sender
	refundRecipient := outbound.Sender
	if outbound.RevertInstructions != nil && outbound.RevertInstructions.FundRecipient != "" {
		refundRecipient = outbound.RevertInstructions.FundRecipient
	}
	recipientAddr := common.HexToAddress(refundRecipient)

	refundPcTx := &types.PCTx{
		Sender:      outbound.Sender,
		BlockHeight: uint64(ctx.BlockHeight()),
	}

	// Step 1: try refund with swap (gasToken → PC native)
	fee, swapErr := k.GetDefaultFeeTierForToken(ctx, gasToken)
	var swapFallbackReason string

	if swapErr == nil {
		quote, quoteErr := k.getSwapQuoteForRefund(ctx, gasToken, fee, refundAmount)
		if quoteErr == nil {
			minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
			minPCOut.Div(minPCOut, big.NewInt(100))

			resp, err := k.CallUniversalCoreRefundUnusedGas(ctx, gasToken, refundAmount, recipientAddr, true, fee, minPCOut)
			if err == nil {
				refundPcTx.TxHash = resp.Hash
				refundPcTx.GasUsed = resp.GasUsed
				refundPcTx.Status = "SUCCESS"
				outbound.PcRefundExecution = refundPcTx
				return
			}
			swapFallbackReason = fmt.Sprintf("swap refund failed: %s", err.Error())
		} else {
			swapFallbackReason = fmt.Sprintf("quote fetch failed: %s", quoteErr.Error())
		}
