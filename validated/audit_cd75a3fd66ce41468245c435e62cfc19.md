### Title
Gas-abstraction auto-swap relies on an unvalidated, manipulable spot-price quote from `GetSwapQuote`, enabling price-manipulation losses during PRC20→WPC conversion - (File: `x/uexecutor/keeper/evm.go`, `x/uexecutor/keeper/execute_inbound_gas.go`, `x/uexecutor/keeper/execute_inbound_gas_and_payload.go`, `x/uexecutor/keeper/outbound.go`)

### Summary
The external report flags that Chainlink's `latestRoundData()` was consumed without checking for stale rounds or a sane price, so a downstream `quoteAmount` could be wrong. Push Chain's analog "price feed" is `Keeper.GetSwapQuote`, which reads a live Uniswap V3 `QuoterV2.quoteExactInputSingle` spot quote and uses it, unvalidated, to derive `minPCOut` for the protocol's own gas-abstraction auto-swap. Like the Chainlink case, the returned value is trusted directly with no sanity/deviation check, except this oracle is not merely stale — it is an on-chain instantaneous price that any unprivileged user can move within the same or an adjacent block.

### Finding Description
`Keeper.GetSwapQuote` calls `quoteExactInputSingle` on the configured `uniswapV3Quoter` and returns the raw `amountOut` with no bounds checking of any kind: [1](#0-0) 

This quote is used directly to compute the slippage floor for the protocol-executed swap:
```go
quote, execErr = k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
...
minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
minPCOut.Div(minPCOut, big.NewInt(100))
receipt, execErr = k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
``` [2](#0-1) 

The same pattern recurs in the GAS_AND_PAYLOAD execution path: [3](#0-2)  and in the unused-gas refund swap path: [4](#0-3) 

Because `quoteExactInputSingle` reflects the Uniswap V3 pool's current tick/price with `SqrtPriceLimitX96 = 0` (no limit), it is trivially moved by ordinary swaps against that same pool — no flash loan or special privilege is required, just capital and pool access, both available to any unprivileged Push Chain user. `minPCOut` is only a 5%-below-quote floor computed off that same manipulated instant, so the derived floor moves together with the manipulated price and provides no real protection against the manipulation itself (it only bounds slippage relative to whatever price the attacker has already set).

The inbound gas-abstraction flow (`ExecuteInboundGas` / `ExecuteInboundGasAndPayload`) is reached from the ordinary user crosschain-deposit path: a user deposits an asset on a source chain, Universal Validators vote it in (an honest-validator process, not attacker-controlled), and the deposit's PRC20 representation is auto-swapped into WPC through this exact quote-then-swap sequence — entirely within default transaction submission paths and reachable by an unprivileged attacker who is simply the depositor.

### Impact Explanation
An attacker who also holds/trades the WPC/PRC20 pool on Push Chain can push the pool's instantaneous price in their favor immediately before (or in the same block window as) their own gas-abstraction deposit executes, causing `CallPRC20DepositAutoSwap` to execute at a manipulated rate. Because `minPCOut` is derived from that same manipulated quote rather than any external/TWAP reference, the swap is not protected from the manipulation — value is transferred out of the protocol-controlled swap pool relative to fair market value, corrupting gas/refund accounting and directly costing the protocol-controlled liquidity used for gas abstraction (`WPC`). This falls under "corruption of ... gas fee accounting, refund accounting ... or unauthorized state transitions" and "draining ... of protocol-controlled funds" in scope.

### Likelihood Explanation
Medium. The attacker does not need any privileged role — it only requires ordinary trading capability against the on-chain WPC/PRC20 pool and the ability to trigger their own inbound deposit (which any user can do). The main uncertainty is precise block-level timing control over when the honest-validator-driven inbound execution lands relative to the attacker's manipulation transaction, but repeated attempts, or being the sole/major depositor at low-liquidity pool moments, make this practically exploitable, especially for newly-listed low-liquidity PRC20/WPC pairs.

### Recommendation
Do not derive `minPCOut` solely from the same instantaneous quote being protected against. Options:
- Use a time-weighted average price (TWAP) from the pool (Uniswap V3 supports `observe`) as the reference price rather than the instant `quoteExactInputSingle` result, with a bounded maximum deviation check between spot and TWAP before proceeding, analogous to the Chainlink staleness/round-completeness checks recommended in the source report.
- Enforce a protocol-configured maximum acceptable price-impact/deviation threshold, rejecting or reverting the auto-swap (falling back to the no-swap deposit path) when the computed quote deviates too far from a trusted reference.
- Consider routing gas-abstraction swaps through a mechanism resistant to atomic manipulation (e.g., minimum liquidity checks, cool-down after large trades, or restricting the swap pool from arbitrary public composability).

### Proof of Concept
1. Attacker holds a modest position and pool access to the WPC/`PRC20_X` Uniswap V3 pool referenced by `uniswapV3Quoter`/`defaultFeeTier[PRC20_X]` on Push Chain.
2. Attacker submits a large swap against that pool to depress `PRC20_X`'s price relative to WPC.
3. Attacker (or in parallel) submits a crosschain deposit of `PRC20_X` on a source chain with `GAS`/`GAS_AND_PAYLOAD` type; once validators vote it in, `ExecuteInboundGas`/`ExecuteInboundGasAndPayload` calls `GetSwapQuote` → gets the manipulated low quote → computes `minPCOut` at 95% of that depressed quote → `CallPRC20DepositAutoSwap` executes the swap at the manipulated rate.
4. Attacker reverses the initial manipulating swap, netting the WPC drained from the pool during step 3 above fair value, while the protocol/pool absorbs the loss (evidenced by `GetSwapQuote` in `x/uexecutor/keeper/evm.go:500-538` returning the manipulable value used verbatim in `execute_inbound_gas.go:134-153` with no deviation or TWAP check).

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}
