### Title
Signer entries with a malformed (non-33-byte) signing key are silently coerced to an all-zero public key instead of being rejected - ([File: stackslib/src/chainstate/nakamoto/signer_set.rs])

### Summary
`RawRewardSetEntry::from_pox_4_tuple` extracts the `signer` field from the PoX reward-set tuple using `expect_buff(SIGNERS_PK_LEN)`, which — per the code's own comment — only enforces a *maximum* length of 33 bytes, not an exact length. When the buffer's actual length differs from `SIGNERS_PK_LEN`, the code does not reject the entry; it silently substitutes a fixed all-zero 33-byte array as the signer's public key and continues building the reward-set/signer-set entry as if it were valid.

### Finding Description
`RawRewardSetEntry::from_pox_4_tuple` in [1](#0-0)  pulls the `signer` buffer out of the pox-4 tuple and checks its length only for equality against `SIGNERS_PK_LEN` (33). If the length check fails, instead of propagating an error (as every other missing/malformed field in this function does via `ChainstateError::Expects`), it falls back to `[0; SIGNERS_PK_LEN]`:

```rust
// (buff 33) only enforces max size, not min size, so we need to do a len check
let pk_bytes = if signer.len() == SIGNERS_PK_LEN {
    let mut bytes = [0; SIGNERS_PK_LEN];
    bytes.copy_from_slice(signer.as_slice());
    bytes
} else {
    [0; SIGNERS_PK_LEN]
};
``` [2](#0-1) 

This mirrors the reported bug class exactly: a length-only validation (`_validateToLength` in the external report / `expect_buff(SIGNERS_PK_LEN)` here) that never asserts the payload actually decodes to the required fixed-size identity, followed by a silent substitution (burn-with-no-revert in the report / zero-pubkey coercion here) rather than a hard failure. The resulting `RawRewardSetEntry` is folded, with its full stacked-`amount_stacked` weight intact, into the Nakamoto reward/signer set used to determine signer voting weight for a reward cycle (see the surrounding call sites that build `RawRewardSetEntry` lists in [3](#0-2) ).

### Impact Explanation
Because the same deterministic substitution runs on every node, this does not by itself desynchronize state roots — every node computes the identical zeroed-out entry. The consensus-relevant harm is that a stacker who supplies a malformed (wrong-length) `signer` buffer to `stack-stx`/pox-4 gets accepted into the signer/reward set with their full stacked-STX weight attributed to the fixed placeholder key `[0u8;33]`, rather than being rejected outright. Because the substitution is a *fixed constant*, distinct minority actors that each submit a malformed signing key (whether by accident or intentionally) collapse onto the *same* signer identity, silently merging otherwise-independent stake weight under one unusable "phantom" signer entry that no private key can ever produce a valid signature for. This permanently and unrecoverably strips that stacked-STX's signing weight from the reachable threshold for the reward cycle (nobody holds the zero-key's private key), which is a bounded, minority-triggerable, silent loss of usable signer weight rather than a full chain split — analogous in class to the report's "silent burn on malformed but length-plausible input", but the actual chain-split/invalid-block-accepted severity claimed by the external report does not transfer here since all nodes agree on the (buggy) zeroed value.

### Likelihood Explanation
Triggering this requires only a single unprivileged `stack-stx`/pox-4 call with a `signer-key` buffer whose length is not exactly 33 bytes (Clarity's `(buff 33)` type only bounds the maximum length, not the minimum, so shorter buffers are legal Clarity values) — no majority, admin key, or additional coordination is needed, matching a minority-triggerable trigger condition.

### Recommendation
Reject the reward-set entry (propagate a `ChainstateError::Expects`/`Err`) whenever `signer.len() != SIGNERS_PK_LEN`, instead of silently substituting the placeholder `[0; SIGNERS_PK_LEN]` array, so malformed signer keys cannot be silently admitted into the signer set with real stacked weight attached.

### Proof of Concept
1. Call pox-4's `stack-stx` (or equivalent lock-up function) supplying a `signer-key` argument of, e.g., 4 bytes instead of the expected 33 bytes; the Clarity type `(buff 33)` accepts this because it only bounds the maximum length.
2. When the reward set for the corresponding cycle is computed, `RawRewardSetEntry::from_pox_4_tuple` reads this tuple, finds `signer.len() != SIGNERS_PK_LEN`, and falls into the `else` branch, producing `pk_bytes = [0; 33]` [2](#0-1) .
3. The resulting `RawRewardSetEntry` — carrying the staker's full `total_ustx` weight — is included in the signer set under the placeholder all-zero public key, indistinguishable from any other malformed-key entry from a different staker, silently pooling their weight under a key nobody controls.

impl RawRewardSetEntry {
    pub fn from_pox_4_tuple(is_mainnet: bool, tuple: TupleData) -> Result<Self, ChainstateError> {
        let mut tuple_data = tuple.data_map;

        let pox_addr_tuple = tuple_data.remove("pox-addr").ok_or_else(|| {
            ChainstateError::Expects(
                "no `pox-addr` in return value from (get-reward-set-pox-address)".into(),
            )
        })?;

        let reward_address = PoxAddress::try_from_pox_tuple(is_mainnet, &pox_addr_tuple)
            .unwrap_or_else(|| {
                warn!("Invalid PoX address supplied, replacing with burn address"; "pox_addr_tuple" => %pox_addr_tuple);
                PoxAddress::standard_burn_address(is_mainnet)
            });

        let total_ustx = tuple_data
            .remove("total-ustx")
            .ok_or_else(|| {
                ChainstateError::Expects(
                    "no 'total-ustx' in return value from (pox-4.get-reward-set-pox-address)"
                        .into(),
                )
            })?
            .expect_u128().map_err(|_| {
                ChainstateError::Expects(
                    "'total-ustx' in return value from (pox-4.get-reward-set-pox-address) is not a u128".into(),
                )
            })?.try_into().map_err(|_| ChainstateError::Expects("'total-ustx' value out of range for u64".into()))?;

        let stacker = tuple_data
            .remove("stacker")
            .ok_or_else(|| {
                ChainstateError::Expects(
                    "no 'stacker' in return value from (pox-4.get-reward-set-pox-address)".into(),
                )
            })?
            .expect_optional().map_err(|_| {
                ChainstateError::Expects(
                    "'stacker' in return value from (pox-4.get-reward-set-pox-address) is not optional".into(),
                )
            })?
            .map(|value| value.expect_principal())
            .transpose().map_err(|_| {
                ChainstateError::Expects(
                    "'stacker' in return value from (pox-4.get-reward-set-pox-address) is not a principal".into(),
                )
            })?;

        let signer = tuple_data
            .remove("signer")
            .ok_or_else(|| {
                ChainstateError::Expects(
                    "no 'signer' in return value from (pox-4.get-reward-set-pox-address)".into(),
                )
            })?
            .expect_buff(SIGNERS_PK_LEN).map_err(|_| {
                ChainstateError::Expects(
                    format!("'signer' in return value from (pox-4.get-reward-set-pox-address) is not a buff of length {SIGNERS_PK_LEN}"),
                )
            })?;

        // (buff 33) only enforces max size, not min size, so we need to do a len check
        let pk_bytes = if signer.len() == SIGNERS_PK_LEN {
            let mut bytes = [0; SIGNERS_PK_LEN];
            bytes.copy_from_slice(signer.as_slice());
            bytes
        } else {
            [0; SIGNERS_PK_LEN]
        };

        debug!(
            "Parsed PoX reward address";
            "stacked_ustx" => total_ustx,
            "reward_address" => %reward_address,
            "stacker" => ?stacker,
            "signer" => to_hex(&signer),
        );

        Ok(Self {
            reward_address,
            amount_stacked: total_ustx,
            stacker,
            signer: Some(pk_bytes),
        })
    }
