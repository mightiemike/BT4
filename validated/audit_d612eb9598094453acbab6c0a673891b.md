**Analysis:** `ConcurrentBTreeInterner::lookup`/`intern_deferred` in [1](#0-0)  use a standard double-checked-locking pattern: `intern_deferred` first takes a read lock to check for an existing entry, and if absent, takes a write lock and **rechecks** the map before inserting [2](#0-1) . A concurrent `lookup()` can only ever return `None` for a value that has not yet completed insertion under the write lock — it cannot return `None` for a value whose `intern_deferred` call has already returned/completed, because completion of `intern_deferred` happens-after the `map.insert` under the same lock that `lookup`'s `map.get` also acquires (RwLock ensures no reordering visible across threads). This is validated by the crate's own proptest `test_interner_consistency`, which asserts `lookup` never contradicts a completed `intern` for the same value [3](#0-2) .

More importantly, this interner is not wired into any authenticated API or state-view path. The only production wrapper, `InternedModuleIdPool`, is used solely by `#[cfg(test)]` test utilities [4](#0-3) . The actual production struct-name caching used for `StructTag` resolution, `StructNameIndexMap::struct_name_to_idx`, is a separate, independent implementation (its own `RwLock<IndexMap<...>>` with its own double-checked-locking, not `ConcurrentBTreeInterner`) [5](#0-4) . Neither structure caches a "None"/negative lookup result anywhere that would be served back to an API consumer for a later versioned read — there is no such negative-result cache in this code at all.

Since (a) there is no race window in which `lookup` can observe `None` after a completed `intern_deferred` for the same value, and (b) there is no caching/API layer here that persists or serves negative lookup results across versioned state reads, the described exploit chain does not exist in this code.

    pub fn intern_deferred(&self, val: Cow<T>) -> usize
    where
        T: Clone + Ord,
    {
        {
            let inner = self.inner.read();
            if let Some(idx) = inner.map.get(val.as_ref()) {
                return *idx;
            }
        }

        // Convert the value into owned outside the critical section to reduce contention.
        // (This could be an expensive clone.)
        let val = val.into_owned();

        // Note on synchronization: once we acquire the write lock, we need to check again
        // if the value has already been interned, which could happen due to race conditions.
        let mut inner = self.inner.write();
        if let Some(idx) = inner.map.get(&val) {
            return *idx;
        }

        unsafe {
            let r = inner.alloc(val);
            inner.vec.push(r);
            let idx = inner.vec.len() - 1;
            inner.map.insert(r, idx);
            idx
        }
    }

    /// Returns the number of interned values.
    pub fn len(&self) -> usize {
        self.inner.read().vec.len()
    }

    /// Returns true if the interner is empty.
    pub fn is_empty(&self) -> bool {
        self.inner.read().vec.is_empty()
    }

    /// Looks up a value by reference and returns its index.
    /// Returns None if the value has not been interned yet.
    pub fn lookup(&self, val: &T) -> Option<usize> {
        self.inner.read().map.get(val).cloned()
    }

    fn test_interner_consistency() {
        use proptest::prelude::*;
        use std::collections::HashMap;

        #[derive(Debug, Clone)]
        enum Operation {
            Intern(i32),
            Lookup(i32),
        }

        impl Arbitrary for Operation {
            type Parameters = ();
            type Strategy = BoxedStrategy<Operation>;

            fn arbitrary_with(_args: ()) -> Self::Strategy {
                use proptest::strategy::Strategy;

                (any::<bool>(), any::<i32>())
                    .prop_map(|(is_intern, value)| {
                        if is_intern {
                            Operation::Intern(value)
                        } else {
                            Operation::Lookup(value)
                        }
                    })
                    .boxed()
            }
        }

        proptest!(|(operations: Vec<Operation>)| {
            let interner = ConcurrentBTreeInterner::new();
            let mut expected_indices: HashMap<i32, usize> = HashMap::new();

            for operation in operations {
                match operation {
                    Operation::Intern(value) => {
                        let idx = interner.intern(value);

                        // Check index stability: if we've seen this value before, index should be the same
                        if let Some(&expected_idx) = expected_indices.get(&value) {
                            prop_assert_eq!(idx, expected_idx, "Index stability violated for value {}", value);
                        } else {
                            // First time seeing this value, record the index
                            expected_indices.insert(value, idx);
                        }

                        // Check intern <=> get consistency
                        let retrieved = interner.get(idx);
                        prop_assert!(retrieved.is_some(), "Get returned None for index {}", idx);
                        prop_assert_eq!(*retrieved.unwrap(), value, "Get returned wrong value for index {}", idx);

                        // Check intern <=> lookup consistency
                        let lookup_idx = interner.lookup(&value);
                        prop_assert_eq!(lookup_idx, Some(idx), "Lookup returned wrong index for value {}", value);
                    },
                    Operation::Lookup(value) => {
                        let lookup_idx = interner.lookup(&value);

                        if let Some(idx) = lookup_idx {
                            // If lookup found the value, check consistency
                            let retrieved = interner.get(idx);
                            prop_assert!(retrieved.is_some(), "Get returned None after lookup for value {}", value);
                            prop_assert_eq!(*retrieved.unwrap(), value, "Lookup <=> get consistency violated for value {}", value);

                            // Check index stability
                            if let Some(&expected_idx) = expected_indices.get(&value) {
                                prop_assert_eq!(idx, expected_idx, "Index stability violated for value {}", value);
                            } else {
                                // This shouldn't happen - if lookup found it, we should have recorded it
                                prop_assert!(false, "Lookup found value {} but it wasn't in expected_indices", value);
                            }
                        } else {
                            // If lookup didn't find it, it shouldn't be in our expected indices
                            prop_assert!(!expected_indices.contains_key(&value), "Lookup missed value {} that should exist", value);
                        }
                    }
                }
            }

            // Check that interner length matches our expectations
            prop_assert_eq!(interner.len(), expected_indices.len(), "Interner length mismatch");
        });

    pub fn struct_name_to_idx(
        &self,
        struct_name: &StructIdentifier,
    ) -> PartialVMResult<StructNameIndex> {
        {
            let index_map = self.0.read();
            if let Some(idx) = index_map.forward_map.get(struct_name) {
                return Ok(StructNameIndex(*idx));
            }
        }

        // Possibly need to insert, so make the copies outside of the lock.
        let forward_key = struct_name.clone();
        let backward_value = Arc::new(struct_name.clone());

        let idx = {
            let mut index_map = self.0.write();

            if let Some(idx) = index_map.forward_map.get(struct_name) {
                return Ok(StructNameIndex(*idx));
            }

            let idx = index_map.backward_map.len() as u32;
            index_map.backward_map.push(backward_value);
            index_map.forward_map.insert(forward_key, idx);
            idx
        };

        Ok(StructNameIndex(idx))
    }
