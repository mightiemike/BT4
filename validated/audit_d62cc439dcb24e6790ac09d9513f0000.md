### Title
Poison-microblock report can be created against an honest, non-equivocating miner via ECDSA signature malleability, since no check verifies the two headers actually diverge in content - (File: `stackslib/src/chainstate/stacks/db/transactions.rs`)

### Summary
`handle_poison_microblock` and its helper `check_microblock_header_signer` only verify that `mblock_header_1` and `mblock_header_2` share `sequence`/`prev_block`/`version` and that `check_recover_pubkey()` on each recovers to the same `Hash160`. Neither this function nor the mempool-level precheck in `stackslib/src/chainstate/stacks/db/blocks.rs` ever checks that the two headers actually diverge in content (e.g. differing `tx_merkle_root`), so a single genuinely-broadcast microblock header can be turned into a "conflicting pair" by pure public-key signature malleability, without the reporter ever observing a real fork.

### Finding Description
The intended equality is: *a recorded poison-microblock report at height H for pubkey-hash P implies the miner holding P actually double-signed two distinct microblocks (different content) at the same sequence number* — i.e. genuine equivocation.

The code path:
- `TransactionPayload::PoisonMicroblock(header_1, header_2)` is checked in the mempool precheck at [1](#0-0)  — it only verifies `sequence`, `prev_block`, `version` equality and that `check_recover_pubkey()` on both headers yields the same `Hash160`. It never checks `tx_merkle_root` or otherwise that the header contents differ.
- `StacksChainState::check_microblock_header_signer` in `transactions.rs` performs the same signer-equality check with no content-divergence check: [2](#0-1) .
- `handle_poison_microblock` then trusts this result and, once the pubkey-hash's maturity window is satisfied, records a report via `insert_microblock_poison` keyed only on `mblock_pubk_height` and `mblock_header_1.sequence`: [3](#0-2) .
- `check_recover_pubkey` computes the recovered pubkey from a digest that **excludes the signature field** (it is zeroed before hashing) via `StacksMicroblockHeader::serialize(..., true)`, then calls `recover_to_pubkey_without_validating_low_s`: [4](#0-3) .

Because the recovery function explicitly does **not** enforce canonical low-S signatures, both the canonical `(r, s)` and its ECDSA-malleable counterpart `(r, n-s)` (with flipped recovery id) recover to the identical public key/`Hash160` — this is standard ECDSA malleability and requires no knowledge of the private key, only the original valid signature (which is public, since it was broadcast in the miner's microblock).

Exploit: an attacker observes one legitimately broadcast, non-conflicting microblock header (version, sequence, prev_block, tx_merkle_root, signature) from an honest miner. The attacker computes the malleated signature variant of the same signature (public-key-only arithmetic) and constructs `header_2` as a byte-identical copy of `header_1` except for this alternate signature encoding. Both headers now have equal `sequence`/`prev_block`/`version` (trivially, since they are otherwise identical) and both recover to the same `Hash160`, satisfying every check in `check_microblock_header_signer` and the mempool precheck. Submitting this as `TransactionPayload::PoisonMicroblock(header_1, header_2)` causes `insert_microblock_poison` to record a report against the honest miner even though the miner never produced two divergent microblocks — no fork occurred.

Existing guards do not catch this: the maturity-window check (`MINER_REWARD_MATURITY`) only bounds *when* a report can be filed, not *whether* the headers genuinely conflict; `check_microblock_header_signer` only asserts "same signer," never "different content."

### Impact Explanation
This is a reward-theft/mis-slashing vector: filing a poison-microblock report against an honest miner diverts/withholds that miner's coinbase reward (per the poison-microblock commission logic) to an attacker who reports a fabricated "second" header, without the honest miner ever having equivocated. This is block-reward theft from an honest miner's coinbase, matching the Critical impact category (reward paid to the wrong party).

### Likelihood Explanation
Preconditions: the attacker needs (1) a single publicly-broadcast, valid microblock header signed by a target miner whose `microblock_pubkey_hash` is still within `MINER_REWARD_MATURITY` blocks, and (2) the ability to submit a standard `PoisonMicroblock` transaction (no special privilege, stake, or key required). Deriving the malleated signature variant is pure elliptic-curve arithmetic on public data (r, s, recovery id) and requires no private key or majority stake. This is repeatable against any miner whose microblocks are observed while their key is within the maturity window, making it a low-cost, low-skill, fully reproducible attack for an unprivileged party.

### Recommendation
In `check_microblock_header_signer` (and/or in the mempool precheck in `blocks.rs`), require that the two headers actually diverge in the portion attesting to distinct block content — e.g., assert `mblock_hdr_1.tx_merkle_root != mblock_hdr_2.tx_merkle_root` (or, more robustly, that the full serialized headers excluding signature are not identical) before accepting a PoisonMicroblock as evidence of equivocation. Additionally, consider validating that both signatures are canonical (low-S) so that a single message cannot yield two distinct-looking accepted signatures via malleability, or normalize signatures before comparison so malleated duplicates collapse to the same encoding and fail the "distinct header" check.

### Proof of Concept
Rust integration test plan:
1. Generate `StacksPrivateKey` for miner M; compute `Hash160` `pubkh` from its public key and record it as `microblock_pubkey_hash` at some block height H in test chainstate (so `get_microblock_pubkey_hash_height` returns `H`), with current height within `H + MINER_REWARD_MATURITY`.
2. Construct a genuine `StacksMicroblockHeader` (`version`, `sequence`, `prev_block`, `tx_merkle_root`) and sign it with M's key via `.sign(&privk)` to get `header_1` (valid signature `(r, s, recid)`).
3. Programmatically derive the ECDSA-malleable counterpart signature `(r, n-s, 1-recid)` from `header_1.signature` (pure secp256k1 field/scalar arithmetic, no access to `privk`), and construct `header_2` identical to `header_1` in every field except `signature`.
4. Call `StacksChainState::check_microblock_header_signer(&header_1, &header_2)` and assert it returns `Ok(pubkh)` (both sides of the intended equality: "same recovered signer" holds, but "distinct microblock content" — assert `header_1.tx_merkle_root == header_2.tx_merkle_root` — also holds, proving no real equivocation).
5. Submit `TransactionPayload::PoisonMicroblock(header_1, header_2)` through the normal transaction-processing path (or directly call `handle_poison_microblock`) and assert `get_microblock_poison_report`/`get_microblock_poison_report` for `pubkh` at height `H` now returns `Some((reporter_principal, header_1.sequence))`, despite only one microblock ever having been produced by M.     fn check_microblock_header_signer(
        mblock_hdr_1: &StacksMicroblockHeader,
        mblock_hdr_2: &StacksMicroblockHeader,
    ) -> Result<Hash160, Error> {
        let pkh1 = mblock_hdr_1.check_recover_pubkey().map_err(|e| {
            Error::InvalidStacksTransaction(
                format!("Failed to recover public key: {:?}", &e),
                false,
            )
        })?;

        let pkh2 = mblock_hdr_2.check_recover_pubkey().map_err(|e| {
            Error::InvalidStacksTransaction(
                format!("Failed to recover public key: {:?}", &e),
                false,
            )
        })?;

        if pkh1 != pkh2 {
            let msg = format!(
                "Invalid PoisonMicroblock transaction -- signature pubkey hash {} != {}",
                &pkh1, &pkh2
            );
            warn!("{}", &msg);
            return Err(Error::InvalidStacksTransaction(msg, false));
        }
        Ok(pkh1)
    }

    pub fn handle_poison_microblock(
        env: &mut ExecutionState,
        invoke_ctx: &InvocationContext,
        mblock_header_1: &StacksMicroblockHeader,
        mblock_header_2: &StacksMicroblockHeader,
    ) -> Result<Value, Error> {
        let cost_before = env.global_context.cost_track.get_total();

        // encodes MARF reads for loading microblock height and current height, and loading and storing a
        // poison-microblock report
        runtime_cost(ClarityCostFunction::PoisonMicroblock, env, 0)
            .map_err(|e| Error::from_cost_error(e, cost_before.clone(), env.global_context))?;

        let sender_principal = match &invoke_ctx.sender {
            Some(ref sender) => {
                if let PrincipalData::Standard(sender) = sender.clone() {
                    sender
                } else {
                    panic!(
                        "BUG: tried to handle poison microblock without a standard principal sender"
                    );
                }
            }
            None => {
                panic!("BUG: tried to handle poison microblock without a sender");
            }
        };

        // is this valid -- were both headers signed by the same key?
        let pubkh =
            StacksChainState::check_microblock_header_signer(mblock_header_1, mblock_header_2)?;

        let microblock_height_opt = env
            .global_context
            .database
            .get_microblock_pubkey_hash_height(&pubkh)?;
        let current_height = env.global_context.database.get_current_block_height();

        // for the microblock public key hash we had to process
        env.add_memory(20)
            .map_err(|e| Error::from_cost_error(e, cost_before.clone(), env.global_context))?;

        // for the block height we had to load
        env.add_memory(4)
            .map_err(|e| Error::from_cost_error(e, cost_before.clone(), env.global_context))?;

        // was the referenced public key hash used anytime in the past
        // MINER_REWARD_MATURITY blocks?
        let mblock_pubk_height = match microblock_height_opt {
            None => {
                // public key has never been seen before
                let msg = format!(
                    "Invalid Stacks transaction: microblock public key hash {} never seen in this fork",
                    &pubkh
                );
                warn!("{}", &msg;
                      "microblock_pubkey_hash" => %pubkh
                );

                return Err(Error::InvalidStacksTransaction(msg, false));
            }
            Some(height) => {
                if height
                    .checked_add(
                        u32::try_from(MINER_REWARD_MATURITY).expect("FATAL: maturity > 2^32"),
                    )
                    .expect("BUG: too many blocks")
                    < current_height
                {
                    let msg = format!(
                        "Invalid Stacks transaction: microblock public key hash from height {} has matured relative to current height {}",
                        height, current_height
                    );
                    warn!("{}", &msg;
                          "microblock_pubkey_hash" => %pubkh
                    );

                    return Err(Error::InvalidStacksTransaction(msg, false));
                }
                height
            }
        };

        // add punishment / commission record, if one does not already exist at lower sequence
        let (reporter_principal, reported_seq) = if let Some((reporter, seq)) = env
            .global_context
            .database
            .get_microblock_poison_report(mblock_pubk_height)?
        {
            // account for report loaded
            env.add_memory(u64::from(TypeSignature::PrincipalType.size().map_err(
                |_| Error::Expects("Failed to get size of PrincipalType".into()),
            )?))
            .map_err(|e| Error::from_cost_error(e, cost_before.clone(), env.global_context))?;

            // u128 sequence
            env.add_memory(16)
                .map_err(|e| Error::from_cost_error(e, cost_before.clone(), env.global_context))?;

            if mblock_header_1.sequence < seq {
                // this sender reports a point lower in the stream where a fork occurred, and is now
                // entitled to a commission of the punished miner's coinbase
                debug!("Sender {} reports a better poison-miroblock record (at {}) for key {} at height {} than {} (at {})", &sender_principal, mblock_header_1.sequence, &pubkh, mblock_pubk_height, &reporter, seq;
                    "sender" => %sender_principal,
                    "microblock_pubkey_hash" => %pubkh
                );
                env.global_context.database.insert_microblock_poison(
                    mblock_pubk_height,
                    &sender_principal,
                    mblock_header_1.sequence,
                )?;
                (sender_principal, mblock_header_1.sequence)
            } else {
                // someone else beat the sender to this report
                debug!("Sender {} reports an equal or worse poison-microblock record (at {}, but already have one for {}); dropping...", &sender_principal, mblock_header_1.sequence, seq;
                    "sender" => %sender_principal,
                    "microblock_pubkey_hash" => %pubkh
                );
                (reporter, seq)
            }
        } else {
            // first-ever report of a fork
            debug!(
                "Sender {} reports a poison-microblock record at seq {} for key {} at height {}",
                &sender_principal, mblock_header_1.sequence, &pubkh, &mblock_pubk_height;
                "sender" => %sender_principal,
                "microblock_pubkey_hash" => %pubkh
            );
            env.global_context.database.insert_microblock_poison(
                mblock_pubk_height,
                &sender_principal,
                mblock_header_1.sequence,
            )?;
            (sender_principal, mblock_header_1.sequence)
        };

    pub fn check_recover_pubkey(&self) -> Result<Hash160, AuthError> {
        let mut bytes = vec![];
        self.serialize(&mut bytes, true)
            .expect("BUG: failed to serialize to a vec");
        let digest = Sha512Trunc256Sum::from_data(&bytes[..]);

        let mut pubk = StacksPublicKey::recover_to_pubkey_without_validating_low_s(
            digest.as_bytes(),
            &self.signature,
        )
        .map_err(|_ve| {
            AuthError::VerifyingError(
                "Failed to verify signature: failed to recover public key".to_string(),
            )
        })?;

        pubk.set_compressed(true);
        Ok(Hash160::from_node_public_key(&pubk))
    }
