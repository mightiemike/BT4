### Title
On-chain Uniswap-quoter price used for gas-abstraction auto-swap slippage bounds is sandwichable, allowing drain of user/protocol swap value - (File: `x/uexecutor/keeper/evm.go`, `x/uexecutor/keeper/execute_inbound_gas.go`, `x/uexecutor/keeper/execute_inbound_gas_and_payload.go`, `x/uexecutor/keeper/outbound.go`)

### Summary
Push Chain's gas-abstraction flow (inbound deposit auto-swap, gas-and-payload auto-swap, and outbound gas refund swap) computes the `minPCOut` slippage floor from a live, unauthenticated on-chain AMM quote (`QuoterV2.quoteExactInputSingle`) and then executes the real swap in the same deterministic keeper call. This is the same bug class as the reported `SwapperUniV3._swap`/`_getBestFee` issue: an on-chain quote read from a manipulable pool is used to bound the swap it is about to execute, so an attacker who moves the pool price immediately before block execution can force the module to accept a materially worse conversion rate and extract the difference.

### Finding Description
`GetSwapQuote` calls `QUOTER.quoteExactInputSingle` against the live PRC20/WPC Uniswap-V3-style pool deployed as the `UNIVERSAL_CORE` system contract on Push Chain's own EVM: [1](#0-0) 

This quote is used to derive a fixed 5% slippage bound in three separate call sites that then immediately execute the swap against the same pool:

1. Inbound gas-only auto-swap (`ExecuteInboundGas`): [2](#0-1) 

2. Gas-and-payload auto-swap (`gasAndPayloadDepositAutoSwap`): [3](#0-2) 

3. Outbound unused-gas refund swap (`applyGasRefund` / `getSwapQuoteForRefund`): [4](#0-3) [5](#0-4) 

In all three, `minPCOut` is `quote * 95 / 100`, where `quote` is fetched by a non-committing (`commit=false`) simulated call to the quoter contract immediately before the real, committing swap (`CallPRC20DepositAutoSwap` / `CallUniversalCoreRefundUnusedGas`) is dispatched via `DerivedEVMCall`. Because the quote and the swap both read/act on the same pool state at (near) the same block height, and because these keeper calls execute deterministically as part of ordinary inbound/outbound processing (i.e., triggered by ordinary user deposits reaching finalization, not by a privileged actor), an unprivileged attacker can:

- Submit ordinary EVM transactions against the PRC20/WPC pool in the same block window immediately before the module's deterministic auto-swap/refund-swap executes, pushing the price so that the "live" quote itself is already the manipulated (bad) price.
- Let the module compute `minPCOut` off of this manipulated price (5% below the manipulated quote, not a fair/reference price), then let the module's swap execute at that same manipulated price.
- Reverse the price-moving trade afterward, capturing the spread extracted from the user's deposited collateral/gas-token amount that was converted to WPC by the module on the user's behalf.

This directly mirrors the reported class: on-chain quoting is not a manipulation-resistant price oracle, and using it to compute the very slippage bound that protects the swap it precedes provides no real protection against sandwiching, especially for low-liquidity PRC20/WPC pools that are likely to exist per-supported-asset.

### Impact Explanation
The swapped funds originate from user-deposited PRC20 tokens (inbound gas abstraction) or protocol-held unused gas surplus (outbound refund) — i.e., user/protocol-controlled funds, not attacker-controlled funds. A successful sandwich lets an unprivileged attacker extract value from these conversions, effectively draining user/protocol funds during routine, unprivileged operations (inbound execution and outbound gas refunds), which are core, frequently-triggered paths in the universal execution flow. This fits the in-scope impact of "stealing... funds" and "corruption of ... gas fee accounting, refund accounting."

### Likelihood Explanation
The trigger requires no privileged access — any user can submit a normal inbound (deposit) to cause `ExecuteInboundGas`/`gasAndPayloadDepositAutoSwap` to run, and any user can trade against the PRC20/WPC pool via ordinary EVM transactions on Push Chain to move its price beforehand. The 5% band is generous relative to the price impact achievable in a thin pool, and no TWAP, external oracle, or off-chain reference price is used anywhere in this path, so the likelihood of profitable exploitation is high wherever pool liquidity is not deep relative to swap sizes.

### Recommendation
Do not derive slippage protection solely from a same-block/same-transaction on-chain quote of the pool being traded against. Options:
- Use a manipulation-resistant reference price (e.g., TWAP over multiple blocks, or an external price feed already validated/bound elsewhere in the registry) to compute `minPCOut`, independent of the instantaneous pool state.
- Widen the effective protection by comparing the instantaneous quote against a longer-window TWAP and rejecting/deferring the swap if they diverge beyond a safe threshold.
- Consider allowing governance/registry-configured per-token max slippage combined with a circuit breaker if quoted price deviates sharply from a stored reference price in `uregistry`.

### Proof of Concept
1. Attacker identifies a PRC20↔WPC pool used by `UNIVERSAL_CORE` for token `X` with modest liquidity, and the `defaultFeeTier` used for it via `GetDefaultFeeTierForToken`. [6](#0-5) 
2. Attacker submits a large swap into the pool (via normal EVM tx) to push the WPC price of token `X` down just before a block that will process a pending inbound deposit of token `X` (inbound processing is deterministic and observable from mempool/finalized ballots).
3. When `ExecuteInboundGas` executes for that inbound, `GetSwapQuote` returns the attacker-manipulated (low) price; `minPCOut` is computed as 95% of this already-bad price. [7](#0-6) 
4. `CallPRC20DepositAutoSwap` executes the swap and succeeds (since `minPCOut` was derived from the manipulated price, not a fair price), converting the victim's deposited token `X` to WPC at an unfavorable rate.
5. Attacker reverses their initial trade, restoring the pool price and capturing the value difference extracted from the user's deposit — repeatable for every inbound gas-abstraction swap and outbound gas refund swap touching a manipulable pool.

```go
// GetDefaultFeeTierForToken reads defaultFeeTier[prc20] from UniversalCore.
func (k Keeper) GetDefaultFeeTierForToken(ctx sdk.Context, prc20Address common.Address) (*big.Int, error) {
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse UniversalCore ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	receipt, err := k.evmKeeper.CallEVM(ctx, abi, ueModuleAccAddress, handlerAddr, false, nil, "defaultFeeTier", prc20Address)
	if err != nil {
		return nil, errors.Wrap(err, "failed to call defaultFeeTier")
	}

	results, err := abi.Methods["defaultFeeTier"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack defaultFeeTier result")
	}

	// go-ethereum unpacks uint24 as *big.Int (non-standard widths always map to *big.Int)
	fee, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for defaultFeeTier: %T", results[0])
	}

	return fee, nil
}
```

```go
// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
```

```go
// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}
```

```go
// getSwapQuoteForRefund fetches a Uniswap quote for the gas token refund swap.
func (k Keeper) getSwapQuoteForRefund(ctx sdk.Context, gasToken common.Address, fee *big.Int, amount *big.Int) (*big.Int, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(ctx)
	if err != nil {
		return nil, err
	}
	wpcAddr, err := k.GetUniversalCoreWPCAddress(ctx)
	if err != nil {
		return nil, err
	}
	return k.GetSwapQuote(ctx, quoterAddr, gasToken, wpcAddr, fee, amount)
```
