### Title
Open Redirect via unsanitized `exitIframe` destination in App Bridge exit-iframe route - ([File: `packages/apps/shopify-app-remix/src/server/authenticate/admin/authenticate.ts` / `packages/apps/shopify-app-react-router/src/server/authenticate/admin/authenticate.ts`, function `respondToExitIframeRequest`])

### Summary
The `exitIframe` query parameter is passed directly into `renderAppBridge(...,{url: destination})`, which only validates the URL via `sanitizeRedirectUrl`. That validator does not restrict destinations to the app's own origin or to Shopify-approved domains — it only rejects `file://` URIs, whitespace, malformed relative paths, and non-`http(s)` protocols. Any external `https://` URL is accepted, resulting in an open redirect reachable pre-authentication.

### Finding Description
`respondToExitIframeRequest` reads the attacker-controlled `exitIframe` parameter unauthenticated (this handler runs before session token/HMAC validation) and forwards it as the redirect target: [1](#0-0) 

`renderAppBridge` sanitizes the destination via `sanitizeRedirectUrl(config.appUrl, redirectTo.url)` before embedding it in a `window.open(...)` script: [2](#0-1) 

However, `sanitizeRedirectUrl`'s underlying `isSafe` check does not enforce same-origin/allowlist restrictions against `domain` (the app's own URL). It only blocks `file://` URIs (`FILE_URI_MATCH`), whitespace, invalid relative-path patterns (`INVALID_RELATIVE_URL`), and non-`http`/`https` protocols; any well-formed absolute `https://` URL — including one pointing at an attacker's own domain — passes validation: [3](#0-2) 

The existing test suite for this route only asserts that `file:///not/allowed/path` is rejected and that same-origin/relative destinations are accepted — it never asserts rejection of an external `https://evil.example` destination, confirming there is no allowlist enforced against the app or Shopify domain: [4](#0-3) 

`getShopFromRequest(request)` is indeed only used for logging in this path, so it plays no protective role.

### Impact Explanation
An unauthenticated attacker can craft `GET {exitIframePath}?exitIframe=https://evil.example&shop=<any-shop>&host=<base64-host>` and receive a `200` HTML response whose script does `window.open("https://evil.example/", "_top")`, causing top-level browser navigation away from the Shopify Admin/app context to an attacker-controlled site. This is a classic embedded-app open redirect (matches Shopify's "open redirect" bounty class). Combined with App Bridge's retry-with-session-token behavior on unauthorized responses, this could be leveraged to phish or exfiltrate session context from a merchant browsing an embedded app, though full token exfiltration would require additional confirmation of App Bridge's exact retry semantics.

### Likelihood Explanation
No authentication or special preconditions are required — this route is designed to run before session validation so App Bridge can bounce out of the iframe. Any anonymous actor can trigger it by sending a merchant a link into the app's `exit-iframe` endpoint with an external `exitIframe` value; feasibility is high and fully repeatable.

### Recommendation
Enforce that `sanitizeRedirectUrl`'s resulting URL's origin matches `config.appUrl`'s origin (or a small allowlist of Shopify domains, e.g. `admin.shopify.com`/`*.myshopify.com`) rather than merely checking protocol/format. Reject any destination whose origin differs from the app's own origin unless explicitly on an allowlist.

export function renderAppBridge(
  {config}: BasicParams,
  request: Request,
  redirectTo?: RedirectToOptions,
): never {
  let redirectToScript = '';
  if (redirectTo) {
    const destination = sanitizeRedirectUrl(config.appUrl, redirectTo.url);

    const target = redirectTo.target ?? '_top';

    redirectToScript = `<script>window.open(${JSON.stringify(
      destination.toString(),
    )}, ${JSON.stringify(target)})</script>`;
  }

function isSafe(
  domain: string,
  redirectUrl: unknown,
  requireSSL: boolean | undefined = true,
): redirectUrl is string {
  if (typeof redirectUrl !== 'string') {
    return false;
  }

  if (
    FILE_URI_MATCH.test(redirectUrl) ||
    WHITESPACE_CHARACTER.test(redirectUrl)
  ) {
    return false;
  }

  let url: URL;

  try {
    url = new URL(redirectUrl, domain);
  } catch (_error) {
    return false;
  }

  if (INVALID_RELATIVE_URL.test(url.pathname)) {
    return false;
  }

  if (!VALID_PROTOCOLS.includes(url.protocol)) {
    return false;
  }

  if (requireSSL && url.protocol !== 'https:') {
    return false;
  }

  return true;
}
