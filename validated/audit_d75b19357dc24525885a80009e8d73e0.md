**Rationale:** `BN254_CONSTANTS` in `crates/aptos-crypto/src/poseidon_bn254/constants.rs` is a hardcoded `Lazy` static built entirely from string literals compiled into the binary at build time [1](#0-0) . There is no code path by which unprivileged transaction, package, API, view, bytecode, or proof input can alter, truncate, or reorder rows of this constants table — it is fixed data selected purely by the compile-time macro `neptune_constants!` indexing `$constants[w-1]` and `PARTIAL_ROUNDS[w-1]` [2](#0-1) . A truncated row would be a static implementation bug baked into every node's binary identically (not an attacker-triggered divergence), which falls under "trusted operator mistakes alone," explicitly excluded by the Decision Standard. Since the scope rule requires the path to *begin from unprivileged input*, and this data has no such origin (it is not derived from EPK bytes, proof inputs, or any other attacker-supplied value — `pad_and_pack_bytes_to_scalars_with_len` in `crates/aptos-crypto/src/poseidon_bn254/keyless.rs` only produces the *scalars to be hashed*, not the round constants used by the hasher) [3](#0-2) , there is no viable unprivileged-input-driven exploit here.

macro_rules! neptune_constants {
    ($constants:expr, $matrices:expr, $ui:ty) => {{
        let w = <$ui>::to_usize();
        PoseidonConstants::new_from_parameters(
            w + 1,
            $matrices[w - 1].clone(),
            $constants[w - 1].clone(),
            FULL_ROUNDS,
            PARTIAL_ROUNDS[w - 1],
            HashType::<AltFr, $ui>::Sponge,
            Strength::Standard,
        )
    }};
}

pub fn pad_and_pack_bytes_to_scalars_with_len(
    bytes: &[u8],
    max_bytes: usize,
) -> anyhow::Result<Vec<ark_bn254::Fr>> {
    let len = bytes.len();
    if max_bytes > MAX_NUM_INPUT_BYTES {
        bail!(
            "Cannot hash more than {} bytes. Was given {} bytes.",
            MAX_NUM_INPUT_BYTES,
            len
        );
    }
    if len > max_bytes {
        bail!(
            "Byte array length of {} is NOT <= max length of {} bytes.",
            bytes.len(),
            max_bytes
        );
    }

    let len_scalar = pack_bytes_to_one_scalar(&len.to_le_bytes())?;
    let scalars = pad_and_pack_bytes_to_scalars_no_len(bytes, max_bytes)?
        .into_iter()
        .chain([len_scalar])
        .collect::<Vec<ark_bn254::Fr>>();
    Ok(scalars)
}
