## Finding

### Title
Unbounded CPU amplification in `Wallet.estimateEnergy` via repeated `Program.OutOfTimeException` retries during binary search - (File: framework/src/main/java/org/tron/core/Wallet.java)

### Summary
`Wallet.estimateEnergy` performs an initial call plus up to `log2(maxFeeLimit/TRX_PRECISION)` binary-search calls to `cleanContextAndTriggerConstantContract`, and each of these call sites independently retries up to `estimateEnergyMaxRetry` times whenever `Program.OutOfTimeException` is thrown. A contract whose execution reliably times out (e.g., a bounded but near-timeout storage-write loop) causes every search step to consume its full retry budget, multiplying the CPU work of a single `/wallet/estimateenergy` HTTP request by roughly `(estimateEnergyMaxRetry + 1) × (2 + log2(maxFeeLimit/TRX_PRECISION))` full VM executions.

### Finding Description
`estimateEnergy` is reachable unauthenticated via `EstimateEnergyServlet.doPost` (framework/src/main/java/org/tron/core/services/http/EstimateEnergyServlet.java:61-62) and via `TronJsonRpcImpl.estimateEnergy` (framework/src/main/java/org/tron/core/services/jsonrpc/TronJsonRpcImpl.java:491-514), both requiring only `estimateEnergy` and `supportConstant` enabled — a normal, documented node configuration, not a privileged or non-default hardening flag.

Inside `Wallet.estimateEnergy` (framework/src/main/java/org/tron/core/Wallet.java:2986-3087) there are four separate `while(true) { try { ... } catch (Program.OutOfTimeException e) { retry--; if (retry < 0) throw e; } }` blocks:
- the initial upper-bound probe at `high` (lines 3006-3017),
- the `twoTimes` doubling probe (lines 3030-3048),
- each iteration of the `while (low + TRX_PRECISION < high)` binary-search loop (lines 3051-3072),
- the final confirmation call at `high` (line 3075, not wrapped in retry).

Critically, the same shared `retry` counter (initialized once from `Args.getInstance().estimateEnergyMaxRetry`, default 3, at line 2999) decrements across all these loops, but each individual `while(true)` block only aborts once `retry` goes negative — meaning a contract that throws `Program.OutOfTimeException` on *every* attempt will burn through the entire `retry` budget once per binary-search step before the outer binary search even terminates (since it re-executes `cleanContextAndTriggerConstantContract` → `triggerConstantContract` → `callConstantContract`, i.e., full VM warm-up, context reset (`txCap.resetResult()`, `txExtBuilder.clear()`, `txRetBuilder.clear()`), and VM execution up to the constant-call time limit on every retry). This is confirmed by the existing test `WalletTest.testEstimateEnergyOutOfTime` (framework/src/test/java/org/tron/core/WalletTest.java:1333-1379), which shows a single busy-loop contract deterministically throws `Program.OutOfTimeException` out of `estimateEnergy`, proving that a contract can be crafted to reliably hit the constant-call VM time limit.

Because the number of binary-search steps is `O(log2(maxFeeLimit / TRX_PRECISION))` (bounded by `dps.getMaxFeeLimit()`, a chain parameter, divided by `TRX_PRECISION`), and each step can independently consume up to `estimateEnergyMaxRetry` retries before failing, the worst-case number of full VM executions per single HTTP request is on the order of `(estimateEnergyMaxRetry + 1) × O(log2(maxFeeLimit/TRX_PRECISION))`. None of the standard mitigations apply here: `Util.checkBodySize`/`Util.validateParameter` bound only the HTTP payload size, not CPU time; there is no fee/energy charge for constant/estimate calls since they do not persist state or consume real transaction energy against an account; and the constant-call VM deadline (`constantCallTimeoutMs`/shared block-processing deadline) governs a single call's duration but not the aggregate number of repeated calls per request.

### Impact Explanation
This is a DoS via RPC-API: an unprivileged, unauthenticated attacker who can reach `/wallet/estimateenergy` (or the equivalent JSON-RPC `eth_estimateGas` path routed through the same method) can force the HTTP worker thread handling the request to perform substantially more CPU work than a normal single-shot constant call, for the cost of one HTTP POST. Repeated concurrent requests against such a contract can exhaust HTTP worker threads/CPU capacity on the node, degrading or denying the estimate-energy/RPC service for other users. It does not affect consensus state, funds, or keys — the impact is scoped to RPC-API availability (worker-thread/CPU starvation), not node crash or state corruption.

### Likelihood Explanation
Preconditions are default and no privileged role is required: `vm.estimateEnergy = true` and `vm.supportConstant = true` are ordinary node operator settings enabling a public API feature (not hardening flags being disabled by the attacker). The attacker only needs to deploy or reference a public contract with a loop tuned to sit near the per-call time limit (e.g., a large-but-bounded SSTORE loop as in the reference bytecode used by `testEstimateEnergyOutOfTime`) and issue a single unauthenticated POST to `/wallet/estimateenergy`. No fee is charged for constant/estimate calls that don't broadcast a transaction, so the attacker's cost is essentially the price of contract deployment (once) plus network requests, and the attack is fully repeatable and parallelizable across many requests/threads.

### Recommendation
Bound total CPU work per `estimateEnergy` request independent of the number of binary-search steps, e.g.: (1) track a single wall-clock deadline for the entire `estimateEnergy` call (not per-block-execution) and abort the whole binary search once exceeded, rather than restarting the deadline on every retry; (2) treat `Program.OutOfTimeException` during binary search as a search outcome (e.g., treat it like a "low" result, since more energy generally reduces the chance of hitting the wall-clock limit) instead of blindly retrying up to `estimateEnergyMaxRetry` times at every step; (3) cap the total number of retries across the *entire* `estimateEnergy` invocation, not reset/shared loosely per loop, so worst-case cost is `O(single call cost) × constant`, not `O(retries × log(maxFeeLimit))`.

  // ... setup identical to testEstimateEnergyOutOfTime ...

    Args.getInstance().setEstimateEnergyMaxRetry(retry);

  public Transaction estimateEnergy(TriggerSmartContract triggerSmartContract,
      TransactionCapsule txCap, TransactionExtention.Builder txExtBuilder,
      Return.Builder txRetBuilder, GrpcAPI.EstimateEnergyMessage.Builder estimateBuilder)
      throws ContractValidateException, ContractExeException, HeaderNotFound, VMIllegalException {

    if (!Args.getInstance().estimateEnergy) {
      throw new ContractValidateException("this node does not support estimate energy");
    }

    if (!Args.getInstance().supportConstant) {
      throw new ContractValidateException("this node does not support constant, "
          + "so estimate energy cannot work");
    }
    int retry = Args.getInstance().estimateEnergyMaxRetry;

    DynamicPropertiesStore dps = chainBaseManager.getDynamicPropertiesStore();
    long high = dps.getMaxFeeLimit();

    Transaction transaction;

    while (true) {
      try {
        transaction = cleanContextAndTriggerConstantContract(
            triggerSmartContract, txCap, txExtBuilder, txRetBuilder, high);
        break;
      } catch (Program.OutOfTimeException e) {
        retry--;
        if (retry < 0) {
          throw e;
        }
      }
    }

    // If failed, return directly.
    if (transaction.getRet(0).getRet().equals(code.FAILED)) {
      txRetBuilder.setCode(response_code.CONTRACT_EXE_ERROR);
      estimateBuilder.setResult(txRetBuilder);
      return transaction;
    }

    long low = dps.getEnergyFee() * txExtBuilder.getEnergyUsed();

    long twoTimes = low * 2;
    if (twoTimes < high) {
      while (true) {
        try {
          transaction = cleanContextAndTriggerConstantContract(
              triggerSmartContract, txCap, txExtBuilder, txRetBuilder, twoTimes);

          if (transaction.getRet(0).getRet().equals(code.FAILED)) {
            low = twoTimes;
          } else {
            high = twoTimes;
          }

          break;
        } catch (Program.OutOfTimeException e) {
          retry--;
          if (retry < 0) {
            throw e;
          }
        }
      }
    }

    while (low + TRX_PRECISION < high) {
      long mid = (low + high) / 2;

      while (true) {
        try {
          transaction = cleanContextAndTriggerConstantContract(
              triggerSmartContract, txCap, txExtBuilder, txRetBuilder, mid);
          break;
        } catch (Program.OutOfTimeException e) {
          retry--;
          if (retry < 0) {
            throw e;
          }
        }
      }

      if (transaction.getRet(0).getRet().equals(code.FAILED)) {
        low = mid;
      } else {
        high = mid;
      }
    }

    // Retry the binary search result
    transaction = cleanContextAndTriggerConstantContract(
        triggerSmartContract, txCap, txExtBuilder, txRetBuilder, high);
    // Setting estimating result
    estimateBuilder.setResult(txRetBuilder);
    if (transaction.getRet(0).getRet().equals(code.SUCESS)) {
      txRetBuilder.setResult(true);
      txRetBuilder.setCode(response_code.SUCCESS);
      estimateBuilder.setEnergyRequired((long) ceil((double) high / dps.getEnergyFee(),
          dps.disableJavaLangMath()));
    }

    return transaction;
  }

  protected void doPost(HttpServletRequest request, HttpServletResponse response)
      throws IOException {
    TriggerSmartContract.Builder build = TriggerSmartContract.newBuilder();
    TransactionExtention.Builder trxExtBuilder = TransactionExtention.newBuilder();
    EstimateEnergyMessage.Builder estimateEnergyBuilder = EstimateEnergyMessage.newBuilder();
    Return.Builder retBuilder = Return.newBuilder();
    boolean visible = false;
    try {
      String contract = request.getReader().lines()
          .collect(Collectors.joining(System.lineSeparator()));
      Util.checkBodySize(contract);
      visible = Util.getVisiblePost(contract);
      Util.validateParameter(contract);
      JsonFormat.merge(contract, build, visible);
      JSONObject jsonObject = JSONObject.parseObject(contract);

      boolean isFunctionSelectorSet =
          !StringUtil.isNullOrEmpty(jsonObject.getString(Util.FUNCTION_SELECTOR));
      if (isFunctionSelectorSet) {
        String selector = jsonObject.getString(Util.FUNCTION_SELECTOR);
        String parameter = jsonObject.getString(Util.FUNCTION_PARAMETER);
        String data = Util.parseMethod(selector, parameter);
        build.setData(ByteString.copyFrom(ByteArray.fromHexString(data)));
      }

      TransactionCapsule trxCap = wallet.createTransactionCapsule(build.build(),
          Protocol.Transaction.Contract.ContractType.TriggerSmartContract);

      wallet.estimateEnergy(build.build(), trxCap,
          trxExtBuilder, retBuilder, estimateEnergyBuilder);
    } catch (ContractValidateException e) {
      retBuilder.setResult(false).setCode(Return.response_code.CONTRACT_VALIDATE_ERROR)
          .setMessage(ByteString.copyFromUtf8(e.getMessage()));
    } catch (Exception e) {
      String errString = null;
      if (e.getMessage() != null) {
        errString = e.getMessage().replaceAll("[\"]", "\'");
      }
      retBuilder.setResult(false).setCode(Return.response_code.OTHER_ERROR)
          .setMessage(ByteString.copyFromUtf8(e.getClass() + " : " + errString));
    }
    estimateEnergyBuilder.setResult(retBuilder);
    response.getWriter().println(
        Util.printEstimateEnergyMessage(estimateEnergyBuilder.build(), visible));
  }

  private void estimateEnergy(byte[] ownerAddressByte, byte[] contractAddressByte,
      long value, byte[] data, TransactionExtention.Builder trxExtBuilder,
      Return.Builder retBuilder, EstimateEnergyMessage.Builder estimateBuilder)
      throws ContractValidateException, ContractExeException, HeaderNotFound, VMIllegalException {

    TriggerSmartContract triggerContract = triggerCallContract(
        ownerAddressByte,
        contractAddressByte,
        value,
        data,
        0,
        null
    );

    TransactionCapsule trxCap = wallet.createTransactionCapsule(triggerContract,
        ContractType.TriggerSmartContract);
    Transaction trx =
        wallet.estimateEnergy(triggerContract, trxCap, trxExtBuilder, retBuilder, estimateBuilder);
    trxExtBuilder.setTransaction(trx);
    trxExtBuilder.setTxid(trxCap.getTransactionId().getByteString());
    trxExtBuilder.setResult(retBuilder);
    retBuilder.setResult(true).setCode(response_code.SUCCESS);
    estimateBuilder.setResult(retBuilder);
  }
