### Title
Cairo0 (deprecated) class content is served from the in-process class cache without re-verifying declaration status, unlike Cairo1 classes - (File: crates/blockifier/src/state/state_reader_and_contract_manager.rs)

### Summary
`StateReaderAndContractManager::get_compiled_from_class_manager` explicitly re-checks `is_declared()` against the authoritative state reader for cached Cairo1 (`RunnableCompiledClass::V1`/`V1Native`) classes before serving them from the shared `contract_class_manager` cache, because "existence in the cache does not guarantee that [it's declared] (it might contain a declared class from a reverted block, for example)". The exact same re-validation is *not* performed for `RunnableCompiledClass::V0` (deprecated Cairo0) classes — the `match` arm for `V0` is a no-op that immediately returns the cached class. [1](#0-0) 

### Finding Description
This mirrors the CVE-2026-60023 bug class: a "single-item read path" (the cache-backed `get_compiled_class` lookup) exposes content that should be gated behind a currently-valid "is this still declared" check, while an equivalent listing/validation path (the Cairo1 branch, or `StateReader::is_declared` in general) does enforce it.

`ContractClassManager`'s cache is a long-lived, process-global cache keyed only by `ClassHash`, populated the first time any state reader resolves a class (`self.contract_class_manager.set_and_compile(...)` at line 91). If a block that declares a Cairo0 class is later reverted (e.g., during a chain reorg / `revert_block` flow, as exercised in storage-level tests such as `declare_revert_declare_scenario` and `declare_revert_declare_without_classes_scenario`), the storage layer correctly deletes the class from `deprecated_declared_classes_table`/`deprecated_declared_classes_block_table`: [2](#0-1) 

However, the in-memory `contract_class_manager` cache used by the blockifier is not keyed or invalidated per that revert unless explicitly cleared (only done in the Python-facing `native_blockifier` path via `self.contract_class_manager.clear()` in `revert_block`): [3](#0-2) 

Because the `V0` branch of `get_compiled_from_class_manager` skips the `is_declared` re-check that the `V1` branch performs, a Cairo0 class that was cached while a since-reverted declaration was "live" will continue to be served as valid/executable via `get_compiled_class` for any subsequent contract call/deploy referencing that `class_hash`, even though the authoritative state no longer considers it declared.

### Impact Explanation
`is_declared`/`UndeclaredClassHash` is meant to be an authorization gate: only successfully (and still-)declared classes may be executed. This inconsistency lets execution proceed against a class hash that is undeclared per the canonical state, purely as a function of whether that node's process-local cache happens to be warm. Two sequencer/full nodes that process the same block but differ in cache warmth (one warmed the V0 class before a revert, one did not) can diverge on whether a transaction invoking/deploying that class hash succeeds or fails with `UndeclaredClassHash`, producing different execution results, receipts, resource usage, and induced state diffs — i.e., honest-node divergence and a wrong committed state root/block hash for the affected block.

### Likelihood Explanation
Reverts are a first-class, expected event in this codebase (`apollo_reverts::revert_block`, `Batcher::revert_block`, storage `revert_state_diff`), used for handling reorgs/consensus rollbacks. Any Cairo0 class declaration that gets included in a block that is subsequently reverted, on a node whose blockifier already resolved/cached that class (e.g., during initial execution, validation, or a prior `simulate`/`trace` call), leaves that node's cache permanently "poisoned" with a class the state no longer recognizes as declared, with no revert-triggered invalidation in this code path. No special privileges beyond submitting an ordinary Cairo0 `DECLARE` transaction are required to create the divergence-triggering condition; the divergence itself depends on chain revert scheduling, which is realistic in this codebase's normal reorg-handling flow.

### Recommendation
In `get_compiled_from_class_manager`, apply the same `is_declared` (or an equivalent authoritative check) re-validation to the `RunnableCompiledClass::V0` branch as is already done for the non-V0 branches, or otherwise ensure the `ContractClassManager` cache is invalidated for classes affected by any block revert (not only in the `native_blockifier`/Python entry point) before it can be safely omitted.

### Proof of Concept
1. Node executes/validates a block `N` containing `DECLARE` of a Cairo0 class `C` at `class_hash = H`. During this execution, `get_compiled_from_class_manager(H)` is called, causing `contract_class_manager` to cache `RunnableCompiledClass::V0` for `H`.
2. Block `N` is reverted via the standard revert path (`apollo_reverts::revert_block` / `Batcher::revert_block` / `StorageTxn::revert_state_diff`), which deletes `H` from `deprecated_declared_classes_table` and `deprecated_declared_classes_block_table` — confirmed by `declare_revert_declare_scenario` in [4](#0-3) , so `is_declared`/`get_deprecated_class_definition_at` now correctly report "not declared".
3. A subsequent transaction (e.g., `DEPLOY`/`INVOKE`) references `class_hash = H` on this node. `StateReaderAndContractManager::get_compiled_class(H)` → `get_compiled_from_class_manager(H)` hits the warm cache, matches `RunnableCompiledClass::V0(_) => {}`, and returns the cached class immediately without calling `self.state_reader.is_declared(H)`, unlike the `V1` branch.
4. Execution proceeds as if `H` were declared. A peer node without a warm cache entry for `H` (e.g., it never executed block `N`, or cleared its cache) calls `get_compiled_classes`/`is_declared`, finds `H` undeclared, and returns `StateError::UndeclaredClassHash`. The two nodes now produce different execution results/state diffs for the identical transaction and block.

    fn get_compiled_from_class_manager(
        &self,
        class_hash: ClassHash,
    ) -> StateResult<RunnableCompiledClass> {
        if let Some(runnable_class) =
            self.contract_class_manager.get_runnable(&class_hash, &self.native_classes_whitelist)
        {
            match &runnable_class {
                RunnableCompiledClass::V0(_) => {}
                _ => {
                    // The Cairo1 class is cached; verify it is declared,
                    // since existence in the cache does not guarantee that
                    // (it might contain a declared class from a reverted block, for example).
                    if !self.state_reader.is_declared(class_hash)? {
                        return Err(StateError::UndeclaredClassHash(class_hash));
                    }
                }
            }
            self.increment_cache_hit_metric();
            self.update_native_metrics(&runnable_class);
            return Ok(runnable_class);
        }

fn declare_revert_declare_scenario() {
    // Declare a class and a deprecated class.
    let contract_address: ContractAddress = contract_address!("0x11");
    let deprecated_class_hash = class_hash!("0xc1a55");
    let class_hash = class_hash!("0xdec1a55");
    let deprecated_class = DeprecatedContractClass::default();
    let class = SierraContractClass::default();
    let compiled_class_hash = compiled_class_hash!(5_u8);
    let diff0 = ThinStateDiff {
        deployed_contracts: IndexMap::from([(contract_address, deprecated_class_hash)]),
        storage_diffs: IndexMap::new(),
        deprecated_declared_classes: vec![deprecated_class_hash],
        class_hash_to_compiled_class_hash: IndexMap::from([(class_hash, compiled_class_hash)]),
        nonces: IndexMap::from([(contract_address, Nonce(StarkHash::from(1_u8)))]),
    };

    let ((reader, mut writer), _temp_dir) = get_test_storage();
    writer
        .begin_rw_txn()
        .unwrap()
        .append_state_diff(BlockNumber(0), diff0.clone())
        .unwrap()
        .append_classes(
            BlockNumber(0),
            &[(class_hash, &class)],
            &[(deprecated_class_hash, &deprecated_class)],
        )
        .unwrap()
        .commit()
        .unwrap();

    // Assert that both classes are declared.
    let state_number = StateNumber::unchecked_right_after_block(BlockNumber(0));
    let txn = reader.begin_ro_txn().unwrap();
    let state_reader = txn.get_state_reader().unwrap();
    assert!(state_reader.get_class_definition_at(state_number, &class_hash).unwrap().is_some());
    assert!(
        state_reader
            .get_deprecated_class_definition_at(state_number, &deprecated_class_hash)
            .unwrap()
            .is_some()
    );

    // Revert the block and assert that the classes are no longer declared.
    let (txn, _) = writer.begin_rw_txn().unwrap().revert_state_diff(BlockNumber(0)).unwrap();
    txn.commit().unwrap();
    let txn = reader.begin_ro_txn().unwrap();
    let state_reader = txn.get_state_reader().unwrap();
    assert!(state_reader.get_class_definition_at(state_number, &class_hash).unwrap().is_none());
    assert!(
        state_reader
            .get_deprecated_class_definition_at(state_number, &deprecated_class_hash)
            .unwrap()
            .is_none()
    );
