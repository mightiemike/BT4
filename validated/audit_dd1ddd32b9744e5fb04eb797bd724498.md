### Title
Gas-abstraction auto-swap uses a self-referential Uniswap V3 spot-price quote as its own slippage bound, allowing value extraction via price manipulation - (File: `x/uexecutor/keeper/execute_inbound_gas.go`, `x/uexecutor/keeper/evm.go`)

### Summary
The external report describes an ERC-4626-style vault whose share price is computed from spot on-chain balances, letting an attacker "donate" assets immediately before a victim deposit to distort the price used to value that deposit, extracting the victim's funds. Push Chain has a structurally identical pattern in the gas-abstraction swap path: the "fair price" used to protect a user's inbound-gas swap is derived from the very same manipulable spot state that produces the executed swap, and the protective bound is computed from that manipulated value instead of from any manipulation-resistant reference (e.g., TWAP or oracle).

### Finding Description
`ExecuteInboundGas` in [1](#0-0)  computes a swap "quote" via `k.GetSwapQuote` and then immediately derives its own slippage floor from that same quote:

```
quote, execErr = k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
...
minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
minPCOut.Div(minPCOut, big.NewInt(100))
receipt, execErr = k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
```

`GetSwapQuote` (in [2](#0-1)  ) calls `QuoterV2.quoteExactInputSingle` against the live Uniswap V3 pool — a pure spot-price simulation with no TWAP/observe-based reference. `CallPRC20DepositAutoSwap` ( [3](#0-2)  ) then performs the actual swap using `minPCOut` as the only floor.

Because `minPCOut` is 95% of the same-block, same-pool-state `quote` (not of a fair/independent value), an attacker who can move the pool's spot price in the same block *before* the validator-driven `ExecuteInboundGas` call executes (e.g., by pushing a large ordinary swap through the same Uniswap V3 pool) forces `GetSwapQuote` to observe the distorted price. `minPCOut` is then computed from that distorted price, so it "protects" the swap only against further movement away from the attacker's own distortion — not against the manipulation itself. The victim's PRC20 is swapped into WPC at the manipulated rate, and the attacker (or a colluding taker) captures the difference by reversing their position afterward, exactly mirroring the vault "donate-then-let-victim-deposit-at-distorted-price" pattern from the ERC-4626 report.

### Impact Explanation
This directly causes a fund-loss impact in scope ("permanent loss ... of user or protocol-controlled funds"): a user's inbound gas-token deposit is auto-swapped to WPC at a price the attacker manufactured, so the user receives materially less WPC than fair value, with the shortfall captured by the manipulator. The trigger requires only ordinary, unprivileged interaction with the public Uniswap V3 pool used by `UniversalCore` for gas abstraction — no validator, relayer, or admin compromise is needed.

### Likelihood Explanation
Any external, unprivileged actor that can submit ordinary EVM transactions against the WPC/PRC20 pool can attempt this in the same block window as a pending gas-abstraction inbound. Because `minPCOut` is self-referential to the manipulated quote rather than to an external/TWAP reference, the "5% slippage" guard provides no defense against this class of attack — likelihood depends only on pool liquidity depth and the attacker's capital, not on any privileged access.

### Recommendation
Do not derive the slippage floor from the same instantaneous quote used to execute the swap. Use a manipulation-resistant reference price (Uniswap V3 TWAP/`observe`, or an external oracle) to compute `minPCOut`, and/or bound the maximum allowed deviation between the TWAP-derived fair price and the spot quote before allowing the auto-swap to proceed, rejecting/deferring the deposit if the spot price has moved beyond a safe threshold from the TWAP.

### Proof of Concept
1. Attacker observes a pending gas-abstraction inbound (`TxType` requiring `ExecuteInboundGas`) that will trigger an on-chain PRC20→WPC swap once validator quorum is reached.
2. In the same block (or immediately before the quorum-triggering `MsgVoteInbound` is included), attacker submits an ordinary large swap against the same Uniswap V3 pool (`prc20Address` / `wpcAddress`, `fee` tier) to push the spot price against WPC.
3. Validator quorum finalizes the inbound; `ExecuteInboundGas` calls `GetSwapQuote`, which reflects the attacker-distorted spot price, and computes `minPCOut = quote * 95/100` from that distorted value ( [4](#0-3) ).
4. `CallPRC20DepositAutoSwap` executes the swap for the victim at the manipulated rate, well below fair market value, since `minPCOut` was never anchored to an unmanipulated price.
5. Attacker reverses their position in the pool after the module's swap executes, realizing profit equal to the victim's loss.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil

// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)
}
