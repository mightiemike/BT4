Single-block Uniswap V3 spot quote with only 5% slippage protection lets an unprivileged user manipulate gas-abstraction and refund swaps to drain PC/PRC20 value from the protocol - ([File: x/uexecutor/keeper/evm.go], [File: x/uexecutor/keeper/execute_inbound_gas.go], [File: x/uexecutor/keeper/outbound.go])

### Summary
The external report's core pattern — a value computed from a live, unprotected variable (elapsed time) that a fee model assumes will be "reasonable" but which an attacker can drive to a degenerate value (near-zero), causing the counterparty to eat a fixed cost — has a direct native analog in Push Chain's gas-abstraction and gas-refund swap paths. Instead of "time since last payment," the degenerate/attacker-influenceable input here is the **spot price of a Uniswap V3 pool queried in the same transaction that consumes it**, protected only by a flat 5% slippage band computed off that same manipulable quote.

### Finding Description
Three flows in `x/uexecutor` move real value (PRC20 gas tokens ↔ wrapped PC) using an on-chain, single-block AMM quote as both the pricing oracle and the slippage baseline:

1. `GetSwapQuote` in [1](#0-0)  calls `QuoterV2.quoteExactInputSingle` to fetch `amountOut` for a `prc20 → wpc` swap using the pool's current instantaneous price (no TWAP, no external reference, no upper/lower sanity bound).
2. `minPCOut` is then derived from that same instantaneous quote with a fixed 5% haircut in the inbound gas-abstraction path (`ExecuteInboundGas`, [2](#0-1) ), the gas-and-payload path (`gasAndPayloadDepositAutoSwap`, [3](#0-2) ), and the outbound gas-refund path (`applyGasRefund` → `getSwapQuoteForRefund`, [4](#0-3) [5](#0-4) ).
3. The swap is then executed via `CallPRC20DepositAutoSwap` / `CallUniversalCoreRefundUnusedGas` against the same pool, in the same or an immediately subsequent block, passing that `minPCOut` as the only floor.

Because the quote and the trade both read from the identical, attacker-visible/attacker-influenceable pool state, an unprivileged actor who can move the pool price beforehand (e.g., via a normal swap on the pool in a prior transaction/block, since these are ordinary low/mid-liquidity gas-token pools deployed for PRC20↔WPC pairs on Push Chain's own EVM) can push the "fair" spot price to a level of their choosing. The subsequent module-driven swap — triggered by an ordinary user's gas-abstraction deposit (`ExecuteInboundGas`) or by honest UV finalization of `MsgVoteOutbound` (`applyGasRefund`) — then executes at that already-skewed price, with only 5% additional protection against price movement *after* the quote. There is no minimum absolute output bound, no TWAP comparison, and no check that the instantaneous price is close to a longer-window reference, mirroring the report's missing "minimum interest/fee floor": the value the protocol/relayer nets from the swap can be driven arbitrarily low relative to what a fair-price trade would have produced, while the amount handed to the recipient (or burned from the protocol) is fixed by contract logic assuming a healthy price.

This directly corrupts PRC20/native asset accounting and refund accounting (an explicit in-scope impact): the module either (a) delivers too little WPC/native PC to a user during gas-abstraction deposit relative to the PRC20 consumed, or (b) pays out an inflated/deflated amount during `refundUnusedGas`, in both cases reachable purely from ordinary user deposit and voting flows with honest validators.

### Impact Explanation
- Users performing gas-abstraction deposits (`GAS`/`GAS_AND_PAYLOAD` inbound types) or receiving gas refunds on outbound completion can have their expected PC/WPC proceeds skewed by manipulated pool state, resulting in under- or over-delivery of protocol-controlled or user funds.
- Because the swap module account is the `uexecutor` module (a privileged on-chain actor moving real PRC20/PC value), sustained or repeated manipulation extracts value from the protocol's own liquidity/reserves at each swap event, which is an unauthorized/incorrect state transition in the universal execution and refund accounting path — squarely in the "Registry and accounting path" and "corruption of PRC20 or native asset accounting ... refund accounting" impact categories from the report's allowed-impact gate.
- Impact severity scales with pool liquidity depth for each gas-token pair; for thinly-liquidity gas tokens this could be a substantial, repeatable value leak.

### Likelihood Explanation
Likelihood is moderate-to-high for any newly listed or thin-liquidity gas token: an unprivileged actor only needs the ability to submit ordinary swap transactions against the same Uniswap V3 pool that `GetSwapQuote`/`CallPRC20DepositAutoSwap` reference, then trigger (or wait for) a gas-abstraction deposit or gas refund. No validator, relayer, or admin collusion is required — only capital and normal transaction submission, which matches the "unprivileged external attacker" constraint. The exact profitability depends on pool depth and the 5% band, which is not verified here without exact pool-liquidity numbers; this is the main residual uncertainty.

### Recommendation
Replace or supplement the single-block spot quote with a manipulation-resistant reference: use a Uniswap V3 TWAP (time-weighted average, over a window long enough to make same-block/near-block manipulation costly) as the baseline for `minPCOut`, and/or clamp accepted spot prices to a bounded deviation from a longer-window observation before allowing `CallPRC20DepositAutoSwap` / `CallUniversalCoreRefundUnusedGas` to proceed. Consider also enforcing an absolute minimum output floor independent of the live quote for critical/thin-liquidity pools, analogous to the report's recommended "minimum interest to pay."

### Proof of Concept
Not independently executable from static analysis alone (would require deploying/observing the actual `UniversalCore`/QuoterV2/pool contracts and liquidity depths, which are outside the Go module code indexed here). Conceptual PoC:
1. Attacker identifies a gas-token/WPC Uniswap V3 pool with low liquidity used by `uregistryKeeper`-configured gas tokens.
2. Attacker swaps into/out of the pool to move `sqrtPriceX96` favorably (e.g., depress `WPC` price in gasToken terms).
3. Attacker (or any user) submits a normal `GAS`/`GAS_AND_PAYLOAD` inbound deposit, or waits for an outbound they control to be voted `OBSERVED`/`REVERTED` by honest UVs with `gasFeeUsed < gasFee`.
4. `GetSwapQuote` returns a price reflecting step 2's manipulation; `minPCOut = quote*95/100` only bounds slippage from that skewed baseline.
5. `CallPRC20DepositAutoSwap`/`CallUniversalCoreRefundUnusedGas` executes at the skewed price, and attacker profits from the price differential versus fair value, or the protocol/recipient receives less value than intended.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

func (k Keeper) getSwapQuoteForRefund(ctx sdk.Context, gasToken common.Address, fee *big.Int, amount *big.Int) (*big.Int, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(ctx)
	if err != nil {
		return nil, err
	}
	wpcAddr, err := k.GetUniversalCoreWPCAddress(ctx)
	if err != nil {
		return nil, err
	}
	return k.GetSwapQuote(ctx, quoterAddr, gasToken, wpcAddr, fee, amount)
}
