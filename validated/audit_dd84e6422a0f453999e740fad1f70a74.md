## Finding

### Title
Starknet OS `execute_replace_class` accepts undeclared/unverified class hashes, diverging from blockifier's `replace_class` semantics - ([File: crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo])

### Summary
The Starknet OS Cairo implementation of the `replace_class` syscall writes an attacker-supplied `class_hash` directly into `contract_state_changes`/`contract_class_changes` without checking that the class is actually declared (or that it is a Cairo1 class), while the blockifier's Rust implementation of the same syscall — which is what actually governs real sequencer execution — enforces both checks. This mirrors the RAC bug class: an action (replacing a contract's associated resource/class) is permitted by one enforcement path without validating an authorization/ownership precondition that a sibling, authoritative path does enforce.

### Finding Description
In the blockifier (used during real transaction execution/validation by the sequencer), `replace_class` explicitly verifies the class is declared and is a Cairo1 class before mutating state: [1](#0-0) 

The deprecated (Cairo0) syscall path enforces the same declared-class precondition via `get_compiled_class`: [2](#0-1) 

However, in the Starknet OS's Cairo implementation of the same syscall (used for re-execution and generating the STARK proof / state commitments that back the sequencer's claimed state transition), the equivalent function performs **no such check**. It simply reads the class hash from the syscall request and writes it into `contract_state_changes`, with an explicit TODO acknowledging the missing validation: [3](#0-2) 

The same gap exists in the deprecated (Cairo0) execution path of the OS: [4](#0-3) 

Because the OS is the component that re-executes the sequencer's claimed transactions to produce the committed contract-class Patricia tree (`compute_class_commitment`) and the final global state root, this missing check means the OS's notion of "valid" `replace_class` execution is strictly weaker than the blockifier's. The blockifier would reject/revert a `replace_class` call with an undeclared class hash (`StateError::UndeclaredClassHash`) or with a Cairo0 class hash (`ForbiddenClassReplacement`), but the OS will silently accept it and commit it into the contract state tree.

### Impact Explanation
This is a divergence between the two components that are supposed to compute the *same* state transition function: the blockifier (sequencer) and the Starknet OS (prover/re-executor). If a discrepancy in this enforcement is ever exercised — e.g., through a difference in how "declared" is tracked between OS-guessed compiled-class facts vs. the blockifier's `CachedState`/`StateReaderAndContractManager` declaration bookkeeping (see `is_declared` checks in `crates/blockifier/src/state/state_reader_and_contract_manager.rs:65-104`) — the OS could compute and commit a class-tree/state root that does not correspond to what the blockifier actually executed and would allow to reach, or the OS could accept a class replacement to an unauthorized/never-declared class hash that the real network would have rejected. This falls squarely into "wrong committed root" / "honest-node divergence" territory, since the class commitment tree (`compute_class_commitment`) and the resulting global state root are derived directly from `contract_class_changes`, which is populated by this unchecked syscall handler.

### Likelihood Explanation
Any contract deployer can trivially reach this code path by deploying a contract that calls `replace_class` with an arbitrary, undeclared, or Cairo0 class hash. No special privileges are required — this is reachable from a single ordinary invoke transaction executing a contract that calls `replace_class`.

### Recommendation
Add the same declared-class (and Cairo1-type, for the non-deprecated syscall) verification in the OS's `execute_replace_class` (both `syscall_impls.cairo` and `deprecated_execute_syscalls.cairo`) that the blockifier enforces in `syscall_base.rs::replace_class` and `hint_processor.rs::replace_class`, i.e., assert the presence of a valid compiled-class fact for the requested `class_hash` (and reject Cairo0 replacement targets in the Cairo1 syscall) before writing the new `StateEntry` into `contract_state_changes`.

### Proof of Concept
1. Deploy a Cairo1 contract implementing `test_replace_class`-style logic that calls the `replace_class` syscall with an arbitrary, never-declared `class_hash` (as in the blockifier test `undeclared_class_hash` at [5](#0-4) , which shows the blockifier correctly rejects this with "is not declared").
2. Execute the equivalent call path through the Starknet OS's `execute_replace_class` (`syscall_impls.cairo:883-921`) — since it lacks a `get_compiled_class`/declared check, it will write `class_hash` into `contract_state_changes` and later into the committed class tree via `compute_class_commitment`, unlike the blockifier which reverts the transaction.
3. Compare the state root/class-tree root produced by OS re-execution against what the blockifier would compute for the identical transaction — the two diverge because the OS's class tree contains an update the blockifier never allowed.

    pub fn replace_class(&mut self, class_hash: ClassHash) -> SyscallResult<()> {
        // Ensure the class is declared (by reading it), and of type V1.
        let compiled_class = self.state.get_compiled_class(class_hash)?;

        if !is_cairo1(&compiled_class) {
            return Err(SyscallExecutionError::ForbiddenClassReplacement { class_hash });
        }
        self.state.set_class_hash_at(self.call.storage_address, class_hash)?;
        Ok(())
    }

// Replaces the class.
func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
