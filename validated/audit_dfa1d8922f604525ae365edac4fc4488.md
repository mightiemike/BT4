### Title
Unauthenticated identity spoofing in `AccountInitDecorator` allows forging first-time votes for any not-yet-initialized bonded Universal Validator — (File: `app/ante/account_init_decorator.go`)

### Summary
The external report's bug class is "a party can execute privileged operations by having a signature accepted for an identity it doesn't control, because the signature-verification path does not actually bind the signature to the claimed identity." Push Chain's gasless-transaction admission path, `AccountInitDecorator`, reproduces the same class of bug natively: it verifies that *a* valid signature exists, but never checks that the signing public key actually belongs to the address the message claims as `Signer`. Any not-yet-initialized bonded Universal Validator's address can therefore be impersonated for its first transaction, which is exactly the scenario the decorator was built to support (`app/README.md:182`: "lets a freshly-keygen'd Universal Validator hot key vote on its very first tx, without anyone first having to fund it").

### Finding Description
`AccountInitDecorator.AnteHandle` (`app/ante/account_init_decorator.go:31-81`) is spliced into the Cosmos ante chain immediately before `SetPubKeyDecorator`/`SigVerificationDecorator` (`app/ante/ante_cosmos.go:43-53`). For any gasless message (`app/txpolicy/gasless.go:14-49` — includes `MsgVoteInbound`, `MsgVoteOutbound`, `MsgVoteChainMeta`, `MsgVoteTssKeyProcess`, `MsgVoteFundMigration`), if the tx's sole signer address has no on-chain account yet (`!aid.ak.HasAccount(ctx, newAccAddr)`), the decorator:

1. Calls `verifySignatureForNewAccount` (`account_init_decorator.go:83-170`), which pulls `pubKey := sig.PubKey` straight from the transaction's own `SignaturesV2`, builds `signerData` with `Address: newAccAddr.String()` (the address taken from `GetSigners()`, i.e. from the message's `signer` field), and calls `authsigning.VerifySignature(ctx, pubKey, signerData, sig.Data, ...)`.
2. If that succeeds, it does `acc := aid.ak.NewAccountWithAddress(ctx, newAccAddr); acc.SetSequence(1); aid.ak.SetAccount(ctx, acc)` and **returns `ctx, nil` directly — it never calls `next(ctx, tx, simulate)`.**

Standard Cosmos SDK `SetPubKeyDecorator` normally enforces `sdk.AccAddress(pk.Address()) == addr` — i.e., that the address derived from the actual signing public key equals the message's claimed signer address. `verifySignatureForNewAccount` never performs this check anywhere. It cryptographically verifies only that *some* keypair produced a valid signature over the tx bytes (which is trivially true for a signature the attacker generated with their own key over a tx they built themselves, including whatever `Signer` field they choose inside the message body). Because this path also fully short-circuits (skips `SetPubKeyDecorator`, `ValidateSigCountDecorator`, `SigVerificationDecorator`, `IncrementSequenceDecorator`), no other layer in the ante chain ever performs the address-to-pubkey binding check for this transaction.

Consequently, an attacker who knows the bech32 address of a bonded, not-yet-initialized Universal Validator (addresses are public — visible via the validator set) can:
- Build `MsgVoteInbound` / `MsgVoteTssKeyProcess` / `MsgVoteFundMigration` with `Signer = <victim UV address>`.
- Sign the transaction with their **own** arbitrary private key.
- Submit it. `verifySignatureForNewAccount` succeeds since the signature is self-consistent (attacker's key over attacker-authored bytes). The account for the victim address is created and the message is dispatched with `msg.Signer = victim` treated as authenticated.

Downstream keeper checks (`IsBondedUniversalValidator(msg.Signer)`, `IsTombstonedUniversalValidator`) only look at the string address, which the attacker supplied — they pass, because the attacker chose a real bonded UV's address. The vote is recorded and counted toward ballot quorum in the generic ballot machine (`x/uvalidator`), directly affecting inbound finalization, TSS key/process finalization, and fund migration finalization outcomes.

### Impact Explanation
This breaks the "honest-validator finalization path" invariant explicitly called out in-scope: an unprivileged attacker can inject a forged vote attributed to a legitimate (but not-yet-onboarded) Universal Validator into inbound/outbound/TSS/fund-migration ballots without ever compromising that validator's key. Depending on the quorum threshold and number of already-cast votes (most impactful shortly after a new UV joins, before its hot key has ever broadcast a transaction — the exact scenario the decorator was designed for), this forged vote can:
- Tip an inbound ballot to `PASSED`, causing unauthorized PRC20 minting / payload execution for attacker-chosen inbound data.
- Tip a TSS key process or fund migration vote, corrupting `CurrentTssKey`/`FundMigrations` state or falsely marking a migration `SUCCESS`.
- Corrupt outbound observation votes.

This is a direct match to "forged... ballot, TSS, or migration state accepted through user-reachable flows with honest validators and honest nodes" in the allowed impact gate, with concrete, unprivileged reachability.

### Likelihood Explanation
Exploitability requires only: (1) knowledge of a bonded UV's public address (public validator-set data), and (2) that address not having sent any transaction yet — which is the explicitly documented, expected normal-operating condition for freshly onboarded UVs ("lets a freshly-keygen'd Universal Validator hot key vote on its very first tx"). No validator collusion, no key compromise, and no privileged access is needed by the attacker — only a single crafted, self-signed transaction.

### Recommendation
In `verifySignatureForNewAccount` (or immediately before calling it), require that the address derived from `sig.PubKey` (`sdk.AccAddress(pubKey.Address())`) equals `newAccAddr`, mirroring the check performed by the standard `SetPubKeyDecorator`. Reject the transaction if this binding fails, before performing the cryptographic `VerifySignature` call or creating the account.

### Proof of Concept
1. Query the active Universal Validator set (`x/uvalidator` `UniversalValidatorSet`) to find a bonded UV address `V` that has not yet submitted any transaction (`ak.HasAccount(ctx, V) == false`).
2. As attacker, generate a fresh keypair `(skA, pkA)` unrelated to `V`.
3. Construct `MsgVoteTssKeyProcess{ Signer: V, ProcessId: ..., TssPubkey: attackerChosenKey, KeyId: ... }` (or `MsgVoteInbound`/`MsgVoteFundMigration`), wrap in a tx with `account_number=0, sequence=0`, sign using `skA`, and set the tx's `AuthInfo.SignerInfo.PublicKey = pkA`.
4. Broadcast the tx. `IsGaslessTx` returns true; `AccountInitDecorator` sees `!ak.HasAccount(ctx, V)`, runs `verifySignatureForNewAccount`, which verifies `pkA`'s signature against the self-consistent sign bytes and succeeds (no check that `pkA` hashes to `V`); the decorator creates the account for `V` and short-circuits, and the message dispatches with `msg.Signer = V`.
5. `x/utss` (or `x/uexecutor`) keeper accepts the vote as coming from bonded UV `V` because `IsBondedUniversalValidator(V)` is true, recording an attacker-controlled vote toward ballot quorum under `V`'s identity. [1](#0-0) [2](#0-1) [3](#0-2) [4](#0-3) [5](#0-4) [6](#0-5)

func (aid AccountInitDecorator) AnteHandle(ctx sdk.Context, tx sdk.Tx, simulate bool, next sdk.AnteHandler) (sdk.Context, error) {
	if !txpolicy.IsGaslessTx(tx) {
		// Skip account initialization for non-gasless transactions
		ctx.Logger().Debug("account init decorator: non-gasless tx, skipping account init")
		return next(ctx, tx, simulate)
	}

	sigTx, ok := tx.(authsigning.Tx)
	if !ok {
		return ctx, errorsmod.Wrap(sdkerrors.ErrTxDecode, "invalid transaction type")
	}

	signers, err := sigTx.GetSigners()
	if err != nil || len(signers) != 1 {
		ctx.Logger().Debug("account init decorator: could not get unique signer, passing to next handler",
			"num_signers", len(signers),
			"error", err,
		)
		return next(ctx, tx, simulate)
	}

	newAccAddr := signers[0]
	if !aid.ak.HasAccount(ctx, newAccAddr) {
		ctx.Logger().Debug("account init decorator: new account detected on gasless tx, verifying signature",
			"address", sdk.AccAddress(newAccAddr).String(),
			"simulate", simulate,
		)
		// if account does not exist on chain, bypass rest of ante chain (especially gas and signature verification) here.
		// Perform signature verification on account number e and sequence number e instead.
		if err := aid.verifySignatureForNewAccount(ctx, tx, simulate); err != nil {
			ctx.Logger().Debug("account init decorator: signature verification failed for new account",
				"address", sdk.AccAddress(newAccAddr).String(),
				"error", err,
			)
			return ctx, err
		}

		acc := aid.ak.NewAccountWithAddress(ctx, newAccAddr)
		acc.SetSequence(1)
		aid.ak.SetAccount(ctx, acc)
		ctx.Logger().Info("account init decorator: new account created via gasless tx",
			"address", sdk.AccAddress(newAccAddr).String(),
		)
		return ctx, nil
	}

	ctx.Logger().Debug("account init decorator: existing account on gasless tx, passing to next handler",
		"address", sdk.AccAddress(newAccAddr).String(),
	)
	return next(ctx, tx, simulate)
}

func (aid AccountInitDecorator) verifySignatureForNewAccount(ctx sdk.Context, tx sdk.Tx, simulate bool) error {
	sigTx, ok := tx.(authsigning.Tx)
	if !ok {
		return errorsmod.Wrap(sdkerrors.ErrTxDecode, "invalid transaction type")
	}

	// stdSigs contains the sequence number, account number, and signatures.
	// When simulating, this would just be a 0-length slice.
	sigs, err := sigTx.GetSignaturesV2()
	if err != nil {
		return err
	}

	signers, err := sigTx.GetSigners()
	if err != nil {
		return err
	}

	// check that signer length and signature length are the same
	if len(sigs) != len(signers) {
		return errorsmod.Wrapf(sdkerrors.ErrUnauthorized, "invalid number of signer;  expected: %d, got %d", len(signers), len(sigs))
	}

	newAccAddr := sdk.AccAddress(signers[0])
	for _, sig := range sigs {
		pubKey := sig.PubKey
		if pubKey == nil {
			return errorsmod.Wrap(sdkerrors.ErrInvalidPubKey, "pubkey is not provided in signature")
		}

		// retrieve signer data
		chainID := ctx.ChainID()
		var accSequence uint64 = 0
		var accNum uint64 = 0

		// no need to verify signatures on recheck tx
		if !simulate && !ctx.IsReCheckTx() && ctx.IsSigverifyTx() {
			anyPk, _ := codectypes.NewAnyWithValue(pubKey)

			signerData := txsigning.SignerData{
				Address:       newAccAddr.String(),
				ChainID:       chainID,
				AccountNumber: accNum,
				Sequence:      accSequence,
				PubKey: &anypb.Any{
					TypeUrl: anyPk.TypeUrl,
					Value:   anyPk.Value,
				},
			}
			adaptableTx, ok := tx.(authsigning.V2AdaptableTx)
			if !ok {
				return fmt.Errorf("expected tx to implement V2AdaptableTx, got %T", tx)
			}
			txData := adaptableTx.GetSigningTxData()
			ctx.Logger().Debug("account init decorator: verifying signature for new account",
				"address", newAccAddr.String(),
				"chain_id", chainID,
				"acc_num", accNum,
				"sequence", accSequence,
			)
			err = authsigning.VerifySignature(ctx, pubKey, signerData, sig.Data, aid.signModeHandler, txData)
			if err != nil {
				var errMsg string
				if OnlyLegacyAminoSigners(sig.Data) {
					// If all signers are using SIGN_MODE_LEGACY_AMINO, we rely on VerifySignature to check account sequence number,
					// and therefore communicate sequence number as a potential cause of error.
					errMsg = fmt.Sprintf("signature verification failed; please verify account number (%d), sequence (%d) and chain-id (%s)", accNum, accSequence, chainID)
				} else {
					errMsg = fmt.Sprintf("signature verification failed; please verify account number (%d) and chain-id (%s): (%s)", accNum, chainID, err.Error())
				}
				ctx.Logger().Debug("account init decorator: signature invalid for new account",
					"address", newAccAddr.String(),
					"chain_id", chainID,
				)
				return errorsmod.Wrap(sdkerrors.ErrUnauthorized, errMsg)

			}
		} else {
			ctx.Logger().Debug("account init decorator: skipping signature verification",
				"address", newAccAddr.String(),
				"simulate", simulate,
				"is_recheck_tx", ctx.IsReCheckTx(),
				"is_sigverify_tx", ctx.IsSigverifyTx(),
			)
		}
	}
	return nil
}

// IsGaslessTx checks if a transaction contains only allowed gasless message types
// Returns true if all messages in the transaction are in the allowed gasless message types
func IsGaslessTx(tx sdk.Tx) bool {
	var (
		// GaslessMsgTypes defines the message types that are allowed in gasless transactions
		GaslessMsgTypes = []string{
			sdk.MsgTypeURL(&uexecutortypes.MsgMigrateUEA{}),
			sdk.MsgTypeURL(&uexecutortypes.MsgExecutePayload{}),
			sdk.MsgTypeURL(&uexecutortypes.MsgVoteInbound{}),
			sdk.MsgTypeURL(&uexecutortypes.MsgVoteOutbound{}),
			sdk.MsgTypeURL(&utsstypes.MsgVoteTssKeyProcess{}),
			sdk.MsgTypeURL(&utsstypes.MsgVoteFundMigration{}),
			sdk.MsgTypeURL(&uexecutortypes.MsgVoteChainMeta{}),
		}
	)

	msgs := tx.GetMsgs()
	if len(msgs) == 0 {
		return false
	}

	for _, msg := range msgs {
		switch m := msg.(type) {
		case *authz.MsgExec:
			// Only gasless if ALL inner messages are allowed
			for _, innerMsg := range m.Msgs {
				if !slices.Contains(GaslessMsgTypes, innerMsg.TypeUrl) {
					return false
				}
			}
		default:
			if !slices.Contains(GaslessMsgTypes, sdk.MsgTypeURL(msg)) {
				return false
			}
		}
	}
	return true
}

// VoteTssKeyProcess implements types.MsgServer.
func (ms msgServer) VoteTssKeyProcess(ctx context.Context, msg *types.MsgVoteTssKeyProcess) (*types.MsgVoteTssKeyProcessResponse, error) {
	signerAccAddr, err := sdk.AccAddressFromBech32(msg.Signer)
	if err != nil {
		return nil, fmt.Errorf("invalid signer address: %w", err)
	}

	// Convert account to validator operator address
	signerValAddr := sdk.ValAddress(signerAccAddr)

	// Lookup the linked universal validator for this signer
	isBonded, err := ms.k.uvalidatorKeeper.IsBondedUniversalValidator(ctx, msg.Signer)
	if err != nil {
		return nil, errors.Wrapf(err, "failed to check bonded status for signer %s", msg.Signer)
	}
	if !isBonded {
		return nil, fmt.Errorf("universal validator for signer %s is not bonded", msg.Signer)
	}

	isTombstoned, err := ms.k.uvalidatorKeeper.IsTombstonedUniversalValidator(ctx, msg.Signer)
	if err != nil {
		return nil, errors.Wrapf(err, "failed to check tombstoned status for signer %s", msg.Signer)
	}
	if isTombstoned {
		return nil, fmt.Errorf("universal validator for signer %s is tombstoned", msg.Signer)
	}

	err = ms.k.VoteTssKeyProcess(ctx, signerValAddr, msg.TssPubkey, msg.KeyId, msg.ProcessId)
	if err != nil {
		return nil, err
	}

	return &types.MsgVoteTssKeyProcessResponse{}, nil
}
