CVE-2018-10893 concerns integer overflow and buffer overflow in spice-client's LZ (Lempel-Ziv) compressed frame decompression—a codec that has no analog in protobuf-go. This repository contains no LZ compression/decompression logic at all.

Examining the actual bug class (integer overflow in length calculations leading to out-of-bounds buffer writes) against protobuf-go's wire decoding paths shows the relevant invariant is consistently enforced:

- `protowire.ConsumeBytes` checks `m > uint64(len(b[n:]))` before slicing, rejecting any length-prefixed value that would overrun the buffer [1](#0-0) .
- `protowire.ConsumeVarint`/`ConsumeFixed32`/`ConsumeFixed64` bound-check `len(b)` before reading and return an error code rather than reading past the slice [2](#0-1) [3](#0-2) .
- The lazy-decode `BufferReader` used internally for skipping/indexing fields (`internal/protolazy/bufferreader.go`) similarly checks `i >= len(buf)` and uses `Skip`, which validates `len(b.Buf) < b.Pos+n` before advancing, preventing any overflow-driven out-of-bounds access [4](#0-3) [5](#0-4) .
- Generated coder functions (e.g., `consumeBytesSlice`, `consumeSfixed64Slice`) all route through `protowire.ConsumeBytes`/`ConsumeFixed*` and check `n < 0` before using the result, so no unchecked length value ever reaches a slice/copy operation [6](#0-5) .

There is no decompression codec, no derived-length arithmetic that could overflow before a bounds check, and no buffer-ownership pattern resembling the spice-client LZ flaw. This is a different project's codec-specific memory-safety bug with no matching broken invariant on any reachable protobuf-go decode path.

// ConsumeFixed32 parses b as a little-endian uint32, reporting its length.
// This returns a negative length upon an error (see [ParseError]).
func ConsumeFixed32(b []byte) (v uint32, n int) {
	if len(b) < 4 {
		return 0, errCodeTruncated
	}
	v = uint32(b[0])<<0 | uint32(b[1])<<8 | uint32(b[2])<<16 | uint32(b[3])<<24
	return v, 4
}

func ConsumeBytes(b []byte) (v []byte, n int) {
	m, n := ConsumeVarint(b)
	if n < 0 {
		return nil, n // forward error code
	}
	if m > uint64(len(b[n:])) {
		return nil, errCodeTruncated
	}
	return b[n:][:m], n + int(m)
}

// skip skips the specified number of bytes
func (b *BufferReader) Skip(n int) (err error) {
	if len(b.Buf) < b.Pos+n {
		return io.ErrUnexpectedEOF
	}
	b.Pos += n
	return
}
