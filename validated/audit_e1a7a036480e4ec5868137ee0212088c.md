## Title
Unbounded per-cycle iteration in `MaintenanceManager.doMaintenance()` can stall consensus block processing - (File: `consensus/src/main/java/org/tron/consensus/dpos/MaintenanceManager.java`)

### Summary
The external report describes a Chainlink VRF callback (`fulfillRandomWords()`) whose cost grows with an attacker-influenceable parameter until it exceeds a hard, externally-imposed gas cap, causing the callback to revert and DoS the protocol. java-tron has a structurally analogous pattern in its DPoS consensus layer: `MaintenanceManager.doMaintenance()` [1](#0-0)  is invoked synchronously, once per fixed maintenance cycle, from `applyBlock()` [2](#0-1) , which itself runs inside the block-push critical section on every node (analogous to a "scheduled callback"). Unlike TVM transaction execution, which is metered by `EnergyProcessor`/energy limits [3](#0-2) , this maintenance path has **no gas/time bound at all** and its cost scales with attacker-controllable state (`VotesStore` size and `getAllWitnesses()` size), not with any fee paid by the caller.

### Finding Description
`doMaintenance()` performs several unbounded, whole-store iterations every maintenance cycle:
- `countVote(votesStore)` iterates every entry in `VotesStore` and deletes each one [4](#0-3) .
- `consensusDelegate.getAllWitnesses().forEach(...)` iterates all witnesses to accumulate reward VI values, when the new reward algorithm is active [5](#0-4) .
- A second full `getAllWitnesses()` loop persists brokerage/vote data per cycle [6](#0-5) .

`VotesStore` is keyed by the **voter's own account address** (`VotesCapsule.createDbKey()` returns the voter address, not the witness address) [7](#0-6) . Every account that submits a `VoteWitnessContract` gets its own entry written via `VoteWitnessActuator.countVoteAccount()` [8](#0-7)  or the equivalent TVM-native path in `VoteWitnessProcessor.execute()` [9](#0-8) . The only requirement to vote is holding non-zero TRON Power (frozen balance), which under `FreezeBalanceV2Contract` can be an arbitrarily small amount, so an attacker can cheaply create a very large number of distinct voting accounts, each contributing one `VotesStore` entry.

Because `doMaintenance()` (and its `countVote`/witness loops) run synchronously inside `Manager.pushBlock()`'s `synchronized` block on every full node that processes the maintenance-boundary block, an attacker who inflates `VotesStore` to a very large size can make this per-cycle work arbitrarily expensive with no cap, unlike smart-contract execution which is strictly energy-limited by `calculateGlobalEnergyLimit`/`useEnergy` in `EnergyProcessor` [10](#0-9) .

### Impact Explanation
If `doMaintenance()` takes excessively long, block processing for the maintenance-boundary block is delayed on every node, including the node scheduled to produce the next block. `DposTask.produceBlock()` enforces a hard production `timeout` derived from `BLOCK_PRODUCED_INTERVAL` [11](#0-10) , and `generateBlock()` also aborts packing more transactions once `System.currentTimeMillis() > timeout` [12](#0-11) . A sufficiently expensive `doMaintenance()` call can cause witnesses to miss their production slot at the maintenance boundary, repeatedly, degrading block production cadence chain-wide — a protocol-level DoS analogous to the VRF callback exceeding its gas ceiling and reverting, disrupting the game/protocol's ability to continue.

### Likelihood Explanation
Reachability is via ordinary, unprivileged, broadcastable transactions (`VoteWitnessContract`, `FreezeBalanceV2Contract`), with no special permission required. The cost to the attacker is proportional to the number of accounts/freeze+vote transactions created, so this is a resource-exhaustion play rather than a single crafted transaction, but it is fully reachable by any external actor over normal RPC broadcast without any privileged role, matching the "malicious API/RPC client submitting crafted inputs at scale" attacker profile.

### Recommendation
- Bound the per-cycle maintenance work independent of the number of accounts that voted, e.g. by capping/pagination of `VotesStore` iteration, or by tracking vote deltas incrementally at vote time instead of aggregating the whole store at the maintenance boundary.
- Consider adding an execution-time or iteration-count safety valve to `doMaintenance()` so it cannot indefinitely extend past a fixed budget within a block-production window, with any leftover work deferred to subsequent cycles.
- Re-evaluate the minimum TRON Power required to create a `VotesStore` entry so cheap Sybil accounts cannot cheaply blow up store size.

### Proof of Concept
1. Attacker creates N accounts and, for each, submits `FreezeBalanceV2Contract` for the minimum allowed frozen balance (validated only by `contract.getVotesCount() > 0` and `sum <= tronPower` in `VoteWitnessActuator.validate()` [13](#0-12) ).
2. From each account, attacker submits a `VoteWitnessContract` for any existing witness; `countVoteAccount()` writes one `VotesCapsule` per distinct owner address into `VotesStore` [14](#0-13) .
3. Repeating this for a very large N (bounded only by attacker's willingness to pay minimal freeze/fee) grows `VotesStore` to a large size.
4. At the next maintenance boundary, `MaintenanceManager.doMaintenance()` calls `countVote(votesStore)`, iterating and deleting every one of the N entries synchronously inside block processing [4](#0-3) , increasing processing latency for that block on every node and risking missed production slots enforced by `DposTask`'s `timeout` logic [15](#0-14) .

    VotesStore votesStore = consensusDelegate.getVotesStore();

    DelegationStore delegationStore = consensusDelegate.getDelegationStore();

    if (!countWitness.isEmpty()) {
      List<ByteString> currentWits = consensusDelegate.getActiveWitnesses();

      List<ByteString> newWitnessAddressList = new ArrayList<>();
      consensusDelegate.getAllWitnesses()
          .forEach(witnessCapsule -> newWitnessAddressList.add(witnessCapsule.getAddress()));

        if (witnessCapsule == null) {

          logger.warn("Witness account is null. address is {}", Hex.toHexString(witnessAddress));
          return;
        }
        witnessCapsule.setVoteCount(witnessCapsule.getVoteCount() + voteCount);
        consensusDelegate.saveWitness(witnessCapsule);
        logger.info("address is {} , countVote is {}", witnessCapsule.createReadableString(),
            witnessCapsule.getVoteCount());
      });

      dposService.updateWitness(newWitnessAddressList);

      incentiveManager.reward(newWitnessAddressList);

      List<ByteString> newWits = consensusDelegate.getActiveWitnesses();
      if (!CollectionUtils.isEqualCollection(currentWits, newWits)) {
        currentWits.forEach(address -> {
          WitnessCapsule witnessCapsule = consensusDelegate.getWitness(address.toByteArray());
          witnessCapsule.setIsJobs(false);
          consensusDelegate.saveWitness(witnessCapsule);
        });
        newWits.forEach(address -> {
          WitnessCapsule witnessCapsule = consensusDelegate.getWitness(address.toByteArray());
          witnessCapsule.setIsJobs(true);
          consensusDelegate.saveWitness(witnessCapsule);
        });

        SRMetrics.recordSrSetChange(currentWits, newWits);
      }

      logger.info("Update witness success. \nbefore: {} \nafter: {}",
          getAddressStringList(currentWits),
          getAddressStringList(newWits));
    }

    if (dynamicPropertiesStore.allowChangeDelegation()) {
      long nextCycle = dynamicPropertiesStore.getCurrentCycleNumber() + 1;
      dynamicPropertiesStore.saveCurrentCycleNumber(nextCycle);
      consensusDelegate.getAllWitnesses().forEach(witness -> {

            delegationStore.getBrokerage(witness.createDbKey()));
        delegationStore.setWitnessVote(nextCycle, witness.createDbKey(), witness.getVoteCount());

  private Map<ByteString, Long> countVote(VotesStore votesStore) {
    final Map<ByteString, Long> countWitness = Maps.newHashMap();
    Iterator<Entry<byte[], VotesCapsule>> dbIterator = votesStore.iterator();
    long sizeCount = 0;
    while (dbIterator.hasNext()) {
      Entry<byte[], VotesCapsule> next = dbIterator.next();
      VotesCapsule votes = next.getValue();
      votes.getOldVotes().forEach(vote -> {
        ByteString voteAddress = vote.getVoteAddress();
        long voteCount = vote.getVoteCount();
        if (countWitness.containsKey(voteAddress)) {
          countWitness.put(voteAddress, countWitness.get(voteAddress) - voteCount);
        } else {
          countWitness.put(voteAddress, -voteCount);
        }
      });
      votes.getNewVotes().forEach(vote -> {
        ByteString voteAddress = vote.getVoteAddress();
        long voteCount = vote.getVoteCount();
        if (countWitness.containsKey(voteAddress)) {
          countWitness.put(voteAddress, countWitness.get(voteAddress) + voteCount);
        } else {
          countWitness.put(voteAddress, voteCount);
        }
      });
      sizeCount++;
      votesStore.delete(next.getKey());
    }
    logger.info("There is {} new votes in this epoch", sizeCount);
    return countWitness;
  }

  public boolean useEnergy(AccountCapsule accountCapsule, long energy, long now) {

    long energyUsage = accountCapsule.getEnergyUsage();
    long latestConsumeTime = accountCapsule.getAccountResource().getLatestConsumeTimeForEnergy();
    long energyLimit = calculateGlobalEnergyLimit(accountCapsule);
    long newEnergyUsage;
    if (!dynamicPropertiesStore.supportUnfreezeDelay()) {
      newEnergyUsage = increase(energyUsage, 0, latestConsumeTime, now);
    } else {
      // only participate in the calculation as a temporary variable, without disk flushing
      newEnergyUsage = recovery(accountCapsule, ENERGY, energyUsage,
          latestConsumeTime, now);
    }

    if (energy > (energyLimit - newEnergyUsage)
        && dynamicPropertiesStore.getAllowTvmFreeze() == 0
        && !dynamicPropertiesStore.supportUnfreezeDelay()) {
      return false;
    }

    long latestOperationTime = dynamicPropertiesStore.getLatestBlockHeaderTimestamp();
    if (!dynamicPropertiesStore.supportUnfreezeDelay()) {
      newEnergyUsage = increase(newEnergyUsage, energy, now, now);
    } else {
      // Participate in calculation and flush disk persistence
      newEnergyUsage = increase(accountCapsule, ENERGY, energyUsage, energy,
          latestConsumeTime, now);
    }

    accountCapsule.setEnergyUsage(newEnergyUsage);
    accountCapsule.setLatestOperationTime(latestOperationTime);
    accountCapsule.setLatestConsumeTimeForEnergy(now);

    accountStore.put(accountCapsule.createDbKey(), accountCapsule);

    if (dynamicPropertiesStore.getAllowAdaptiveEnergy() == 1) {
      long blockEnergyUsage = dynamicPropertiesStore.getBlockEnergyUsage() + energy;
      dynamicPropertiesStore.saveBlockEnergyUsage(blockEnergyUsage);
    }

    return true;
  }

  private void countVoteAccount(VoteWitnessContract voteContract) {
    AccountStore accountStore = chainBaseManager.getAccountStore();
    VotesStore votesStore = chainBaseManager.getVotesStore();
    MortgageService mortgageService = chainBaseManager.getMortgageService();
    byte[] ownerAddress = voteContract.getOwnerAddress().toByteArray();

    VotesCapsule votesCapsule;

    //
    mortgageService.withdrawReward(ownerAddress);

    AccountCapsule accountCapsule = accountStore.get(ownerAddress);

    DynamicPropertiesStore dynamicStore = chainBaseManager.getDynamicPropertiesStore();
    if (dynamicStore.supportAllowNewResourceModel()
        && accountCapsule.oldTronPowerIsNotInitialized()) {
      accountCapsule.initializeOldTronPower();
    }

    if (!votesStore.has(ownerAddress)) {
      votesCapsule = new VotesCapsule(voteContract.getOwnerAddress(),
          accountCapsule.getVotesList());
    } else {
      votesCapsule = votesStore.get(ownerAddress);
    }

    accountCapsule.clearVotes();
    votesCapsule.clearNewVotes();

    voteContract.getVotesList().forEach(vote -> {
      logger.debug("countVoteAccount, address[{}]",
          ByteArray.toHexString(vote.getVoteAddress().toByteArray()));

      votesCapsule.addNewVotes(vote.getVoteAddress(), vote.getVoteCount());
      accountCapsule.addVotes(vote.getVoteAddress(), vote.getVoteCount());
    });

    accountStore.put(accountCapsule.createDbKey(), accountCapsule);
    votesStore.put(ownerAddress, votesCapsule);
  }
