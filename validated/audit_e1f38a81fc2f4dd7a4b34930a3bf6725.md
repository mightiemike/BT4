### Title
Missing declared-class check in Starknet OS `execute_replace_class` diverges from blockifier's enforced check, causing wrong committed state root on re-execution - ([File: crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo])

### Summary
The Rust blockifier (the sequencer's real execution engine) enforces that `replace_class` syscall targets must reference a declared, Cairo1-type class before mutating a contract's class hash. The Starknet OS Cairo implementation of the same syscall — used for re-execution and proof generation — does not perform this check at all; it is marked with an explicit `TODO` acknowledging the gap. Any unprivileged caller can invoke `replace_class_syscall` with an arbitrary felt as `class_hash`. In the sequencer's real (blockifier) path this reverts; in the OS's Cairo re-execution path it silently succeeds and writes the arbitrary class hash into `contract_state_changes`, which then flows directly into the Patricia state-commitment computation.

### Finding Description
The blockifier's syscall implementations for `replace_class` explicitly validate that the target class is declared (and, in the Cairo-native/Cairo1 handler, that it is Cairo1) before mutating state: [1](#0-0) [2](#0-1) 

This is validated by dedicated unit tests confirming the negative flow rejects undeclared/Cairo0 class hashes: [3](#0-2) [4](#0-3) 

In contrast, the Starknet OS's Cairo implementation of the identical syscall — used to independently re-execute the block's transactions for proving — performs no such check. Both the Cairo1 (current) syscall path and the deprecated (Cairo0) syscall path in the OS program directly overwrite the contract's `class_hash` field in `contract_state_changes` with the attacker-supplied value, with an explicit acknowledgment that the check is missing: [5](#0-4) [6](#0-5) 

The `contract_state_changes` dictionary that this syscall mutates is fed directly into the Patricia-tree commitment computation that derives the contract-state root: [7](#0-6) [8](#0-7) 

Root cause: the check "class hash must be declared" is enforced only in the blockifier's Rust syscall handler, not independently re-verified inside the OS Cairo program that re-executes the same bytecode for proof generation. This is a duplicated-trust-boundary bug: the OS's execution trace is supposed to be a byte-for-byte faithful re-execution of what the blockifier did, but for this one syscall the OS accepts an input (undeclared class hash) that the real sequencer execution would have rejected as a revert.

### Impact Explanation
`replace_class` is reachable from any account/contract by any unprivileged sender (no privileges required) via a standard `Invoke` transaction that calls a contract using the `replace_class_syscall`. If the blockifier and the Starknet OS diverge on whether this call succeeds or reverts:
- The state diff/root that the sequencer commits (via the real, correct blockifier execution — reverted, class unchanged) differs from the state diff/root the OS proves (succeeded, class hash overwritten with an arbitrary/garbage value).
- This produces a wrong committed root / honest-node divergence between the block builder execution and the Starknet OS re-execution used for proving, one of the explicitly accepted impact categories (wrong committed root or block hash, honest-node divergence).
- Because the mutated `class_hash` in the state entry participates directly in `get_contract_state_hash` used by the Patricia tree commitment, the OS-computed state root would not match the state actually persisted by the node, potentially causing proof/state verification failures or a corrupted committed state for that contract address (permanently freezing further correct interaction with the affected contract if the wrong class hash is finalized).

This satisfies the High-severity threshold: it's a concrete, unprivileged, transaction-triggerable defect with a clear divergence mechanism between two components that are required to agree bit-for-bit.

### Likelihood Explanation
Likelihood is high in terms of reachability (any invoke transaction from any contract using `replace_class_syscall` with a bogus class hash reaches this code path with zero privileges), but the practical severity depends on operational specifics not fully visible in the indexed code (e.g., whether the sequencer's block-building pipeline ever routes a transaction to the OS/prover without first confirming it matches the blockifier's real revert path, or whether there is a separate consistency check elsewhere in the prover pipeline — such as `starknet_transaction_prover`'s `validate_virtual_os_state_diff` — that might catch such a mismatch before finalization). I was not able to locate a check in the retrieved code that cross-validates the OS's state diff against the blockifier's actual state diff for this specific field before committing. Given the explicit unaddressed `TODO(Yoni, 1/1/2026)` comment directly acknowledging the missing validation, this appears to be a known, currently-unmitigated gap in the codebase at the time of this snapshot.

### Recommendation
Add the same "declared class hash" (and, where applicable, "Cairo1-only") validation inside the Starknet OS Cairo `execute_replace_class` implementations (both `syscall_impls.cairo` and `deprecated_execute_syscalls.cairo`) that already exists in the blockifier's Rust syscall handlers, so that the OS's re-execution is guaranteed to diverge identically (i.e., also revert) whenever the blockifier would revert. Alternatively/additionally, add a cross-check in the prover pipeline (e.g., in `starknet_transaction_prover`) that asserts the OS-derived state diff for `address_to_class_hash` matches the state diff produced by the blockifier before committing/proving a block.

### Proof of Concept
1. Deploy any contract exposing `replace_class_syscall` passthrough (e.g., the existing `test_replace_class` entry point in the feature-contract test fixtures: `crates/blockifier_test_utils/resources/feature_contracts/cairo1/test_contract.cairo:513-516`).
2. Submit an `Invoke` transaction from any unprivileged account calling `test_replace_class(class_hash=<undeclared_arbitrary_felt>)`.
3. In the blockifier (as verified by `crates/blockifier/src/execution/syscalls/syscall_tests/replace_class.rs:15-29`), this call fails with "is not declared", causing that inner call (and typically the whole `__execute__`) to revert; the contract's `class_hash` in the real committed state is unchanged.
4. When the same transaction bytecode is re-executed by the Starknet OS (`execute_replace_class` in `syscall_impls.cairo:881-920` / `deprecated_execute_syscalls.cairo:307-329`), no declared-class check is performed, so the OS's `contract_state_changes` dictionary is updated to the attacker-supplied class hash and that value flows into `compute_contract_state_commitment` (`commitment.cairo:76-111`, `151-206`), producing a state root inconsistent with the actual, correctly-reverted execution.

    pub fn replace_class(&mut self, class_hash: ClassHash) -> SyscallResult<()> {
        // Ensure the class is declared (by reading it), and of type V1.
        let compiled_class = self.state.get_compiled_class(class_hash)?;

        if !is_cairo1(&compiled_class) {
            return Err(SyscallExecutionError::ForbiddenClassReplacement { class_hash });
        }
        self.state.set_class_hash_at(self.call.storage_address, class_hash)?;
        Ok(())
    }

#[test]
fn test_replace_class() {
    // Negative flow.
    let chain_info = &ChainInfo::create_for_testing();
    let test_contract = FeatureContract::TestContract(CairoVersion::Cairo0);
    let empty_contract = FeatureContract::Empty(CairoVersion::Cairo0);
    let mut state = test_state(chain_info, Fee(0), &[(test_contract, 1), (empty_contract, 1)]);
    let test_address = test_contract.get_instance_address(0);
    // Replace with undeclared class hash.
    let calldata = calldata![felt!(1234_u16)];
    let entry_point_call = CallEntryPoint {
        calldata,
        entry_point_selector: selector_from_name("test_replace_class"),
        ..trivial_external_entry_point_new(test_contract)
    };
    let error = entry_point_call.execute_directly(&mut state).unwrap_err().to_string();
    assert!(error.contains("is not declared"));

    // Positive flow.
    let old_class_hash = test_contract.get_class_hash();
    let new_class_hash = empty_contract.get_class_hash();
    assert_eq!(state.get_class_hash_at(test_address).unwrap(), old_class_hash);
    let entry_point_call = CallEntryPoint {
        calldata: calldata![new_class_hash.0],
        entry_point_selector: selector_from_name("test_replace_class"),
        ..trivial_external_entry_point_new(test_contract)
    };
    entry_point_call.execute_directly(&mut state).unwrap();
    assert_eq!(state.get_class_hash_at(test_address).unwrap(), new_class_hash);
}

func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}

    contract_state_changes_start: DictAccess*,

    // Hash the entries of the contract state changes to prepare the input for the commitment tree
    // multi-update.

    compute_contract_state_commitment_inner(
        state_changes=contract_state_changes_start,
        n_contract_state_changes=n_contract_state_changes,
        hashed_state_changes=hashed_state_changes,
        patricia_update_constants=patricia_update_constants,
    );

    // Compute the initial and final roots of the contracts' state tree.
    local initial_root;
    local final_root;

    %{ SetPreimageForStateCommitments %}

    // Call patricia_update_using_update_constants() instead of patricia_update()
    // in order not to repeat globals_pow2 calculation.

        patricia_update_constants=patricia_update_constants,

        n_updates=n_contract_state_changes,
        height=MERKLE_HEIGHT,
        prev_root=initial_root,
        new_root=final_root,
    );

    return (CommitmentUpdate(initial_root=initial_root, final_root=final_root));
