## Analysis

The Sherlock report's root cause is: deriving a "safe" price/quote from an AMM pool that reflects the *current, manipulable* on-chain reserve state, then using that self-referential value both as the trade input and its own slippage guard. Push Chain has a structurally identical pattern in its GAS/GAS_AND_PAYLOAD inbound execution path.

### Title
Autoswap minPCOut slippage guard is derived from a manipulable Uniswap V3 spot quote, allowing sandwich extraction of user deposit value - (File: `x/uexecutor/keeper/evm.go`)

### Summary
When a user deposits native gas token via a `GAS` or `GAS_AND_PAYLOAD` inbound, the `uexecutor` module account swaps the deposited PRC20 into PC through `depositPRC20WithAutoSwap`, using `QuoterV2.quoteExactInputSingle` as the reference price and a fixed 5% band on that same quote as the only slippage protection.

### Finding Description
`GetSwapQuote` calls the Uniswap V3 `QuoterV2.quoteExactInputSingle`, which resolves the current spot price from pool state (`sqrtPriceX96`) — an instantaneous, single-block value, not a TWAP. [1](#0-0) 

`ExecuteInboundGas` (and `gasAndPayloadDepositAutoSwap`) then computes `minPCOut = quote * 95 / 100` from that exact quote and immediately feeds it into `CallPRC20DepositAutoSwap`, which executes the real swap against the same pool in the same call. [2](#0-1) [3](#0-2) 

Because `quote` and the actual executed swap read the *same* pool state at essentially the same point (both invoked from within the same `ExecuteInboundGas`/`ExecuteInboundGasAndPayload` execution, which itself runs deterministically once the inbound ballot finalizes), the slippage guard offers no protection against pre-existing price manipulation: an attacker can push the PRC20/WPC pool price down immediately before the ballot-triggered execution (front-run), causing `GetSwapQuote` to return a depressed `amountOut`, then let `depositPRC20WithAutoSwap` execute at that same depressed price (which still satisfies `minPCOut` because both numbers are computed off the same manipulated state), and finally reverse the manipulation (back-run) to recapture the extracted value. The victim is the UEA receiving PC — it receives PC valued at the manipulated price instead of the true market price, and the difference is captured by the attacker's sandwich trade.

This mirrors the Sherlock H-9 root cause exactly: an AMM's instantaneous, reserve-derived price is used as ground truth for a critical fund-conversion step, and the "protection" (proportion/slippage threshold) is computed from the very same manipulable value, so it cannot prevent extraction.

### Impact Explanation
Falls under "corruption of PRC20 or native asset accounting" / degraded value delivered to users in the universal execution path. Every `GAS`/`GAS_AND_PAYLOAD` inbound routed through autoswap can have its PC output value skimmed by a sandwiching attacker, with no privileged access required — it is purely a function of controlling swaps in the same underlying Uniswap V3 pool that `UniversalCore` uses for `defaultFeeTier`/`quoteExactInputSingle`/`depositPRC20WithAutoSwap`.

### Likelihood Explanation
The inbound execution triggers deterministically when the UV ballot passes 2/3 threshold — an event visible in the mempool/consensus process before it lands, giving an attacker a predictable window to manipulate the pool and unwind afterward. Any attacker with capital to move the target PRC20/WPC pool (which is protocol-deployed and likely to have moderate liquidity) can execute this without needing validator, TSS, or admin privileges — satisfying the "unprivileged external attacker" scope requirement.

### Recommendation
Do not derive the slippage floor from the same spot quote used to authorize the trade. Use a TWAP-based quote (e.g., Uniswap V3 `observe`/oracle cardinality) with a bounded max deviation from a recent multi-block window, or apply a protocol-configured, registry-driven price band per token (via `uregistry` `TokenConfigs`) instead of a percentage of the instantaneous quote, so a single-block manipulation cannot simultaneously set both the trade price and its own acceptance bound.

### Proof of Concept
1. Attacker observes a pending `MsgVoteInbound` (or the accumulating votes) for a `GAS`/`GAS_AND_PAYLOAD` inbound that will trigger `ExecuteInboundGas`/`ExecuteInboundGasAndPayload` once threshold is reached.
2. Immediately before the finalizing vote lands, attacker swaps a large amount into the PRC20→WPC Uniswap V3 pool used by `UniversalCore`, depressing the spot price.
3. The finalizing vote executes `ExecuteInboundGas`, which calls `GetSwapQuote` (depressed) → computes `minPCOut = quote*95/100` (also depressed) → calls `CallPRC20DepositAutoSwap`, which swaps at the manipulated price and satisfies its own depressed `minPCOut`. [4](#0-3) 
4. Attacker reverses their initial swap, restoring the price and capturing the value difference between true market price and manipulated execution price, at the expense of the PC amount actually credited to the victim's UEA.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}
