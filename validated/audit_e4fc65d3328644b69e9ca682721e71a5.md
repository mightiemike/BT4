### Title
Sandwichable spot-price quote in `GetSwapQuote`/`CallPRC20DepositAutoSwap` lets an unprivileged trader extract value from inbound gas-swap depositors - (File: `x/uexecutor/keeper/evm.go`, `x/uexecutor/keeper/execute_inbound_gas.go`, `x/uexecutor/keeper/execute_inbound_gas_and_payload.go`, `x/uexecutor/keeper/outbound.go`)

### Summary
When a `GAS` / `GAS_AND_PAYLOAD` inbound reaches quorum, `ExecuteInboundGas`/`gasAndPayloadDepositAutoSwap` fetch a live spot quote from the Uniswap V3 `QuoterV2` contract and immediately execute a real swap using that quote with a fixed 5% slippage tolerance, with no TWAP or price-limit protection. This is precisely the pattern in the TrueFi report: a value used to compute another user's payout is read from a shared, externally-manipulable AMM pool right before it is consumed, letting an unprivileged actor move the price beforehand (and reverse it afterward) to skim value from the honest flow, repeatably, at low cost.

### Finding Description
`GetSwapQuote` calls `quoterAddr.quoteExactInputSingle` with `SqrtPriceLimitX96: big.NewInt(0)` (no price bound) to get the current spot conversion rate for `prc20 → wpc`: [1](#0-0) 

The resulting `quote` is used to compute `minPCOut = quote * 95 / 100` (a flat 5% slippage allowance) and passed straight into `CallPRC20DepositAutoSwap`, which performs the actual on-chain swap via `depositPRC20WithAutoSwap`: [2](#0-1) 

The same pattern repeats for `GAS_AND_PAYLOAD` inbounds and for outbound gas refunds: [3](#0-2) [4](#0-3) 

Because the quote is a single instantaneous read of the Uniswap V3 pool's current tick/price with no TWAP averaging and no `sqrtPriceLimitX96` bound, any ordinary, unprivileged trader can submit an EVM transaction against the same pool in a block ordered ahead of the validators' `MsgVoteInbound` that triggers this swap. This pushes the pool price against the module's forthcoming swap direction; the module then reads the now-skewed quote, computes `minPCOut` off that skewed value, and executes the swap, receiving (and passing on to the depositing user's UEA) up to ~5% less `PC`/`WPC` than fair value. The attacker then reverses their position afterward, capturing the price impact as profit. No validator or admin action is required — this is triggerable purely by an ordinary EVM user placing swaps in the shared Uniswap pool around the time third-party inbound votes reach quorum, mirroring Alice's front-run-then-repay borrow in the TrueFi report exactly: legitimate-looking transactions bracketing a protocol read/execute step that another user's outcome depends on.

### Impact Explanation
Every `GAS`/`GAS_AND_PAYLOAD` inbound deposit and every outbound gas refund routes value through this quote-then-swap sequence. Depositors and outbound-fee-refund recipients receive PRC20/PC accounting that is silently corrupted by attacker-controlled price manipulation, up to the 5% slippage budget per occurrence, and the attack is repeatable indefinitely against any user whose inbound/outbound happens to land near an attacker's sandwich. This corrupts native/PRC20 asset accounting and causes material, permanent value loss to the affected user, fitting the "corruption of PRC20 or native asset accounting" and "permanent loss ... of user ... funds" allowed impacts.

### Likelihood Explanation
No privileged role is required — any address can trade against the Uniswap V3 pool backing `WPC`/gas-token pairs. The attack only requires observing pending `MsgVoteInbound`/`MsgVoteOutbound` transactions (public mempool) and placing an ordinary swap ahead of them, then reversing afterward — standard, low-cost MEV/sandwich tooling. The fixed, generous 5% slippage tolerance (rather than a TWAP-based or otherwise manipulation-resistant reference price) is what turns ordinary trading into an extractable griefing vector against these protocol-initiated swaps.

### Recommendation
Replace the instantaneous `quoteExactInputSingle` spot read with a manipulation-resistant reference (e.g., TWAP over a meaningful window, or a `sqrtPriceLimitX96` bound derived from a recent oracle-checked price), tighten/adaptively size the slippage tolerance instead of a flat 5%, and/or execute the swap atomically with the quote in a way that cannot be sandwiched by ordinary same-block trades (e.g., commit-reveal or minimum-output bound sourced from an off-chain, validator-attested price rather than the same pool being swapped against).

### Proof of Concept
1. Attacker monitors the Push Chain mempool for `MsgVoteInbound` transactions that will bring a `GAS`/`GAS_AND_PAYLOAD` inbound to quorum (2/3+ votes), which triggers `ExecuteInboundGas`.
2. Immediately before that vote lands, attacker submits an ordinary EVM swap against the same Uniswap V3 pool (`prc20`/`WPC`) used by `GetSwapQuote`, moving the pool's spot price unfavorably for the upcoming `prc20 → wpc` swap direction.
3. The validators' vote finalizes in the same or next block; `ExecuteInboundGas` calls `GetSwapQuote` (reading the now-skewed price), computes `minPCOut = quote * 95/100`, and calls `CallPRC20DepositAutoSwap`, executing at the manipulated rate.
4. Attacker reverses their position (sells back) after the module's swap executes, capturing the price-impact spread as profit while the depositing user's UEA receives fewer `WPC`/`PC` tokens than fair value.
5. Repeat against subsequent inbound/outbound gas-swap flows at low cost per iteration.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
