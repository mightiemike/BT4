## Analysis

The reported bug class — an on-chain "price" variable that is written periodically by a permissioned updater and then consumed in a value-changing operation with no freshness check at the point of use — has a direct analog in Push Chain's cross-chain gas-fee accounting path.

### Where the pattern reappears

`x/uexecutor/keeper/chain_meta.go`'s `VoteChainMeta` carefully filters votes by freshness (`chainMetaVoteStalenessSeconds`) before computing the median and pushing it on-chain via `CallUniversalCoreSetChainMeta` (`setChainMeta`) [1](#0-0) . That staleness discipline, however, only governs *which votes contribute to the next write*. Once the median is written to the `UniversalCore` system contract, the stored `gasPriceByChainNamespace` value is durable and carries no expiry: `GetGasPriceByChain`/`GetOutboundTxGasAndFees` simply read whatever was last written [2](#0-1) .

The `UniversalCore` ABI exposes a `timestampObservedAtByChainNamespace` view [3](#0-2) , indicating the contract does track an observation timestamp, but none of the Go call sites that consume the price for fee accounting check it:

- `GetOutboundTxGasAndFees` calls `getOutboundTxGasAndFees` and unpacks `gasToken/gasFee/gasPrice/gasLimit` with no staleness gate [4](#0-3) .
- `buildRevertOutbound` uses that same unguarded call to populate `OutboundTx.GasFee/GasPrice` for a revert path [5](#0-4) .
- `BuildOutboundsFromReceipt` copies `gas_fee`/`gas_price` straight from the `UniversalTxOutboundEvent` emitted by the Solidity gateway, which itself derives those values from the same stale-tolerant `gasPriceByChainNamespace` storage slot at execution time [6](#0-5) .
- `applyGasRefund`/`handleSuccessfulOutbound`/`handleFailedOutbound` reconcile only the difference between the *reserved* `gas_fee` (computed from the possibly stale price) and the *observed* `gas_fee_used` reported by validators — there is no check that the reserved fee was computed from a fresh oracle read before it is trusted as the basis for refunds [7](#0-6) .

### Why this matters

The `ChainMetaOracle` in `universalClient` (both EVM and SVM variants) is a periodic off-chain ticker that fetches gas price and votes it in [8](#0-7) . If this reporting stalls for any chain (RPC outage, restart, config issue — none of which require a malicious validator), the on-chain `gasPriceByChainNamespace` value silently freezes at its last-written level while `getOutboundTxGasAndFees`/`getRescueFundsGasLimit` continue to be treated as authoritative, current data for computing what a user is charged for an outbound, exactly mirroring the `WrappedIbbtcEth.balanceToShares` pattern of using a contract-cached price with no `lastPricePerShareUpdate`-style guard at consumption time.

An unprivileged user who monitors the destination chain's real gas price against Push Chain's `QueryGasPriceRequest` (`GasPrice`/`AllGasPrices` query, `x/uexecutor/keeper/query_server.go`) can time inbound `GAS`/`GAS_AND_PAYLOAD`/`FUNDS_AND_PAYLOAD` submissions to land while the on-chain quote is stale-low relative to the real market rate, systematically under-paying the reserved `gas_fee` that funds the destination-chain outbound execution. Because the pool that fronts destination-chain execution absorbs any shortfall between the reserved `gas_fee` and true cost, this is a repeatable, unprivileged drain vector on protocol-held gas funds rather than a benign accounting quirk — this squarely falls in the allowed "corruption of ... gas fee accounting, refund accounting" impact category.

However, I want to flag important caveats before treating this as a confirmed finding rather than a plausible analog:
- I could not find the actual `UniversalCore.sol` source in this repository (only its Go-side ABI mirror), so I cannot confirm whether the Solidity contract itself enforces a staleness check that the Go/keeper layer simply doesn't need to duplicate (e.g., `getOutboundTxGasAndFees` reverting if `timestampObservedAtByChainNamespace` is too old). If the contract does self-gate on staleness, this reduces to a non-issue at the repo's reachable layer.
- Quantifying the exploitable margin requires knowing typical oracle poll intervals versus real-world gas volatility, which is operational/deployment data not present in the repo.

Given the uncertainty about whether `UniversalCore.sol`'s Solidity itself already gates on `timestampObservedAtByChainNamespace` (the ABI's mere existence suggests the authors were aware of the staleness concern and built in the tracking primitive, which is a strong signal a check may already exist there, just not verifiable from this repo's contents), I can't assert with confidence that scoped Go-side guards are actually missing versus redundant with unseen Solidity guards. [3](#0-2)  If you want a definitive verdict, the Solidity source for `UniversalCore` (not present in this indexed repo — likely lives in a separate contracts repository) would need to be reviewed for whether `getOutboundTxGasAndFees`/`refundUnusedGas` check `timestampObservedAtByChainNamespace` against a threshold before returning/using the stored price. Due to index size limits, some file contents (particularly any Solidity contracts) may not be available here — starting a Devin session with full repository access would let you confirm this definitively.

// GetGasPriceByChain reads the gas price for a chain from the UniversalCore contract.
func (k Keeper) GetGasPriceByChain(ctx sdk.Context, chainNamespace string) (*big.Int, error) {
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse UniversalCore ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	receipt, err := k.evmKeeper.CallEVM(ctx, abi, ueModuleAccAddress, handlerAddr, false, nil, "gasPriceByChainNamespace", chainNamespace)
	if err != nil {
		return nil, errors.Wrap(err, "failed to call gasPriceByChainNamespace")
	}

	results, err := abi.Methods["gasPriceByChainNamespace"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack gasPriceByChainNamespace result")
	}

	return results[0].(*big.Int), nil
}

func (k Keeper) GetOutboundTxGasAndFees(ctx sdk.Context, prc20 common.Address, gasLimitWithBaseLimit *big.Int) (*GasFeeInfo, error) {
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	ucABI, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse UniversalCore ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	receipt, err := k.evmKeeper.CallEVM(ctx, ucABI, ueModuleAccAddress, handlerAddr, false, nil,
		"getOutboundTxGasAndFees", prc20, gasLimitWithBaseLimit)
	if err != nil {
		return nil, errors.Wrap(err, "failed to call getOutboundTxGasAndFees")
	}

	results, err := ucABI.Methods["getOutboundTxGasAndFees"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack getOutboundTxGasAndFees result")
	}

	gasToken := results[0].(common.Address)
	gasFee := results[1].(*big.Int)
	// protocolFee := results[2].(*big.Int) — not needed for outbound fields
	gasPrice := results[3].(*big.Int)
	// chainNamespace := results[4].(string) — not needed for outbound fields
	// gasLimitUsed (results[5]) is the exact gas limit the contract resolved
	// (caller-supplied or per-chain baseGasLimitByChainNamespace fallback).
	// Reading it directly avoids the gasFee/gasPrice round-trip and keeps us
	// in lock-step with the contract's own resolution.
	gasLimit := results[5].(*big.Int)

	return &GasFeeInfo{
		GasToken: gasToken,
		GasFee:   gasFee,
		GasPrice: gasPrice,
		GasLimit: gasLimit,
	}, nil
}

// applyGasRefund computes the excess gas (gasFee - gasFeeUsed) and, if positive,
// calls UniversalCore refundUnusedGas. The result is recorded in outbound.PcRefundExecution.
// It is called for both successful and failed outbounds — gas is consumed on the
// external chain regardless of execution outcome.
func (k Keeper) applyGasRefund(ctx sdk.Context, outbound *types.OutboundTx, obs *types.OutboundObservation) {
	if obs.GasFeeUsed == "" || outbound.GasFee == "" || outbound.GasToken == "" {
		return
	}

	gasFee := new(big.Int)
	if _, ok := gasFee.SetString(outbound.GasFee, 10); !ok {
		return
	}

	gasFeeUsed := new(big.Int)
	if _, ok := gasFeeUsed.SetString(obs.GasFeeUsed, 10); !ok {
		return
	}

	// No excess gas to refund
	if gasFee.Cmp(gasFeeUsed) <= 0 {
		return
	}

	defer g.wg.Done()

		Dur("interval", interval).
