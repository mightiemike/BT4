### Title
Panic/DoS in `decompress` via malformed compressed state-diff header causes Starknet OS output parsing to abort - (File: crates/starknet_os/src/io/os_output_types.rs, crates/starknet_os/src/hints/hint_implementation/stateless_compression/utils.rs)

### Summary
`decompress()` in `crates/starknet_os/src/hints/hint_implementation/stateless_compression/utils.rs:545-617` unpacks a header and several length fields (`unique_value_bucket_lengths`, `n_repeating_values`, `data_len`, `bucket_index_per_elm`) directly from the felt stream with no bounds validation before using them as slice lengths / indices (`unique_values[*ptr]`, `bucket_offset_trackers[bucket_index]`, `header[2..2+N_UNIQUE_BUCKETS]`). This is invoked from `PartialOsStateDiff::try_from_output_iter` (`crates/starknet_os/src/io/os_output_types.rs:401-420`), which parses the OS program output/state-diff stream that ultimately encodes contract storage changes.

### Finding Description
`decompress` reads a header of unchecked usize values via `unpack_chunk_to_usize` (`utils.rs:571-577`) and then:
- Uses `unique_value_bucket_lengths[i]` and `n_repeating_values` to slice/iterate the incoming felt iterator (`utils.rs:580-591`).
- Indexes `unique_values[*ptr]` with `ptr` values taken from `repeating_value_pointers` without validating `ptr < unique_values.len()` (`utils.rs:593-594`), unlike the Cairo counterpart in `compression.cairo` which explicitly proves pointer bounds via `dict_squash`/`dict_update` (`compression.cairo:280-303`, comment at `compression.cairo:199-200` "unpack_repeating_value_pointers guarantees each pointer is in range").
- Indexes `bucket_offset_trackers[bucket_index]` with `bucket_index` values taken from `bucket_index_per_elm`, again unchecked in Rust (`utils.rs:610-613`), whereas the Cairo code enforces the invariant with a squashed dictionary.

In short, the Rust `decompress` (used for parsing OS output, not the proven Cairo VM execution) omits the bound checks the Cairo implementation encodes as provable constraints (dict_squash), so any malformed/inconsistent length or pointer field in the input causes an out-of-bounds Vec index, panicking the process (Rust panics on out-of-bounds slice/vec index by default, equivalent in kind to the fortify/panic in the kernel CVE, though Rust's memory-safety guarantees turn what would be a C memory-corruption bug into a guaranteed abort rather than a write past a buffer).

### Impact Explanation
This function is reached when decoding `PartialOsStateDiff` from a felt iterator that ultimately represents a state diff/output stream. If this parsing path is exercised on data whose provenance is not fully re-validated against Cairo-proven constraints (e.g., replay/verification tooling, Echonet, or any off-chain consumer that decodes OS output before/without relying solely on the STARK proof), a crafted or corrupted header can trigger a panic (denial of service in that component) rather than a graceful error. Note `decompress` is annotated `#[allow(dead_code)]` in the file I inspected, and I could not fully confirm within the available context whether this code path is exercised in the actual sequencer/consensus block-execution hot path versus only in auxiliary/offline tooling (e.g., Echonet output decoding) — this is the main source of uncertainty in the finding.

### Likelihood Explanation
If the sequencer's own Cairo VM execution enforces the bucket/pointer invariants via `dict_squash` (as `compression.cairo` does), a legitimately-proven block cannot present malformed header/pointer values, which would make this Rust path unreachable with attacker-controlled data during normal execution. The bug is only concretely exploitable if some component decodes `PartialOsStateDiff`/`decompress` from data that has not passed through the Cairo-proof-enforced invariants — I could not verify this precisely from the available files.

### Recommendation
Add explicit bounds checks in the Rust `decompress` function (`utils.rs`) mirroring the Cairo-side invariants: validate that every `bucket_index` is within `[0, TOTAL_N_BUCKETS)` and within the current bucket_offset_trackers array bounds, and that every repeating-value pointer is `< unique_values.len()`, returning a typed error (e.g., `OsHintError`/`OsOutputError`) instead of panicking on out-of-range indices.

/// Decompresses the given compressed data.
#[allow(dead_code)]
pub fn decompress(compressed: &mut impl Iterator<Item = Felt>) -> Vec<Felt> {
    fn unpack_chunk<const LENGTH: usize>(
        compressed: &mut impl Iterator<Item = Felt>,
        n_elms: usize,
    ) -> Vec<Felt> {
        let n_elms_per_felt = BitLength::min_bit_length(LENGTH).unwrap().n_elems_in_felt();
        let n_packed_felts = n_elms.div_ceil(n_elms_per_felt);
        let compressed_chunk: Vec<_> = compressed.take(n_packed_felts).collect();
        unpack_felts(&compressed_chunk, n_elms)
            .into_iter()
            .map(|bits: BitsArray<LENGTH>| felt_from_bits_le(&bits.0).unwrap())
            .collect()
    }

    fn unpack_chunk_to_usize(
        compressed: &mut impl Iterator<Item = Felt>,
        n_elms: usize,
        elm_bound: ElmBoundType,
    ) -> Vec<usize> {
        let n_elms_per_felt = get_n_elms_per_felt(elm_bound);
        let n_packed_felts = n_elms.div_ceil(n_elms_per_felt);

        let compressed_chunk: Vec<_> = compressed.take(n_packed_felts).collect();
        unpack_felts_to::<usize>(&compressed_chunk, n_elms, elm_bound)
    }

    let header = unpack_chunk_to_usize(compressed, HEADER_LEN, HEADER_ELM_BOUND);
    let version = &header[0];
    assert!(version == &usize::from(COMPRESSION_VERSION), "Unsupported compression version.");

    let data_len = &header[1];
    let unique_value_bucket_lengths: Vec<usize> = header[2..2 + N_UNIQUE_BUCKETS].to_vec();
    let n_repeating_values = &header[2 + N_UNIQUE_BUCKETS];

    let mut unique_values = Vec::new();
    unique_values.extend(compressed.take(unique_value_bucket_lengths[0])); // 252 bucket.
    unique_values.extend(unpack_chunk::<125>(compressed, unique_value_bucket_lengths[1]));
    unique_values.extend(unpack_chunk::<83>(compressed, unique_value_bucket_lengths[2]));
    unique_values.extend(unpack_chunk::<62>(compressed, unique_value_bucket_lengths[3]));
    unique_values.extend(unpack_chunk::<31>(compressed, unique_value_bucket_lengths[4]));
    unique_values.extend(unpack_chunk::<15>(compressed, unique_value_bucket_lengths[5]));

    let repeating_value_pointers = unpack_chunk_to_usize(
        compressed,
        *n_repeating_values,
        unique_values.len().try_into().unwrap(),
    );

    let repeating_values: Vec<_> =
        repeating_value_pointers.iter().map(|ptr| unique_values[*ptr]).collect();

    let mut all_values = unique_values;
    all_values.extend(repeating_values);

    let bucket_index_per_elm: Vec<usize> =
        unpack_chunk_to_usize(compressed, *data_len, TOTAL_N_BUCKETS.try_into().unwrap());

    let all_bucket_lengths: Vec<usize> =
        unique_value_bucket_lengths.into_iter().chain([*n_repeating_values]).collect();

    let bucket_offsets = get_bucket_offsets(&all_bucket_lengths);

    let mut bucket_offset_trackers: Vec<_> = bucket_offsets;

    let mut result = Vec::new();
    for bucket_index in bucket_index_per_elm {
        let offset = &mut bucket_offset_trackers[bucket_index];
        let value = all_values[*offset];
        *offset += 1;
        result.push(value);
    }
    result
}

// Unpacks the repeating value pointers from `compressed`.
// Each pointer points to a value in the unique_values and corresponds to the original data element
// at the same position.
// The function guarantees that: each pointer is in range [0, n_unique_values).
func unpack_repeating_value_pointers{range_check_ptr, compressed: felt*}(
    n_repeating_values: felt, n_unique_values: felt
) -> felt* {
    alloc_locals;
    let (local pointers: felt*) = alloc();

    // The pointer bound (unlike the fixed bucket bounds) is dynamically set as the number of
    // unique values.
    let pointer_bound = n_unique_values;
    let n_elms_per_felt = get_n_elms_per_felt(elm_bound=pointer_bound);

    let decompressed_dst = pointers;
    with decompressed_dst {
        unpack_felts(
            n_elms=n_repeating_values, elm_bound=pointer_bound, n_elms_per_felt=n_elms_per_felt
        );
    }
    return pointers;
}
