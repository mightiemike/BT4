### Title
Starknet OS `execute_replace_class` skips the declared-class and V0/V1-compatibility checks that blockifier enforces, causing OS/sequencer state divergence - (File: crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo)

### Summary
The `replace_class` syscall lets any contract invoked from an unprivileged transaction swap the class hash bound to its own storage address. In the blockifier (the execution engine that actually builds blocks), this syscall is guarded: the target class hash must be a declared class, and a Cairo1 (Sierra/V1) class may not be replaced by a Cairo0 (V0) class. In the Starknet OS Cairo program (which re-executes transactions to produce the state-transition proof), the equivalent function performs neither check — it is explicitly flagged with a `TODO` acknowledging the missing validation. This is the same bug class as the Flowise report: a caller-supplied identifier (here, `class_hash`, analogous to `credentialId`) is trusted and used to mutate privileged state by one code path while a parallel/downstream code path (the OS re-execution, analogous to a second consumer of the same identifier) omits the ownership/validity check the primary path performs.

In the Starknet OS Cairo program, the analogous function directly overwrites the contract's state entry with the attacker-supplied `class_hash` with **no declared-class check and no V0/V1 compatibility check** — the code contains an explicit acknowledgment of the gap: [4](#0-3)

Both OS entry points are reachable from any ordinary transaction, since `REPLACE_CLASS_SELECTOR` is dispatched unconditionally for any contract's syscall stream: [6](#0-5) 

### Impact Explanation
Blockifier is the authority for what actually happens on-chain when a block is built; the Starknet OS is a separate Cairo re-execution of the same transactions used to produce the STARK proof and the committed state root/block hash. If a transaction's `replace_class` syscall targets an undeclared class hash, or attempts to downgrade a V1 contract to a V0 class, blockifier fails/reverts that call (and the enclosing transaction), leaving the contract's class hash unchanged in the real, committed state. Because the OS's `execute_replace_class` has no equivalent check, it will treat the same syscall as *successful* and unconditionally write the attacker-controlled `class_hash` into `contract_state_changes` for that contract address.

This produces a genuine divergence between:
- the actual state maintained by the sequencer/blockifier (the source of truth honest nodes observe), and
- the state diff / state root computed by the Starknet OS re-execution, which is what gets committed as the finalized state root and proved to L1.

This satisfies the "wrong committed root" / "honest-node divergence" criteria: the OS can compute and attest to a state transition (a contract's class hash silently reassigned to an arbitrary, potentially undeclared or version-incompatible class) that never actually happened in the canonical sequencer execution. This can permanently corrupt the committed representation of a contract's code without ever having passed blockifier's declared-class/version safety checks.

### Likelihood Explanation
Reachability requires nothing beyond ordinary permissionless capabilities: declare/deploy a contract that calls `replace_class_syscall` with an attacker-chosen felt as `class_hash`, then submit a normal invoke transaction. No special privileges, staker/prover access, or network position are needed — this is directly reachable from a single submitted transaction, matching the "unprivileged transaction sender" reachability requirement. The only friction is that the transaction is expected to revert in the real network (per blockifier), but reverted transactions are still included on-chain and still re-executed by the OS for proving, so the code path is definitely exercised.

### Recommendation
Add the same two checks in the Starknet OS's `execute_replace_class` (both `syscall_impls.cairo` and the deprecated `deprecated_execute_syscalls.cairo` variant) that blockifier already enforces:
1. Verify the target `class_hash` corresponds to a class that is actually declared (fail/revert consistently with blockifier's `UndeclaredClassHash` behavior) — resolving the outstanding `TODO(Yoni, 1/1/2026)`.
2. Reject replacement of a Cairo1/V1 class with a Cairo0/V0 class hash, matching blockifier's `ForbiddenClassReplacement` check.

Both checks must produce exactly the same success/failure outcome (and therefore the same resulting state diff) as blockifier for every transaction, to guarantee the OS proof always matches the sequencer's real execution.

### Proof of Concept
1. Deploy a Cairo1 account/contract `A` with a class hash `H_A` that has been legitimately declared.
2. Invoke `A`'s entry point that calls `replace_class_syscall(class_hash=X)` where `X` is either (a) an arbitrary felt that has never been declared, or (b) the class hash of a legitimately declared Cairo0 (V0) class.
3. In blockifier's real execution, this call fails: `state.get_compiled_class(X)` returns `UndeclaredClassHash` (case a) or the base `replace_class` returns `ForbiddenClassReplacement` (case b); the transaction reverts, and `A`'s class hash remains `H_A` in the real state (confirmed by `crates/blockifier/src/execution/syscalls/syscall_tests/replace_class.rs`).
4. When the Starknet OS re-executes the same (reverted) transaction to build the block's proof, `execute_replace_class` in `syscall_impls.cairo` performs no such check, unconditionally updates `contract_state_changes` for `A`'s address with `class_hash = X`, and proceeds as if the syscall succeeded.
5. Result: the OS-computed state diff/state root asserts `A`'s class is now `X`, while the actual canonical (blockifier) state still has `A`'s class as `H_A` — a divergence between the honest sequencer state and the state committed/proved by the Starknet OS.

// Replaces the class.
func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
