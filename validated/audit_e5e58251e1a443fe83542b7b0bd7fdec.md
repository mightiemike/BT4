Every validator executing the same transaction at the same ledger version sees the identical `timestamp_micros` (derived from consensus-committed block timestamp) fed into `TimedFeaturesBuilder::new`, so `is_enabled(FixTableNativesMemoryDoubleCounting)` evaluates identically for all honest validators executing that block.
