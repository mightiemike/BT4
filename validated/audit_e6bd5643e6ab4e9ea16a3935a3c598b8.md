### Title
Open redirect via unvalidated `exitIframe` destination domain in `respondToExitIframeRequest` - ([File: packages/apps/shopify-app-remix/src/server/authenticate/admin/authenticate.ts])

### Summary
`respondToExitIframeRequest` reads the `exitIframe` query parameter directly from the incoming request and passes it as the redirect target to `renderAppBridge`. The downstream sanitizer `sanitizeRedirectUrl` only checks the URL's protocol/format (no `file://`, no whitespace, no `///`, http/https only) but never restricts the destination to the app's own domain or a Shopify-owned domain, allowing any external HTTPS/HTTP URL to be rendered as an app-bridge exit-iframe redirect.

### Finding Description
`respondToExitIframeRequest` at `packages/apps/shopify-app-remix/src/server/authenticate/admin/authenticate.ts:68-80` takes `exitIframe` straight from `url.searchParams.get('exitIframe')` and forwards it unmodified as `{url: destination}` to `renderAppBridge`. [1](#0-0) 

`renderAppBridge` (`packages/apps/shopify-app-remix/src/server/authenticate/admin/helpers/render-app-bridge.ts:14-46`) calls `sanitizeRedirectUrl(config.appUrl, redirectTo.url)` and embeds the result verbatim into a `<script>window.open(...)</script>` payload served to the browser inside the app-bridge exit page. [2](#0-1) 

The sanitizer, `sanitizeRedirectUrl`/`isSafe` in `validate-redirect-url.ts:16-67`, resolves the URL with `new URL(redirectUrl, domain)`. Because `redirectUrl` here can be a fully-qualified absolute URL, the `domain` base parameter is ignored by the `URL` constructor, and the function only verifies: no `file://` triple slash, no whitespace, no `//` in the pathname, and protocol is `http:`/`https:` (with SSL required by default). It never compares `url.hostname` against `config.appUrl`'s hostname or any Shopify-owned domain allowlist. [3](#0-2) [4](#0-3) 

As a result, an unauthenticated attacker who gets a merchant/admin to load `https://<app>/<exitIframePath>?exitIframe=https://evil.example.com&shop=<shop>.myshopify.com` will receive a page that runs `window.open("https://evil.example.com/", "_top")`, breaking out of the Shopify admin iframe and navigating the top-level browsing context to the attacker's domain.

### Impact Explanation
This is an open redirect out of the embedded iframe/app-bridge context, controlled entirely by an unauthenticated request parameter, with no allowlist check against Shopify-owned or the app's own domain. It matches Shopify's "open redirect" bounty class and is usable for phishing (e.g., presenting a fake Shopify login/consent page to steal merchant credentials, or chaining with OAuth flows that trust the exit-iframe path).

### Likelihood Explanation
Any anonymous party can construct the URL and only needs to get a merchant to click it (e.g., via a link, email, or embedded ad) — no secret, session, or privileged role is required, and it works against the default library configuration since the vulnerable check is `sanitizeRedirectUrl`'s built-in logic. It is fully reproducible with a single crafted GET request.

### Recommendation
In `sanitizeRedirectUrl`/`isSafe`, require that absolute redirect URLs' hostname match the app's own domain (`config.appUrl`) or a Shopify-owned domain (e.g., `*.myshopify.com`, `admin.shopify.com`), rejecting any external hostname instead of only checking protocol/format. Apply this before constructing the final `URL` used in `renderAppBridge`.

```typescript
  {config}: BasicParams,
```

```typescript
function isSafe(
  domain: string,
  redirectUrl: unknown,
  requireSSL: boolean | undefined = true,
): redirectUrl is string {
  if (typeof redirectUrl !== 'string') {
    return false;
  }

  if (
    FILE_URI_MATCH.test(redirectUrl) ||
    WHITESPACE_CHARACTER.test(redirectUrl)
  ) {
    return false;
  }

  let url: URL;

  try {
    url = new URL(redirectUrl, domain);
  } catch (_error) {
    return false;
  }

  if (INVALID_RELATIVE_URL.test(url.pathname)) {
    return false;
  }

  if (!VALID_PROTOCOLS.includes(url.protocol)) {
    return false;
  }

  if (requireSSL && url.protocol !== 'https:') {
    return false;
  }

  return true;
}
```

```typescript
export function sanitizeRedirectUrl<OptionsArg extends Options>(
  domain: string,
  redirectUrl: unknown,
  options: OptionsArg = {} as OptionsArg,
): SanitizedRedirectUrl<OptionsArg> {
  if (isSafe(domain, redirectUrl, options.requireSSL)) {
    return new URL(redirectUrl, domain) as SanitizedRedirectUrl<OptionsArg>;
  } else if (options.throwOnInvalid === false) {
    return undefined as SanitizedRedirectUrl<OptionsArg>;
  } else {
    throw new ShopifyError('Invalid URL. Refusing to redirect');
  }
}
```
