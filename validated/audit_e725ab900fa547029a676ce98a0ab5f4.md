### Title
Sandwichable spot-price Uniswap V3 quote with fixed 5% slippage tolerance enables value extraction from protocol-held PRC20 gas-token swaps - (File: `x/uexecutor/keeper/outbound.go`, `x/uexecutor/keeper/evm.go`, `x/uexecutor/keeper/execute_inbound_gas.go`, `x/uexecutor/keeper/execute_inbound_gas_and_payload.go`)

### Summary
The external report's bug class is a hard-coded, poorly calibrated percentage threshold (health/liquidation margin) applied against a value that can drift or be manipulated faster than the safety margin can react, letting the protocol pay out more than it should. Push Chain's own gas-token-to-native-token swap paths use the same *pattern*: they fetch a single-block, single-pool spot quote from a Uniswap V3 `QuoterV2` and apply a fixed `5%` slippage tolerance (`minPCOut = quote * 95 / 100`) with no TWAP or external price check, then immediately execute the swap in the same call.

### Finding Description
Every PRC20 auto-swap and gas-refund-with-swap path computes `minPCOut` the same way: [1](#0-0) 

```go
quote, quoteErr := k.getSwapQuoteForRefund(ctx, gasToken, fee, refundAmount)
minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
minPCOut.Div(minPCOut, big.NewInt(100))
resp, err := k.CallUniversalCoreRefundUnusedGas(ctx, gasToken, refundAmount, recipientAddr, true, fee, minPCOut)
```

`getSwapQuoteForRefund` and `GetSwapQuote` call `QuoterV2.quoteExactInputSingle` with `commit=false`, i.e. a live spot-price read of the on-chain Uniswap V3 pool at the moment of execution: [2](#0-1) 

The identical 5%-slippage/spot-quote pattern is repeated in the inbound GAS and GAS_AND_PAYLOAD paths: [3](#0-2)  and [4](#0-3) .

The chain-upgrade notes confirm this is an intentional, static design choice rather than a temporary default: [5](#0-4) 

Because the quote and the swap execution happen back-to-back within the same message-server call (there is no TWAP, no external price oracle cross-check, and no minimum liquidity/deviation guard), an unprivileged attacker who can influence transaction ordering in the block that contains a `MsgVoteOutbound` (the vote that triggers `applyGasRefund`) or a `MsgVoteInbound` (that triggers the GAS/GAS_AND_PAYLOAD auto-swap) can sandwich the underlying Uniswap V3 pool: push the pool price against the protocol immediately before the quote is read, let the protocol's swap execute at the manipulated spot price still within the fixed 5% band, then reverse the manipulation afterward, capturing the difference. All of this requires only ordinary unprivileged transaction submission on Push Chain plus ordinary DEX interaction — no malicious validator, no privileged actor, and no compromise of the honest-UV ballot-finalization logic is needed. The UV votes themselves are entirely honest and correct; the value leak occurs purely in the deterministic EVM-side swap execution that the core-validator module triggers.

This mirrors the report's root cause precisely: a fixed percentage safety margin (5% here, vs. 10%/30%/50% in the report) is checked against a value (spot AMM price vs. GLP collateral ratio) that an unprivileged party can move faster/further than the margin accounts for, letting protocol-controlled funds be extracted at an unfavorable rate.

### Impact Explanation
The PRC20 gas tokens being swapped in `applyGasRefund`, `CallPRC20DepositAutoSwap`/`gasAndPayloadDepositAutoSwap` are protocol/module-custodied assets (collected as relayer gas fees or bridged deposits), not attacker-owned prior to the swap. A successful sandwich siphons value out of these module-held funds into the attacker's LP/arb position, i.e., unauthorized drain of protocol-controlled funds via a corrupted swap-accounting outcome, matching the in-scope "corruption of ... gas fee accounting ... or canonical UniversalTx state" and "draining ... of protocol-controlled funds" impact categories.

### Likelihood Explanation
Likelihood depends on the liquidity depth of the specific PRC20/WPC Uniswap V3 pool and whether MEV/front-running is economically viable on Push Chain's block-production/mempool model. Because the quote-then-swap sequence is entirely deterministic and repeats on every inbound GAS/GAS_AND_PAYLOAD deposit and every outbound gas refund, the attack surface is broad and repeatable; the fixed 5% band is generous enough to profit from on shallow pools.

### Recommendation
Replace the single-block spot quote with a TWAP-based or otherwise manipulation-resistant price source for computing `minPCOut`, and/or tighten and dynamically calibrate the slippage tolerance based on observed pool depth/volatility rather than a hard-coded 5% constant. Consider adding a maximum quote-to-swap block-distance check, or executing the swap via a mechanism that is resistant to same-block manipulation (e.g., commit-reveal, or routing through a price oracle independent of the swapped pool).

### Proof of Concept
1. Attacker identifies a shallow PRC20/WPC Uniswap V3 pool used by `UniversalCore` for gas-token swaps.
2. Attacker triggers (or waits for) an inbound GAS/GAS_AND_PAYLOAD deposit or a `MsgVoteOutbound` that will hit `applyGasRefund`/`gasAndPayloadDepositAutoSwap`.
3. In the same block, attacker front-runs with a large swap that shifts the pool's spot price adversely for the protocol's soon-to-execute quote (`GetSwapQuote`), then back-runs to restore price after the protocol's `depositPRC20WithAutoSwap`/`refundUnusedGas` swap executes at the manipulated rate (still within the fixed 5% band, so `minPCOut` does not revert it).
4. Attacker closes out the sandwich, netting the difference extracted from the protocol-held PRC20 tokens. [6](#0-5)

// applyGasRefund computes the excess gas (gasFee - gasFeeUsed) and, if positive,
// calls UniversalCore refundUnusedGas. The result is recorded in outbound.PcRefundExecution.
// It is called for both successful and failed outbounds — gas is consumed on the
// external chain regardless of execution outcome.
func (k Keeper) applyGasRefund(ctx sdk.Context, outbound *types.OutboundTx, obs *types.OutboundObservation) {
	if obs.GasFeeUsed == "" || outbound.GasFee == "" || outbound.GasToken == "" {
		return
	}

	gasFee := new(big.Int)
	if _, ok := gasFee.SetString(outbound.GasFee, 10); !ok {
		return
	}

	gasFeeUsed := new(big.Int)
	if _, ok := gasFeeUsed.SetString(obs.GasFeeUsed, 10); !ok {
		return
	}

	// No excess gas to refund
	if gasFee.Cmp(gasFeeUsed) <= 0 {
		return
	}

	refundAmount := new(big.Int).Sub(gasFee, gasFeeUsed)
	gasToken := common.HexToAddress(outbound.GasToken)

	// Refund recipient: prefer fund_recipient in revert_instructions, fall back to sender
	refundRecipient := outbound.Sender
	if outbound.RevertInstructions != nil && outbound.RevertInstructions.FundRecipient != "" {
		refundRecipient = outbound.RevertInstructions.FundRecipient
	}
	recipientAddr := common.HexToAddress(refundRecipient)

	refundPcTx := &types.PCTx{
		Sender:      outbound.Sender,
		BlockHeight: uint64(ctx.BlockHeight()),
	}

	// Step 1: try refund with swap (gasToken → PC native)
	fee, swapErr := k.GetDefaultFeeTierForToken(ctx, gasToken)
	var swapFallbackReason string

	if swapErr == nil {
		quote, quoteErr := k.getSwapQuoteForRefund(ctx, gasToken, fee, refundAmount)
		if quoteErr == nil {
			minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
			minPCOut.Div(minPCOut, big.NewInt(100))

			resp, err := k.CallUniversalCoreRefundUnusedGas(ctx, gasToken, refundAmount, recipientAddr, true, fee, minPCOut)
			if err == nil {
				refundPcTx.TxHash = resp.Hash
				refundPcTx.GasUsed = resp.GasUsed
				refundPcTx.Status = "SUCCESS"
				outbound.PcRefundExecution = refundPcTx
				return
			}
			swapFallbackReason = fmt.Sprintf("swap refund failed: %s", err.Error())
		} else {
			swapFallbackReason = fmt.Sprintf("quote fetch failed: %s", quoteErr.Error())
		}
	} else {
		swapFallbackReason = fmt.Sprintf("fee tier fetch failed: %s", swapErr.Error())
	}

	// Step 2: fallback — refund without swap (deposit PRC20 directly to recipient)
	ctx.Logger().Error("applyGasRefund: swap refund failed, falling back to no-swap",
		"outbound_id", outbound.Id,
		"reason", swapFallbackReason,
	)

	resp, err := k.CallUniversalCoreRefundUnusedGas(ctx, gasToken, refundAmount, recipientAddr, false, big.NewInt(0), big.NewInt(0))
	if err != nil {
		refundPcTx.Status = "FAILED"
		refundPcTx.ErrorMsg = err.Error()
	} else {
		refundPcTx.TxHash = resp.Hash
		refundPcTx.GasUsed = resp.GasUsed
		refundPcTx.Status = "SUCCESS"
	}

	outbound.PcRefundExecution = refundPcTx
	outbound.RefundSwapError = swapFallbackReason
}

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}
