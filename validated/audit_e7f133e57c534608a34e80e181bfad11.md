### Title
Public Free Bandwidth Pool Can Be Fully Drained by Any Unprivileged Account, Denying the Shared Subsidy to All Users - (File: chainbase/src/main/java/org/tron/core/db/BandwidthProcessor.java)

### Summary
java-tron maintains a single, chain-wide "public free bandwidth" pool (`PUBLIC_NET_LIMIT`/`PUBLIC_NET_USAGE`) that subsidizes free-tier bandwidth consumption for every account on the network. Just like the Drips `commonFunds`, this pool is a shared, unrestricted resource: any anonymous account that broadcasts ordinary transactions can consume it with no throttling, whitelist, or per-account cap on how much of the *global* quota a single caller can burn before others get a chance.

### Finding Description
`BandwidthProcessor.useFreeNet()` first checks the caller's per-account `FREE_NET_LIMIT`, and if that passes, checks and updates the network-wide public quota: [1](#0-0) 

Every account has an independent per-account free-net quota (`freeNetLimit`), but the `publicNetLimit`/`publicNetUsage` counters are global singletons in `DynamicPropertiesStore`: [2](#0-1) 

Because `useFreeNet()` only rejects a request when the *global* pool is already exhausted (`bytes > (publicNetLimit - newPublicNetUsage)`), and there is no per-caller rate limit, weight, stake requirement, or reputation check on how much of the shared pool one address may consume, a single unprivileged actor holding many addresses (or one address issuing many minimal-cost, zero-fee transactions) can repeatedly call `useFreeNet` and consume the entire `publicNetLimit` for the current window well before its own per-account `freeNetLimit` is exhausted. This exactly mirrors the reported bug class: a commons ("commonFunds"/public subsidy) that anyone can burn because "there is no restriction on requesting" it.

### Impact Explanation
Once `publicNetUsage` reaches `publicNetLimit`, `useFreeNet` returns `false` for every account network-wide until the time window rolls over (`getPublicNetTime`), even for accounts that still have unused personal `freeNetLimit`. This is a protocol-level denial-of-service against the shared free-bandwidth subsidy: an attacker who wants to grief low-balance users (who rely on free bandwidth because they cannot pay net fees) can force their subsequent free transfers to fail bandwidth validation, since the public pool is depleted. This is reachable purely by broadcasting normal `TransferContract`/`TransferAssetContract` transactions — no privileged role, leaked key, or malicious peer is required.

### Likelihood Explanation
The public net pool is a small, chain-parameter-bounded quota (`PublicNetLimit`), refreshed roughly once every fixed period, so a single account (or a modest set of cheaply-created accounts) issuing minimal, essentially free transactions can exhaust it well within the window. This requires no special privileges — only the ability to broadcast transactions, which is available to anyone.

### Recommendation
Introduce a per-account cap on how much of the global `publicNetLimit` a single address can consume per window (e.g., proportional throttling or a max-share-per-account rule), rather than allowing the pool to be depleted purely on a first-come-first-served basis with no per-caller ceiling.

### Proof of Concept
1. Observe current `PublicNetLimit`/`PublicNetUsage` via `DynamicPropertiesStore.getPublicNetLimit/getPublicNetUsage` (also exposed through `Wallet.getAccountNet`/`getAccountResource`, see [3](#0-2) ).
2. From one or a handful of freshly-created, unfunded/low-balance accounts (each still under their own `freeNetLimit`), repeatedly broadcast minimal-size `TransferContract` transactions.
3. Each accepted transaction increments the global `publicNetUsage` counter via `useFreeNet` at [4](#0-3)  until `publicNetUsage` reaches `publicNetLimit`.
4. After exhaustion, any other unrelated account attempting a free transfer — even one with untouched personal `freeNetLimit` — is rejected at the `bytes > (publicNetLimit - newPublicNetUsage)` check, confirming the shared subsidy has been fully consumed by the attacker until the next refresh window.

  private boolean useFreeNet(AccountCapsule accountCapsule, long bytes, long now) {

    long freeNetLimit = chainBaseManager.getDynamicPropertiesStore().getFreeNetLimit();
    long freeNetUsage = accountCapsule.getFreeNetUsage();
    long latestConsumeFreeTime = accountCapsule.getLatestConsumeFreeTime();
    long newFreeNetUsage = increase(freeNetUsage, 0, latestConsumeFreeTime, now);

    if (bytes > (freeNetLimit - newFreeNetUsage)) {
      logger.debug("Free net usage is running out."
              + " Bytes: {}, freeNetLimit: {}, newFreeNetUsage: {}.",
          bytes, freeNetLimit, newFreeNetUsage);
      return false;
    }

    long publicNetLimit = chainBaseManager.getDynamicPropertiesStore().getPublicNetLimit();
    long publicNetUsage = chainBaseManager.getDynamicPropertiesStore().getPublicNetUsage();
    long publicNetTime = chainBaseManager.getDynamicPropertiesStore().getPublicNetTime();

    long newPublicNetUsage = increase(publicNetUsage, 0, publicNetTime, now);

    if (bytes > (publicNetLimit - newPublicNetUsage)) {
      logger.debug("Free public net usage is running out."
              + " Bytes: {}, publicNetLimit: {}, newPublicNetUsage: {}.",
          bytes, publicNetLimit, newPublicNetUsage);
      return false;
    }

    latestConsumeFreeTime = now;
    long latestOperationTime = chainBaseManager.getHeadBlockTimeStamp();
    publicNetTime = now;
    newFreeNetUsage = increase(newFreeNetUsage, bytes, latestConsumeFreeTime, now);
    newPublicNetUsage = increase(newPublicNetUsage, bytes, publicNetTime, now);
    accountCapsule.setFreeNetUsage(newFreeNetUsage);
    accountCapsule.setLatestConsumeFreeTime(latestConsumeFreeTime);
    accountCapsule.setLatestOperationTime(latestOperationTime);

    chainBaseManager.getDynamicPropertiesStore().savePublicNetUsage(newPublicNetUsage);
    chainBaseManager.getDynamicPropertiesStore().savePublicNetTime(publicNetTime);
    chainBaseManager.getAccountStore().put(accountCapsule.createDbKey(), accountCapsule);
    return true;

  public void savePublicNetUsage(long publicNetUsage) {
    this.put(DynamicResourceProperties.PUBLIC_NET_USAGE,
        new BytesCapsule(ByteArray.fromLong(publicNetUsage)));
  }

  public long getPublicNetUsage() {
    return Optional.ofNullable(getUnchecked(DynamicResourceProperties.PUBLIC_NET_USAGE))
        .map(BytesCapsule::getData)
        .map(ByteArray::toLong)
