## Analysis

The upstream report's bug class is "price-dependent value transfer computed without protecting the user from adverse price movement between price discovery and execution." Searching Push Chain's `x/uexecutor` module, the same anti-pattern reappears in the auto-swap paths used for **GAS** and **GAS_AND_PAYLOAD** inbound execution and for the **excess-gas refund** path on outbound finalization — except here the "protection" (`minPCOut`) is derived from a spot AMM quote taken from the very same, single-transaction execution that then consumes that quote, so it offers no real defense against a same-block sandwich.

### Root cause
`GetSwapQuote` calls `QuoterV2.quoteExactInputSingle` (a spot-price read of the live Uniswap V3 pool) immediately before the real swap is submitted: [1](#0-0) 

The 5% tolerance is then computed purely as a percentage of that same spot quote and passed straight into the swap call, all inside one keeper execution with no external reference price or TWAP: [2](#0-1) [3](#0-2) [4](#0-3) 

`CallPRC20DepositAutoSwap` forwards `minPCOut` to the on-chain `depositPRC20WithAutoSwap` call, and `deadline` is hard-coded to `0` ("contract uses its default"), so there is no meaningful bound on how much the on-chain price can be pushed before the swap executes: [5](#0-4) 

### Why this matters
Because quote-fetch and swap-execution both read the same pool state within the same block/transaction (triggered deterministically when the finalizing `MsgVoteInbound`/`MsgVoteOutbound` lands), an unprivileged attacker who observes the finalizing vote in the mempool can sandwich it: swap into the PRC20/WPC pool to depress price, let the module's quote+swap execute against the manipulated pool (the "5% slippage" floor is computed from the already-manipulated price, so it never triggers a revert), then swap back out, extracting value that should have gone to the user's gas top-up or gas refund. This is functionally identical to the reported `burn()` issue — value paid out is computed from a manipulable "market price" with no independent, time-resistant floor — reachable by any ordinary unprivileged actor with capital, requiring no validator, relayer, or admin compromise.

### Title
On-chain spot-quote-derived `minPCOut` slippage floor is sandwichable, allowing value extraction from GAS/GAS_AND_PAYLOAD deposits and gas refunds - (File: `x/uexecutor/keeper/evm.go`, `x/uexecutor/keeper/execute_inbound_gas.go`, `x/uexecutor/keeper/execute_inbound_gas_and_payload.go`, `x/uexecutor/keeper/outbound.go`)

### Summary
`GetSwapQuote` reads a spot price from the same Uniswap V3 pool that `CallPRC20DepositAutoSwap`/`CallUniversalCoreRefundUnusedGas` subsequently swap against, in the same execution. The resulting `minPCOut = quote * 95%` is not an independent slippage guarantee — it is 95% of whatever price an attacker has already manipulated the pool to, at the moment the finalizing vote transaction executes.

### Finding Description
`ExecuteInboundGas` (GAS route), `gasAndPayloadDepositAutoSwap` (GAS_AND_PAYLOAD route), and `applyGasRefund` (outbound excess-gas refund) all call `k.GetSwapQuote(...)` to fetch a spot quote from `QuoterV2.quoteExactInputSingle`, compute `minPCOut = quote * 95 / 100`, and immediately pass that bound into the same-transaction swap call (`CallPRC20DepositAutoSwap` / `CallUniversalCoreRefundUnusedGas`). Both the quote and the real swap read the same on-chain pool reserves at the same block, so any pre-manipulation of the pool (e.g., via a large PRC20⇄WPC swap or flash loan immediately before the module's finalizing transaction) is baked into both the "protective" bound and the actual execution price. The `deadline` parameter is also hard-coded to `0`, providing no additional execution-time constraint.

### Impact Explanation
Impact is medium: any user whose inbound GAS/GAS_AND_PAYLOAD deposit is auto-swapped to PC, or whose outbound leaves excess gas fee eligible for refund, can receive a systematically worse conversion rate than fair market price. Value is transferred from the depositor/protocol to the sandwiching attacker — an unauthorized, unprivileged extraction of user/protocol-controlled value via the universal execution flow.

### Likelihood Explanation
Likelihood is medium-to-high: the finalizing vote (last UV's `MsgVoteInbound`/`MsgVoteOutbound`) is publicly visible in the mempool before inclusion, and executing a sandwich around it only requires ordinary swap capability against the same pool — no validator, relayer, or admin privileges are needed. Low-liquidity PRC20/WPC pools make manipulation cheaper.

### Recommendation
Do not derive the slippage floor from a spot quote taken in the same transaction as the protected swap. Use a time-weighted average price (TWAP) from the pool, an external/registry-configured reference price with a bounded deviation check, or require the quote to be sourced from a block prior to execution with a maximum staleness/deviation guard. Additionally, set a real `deadline` rather than `0`, and consider capping per-swap notional size or requiring minimum pool liquidity checks before routing through auto-swap.

### Proof of Concept
1. Attacker observes a `MsgVoteInbound` (GAS type) in the mempool that will finalize a ballot and trigger `ExecuteInboundGas`.
2. Attacker front-runs with a large swap in the PRC20/WPC pool used by `GetUniversalCoreQuoterAddress`/`GetUniversalCoreWPCAddress`, depressing the PRC20→WPC price.
3. The finalizing transaction executes: `GetSwapQuote` reads the manipulated price, `minPCOut` is computed as 95% of that already-bad price, and `CallPRC20DepositAutoSwap` swaps at the same manipulated price — the check passes trivially.
4. Attacker back-runs to restore the pool price and pockets the spread, while the depositing user receives less PC than fair value for their bridged gas token.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}
