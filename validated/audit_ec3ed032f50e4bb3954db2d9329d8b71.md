### Title
Class Manager exposes cached compiled-class data before the declaring transaction is committed to state - ([File: crates/apollo_rpc_execution/src/state_reader.rs])

### Summary
`ExecutionStateReader::get_compiled_class_hash_v2` returns data straight from the `ClassManager`'s cache without verifying that the corresponding class has actually been committed to the sequencer's canonical state, unlike its sibling method `get_compiled_class` which explicitly performs this check.

### Finding Description
The class manager persists a Sierra class and its compiled CASM as soon as a `Declare` transaction reaches the gateway, *before* stateful validation, mempool admission, or block inclusion occur: [1](#0-0) 

`ClassManager::add_class` compiles and stores the class unconditionally and caches the executable class hash as an "existence marker", independent of whether the originating `Declare` transaction is ever admitted to the mempool or included in a block: [2](#0-1) [3](#0-2) 

Consumers of this cached data are supposed to gate access on whether the class is actually part of committed state. `ExecutionStateReader::get_compiled_class` (used by RPC execution paths such as `estimate_fee`/`simulate_transactions`) does exactly that — it calls `is_contract_class_declared` against on-disk committed state before trusting the class-manager-provided CASM: [4](#0-3) 

However, the sibling method `get_compiled_class_hash_v2` on the same reader — implementing the `StateReader` trait used by Blockifier during transaction execution/validation (including the declare-once check documented in `CachedState::update_initial_values_of_write_only_access`, "Compiled class hash: verify the class is not declared through `get_compiled_class`") — skips this committed-state check entirely and returns whatever the class manager cache has: [5](#0-4) [6](#0-5) 

This is the direct analog of the Liferay bug class: an artifact (uploaded file / compiled class) is made retrievable as soon as it is stored by the backing component, rather than only after the associated "object entry" (declare transaction / form submission) has been confirmed/committed. Here, any attacker who submits a syntactically valid `Declare` transaction with a garbage signature/insufficient fee (which fails gateway stateful validation and is never admitted to the mempool or committed to state) still causes `ClassManager::add_class` to compile and permanently cache the class and its `executable_class_hash_v2`. Any subsequent state read through `get_compiled_class_hash_v2` (e.g. during another node's/attempt's declare-once check) will see that hash as if the class were already declared, even though it is absent from the canonical committed state.

### Impact Explanation
Because different sequencer nodes' local `ClassManager` caches can diverge (a node that received the failed/never-committed declare will have the class cached; a node that never saw it will not), a `get_compiled_class_hash_v2` result that trusts the cache instead of committed state can produce different outcomes for the same block/transaction across honest nodes. In the context of the declare-once enforcement (`assert_not_zero`/`prev_value=0` checks in `execute_declare_transaction`), this can cause honest-node execution divergence when re-executing or validating declare transactions, since one node's cache may report a class hash as "already known" while another correctly reports it absent from state. This falls under the "honest-node divergence" impact category required by the assessment rules.

### Likelihood Explanation
Reaching this path only requires submitting a single `Declare` transaction from an unprivileged account — no special privileges, staking, or node compromise is needed. The transaction does not even need to succeed: since `ClassManager::add_class` runs and caches the compiled class *before* stateful validation completes, a transaction that is guaranteed to be rejected (bad signature, insufficient fee, wrong nonce) is sufficient to poison the local cache with an executable class hash that never becomes part of committed state.

### Recommendation
Add the same committed-state verification used in `get_compiled_class` to `get_compiled_class_hash_v2` in `crates/apollo_rpc_execution/src/state_reader.rs` — i.e., confirm via `is_contract_class_declared` (or the storage-backed state reader) that the class hash is present in the canonical committed state before trusting the value returned by the class manager cache. More broadly, ensure the class manager's caching layer (`crates/apollo_class_manager/src/class_manager.rs` / `class_storage.rs`) is never treated as a proxy for "declared in committed state" without cross-checking actual state.

### Proof of Concept
1. An attacker submits a `Declare` transaction (any valid Sierra class) with a nonce/fee/signature guaranteed to fail stateful validation in the gateway.
2. `GenericGateway::add_tx_inner` calls `convert_rpc_tx_to_internal_and_executable_txs`, which internally invokes `ClassManager::add_class`, compiling and permanently caching the class and its `executable_class_hash_v2` before stateful validation runs: [7](#0-6) 
3. Stateful validation subsequently rejects the transaction; it is never sent to the mempool and never committed to state.
4. A later call path (e.g., re-execution/validation using `ExecutionStateReader::get_compiled_class_hash_v2`) queries the class hash and receives a non-empty result from the class-manager cache, despite the class never being part of committed state — producing state/behavior inconsistent with nodes whose cache does not contain the artifact.

    #[instrument(skip(self, class), ret, err)]
    pub async fn add_class(&mut self, class: RawClass) -> ClassManagerResult<ClassHashes> {
        let sierra_class = SierraContractClass::try_from(&class)?;
        let class_hash = sierra_class.calculate_class_hash();
        if let Ok(Some(executable_class_hash_v2)) =
            self.classes.get_executable_class_hash_v2(class_hash)
        {
            // Class already exists.
            return Ok(ClassHashes { class_hash, executable_class_hash_v2 });
        }

        let compilation_start_time = Instant::now();
        let (raw_executable_class, executable_class_hash_v2) =
            self.compiler.compile(class.clone()).await.map_err(|err| match err {
                SierraCompilerClientError::SierraCompilerError(error) => {
                    ClassManagerError::SierraCompiler { class_hash, error }
                }
                SierraCompilerClientError::ClientError(error) => {
                    ClassManagerError::Client(error.to_string())
                }
            })?;
        debug!(
            %class_hash,
            compiled_class_hash = %executable_class_hash_v2,
            compilation_elapsed_ms = compilation_start_time.elapsed().as_millis(),
            class_size_bytes =
                class.size().map_or("Failed to get class size".to_owned(), |size| size.to_string()),
            casm_size_bytes =
                raw_executable_class.size().map_or("Failed to get casm size".to_owned(), |size| size.to_string()),
            "Finished compiling class."
        );

        self.validate_class_length(&raw_executable_class)?;
        Self::validate_class_version(&sierra_class)?;
        self.classes.set_class(
            class_hash,
            class,
            executable_class_hash_v2,
            raw_executable_class,
        )?;

        let class_hashes = ClassHashes { class_hash, executable_class_hash_v2 };
        Ok(class_hashes)
    }

    #[instrument(skip(self, class, executable_class), level = "debug", ret, err)]
    fn set_class(
        &mut self,
        class_id: ClassId,
        class: RawClass,
        executable_class_hash_v2: ExecutableClassHash,
        executable_class: RawExecutableClass,
    ) -> Result<(), Self::Error> {
        if self.class_cached(class_id) {
            return Ok(());
        }

        self.storage.set_class(
            class_id,
            class.clone(),
            executable_class_hash_v2,
            executable_class.clone(),
        )?;

        increment_n_classes(CairoClassType::Regular);
        record_class_size(ClassObjectType::Sierra, &class);
        record_class_size(ClassObjectType::Casm, &executable_class);

        // Cache the class.
        // Done after successfully writing to storage as an optimization;
        // does not require atomicity.
        self.classes.set(class_id, class);
        self.executable_classes.set(class_id, executable_class);
        // Cache the executable class hash last; acts as an existence marker.
        self.executable_class_hashes_v2.set(class_id, executable_class_hash_v2);

        Ok(())
    }

    fn get_compiled_class_hash_v2(
        &self,
        class_hash: ClassHash,
        _compiled_class: &RunnableCompiledClass,
    ) -> StateResult<CompiledClassHash> {
        let maybe_hash =
            if let Some((class_manager_client, run_time_handle)) = &self.class_manager_handle {
                // First, try getting from class manager if available.
                run_time_handle
                    .block_on(class_manager_client.get_executable_class_hash_v2(class_hash))
                    .map_err(|e| StateError::StateReadError(e.to_string()))?
            } else {
                // Fall back to reading from storage.
                self.storage_reader
                    .begin_ro_txn()
                    .map_err(storage_err_to_state_err)?
                    .get_executable_class_hash_v2(&class_hash)
                    .map_err(storage_err_to_state_err)?
            };

        maybe_hash.ok_or(StateError::MissingCompiledClassHashV2(class_hash))
    }
