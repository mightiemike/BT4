### Title
Uniswap V3 spot-quote used as the sole slippage bound for auto-swaps lets an unprivileged actor sandwich every inbound/gas-refund swap - (File: x/uexecutor/keeper/execute_inbound_gas.go, x/uexecutor/keeper/execute_inbound_gas_and_payload.go, x/uexecutor/keeper/outbound.go, x/uexecutor/keeper/evm.go)

### Summary
The external report's class of bug is "a value that can be atomically skewed by an unprivileged actor is used, uncorrected, as the sole input to a protocol threshold/guard." Push Chain's analog is not a governance quorum (the UV ballot quorum in `x/uvalidator`/`x/uexecutor` is keyed off the admin-managed, staking-derived `GetEligibleVoters` set, which an unprivileged external attacker cannot skew — see `x/uexecutor/keeper/voting.go`). The real analog is the on-chain Uniswap V3 `QuoterV2.quoteExactInputSingle` spot quote used as the *only* source of truth for the `minPCOut` slippage floor on every PRC20→PC auto-swap performed during inbound execution and gas refunds.

### Finding Description
`GetSwapQuote` in [1](#0-0)  calls the Uniswap V3 `QuoterV2.quoteExactInputSingle` view function to price a PRC20→WPC swap. This spot quote is then used, unmodified other than a flat 5% haircut, to compute `minPCOut`: [2](#0-1) 

The same pattern repeats in the `GAS_AND_PAYLOAD` inbound path (`gasAndPayloadDepositAutoSwap`) and in the outbound gas-refund swap path (`applyGasRefund` / `getSwapQuoteForRefund`): [3](#0-2) [4](#0-3) 

In all three cases `minPCOut = quote * 95 / 100`, where `quote` is read from the live on-chain AMM pool state at execution time, with no comparison against an independent price reference (e.g., the chain-meta gas-price oracle, a TWAP, or an admin/registry-configured max deviation). Because `Enabled`/liquidity for the Uniswap V3 pool backing each PRC20 is otherwise permissionless to trade against, any unprivileged holder of the PRC20 or WPC can move the pool's spot price with an ordinary swap transaction placed in a prior block (or earlier in the same block, since Push Chain's mempool ordering is not MEV-protected) immediately before a pending inbound/outbound finalizes. Because the quote and the swap execution both read the *already-manipulated* pool state, the 5% band does not protect against attacker-induced price impact — it only guards against normal quote/execution slippage. The attacker then reverses the price-moving trade after the protocol's auto-swap lands, extracting the difference between the fair price and the manipulated execution price at the expense of the depositor/refund recipient.

### Impact Explanation
This is a real, unprivileged-attacker-reachable value-extraction vector against `x/uexecutor`'s universal execution flow: every `GAS`/`GAS_AND_PAYLOAD` inbound deposit-auto-swap and every outbound excess-gas refund swap can be sandwiched, silently reducing the PC amount credited to end users while transferring that value to the attacker. This falls within "corruption of PRC20 or native asset accounting" / unauthorized value drain from user-controlled funds in the universal execution path, since the protocol treats the manipulated quote as authoritative with no external price check.

### Likelihood Explanation
Likelihood is high wherever the underlying Uniswap V3 pool has thin liquidity relative to the swap size, and the attack requires no privileged role (no validator, admin, or TSS access) — only capital to trade against the PRC20/WPC pool, which is by design open to any user. It is bounded in practice by pool depth and MEV infrastructure availability on Push Chain, but the flat 5% band is a fixed, attacker-known parameter, making the maximum extractable value per transaction predictable and choosable by the attacker up to that bound.

### Recommendation
- Do not rely solely on a live spot quote fetched from the same pool being swapped against. Cross-check the quote against an independent reference (chain-meta oracle price, a TWAP over multiple blocks, or an admin-configured max/min price band per token) before accepting `minPCOut`.
- Consider tightening or making the slippage tolerance configurable per token via `uregistry` `TokenConfig`, and cap the maximum single-block price deviation allowed before falling back to the no-swap path (already present as a fallback for other error conditions in `applyGasRefund`).
- If a TWAP is not available, consider deferring pool-price-based swaps to a batched/limit-oriented mechanism, or use the chain-meta oracle price as the primary bound and the spot quote only as a secondary safety check.

### Proof of Concept
1. Observe a pending inbound `GAS_AND_PAYLOAD`/`GAS` transaction (or outbound with excess gas) for a PRC20 token `T` about to be executed by `ExecuteInboundGas`/`ExecuteInboundGasAndPayload`/`applyGasRefund`.
2. Before the finalizing vote transaction lands, submit a large swap on the same Uniswap V3 pool (`T`→WPC) to depress `T`'s price against WPC.
3. When the protocol's `GetSwapQuote` + `CallPRC20DepositAutoSwap` (or `CallUniversalCoreRefundUnusedGas` with `withSwap=true`) executes, it reads the depressed spot price, computes `minPCOut` off that depressed price, and executes the swap at the bad price — well within the "protected" 5% band relative to itself.
4. After the protocol's swap lands, submit a reverse swap (WPC→T) to restore the price, capturing the price-impact spread as profit while the depositor/refund recipient receives less PC than fair value.

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}
