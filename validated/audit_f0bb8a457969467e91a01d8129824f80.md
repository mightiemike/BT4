### Title
Missing "class declared" validation in Starknet OS `replace_class` syscall causes honest-node state divergence from Blockifier - (File: `crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo`)

### Summary
The Starknet OS's Cairo re-execution implementation of the `replace_class` syscall writes an arbitrary caller-supplied `class_hash` into a contract's state entry without verifying that the class is actually declared (or, for Cairo1 contracts, that it is a valid Cairo1 class). The production `blockifier` execution engine, which computes the actual committed state during block building, performs this validation and rejects the transaction when it fails. Because any unprivileged contract can invoke `replace_class` on itself via a normal `__execute__` call, a transaction crafted to replace a contract's class with an undeclared (or version-mismatched) class hash is rejected/reverted by `blockifier` but is accepted by the OS's own re-execution of the same call, producing two different state transitions for the same transaction.

### Finding Description
`blockifier`'s Cairo1 syscall handler enforces the invariant before mutating storage: [1](#0-0) 

and the Cairo0/deprecated handler enforces the "declared" check as well: [2](#0-1) 

In contrast, the corresponding logic inside the Starknet OS Cairo program (`apollo_starknet_os_program`, executed during SNOS re-execution/proving) skips this check entirely and even carries an explicit TODO acknowledging the gap: [3](#0-2) 

The deprecated (Cairo0) OS execution path has the identical omission, with no declared-class check at all before updating `contract_state_changes`: [4](#0-3) 

Any account/contract can reach `replace_class` unprivileged simply by invoking the syscall on itself during `__execute__`, as demonstrated in the feature-contract test helper: [5](#0-4) 

Because the OS independently re-executes transactions (rather than blindly trusting a pre-computed diff) as part of proving the block, a divergence between what `blockifier` accepts/produces and what the OS Cairo program accepts/produces for the exact same transaction means the OS can compute a different post-state (and therefore a different committed root) than the one actually produced by the sequencer during real block execution.

### Impact Explanation
This is a state-transition-validity mismatch between the two independent implementations of the same syscall (`blockifier` vs. the Starknet OS Cairo program) that are both reachable from a single unprivileged transaction. `blockifier` will reject (revert) a `replace_class` call using an undeclared class hash or, for Cairo1 contracts, a Cairo0 class hash, while the OS silently accepts it and writes the raw class hash into `contract_state_changes`. This is exactly the "honest-node divergence" / "wrong committed root" impact class: the block actually produced by the sequencer (via blockifier) and the state transition re-derived/verified by the Starknet OS for the same transaction can disagree, undermining the soundness of the OS's re-execution proof relative to the real state the network committed to.

### Likelihood Explanation
The syscall is reachable by any contract with a single `__execute__` invocation - no special privileges, sequencer/operator role, or unusual configuration are required. The only requirement is supplying a `class_hash` value that is undeclared or (in the Cairo1 case) a Cairo0 class hash, both trivial for any user to construct.

### Recommendation
Add the same validation the `blockifier` performs to both OS implementations before writing the new class hash into `contract_state_changes`:
1. In `syscall_impls.cairo::execute_replace_class`, verify the target `class_hash` corresponds to a declared class (resolve it in `contract_class_changes`/`compiled_class_hash` lookups) and enforce the same "Cairo1-only" restriction implemented in `syscall_base.rs::replace_class`.
2. In `deprecated_execute_syscalls.cairo::execute_replace_class`, add the equivalent declared-class check present in `hint_processor.rs::replace_class`.
3. Add a Starknet-OS-level test (e.g., in `starknet_os_flow_tests`) that replays a transaction rejected by `blockifier` due to an undeclared/mismatched `replace_class` target and asserts the OS also fails/reverts identically.

### Proof of Concept
1. Deploy a Cairo1 contract `A` that calls `replace_class_syscall(undeclared_class_hash)` from its `__execute__`.
2. Submit an invoke transaction targeting `A`. `blockifier` rejects this with `"is not declared"` (as shown by the existing test `undeclared_class_hash` in `crates/blockifier/src/execution/syscalls/syscall_tests/replace_class.rs:17-29`), so no state change to `A`'s class hash occurs in the real block.
3. Independently feed the same transaction (calldata/trace) through the Starknet OS's `execute_replace_class` in `syscall_impls.cairo`: because it lacks the "declared class" check (see the `TODO(Yoni, 1/1/2026)` comment at line 902), it accepts the replacement and updates `contract_state_changes` for `A` with the undeclared class hash — a state transition that never actually happened in the real block, demonstrating the divergence.

    pub fn replace_class(&mut self, class_hash: ClassHash) -> SyscallResult<()> {
        // Ensure the class is declared (by reading it), and of type V1.
        let compiled_class = self.state.get_compiled_class(class_hash)?;

        if !is_cairo1(&compiled_class) {
            return Err(SyscallExecutionError::ForbiddenClassReplacement { class_hash });
        }
        self.state.set_class_hash_at(self.call.storage_address, class_hash)?;
        Ok(())
    }

func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,

    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];
