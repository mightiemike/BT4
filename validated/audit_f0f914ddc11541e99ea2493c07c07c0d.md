### Title
Hardcoded 5% slippage tolerance on module-driven Uniswap V3 auto-swaps enables sandwich attacks against GAS/GAS_AND_PAYLOAD deposits and gas refunds - (File: x/uexecutor/keeper/evm.go, execute_inbound_gas.go, execute_inbound_gas_and_payload.go, outbound.go)

### Summary
The GAS and GAS_AND_PAYLOAD inbound routes, and the excess-gas-refund path, protect their internal Uniswap V3 `depositPRC20WithAutoSwap` / `refundUnusedGas` swaps with a fixed `minPCOut = quote * 95 / 100` computed from a freshly-fetched `QuoterV2` quote [1](#0-0) . Because the quote is fetched from the live on-chain WPC/PRC20 pool at the moment the finalizing `MsgVoteInbound` (or outbound-vote) transaction is processed, an unprivileged attacker who can influence transaction ordering within that block (e.g. by outbidding on gas price/priority) can move the pool price before the module's quote call executes, causing the swap to legitimately land inside the 5%-tolerance band while still being economically unfavorable to the depositing user — a standard AMM sandwich, just capped at 5% loss instead of unbounded.

### Finding Description
`GetSwapQuote` performs a non-committing `CallEVM` to `QuoterV2.quoteExactInputSingle` immediately before the module issues the real swap via `CallPRC20DepositAutoSwap` / `CallUniversalCoreRefundUnusedGas` (`DerivedEVMCall`, `commit=true`) [2](#0-1) . Both calls happen back-to-back inside a single keeper function invoked synchronously from `ExecuteInboundGas`, which itself is dispatched from `VoteInbound` when the last vote finalizes the inbound ballot [3](#0-2) . `VoteInbound` runs as ordinary `DeliverTx` processing of a `MsgVoteInbound` transaction, which is broadcast like any other transaction and is visible to observers before it lands in a block (its ballot key is derivable from the corresponding public on-chain gateway event, and prior votes accumulate on-chain — votes from 2 of 3 validators are readable before the quorum-completing vote is submitted). An unprivileged external actor can therefore predict the block in which the swap will fire and place ordinary EVM transactions (own gas price/priority) around the finalizing `MsgVoteInbound`/`MsgVoteOutbound` tx to move the WPC/PRC20 Uniswap V3 pool price, then reverse it after the module's swap executes — the classic sandwich pattern. Because the module always accepts amounts within a fixed 5% band regardless of the pool's actual depth, deposits routed through thin pools can be sandwiched for close to the full 5% on every GAS/GAS_AND_PAYLOAD deposit, and on every gas-fee refund via `applyGasRefund` [4](#0-3) , and via `gasAndPayloadDepositAutoSwap` [5](#0-4) .

This is the direct Push Chain analog of the reported bug class: the C4 finding is "no slippage control at all"; here the mitigation exists but is a fixed percentage disconnected from pool liquidity/depth, so it only bounds — not eliminates — the sandwich, and for shallow pools the bound itself (5%) is a material, guaranteed value leak per swap.

### Impact Explanation
Every user whose cross-chain GAS or GAS_AND_PAYLOAD deposit is auto-swapped to native PC, and every relayer/user receiving an excess-gas refund swapped back to PC, can have up to ~5% of the swapped value extracted by an attacker executing the sandwich, without any validator or admin misbehavior. This is a repeated, protocol-core value leak affecting the PRC20/native-asset accounting path (`CallPRC20DepositAutoSwap`, `CallUniversalCoreRefundUnusedGas`) that is reachable purely from unprivileged users submitting ordinary EVM transactions on Push Chain.

### Likelihood Explanation
Likelihood is moderate: it requires the attacker to identify pending inbound/outbound ballots close to quorum (observable on-chain) and to win block-ordering priority around the finalizing vote transaction, and it requires a WPC/PRC20 pool with limited depth relative to deposit size for the 5% band to be fully exploitable. On low-liquidity pools (likely in early deployments) this is straightforward and economically attractive since the entire 5% tolerance is realizable profit.

### Recommendation
Bind `minPCOut` to actual pool liquidity/depth rather than a flat percentage — e.g., use a TWAP-based reference price, cap the swap size relative to pool reserves, or let the recipient/route configuration set a liquidity-aware tolerance. Alternatively, execute quote-and-swap using an oracle-independent, on-chain-committed price (or a per-pool dynamic slippage parameter) so the realized tolerance shrinks as pool depth shrinks, rather than always allowing up to 5% loss regardless of market conditions.

### Proof of Concept
1. Attacker watches `x/uexecutor` for an inbound with `TxType_GAS`/`TxType_GAS_AND_PAYLOAD` that has reached 2-of-3 validator votes (visible via `PendingInbounds`/mempool).
2. Attacker submits an EVM transaction with higher gas price that swaps a large amount of WPC→PRC20 (or vice versa) in the same target pool right before the quorum-completing `MsgVoteInbound` lands in the block, moving the pool price unfavorably for the upcoming deposit swap.
3. When `VoteInbound` finalizes and calls `ExecuteInboundGas`, `GetSwapQuote` returns a quote reflecting the manipulated price; `CallPRC20DepositAutoSwap` executes with `minPCOut = quote*95/100`, still passing validation but paying the victim up to 5% less PC than fair value.
4. Attacker reverses their initial swap in a subsequent transaction, realizing profit approximately equal to the value extracted from the victim's deposit, bounded by the pool's liquidity and the 5% tolerance. [6](#0-5) [7](#0-6) [8](#0-7)

// GetSwapQuote calls QuoterV2.quoteExactInputSingle (commit=false) to get the expected
// output amount for swapping prc20 → wpc.
func (k Keeper) GetSwapQuote(
	ctx sdk.Context,
	quoterAddr, prc20Address, wpcAddress common.Address,
	fee, amount *big.Int,
) (*big.Int, error) {
	quoterABI, err := types.ParseUniswapQuoterV2ABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse QuoterV2 ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	params := types.AbiQuoteExactInputSingleParams{
		TokenIn:           prc20Address,
		TokenOut:          wpcAddress,
		AmountIn:          amount,
		Fee:               fee,
		SqrtPriceLimitX96: big.NewInt(0),
	}

	receipt, err := k.evmKeeper.CallEVM(ctx, quoterABI, ueModuleAccAddress, quoterAddr, false, nil, "quoteExactInputSingle", params)
	if err != nil {
		return nil, errors.Wrap(err, "QuoterV2 quoteExactInputSingle failed")
	}

	results, err := quoterABI.Methods["quoteExactInputSingle"].Outputs.Unpack(receipt.Ret)
	if err != nil {
		return nil, errors.Wrap(err, "failed to unpack quoteExactInputSingle result")
	}

	amountOut, ok := results[0].(*big.Int)
	if !ok {
		return nil, fmt.Errorf("unexpected type for amountOut: %T", results[0])
	}

	return amountOut, nil
}

// Calls Handler Contract to deposit prc20 tokens with auto-swap.
// fee and minPCOut must be pre-computed by the caller (see GetDefaultFeeTierForToken / GetSwapQuote).
func (k Keeper) CallPRC20DepositAutoSwap(
	ctx sdk.Context,
	prc20Address, to common.Address,
	amount, fee, minPCOut *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	k.Logger().Debug("EVM call: depositPRC20WithAutoSwap",
		"prc20", prc20Address.Hex(),
		"recipient", to.Hex(),
		"amount", amount.String(),
		"fee", fee.String(),
		"min_pc_out", minPCOut.String(),
	)
	handlerAddr := common.HexToAddress(uregistrytypes.SYSTEM_CONTRACTS["UNIVERSAL_CORE"].Address)

	abi, err := types.ParseUniversalCoreABI()
	if err != nil {
		return nil, errors.Wrap(err, "failed to parse Handler Contract ABI")
	}

	ueModuleAccAddress, _ := k.GetUeModuleAddress(ctx)

	// Before sending an EVM tx from module
	nonce, err := k.GetModuleAccountNonce(ctx)
	if err != nil {
		return nil, err
	}

	// increment first (safe for internal modules)
	if _, err := k.IncrementModuleAccountNonce(ctx); err != nil {
		return nil, err
	}

	return k.evmKeeper.DerivedEVMCall(
		ctx,
		abi,
		ueModuleAccAddress, // who is sending the transaction
		handlerAddr,        // destination: Handler contract
		big.NewInt(0),
		nil,
		true,   // commit = true (real tx, not simulation)
		false,  // gasless = false (@dev: we need gas to be emitted in the tx receipt)
		true,   // module sender = true
		&nonce, // manual nonce of module
		"depositPRC20WithAutoSwap",
		prc20Address,
		amount,
		to,
		fee,
		minPCOut,
		big.NewInt(0), // deadline = 0 → contract uses its default
	)
}

// applyGasRefund computes the excess gas (gasFee - gasFeeUsed) and, if positive,
// calls UniversalCore refundUnusedGas. The result is recorded in outbound.PcRefundExecution.
// It is called for both successful and failed outbounds — gas is consumed on the
// external chain regardless of execution outcome.
func (k Keeper) applyGasRefund(ctx sdk.Context, outbound *types.OutboundTx, obs *types.OutboundObservation) {
	if obs.GasFeeUsed == "" || outbound.GasFee == "" || outbound.GasToken == "" {
		return
	}

	gasFee := new(big.Int)
	if _, ok := gasFee.SetString(outbound.GasFee, 10); !ok {
		return
	}

	gasFeeUsed := new(big.Int)
	if _, ok := gasFeeUsed.SetString(obs.GasFeeUsed, 10); !ok {
		return
	}

	// No excess gas to refund
	if gasFee.Cmp(gasFeeUsed) <= 0 {
		return
	}

	refundAmount := new(big.Int).Sub(gasFee, gasFeeUsed)
	gasToken := common.HexToAddress(outbound.GasToken)

	// Refund recipient: prefer fund_recipient in revert_instructions, fall back to sender
	refundRecipient := outbound.Sender
	if outbound.RevertInstructions != nil && outbound.RevertInstructions.FundRecipient != "" {
		refundRecipient = outbound.RevertInstructions.FundRecipient
	}
	recipientAddr := common.HexToAddress(refundRecipient)

	refundPcTx := &types.PCTx{
		Sender:      outbound.Sender,
		BlockHeight: uint64(ctx.BlockHeight()),
	}

	// Step 1: try refund with swap (gasToken → PC native)
	fee, swapErr := k.GetDefaultFeeTierForToken(ctx, gasToken)
	var swapFallbackReason string

	if swapErr == nil {
		quote, quoteErr := k.getSwapQuoteForRefund(ctx, gasToken, fee, refundAmount)
		if quoteErr == nil {
			minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
			minPCOut.Div(minPCOut, big.NewInt(100))

			resp, err := k.CallUniversalCoreRefundUnusedGas(ctx, gasToken, refundAmount, recipientAddr, true, fee, minPCOut)
			if err == nil {
				refundPcTx.TxHash = resp.Hash
				refundPcTx.GasUsed = resp.GasUsed
				refundPcTx.Status = "SUCCESS"
				outbound.PcRefundExecution = refundPcTx
				return
			}
			swapFallbackReason = fmt.Sprintf("swap refund failed: %s", err.Error())
		} else {
			swapFallbackReason = fmt.Sprintf("quote fetch failed: %s", quoteErr.Error())
		}
	} else {
		swapFallbackReason = fmt.Sprintf("fee tier fetch failed: %s", swapErr.Error())
	}

// gasAndPayloadDepositAutoSwap handles the swap quote + deposit autoswap for GAS_AND_PAYLOAD.
func (k Keeper) gasAndPayloadDepositAutoSwap(
	sdkCtx sdk.Context,
	prc20AddressHex common.Address,
	ueaAddr common.Address,
	amount *big.Int,
) (*evmtypes.MsgEthereumTxResponse, error) {
	quoterAddr, err := k.GetUniversalCoreQuoterAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	wpcAddr, err := k.GetUniversalCoreWPCAddress(sdkCtx)
	if err != nil {
		return nil, err
	}

	fee, err := k.GetDefaultFeeTierForToken(sdkCtx, prc20AddressHex)
	if err != nil {
		return nil, err
	}

	quote, err := k.GetSwapQuote(sdkCtx, quoterAddr, prc20AddressHex, wpcAddr, fee, amount)
	if err != nil {
		return nil, err
	}

	// 5% slippage: minPCOut = quote * 95 / 100
	minPCOut := new(big.Int).Mul(quote, big.NewInt(95))
	minPCOut.Div(minPCOut, big.NewInt(100))

	return k.CallPRC20DepositAutoSwap(sdkCtx, prc20AddressHex, ueaAddr, amount, fee, minPCOut)
}
