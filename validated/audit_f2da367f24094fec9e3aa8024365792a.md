### Title
Missing address–pubkey binding in gasless account auto-creation allows corrupting arbitrary (including module) accounts, causing state-machine panic / DoS - (File: `app/ante/account_init_decorator.go`)

### Summary
`AccountInitDecorator.AnteHandle` creates a new `BaseAccount` at whatever address `sigTx.GetSigners()[0]` returns for gasless messages, without ever verifying that the address is actually derived from the signature's public key.

### Finding Description
For gasless message types (`MsgVoteInbound`, `MsgVoteOutbound`, `MsgExecutePayload`, `MsgMigrateUEA`, `MsgVoteChainMeta`, `MsgVoteTssKeyProcess`, `MsgVoteFundMigration`), `GetSigners()` simply parses the free-form `signer` protobuf field with no cryptographic tie to the tx's public key: [1](#0-0)  and `ValidateBasic` only checks that it is a syntactically valid bech32 address [2](#0-1) .

`AnteHandle` then does:
```
newAccAddr := signers[0]
if !aid.ak.HasAccount(ctx, newAccAddr) {
    ... aid.verifySignatureForNewAccount(ctx, tx, simulate) ...
    acc := aid.ak.NewAccountWithAddress(ctx, newAccAddr)
    acc.SetSequence(1)
    aid.ak.SetAccount(ctx, acc)
    return ctx, nil
}
``` [3](#0-2) 

`verifySignatureForNewAccount` never checks `sdk.AccAddress(pubKey.Address()) == newAccAddr` — the standard Cosmos SDK `SetPubKeyDecorator` invariant is absent here [4](#0-3) . For `SIGN_MODE_DIRECT`, the sign bytes are `BodyBytes + AuthInfoBytes + ChainID + AccountNumber`; the `Address` field placed into `signerData` is not part of what's cryptographically bound for direct-mode verification. This means an attacker can sign with **any keypair they control** while setting the message's `signer` field to an arbitrary bech32 address that has never been used on-chain — including a Cosmos module account address (e.g. `x/mint`, `x/uexecutor`'s "ue" account, etc.) computed via `authtypes.NewModuleAddress(name)`.

Because this decorator returns `ctx, nil` and terminates the ante chain immediately (it does not call `next`), it bypasses subsequent fee/signature decorators, but the account it just created is still committed: `baseapp.runTx` commits the ante-handler's cache-context state (`msCache.Write()`) as long as the `AnteHandler` itself returns no error, *before* running the actual message handler. So even if the inner message subsequently fails (e.g., `MsgVoteInbound`'s `isBonded` check rejects the forged signer as an unregistered universal validator) [5](#0-4) , the spurious `BaseAccount` created at the module address by the ante decorator remains committed to state.

If a module account address is targeted before that module account has been materialized in the auth store (e.g., a custom module such as `x/uexecutor`'s "ue" account, which is only created lazily on first use, per `GetModuleAccount`/`GetUeModuleAddress` usage in this codebase) [6](#0-5) , the subsequent legitimate lazy-creation call (`ak.GetModuleAccount`) will find an existing `BaseAccount` at that address and fail the type assertion to `ModuleAccountI`, which cosmos-sdk implements as a `panic`. Since every honest node executes the same deterministic state transition, this panic occurs identically on all validators, halting block execution/consensus for the module-dependent code path.

### Impact Explanation
An unprivileged attacker who can identify or predict a not-yet-materialized module account address can, with a single free (gasless) transaction and an arbitrary throwaway keypair, plant a `BaseAccount` at that address. This corrupts account-type invariants relied upon by `x/auth`'s module-account machinery and can crash/halt any code path that later calls `GetModuleAccount` for that name — a state-machine-level denial of service triggered purely by ordinary user tx submission, without needing to compromise any private key or module keeper. More generally, the same primitive lets an attacker "squat" any yet-unused address (potential future user or contract-derived UEA address) with sequence=1 and no pubkey, corrupting first-use nonce/pubkey-binding invariants for that address.

### Likelihood Explanation
Requires only crafting a gasless message (e.g. `MsgVoteInbound`) with `signer` set to the target module address and signing with any locally-generated keypair — no privileged access, no need to compromise validators, relayers, or TSS participants. The main uncertainty is whether the specific module account in question is already materialized in state by genesis time; this is not verifiable purely from the indexed code (module account genesis initialization order in `app.go`/module `InitGenesis` was not available in the indexed sources), so likelihood depends on which module account is targeted and its lazy-initialization timing.

### Recommendation
Add the missing binding check in `verifySignatureForNewAccount`: require `sdk.AccAddress(pubKey.Address()).Equals(newAccAddr)` before allowing account creation, mirroring cosmos-sdk's `SetPubKeyDecorator`. Additionally, explicitly reject account auto-creation when `newAccAddr` matches any known/reserved module account address (`ak.GetModuleAddress` set), and set the derived pubkey on the newly created account via `acc.SetPubKey(pubKey)` so future signature checks are properly bound.

### Proof of Concept
1. Compute a module account address, e.g. `moduleAddr := authtypes.NewModuleAddress("<a not-yet-materialized module name>")`.
2. Generate an arbitrary local keypair `Y` (attacker-controlled, unrelated to `moduleAddr`).
3. Build `MsgVoteInbound{Signer: moduleAddr.String(), Inbound: <any syntactically valid Inbound>}`.
4. Sign the tx with keypair `Y` using `SIGN_MODE_DIRECT`, submit as a gasless tx (no fee needed since `IsGaslessTx` matches this message type).
5. Observe that `AccountInitDecorator.AnteHandle` accepts the tx (`HasAccount(moduleAddr)` is false, signature verification succeeds against `Y`'s pubkey regardless of `moduleAddr`), creates a `BaseAccount` at `moduleAddr` with sequence 1, and commits it — even though the subsequent `VoteInbound` message handler later rejects the vote for lack of bonded-UV status.
6. Trigger any later code path that calls `ak.GetModuleAccount(ctx, "<that module>")`; observe the type-assertion panic due to the existing non-module `BaseAccount`.

func (aid AccountInitDecorator) verifySignatureForNewAccount(ctx sdk.Context, tx sdk.Tx, simulate bool) error {
	sigTx, ok := tx.(authsigning.Tx)
	if !ok {
		return errorsmod.Wrap(sdkerrors.ErrTxDecode, "invalid transaction type")
	}

	// stdSigs contains the sequence number, account number, and signatures.
	// When simulating, this would just be a 0-length slice.
	sigs, err := sigTx.GetSignaturesV2()
	if err != nil {
		return err
	}

	signers, err := sigTx.GetSigners()
	if err != nil {
		return err
	}

	// check that signer length and signature length are the same
	if len(sigs) != len(signers) {
		return errorsmod.Wrapf(sdkerrors.ErrUnauthorized, "invalid number of signer;  expected: %d, got %d", len(signers), len(sigs))
	}

	newAccAddr := sdk.AccAddress(signers[0])
	for _, sig := range sigs {
		pubKey := sig.PubKey
		if pubKey == nil {
			return errorsmod.Wrap(sdkerrors.ErrInvalidPubKey, "pubkey is not provided in signature")
		}

		// retrieve signer data
		chainID := ctx.ChainID()
		var accSequence uint64 = 0
		var accNum uint64 = 0

		// no need to verify signatures on recheck tx
		if !simulate && !ctx.IsReCheckTx() && ctx.IsSigverifyTx() {
			anyPk, _ := codectypes.NewAnyWithValue(pubKey)

			signerData := txsigning.SignerData{
				Address:       newAccAddr.String(),
				ChainID:       chainID,
				AccountNumber: accNum,
				Sequence:      accSequence,
				PubKey: &anypb.Any{
					TypeUrl: anyPk.TypeUrl,
					Value:   anyPk.Value,
				},
			}
			adaptableTx, ok := tx.(authsigning.V2AdaptableTx)
			if !ok {
				return fmt.Errorf("expected tx to implement V2AdaptableTx, got %T", tx)
			}
			txData := adaptableTx.GetSigningTxData()
			ctx.Logger().Debug("account init decorator: verifying signature for new account",
				"address", newAccAddr.String(),
				"chain_id", chainID,
				"acc_num", accNum,
				"sequence", accSequence,
			)
			err = authsigning.VerifySignature(ctx, pubKey, signerData, sig.Data, aid.signModeHandler, txData)
			if err != nil {
				var errMsg string
				if OnlyLegacyAminoSigners(sig.Data) {
					// If all signers are using SIGN_MODE_LEGACY_AMINO, we rely on VerifySignature to check account sequence number,
					// and therefore communicate sequence number as a potential cause of error.
					errMsg = fmt.Sprintf("signature verification failed; please verify account number (%d), sequence (%d) and chain-id (%s)", accNum, accSequence, chainID)
				} else {
					errMsg = fmt.Sprintf("signature verification failed; please verify account number (%d) and chain-id (%s): (%s)", accNum, chainID, err.Error())
				}
				ctx.Logger().Debug("account init decorator: signature invalid for new account",
					"address", newAccAddr.String(),
					"chain_id", chainID,
				)
				return errorsmod.Wrap(sdkerrors.ErrUnauthorized, errMsg)

			}
		} else {
			ctx.Logger().Debug("account init decorator: skipping signature verification",
				"address", newAccAddr.String(),
				"simulate", simulate,
				"is_recheck_tx", ctx.IsReCheckTx(),
				"is_sigverify_tx", ctx.IsSigverifyTx(),
			)
		}
	}
	return nil
```

func (ms msgServer) VoteInbound(ctx context.Context, msg *types.MsgVoteInbound) (*types.MsgVoteInboundResponse, error) {
	signerAccAddr, err := sdk.AccAddressFromBech32(msg.Signer)
	if err != nil {
		return nil, fmt.Errorf("invalid signer address: %w", err)
	}

	// Convert account to validator operator address
	signerValAddr := sdk.ValAddress(signerAccAddr)

	// Lookup the linked universal validator for this signer
	isBonded, err := ms.k.uvalidatorKeeper.IsBondedUniversalValidator(ctx, msg.Signer)
	if err != nil {
		return nil, errors.Wrapf(err, "failed to check bonded status for signer %s", msg.Signer)
	}
	if !isBonded {
		return nil, fmt.Errorf("universal validator for signer %s is not bonded", msg.Signer)
	}

	isTombstoned, err := ms.k.uvalidatorKeeper.IsTombstonedUniversalValidator(ctx, msg.Signer)
	if err != nil {
		return nil, errors.Wrapf(err, "failed to check tombstoned status for signer %s", msg.Signer)
	}
	if isTombstoned {
		return nil, fmt.Errorf("universal validator for signer %s is tombstoned", msg.Signer)
	}
