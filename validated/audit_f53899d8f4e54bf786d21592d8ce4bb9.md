### Title
`GetPaginatedNowWitnessList` API performs a full unbounded scan of `VotesStore` per request, enabling DoS via unauthenticated RPC/HTTP calls - (File: framework/src/main/java/org/tron/core/Wallet.java)

### Summary
The `massUpdatePools()` finding describes an unbounded loop over a growable collection reachable from an external call, risking resource exhaustion / DoS. In java-tron, `Wallet.getPaginatedNowWitnessList()` — exposed via unauthenticated gRPC (`WalletSolidity.GetPaginatedNowWitnessList`) and HTTP (`GetPaginatedNowWitnessListServlet`) — always performs a full, unbounded iteration over the entire `VotesStore` on every call, regardless of the caller-supplied `offset`/`limit` pagination parameters, before applying pagination to the output.

### Finding Description
`getPaginatedNowWitnessList(offset, limit)` first fetches all witnesses, then calls the private helper `countVote(votesStore)`, which walks a full DB iterator over `VotesStore` to recompute real-time vote deltas: [1](#0-0) [2](#0-1) 

Only after this full-store scan does the code apply `skip(offset).limit(limit)` to the output witness list: [3](#0-2) 

`VotesStore` accumulates one entry per account per vote transaction (`VoteWitnessContract`) submitted during the current maintenance cycle, and is only cleared during `MaintenanceManager.doMaintenance()`'s own full-store `countVote` pass at the next cycle boundary: [4](#0-3) 

Because any account can freely submit vote transactions between maintenance cycles, the size of `VotesStore` is attacker-influenceable and can grow large before the next maintenance clears it. The pagination parameters (`offset`/`limit`) only bound the *response size*, not the *work performed* — the full-store iteration cost is paid on every single call. This function is reachable without authentication via:
- gRPC `WalletSolidityApi.getPaginatedNowWitnessList` [5](#0-4) 
- HTTP `GetPaginatedNowWitnessListServlet` [6](#0-5) 
- The Solidity-node and PBFT-node equivalents that simply forward to the same implementation [7](#0-6) 

### Impact Explanation
Each anonymous, unauthenticated request to this widely-exposed API triggers a full linear scan of an unbounded, attacker-growable store, consuming CPU and I/O proportional to the number of outstanding votes in the current cycle. Repeated calls (a single client can call this endpoint continuously, and the rate limiter only throttles per-caller request rate, not the cost of each individual request) can degrade node responsiveness for legitimate RPC-API consumers — a resource-exhaustion DoS vector on the node's RPC/HTTP surface, analogous to the unbounded `massUpdatePools()` loop in the original report.

### Likelihood Explanation
Likelihood is moderate: no privileged access is required, the endpoint is public and commonly enabled on full/solidity/PBFT nodes, and the size of `VotesStore` is directly influenced by ordinary vote transactions from any account, which are inexpensive to broadcast repeatedly to inflate the store before hammering this API.

### Recommendation
Avoid recomputing vote deltas for the entire `VotesStore` on every paginated read; either cache/maintain incrementally-updated real-time vote counts instead of recomputing from a full store scan per request, or bound/rate-limit the cost of the scan (e.g., cap the number of `VotesStore` entries processed per call, or compute the aggregate off the request path on a schedule) so that request cost does not scale unboundedly with attacker-controllable state.

### Proof of Concept
1. From any account, repeatedly submit `VoteWitnessContract` transactions across many distinct voter accounts within a single maintenance cycle to inflate `VotesStore` size.
2. Concurrently issue many calls to the public `GetPaginatedNowWitnessList` gRPC/HTTP endpoint (e.g., with `offset=0, limit=1`).
3. Observe that each call's latency/CPU cost scales with the full `VotesStore` size via `countVote()` [8](#0-7) , independent of the tiny requested page size, degrading node responsiveness for other RPC-API clients.

  private Map<ByteString, Long> countVote(VotesStore votesStore) {
    // Initialize a result map to store vote changes for each witness
    Map<ByteString, Long> countWitness = Maps.newHashMap();

    // VotesStore is a key-value store, where the key is the address of the voter
    Iterator<Entry<byte[], VotesCapsule>> dbIterator = votesStore.iterator();

    while (dbIterator.hasNext()) {
      Entry<byte[], VotesCapsule> next = dbIterator.next();
      VotesCapsule votes = next.getValue();

      /**
       * VotesCapsule contains two lists:
       * - Old votes: Last votes from the previous epoch, updated in maintenance period
       * - New votes: Latest votes in current epoch, updated after each vote transaction
       */
      votes.getOldVotes().forEach(vote -> {
        ByteString voteAddress = vote.getVoteAddress();
        long voteCount = vote.getVoteCount();
        countWitness.put(voteAddress,
            countWitness.getOrDefault(voteAddress, 0L) - voteCount);
      });
      votes.getNewVotes().forEach(vote -> {
        ByteString voteAddress = vote.getVoteAddress();
        long voteCount = vote.getVoteCount();
        countWitness.put(voteAddress,
            countWitness.getOrDefault(voteAddress, 0L) + voteCount);
      });
    }
    return countWitness;

  private Map<ByteString, Long> countVote(VotesStore votesStore) {
    final Map<ByteString, Long> countWitness = Maps.newHashMap();
    Iterator<Entry<byte[], VotesCapsule>> dbIterator = votesStore.iterator();
    long sizeCount = 0;
    while (dbIterator.hasNext()) {
      Entry<byte[], VotesCapsule> next = dbIterator.next();
      VotesCapsule votes = next.getValue();
      votes.getOldVotes().forEach(vote -> {
        ByteString voteAddress = vote.getVoteAddress();
        long voteCount = vote.getVoteCount();
        if (countWitness.containsKey(voteAddress)) {
          countWitness.put(voteAddress, countWitness.get(voteAddress) - voteCount);
        } else {
          countWitness.put(voteAddress, -voteCount);
        }
      });
      votes.getNewVotes().forEach(vote -> {
        ByteString voteAddress = vote.getVoteAddress();
        long voteCount = vote.getVoteCount();
        if (countWitness.containsKey(voteAddress)) {
          countWitness.put(voteAddress, countWitness.get(voteAddress) + voteCount);
        } else {
          countWitness.put(voteAddress, voteCount);
        }
      });
      sizeCount++;
      votesStore.delete(next.getKey());
    }
