### Title
Gas Key Balance Permanently Irrecoverable When Account Holds Only a `GasKeyFunctionCall` Key and Balance Exceeds `MAX_BALANCE_TO_BURN` — (`runtime/runtime/src/access_keys.rs`)

---

### Summary

The nearcore Gas Key feature introduces a `balance` field inside access keys. When that balance exceeds `GasKeyInfo::MAX_BALANCE_TO_BURN` (1 NEAR) and the account's only remaining key is a `GasKeyFunctionCall` (restricted) key, the balance is permanently locked: every exit path is blocked by the protocol with no escape hatch.

---

### Finding Description

**Three interlocking guards create the lock:**

**1. `delete_gas_key` blocks `DeleteKey`**

`delete_gas_key` in `runtime/runtime/src/access_keys.rs` returns `GasKeyBalanceTooHigh` and aborts without deleting the key or returning the balance to the account whenever `gas_key_info.balance > GasKeyInfo::MAX_BALANCE_TO_BURN`. [1](#0-0) 

`MAX_BALANCE_TO_BURN` is hard-coded at exactly 1 NEAR: [2](#0-1) 

**2. `action_delete_account` blocks `DeleteAccount`**

The same threshold is applied to the aggregate gas key balance sum before account deletion proceeds: [3](#0-2) 

**3. `WithdrawFromGasKey` is the only recovery path — but it is unreachable from a `GasKeyFunctionCall` key**

`action_withdraw_from_gas_key` moves balance from the gas key back to the account: [4](#0-3) 

However, to invoke this action the user must submit a signed transaction. The verifier applies `verify_function_call_permission` to any key that has `function_call_permission()` — which includes `GasKeyFunctionCall` keys. Because `WithdrawFromGasKey` is not a `FunctionCall` action, the permission check rejects it unconditionally: [5](#0-4) 

A `GasKeyFullAccess` key has no such restriction and can sign `WithdrawFromGasKey`. But if the account has already deleted all full-access and `GasKeyFullAccess` keys, only the restricted `GasKeyFunctionCall` key remains, and the withdrawal is permanently blocked.

**The `GasKeyBalanceTooHigh` error is confirmed by tests:** [6](#0-5) [7](#0-6) 

---

### Impact Explanation

**Impact: Loss of funds.**

Any NEAR tokens deposited into a gas key via `TransferToGasKey` that push the balance above 1 NEAR become permanently unrecoverable once the account's full-access and `GasKeyFullAccess` keys are gone. The tokens are not burned (they remain in the trie under the access key entry), not transferred to any beneficiary, and not refundable — they are simply frozen forever. The broken invariant is: *every balance credited to an account-controlled key must be reachable by the account owner*.

---

### Likelihood Explanation

**Likelihood: Low but reachable by an ordinary user without any privileged assumption.**

The trigger sequence is:
1. User adds a `GasKeyFunctionCall` key (e.g., for a dApp).
2. User funds the gas key with > 1 NEAR via `TransferToGasKey`.
3. User deletes their full-access key (e.g., to "lock" the account to function-call-only mode, a pattern used in some wallet designs).

All three steps are normal, unprivileged, user-initiated transactions. No validator control, no malicious deployment, and no external system is required. The protocol itself provides no warning or guard against reaching this state.

---

### Recommendation

Provide an unconditional escape hatch for gas key balances. Two options:

1. **Allow `WithdrawFromGasKey` to be signed by any key type**, including `GasKeyFunctionCall`. The action only moves balance from the gas key to the owning account — it does not grant cross-account authority — so relaxing the permission check here does not introduce authorization risk.

2. **Remove the `GasKeyBalanceTooHigh` guard and instead transfer the gas key balance to the account (or beneficiary) during `DeleteKey` / `DeleteAccount`**, rather than burning it. The burn-cap was introduced to limit accidental loss, but it should not create a permanent lock.

---

### Proof of Concept

```
1. alice.near has: full-access key K_full, gas key K_gas (GasKeyFunctionCall,
   receiver="ft.near", methods=["ft_transfer"])

2. alice.near calls TransferToGasKey { public_key: K_gas, deposit: 2 NEAR }
   → gas key balance = 2 NEAR  (> MAX_BALANCE_TO_BURN = 1 NEAR)

3. alice.near calls DeleteKey { public_key: K_full }
   → only K_gas remains on the account

4. alice.near tries DeleteKey { public_key: K_gas }
   → runtime: delete_gas_key: balance 2 NEAR > MAX_BALANCE_TO_BURN
   → ActionError::GasKeyBalanceTooHigh  ← BLOCKED

5. alice.near tries DeleteAccount { beneficiary_id: "bob.near" }
   → runtime: compute_gas_key_balance_sum = 2 NEAR > MAX_BALANCE_TO_BURN
   → ActionError::GasKeyBalanceTooHigh  ← BLOCKED

6. alice.near tries WithdrawFromGasKey { public_key: K_gas, amount: 1.5 NEAR }
   signed by K_gas (GasKeyFunctionCall)
   → verifier: verify_function_call_permission rejects WithdrawFromGasKey
     (not a FunctionCall action)
   → InvalidTxError  ← BLOCKED

Result: 2 NEAR is permanently locked in the gas key entry in the trie.
        No protocol path exists to recover it.
```

pub(crate) fn action_withdraw_from_gas_key(
    state_update: &mut TrieUpdate,
    account: &mut Account,
    result: &mut ActionResult,
    account_id: &AccountId,
    action: &WithdrawFromGasKeyAction,
) -> Result<(), RuntimeError> {
    let Some(mut access_key) = get_access_key(state_update, account_id, &action.public_key)? else {
        result.result = Err(ActionErrorKind::GasKeyDoesNotExist {
            account_id: account_id.clone(),
            public_key: Box::new(action.public_key.clone()),
        }
        .into());
        return Ok(());
    };
    let Some(gas_key_info) = access_key.gas_key_info_mut() else {
        // Key exists but is not a gas key
        result.result = Err(ActionErrorKind::GasKeyDoesNotExist {
            account_id: account_id.clone(),
            public_key: Box::new(action.public_key.clone()),
        }
        .into());
        return Ok(());
    };

    let Some(updated_balance) = gas_key_info.balance.checked_sub(action.amount) else {
        result.result = Err(ActionErrorKind::InsufficientGasKeyBalance {
            account_id: account_id.clone(),
            public_key: Box::new(action.public_key.clone()),
            balance: gas_key_info.balance,
            required: action.amount,
        }
        .into());
        return Ok(());
    };
    gas_key_info.balance = updated_balance;
    set_access_key(state_update, account_id.clone(), action.public_key.clone(), &access_key);

    let new_account_balance = account.amount().checked_add(action.amount).ok_or_else(|| {
        RuntimeError::StorageError(StorageError::StorageInconsistentState(
            "Account balance integer overflow".to_string(),
        ))
    })?;
    account.set_amount(new_account_balance);
    Ok(())

    #[test]
    fn test_delete_account_gas_key_balance_too_high() {
        let (account_id, public_key, access_key) = test_account_keys();
        let public_keys: Vec<PublicKey> = (0..3)
            .map(|i| PublicKey::from_seed(KeyType::ED25519, &format!("gas_key_{i}")))
            .collect();
        let mut state_update = setup_account(&account_id, &public_key, &access_key);
        let mut account = get_account(&state_update, &account_id).unwrap().unwrap();
        for public_key in &public_keys {
            add_gas_key_to_account(&mut state_update, &mut account, &account_id, public_key);
        }

        // Fund gas keys so total exceeds 1 NEAR
        let deposit_amounts = [
            Balance::from_millinear(400),
            Balance::from_millinear(400),
            Balance::from_millinear(201),
        ];
        for (pk, amount) in public_keys.iter().zip(deposit_amounts.iter()) {
            transfer_to_gas_key(&mut state_update, &account_id, pk, *amount);
        }
        state_update.commit(StateChangeCause::InitialState);

        let action_result = test_delete_account(
            &account_id,
            AccountContract::from_local_code_hash(CryptoHash::default()),
            100,
            PROTOCOL_VERSION,
            &mut state_update,
        );
        let expected_total =
            deposit_amounts.iter().fold(Balance::ZERO, |acc, x| acc.checked_add(*x).unwrap());
        assert_eq!(
            action_result.result,
            Err(ActionErrorKind::GasKeyBalanceTooHigh {
                account_id: account_id.clone(),
                public_key: None,
                balance: expected_total,
            }
            .into())
        );
        assert_eq!(action_result.tokens_burnt, Balance::ZERO);
    }
