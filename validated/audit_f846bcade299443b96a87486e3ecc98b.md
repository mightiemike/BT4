The reported bug class (using `transferFrom()` instead of `safeTransferFrom()` so a non-compatible recipient can permanently lock the asset) does not have a reachable analog in nearcore. The runtime already implements the safe-transfer equivalent for its own value-transfer path: `check_account_existence` in `runtime/runtime/src/actions.rs` explicitly validates whether the receiver account exists (or is eligible for implicit creation) before an `Action::Transfer` is allowed to proceed, and rejects the receipt with `ActionErrorKind::AccountDoesNotExist` when it is not. [1](#0-0) 

When such a rejection happens, the deposit is not lost — the transaction fails atomically and the funds remain with (or are refunded to) the sender, as verified by `test_refund_on_send_money_to_non_existent_account`. [2](#0-1) 

Additionally, the closest higher-level analog — the NEAR Wallet Contract's emulated ERC-20/NEP-141 transfers — already implements the "safe transfer" pattern by checking `storage_balance_of` on the receiver before calling `ft_transfer`, and performing `storage_deposit` first if the receiver isn't registered, rather than blindly transferring and risking a stuck balance. [3](#0-2) 

Since there is no unprivileged, reachable path where a NEAR-native or wallet-contract-mediated transfer can permanently strand value in an account that cannot handle it (the runtime instead fails and refunds, or checks registration first), this bug class does not translate into a valid Medium/High/Critical finding for nearcore.

pub fn test_refund_on_send_money_to_non_existent_account(node: impl Node) {
    let account_id = &node.account_id().unwrap();
    let node_user = node.user();
    let root = node_user.get_state_root();
    let money_used = Balance::from_yoctonear(10);
    // Successful atomic transfer has the same cost as failed atomic transfer.
    let fee_helper = fee_helper(&node);
    let transfer_cost = fee_helper.transfer_cost();
    let transaction_result =
        node_user.send_money(account_id.clone(), eve_dot_alice_account(), money_used).unwrap();
    assert_eq!(
        transaction_result.status,
        FinalExecutionStatus::Failure(
            ActionError {
                index: Some(0),
                kind: ActionErrorKind::AccountDoesNotExist { account_id: eve_dot_alice_account() }
            }
            .into()
        )
    );
    assert_eq!(transaction_result.receipts_outcome.len(), 2 + extra_refund_outcomes());
    let new_root = node_user.get_state_root();
    assert_ne!(root, new_root);
    let result1 = node_user.view_account(account_id).unwrap();
    assert_eq!(
        (result1.amount, result1.locked),
        (
            TESTING_INIT_BALANCE
                .checked_sub(TESTING_INIT_STAKE)
                .unwrap()
                .checked_sub(transfer_cost)
                .unwrap(),
            TESTING_INIT_STAKE
        )
    );
    assert_eq!(node_user.get_access_key_nonce_for_signer(account_id).unwrap(), 1);
    let result2 = node_user.view_account(&eve_dot_alice_account());
    assert!(result2.is_err());
}
