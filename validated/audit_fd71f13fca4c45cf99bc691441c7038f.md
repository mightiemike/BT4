## Analog Found

### Title
Starknet OS `replace_class` syscall skips the declared-class and Cairo1-only checks enforced by Blockifier, causing sequencer/prover state divergence - (File: `crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/execution/syscall_impls.cairo`)

### Summary
The external report's root cause pattern — a privileged operation whose safety depends on an *implicit* validation that one code path enforces but another does not — maps onto a real gap between the sequencer's Blockifier execution of the `replace_class` syscall and the Starknet OS's (Cairo) re-execution of the same syscall used for proving.

### Finding Description
When a contract invokes the `replace_class` syscall, Blockifier's implementation performs two checks before mutating the class hash: [1](#0-0) 

It (1) requires the target `class_hash` to already be declared (`get_compiled_class` returns an error otherwise) and (2) requires the declared class to be Cairo1 (`is_cairo1`), explicitly rejecting Cairo0/deprecated class hashes.

The Starknet OS Cairo implementation of the same syscall, used by the prover to re-execute the block and produce the proof of correct execution, does **not** perform either check. It contains an explicit TODO acknowledging the missing declared-class validation, and has no analog of the Cairo1-only check at all: [2](#0-1) 

The same gap exists in the deprecated (Cairo0) syscall dispatch path used by the OS: [3](#0-2) 

Because Cairo allows a contract to invoke `replace_class_syscall` and inspect its `Result` without unwrapping/panicking (i.e., without reverting the whole transaction on error), a contract can deliberately probe the syscall with an undeclared or Cairo0 class hash and branch on success/failure. Blockifier will return an error for such a call (since the class is undeclared or not Cairo1), while the OS's `execute_replace_class` unconditionally accepts the request and writes the new (possibly undeclared) class hash into `contract_state_changes`.

### Impact Explanation
This is exactly the "authority/precondition enforced in one path but not the other" bug class from the reference report, but reachable via a single unprivileged transaction against the Starknet sequencer stack rather than a privileged CPI. If the sequencer (Blockifier) and the Starknet OS (used for STARK proving/re-execution) disagree on whether a `replace_class` call succeeds, the OS-computed final state (and thus the block's provable state diff/state root) can diverge from what the sequencer already committed on L1 as the block's state diff. This is a state-commitment/honest-node-divergence class issue: the prover either fails to reproduce the committed state (blocking proof generation and therefore blocking confirmation of new blocks), or — if the divergent path happens to be silently tolerated — the network ends up proving an execution trace that permits setting a contract's class hash to an undeclared/invalid class, which is an unauthorized state mutation.

### Likelihood Explanation
The only prerequisite is an on-chain contract that calls `replace_class_syscall` and does not immediately `.unwrap_syscall()` the result (i.e., pattern-matches on the `Result`), which is fully within the control of any contract deployer, and can then be triggered by any unprivileged invoke transaction. No special privileges, staking role, or operator collusion is required.

### Recommendation
Port the same two checks Blockifier performs — (1) the class hash must be declared (fail otherwise), and (2) the declared class must be Cairo1 — into the Starknet OS's Cairo `execute_replace_class` implementations (both `syscall_impls.cairo` and the deprecated syscall dispatcher), so the OS's semantics for `replace_class` are provably identical to Blockifier's for both the success and failure paths.

### Proof of Concept
1. Declare (via a normal `DECLARE` transaction) a Cairo0 (deprecated) class, or simply pick an arbitrary undeclared `class_hash` felt.
2. Deploy/invoke a contract whose entry point calls `replace_class_syscall(class_hash)` and matches on the `Result` (does not call `.unwrap_syscall()`), e.g. storing whether the call succeeded.
3. Submit this as a normal `INVOKE` transaction. Under Blockifier, the syscall returns `Err` (undeclared class / not Cairo1), so the contract's stored "success" flag is `false` and no class-hash state change occurs, matching `crates/blockifier/src/execution/syscalls/syscall_tests/replace_class.rs` negative-flow tests.
4. When the block is re-executed by the Starknet OS for proving, `execute_replace_class` in `syscall_impls.cairo` performs no declared/Cairo1 check, so it treats the call as successful, updating `contract_state_changes` with the (undeclared) class hash — a different execution result and state diff than what Blockifier produced and the sequencer already committed.

    pub fn replace_class(&mut self, class_hash: ClassHash) -> SyscallResult<()> {
        // Ensure the class is declared (by reading it), and of type V1.
        let compiled_class = self.state.get_compiled_class(class_hash)?;

        if !is_cairo1(&compiled_class) {
            return Err(SyscallExecutionError::ForbiddenClassReplacement { class_hash });
        }
        self.state.set_class_hash_at(self.call.storage_address, class_hash)?;
        Ok(())
    }

// Replaces the class.
func execute_replace_class{
    range_check_ptr,
    syscall_ptr: felt*,
    contract_state_changes: DictAccess*,
    revert_log: RevertLogEntry*,
}(contract_address: felt) {
    alloc_locals;
    let request = cast(syscall_ptr + RequestHeader.SIZE, ReplaceClassRequest*);

    // Reduce gas.
    let success = reduce_syscall_gas_and_write_response_header(
        total_gas_cost=REPLACE_CLASS_GAS_COST, request_struct_size=ReplaceClassRequest.SIZE
    );
    if (success == FALSE) {
        // Not enough gas to execute the syscall.
        return ();
    }

    let class_hash = request.class_hash;

    // TODO(Yoni, 1/1/2026): Check that there is a declared contract class with the given hash.
    local state_entry: StateEntry*;
    %{ GetContractAddressStateEntry %}

    tempvar new_state_entry = new StateEntry(
        class_hash=class_hash, storage_ptr=state_entry.storage_ptr, nonce=state_entry.nonce
    );

    dict_update{dict_ptr=contract_state_changes}(
        key=contract_address,
        prev_value=cast(state_entry, felt),
        new_value=cast(new_state_entry, felt),
    );

    assert [revert_log] = RevertLogEntry(selector=CHANGE_CLASS_ENTRY, value=state_entry.class_hash);
    let revert_log = &revert_log[1];

    return ();
}
